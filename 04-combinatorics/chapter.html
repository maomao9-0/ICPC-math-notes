04 — Advanced Combinatorics

Combinatorics is not primarily a collection of formulas. It is the job of describing exactly what one valid object is, then counting those objects without losing or duplicating any of them. This chapter starts from that description. It assumes that factorials and binomial coefficients are already in your library, but it does not assume that you have previously seen the counting models below.

Before doing algebra, write four answers on paper:

  1. What is one object I am counting?
  2. Are its atoms labelled (distinguishable)?
  3. Does the order of components matter?
  4. Which restrictions are hard, and is their intersection easier to count?

Those answers prevent most wrong applications of a correct formula.

Prerequisites and learning objectives

Read proofs and counting arguments and units in modular algebra. After this chapter you should be able to derive an inclusion–exclusion sum, distinguish labelled assignments from unlabelled partitions, identify a unique recursive split, and expose convolution inside a binomial sum.

Throughout, \([n]=\{1,\ldots,n\}\) for an integer \(n\ge0\), with \([0]=\varnothing\). An empty product is \(1\). We use \(\binom nk=0\) for \(k<0\) or \(k>n\) when \(n\ge0\). The value \(0^0=1\) in a counting formula represents the unique empty function. Binomial coefficients count subsets; factorials count linear orders of distinct objects. Neither definition requires division in a coefficient ring.

1. Recognition map

Wording in a statement First model to try The question to ask next
every required property is present inclusion–exclusion (IE) over missing properties can I count an intersection of chosen missing properties?
exactly/at least \(k\) properties binomial inversion or weighted IE how many selected conditions does each object satisfy?
partition labelled objects into unlabeled nonempty groups Stirling numbers of the second kind are the groups really unordered?
cycles of a permutation unsigned Stirling numbers of the first kind where can the new label be inserted?
recursively nested/balanced/plane-tree object Catalan decomposition does the first return/root split it independently?
sum over subsets whose term depends only on its size binomial transform can factorial scaling turn it into convolution?
forbidden row–column assignments rook polynomial are selected forbidden assignments compatible?

For example, “put \(n\) students into \(k\) nonempty teams” has labelled students but unlabelled teams. “Assign every student one of \(k\) named rooms” has labelled rooms. The two answers differ by a factor of \(k!\); it is not a minor implementation detail.

2. Inclusion–exclusion: correcting overcounting

Suppose \(U\) is the set of all candidate objects and \(E_i\) is the set of objects violating requirement \(i\). We want objects in none of the bad sets:

\[|U\setminus(E_1\cup\cdots\cup E_m)|.\]

The easy count \(|U|\) includes bad objects. Subtracting every \(|E_i|\) removes an object that violates two requirements twice, so it is now missing once too many. Add pair intersections back; then three-way intersections are too large again; and so on. The resulting formula is

\[ |U\setminus\textstyle\bigcup_i E_i| =\sum_{S\subseteq[m]}(-1)^{|S|}\left|\bigcap_{i\in S}E_i\right|. \tag{IE} \]

The empty intersection is \(U\). Formula (IE) is safest when understood per object: if a particular object violates exactly \(t\) requirements, it occurs in \(\binom{t}{j}\) intersections of size \(j\), so its total coefficient is

\[\sum_{j=0}^{t}(-1)^j\binom tj=(1-1)^t.\]

It is \(1\) for a valid object (\(t=0\)) and \(0\) otherwise. This tells us exactly what IE is calculating: it filters all candidates down to candidates with no bad property.

Example: functions that use every target

How many functions from \([n]=\{1,\ldots,n\}\) to \([k]\) use every one of the \(k\) targets? There are \(k^n\) unrestricted functions. Let \(E_j\) mean “target \(j\) is unused.” If we insist that a chosen set \(S\) of \(i\) targets is unused, each input has only \(k-i\) possible images, so the intersection has \((k-i)^n\) functions. There are \(\binom ki\) choices of \(S\). Thus

\[\#\text{surjections}=\sum_{i=0}^{k}(-1)^i\binom ki(k-i)^n. \tag{1}\]

Notice the separate meaning of every factor: choose which forbidden targets are absent, then count functions that avoid all of them. IE is useful here because intersections are simpler than “uses every target” directly.

Exactly \(r\) satisfied conditions

Sometimes the target is not “none of the bad events.” Let \(a_j\) be the number of objects satisfying exactly \(j\) of \(m\) conditions. Let \(b_k\) count pairs

\[\bigl(\text{object},\ \text{a chosen set of $k$ conditions it satisfies}\bigr).\]

An object satisfying exactly \(j\) conditions contributes \(\binom jk\) such pairs, so double counting gives

\[b_k=\sum_{j\ge k}\binom jk a_j. \tag{2}\]

Binomial inversion undoes that “choose \(k\) among \(j\)” operation:

\[a_r=\sum_{k=r}^{m}(-1)^{k-r}\binom kr b_k. \tag{3}\]

To verify this inverse, fix an object satisfying \(j\) conditions. Its coefficient on the right is

\[ \sum_{k=r}^j(-1)^{k-r}\binom kr\binom jk =\binom jr\sum_{k=r}^j(-1)^{k-r}\binom{j-r}{k-r} =\binom jr(1-1)^{j-r}. \]

The first equality chooses the \(r\) distinguished conditions first, then the other \(k-r\) selected conditions. This weight is one when \(j=r\) and zero otherwise, which proves (3). Notice that \(b_k\) counts marked pairs, not simply the objects satisfying at least \(k\) conditions.

For example, take all subsets of \(\{1,2\}\) and let condition \(i\) be membership of \(i\). Then \((a_0,a_1,a_2)=(1,2,1)\) and \((b_0,b_1,b_2)=(4,4,1)\): the full subset contributes twice to \(b_1\). Formula (3) gives \(a_1=b_1-2b_2=2\). Treating \(b_1\) as the three nonempty subsets would instead give \(1\), exposing the mistaken interpretation.

Use (2) to derive the quantity you can count, and (3) only after you know what \(b_k\) means. This prevents the common mistake of alternating signs without a defined universe.

3. Three recurring object families

Stirling numbers: partitions and permutation cycles

The second-kind Stirling number \(\left\{ {n\atop k}\right\}\) is the number of ways to split \(n\) labelled elements into \(k\) nonempty unlabelled blocks. Consider where label \(n\) goes. Either it joins one of the existing \(k\) blocks of a partition of \([n-1]\), or it forms its own block beside a partition into \(k-1\) blocks. Therefore

\[ \left\{ {n\atop k}\right\} =k\left\{ {n-1\atop k}\right\} +\left\{ {n-1\atop k-1}\right\}. \tag{4} \]

For instance, \(\left\{ {3\atop2}\right\}=3\): the singleton can be \(1\), \(2\), or \(3\). If the \(k\) blocks are then assigned to \(k\) named targets, there are \(k!\left\{ {n\atop k}\right\}\) functions using every target. Comparing this with (1) explains, rather than merely states,

\[\left\{ {n\atop k}\right\}={1\over k!}\sum_{i=0}^k(-1)^{k-i}\binom ki i^n.\]

This is first an identity of integers. If it is evaluated by dividing in a coefficient ring, \(k!\) must be a unit; over \(\mathbb F_p\) the usual factorial-inverse route therefore requires \(k<p\).

The unsigned first-kind number \(\left[ {n\atop k}\right]\) counts permutations of \([n]\) having \(k\) cycles. To add label \(n\), either make it a one-element cycle, or insert it immediately after any of the \(n-1\) existing labels in a cycle. This gives

\[ \left[ {n\atop k}\right] =(n-1)\left[ {n-1\atop k}\right] +\left[ {n-1\atop k-1}\right]. \tag{5} \]

Both triangles begin with value \(1\) at \((n,k)=(0,0)\) and zero outside \(0\le k\le n\); entries with \(k=0<n\) are zero. For \(n=3\), the cycle counts for \(k=1,2,3\) are \(2,3,1\): the two directed three-cycles, the three choices of a transposition, and the identity. These sum to \(3!=6\).

The second-kind triangle also changes polynomial bases. Let \(x^{\underline j}=x(x-1)\cdots(x-j+1)\), with \(x^{\underline0}=1\). Counting functions from \([K]\) to \([x]\) by the partition of inputs with equal images gives

\[x^K=\sum_{j=0}^K\left\{{K\atop j}\right\}x^{\underline j}.\]

Each summand first partitions the inputs into \(j\) nonempty fibers, then assigns distinct target names to those fibers. The proof holds for all nonnegative integer \(x\), hence gives a polynomial identity over the integers. For \(K=3\), \(x^3=x^{\underline3}+3x^{\underline2}+x\).

Catalan objects: an independent first split

Catalan numbers count many objects because those objects have the same decomposition. A balanced-parenthesis string is either empty, or has the form

( a balanced string ) another balanced string. The first matching ) creates this split uniquely. If \(C_n\) counts strings with \(n\) pairs, choosing \(i\) pairs inside the first pair leaves \(n-1-i\) pairs after it, so

\[C_0=1,\qquad C_n=\sum_{i=0}^{n-1}C_iC_{n-1-i}. \tag{6}\]

The product appears because the two pieces can be chosen independently. With \(C(x)=\sum_{n\ge0}C_nx^n\), (6) becomes \(C(x)=1+xC(x)^2\), from which

\[C_n={1\over n+1}\binom{2n}{n}.\]

One direct derivation views a parenthesis string as a path with an up-step for ( and a down-step for ). There are \(\binom{2n}{n}\) paths ending at height zero. Reflect the prefix through the first step below zero; this bijects the bad paths with paths having \(n+1\) up-steps and \(n-1\) down-steps, of which there are \(\binom{2n}{n+1}=\binom{2n}{n-1}\). Therefore

\[ C_n=\binom{2n}{n}-\binom{2n}{n-1} =\frac1{n+1}\binom{2n}{n}. \]

This quotient is an integer combinatorially; when evaluating it in a field, also require \(n+1\) to be invertible (or compute it as an integer before reducing). Computing the binomial by inverse factorials additionally requires factorials through \(2n\) to be units; over \(\mathbb F_p\), \(2n<p\) suffices. When those factorials vanish, the integer identity still holds but this implementation does not; see modular combinatorics. Do not apply the formula merely because parentheses or trees appear: verify the unique, independent split first.

Integer partitions: choose a multiplicity for each part size

An integer partition ignores the order of parts. For a part size \(j\), we may use it zero, one, two, … times, contributing the size-marking series

\[1+x^j+x^{2j}+\cdots={1\over1-x^j}.\]

Here \([x^n]F(x)\) means the coefficient of \(x^n\) in \(F\). Multiplication adds exponents, so it adds sizes. The displayed inverse is formal: multiplying the series by \(1-x^j\) cancels every positive-degree term and leaves \(1\). There is no claim about substituting a real number into an infinite sum.

Choices for different sizes are independent, so multiply them:

\[P(x)=\prod_{j\ge1}{1\over1-x^j}. \tag{7}\]

This infinite product is formal: to determine \([x^n]P\), factors with \(j>n\) can be replaced by \(1\), so every requested coefficient depends on only finitely many choices.

For \(n=4\), the coefficient of \(x^4\) represents \(4\), \(3+1\), \(2+2\), \(2+1+1\), and \(1+1+1+1\). If each size can be used once, replace the relevant factor by \(1+x^j\); if only some sizes are allowed, omit the others. The product comes from a modelling decision, not from a pattern to memorise.

4. Fast binomial transforms by factorial scaling

The binomial transform

\[b_n=\sum_{k=0}^n\binom nk a_k\]

looks quadratic for all \(n\). Expand the binomial coefficient:

\[ b_n=n!\sum_{k=0}^n\frac{a_k}{k!}\frac1{(n-k)!}. \tag{8} \]

The right side is the coefficient of \(x^n\) in the product of the two ordinary polynomials whose coefficients are \(a_k/k!\) and \(1/k!\). Thus one convolution, followed by multiplying coefficient \(n\) by \(n!\), computes all \(b_n\).

This is a change of representation: labelled choices produce \(\binom nk\); dividing by factorials changes “choose labels” into ordinary convolution. It requires the factorials through the desired degree to be invertible, normally a prime modulus larger than that degree. See Chapter 06 for the convolution contract.

5. Rook polynomials: IE for forbidden permutations

There are \(n\) people and \(n\) jobs. A permutation \(\pi\) is a complete assignment: person \(i\) receives job \(\pi(i)\), with every job used once. Draw an \(n\times n\) board. Row \(i\), column \(j\) is a forbidden cell when person \(i\) may not receive job \(j\). We want the number of permutations that avoid every forbidden cell.

For each forbidden cell \((i,j)\), define the bad event

\[E_{i,j}=\{\pi:\pi(i)=j\}.\]

IE says to sum over sets \(S\) of forbidden assignments that are all forced to happen. But an intersection is impossible if \(S\) asks one person to take two jobs, or two people to take one job. The possible sets are exactly placements of nonattacking rooks on forbidden cells: no two share a row or a column.

Let \(r_k\) be the number of ways to place \(k\) such rooks. Fix one placement. It forces \(k\) person–job pairs, and the remaining \(n-k\) people can be matched to the remaining \(n-k\) jobs in exactly \((n-k)!\) ways. Every placement with \(k\) rooks therefore contributes the same intersection size. Grouping IE terms by \(k\) gives

\[ \boxed{\#\text{valid assignments} =\sum_{k=0}^n(-1)^k r_k(n-k)!}. \tag{9} \]

So IE in (9) is calculating the number of complete assignments that use no forbidden cell. \(r_k\) is not the number of assignments; it counts the compatible ways to force \(k\) forbidden assignments while performing IE.

Small example

Suppose \(n=3\) and the forbidden cells are \((1,1)\) and \((2,2)\). The rook counts are \(r_0=1\), \(r_1=2\), \(r_2=1\): place no rook; choose either cell; or choose both cells, which do not share a row or column. Formula (9) gives

\[3!-2\cdot2!+1\cdot1!=6-4+1=3.\]

Indeed the valid permutations are \((2,1,3)\), \((2,3,1)\), and \((3,1,2)\).

Package the rook counts as a polynomial

\[R_B(z)=\sum_{k\ge0}r_kz^k,\]

where \(B\) is the forbidden board. If the forbidden cells split into two parts using disjoint sets of rows and columns, a nonattacking placement is an independent placement in each part. Consequently

\[R_{B_1\cup B_2}(z)=R_{B_1}(z)R_{B_2}(z).\]

For example, \(t\) isolated forbidden cells in distinct rows and columns have \(R_B(z)=(1+z)^t\). This product rule is valuable only after checking that the components share neither a person nor a job; disconnected-looking cells that share a row are not independent.

6. A derivation habit and failure checks

When a formula is unfamiliar, reconstruct it with this sequence:

  1. Name the candidates and the desired subset.
  2. State what one term or one coefficient counts.
  3. Explain why choices multiply or why cases add.
  4. Test the result on \(n=0,1,2\) or a hand-enumerable board.
  5. Only then choose a DP, convolution, or generating-function implementation.

Common errors are conceptual rather than syntactic:

  • confusing \(k!\left\{ {n\atop k}\right\}\) named groups with \(\left\{ {n\atop k}\right\}\) unnamed groups;
  • dividing by \(k!\) although it is zero modulo the chosen characteristic;
  • using IE when intersections are harder than the original condition;
  • using a rook product although board pieces share a row or column;
  • counting rotations/reflections as distinct when the problem regards them as identical (continue to Chapter 05).

7. From a count to an algorithm

Worked reduction: a binomially weighted power

Suppose we want \(\sum_{s=0}^N\binom Ns s^K\) for small \(K\) but huge \(N\). An object is a chosen subset \(S\subseteq[N]\) together with a function from \([K]\) into \(S\). Group functions by their \(j\) distinct used targets:

\[ \begin{aligned} \sum_{s=0}^N\binom Ns s^K &=\sum_{j=0}^{\min(K,N)}\left\{{K\atop j}\right\} \sum_{s=j}^N\binom Ns s^{\underline j}\\ &=\sum_{j=0}^{\min(K,N)}\left\{{K\atop j}\right\} N^{\underline j}\sum_{s=j}^N\binom{N-j}{s-j}\\ &=\sum_{j=0}^{\min(K,N)}\left\{{K\atop j}\right\} N^{\underline j}2^{N-j}. \end{aligned} \]

The used targets are distinct and ordered by their fiber blocks; every unused target independently joins \(S\) or stays outside. For \(N=3,K=2\), the original sum is \(0+3+12+9=24\). The transformed sum is \(3\cdot4+6\cdot2=24\). Compute the Stirling row in \(O(K^2)\) ring operations and the falling factorials in \(O(K)\). Binary exponentiation for each power is a safe \(O(K\log N)\) route even when \(2\) is not a unit; division by two to update powers needs a unit.

Worked failure: visually separated forbidden cells

For \(n=3\), forbid \((1,1)\) and \((1,2)\). They share a row, so \(R_B(z)=1+2z\), not \((1+z)^2\). There are \(6-2\cdot2=2\) valid assignments: person 1 must take job 3, then the other two people may swap jobs 1 and 2. The tempting product would add a nonexistent two-rook placement and incorrectly return \(3\).

General IE on \(m\) bad events costs \(2^m\) intersection counts. Stirling or Catalan recurrence tables cost \(O(n^2)\) arithmetic operations through size \(n\). The partition coefficients through \(n\) can use part-size DP in \(O(n^2)\) time and \(O(n)\) space; its invariant fixes multiplicities for the part sizes already processed. A factorial-scaled binomial transform costs one convolution plus \(O(n)\) scaling, under its unit assumptions. Rook IE is fast only if the rook numbers can themselves be obtained efficiently; an arbitrary forbidden board has no promised polynomial-time counting algorithm here.
