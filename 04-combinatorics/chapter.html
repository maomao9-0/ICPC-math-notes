04 — Advanced Combinatorics

This chapter is the bridge from “know the formula” to derive the formula under contest pressure. It assumes factorials, binomial coefficients and elementary inclusion–exclusion (IE). Read it before group actions and generating functions.

1. Recognition map

Wording in a statement First model to try
every required property is present IE over missing properties
exactly/at least \(k\) properties binomial inversion or weighted IE
partition labelled objects into unlabeled nonempty groups Stirling numbers of the second kind
cycles of a permutation unsigned Stirling numbers of the first kind
recursively nested / balanced / plane tree Catalan family
sum over all subsets with a statistic depending only on size binomial transform
constraints are local but labels are global combinatorial class + EGF

Always write what one object is, what is labelled, and whether order matters. Most wrong generating functions arise before any algebra is performed.

2. Inclusion–exclusion as a transform

For bad events \(E_1,\ldots,E_m\), attach a set \(B(x)\subseteq[m]\) of bad properties to each object. Then

\[ \mathbf 1[B(x)=\varnothing]=\sum_{S\subseteq B(x)}(-1)^{|S|}. \]

Summing this identity over objects proves IE and is more robust than memorising signs. If \(f(S)\) counts objects having every bad property in \(S\), the answer is \(\sum_S(-1)^{|S|}f(S)\). Symmetry often collapses \(2^{m}\) terms into \(m+1\): if \(f(S)=g(|S|)\), use \(\sum_k(-1)^{k}{m\choose k}g(k)\).

Exactly \(r\) satisfied conditions

Let \(a_j\) count objects satisfying exactly \(j\) conditions and let \(b_k=\sum_{|S|=k}f(S)\). Double counting pairs (object, chosen k true conditions) gives

\[ b_k=\sum_{j\ge k}{j\choose k}a_j, \qquad a_r=\sum_{k\ge r}(-1)^{k-r}{k\choose r}b_k. \]

This is binomial inversion. The common transforms \(b_n=\sum_{k\le n}{n\choose k}a_k\) and \(a_n=\sum_{k\le n}(-1)^{n-k}{n\choose k}b_k\) follow similarly.

3. Classical counting families

Stirling numbers

\[ {n\brace k}=k{n-1\brace k}+{n-1\brace k-1},\qquad {n\brack k}=(n-1){n-1\brack k}+{n-1\brack k-1}. \]

The first recurrence puts label \(n\) into one of \(k\) blocks or makes a new block. The second inserts it after one of \(n-1\) existing permutation elements, or creates a new cycle. Useful closed transforms are

\[ {n\brace k}=\frac1{k!}\sum_{i=0}^k(-1)^{k-i}{k\choose i}i^n, \quad x^{\overline n}=\sum_k {n\brack k}x^k. \]

Bell numbers satisfy \(B_n=\sum_k{n\brace k}\). Their EGF is \(\exp(e^{x}-1)\): a partition is a labelled set of nonempty labelled sets.

Catalan schema

A plane rooted binary object is empty or a root with an ordered pair of such objects, so \(C(x)=1+xC(x)^{2}\). Hence

\[ C_n=\frac1{n+1}{2n\choose n},\qquad C_{n+1}=\sum_{i=0}^n C_iC_{n-i}. \]

Equivalent objects include Dyck paths, balanced parentheses, triangulations, and binary-search-tree shapes. Do not apply Catalan merely because parentheses appear: check that the first-return decomposition is independent.

Integer partitions

For unlimited parts, mark total size:

\[ P(x)=\prod_{j\ge1}(1-x^j)^{-1}. \]

Restricting parts to a set deletes factors; allowing each at most once changes the factor to \(1+x^{j}\). Euler’s pentagonal recurrence computes all \(p(n)\) in \(O(N\sqrt N)\):

\[ p(n)=\sum_{k\ge1}(-1)^{k-1} \left(p(n-k(3k-1)/2)+p(n-k(3k+1)/2)\right). \]

4. Fast transforms by factorial scaling

Many triangular sums become one convolution. For example,

\[ b_n=\sum_{k=0}^n {n\choose k}a_k =n!\sum_{k=0}^n\frac{a_k}{k!}\frac1{(n-k)!}. \]

Convolve \(A_k=a_k/k!\) and \(F_k=1/k!\), then multiply coefficient \(n\) by \(n!\). This is \(O(N\log N)\) with NTT. The formula requires all required factorials to be invertible; normally use a prime modulus with \(N<p\).

Stirling columns can also be obtained by convolution from the explicit formula. For all \({n\brace k}\) at one fixed \(n\), convolve \(A_i=(-1)^{i}/i!\) and \(B_i=i^{n}/i!\); the coefficient at \(k\) is \({n\brace k}\).

5. Rook polynomial viewpoint

For permutations avoiding forbidden cells, place nonattacking rooks in the forbidden board. If \(r_k\) is the number of ways to choose \(k\) mutually compatible forbidden assignments, IE yields

\[ \sum_{k=0}^n(-1)^k r_k(n-k)!. \]

Disconnected boards multiply rook polynomials. This turns some intimidating IE into polynomial products over small components.

6. Pitfalls and a worked derivation

Example: surjections. Count functions \([n] \to [k]\) using every target. Choose \(i\) omitted targets and apply IE: \(\sum_i(-1)^{i}{k\choose i}(k-i)^{n}=k!{n\brace k}\). This simultaneously explains the Stirling explicit formula: a partition into \(k\) nonempty fibers, then an ordering of the fibers.

Frequent bugs:

  • confusing labelled blocks (\(k! {n\brace k}\)) with unlabeled blocks;
  • dividing by \(k!\) when the modulus does not permit it;
  • using a closed form whose range crosses the characteristic;
  • performing IE over constraints although intersections are not easier;
  • silently counting rotations/reflections as distinct (see chapter 05).
