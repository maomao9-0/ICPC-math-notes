Welcome to the Advanced String Algorithms, Structural Periodicity & Combinatorics on Words textbook (Ch 01–Ch 30), paired with 7 Part-End Blind Topic-Group Checkpoints (CP-I–CP-VII), a 30-Problem Grandmaster Multi-Chapter Synthesis Reserve (Syn-01–Syn-30), and a Master Curated Problem Archive (337+ fully derived non-template problems plus 32 quarantined bare library templates R-01–R-32).

1. The Core Pedagogical Shift: Why Templates Fail and Word Invariants Win

Consistent with the repository’s editorial policy, this textbook assumes your competitive programming library already contains tested, black-box implementations of foundational string algorithms. You will never see beginner tutorials or boilerplate code dumps for KMP, Z-arrays, basic Suffix Arrays, or single-string Suffix Automata here.

Why, then, do advanced string problems on Codeforces (Div. 1 D–F), AtCoder (ARC/AGC), Universal Cup / QOJ, ICPC World Finals, and the Chinese NOI / 国家集训队论文 circuit routinely defeat competitors who carry complete SA, SAM, and PAM templates in their library? Because advanced stringology is governed not by black-box automaton templates, but by three deep structural pillars:

  1. Combinatorial Word Sparsity (“Why do \(\Theta(N)\) or \(\Theta(N^2)\) candidates collapse to \(O(\log N)\) or \(< N\)?”):
    • The Weak Periodicity Lemma & Border APs (Part I): All borders of \(S[1..u]\) of length \(\ge \lceil u/2 \rceil\) share a single minimal period \(d = u - \pi[u]\), partitioning all borders and palindromic suffixes of \(S[1..u]\) into \(\le \lceil \log_2 u \rceil\) half-open arithmetic progressions \((\text{slink}[u], u]\).
    • The Significant Suffixes Theorem (Part II, 显著后缀): If two suffixes \(u \sqsubset v\) of \(S[1..r]\) satisfy \(|u| < |v| < 2|u|\), their overlap forces a tandem repeat \(u = w u'\), \(v = w^2 u'\) such that \(\min(u'T, vT) < uT < \max(u'T, vT)\) for every right extension \(T \in \Sigma^*\). Thus \(u\) is annihilated, leaving at most \(\lfloor \log_2 |U| \rfloor + 1\) candidate suffixes (Cand) and at most one survivor from the left child during a Segment Tree pushup ([ZJOI2017] 字符串).
    • The Runs Theorem (Part II, Bannai et al. 2017): Choosing between standard order \(<\) and reversed order \(>\) assigns every maximal periodic run \(R = [l, r, p]\) a non-empty set of interior Lyndon roots of length \(p\) whose start positions are pairwise disjoint across all runs—immediately proving \(|\mathcal{R}(S)| < N\), \(\sum \text{exp}(R) < 3N\), and \(< 2N\) representative squares.
    • Tiskin’s Unit-Monge Seaweed Algebra (Part VI, 海草矩阵): The cross-difference of semi-local substring alignment scores \(\text{LCS}(A[1..i], B[l..r])\) is a \(0\)-\(1\) permutation matrix (Seaweed Matrix \(W[1..N]\)) evolved by planar wire uncrossing (if (A[i] == B[j] || u > W[j]) swap(u, W[j])), compressing all \(\Theta(N^2)\) interval LCS answers into \(N\) integers and an \(O(K \log K)\) Unit-Monge \(\boxdot\) product ([THUPC 2021] 区间 LCS).
  2. Substring Clipping & Dynamic Data-Structure Coupling (“How do you query \(S[l..r]\) on a whole-string automaton?”):
    • Standard SAM and PAM represent prefixes of the entire string \(S[1..N]\). When a query restricts attention to an arbitrary substring \(S[l..r]\), a pattern \(P \in E(u)\) of length \(L\) occurs inside \(S[l..r]\) if and only if its ending position satisfies \(\text{endpos}_S(u) \cap [l + L - 1, r] \ne \emptyset\)—reducing variable-length string containment to a 1D clipped range query on a Persistent Segment Tree Merge ([NOI2018] 你的名字).
    • When counting distinct substrings or palindromes inside \(S[l..r]\), sweeping \(r = 1 \dots N\) with Link-Cut Tree (LCT) access color-chain sweeping (Part III) or PAM slink periodic telescoping (Part IV, [徐毅 2014]) collapses \(\Theta(N)\) ancestor updates into \(O(\log N)\) gapless interval shifts on a Fenwick Tree.
  3. Algebraic, Polynomial & Non-Abelian Group Reformulations (Parts V–VII):
    • Non-transitive character compatibility (wildcards, thresholds, involutions \(\pi^2 = \text{id}\), \(k\)-mismatch) compiles into 1-NTT Degree-Reduced Indicator Polynomials, Kalai Projections, and the \(O(N\sqrt{k \log k})\) \(2k\)-Period Dichotomy (Part V).
    • Pattern avoidance, \(k\)-occurrence counting, and moment extraction at \(N \le 10^{18}\) compile into Guibas–Odlyzko \(m \times m\) Overlap Systems and the \(t = 1 + u\) Binomial Moment Shift (Part VI).
    • Adjacency stack cancellation (cc \(\to \varepsilon\) or Dyck brackets) compiles deterministically into Stack-Trie Simple Path Isomorphism (\(\text{LCA}\) LCE) and algebraically into trace-zero \(\det = -1\) involutions in \(GL_2(\mathbb{F}_p)\) / height-indexed \(SL_2(\mathbb{F}_p)\) (Part VII).

3. The 4-Step “Zero Magic Invariants & Structural Decompositions” Standard

Every chapter and every solved problem in this textbook strictly enforces a 4-Step Derivation Protocol:

\[\text{1. Diagnostic Signal} \longrightarrow \text{2. Combinatorial Word Invariant} \longrightarrow \text{3. Algorithmic Compilation} \longrightarrow \text{4. Broken-Invariant Counterexample}\]

  1. The Diagnostic Signal (Why Naive String Structures Fail): We pinpoint the exact feature in the problem statement and constraints—such as substring clipping \(S[l..r]\), right-extension comparison \(S[i..r]+T\), palindrome/border DP transitions, all-pairs interval LCS, or \(N \le 10^{18}\) morphic/SLP strings—that forces standard whole-string SAM/SA/PAM/KMP into \(\Omega(N^2)\) time or memory.
  2. The Combinatorial Word Invariant (Double-Overlap, Periodicity, or Monge Proof): Before introducing any data structure, we prove the underlying word-combinatorial collapse using explicit alignment diagrams and index equalities.
  3. The Reverse-Engineering Scratchpad (Algorithmic & Data-Structure Compilation): We compile the invariant into exact state transitions, half-open index boundaries, rolling offsets, or polynomial convolutions, providing clean implementation contracts for non-standard machinery.
  4. Boundary Pitfalls & Broken-Invariant Counterexamples: We exhibit concrete small strings—frequently Central Sturmian / Fibonacci words (abaababaaba), Thue–Morse prefixes, or unary-bordered traps (aaba, bab)—that break naive shortcuts (such as closed-interval \([\text{slink}[u], u]\) double-counting, initializing g[u] = dp[r - len[u]] instead of dp[r - len[slink[u]] - diff[u]], unclipped \([l, r]\) endpos queries, or Trie-DFS \(\Theta(V^2)\) blowup on Generalized SAM).

3.1 Four Flagship Snapshots of the 4-Step Standard in Action

NoteSnapshot A (Part I · Ch 04): Why PAM slink DP Initializes at \(r - \text{len}[\text{slink}[u]] - \text{diff}[u]\), Never \(r - \text{len}[u]\)

  • 1. Diagnostic Signal: In CF 932G — Palindrome Partition (\(N \le 10^6\)), we must compute \(dp[r] = \sum_{L \in \text{PalSuf}(r)} dp[r - L]\). On \(S = \texttt{a}^N\), \(|\text{PalSuf}(r)| = r\), so iterating u = fail[u] takes \(\Theta(N^2)\) time.

  • 2. Combinatorial Word Invariant: Let \(u\) be the head of a half-open slink arithmetic progression \((\text{slink}[u], u]\) with common difference \(d = \text{diff}[u] = \text{len}[u] - \text{len}[\text{fail}[u]]\). When \(\text{diff}[u] = \text{diff}[\text{fail}[u]] = d\), the set of left endpoints \(\mathcal{I}(u, r) = \{r - \ell_1, \dots, r - \ell_k\}\) satisfies the exact shift-overlap decomposition: \[\mathcal{I}(u, r) = \mathcal{I}(\text{fail}[u],\, r - d) \;\sqcup\; \bigl\{\,r - \text{len}[\text{slink}[u]] - d\,\bigr\}.\] Crucially, \(v = \text{fail}[u]\) occurred at \(r - d\), was a slink chain head at \(r - d\) (otherwise period \(d\) would extend \(u\) at \(r\)), and was never visited during \((r - d, r)\), so g[fail[u]] already stores the exact sum over \(\mathcal{I}(\text{fail}[u], r - d)\)!

  • 3. Algorithmic Compilation: At each \(r\), walk \(u \leftarrow \text{slink}[u]\) in \(\le \lceil \log_2 r \rceil\) steps: set g[u] = dp[r - len[slink[u]] - diff[u]], add g[fail[u]] if diff[u] == diff[fail[u]], and add g[u] to dp[r].

  • 4. Broken-Invariant Counterexample: Initializing g[u] = dp[r - len[u]] double-counts the longest palindrome’s left endpoint \(r - \text{len}[u] = (r - d) - \text{len}[\text{fail}[u]]\) (which is already the oldest element inside g[fail[u]]) and completely omits the shortest palindrome’s left endpoint \(r - \text{len}[\text{slink}[u]] - d\)!

NoteSnapshot B (Part II · Ch 06): Why Only ONE Left-Child Candidate Survives a Segment Tree pushup ([ZJOI2017] 字符串)
  • 1. Diagnostic Signal: Given \(S[1..N]\) under range character shifts, query the lexicographically minimal suffix of \(S[l..r]\). Because a suffix of \(S[l..m]\) has \(S[m+1..r]\) appended to its right inside \(S[l..r]\), local minimum suffixes do not compose naively.
  • 2. Combinatorial Word Invariant: Suppose \(u \sqsubset v\) are two suffixes of \(U\) with \(|u| < |v| < 2|u|\). Then \(u\) is a border of \(v\) of length \(> |v|/2\), forcing a tandem repeat \(u = w u'\) and \(v = w^2 u'\) (\(u' \in \text{Suf}(U)\)). By left-cancellation of lexicographical order, \(\min(u'T, vT) < uT < \max(u'T, vT)\) for every right extension \(T \in \Sigma^*\). When merging left_child \([L, M]\) and right_child \([M+1, R]\) in a Segment Tree, all suffixes starting in \([L, M]\) have lengths in \([R-M+1, R-L+1]\) inside \([L, R]\). Since \(R-L+1 \le 2(R-M+1)\), their length ratio is \(< 2\), so at most ONE candidate from left_child can survive in \(\text{Cand}([L, R])\)!
  • 3. Algorithmic Compilation: Every Segment Tree node stores at most \(\lfloor \log_2(\text{len}) \rfloor + 1\) candidates, and pushup performs a single tournament over left_child’s candidates (modulated by right extension \(S[M+1..R]\)) to pick its lone survivor.
  • 4. Broken-Invariant Counterexample: Assuming \(\text{Cand}_{\min}(S[l..r]) \subseteq \text{Cand}_{\min}(S[1..r])\) fails on \(S = \texttt{aaba}\) and \([l, r] = [2, 4]\): on \([1, 4]\), \(\texttt{aaba}(1)\) kills \(\texttt{aba}(2)\), but on \([2, 4]\), index \(1\) is cut off and \(\texttt{aba}(2)\) revives!
NoteSnapshot C (Part III · Ch 10): Why Substring Containment Clips \(\text{endpos}_S(u)\) to \([l + L - 1, r]\), Never \([l, r]\)
  • 1. Diagnostic Signal: In [NOI2018] 你的名字 (\(|S|, \sum |T| \le 5 \times 10^5\)), we must count substrings of \(T\) that do not occur inside substring \(S[l..r]\).
  • 2. Combinatorial Word Invariant: A substring \(P \in E(u)\) of current match length \(L\) occurs completely inside \(S[l..r]\) if and only if there is an ending position \(e \in \text{endpos}_S(u)\) such that both \(e \le r\) and \(e - L + 1 \ge l \iff e \in [l + L - 1, r]\). Furthermore, if \(e_{\max} = \max(\text{endpos}_S(u) \cap [1, r])\), the longest prefix of \(P\) in \(u\)’s subtree that fits inside \(S[l..r]\) has length \(L_{\text{valid}}(u) = \min(L, e_{\max} - l + 1)\).
  • 3. Algorithmic Compilation: Merge persistent \(\text{endpos}\) Segment Trees bottom-up on \(\mathcal{T}_{\text{link}}(\text{SAM}(S))\) in \(O(N \log N)\) time; while scanning \(T\), shrink \(L\) via predecessor query \(e_{\max} \le r\) before jumping \(u \leftarrow \text{link}(u)\).
  • 4. Broken-Invariant Counterexample: Querying \(\text{endpos}_S(u) \cap [l, r] \ne \emptyset\) instead of \([l + L - 1, r]\) falsely accepts an occurrence ending at \(e = l\) whose start position \(l - L + 1 < l\) overhangs the left boundary of \(S[l..r]\)!
NoteSnapshot D (Part VI · Ch 23): How Tiskin’s Seaweed Permutation Encodes All \(\Theta(N^2)\) Interval LCS Values in \(N\) Integers

  • 1. Diagnostic Signal: In [THUPC 2021] 区间 LCS (\(|A| \le 5\,000, |B|, Q \le 10^5\)), we must answer \(Q\) queries for \(\text{LCS}(A, B[l..r])\). Running DP per query takes \(O(Q |A| |B|)\) time.

  • 2. Combinatorial Word Invariant: The alignment grid of \(A[1..M]\) and \(B[1..N]\) satisfies the Unit-Monge anti-diagonal cross-difference identity: \(\Delta^{\square}(l, r) = 1\) for at most one \(r\) per \(l\). Tracing non-crossing “seaweed” wires from top ports \(1 \dots N\) and left ports \(0 \dots -(M-1)\) with local comb rule if (A[i] == B[j] || u > W[j]) swap(u, W[j]) produces a single bottom permutation \(W[1..N]\) such that: \[\text{LCS}(A[1..i],\, B[l..r]) \;=\; \#\bigl\{\,k \in [l, r] \;\big|\; -i \le W[k] < l\,\bigr\}.\]

  • 3. Algorithmic Compilation: Compute \(W[1..N]\) in \(O(MN)\) time (or \(O((M+N)\log^2 N)\) via Unit-Monge \(\boxdot\) divide-and-conquer) and answer each \(\text{LCS}(A, B[l..r])\) query in \(O(\log N)\) time as a 2D dominance point count on a Chairman Tree.

  • 4. Broken-Invariant Counterexample: Confusing top-to-bottom port map \(p[i]\) with bottom-to-top port map \(W[k]\) fails whenever a wire entering from the left border (\(u \le 0\)) exits at column \(k \in [l, r]\), because \(W[k] < l\) automatically captures both top wires \(< l\) and left-border wires \(\le 0\)!
