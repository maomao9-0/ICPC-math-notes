1. The Four-Way Suffix Tree Isomorphism & Equal-Height Contraction (T-2B-02)

1.1 The Diagnostic Signal: Why Explicit Suffix Trees Are Almost Never Needed

A classic Suffix Tree \(\operatorname{ST}(S)\) is the compacted trie of all \(N\) suffixes \(\operatorname{suf}(i) = S[i..N]\$\) (\(1 \le i \le N\)). In contest problems, tasks naturally phrase their questions in terms of \(\operatorname{ST}(S)\):

  • Subset Pair Aggregations: Given \(Q\) queries specifying subsets of suffixes or substrings \(A_q, B_q\) with \(\sum_q (|A_q| + |B_q|) \le 5 \times 10^5\), evaluate \(\sum_{u \in A_q} \sum_{v \in B_q} f\bigl(\operatorname{LCP}(u, v)\bigr)\) (CF 1073G).
  • Thresholded Component Statistics: For every similarity threshold \(r \in [0, N-1]\), count pairs of suffixes \((i, j)\) with \(\operatorname{LCP}(\operatorname{suf}(i), \operatorname{suf}(j)) \ge r\) and maximize \(a_i \cdot a_j\) where vertex weights \(a_i \in [-10^9, 10^9]\) can be negative ([NOI2015] 品酒大会).
  • 2D Index-Range Pair Optimization: Given \(Q\) range queries \([l, r]\) on original string indices, optimize a function of \(\operatorname{LCP}(\operatorname{suf}(a), \operatorname{suf}(b))\) over all \(\binom{r-l+1}{2}\) pairs \(l \le a < b \le r\) (CF 1043G, CF 1098F).

Implementing Ukkonen’s online Suffix Tree algorithm directly is notorious for edge-splitting boilerplate and alphabet-sized transition maps. Worse, even if you build an explicit tree \(\mathcal{T}\) of \(2N-1\) nodes and run standard Heavy-Light or Euler-tour LCA to build a Virtual Tree over query substrings \(U_t = S[l_t..r_t]\), locating the locus of each \(U_t\) on \(\mathcal{T}\) requires \(O(\log N)\) binary lifting per substring before the Virtual Tree even begins!

The key insight of this chapter is that the Suffix Array SA[1..N] and adjacent LCP array height[2..N] already encode the complete topology of \(\operatorname{ST}(S)\).

1.2 The Combinatorial Word Invariant: Concrete Objects & The Canonical Four-Way Isomorphism

Let \(S[1..N]\) have Suffix Array \(\operatorname{SA}[1..N]\), inverse rank array \(\operatorname{rk}[1..N]\), and adjacent LCP array \(H[k] = \operatorname{height}[k] = \operatorname{LCP}\bigl(\operatorname{suf}(\operatorname{SA}[k-1]),\, \operatorname{suf}(\operatorname{SA}[k])\bigr)\) for \(2 \le k \le N\) (with boundary sentinels \(H[1] = H[N+1] = 0\)). By the fundamental LCP Interval Identity, for any two suffix ranks \(1 \le x < y \le N\):

\[\operatorname{LCP}\bigl(\operatorname{suf}(\operatorname{SA}[x]),\, \operatorname{suf}(\operatorname{SA}[y])\bigr) \;=\; \min_{x < k \le y} H[k].\]

This single equation implies that every branching node of \(\operatorname{ST}(S)\) is a local minimum bottleneck in \(H[2..N]\). More precisely, four seemingly distinct tree structures on \(S\) are canonically isomorphic:

NoteTheorem 13.1 (The Canonical Four-Way Suffix Tree Isomorphism)

For any string \(S[1..N]\), there is a canonical bijection between the internal branching nodes (and leaves) of the following four rooted trees, preserving string depth \(\ell_u\), leaf occurrence sets, and pairwise \(\operatorname{LCA}\) depths: \[\boxed{\operatorname{ST}(S) \;\cong\; \operatorname{Contracted-Min-Cartesian}\bigl(H[2..N]\bigr) \;\cong\; \mathcal{T}_{\text{Kruskal-DSU}}\bigl(H[2..N]\bigr) \;\cong\; \mathcal{T}_{\text{link}}\bigl(\operatorname{SAM}(S^R)\bigr).}\] Specifically, for every internal node \(u\) spanning the contiguous Suffix Array leaf interval \([L_u, R_u] \subseteq [1, N]\) (\(L_u < R_u\)):

  1. String Depth & Parent Depth: Node \(u\) has string depth \(\ell_u = \min_{L_u < k \le R_u} H[k]\), and its parent \(p(u)\) in the contracted tree has string depth \(\ell_{p(u)} = \max\bigl(H[L_u],\, H[R_u + 1]\bigr) < \ell_u\).
  2. Exact Substring Partition: Node \(u\) represents the \(\ell_u - \ell_{p(u)}\) distinct substrings \(S\bigl[\operatorname{SA}[L_u] .. \operatorname{SA}[L_u] + d - 1\bigr]\) for \(d \in \bigl[\ell_{p(u)} + 1,\, \ell_u\bigr]\), each occurring exactly \(\operatorname{sz}(u) = R_u - L_u + 1 \ge 2\) times in \(S\) (at starting positions \(\{\operatorname{SA}[x] : L_u \le x \le R_u\}\)).
  3. Unique-Occurrence Leaf Edges (\(\operatorname{occ} = 1\)): Each leaf \(x \in [1, N]\) corresponds to suffix \(\operatorname{suf}(\operatorname{SA}[x])\) of length \(\operatorname{len}_x = N - \operatorname{SA}[x] + 1\), attached below parent depth \(\ell_{p(x)} = \max\bigl(H[x],\, H[x+1]\bigr)\), representing \(\operatorname{len}_x - \max\bigl(H[x], H[x+1]\bigr)\) distinct substrings that occur exactly once in \(S\).

Proof of Theorem 13.1

  1. \(\operatorname{ST}(S) \leftrightarrow \mathcal{T}_{\text{link}}(\operatorname{SAM}(S^R))\): Proved in Chapter 09, Theorem 9.2: reversing \(S\) maps starting positions of \(w\) in \(S\) to ending positions of \(w^R\) in \(S^R\), and right-extensions \(w \to wc\) in \(\operatorname{ST}(S)\) to left-extensions \(cw^R \leftarrow w^R\) along suffix links in \(\operatorname{SAM}(S^R)\).
  2. \(\operatorname{ST}(S) \leftrightarrow \operatorname{Contracted-Min-Cartesian}(H[2..N])\): In the binary Min-Cartesian Tree of \(H[2..N]\), each index \(k \in [2..N]\) splits a maximal interval of gaps \([L'_k, R'_k] \subseteq [2, N]\) where \(H[j] \ge H[k]\), which corresponds to the Suffix Array leaf interval \([L_k, R_k] = [L'_k - 1, R'_k]\). If a node \(k\) has \(H[k] = H[\operatorname{par}(k)]\) (because multiple gaps inside \([L_u, R_u]\) tie for the minimum LCP \(\ell_u\)), contracting all zero-weight edges \(H[k] - H[\operatorname{par}(k)] = 0\) merges those binary splits into a single multi-way branching node \(u\) whose children correspond to the maximal sub-intervals with strictly larger internal LCP (\(> \ell_u\)). That multi-way node is the exact branching node of \(\operatorname{ST}(S)\) at string depth \(\ell_u\).
  3. \(\operatorname{Contracted-Min-Cartesian}(H[2..N]) \leftrightarrow \mathcal{T}_{\text{Kruskal-DSU}}(H[2..N])\): Sweeping threshold \(\ell\) from \(N\) down to \(0\) and uniting adjacent Suffix Array leaves \((k-1, k)\) whenever \(H[k] = \ell\) (Kruskal’s algorithm on the path graph \(1 - 2 - \dots - N\) with edge weights \(H[k]\)) forms a connected component \([L_u, R_u]\) at threshold \(\ell = \ell_u\) that remains intact until \(\ell\) drops to \(\max(H[L_u], H[R_u+1]) = \ell_{p(u)}\). Thus the Kruskal DSU merge tree (with equal-weight merges contracted) is identical to the Contracted Min-Cartesian Tree. \(\blacksquare\)

2. Monotonic-Stack LCP Sums, Kruskal DSU & Zero-Tree Virtual Suffix Trees (T-2B-02)

2.1 Engine A & Engine B: Monotonic Stack vs. Decreasing-height Kruskal DSU

Before restricting to query subsets, let us contrast the two global aggregation engines on \(H[2..N]\):

  1. Engine A — Asymmetric Monotonic Stack for All-Pairs LCP Sums ([AHOI2013] 差异, CF 802I): To evaluate \(\sum_{1 \le x < y \le N} \operatorname{LCP}(\operatorname{SA}[x], \operatorname{SA}[y]) = \sum_{1 \le x < y \le N} \min_{x < k \le y} H[k]\) in \(O(N)\) time, every pair \((x, y)\) must be charged to a unique minimum gap index \(k \in (x, y]\). We break ties among equal minimum values in \(H\) by choosing the leftmost minimum:

    • Define \(L'_k \le k\) as the smallest gap index such that \(H[j] > H[k]\) for all \(j \in [L'_k, k-1]\) (strict > on the left).
    • Define \(R'_k \ge k\) as the largest gap index such that \(H[j] \ge H[k]\) for all \(j \in [k+1, R'_k]\) (non-strict >= on the right).
    • Invariant: Every pair of suffix ranks \((x, y)\) with \(L'_k - 1 \le x < k \le y \le R'_k\) has leftmost minimum gap \(k\), contributing: \[\sum_{1 \le x < y \le N} \operatorname{LCP}(\operatorname{SA}[x], \operatorname{SA}[y]) \;=\; \sum_{k=2}^N H[k] \cdot (k - L'_k + 1) \cdot (R'_k - k + 1).\]

  2. Engine B — Decreasing-height Kruskal DSU Sweep ([NOI2015] 品酒大会): When a problem asks for component-level extrema at every threshold \(r \in [0, N-1]\)—such as \(\max_{\operatorname{LCP}(i, j) \ge r} (a_i \cdot a_j)\) where \(a_i \in [-10^9, 10^9]\)—bucket-sort the gaps \(k \in [2..N]\) in decreasing order of \(H[k]\). Maintain DSU components storing \((\operatorname{sz}[u], \max_1[u], \min_1[u])\). Merging \(u = \operatorname{find}(k-1)\) and \(v = \operatorname{find}(k)\) at \(r = H[k]\) adds \(\operatorname{sz}[u]\operatorname{sz}[v]\) pairs with exact \(\operatorname{LCP} = r\) and updates the maximum product with \(\max\bigl(\max_1[u]\max_1[v],\, \min_1[u]\min_1[v]\bigr)\). A single backward suffix sweep \(r = N-1 \downarrow 0\) converts exact \(\operatorname{LCP} = r\) statistics into \(\operatorname{LCP} \ge r\).

2.2 Engine C: Zero-Tree Substring Virtual Suffix Trees (后缀树虚树, CF 1073G)

Now suppose query \(q\) gives \(k_q\) arbitrary substrings \(U_1, U_2, \dots, U_k\) of \(S\), where \(U_t = S[l_t .. r_t]\) has length \(|U_t| = r_t - l_t + 1\) (note that full suffixes are simply the special case \(r_t = N\)). How do we construct the Virtual Suffix Tree (后缀树虚树) of \(\{U_1, \dots, U_k\}\) in \(O(k \log k)\) time without building \(\operatorname{ST}(S)\) or binary-lifting on \(\operatorname{SAM}(S^R)\)?

NoteTheorem 13.2 (Zero-Tree Substring Virtual Suffix Tree via Clipped Adjacent LCEs)

Let \(U_1, U_2, \dots, U_k\) (\(U_t = S[l_t .. r_t]\)) be \(k\) arbitrary substrings of \(S\), sorted in non-decreasing lexicographical order \(U_1 \le_{\text{lex}} U_2 \le_{\text{lex}} \dots \le_{\text{lex}} U_k\) using the \(O(1)\) comparator: \[U_a \lessgtr_{\text{lex}} U_b \iff \begin{cases} |U_a| \lessgtr |U_b| & \text{if } \operatorname{LCE}_S(l_a, l_b) \ge \min(|U_a|, |U_b|), \\ \operatorname{rk}[l_a] \lessgtr \operatorname{rk}[l_b] & \text{otherwise.} \end{cases}\] Define the clipped adjacent LCP array \(h_2, h_3, \dots, h_k\) by: \[\boxed{h_t \;=\; \operatorname{LCP}(U_{t-1},\, U_t) \;=\; \min\Bigl(\operatorname{LCE}_S(l_{t-1},\, l_t),\;\; |U_{t-1}|,\;\; |U_t|\Bigr), \qquad 2 \le t \le k.}\] Then for every pair of indices \(1 \le a < b \le k\): \[\boxed{\operatorname{LCP}(U_a,\, U_b) \;=\; \min_{a < t \le b} h_t,}\] and the Contracted Min-Cartesian Tree built on \(h_2, \dots, h_k\) in \(O(k)\) time is canonically isomorphic to the Virtual Suffix Tree of \(\{U_1, \dots, U_k\}\) inside \(\operatorname{ST}(S)\).

Proof of Theorem 13.2

For any three strings \(X \le_{\text{lex}} Y \le_{\text{lex}} Z\), if both \(\operatorname{LCP}(X, Y) \ge d\) and \(\operatorname{LCP}(Y, Z) \ge d\), then \(X\) and \(Z\) both have length \(\ge d\) and agree with \(Y\) on their first \(d\) characters, so \(\operatorname{LCP}(X, Z) \ge d\). Conversely, if \(X\) and \(Z\) agree on their first \(d\) characters, then because \(X \le_{\text{lex}} Y \le_{\text{lex}} Z\) is sandwiched between two strings starting with the same length-\(d\) prefix \(P\), \(Y\) must also start with \(P\), forcing \(\operatorname{LCP}(X, Y) \ge d\) and \(\operatorname{LCP}(Y, Z) \ge d\). Thus \(\operatorname{LCP}(X, Z) = \min\bigl(\operatorname{LCP}(X, Y),\, \operatorname{LCP}(Y, Z)\bigr)\). Inducting across the sorted sequence \(U_a \le_{\text{lex}} U_{a+1} \le_{\text{lex}} \dots \le_{\text{lex}} U_b\) yields \(\operatorname{LCP}(U_a, U_b) = \min_{a < t \le b} h_t\). By Theorem 13.1, the Contracted Min-Cartesian Tree of \(h_2, \dots, h_k\) is the exact compacted trie (Virtual Suffix Tree) of \(\{U_1, \dots, U_k\}\). \(\blacksquare\)

TipWhy Zero-Tree Virtual Suffix Trees Beat Explicit Virtual Trees

A traditional Virtual Tree on \(\operatorname{SAM}(S^R)\) requires: (1) building \(\operatorname{SAM}(S^R)\) (\(2N\) nodes), (2) precomputing binary lifting or \(O(1)\) Weighted Ancestors to locate the state of each substring \(S[l_t..r_t]\), (3) sorting by Euler-tour dfn, (4) computing \(k-1\) tree LCAs, and (5) splitting compressed edges whenever \(|U_t|\) falls strictly inside an edge \([\operatorname{len}(\operatorname{link}(u))+1, \operatorname{len}(u)]\). Theorem 13.2 bypasses all five steps: sorting by \((\operatorname{rk}[l_t], |U_t|)\) via \(O(1)\) \(\operatorname{LCE}\) automatically places intra-edge substrings in exact tree order, and clipping \(h_t = \min(\operatorname{LCE}(l_{t-1}, l_t), |U_{t-1}|, |U_t|)\) automatically splits compressed edges without touching a single tree node!

3. Suffix Tree Dominant Pairs (启发式合并支配对, T-2B-03)

3.1 The Diagnostic Signal: 2D Range Queries in Original String Index Space

Suppose we are given \(S[1..N]\) and \(Q\) range queries \([l, r]\) (\(1 \le l \le r \le N\)), and we must compute:

  • Range Longest Repeated Substring: the maximum length of a substring occurring at least twice inside \(S[l..r]\), i.e., \[\operatorname{Ans}(l, r) \;=\; \max_{l \le a < b \le r} \min\Bigl(r - b + 1,\;\; \operatorname{LCP}\bigl(\operatorname{suf}(a),\, \operatorname{suf}(b)\bigr)\Bigr),\]

  • Range Repeated Substring Detection (CF 1043G) or Range Pairwise LCP Sums (CF 1098F).

Why is this vastly harder than [NOI2015] 品酒大会 or CF 1073G? Because the query interval \([l, r]\) restricts starting indices \(a, b\) in original string index space \(\{1, \dots, N\}\), whereas \(\operatorname{LCP}(\operatorname{suf}(a), \operatorname{suf}(b))\) is governed by their LCA in Suffix Array / Cartesian Tree space! In general, a contiguous Suffix Tree subtree \([L_u, R_u]\) contains a scattered subset of original string indices, and there are \(\binom{N}{2} = \Theta(N^2)\) suffix pairs \((a, b)\).

How can we compress \(\binom{N}{2}\) pairs down to \(O(N \log N)\) pairs without losing the optimal answer for any query \([l, r]\)?

3.2 The Predecessor/Successor Dominance Proof (Theorem 13.3)

Consider an internal node \(u\) of the Suffix Tree (or Min-Cartesian Tree of \(H[2..N]\)) with string depth \(\ell_u = H[u]\). Suppose \(u\) merges two child subtrees \(\mathcal{A}\) (heavy child) and \(\mathcal{B}\) (light child), and we are considering all cross-subtree pairs \((a, b)\) with \(a \in \mathcal{A}, b \in \mathcal{B}\) (ordered so that \(a < b\) in original string index space). Every such cross-subtree pair has \(\operatorname{LCA}_{\text{ST}}(a, b) = u\), and therefore shares the exact same unclipped LCP:

\[\operatorname{LCP}\bigl(\operatorname{suf}(a),\, \operatorname{suf}(b)\bigr) \;=\; \ell_u.\]

Now fix an element \(i \in \mathcal{B}\) from the light child, and look at all elements of the heavy child \(\mathcal{A}\) in sorted order of their original string indices. Let:

  • \(i^- = \max\{x \in \mathcal{A} : x < i\}\) be the immediate predecessor of \(i\) in \(\mathcal{A}\), and
  • \(i^+ = \min\{x \in \mathcal{A} : x > i\}\) be the immediate successor of \(i\) in \(\mathcal{A}\).

Traverse the Min-Cartesian Tree of \(H[2..N]\) (or \(\mathcal{T}_{\text{link}}(\operatorname{SAM}(S^R))\)) bottom-up using DSU-on-Tree (树上启发式合并 / Small-to-Large Set Merging), maintaining at each node \(u\) an ordered set \(\mathcal{S}_u\) (std::set<int>) of original string starting indices \(\operatorname{SA}[x]\) (\(x \in [L_u, R_u]\)). When merging a light child’s index \(i\) into the heavy set \(\mathcal{S}_u\) at node \(u\) of string depth \(\ell_u\):

  1. Emit Predecessor & Successor Triples: Let \(i^- = \max\{x \in \mathcal{S}_u : x < i\}\) and \(i^+ = \min\{x \in \mathcal{S}_u : x > i\}\). Emit at most two candidate triples \((i^-, i, \ell_u)\) (if \(i^-\) exists) and \((i, i^+, \ell_u)\) (if \(i^+\) exists), then insert \(i\) into \(\mathcal{S}_u\) (or batch-insert after scanning the light child).
  2. Strict 2D Dominance: For any range query \([l, r]\) maximizing a function \(g(a, b, \ell_u)\) that is non-increasing in interval span \([a, b]\) and non-increasing in the right endpoint \(b\) (such as \(\min(r - b + 1, \ell_u)\) for range longest repeat, or indicator \([\ell_u \ge b - a]\) for range tandem squares), every cross-subtree pair \((x, i)\) or \((i, y)\) with \(\operatorname{LCA}(x, i) = u\) is dominated by \((i^-, i, \ell_u)\) or \((i, i^+, \ell_u)\).
  3. Exact Sparsity Bound: Across the entire Suffix Tree of \(S[1..N]\), the total number of generated dominant triples \(\mathcal{D}\) satisfies: \[\boxed{|\mathcal{D}| \;\le\; 2 N \lfloor \log_2 N \rfloor.}\]

Proof of Theorem 13.3

Let \(z \in \mathcal{S}_u\) be any element strictly to the left of \(i^-\) (\(z < i^- < i\)). Both pairs \((z, i)\) and \((i^-, i)\) have \(\operatorname{LCA} = u\) and thus share the exact same \(\operatorname{LCP} = \ell_u\). Moreover:

  • Containment Dominance: Since \(z < i^- < i\), we have \([i^-, i] \subsetneq [z, i]\). Any query \([l, r]\) that contains \([z, i]\) (\(l \le z < i \le r\)) automatically contains \([i^-, i]\) (\(l \le i^- < i \le r\)).
  • Right-Clipping Equivalence: Both \((z, i)\) and \((i^-, i)\) have the exact same right index \(b = i\), so their right-boundary-clipped repeat lengths inside \([l, r]\) are identical: \[\min(r - i + 1,\, \ell_u) \;=\; \min(r - i + 1,\, \ell_u).\] Symmetrically, let \(w \in \mathcal{S}_u\) be any element strictly to the right of \(i^+\) (\(i < i^+ < w\)). Then \([i, i^+] \subsetneq [i, w]\), so \((i, i^+)\) is valid for every query \([l, r]\) where \((i, w)\) is valid, and because \(i^+ < w\), its right-boundary-clipped repeat length is at least as large: \[\min(r - i^+ + 1,\, \ell_u) \;\ge\; \min(r - w + 1,\, \ell_u).\] Finally, whenever an index \(i \in \{1, \dots, N\}\) is merged from a light child into a heavy child, the size of the subtree containing \(i\) at least doubles (\(|\mathcal{S}_{\text{new}}| \ge 2 |\mathcal{S}_{\text{light}}|\)). Thus each index \(i\) acts as a light element at most \(\lfloor \log_2 N \rfloor\) times, emitting at most \(2\) triples per light insertion, giving \(|\mathcal{D}| \le 2 N \lfloor \log_2 N \rfloor\). \(\blacksquare\)
WarningBatch Querying vs. Incremental Insertion During Light-Subtree Merges

When merging a light child \(v\) into the heavy set \(\mathcal{S}_u\) at node \(u\), should you insert elements of \(v\) into \(\mathcal{S}_u\) one by one as you query \((i^-, i^+)\), or query all \(i \in v\) against \(\mathcal{S}_u\) first and then insert all \(i \in v\) into \(\mathcal{S}_u\)?

  • Querying all \(i \in v\) against \(\mathcal{S}_u\) first, then inserting all \(i \in v\) is always valid (and strictly cleaner!), because any pair \((i_1, i_2)\) where both \(i_1, i_2 \in v\) belong to the same light child \(v\) has \(\operatorname{LCA}(i_1, i_2)\) inside \(v\)’s subtree at depth \(\ell \ge \ell_u\)—it was already captured when \(v\)’s subtree was processed!

4. Reverse-Engineering Scratchpad, Algorithmic Contracts, Two-Threshold 2D Sweeps & Boundary Pitfalls (BP-13-01–BP-13-03 / BP-2B-03–BP-2B-05)

4.1 Contract 13.1 — Zero-Tree Substring Virtual Suffix Tree DP (CF 1073G)

Given query sets \(A_q, B_q\) of substrings \(U = S[l..r]\), the following contract computes \(\sum_{u \in A_q} \sum_{v \in B_q} \operatorname{LCP}(u, v)\) in \(O(k \log k)\) time where \(k = |A_q| + |B_q|\):

struct SubItem {
    int l, len;
    long long wA, wB;
};

// Returns true if U < V in lexicographical substring order using O(1) LCE
bool cmp_sub(const SubItem& a, const SubItem& b) {
    if (a.l == b.l) return a.len < b.len;
    int d = std::min({lce_query(a.l, b.l), a.len, b.len});
    if (d == a.len || d == b.len) return a.len < b.len;
    return rk[a.l] < rk[b.l];
}

long long solve_virtual_st_query(std::vector<SubItem>& items) {
    if (items.empty()) return 0;
    std::sort(items.begin(), items.end(), cmp_sub);
    // 1. Deduplicate identical substrings (l_a, len_a) == (l_b, len_b) via LCE >= len
    std::vector<SubItem> U;
    for (const auto& it : items) {
        if (!U.empty() && U.back().len == it.len &&
            lce_query(U.back().l, it.l) >= it.len) {
            U.back().wA += it.wA;
            U.back().wB += it.wB;
        } else {
            U.push_back(it);
        }
    }
    long long ans = 0;
    int m = (int)U.size();
    for (int i = 0; i < m; ++i) ans += U[i].wA * U[i].wB * U[i].len; // Same-substring pairs
    if (m == 1) return ans;

    // 2. Clipped adjacent LCPs h[1 .. m-1]
    std::vector<int> h(m);
    for (int i = 1; i < m; ++i)
        h[i] = std::min({lce_query(U[i - 1].l, U[i].l), U[i - 1].len, U[i].len});

    // 3. Monotonic stack over h[1 .. m-1]
    std::vector<int> L(m), R(m), st;
    for (int i = 1; i < m; ++i) {
        while (!st.empty() && h[st.back()] > h[i]) st.pop_back(); // Strict > on left
        L[i] = st.empty() ? 1 : st.back() + 1;
        st.push_back(i);
    }
    st.clear();
    for (int i = m - 1; i >= 1; --i) {
        while (!st.empty() && h[st.back()] >= h[i]) st.pop_back(); // Non-strict >= on right
        R[i] = st.empty() ? m - 1 : st.back() - 1;
        st.push_back(i);
    }
    std::vector<long long> prefA(m + 1, 0), prefB(m + 1, 0);
    for (int i = 0; i < m; ++i) {
        prefA[i + 1] = prefA[i] + U[i].wA;
        prefB[i + 1] = prefB[i] + U[i].wB;
    }
    for (int i = 1; i < m; ++i) {
        long long leftA  = prefA[i] - prefA[L[i] - 1];
        long long leftB  = prefB[i] - prefB[L[i] - 1];
        long long rightA = prefA[R[i] + 1] - prefA[i];
        long long rightB = prefB[R[i] + 1] - prefB[i];
        ans += 1LL * h[i] * (leftA * rightB + leftB * rightA);
    }
    return ans;
}

4.2 Contract 13.2 — DSU-on-Tree Dominant Pairs + Two-Threshold 2D Sweep (T-2B-03)

Once Theorem 13.3 extracts the \(\le 2N \log_2 N\) dominant triples \((a, b, \ell)\) (\(1 \le a < b \le N\)), how do we answer \(Q\) range longest repeated substring queries \(\operatorname{Ans}(l, r) = \max_{(a, b, \ell) \in \mathcal{D},\, a \ge l,\, b \le r} \min(r - b + 1,\, \ell)\) in \(O(N \log^2 N + Q \log N)\) time?

We decouple the \(\min(r - b + 1, \ell)\) operation by splitting at the right-endpoint threshold \(e = b + \ell - 1\):

  • Regime 1 (Unclipped: \(a \ge l\) and \(b + \ell - 1 \le r\)): The entire repeat of length \(\ell\) starting at \(b\) fits inside \([l, r]\), contributing \(\ell\).
  • Regime 2 (Right-Boundary Clipped: \(a \ge l\) and \(b \le r < b + \ell - 1\)): The repeat starting at \(b\) overhangs \(r\) and is clipped to length \(r - b + 1 = r - (b - 1)\). Maximizing \(r - b + 1\) for a fixed query \(r\) is equivalent to minimizing \(b\) (or maximizing \(-b\)) over all triples with \(a \ge l\), \(b \le r\), and \(b + \ell - 1 > r\)!

By separating the two regimes via sorting by the threshold \(e = b + \ell - 1\) vs. \(r\), we completely avoid any 3D query or deletion from a max-structure:

  • Pass 1 (Regime 1: \(b + \ell - 1 \le r\) and \(a \ge l\)): Sort triples by \(e = b + \ell - 1\) ascending and queries by \(r\) ascending. As \(e \le r\), insert \((a, \text{val} = \ell)\) into a suffix-max Fenwick tree over \(a\), and query \(\max_{a \ge l} \ell\).
  • Pass 2 (Regime 2: \(b + \ell - 1 > r\), \(a \ge l\), and \(b \le r\)): Notice that since \(a < b\), any triple with \(a \ge l\) and \(b \le r\) automatically satisfies \(l \le a < b \le r\)! Sort triples by \(e = b + \ell - 1\) descending and queries by \(r\) descending. As \(e > r\), insert point \(b\) into a Suffix-Min Fenwick tree at position \(a \in [1, N]\)! Then for query \([l, r]\), the minimum \(b_{\min}\) among all inserted triples with \(a \ge l\) satisfies \(b_{\min} \le r\) if and only if at least one valid Regime-2 triple exists, contributing \(r - b_{\min} + 1\)!
// Pass 1 (Unclipped: b + len - 1 <= r, a >= l) & Pass 2 (Clipped: b + len - 1 > r, a >= l)
// Every triple (a, b, len) has 1 <= a < b <= N.
void solve_range_longest_repeat(int N, std::vector<Triple>& dom, std::vector<Query>& qs) {
    // Pass 1: Sort by e = b + len - 1 ascending
    std::sort(dom.begin(), dom.end(), [](const Triple& x, const Triple& y) {
        return x.b + x.len - 1 < y.b + y.len - 1;
    });
    std::sort(qs.begin(), qs.end(), [](const Query& x, const Query& y) {
        return x.r < y.r;
    });
    SuffixMaxBIT bit_len(N); // Supports update(a, len) and query_suffix_max(l)
    size_t p = 0;
    for (auto& q : qs) {
        while (p < dom.size() && dom[p].b + dom[p].len - 1 <= q.r) {
            bit_len.update(dom[p].a, dom[p].len);
            ++p;
        }
        q.ans = std::max(q.ans, bit_len.query(q.l));
    }

    // Pass 2: Sort by e = b + len - 1 descending; maintain min(b) at index a
    SuffixMinBIT bit_b(N); // Supports update(a, b) and query_suffix_min(l)
    int idx = (int)dom.size() - 1;
    for (int i = (int)qs.size() - 1; i >= 0; --i) {
        while (idx >= 0 && dom[idx].b + dom[idx].len - 1 > qs[i].r) {
            bit_b.update(dom[idx].a, dom[idx].b);
            --idx;
        }
        int b_min = bit_b.query(qs[i].l);
        if (b_min <= qs[i].r) {
            qs[i].ans = std::max(qs[i].ans, qs[i].r - b_min + 1);
        }
    }
}

Look closely at Pass 2 in the code above: because we want to maximize \(r - b + 1\), we want the smallest possible \(b\) among all triples with \(e > r\) and \(a \ge l\). If the minimum such \(b_{\min}\) satisfies \(b_{\min} \le r\), it immediately gives the optimal clipped answer \(r - b_{\min} + 1\); if \(b_{\min} > r\), then no triple with \(e > r\) and \(a \ge l\) has \(b \le r\)! Thus Pass 2 needs only a 1D Suffix-Min Fenwick Tree (SuffixMinBIT) over \(a\)—zero Segment Trees required!

  1. Diagnostic Signal: Negative weights mean the maximum product across two subtrees can come from either the two largest values or the two smallest (most negative) values.
  2. Combinatorial Word Invariant: A pair of suffixes \((\operatorname{SA}[x], \operatorname{SA}[y])\) (\(x < y\)) has \(\operatorname{LCP} = r\) if and only if \(x\) and \(y\) become connected for the first time when edges of weight \(H[k] = r\) are added in decreasing order of weight. At the moment edge \((k-1, k)\) merges components \(u\) and \(v\), all \(\operatorname{sz}[u] \cdot \operatorname{sz}[v]\) cross-component pairs have exact \(\operatorname{LCP} = H[k]\), and the extremal cross-component product is \(\max\bigl(\max_1[u]\max_1[v],\, \min_1[u]\min_1[v]\bigr)\).
  3. Algorithmic Compilation:
    • Initialize cnt[0..N-1] = 0 and best[0..N-1] = -INF (where \(\text{INF} = 4 \times 10^{18}\)).
    • Bucket-sort \(k \in [2..N]\) by \(H[k]\) descending. Initialize DSU with \(\operatorname{sz}[x] = 1, \max_1[x] = \min_1[x] = a_{\operatorname{SA}[x]}\).
    • For \(r = N - 1\) down to \(0\): merge all \((k-1, k)\) with \(H[k] = r\), updating cnt[r] and best[r].
    • Sweep \(r = N - 2\) down to \(0\): cnt[r] += cnt[r+1], best[r] = max(best[r], best[r+1]). Print (cnt[r], cnt[r] ? best[r] : 0). Time: \(O(N \alpha(N))\).

Problem 13.3 (W2B-03) — CF 802I — Fake News (hard)

  • Mathematical Statement: Given a string \(S[1..N]\) (\(T\) test cases), compute the sum of squared occurrence counts over all distinct non-empty substrings \(P\) of \(S\): \[\Sigma_{\text{sq}} \;=\; \sum_{P \in \operatorname{Sub}(S)} \operatorname{occ}_S(P)^2.\]

  • Constraints: \(\sum N \le 10^5\), \(|\Sigma| = 26\), time limit \(2.0\text{ s}\).

NoteHint 1 — Diagnostic Signal

There are up to \(\binom{N+1}{2}\) distinct substrings \(P\). We need to group them by their equivalence classes on \(\operatorname{ST}(S)\) or double-count ordered pairs of occurrences.

NoteHint 2 — Combinatorial Word Invariant

View 1 (Cartesian Tree Nodes): By Theorem 13.1, each contracted internal node \(u\) with interval \([L_u, R_u]\) covers \(\ell_u - \ell_{p(u)}\) distinct substrings, each occurring \(\operatorname{sz}(u) = R_u - L_u + 1\) times, and each leaf \(x\) covers \((N - \operatorname{SA}[x] + 1) - \max(H[x], H[x+1])\) substrings occurring \(1\) time. View 2 (Double Counting Pairs): \(\operatorname{occ}_S(P)^2\) counts ordered pairs of starting positions \((i, j)\) where \(P\) occurs. Summing over all \(P\) counts, for each pair \((i, j)\), the number of common non-empty prefixes of \(\operatorname{suf}(i)\) and \(\operatorname{suf}(j)\), which is \(\operatorname{LCP}(\operatorname{suf}(i), \operatorname{suf}(j))\)!

NoteHint 3 — Algorithmic Assembly

Using View 2, separate \(i = j\) (which gives \(\sum_{i=1}^N (N - i + 1) = \frac{N(N+1)}{2}\)) and \(i \ne j\) (which gives \(2 \sum_{1 \le x < y \le N} \operatorname{LCP}(\operatorname{SA}[x], \operatorname{SA}[y])\)), and apply the monotonic stack from Problem 13.1!

TipFull Derivation & Solution (W2B-03)

  1. Diagnostic Signal: Summing \(\operatorname{occ}_S(P)^2\) over distinct substrings \(P\) can be done either on the contracted height Cartesian Tree or by double counting occurrence pairs.

  2. Combinatorial Word Invariant (Double Counting Identity): \[\sum_{P \in \operatorname{Sub}(S)} \operatorname{occ}_S(P)^2 \;=\; \sum_{i=1}^N \sum_{j=1}^N \sum_{d=1}^{\min(|\operatorname{suf}(i)|, |\operatorname{suf}(j)|)} \bigl[S[i..i+d-1] = S[j..j+d-1]\bigr] \;=\; \sum_{i=1}^N \sum_{j=1}^N \operatorname{LCP}\bigl(\operatorname{suf}(i),\, \operatorname{suf}(j)\bigr).\] Splitting diagonal (\(i = j\)) and off-diagonal (\(i \ne j\)) terms gives: \[\Sigma_{\text{sq}} \;=\; \frac{N(N+1)}{2} \;+\; 2 \sum_{k=2}^N H[k] \cdot (k - L'_k + 1) \cdot (R'_k - k + 1).\]

  3. Algorithmic Compilation: Compute \(\operatorname{SA}\), \(H[2..N]\), and monotonic stack bounds \([L'_k, R'_k]\) in \(O(N)\) time, then output the formula above.

  4. Broken-Invariant Counterexample (Counterexample 13.5): If using View 1 (summing \((\ell_u - \ell_{p(u)}) \operatorname{sz}(u)^2\) over Cartesian Tree nodes), forgetting the \(N\) leaf edges \((\operatorname{occ} = 1)\) misses \(\sum_{x=1}^N \bigl((N - \operatorname{SA}[x] + 1) - \max(H[x], H[x+1])\bigr) \cdot 1^2\).

  • Mathematical Statement: Given \(M\) strings \(T_1, \dots, T_M\) with signed integer costs \(c_1, \dots, c_M \in [-10^7, 10^7]\), maximize over all non-empty strings \(P\): \[f(P) \;=\; |P| \cdot \sum_{i=1}^M c_i \cdot \operatorname{occ}_{T_i}(P).\]

Only evaluate intervals where \(H[k] > \max(H[L'_k - 1], H[R'_k + 1])\), plus \(\operatorname{occ}=1\) leaves where \(\operatorname{rem}[\operatorname{SA}[x]] > \max(H[x], H[x+1])\).

    • Run Pass 1 and Pass 2 of Contract 13.2 using two 1D Fenwick Trees in \(O(N \log^2 N + Q \log N)\) total time.

Broken-Invariant Counterexample: Omitting Pass 2 (\(b + \ell_u - 1 > r_q\)) misses valid repeats inside \(S[l_q..r_q]\) whenever the two suffixes \(a, b \in [l_q, r_q]\) continue matching past \(r_q\) (e.g., \(S = \texttt{ababab}\), query \([1, 4] = \texttt{abab}\): pair \((1, 3)\) has global \(\ell = 4\), so \(b + \ell - 1 = 6 > 4\), contributing \(4 - 3 + 1 = 2\) via Pass 2!).

Problem 13.8 (W2B-36) — CF 1043G — Speckled Band

  • Mathematical Statement: Given a string \(S[1..N]\) over \(|\Sigma| = 26\) and \(Q\) substring queries \([l, r]\), you must partition \(S[l..r]\) into \(m \ge 2\) contiguous non-empty segments \(W_1 W_2 \cdots W_m\) such that the number of distinct segment strings \(|\{W_1, \dots, W_m\}|\) is strictly less than \(m\) (at least one segment string is used \(\ge 2\) times).   • Constraints: \(1 \le N, Q \le 2 \times 10^5\), \(|\Sigma| = 26\), time limit \(7.0\text{ s}\).
NoteHint 1 — Diagnostic Signal

Why is the answer always in \(\{-1, 1, 2, 3, 4\}\)?

  • If all characters in \(S[l..r]\) are distinct (only possible when \(r - l + 1 \le 26\)), no substring repeats, so the answer is -1.
  • Otherwise, some single character \(c\) appears at least twice! Cutting out the first two occurrences of \(c\) splits \(S[l..r] = U \cdot c \cdot V \cdot c \cdot W\) (or similar), which uses at most \(4\) distinct strings \(\{c, U, V, W\}\).
NoteHint 2 — Combinatorial Word Invariant

Classify the exact conditions for answers 1, 2, and 3:

  • Answer 1: \(S[l..r] = A^k\) (\(k \ge 2\)) is an exact periodic power (test prime divisors \(p \mid (r - l + 1)\) via \(O(1)\) \(\operatorname{LCE}\), Problem 1.3).
  • Answer 2: \(S[l..r]\) can be written as \(A B A\) (\(S[l..r]\) has a non-empty proper border!), \(A A B\) (\(S[l..r]\) starts with a square \(AA\)), or \(B A A\) (\(S[l..r]\) ends with a square \(AA\)).
  • Answer 3: \(S[l]\) repeats in \(S[l+1..r]\) (\(c B c D\)), \(S[r]\) repeats in \(S[l..r-1]\) (\(D c B c\)), or \(S[l..r]\) contains any square \(AA\) (\(U A A V\))!
NoteHint 3 — Algorithmic Assembly

Precompute the shortest square starting at each \(i\) (\(\operatorname{sqL}[i]\)) and ending at each \(j\) (\(\operatorname{sqR}[j]\)) in \(O(N \log N)\) time using harmonic checkpoints (Chapter 08):

  • Answer 2 holds iff \(\operatorname{sqL}[l] \le r\), or \(\operatorname{sqR}[r] \ge l\), or \(S[l..r]\) has a border (tested in \(O(\sqrt{N})\) via SA-neighborhood + short lengths or \(O(\log N)\) via IPM, Chapter 15).
  • Answer 3 holds iff character \(S[l]\) or \(S[r]\) occurs \(\ge 2\) times in \(S[l..r]\), or \(\min_{l \le i \le r} \operatorname{sqL}[i] \le r\) (a 1D RMQ query!).
TipFull Derivation & Solution (W2B-36)
  1. Diagnostic Signal: Instead of searching over partitions, reduce the minimum color count to a 5-way structural cascade \(\{-1, 1, 2, 3, 4\}\) on \(S[l..r]\).
  2. Combinatorial Word Invariant:
    • -1: All characters in \(S[l..r]\) occur \(\le 1\) time (checked in \(O(|\Sigma|)\) via 26 prefix-sum arrays).
    • 1: \(L = r - l + 1\) has a prime divisor \(p \mid L\) such that \(\operatorname{LCE}_S(l, l + L/p) \ge L - L/p\) (so \(S[l..r] = W^p\) partitions into \(p \ge 2\) identical copies of a single string \(W\), using \(1\) distinct segment).
    • 2: Using \(2\) distinct strings \(A, B\) requires a pattern of the form \(A B A\) (non-empty border), \(A A B\) (prefix square), or \(B A A\) (suffix square), because any longer alternating pattern \(A B A B \dots\) contains one of these three as a prefix/suffix/whole!
    • 3: Using \(3\) distinct strings holds iff \(S[l]\) repeats in \(S[l+1..r]\) (\(S[l] \cdot B \cdot S[l] \cdot C\)), \(S[r]\) repeats in \(S[l..r-1]\), or \(S[l..r]\) contains an interior square \(U \cdot A \cdot A \cdot V\) (\(\min_{i \in [l, r]} \operatorname{sqL}[i] \le r\)).
    • 4: Otherwise, since some character \(c\) repeats inside \(S[l+1..r-1]\), \(U \cdot c \cdot V \cdot c \cdot W\) uses \(4\) strings.
  3. Algorithmic Compilation:
    • Build \(\operatorname{SA}\) + \(O(1)\) \(\operatorname{LCE}\) on \(S\) and \(S^R\).
    • Enumerate harmonic checkpoints \((d, k d)\) (\(1 \le d \le N/2\)) to find all square intervals of half-length \(d\), updating \(\operatorname{sqL}[i] = \min(\operatorname{sqL}[i], i + 2d - 1)\) and \(\operatorname{sqR}[j] = \max(\operatorname{sqR}[j], j - 2d + 1)\) via a DSU next-unvisited jumper (or Segment Tree) in \(O(N \log N)\) time. Build an RMQ table over \(\operatorname{sqL}[1..N]\).
    • For each query \([l, r]\), test -1, 1, 2, 3 in order, falling back to 4.
  4. Broken-Invariant Counterexample: Testing only \(A B A\) (border) for answer 2 fails on \(S[l..r] = \texttt{"aabc"}\) (\(A = \texttt{"a"}, B = \texttt{"bc"}\), which has no border yet splits as \(A \cdot A \cdot B\) with \(2\) colors!).

Along the heavy path from \(v_l\) to the root (or at each centroid ancestor \(c\) of \(v_l\)), each light subtree hanging off ancestor \(u\) has a fixed LCA depth \(\ell_u = \operatorname{len}(u)\) with \(v_l\).

NoteHint 3 — Algorithmic Assembly

Apply the Two-Threshold Split of Section 4.2 to every index \(i \in [l, r]\) meeting \(v_l\) at ancestor \(u\) (depth \(\ell_u\)):

  • Regime 1 (\(i + \ell_u - 1 \le r\)): contributes \(\ell_u\).
  • Regime 2 (\(i \le r < i + \ell_u - 1\)): contributes \(r - i + 1 = (r + 1) - i\). Using Centroid Decomposition on \(\mathcal{T}\), each node \(v_i\) belongs to \(O(\log N)\) centroid subtrees, generating \(O((N + Q)\log N)\) 2D range sum events answered by two Fenwick Trees in \(O((N + Q)\log^2 N)\) time!
TipFull Derivation & Solution (W2A-40)
  1. Diagnostic Signal: Summing \(\min\bigl(r - i + 1,\, \operatorname{len}(\operatorname{LCA}_{\mathcal{T}}(v_l, v_i))\bigr)\) over \(i \in [l, r]\) couples tree LCA depth \(\ell_u\) with the linear right-clipping threshold \(i + \ell_u - 1 \le r\).
  2. Combinatorial Word Invariant:

    • Build \(\mathcal{T} = \mathcal{T}_{\text{link}}(\operatorname{SAM}(S^R))\) (or the Contracted Min-Cartesian Tree of \(H[2..N]\)) where leaf \(v_i\) represents \(\operatorname{suf}(i)\) and \(\operatorname{len}(\operatorname{LCA}(v_l, v_i)) = \operatorname{LCE}_S(l, i)\).

    • Decompose \(\mathcal{T}\) via HLD. When \(v_l\) walks up its \(O(\log N)\) heavy chains to the root, for any \(v_i\) in the subtree of a heavy chain \(C\), \(\operatorname{LCA}(v_l, v_i)\) is the shallower of \(v_l\)’s entry point \(w_l \in C\) and \(v_i\)’s entry point \(w_i \in C\): \[\operatorname{len}\bigl(\operatorname{LCA}(v_l, v_i)\bigr) \;=\; \min\bigl(\operatorname{len}(w_l),\, \operatorname{len}(w_i)\bigr).\]

    • Splitting each heavy chain \(C\) into nodes above \(w_l\) (\(\operatorname{len}(w_i) \le \operatorname{len}(w_l)\), where \(\ell = \operatorname{len}(w_i)\) is determined by \(i\)) and nodes strictly below \(w_l\) (\(\operatorname{len}(w_i) > \operatorname{len}(w_l)\), where \(\ell = \operatorname{len}(w_l)\) is determined by \(l\)), every contribution \(\min(r - i + 1, \ell)\) splits at \(e = i + \ell - 1 \le r\) (contributing \(\ell\)) vs. \(e > r, i \le r\) (contributing \((r + 1) - i\)).

  3. Algorithmic Compilation:
    • Build \(\mathcal{T}\) and its HLD. Each leaf \(v_i\) produces \(O(\log N)\) point events \((w_i, i, \ell = \operatorname{len}(w_i))\), and each query \((l, r)\) produces \(O(\log N)\) chain prefix/suffix queries on \([l, r]\).
    • Process each heavy chain independently (walking down the chain for the \(\ell = \operatorname{len}(w_i)\) pass and up the chain for the \(\ell = \operatorname{len}(w_l)\) pass), maintaining two Fenwick Trees over string index \(i \in [1, N]\) and threshold \(e = i + \ell - 1 \in [1, 2N]\) to sum \(\ell\) for \(e \le r\) and \((r + 1) - i\) for \(i \le r < e\). Total time: \(O((N + Q) \log^2 N)\), space \(O((N + Q) \log N)\).
  4. Broken-Invariant Counterexample: Remember to exclude the sub-branch of \(w_l\) that leads toward \(v_l\) itself (otherwise pairs \((v_l, v_i)\) whose true LCA is deeper than \(w_l\) on the next heavy chain get double-counted at depth \(\operatorname{len}(w_l)\)!).
