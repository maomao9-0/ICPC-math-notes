1. The 5-Structure Inverse Reconstruction Duality: Equality + Forbidden-Edge Decomposition (T-3A-06)

1.1 The Diagnostic Signal: Inverting String Data Structures

In forward stringology, we are given a known string \(S[1..N]\) and compute a structural summary: its KMP prefix function \(\pi[1..N]\), Z-array \(Z[2..N]\), Manacher palindrome radii \(R[1..2N-1]\), Suffix Array \(\operatorname{SA}[1..N]\) (with or without height), or Lyndon array \(\lambda[1..N]\).

In Inverse String Reconstruction, the problem is reversed: we are given a candidate integer array (or partial array with wildcards) and an alphabet \(\Sigma\) of size \(\sigma = |\Sigma|\), and we must:

  1. Realizability & Lex-Smallest Construction: Decide whether any string \(S \in \Sigma^N\) produces the given structure, and if so, output the lexicographically smallest such string \(S\); or
  2. Exact Chromatic / Combinatorial Counting: Count the total number of valid strings \(S \in \Sigma^N\) modulo \(M\) that realize the given structure.

Why does naive backtracking or arbitrary graph coloring fail? Because a KMP, Z, or Manacher array encodes both positive prefix/palindrome equalities (\(S[u] = S[v]\)) and negative termination mismatches (\(S[u] \ne S[v]\)). General graph \(\sigma\)-coloring is NP-complete—yet for valid string arrays, the induced mismatch graph has a hidden left-to-right chordal structure that makes both greedy construction and exact \(\sigma\)-coloring solvable in \(O(N)\) or \(O(N \log N)\) time!

1.2 The Combinatorial Word Invariant: The 5-Structure Inverse Reconstruction Duality Table

Every comparison-based string array is defined by a sequence of longest match extensions: each entry asserts that two substrings match up to a specific length \(L\), and mismatch (or compare by \(<\)) at the very next offset \(L + 1\) (unless one substring hits the boundary of \(S[1..N]\)).

Proof of the Linear Edge-Count Bound for Inverse KMP, Z, and Manacher

  • Inverse KMP: At step \(i\), computing \(\pi[i]\) in forward KMP starts at \(q = \pi[i-1]\), walks \(q \leftarrow \pi[q]\) while \(S[i] \ne S[q + 1]\), and stops as soon as \(S[i] = S[q + 1]\) (setting \(\pi[i] = q + 1\)) or \(q = 0\). Therefore, in the inverse problem, \(\pi[i] \le \pi[i-1] + 1\) is achieved if and only if every ancestor length \(q\) visited along the chain \(\pi[i-1] \to \pi[\pi[i-1]] \to \dots\) down to \(\pi[i]\) had a mismatch \(S[i] \ne S[q + 1]\), and finally \(S[i] = S[\pi[i]]\) (if \(\pi[i] > 0\)) or \(S[i] \ne S[1]\) (if \(\pi[i] = 0\)). Because each mismatch step decreases the potential \(q\) by at least \(1\) while each index \(i\) increases \(q\) by at most \(+1\), the total number of mismatch edges across \(i = 2 \dots N\) is at most \(2N - 2\).
  • Inverse Z-Array & Manacher: We can push all \(N - 1\) range equalities \(S[1..Z[i]] = S[i..i+Z[i]-1]\) (or Manacher palindromes \(S[l_c..r_c] = S[l_c..r_c]^R\)) down a Binary-Lifting DSU (Ch 26) in \(O(N \log N)\) time—or even faster, in \(O(N)\) time, by maintaining the rightmost covered index \(r_{\max}\): whenever \(i + Z[i] - 1 > r_{\max}\), we only copy/unite \(S[r] = S[r - i + 1]\) for \(r = \max(i, r_{\max} + 1) \dots i + Z[i] - 1\) and advance \(r_{\max}\)! \(\blacksquare\)

2. Chordal Mismatch-Graph Chromatic Counting & Mandatory Forward Verification (T-3A-06)

2.1 Why the Mismatch Graph Is Chordal: Simplicial Elimination Ordering

Suppose we contract all forced equalities of a valid KMP \(\pi\) array, Z-array, or Manacher radius array into connected components using DSU (or direct left-to-right assignment). For each component \(c\), let \(\operatorname{first}(c) = \min\{i \in [1..N] : \operatorname{comp}(i) = c\}\) be the earliest index in \(S[1..N]\) belonging to component \(c\), and order the components \(c_1, c_2, \dots, c_m\) by increasing \(\operatorname{first}(c_1) < \operatorname{first}(c_2) < \dots < \operatorname{first}(c_m)\).

Look closely at every mismatch constraint \(S[u] \ne S[v]\) in Theorem 27.1:

  • In KMP: At index \(i\), the mismatch edges are \(S[i] \ne S[q + 1]\) where \(q \le \pi[i-1] \le i - 1\), so \(q + 1 \le i\) (and \(q + 1 < i\) whenever \(q < i - 1\); note \(q = i - 1\) only happens if \(\pi[i-1] = i - 1\), where \(S[1..i-1] = \texttt{a}^{i-1}\) so \(S[q + 1] = S[i-1] = S[1]\) is already at index \(1 < i\)!). Thus when \(i = \operatorname{first}(c)\) is the first appearance of a new component (\(\pi[i] = 0\)), every forbidden partner \(q + 1\) belongs to a component that already appeared in \(S[1..i-1]\)!
  • In Z-Array: A mismatch \(S[1 + Z[i]] \ne S[i + Z[i]]\) relates index \(i + Z[i]\) to the strictly earlier index \(1 + Z[i] < i + Z[i]\).
  • In Manacher: A mismatch \(S[l_c - 1] \ne S[r_c + 1]\) relates index \(r_c + 1\) to the strictly earlier index \(l_c - 1 < r_c + 1\).
NoteTheorem 27.2 (Chordal Mismatch-Graph & Exact Chromatic Polynomial Product)

Let \(\pi[1..N]\), \(Z[1..N]\), or \(R[1..2N-1]\) be a realizable KMP, Z, or Manacher array. Order the equality DSU components \(c_1, c_2, \dots, c_m\) by their first appearance \(\operatorname{first}(c_1) < \dots < \operatorname{first}(c_m)\).

  1. Pairwise Distinctness of Forbidden Predecessors: For any component \(c_r\) with first occurrence \(i = \operatorname{first}(c_r)\), let \(N_{\text{prev}}(c_r) = \{c_j : j < r \text{ and } (c_j, c_r) \in E_{\ne}\}\) be the set of earlier components forbidden at \(c_r\). In any valid string \(S\) realizing the input array, all components in \(N_{\text{prev}}(c_r)\) must already carry pairwise distinct characters! (Equivalently, \(N_{\text{prev}}(c_r)\) forms a clique in the constraint graph, so \(c_m, c_{m-1}, \dots, c_1\) is a perfect elimination ordering of a chordal graph.)
  2. Exact Chromatic Polynomial Formula: Over an alphabet \(\Sigma\) of size \(\sigma = |\Sigma|\), let \(\operatorname{deg}_{\text{prev}}(c_r) := |N_{\text{prev}}(c_r)|\) be the number of distinct earlier components (or distinct characters in a canonical valid reconstruction \(S^*\)) forbidden at \(c_r\). Then the exact number of valid strings \(S \in \Sigma^N\) realizing the input array is: \[\boxed{\#\{S \in \Sigma^N \text{ realizing the array}\} = \prod_{r=1}^{m} \max\bigl(0,\; \sigma - \operatorname{deg}_{\text{prev}}(c_r)\bigr).}\]

Proof of Theorem 27.2

Consider the first occurrence \(i = \operatorname{first}(c_r)\) of component \(c_r\):

  • In KMP, \(i\) is a new component iff \(\pi[i] = 0\). The forbidden positions at step \(i\) are \(\{q + 1 : q \in \operatorname{FailChain}(\pi[i-1])\} \cup \{1\}\). Why must all these positions \(q + 1\) hold pairwise distinct characters in any valid string \(S\)? Suppose two distinct border lengths \(q_1 > q_2\) on the failure chain of \(i - 1\) satisfied \(S[q_1 + 1] = S[q_2 + 1] = x\). Because \(q_2 \in \operatorname{Border}(S[1..q_1])\), appending the matching character \(S[q_1 + 1] = S[q_2 + 1]\) would extend border \(q_2\) to length \(q_2 + 1\) inside \(S[1..q_1 + 1]\), meaning that in KMP’s slink / next-character table (Ch 02), \(q_1\) and \(q_2\) share the same next character—so they represent the same forbidden character in \(S[1..i-1]\)! Thus the number of distinct characters forbidden at \(S[i]\) is invariant across every valid assignment of \(S[1..i-1]\) and equals the number of distinct components in \(N_{\text{prev}}(c_r)\)!
  • In Z-Array (if \(i + Z[i] \le N\), only the single character \(S[1 + Z[i]]\) is forbidden against \(S[i + Z[i]]\) per Z-box termination) and Manacher (only \(S[l_c - 1]\) is forbidden against \(S[r_c + 1]\) per center \(c\)), once we verify that a canonical reconstruction \(S^*\) is valid, every component \(c_r\) at \(i = \operatorname{first}(c_r)\) forbids a set of earlier indices whose values in any valid string must be pairwise distinct whenever they belong to distinct components that mutually conflict, or more directly: in any valid KMP/Manacher/Z array where each termination step at right endpoint \(i\) forbids characters at earlier indices \(< i\), two earlier indices \(a, b < i\) both compared against \(S[i]\) at step \(i\) are linked by the shared prefix/palindrome of \(S[1..i-1]\) unless they are already forced unequal by an earlier termination step! Consequently, the number of available choices for \(c_r\) out of \(\sigma\) letters is always \(\max(0, \sigma - \operatorname{deg}_{\text{prev}}(c_r))\). \(\blacksquare\)

2.2 The Mandatory Forward Verification Pass & The \(\pi = [0, 1, 0, 1, 1]\) Counterexample

A classic trap in Inverse String Reconstruction is checking only local conditions (such as \(\pi[1] = 0\) and \(\pi[i] \le \pi[i-1] + 1\) for KMP, or \(Z[i] \le N - i + 1\) for Z-arrays) and assuming the array is realizable if no direct self-loop \(S[u] \ne S[u]\) occurs during construction.

WarningPitfall 27.1 (BP-27-01 / BP-5A-04: The \(\pi = [0, 1, 0, 1, 1]\) Phantom-Equality Counterexample)

Consider the target KMP array \(\pi[1..5] = [0, 1, 0, 1, 1]\) of length \(N = 5\).

  1. Local Check Passes: \(\pi[1] = 0\), and at every step \(\pi[i] \le \pi[i-1] + 1\) (\(1 \le 1\), \(0 \le 2\), \(1 \le 1\), \(1 \le 2\)).
  2. Trace of Forced Equalities & Mismatches:
    • \(i = 1\): \(\pi[1] = 0 \implies\) assign \(S[1] = \texttt{'a'}\).
    • \(i = 2\): \(\pi[2] = 1 \implies S[2] = S[1] = \texttt{'a'}\).
    • \(i = 3\): \(\pi[3] = 0 \implies\) fail chain from \(\pi[2] = 1\) forbids \(S[3] \ne S[2] = \texttt{'a'}\) and \(S[3] \ne S[1] = \texttt{'a'}\). Assign \(S[3] = \texttt{'b'}\). Now \(S[1..3] = \texttt{"aab"}\).
    • \(i = 4\): \(\pi[4] = 1 \implies S[4] = S[1] = \texttt{'a'}\). Now \(S[1..4] = \texttt{"aaba"}\).
    • \(i = 5\): \(\pi[5] = 1 \implies\) starting from \(q = \pi[4] = 1\), for \(\pi[5]\) to drop from \(q + 1 = 2\) down to \(1\), we need a mismatch at \(q = 1\): \(S[5] \ne S[q + 1] = S[2]\), AND a match at \(\pi[5] = 1\): \(S[5] = S[1]\)!
  3. The Contradiction: Because step \(i = 2\) already forced \(S[2] = S[1] = \texttt{'a'}\), step \(i = 5\) simultaneously demands \(S[5] \ne S[2] = \texttt{'a'}\) and \(S[5] = S[1] = \texttt{'a'}\)! Indeed, any string satisfying the positive equalities has \(S = \texttt{"aabaa"}\), whose true KMP array is \([0, 1, 0, 1, \mathbf{2}] \ne [0, 1, 0, 1, 1]\)!

Universal Safeguard: Whenever you reconstruct a candidate string \(S^*\) from an input KMP \(\pi\), Z-array, or Manacher array \(R\) (whose validity is not guaranteed by the problem statement):

  1. Build \(S^*\) greedily over an unbounded integer alphabet \(\{1, 2, \dots, N\}\) by assigning each new component \(c_r\) the smallest positive integer not present among its forbidden neighbors \(N_{\text{prev}}(c_r)\).
  2. Run the standard \(O(N)\) forward KMP / Z / Manacher algorithm on \(S^*\) and check that the computed array equals the input array entry-for-entry, and that \(\max_{1 \le i \le N} S^*[i] \le \sigma\)!

3. The Suffix Array Adjacency Theorem (CF 1526E, ARC 044 D, T-5A-03)

3.1 Characterizing Valid Strings for a Given Suffix Array

Suppose we are given a permutation \(\operatorname{SA}[1..N]\) of \(\{1, 2, \dots, N\}\) (without the LCP/height array!) and asked to characterize all strings \(S[1..N] \in \Sigma^N\) whose suffix array is \(\operatorname{SA}\).

Let \(\operatorname{rk}[1..N+1]\) be the inverse rank array of \(\operatorname{SA}\), defined by \(\operatorname{rk}[\operatorname{SA}[i]] = i\) for \(1 \le i \le N\), together with the empty-suffix sentinel: \[\boxed{\operatorname{rk}[N + 1] := 0.}\] Why \(\operatorname{rk}[N + 1] = 0\)? Because the empty suffix \(S[N+1..N] = \varepsilon\) is strictly lexicographically smaller than every non-empty suffix \(S[u..N]\).

For any \(i \in \{1, 2, \dots, N - 1\}\), consider two suffixes \(u = \operatorname{SA}[i]\) and \(v = \operatorname{SA}[i + 1]\) that are adjacent in the suffix array. Since \(S[u..N] < S[v..N]\), their first characters must satisfy \(S[u] \le S[v]\). When can they be equal (\(S[u] = S[v]\)), and when must they be strictly unequal (\(S[u] < S[v]\))?

NoteTheorem 27.3 (Nong–Zhang–Chan / Burrows–Wheeler Suffix Array Adjacency Theorem)

Let \(\operatorname{SA}[1..N]\) be a permutation of \(\{1, \dots, N\}\) and \(\operatorname{rk}[1..N+1]\) be its inverse rank array with sentinel \(\operatorname{rk}[N + 1] = 0\). A string \(S[1..N] \in \Sigma^N\) has suffix array \(\operatorname{SA}\) if and only if for every \(i \in \{1, 2, \dots, N - 1\}\) with \(u = \operatorname{SA}[i]\) and \(v = \operatorname{SA}[i + 1]\):

  1. Permissive Step (\(\operatorname{rk}[u + 1] < \operatorname{rk}[v + 1]\)): \(S[u] \le S[v]\) (equality \(S[u] = S[v]\) is allowed).
  2. Forced Strict Step (\(\operatorname{rk}[u + 1] > \operatorname{rk}[v + 1]\)): \(S[u] < S[v]\) (strict inequality is mandatory).

Consequently, let \(D := \sum_{i=1}^{N-1} \mathbf{1}\bigl[\operatorname{rk}[\operatorname{SA}[i] + 1] > \operatorname{rk}[\operatorname{SA}[i + 1] + 1]\bigr]\) be the number of rank descents of shifted suffixes. Then:

  • The minimum alphabet size required to realize \(\operatorname{SA}\) is \(\boxed{\sigma_{\min} = D + 1}\).
  • The lexicographically smallest string realizing \(\operatorname{SA}\) sets \(S[\operatorname{SA}[1]] = \texttt{'a'}\) and \(S[\operatorname{SA}[i + 1]] = S[\operatorname{SA}[i]] + \mathbf{1}\bigl[\operatorname{rk}[\operatorname{SA}[i] + 1] > \operatorname{rk}[\operatorname{SA}[i + 1] + 1]\bigr]\).
  • Over an alphabet of size \(K\), the exact number of valid strings \(S \in \Sigma^N\) realizing \(\operatorname{SA}\) is: \[\boxed{\#\bigl\{S \in \Sigma^N : \operatorname{SA}(S) = \operatorname{SA}\bigr\} = \binom{N + K - 1 - D}{N} = \binom{N + K - 1 - D}{K - 1 - D}.}\]

Proof of Theorem 27.3 (Necessity & Backward-Induction Sufficiency)

  • Necessity (\(\implies\)): If \(\operatorname{SA}(S) = \operatorname{SA}\), then for every \(1 \le i < N\) with \(u = \operatorname{SA}[i]\) and \(v = \operatorname{SA}[i + 1]\), we have \(S[u..N] < S[v..N]\). Writing \(S[u..N] = S[u] \cdot S[u+1..N]\) and \(S[v..N] = S[v] \cdot S[v+1..N]\), lexicographical order requires \(S[u] \le S[v]\), and if \(S[u] = S[v]\), stripping the shared first character requires \(S[u+1..N] < S[v+1..N] \iff \operatorname{rk}[u + 1] < \operatorname{rk}[v + 1]\). Thus \(\operatorname{rk}[u + 1] > \operatorname{rk}[v + 1]\) forces \(S[u] < S[v]\).
  • Sufficiency (\(\impliedby\)): Suppose \(S[1..N]\) satisfies (1) and (2) for all \(1 \le i < N\). By transitivity of \(<\) on characters, to prove \(S[\operatorname{SA}[1]..N] < S[\operatorname{SA}[2]..N] < \dots < S[\operatorname{SA}[N]..N]\), it suffices to prove \(S[\operatorname{SA}[i]..N] < S[\operatorname{SA}[i + 1]..N]\) for every adjacent pair \((u, v) = (\operatorname{SA}[i], \operatorname{SA}[i + 1])\). Suppose for contradiction that some adjacent pair \((u, v) = (\operatorname{SA}[i], \operatorname{SA}[i + 1])\) violates \(S[u..N] < S[v..N]\). Among all violating adjacent pairs, choose the pair \((u, v)\) that maximizes \(\max(u, v)\) (i.e., minimizes the shorter remaining suffix length). Since \(S[u] \le S[v]\) holds by (1)–(2), the violation \(S[u..N] \ge S[v..N]\) is possible only if \(S[u] = S[v]\) and \(S[u+1..N] \ge S[v+1..N]\). Because \(S[u] = S[v]\) was permitted between \(u = \operatorname{SA}[i]\) and \(v = \operatorname{SA}[i + 1]\), Condition (2) guarantees \(\operatorname{rk}[u + 1] < \operatorname{rk}[v + 1]\). (Note that \(u\) cannot be \(N\), because \(\operatorname{rk}[N + 1] = 0 < \operatorname{rk}[v + 1]\) gives \(S[N..N] = S[u] < S[v] \cdot S[v+1..N]\) strictly since \(v \ne N\)!) Now look at the subarray of \(\operatorname{SA}\) from index \(a = \operatorname{rk}[u + 1] \ge 1\) to \(b = \operatorname{rk}[v + 1] > a\): the sequence of suffixes starts at \(S[\operatorname{SA}[a]..N] = S[u+1..N]\) and ends at \(S[\operatorname{SA}[b]..N] = S[v+1..N]\). If every adjacent step \((\operatorname{SA}[j], \operatorname{SA}[j + 1])\) for \(a \le j < b\) satisfied \(S[\operatorname{SA}[j]..N] < S[\operatorname{SA}[j + 1]..N]\), transitivity would give \(S[u+1..N] < S[v+1..N]\), contradicting \(S[u+1..N] \ge S[v+1..N]\)! Hence there exists some \(j \in [a, b - 1]\) where \((u', v') = (\operatorname{SA}[j], \operatorname{SA}[j + 1])\) also violates \(S[u'..N] < S[v'..N]\)—and since \(S[u'..N] \ge S[v'..N]\) forces \(S[u'] = S[v']\), all suffixes in \([a, b]\) share the same first character, or even simpler: on the set of all pairs \((x, y)\) with \(\operatorname{rk}[x] < \operatorname{rk}[y]\) and \(S[x..N] \ge S[y..N]\), advancing \((u, v) \mapsto (u + 1, v + 1)\) strictly increases \(\max(u, v)\) while maintaining \(\operatorname{rk}[u + 1] < \operatorname{rk}[v + 1]\) and \(S[u+1..N] \ge S[v+1..N]\), which must then contain an inverted adjacent pair inside \([\operatorname{rk}[u+1], \operatorname{rk}[v+1]]\)! By induction on \(\min(N - x, N - y)\) from the base case \(\min = 0\), no such pair \((x, y)\) can exist.
  • Stars-and-Bars Bijection: Setting \(\Delta_i = S[\operatorname{SA}[i + 1]] - S[\operatorname{SA}[i]] \ge \mathbf{1}[\operatorname{rk}[\operatorname{SA}[i]+1] > \operatorname{rk}[\operatorname{SA}[i+1]+1]]\) and subtracting the \(D\) mandatory \(+1\) jumps leaves \(N\) non-negative increments summing to \(\le K - 1 - D\), which by stars-and-bars equals \(\binom{N + K - 1 - D}{N}\). \(\blacksquare\)

4. LCP-Witnessed Substring Inequality Digraphs, \(\{0, 1\}\)-Weighted Tarjan SCCs & 2-SAT Prefix Branching (T-5A-03)

4.1 LCP-Witnessed Substring Inequalities \(\to\) DSU + \(\{0, 1\}\)-Weighted SCC DAG

Unlike substring equality (\(AB = CD \iff A = C \wedge B = D\)), a lexicographical substring inequality \(S[l_1..r_1] < S[l_2..r_2]\) or \(S[l_1..r_1] \le S[l_2..r_2]\) is a disjunction over the Longest Common Prefix (LCP) \(t = \operatorname{LCP}(S[l_1..r_1], S[l_2..r_2])\): \[S[l_1..r_1] < S[l_2..r_2] \iff \Bigl(\exists t \in [0, \min(L_1, L_2) - 1] : S[l_1 .. l_1 + t - 1] = S[l_2 .. l_2 + t - 1] \;\wedge\; S[l_1 + t] < S[l_2 + t]\Bigr)\] \[\lor\; \Bigl(L_1 < L_2 \;\wedge\; S[l_1 .. r_1] = S[l_2 .. l_2 + L_1 - 1]\Bigr),\] where \(L_1 = r_1 - l_1 + 1\) and \(L_2 = r_2 - l_2 + 1\).

When the LCP witness \(t\) is given (or determined by an inverse structure such as SA+LCP, Lyndon array, or explicit \(\operatorname{LCP}(U, V) = t\) constraints), each inequality splits cleanly into one range equality of length \(t\) plus at most one point character inequality at offset \(t\). We solve the resulting combined system of substring equalities (\(=\)), weak character inequalities (\(S[u] \le S[v]\)), and strict character inequalities (\(S[u] < S[v]\)) via a 4-Phase Pipeline:

  1. Phase 1 — Binary-Lifting DSU Equality Contraction (Ch 26): Insert all substring equalities \(S[l_1 .. l_1 + t - 1] = S[l_2 .. l_2 + t - 1]\) into a Binary-Lifting DSU and push down to level \(0\) in \(O((M + N \log N)\alpha(N))\) time. Let \(V_0 = \{\operatorname{find}_0(i) : 1 \le i \le N\}\) be the contracted character vertices.
  2. Phase 2 — \(\{0, 1\}\)-Weighted Inequality Digraph \(G = (V_0, E_0 \cup E_1)\):
    • Every weak constraint \(S[u] \le S[v]\) adds a directed edge \(\operatorname{find}_0(u) \xrightarrow{w = 0} \operatorname{find}_0(v)\).
    • Every strict constraint \(S[u] < S[v]\) (i.e., \(S[u] + 1 \le S[v]\)) adds a directed edge \(\operatorname{find}_0(u) \xrightarrow{w = 1} \operatorname{find}_0(v)\).
  3. Phase 3 — Tarjan SCC Feasibility Criterion (Zero Weight-1 Cycles): Run Tarjan’s SCC algorithm on \(G\) (treating both \(w = 0\) and \(w = 1\) edges as directed edges). Inside any Strongly Connected Component \(\mathcal{C} \subseteq V_0\), every vertex can reach every other vertex via \(\le\) edges, so all vertices in \(\mathcal{C}\) must be assigned the exact same character! Therefore: \[\boxed{\text{System is feasible over } \mathbb{Z}_{\ge 0} \iff \text{no weight-}1 \text{ edge } (x \xrightarrow{1} y) \text{ has } \operatorname{SCC}(x) = \operatorname{SCC}(y).}\]
  4. Phase 4 — Condensation DAG Longest Path: Contract each SCC into a super-node in the condensation DAG \(\mathcal{D}\), keeping all edges \((A \xrightarrow{w} B)\) with \(A \ne B\). Compute the longest path to each SCC in topological order: \[\boxed{\operatorname{dist}[B] = \max\Bigl(\{0\} \cup \bigl\{\operatorname{dist}[A] + w(A \to B) : (A \xrightarrow{w} B) \in \mathcal{D}\bigr\}\Bigr).}\] Then \(\sigma_{\min} = 1 + \max_{B} \operatorname{dist}[B]\) is the minimum required alphabet size, and setting \(S[i] = \texttt{'a'} + \operatorname{dist}[\operatorname{SCC}(\operatorname{find}_0(i))]\) produces the pointwise lexicographically smallest valid string \(S[1..N]\)!

4.2 2-SAT Prefix Branching for Unanchored Global Inequalities (CF 568C)

What if the LCP length \(t\) is not given, as in CF 568C — New Language: we are given a reference string \(S_0[1..N]\), a partition of \(\Sigma = \texttt{'a'}..\texttt{'z'}\) into Vowels (V) and Consonants (C), and \(M\) 2-SAT implication rules \((i, \text{type}_1) \implies (j, \text{type}_2)\), and we must find the lexicographically smallest valid string \(S[1..N] \ge S_0[1..N]\) (\(N \le 200\))?

Because there is only one global inequality \(S \ge S_0\), there are only \(N + 1\) possible values for \(t = \operatorname{LCP}(S, S_0) \in \{0, 1, \dots, N\}\)! Moreover, to minimize \(S\) lexicographically, we want the shared prefix \(S[1..t] = S_0[1..t]\) to be as long as possible:

  1. Descending LCP Search (\(t = N\) down to \(0\)):
    • At \(t = N\), check if \(S = S_0\) itself satisfies the 2-SAT clauses.
    • At \(t < N\), fix \(S[1..t] = S_0[1..t]\) (adding unary 2-SAT clauses \(x_i \equiv \operatorname{type}(S_0[i])\) for \(1 \le i \le t\)). At position \(t + 1\), we need \(S[t + 1] > S_0[t + 1]\). Because the 2-SAT graph only depends on whether \(S[t + 1]\) is a Vowel (V) or Consonant (C), we do not need to test all \(26\) letters—we only test at most two candidates for \(S[t + 1]\):
      • \(c_V = \min\{c > S_0[t + 1] : \operatorname{type}(c) = \texttt{V}\}\), and
      • \(c_C = \min\{c > S_0[t + 1] : \operatorname{type}(c) = \texttt{C}\}\) (tested in increasing order of character value).
  2. Left-to-Right Greedy Completion (\(i = t + 2 \dots N\)): Once the largest feasible \(t\) (and minimum valid \(S[t + 1] > S_0[t + 1]\)) is locked in, \(S > S_0\) is already guaranteed! For each remaining index \(i = t + 2 \dots N\), test the smallest overall letter 'a' and the smallest letter of the opposite V/C class via 2-SAT, locking in the smaller feasible choice. Total 2-SAT calls: at most \(2(N + 1) + 2N = 4N + 2\).

4.3 Reverse-Engineering Scratchpad, Algorithmic Contracts & Boundary Pitfalls (BP-27-01–BP-27-04 / BP-5A-04–BP-5A-07)

// Phase 2-4 Solver: {0, 1}-Weighted Inequality Digraph on DSU_0 roots -> Lex-Smallest String
// Input: num_vars, directed edges (u, v, w) where w=0 means S[u] <= S[v], w=1 means S[u] < S[v]
// Returns: dist[0..num_vars-1] (0-indexed minimum character offsets), or empty vector if infeasible
vector<int> solve_inequality_dag(int V, const vector<tuple<int, int, int>>& edges) {
    vector<vector<pair<int, int>>> adj(V);
    for (auto [u, v, w] : edges) {
        if (u == v && w == 1) return {}; // Immediate self-loop S[u] < S[u]
        adj[u].push_back({v, w});
    }
    vector<int> dfn(V, -1), low(V, 0), scc(V, -1), stk;
    int timer = 0, scc_cnt = 0;
    auto dfs = [&](auto& self, int u) -> void {
        dfn[u] = low[u] = timer++;
        stk.push_back(u);
        for (auto [v, w] : adj[u]) {
            if (dfn[v] == -1) {
                self(self, v);
                low[u] = min(low[u], low[v]);
            } else if (scc[v] == -1) {
                low[u] = min(low[u], dfn[v]);
            }
        }
        if (low[u] == dfn[u]) {
            while (true) {
                int x = stk.back(); stk.pop_back();
                scc[x] = scc_cnt;
                if (x == u) break;
            }
            scc_cnt++;
        }
    };
    for (int i = 0; i < V; ++i) if (dfn[i] == -1) dfs(dfs, i);

    // Check feasibility: no weight-1 edge inside any SCC
    // Note: Tarjan numbers SCCs in REVERSE topological order (scc_cnt - 1 down to 0)
    vector<int> dist(scc_cnt, 0);
    for (int u = 0; u < V; ++u) {
        for (auto [v, w] : adj[u]) {
            if (scc[u] == scc[v] && w == 1) return {}; // Positive cycle: S[u] < ... <= S[u]
        }
    }
    vector<vector<pair<int, int>>> dag(scc_cnt);
    for (int u = 0; u < V; ++u)
        for (auto [v, w] : adj[u])
            if (scc[u] != scc[v])
                dag[scc[u]].push_back({scc[v], w});

    for (int c = scc_cnt - 1; c >= 0; --c)
        for (auto [nxt, w] : dag[c])
            dist[nxt] = max(dist[nxt], dist[c] + w);

    vector<int> ans(V);
    for (int i = 0; i < V; ++i) ans[i] = dist[scc[i]];
    return ans;
}
WarningPitfall 27.2 (BP-27-02 / BP-5A-05: Omitting Empty-Suffix Sentinel \(\operatorname{rk}[N + 1] = 0\) in Theorem 27.3)

In the Suffix Array Adjacency Theorem (CF 1526E, ARC 044 D), when \(u = \operatorname{SA}[i] = N\) (the length-\(1\) suffix \(S[N..N]\)), the shifted index is \(u + 1 = N + 1\). Leaving \(\operatorname{rk}[N + 1]\) uninitialized (or out of bounds) corrupts the comparison \(\operatorname{rk}[N + 1] < \operatorname{rk}[v + 1]\). Because \(\varepsilon < S[v+1..N]\) always holds, \(\operatorname{rk}[N + 1] = 0\) (or \(-1\) in 0-based indexing) is always smaller than \(\operatorname{rk}[v + 1]\), so \(u = N\) never forces a strict jump \(S[N] < S[v]\)!

WarningPitfall 27.3 (BP-27-03 / BP-5A-06: Proper-Prefix Trap When \(d = \min(L_1, L_2)\) in LCP-Witnessed Inequalities)

Suppose a constraint specifies \(\operatorname{LCP}(S[l_1..r_1], S[l_2..r_2]) = d\) and \(S[l_1..r_1] \le S[l_2..r_2]\) with \(L_1 = r_1 - l_1 + 1\) and \(L_2 = r_2 - l_2 + 1\).

  • If \(d > \min(L_1, L_2)\), the input is immediately impossible (an LCP cannot exceed the shorter substring’s length).
  • If \(d == \min(L_1, L_2)\), no mismatch character exists at offset \(d\)! Instead, one substring is a prefix of the other, so \(S[l_1..r_1] \le S[l_2..r_2]\) holds if and only if \(L_1 \le L_2\) (and \(S[l_1..r_1] < S[l_2..r_2]\) holds iff \(L_1 < L_2\)). Blindly adding a character edge \(\operatorname{find}_0(l_1 + d) \to \operatorname{find}_0(l_2 + d)\) when \(d == \min(L_1, L_2)\) reads out-of-bounds characters \(S[r_1 + 1]\) and \(S[r_2 + 1]\)!
WarningPitfall 27.4 (BP-27-04 / BP-5A-07: Uninhabited V/C Class in 2-SAT String Construction CF 568C)

In CF 568C, if every letter of \(\Sigma\) is a Vowel (V) and zero letters are Consonants (C), the 2-SAT solver does not inherently know that C is an empty set! You must add unary clauses \((\neg \text{is\_C}(i))\) (i.e., edge C(i) -> V(i)) for every \(1 \le i \le N\) whenever class C (or V) contains \(0\) characters in \(\Sigma\).

    • Check \(0 \le d \le \min(L_1, L_2)\).
    • If \(d > 0\), let \(x_1 = \operatorname{kth\_on\_path}(u_1, v_1, d - 1)\) and \(x_2 = \operatorname{kth\_on\_path}(u_2, v_2, d - 1)\), and equate \(\operatorname{str}(u_1 \rightsquigarrow x_1) = \operatorname{str}(u_2 \rightsquigarrow x_2)\) by splitting at \(\operatorname{LCA}(u_1, x_1)\) and \(\operatorname{LCA}(u_2, x_2)\) into \(\le 3\) vertical equations in the Signed Tree Binary-Lifting DSU (Ch 26 §3.3).
    • If \(d == \min(L_1, L_2)\), require \(L_1 \le L_2\).
    • If \(d < \min(L_1, L_2)\), let \(y_1 = \operatorname{kth\_on\_path}(u_1, v_1, d)\) and \(y_2 = \operatorname{kth\_on\_path}(u_2, v_2, d)\), and record strict edge \(y_1 \xrightarrow{1} y_2\).
  3. Algorithmic Compilation: Push down the Signed Tree Binary-Lifting DSU from \(k = \lfloor \log_2 N \rfloor \downarrow 1\) in \(O(N \log N \alpha(N))\) time, map each recorded inequality \(y_1 \xrightarrow{1} y_2\) to \(\operatorname{find}_0(y_1) \xrightarrow{1} \operatorname{find}_0(y_2)\), and run solve_inequality_dag (§4.3) in \(O(N + M)\) time. Total complexity: \(O((N + M)\log N \cdot \alpha(N))\).
  4. Broken-Invariant Counterexample: Using \(x_1 = \operatorname{kth\_on\_path}(u_1, v_1, d)\) instead of \(d - 1\) for the equality endpoint equates \(d + 1\) vertices (including the mismatch characters \(y_1, y_2\)!), creating an immediate self-loop \(c[y_1] < c[y_1]\) in \(\operatorname{DSU}_0\)!
