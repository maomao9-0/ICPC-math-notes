1. Three Regimes of Range Longest Palindromic Substring (Range LPS, T-3A-03)

1.1 The Diagnostic Signal: Center-Hereditary Palindromes vs. Boundary Clipping

Given a static string \(S[1..N]\) and \(Q\) online queries \([l, r]\), we want to compute \(\operatorname{LPS}(l, r)\), the maximum length of a palindromic substring contained inside \(S[l..r]\). Unlike substring borders in Chapter 15 (which are non-hereditary and require dyadic IPM), palindromes are center-hereditary: shrinking a palindrome symmetrically around its center \(c\) preserves palindromicity! However, in the whole string \(S[1..N]\), a center \(c \in [l, r]\) with odd Manacher radius \(d_1[c]\) has its valid radius inside \(S[l..r]\) clipped by both boundaries: \[d_1^{[l, r]}(c) = \min\bigl(d_1[c],\; c - l + 1,\; r - c + 1\bigr).\] How do we maximize this 3-way minimum over \(c \in [l, r]\)? Depending on \(Q\) and memory limits, we have three increasingly powerful regimes.

1.2 Regime 1 (\(O(\log(r - l))\) Time): Single-Binary-Search + Sparse Table RMQ

Instead of running two separate binary searches for odd-length and even-length palindromes, observe that for any half-length \(k \in [1,\, \lfloor(r - l + 1)/2\rfloor]\), stripping the outermost character pair from a palindrome of length \(\ge 2k + 1\) leaves a palindrome of the same parity of length \(2k - 1\) (odd) or \(2k\) (even) at the same center. Thus the combined predicate \[\operatorname{HasPal}_{\ge 2k-1}(l, r) \iff \left(\max_{c \in [l+k-1,\, r-k+1]} d_1[c] \ge k\right) \;\lor\; \left(\max_{c \in [l+k-1,\, r-k]} d_2[c] \ge k\right)\] is strictly monotone in \(k\)! A single binary search on \(k\) using two \(O(1)\) Sparse Table RMQ lookups finds the optimal half-length \(k^*\) in \(O(\log(r - l))\) time, returning \(2k^*\) if the even RMQ at \(k^*\) is \(\ge k^*\) and \(2k^* - 1\) otherwise.

1.3 Regime 2 (\(O(\log N)\) Time, \(O(N)\) Space): Closed-Form slink Ceiling Division

What if we need the longest palindromic suffix \(P_R\) (or prefix \(P_L\)) of \(S[l..r]\)—i.e., the highest failure ancestor \(u\) of \(u_0 = \text{pos}[r]\) in \(\operatorname{PAM}(S)\) with \(\operatorname{len}[u] \le L_{\text{cap}} := r - l + 1\)—without spending \(O(N \log N)\) memory on a binary-lifting table? Walk \(u \gets \operatorname{slink}[u]\) while \(\operatorname{len}[\operatorname{slink}[u]] > L_{\text{cap}}\) (at most \(\lceil \log_2 N \rceil\) hops). If \(\operatorname{len}[u] > L_{\text{cap}}\), the target ancestor lies inside \(u\)’s arithmetic progression of step \(d = \operatorname{diff}[u]\), so its exact length is given in \(O(1)\) closed form by ceiling division: \[\boxed{\bigl|P_R(l, r)\bigr| = \operatorname{len}[u] - \left\lceil \frac{\operatorname{len}[u] - (r - l + 1)}{\operatorname{diff}[u]} \right\rceil \cdot \operatorname{diff}[u].}\]

1.4 Regime 3 (True Worst-Case \(O(1)\) Online Time): The Two-Boundary Unclipping Theorem

Can we eliminate the \(O(\log N)\) binary search and slink walk entirely to answer Range LPS in true \(O(1)\) worst-case time per query after \(O(N \log N)\) preprocessing?

Insert # between characters of \(S[1..N]\) to form the \((2N - 1)\)-center Manacher coordinate system \(T[1 .. 2N - 1]\), where original character \(S[i]\) sits at odd coordinate \(2i - 1\) (\(1 \le i \le N\)) and the even gap between \(S[i]\) and \(S[i+1]\) sits at even coordinate \(2i\). For each center \(c \in [1 .. 2N - 1]\), let \(\operatorname{len}_{\text{man}}[c] = \operatorname{rad}_{\text{man}}[c] - 1\) be the exact length in \(S\) of the maximal palindrome centered at \(c\) (so \(\operatorname{len}_{\text{man}}[2i - 1] = 2 d_1[i] - 1\) and \(\operatorname{len}_{\text{man}}[2i] = 2 d_2[i]\)). Whenever \(\operatorname{len}_{\text{man}}[c] > 0\), this maximal palindrome spans the closed Manacher coordinate interval \[\bigl[L_{\text{man}}[c],\; R_{\text{man}}[c]\bigr] = \bigl[c - \operatorname{len}_{\text{man}}[c] + 1,\; c + \operatorname{len}_{\text{man}}[c] - 1\bigr].\] Notice that a palindrome centered at \(c\) of length \(\ell > 0\) (with \(\ell \equiv c \pmod 2\)) covers original substring \(S[i..j]\) iff its Manacher interval is \([2i - 1,\, 2j - 1]\).

Now precompute two linear arrays over \([1 .. 2N - 1]\) in \(O(N)\) time:

  • \(\operatorname{rightmost\_reach}[x] = \max\bigl(\{x\} \cup \{c \ge x : \operatorname{len}_{\text{man}}[c] > 0 \text{ and } L_{\text{man}}[c] \le x\}\bigr)\) (the furthest center \(\ge x\) whose palindrome reaches left to or past \(x\));
  • \(\operatorname{leftmost\_reach}[y] = \min\bigl(\{y\} \cup \{c \le y : \operatorname{len}_{\text{man}}[c] > 0 \text{ and } R_{\text{man}}[c] \ge y\}\bigr)\) (the earliest center \(\le y\) whose palindrome reaches right to or past \(y\)).
ImportantTheorem 17.1 (True \(O(1)\) Online Range LPS via Two-Boundary Unclipping)

For any query substring \(S[l..r]\), let \(x_L = 2l - 1\) and \(x_R = 2r - 1\) be its boundary coordinates in \(T[1 .. 2N - 1]\), and look up in \(O(1)\) time: \[c_L = \min\bigl(x_R,\; \operatorname{rightmost\_reach}[x_L]\bigr), \qquad c_R = \max\bigl(x_L,\; \operatorname{leftmost\_reach}[x_R]\bigr).\]

  1. Boundary Prefix & Suffix Identification: \(c_L\) is the exact center of the longest palindromic prefix \(P_L\) of \(S[l..r]\), with length \(|P_L| = c_L - x_L + 1\); and \(c_R\) is the exact center of the longest palindromic suffix \(P_R\) of \(S[l..r]\), with length \(|P_R| = x_R - c_R + 1\).
  2. 100% Unclipped Interior: If \(c_L < c_R\), then for every center \(c\) strictly between \(c_L\) and \(c_R\) (\(c_L < c < c_R\)), its whole-string palindrome in \(S[1..N]\) satisfies \(L_{\text{man}}[c] > x_L\) and \(R_{\text{man}}[c] < x_R\)—it is 100% unclipped by \([l, r]\)! Conversely, every center \(c \le c_L\) has clipped length \(\le c - x_L + 1 \le |P_L|\), and every center \(c \ge c_R\) has clipped length \(\le x_R - c + 1 \le |P_R|\).
  3. True \(O(1)\) Master Formula: \[\boxed{\operatorname{LPS}(l, r) = \max\!\left(\;c_L - (2l - 1) + 1,\;\; (2r - 1) - c_R + 1,\;\; \max_{c \in (c_L,\, c_R)} \operatorname{len}_{\text{man}}[c]\;\right)}\] where the third term is evaluated in \(O(1)\) time by a single Sparse Table RMQ over \((c_L, c_R)\) (and is \(0\) when \(c_L + 1 > c_R - 1\)).

Proof of Theorem 17.1

A palindrome centered at \(c \in [x_L, x_R]\) forms a palindromic prefix of \(S[l..r]\) (clipped at \(x_L\)) iff its whole-string palindrome reaches \(x_L\) (\(L_{\text{man}}[c] \le x_L\)) and its clipped right endpoint \(2c - x_L \le x_R \iff c \le (x_L + x_R)/2\). Note that if \(\operatorname{rightmost\_reach}[x_L]\) exceeds \((x_L + x_R)/2\), then capping at \(c_L\) or noticing that \(c_L \ge c_R\) already yields \(\max(|P_L|, |P_R|)\) covering the midpoint. When \(c_L < c_R\), for any \(c \in (c_L, c_R)\), since \(c > c_L = \operatorname{rightmost\_reach}[x_L]\), we have \(L_{\text{man}}[c] > x_L\) (it does not touch the left boundary \(l\)); since \(c < c_R = \operatorname{leftmost\_reach}[x_R]\), we have \(R_{\text{man}}[c] < x_R\) (it does not touch the right boundary \(r\)). Thus \(\operatorname{len}_{\text{man}}[c]\) lies strictly inside \(S[l..r]\) without clipping! Finally, any \(c \le c_L\) clipped at \(x_L\) has length at most \(c - x_L + 1 \le c_L - x_L + 1 = |P_L|\), and any \(c \ge c_R\) clipped at \(x_R\) has length at most \(x_R - c + 1 \le x_R - c_R + 1 = |P_R|\). \(\blacksquare\)

How to Precompute rightmost_reach and leftmost_reach in \(O(N)\) Time: Initialize rightmost_reach[x] = x and leftmost_reach[x] = x for \(x = 1 \dots 2N - 1\). For each center \(c = 1 \dots 2N - 1\) with \(\operatorname{len}_{\text{man}}[c] > 0\), set rightmost_reach[L_man[c]] = max(rightmost_reach[L_man[c]], c) and leftmost_reach[R_man[c]] = min(leftmost_reach[R_man[c]], c). Then sweep \(x = 2 \dots 2N - 1\): because any palindrome reaching \(x - 1\) from a center \(c \ge x\) also reaches \(x\), set rightmost_reach[x] = max(rightmost_reach[x], rightmost_reach[x - 1])! Symmetrically, sweep \(y = 2N - 2\) down to \(1\) with leftmost_reach[y] = min(leftmost_reach[y], leftmost_reach[y + 1]).

2. Core Combinatorial Word Invariants: Midpoint Decoupling for Range Palindrome Multiplicity (T-3A-03)

Suppose a query \([l, r]\) asks for the total number of palindromic substrings (with multiplicity) inside \(S[l..r]\): \[\operatorname{TotalPal}(l, r) = \sum_{c=l}^r \min\bigl(d_1[c],\, c - l + 1,\, r - c + 1\bigr) + \sum_{c=l}^{r-1} \min\bigl(d_2[c],\, c - l + 1,\, r - c\bigr).\] To eliminate the 3-way minimum, we decouple the left boundary \(l\) from the right boundary \(r\) at the exact parity-specific midpoints:

NoteTheorem 17.2 (The Midpoint Decoupling Identity for Odd and Even Centers)

For any interval \([l, r]\), define the odd midpoint \(m_{\text{odd}} = \bigl\lfloor \frac{l + r}{2} \bigr\rfloor\) and the even midpoint \(m_{\text{even}} = \bigl\lfloor \frac{l + r - 1}{2} \bigr\rfloor\):

  1. Odd Centers (\(c \in [l, r]\)): Since \(c - l + 1 \le r - c + 1 \iff 2c \le l + r \iff c \le m_{\text{odd}}\), \[\operatorname{OddPal}(l, r) = \sum_{c=l}^{m_{\text{odd}}} \min\bigl(d_1[c],\, c - l + 1\bigr) + \sum_{c=m_{\text{odd}}+1}^{r} \min\bigl(d_1[c],\, r - c + 1\bigr).\]

  2. Even Centers (\(c \in [l, r - 1]\), centered between \(c\) and \(c + 1\)): Since \(c - l + 1 \le r - c \iff 2c \le l + r - 1 \iff c \le m_{\text{even}}\), \[\operatorname{EvenPal}(l, r) = \sum_{c=l}^{m_{\text{even}}} \min\bigl(d_2[c],\, c - l + 1\bigr) + \sum_{c=m_{\text{even}}+1}^{r-1} \min\bigl(d_2[c],\, r - c\bigr).\]

On the left half \(c \in [l, m_{\text{odd}}]\), \(\min(d_1[c], c - l + 1)\) equals \(d_1[c]\) when \(L_1(c) := c - d_1[c] + 1 \ge l\), and equals \(c - (l - 1)\) when \(L_1(c) < l\). Maintaining a Persistent Segment Tree (Chairman Tree) (or 3 offline Fenwick Trees) over \(L_1(c)\) and \(R_1(c)\) storing \(\sum d_1[c]\), \(\sum c\), and \(\sum 1\) answers every query in \(O(\log N)\) time! (Bonus \(O(1)\) Query Alternative): Using \(c_L\) and \(c_R\) from Theorem 17.1, all centers \(c \in (c_L, c_R)\) are unclipped (summed via static prefix sums of \(\operatorname{len}_{\text{man}}[c]\) in \(O(1)\)), while centers in \([x_L, c_L]\) and \([c_R, x_R]\) are palindromic prefixes/suffixes of \(P_L\) and \(P_R\)!

WarningBroken-Invariant Counterexample: The Even-Center Midpoint Bug (S = aaaa, [1, 3])

Never use \(m_{\text{odd}} = \lfloor(l + r)/2\rfloor\) as the split point for even centers \(d_2[c]\)! Take \(S = \texttt{aaaa}\) and query \([l, r] = [1, 3]\) (\(S[1..3] = \texttt{aaa}\)):

  • Here \(m_{\text{odd}} = \lfloor(1 + 3)/2\rfloor = 2\), while \(m_{\text{even}} = \lfloor(1 + 3 - 1)/2\rfloor = 1\).
  • At even center \(c = 2\) (between \(S[2]\) and \(S[3]\)), the whole-string even radius is \(d_2[2] = 2\) (\(S[1..4] = \texttt{aaaa}\)). Inside \([1, 3]\), its true clipped radius is \(\min(d_2[2], 2 - 1 + 1, 3 - 2) = \min(2, 2, 1) = 1\).
  • If you wrongly put \(c = 2\) into the left sum \([1, m_{\text{odd}}] = [1, 2]\), you evaluate \(\min(d_2[2], 2 - 1 + 1) = \min(2, 2) = 2\), overcounting by \(+1\) because \(c = 2\) is closer to \(r = 3\) than to \(l = 1\)!

3. Range Distinct Palindromes via PAM slink Telescoping ([徐毅 2014], LOJ #6071, T-3A-04)

3.1 Concrete Objects & The Right-Endpoint Sweep Strategy

Given \(S[1..N]\) and \(Q\) queries \([l, r]\), we want to count the number of distinct non-empty palindromic substrings inside \(S[l..r]\). Following the standard distinct-element sweep (Chapter 11), as we sweep right endpoint \(r = 1 \dots N\), we maintain for every PAM node \(u\) (\(\operatorname{len}[u] > 0\)) the starting index \(\operatorname{start}_r(u) = \operatorname{last\_end}_r(u) - \operatorname{len}[u] + 1\) of its most recent occurrence in \(S[1..r]\), placing a \(+1\) weight at index \(\operatorname{start}_r(u)\) in a Fenwick Tree (or Persistent Segment Tree). Then a query \([l, r]\) simply sums the Fenwick Tree over \([l, r]\).

The Bottleneck: At step \(r\), every failure ancestor \(u\) of \(\text{pos}[r]\) gains a new occurrence ending at \(r\). Updating \(\Theta(N)\) ancestors on \(\texttt{a}^N\) takes \(\Theta(N^2)\) time!

3.2 The Periodic Suffix Telescoping Cancellation Miracle

Group the failure path from \(\text{pos}[r]\) to \(r_0\) into its \(\le \lceil \log_2 r \rceil\) arithmetic progressions (slink chains). Consider a single chain \(u_1 \to u_2 \to \dots \to u_k\) where \(\operatorname{diff}[u_1] = \dots = \operatorname{diff}[u_k] = d\) and \(\operatorname{fail}[u_k] = \operatorname{slink}[u_1]\), so \(\operatorname{len}[u_j] = \operatorname{len}[u_1] - (j - 1)d\) and \(\operatorname{len}[u_k] = \operatorname{len}[\operatorname{slink}[u_1]] + d\).

ImportantTheorem 17.3 (Periodic Suffix Telescoping Cancellation — [国家集训队论文 2014 — 徐毅])

At step \(r\), let \(u_1 \to u_2 \to \dots \to u_k\) be a slink chain on the failure path from \(\text{pos}[r]\) with common difference \(d = \operatorname{diff}[u_1]\).

  1. Deterministic Previous Occurrence of Non-Head Nodes: For every internal/non-head node \(u_j\) (\(2 \le j \le k\)), its most recent occurrence in \(S[1..r-1]\) before step \(r\) ended at exact right endpoint \(r - d\)!

  2. Exact Telescoping Cancellation: For every \(j \in \{2, 3, \dots, k\}\), the old starting position of \(u_j\) (ending at \(r - d\)) equals the new starting position of \(u_{j-1}\) (ending at \(r\)): \[\boxed{\operatorname{start}_{r-1}(u_j) = (r - d) - \operatorname{len}[u_j] + 1 = r - \bigl(\operatorname{len}[u_j] + d\bigr) + 1 = r - \operatorname{len}[u_{j-1}] + 1 = \operatorname{start}_r(u_{j-1})!}\] Consequently, across the entire chain \(\{u_1, \dots, u_k\}\) of \(k\) nodes, all \(k - 1\) pairs of -1 (removing \(\operatorname{start}_{r-1}(u_j)\) for \(j \ge 2\)) and +1 (adding \(\operatorname{start}_r(u_{j-1})\) for \(j \ge 2\)) cancel out completely, leaving at most 2 point updates in the Fenwick Tree:

    • One -1 update at \(\operatorname{prev\_r}(u_1) - \operatorname{len}[u_1] + 1\) (if \(\operatorname{prev\_r}(u_1) > 0\), where \(\operatorname{prev\_r}(u_1)\) is the maximum previous right endpoint in the PAM fail-subtree of \(u_1\)), and
    • One +1 update at \(\operatorname{start}_r(u_k) = r - \operatorname{len}[u_k] + 1 = r - \bigl(\operatorname{len}[\operatorname{slink}[u_1]] + \operatorname{diff}[u_1]\bigr) + 1\).
Step r, slink chain u_1 -> u_2 -> ... -> u_k (step d = diff[u_1]):

  Old starts at r - 1:   prev_start(u_1)     (r-d)-len[u_2]+1    ...    (r-d)-len[u_k]+1
   Fenwick Action:           [ -1 ]                 [ -1 ]         ...         [ -1 ]
                                                    || (CANCELS!)              || (CANCELS!)
   Fenwick Action:                                [ +1 ]         ...         [ +1 ]                 [ +1 ]
  New starts at r:                           r - len[u_1] + 1    ...   r - len[u_{k-1}] + 1   r - len[u_k] + 1

  Net Effect: ONLY (-1 at prev_start(u_1)) and (+1 at r - (len[slink[u_1]] + d) + 1)!

Proof of Theorem 17.3

Because \(u_1\) ends at \(r\) and has period \(d = \operatorname{diff}[u_1] = \operatorname{len}[u_1] - \operatorname{len}[u_2]\), \(u_2 = \operatorname{fail}[u_1]\) is the prefix of \(u_1\) of length \(\operatorname{len}[u_1] - d\), which ends at \((r - \operatorname{len}[u_1] + 1) + (\operatorname{len}[u_1] - d) - 1 = r - d\)! And since \(u_3, \dots, u_k\) are suffixes of \(u_2\), they all occur ending at \(r - d\). Could any \(u_j\) (\(j \ge 2\)) have occurred at some \(r' \in (r - d, r)\)? If \(u_j\) occurred at \(r' \in (r - d, r)\), then by periodicity of \(u_1\) (or reflection inside \(u_1\)), it would create a border of \(u_1\) strictly longer than \(u_2 = \operatorname{fail}[u_1]\), a contradiction! Thus \(\operatorname{last\_end}_{r-1}(u_j) = r - d\) for all \(2 \le j \le k\), proving the telescoping identity. \(\blacksquare\)

4. Rich Words, Even-Palindrome Greedy, 2-Palindromes & \(\theta\)-Palindromes (T-3A-05)

4.1 Droubay–Pirillo Rich Words & \(O(1)\) Range Richness via Factor Closure

By Droubay, Justin, and Pirillo (2001), every word \(W\) of length \(n\) contains at most \(n + 1\) distinct palindromic factors (including \(\varepsilon\), or \(n\) non-empty distinct palindromes), because appending \(W[r]\) creates at most one new palindrome (the longest palindromic suffix). A word \(W\) achieving this upper bound (\(n\) non-empty distinct palindromes) is called a Rich Word (富回文串 / 满回文串).

ImportantTheorem 17.4 (Glen–Justin–Widmer–Zamboni Rich Word Factor Closure & \(O(1)\) Range Test)

For any word \(W\), the following are equivalent:

  1. \(W\) is rich (contains \(|W|\) non-empty distinct palindromes).
  2. Unioccurrent LPS: For every prefix \(W[1..r]\), its longest palindromic suffix occurs uniquely in \(W[1..r]\) (i.e., creates a brand-new PAM state).
  3. Complete Return Palindromes: Every complete return word to any palindrome \(P\) in \(W\) (a factor starting and ending with \(P\) containing no internal occurrences of \(P\)) is itself a palindrome.
  4. Factor Closure: Every substring of a rich word is rich, and every superstring of a non-rich word is non-rich!

Algorithmic Consequence (\(O(N)\) Preprocessing \(\to O(1)\) Online Rich Substring Queries): By Factor Closure (4), for each right endpoint \(r \in [1..N]\) of \(S[1..N]\), there exists a unique minimum left endpoint \(L_{\text{rich}}[r] \in [1, r]\) satisfying \(L_{\text{rich}}[1] \le L_{\text{rich}}[2] \le \dots \le L_{\text{rich}}[N]\) such that: \[\boxed{S[l..r] \text{ is a Rich Word} \iff l \ge L_{\text{rich}}[r]!}\] Using the Queue PAM of Chapter 16, we advance \(r = 1 \dots N\) (push_back(S[r])) and advance \(L\) (pop_front()) while active_distinct < r - L + 1, computing all \(L_{\text{rich}}[1..N]\) in \(O(N)\) total time and answering every query \([l, r]\) in \(O(1)\) time!

(Canonical Counterexample): Every binary word of length \(\le 7\) is rich; the shortest non-rich binary word has length \(8\): \(W = \texttt{00100100}\) (where the complete return word \(\texttt{00100}\) to palindrome \(\texttt{00}\) is not a palindrome, so step \(r = 8\) has longest palindromic suffix \(\texttt{00}\) which already occurred!).

4.2 Greedy Shortest Even-Palindrome Factorization (CF 1827C) & Online 2-Palindromes

  1. Greedy Shortest Even-Palindrome Lemma (CF 1827C): A string \(W\) can be partitioned into non-empty even-length palindromes \(E_1 E_2 \cdots E_k\) if and only if \(W\) has a non-empty even-length palindromic suffix and removing its shortest non-empty even-length palindromic suffix \(E_{\min}\) leaves a string \(W \setminus E_{\min}\) that can also be partitioned into even-length palindromes! Why? If \(E_k\) is the last even palindrome in any valid partition and \(|E_k| > |E_{\min}|\), then \(E_{\min}\) is a proper suffix (and by reflection across \(E_k\)’s even center, a non-overlapping prefix!) of \(E_k\), splitting \(E_k = E_{\min} \cdot M \cdot E_{\min}\) into three even-length palindromes!

  2. The Top-2-of-Each-AP Theorem for Online Substring 2-Palindrome Cuts (S[l..r] = P_1 P_2): Suppose we want to test in \(O(\log(r - l))\) time whether \(W = S[l..r]\) can be split into two non-empty palindromes \(W = P_1 P_2\).

    • Why Naive Longest-Palindrome Greedy Fails (Counterexample: W = bababcba): In \(W = \texttt{bababcba} = \texttt{bab} + \texttt{abcba}\), the longest palindromic prefix is \(Q_1 = \texttt{babab}\) (leaving \(\texttt{cba}\), not a palindrome!). Why? Because \(Q_1 = \texttt{babab}\) over-extended by one period step \(d = 2\) into \(P_2 = \texttt{abcba}\), and its immediate failure parent \(\operatorname{fail}[Q_1] = \texttt{bab}\) is the true cut!

    • Sufficiency of the Top 2 Nodes per slink Chain: If \(W = P_1 P_2\) where \(P_1\) is not the longest palindromic prefix \(Q_1\) of \(W\), then \(P_1\) is a proper border of some palindromic prefix \(Q \sqsubseteq W\), forcing \(Q\) to have period \(d = |Q| - |P_1|\) so that \(Q \setminus P_1\) overlaps \(P_2\). By periodicity alignment (proven in Wave 3A Frontier 3A-II), testing the top 2 nodes (\(u\) and \(\operatorname{fail}[u]\)) of each of the \(O(\log|W|)\) slink chains of the longest palindromic prefix of \(W\) and longest palindromic suffix of \(W\) is 100% sufficient to find a valid 2-palindrome cut!

  3. \(\theta\)-Palindromes (POI XVII Antisymmetry): Given an involution \(\theta : \Sigma \to \Sigma\) (\(\theta(\theta(c)) = c\)), a word \(W\) is a \(\theta\)-palindrome if \(W = \theta(W^R)\). Because reflecting across a \(\theta\)-palindromic center applies \(\theta\) twice (\(\theta^2 = \operatorname{id}\)), a \(\theta\)-palindromic suffix of a \(\theta\)-palindrome reflects to an exact \(\theta\)-palindromic prefix! When \(\theta\) is fixed-point-free (e.g., \(\theta(\texttt{0}) = \texttt{1}\)), only even-length \(\theta\)-palindromes exist.

// Offline Range Distinct Palindromes in O((N + Q) log^2 N) time and O(N) space:
// 1. Build PAM(S) with fail[u], diff[u], slink[u], and Fail-Tree Euler tour [dfn[u], out[u]].
// 2. Maintain SegMax over [1 .. tot] for max right endpoint in fail-subtree, and Fenwick BIT over [1 .. N].

void sweep_range_distinct_palindromes(int N, const std::vector<Query>& queries) {
    // Process r = 1 .. N after building PAM and Euler tour [dfn, out] of fail-tree:
    for (int r = 1; r <= N; ++r) {
        for (int u = pos_at[r]; u >= 2; u = slink[u]) {
            int prev_r = seg_max.query(1, 1, tot, dfn[u], out[u]);
            if (prev_r > 0) {
                bit.add(prev_r - len[u] + 1, -1); // -1 at old start of chain head u_1
            }
            int bot_len = len[slink[u]] + diff[u]; // Length of bottom node u_k in chain
            bit.add(r - bot_len + 1, +1);          // +1 at new start of bottom node u_k
        }
        seg_max.update(1, 1, tot, dfn[pos_at[r]], r);
        for (auto& q : queries_at_r[r]) {
            ans[q.id] = bit.query(r) - bit.query(q.l - 1);
        }
    }
}

    • Part A (W3A-26): By Theorem 17.4, \(S[l..r]\) is rich iff \(|\operatorname{Pal}(S[l..r])| = r - l + 1\), which holds iff \(l \ge L_{\text{rich}}[r]\). The total number of rich substrings in \(S\) is \(\sum_{r=1}^N (r - L_{\text{rich}}[r] + 1)\).
    • Part B (W3A-19): In any split \(S[l..r] = P_1 P_2\), if \(P_1\) is not the head of a slink chain of the longest palindromic prefix \(Q_1\) of \(S[l..r]\) and not its second node \(\operatorname{fail}[u]\), then \(Q_1\) has period \(d = \operatorname{diff}[u]\) with \(\ge 2\) steps overlapping \(P_2\), which forces \(P_2\)’s extension to be captured by the top 2 nodes from the right end \(Q_2\).
  3. Algorithmic Compilation:
    • Part A runs in \(O(N)\) preprocessing and \(O(1)\) query time.
    • Part B walks \(O(\log(r - l))\) slink chains from both ends and checks whether the remaining suffix/prefix is a palindrome in \(O(1)\) via Manacher (\(\operatorname{len}_{\text{man}}[l' + r' - 1] \ge r' - l' + 1\)). Total time: \(O(\log(r - l))\) per query.
  4. Broken-Invariant Counterexample (BP-17-04): On \(W = \texttt{bababcba} = \texttt{bab} + \texttt{abcba}\), the longest palindromic prefix is \(Q_1 = \texttt{babab}\) (\(\operatorname{len}=5\), remainder \(\texttt{cba}\) non-pal), while the second node in \(Q_1\)’s slink chain is \(\operatorname{fail}[Q_1] = \texttt{bab}\) (\(\operatorname{len}=3\), remainder \(\texttt{abcba}\) pal!).

Problem 17.5 (W3A-21) — True O(1) Online Range Longest Palindromic Substring via Two-Boundary Unclipping (UOJ #103 / CTSC 2015 Upgrade)

  • Mathematical Statement: Given a string \(S[1..N]\) and \(Q\) online queries \([l, r]\), output for each query the maximum length of a palindromic substring contained inside \(S[l..r]\) in worst-case \(O(1)\) time per query.
  • Constraints: \(1 \le N \le 5 \times 10^5\), \(1 \le Q \le 2 \times 10^6\), time limit \(1.5\text{ s}\).
NoteHint 1 — Diagnostic Signal

At \(Q = 2 \times 10^6\), an \(O(\log N)\) binary search per query performs \(\approx 3.8 \times 10^7\) Sparse Table lookups and risks TLE. Apply Theorem 17.1 (§1.4, Two-Boundary Unclipping)!

NoteHint 2 — Combinatorial Word Invariant

In the \((2N - 1)\)-center Manacher array \(T[1 .. 2N - 1]\), let \(x_L = 2l - 1\), \(x_R = 2r - 1\), \(c_L = \min(x_R, \operatorname{rightmost\_reach}[x_L])\), and \(c_R = \max(x_L, \operatorname{leftmost\_reach}[x_R])\). Every center \(c \in (c_L, c_R)\) is 100% unclipped by \([l, r]\)!

NoteHint 3 — Algorithmic Assembly

Precompute \(\operatorname{len}_{\text{man}}[1 .. 2N - 1]\), \(\operatorname{rightmost\_reach}[1 .. 2N - 1]\), \(\operatorname{leftmost\_reach}[1 .. 2N - 1]\) in \(O(N)\) time, and build a Sparse Table over \(\operatorname{len}_{\text{man}}\) in \(O(N \log N)\) time. Answer each query in \(O(1)\) via \(\max(c_L - x_L + 1,\, x_R - c_R + 1,\, \operatorname{RMQ}(c_L + 1, c_R - 1))\).

TipFull Derivation & Solution (W3A-21)

  1. Diagnostic Signal: Eliminating binary search from Range LPS requires identifying the exact boundary-clipped centers in \(O(1)\) time.

  2. Combinatorial Word Invariant:

    • By Theorem 17.1, \(c_L\) is the center of the longest palindromic prefix of \(S[l..r]\) (clipped length \(c_L - x_L + 1\)), \(c_R\) is the center of the longest palindromic suffix of \(S[l..r]\) (clipped length \(x_R - c_R + 1\)), and every center \(c \in (c_L, c_R)\) lies strictly inside \(S[l..r]\) without touching \(l\) or \(r\).

  3. Algorithmic Compilation:

    int query_range_lps_O1(int l, int r) {
    int xL = 2 * l - 1, xR = 2 * r - 1;
    int cL = std::min(xR, rightmost_reach[xL]);
    int cR = std::max(xL, leftmost_reach[xR]);
    int ans = std::max(cL - xL + 1, xR - cR + 1);
    if (cL + 1 <= cR - 1) ans = std::max(ans, st_rmq(cL + 1, cR - 1));
    return ans;
}

    Preprocessing: \(O(N \log N)\); Query: strict \(O(1)\).

  4. Broken-Invariant Counterexample (BP-17-01): Querying st_rmq(cL, cR) instead of st_rmq(cL + 1, cR - 1) includes the unclipped whole-string radius of \(c_L\) and \(c_R\), which can extend outside \([l, r]\)!

Problem 17.6 (W3A-31) — LOJ #6071 / [国家集训队论文 2014 — 徐毅] Range Distinct Palindromes (BZOJ 5384)

  • Mathematical Statement: Given a string \(S[1..N]\) and \(Q\) queries \([l, r]\), output for each query the number of distinct non-empty palindromic substrings contained in \(S[l..r]\).
  • Constraints: \(1 \le N, Q \le 3 \times 10^5\), \(|\Sigma| = 26\), time limit \(2.0\text{ s}\).
NoteHint 1 — Diagnostic Signal

This is the canonical application of Theorem 17.3 (§3.2, Periodic Suffix Telescoping Cancellation).

NoteHint 2 — Combinatorial Word Invariant

Along each slink chain \(u_1 \to \dots \to u_k\) on the path from \(\text{pos}[r]\) to \(r_0\), \(\operatorname{start}_{r-1}(u_j) = (r - d) - \operatorname{len}[u_j] + 1 = r - \operatorname{len}[u_{j-1}] + 1 = \operatorname{start}_r(u_{j-1})\) for all \(2 \le j \le k\). Thus all internal nodes cancel, leaving only -1 at \(\operatorname{prev\_r}(u_1) - \operatorname{len}[u_1] + 1\) and +1 at \(r - (\operatorname{len}[\operatorname{slink}[u_1]] + \operatorname{diff}[u_1]) + 1\)!

NoteHint 3 — Algorithmic Assembly

Sort queries offline by right endpoint \(r\), and execute sweep_range_distinct_palindromes from §4.3 using an Euler-tour Segment Tree seg_max over the PAM fail tree and a 1D Fenwick Tree bit over \([1..N]\).

TipFull Derivation & Solution (W3A-31)
  1. Diagnostic Signal: Naively updating the latest start position of every failure ancestor of \(\text{pos}[r]\) takes \(\Theta(N^2)\) time on periodic strings.
  2. Combinatorial Word Invariant:
    • By Theorem 17.3, every slink chain \(u_1 \to \dots \to u_k\) collapses to at most \(2\) Fenwick Tree point updates: removing the old start position of the chain head \(u_1\) (found via the maximum right endpoint \(\operatorname{prev\_r}(u_1)\) in \(u_1\)’s fail-subtree) and inserting the new start position of the chain bottom \(u_k\) (whose length is \(\operatorname{len}[\operatorname{slink}[u_1]] + \operatorname{diff}[u_1]\)).
  3. Algorithmic Compilation:
    • Deploy sweep_range_distinct_palindromes (§4.3). At each \(r \in [1..N]\), there are \(\le \lceil \log_2 r \rceil\) chains, each making \(1\) Segment Tree query (\(O(\log N)\)) and \(\le 2\) Fenwick updates (\(O(\log N)\)), followed by \(1\) Segment Tree point update at \(\operatorname{dfn}[\text{pos}[r]]\). Total time: \(O(N \log^2 N + Q \log N)\), space: \(O(N + Q)\).
  4. Broken-Invariant Counterexample (BP-17-03): On \(S = \texttt{abacaba}\), palindrome \(\texttt{a}\) (\(u_1\)) occurs at \(r = 3\) as a proper border of \(\texttt{aba}\) without \(\text{pos}[3]\) being \(u_1\) itself. Querying seg_max.query(dfn[u_1], out[u_1]) finds \(r = 3\), whereas a scalar last_at_node[u_1] would read \(1\) and corrupt the Fenwick tree!

Problem 17.7 (W3A-33) — Unique Palindromic Factorization Existence, Counting & Minimum Palindromic Length

  • Mathematical Statement: Given \(S[1..N]\), compute for every prefix \(S[1..r]\) (\(1 \le r \le N\)):
    1. Its Minimum Palindromic Length \(\operatorname{PL}(S[1..r])\) (the minimum number of palindromes in a factorization \(S[1..r] = P_1 \cdots P_k\));
    2. Whether this minimum-piece palindromic factorization is unique (and the number of such minimal factorizations modulo \(10^9 + 7\));
    3. The minimum number of pieces in a palindromic factorization using an even number of pieces vs. an odd number of pieces.
  • Constraints: \(1 \le N \le 5 \times 10^5\), time limit \(2.0\text{ s}\).
NoteHint 1 — Diagnostic Signal

Unlike Problem 17.2 (CF 1827C, where only even-length palindromes were allowed), here both odd-length and even-length palindromes are allowed, so greedy fails ("abacaba" has length 1, while greedy shortest takes 7).

NoteHint 2 — Combinatorial Word Invariant

Recall the Series-Link (slink) Shift-Overlap Identity from Chapter 04: \[\mathcal{I}(u, r) = \mathcal{I}(\operatorname{fail}[u],\, r - d) \;\sqcup\; \bigl\{\,r - \operatorname{len}[\operatorname{slink}[u]] - d\,\bigr\}.\] This identity holds over any commutative semiring!

NoteHint 3 — Algorithmic Assembly

Define a semiring state Val = {min_len, ways_mod} (where combine(A, B) keeps the smaller min_len and sums ways_mod on ties), and for Question 3 store a 2-tuple (Val even_pieces, Val odd_pieces). Crucially, store raw prefix DP states inside g[u], and only add +1 (and swap even/odd parity) when folding g[u] into dp[r]!

TipFull Derivation & Solution (W3A-33)
  1. Diagnostic Signal: All-palindrome partition DP requires optimizing over all palindromic suffixes of \(S[1..r]\) in \(O(\log r)\) time per step.
  2. Combinatorial Word Invariant:

    • By Chapter 04, for each slink chain head \(u\) at step \(r\), g[u] aggregates the raw DP states dp[l] over all left endpoints \(l = r - \operatorname{len}[v]\) in the chain \((\operatorname{slink}[u], u]\) via: \[g[u] \gets \operatorname{dp}\bigl[r - \operatorname{len}[\operatorname{slink}[u]] - \operatorname{diff}[u]\bigr] \;\oplus\; \bigl(\operatorname{diff}[u] == \operatorname{diff}[\operatorname{fail}[u]] \ ? \ g[\operatorname{fail}[u]] : \mathbb{0}\bigr).\]

    • Here \(\oplus\) is the \((\min, +)\) semiring operation on pairs (cost, count).

  3. Algorithmic Compilation:
    • Maintain dp[0..N] and g[0..tot], where each entry holds pair<Node, Node> for (even_pieces, odd_pieces).
    • At step \(r\), loop u = pos[r] via u = slink[u]: update g[u], then fold {g[u].odd + 1, g[u].even + 1} into dp[r]. Time: \(O(N \log N)\), space: \(O(N)\).
  4. Broken-Invariant Counterexample: Never add +1 before storing into g[u]—if you do, g[fail[u]] will add +1 a second time when reused at step \(r\)!

Tier 4 — Mastery (W3A-32, W3A-38)

Problem 17.8 (W3A-32) — Weighted & Length-Sum Range Distinct Palindromes via PAM slink Difference Progression & LCT access

  • Mathematical Statement: Given \(S[1..N]\) where each distinct palindrome \(P\) carries weight \(w(P) = |P|^K\) (for \(K \in \{1, 2\}\)) or an arbitrary user-assigned weight \(w(u)\) on its PAM node \(u\), answer \(Q\) queries \([l, r]\) asking for the sum of weights \(\sum_{P \in \operatorname{Pal}(S[l..r])} w(P)\) over all distinct palindromic substrings \(P\) occurring inside \(S[l..r]\).
  • Constraints: \(1 \le N, Q \le 10^5\), time limit \(2.5\text{ s}\).
NoteHint 1 — Diagnostic Signal

When \(w(u_j) \ne w(u_{j-1})\), the +w(u_{j-1}) and -w(u_j) updates at the overlapping start position \(\operatorname{start}_{r-1}(u_j) = \operatorname{start}_r(u_{j-1})\) in Theorem 17.3 no longer cancel to zero! What is their net remainder?

NoteHint 2 — Combinatorial Word Invariant

Look at the two regimes in §3.3:

  1. When \(w(u) = \operatorname{len}[u]\): For every \(2 \le j \le k\) in a slink chain of step \(d = \operatorname{diff}[u_1]\), the net change at position \(p_j = r - \operatorname{len}[u_{j-1}] + 1\) is \[w(u_{j-1}) - w(u_j) = \operatorname{len}[u_{j-1}] - \operatorname{len}[u_j] = d!\] That is a constant \(+d\) added along an arithmetic progression of starting indices with step \(d\)!

  2. When \(w(u)\) is arbitrary: On the PAM fail tree, running Link-Cut Tree access(pos[r]) (Chapter 11) partitions the path to the root into \(O(\log N)\) solid chains where every node in a solid chain shares the exact same previous right endpoint \(r_{\text{old}}\)!

NoteHint 3 — Algorithmic Assembly

For arbitrary weights \(w(u)\), maintain an LCT over the PAM fail tree storing for each solid splay tree the sum of weights \(W_{\text{sub}}\) on the chain (or for \(w(u) = \operatorname{len}[u]\) where start positions \(r_{\text{old}} - \operatorname{len}[u] + 1\) are non-contiguous, combine slink arithmetic progressions with LCT access: inside the intersection of a solid LCT chain and a slink chain, all nodes share both \(r_{\text{old}}\) AND step \(d\), so Theorem 17.3’s telescoping applies!).

TipFull Derivation & Solution (W3A-32)
  1. Diagnostic Signal: Distinct palindrome weighting breaks 0-sum cancellation at intermediate slink nodes unless the weight difference \(w(u_{j-1}) - w(u_j)\) is structured.
  2. Combinatorial Word Invariant:
    • By Theorem 17.3, across a slink chain \(u_1 \to \dots \to u_k\) of step \(d = \operatorname{diff}[u_1]\) at right endpoint \(r\), the net point updates to the start-index array \(A[1..N]\) are:
      • \(A\bigl[\operatorname{prev\_r}(u_1) - \operatorname{len}[u_1] + 1\bigr] \mathrel{-}= w(u_1)\),
      • \(A\bigl[r - \operatorname{len}[u_k] + 1\bigr] \mathrel{+}= w(u_k)\), and
      • For \(k \ge 2\), at every index \(x_j = r - \operatorname{len}[u_j] + 1\) for \(1 \le j \le k - 1\) (an arithmetic progression of indices with step \(d\) and residue \((r - \operatorname{len}[u_1] + 1) \bmod d\)), \(A[x_j] \mathrel{+}= w(u_j) - w(u_{j+1})\)!
    • When \(w(u) = \operatorname{len}[u]\), \(w(u_j) - w(u_{j+1}) = d\). Moreover, a range sum query \(\sum_{x=l}^r A[x]\) after an AP addition \(+d\) on \(\{a, a + d, \dots, b\}\) simply counts how many terms of the AP fall in \([l, r]\)—which is a linear function of \(l\) when tracked on a Segment Tree over endpoints!
    • Specifically, why did slink telescoping (Theorem 17.3) only leave +1 at the bottom node \(u_k\) at \(r\) and -1 at the top node \(u_1\) at \(\operatorname{prev\_r}(u_1)\) in the unweighted case? Because at step \(r\), \(u_1, \dots, u_{k-1}\) were shifted from \(r - d\) to \(r\)!
    • When \(w(u) = \operatorname{len}[u]\), storing at each palindrome’s latest start position \(s_u = \operatorname{last\_end}(u) - \operatorname{len}[u] + 1\) its weight \(\operatorname{len}[u]\) shifts \(u_j\) (\(2 \le j \le k\)) from \(r - d\) to \(r\), moving weight \(\operatorname{len}[u_j]\) from \((r - d) - \operatorname{len}[u_j] + 1 = r - \operatorname{len}[u_{j-1}] + 1\) to \(r - \operatorname{len}[u_j] + 1\), which increases each of the \(k - 1\) positions \(r - \operatorname{len}[u_1] + 1, \dots, r - \operatorname{len}[u_{k-1}] + 1\) by \(+d\).
    • For general weights \(w(u)\), running LCT access(pos[r]) on the PAM fail tree decomposes the path to the root into \(O(\log N)\) solid splay trees where every node shares a uniform previous right endpoint \(r_{\text{old}}\), and since every splay tree decomposes into \(O(\log N)\) slink chains, we maintain the exact weights in \(O((N + Q)\log^2 N)\) time!
  3. Algorithmic Compilation:
    • For \(w(u) = 1\) or polynomial \(w(u) = \operatorname{len}[u]^K\), use sweep_range_distinct_palindromes (§4.3) or LCT access on the PAM fail tree. Time: \(O((N + Q)\log^2 N)\).
  4. Broken-Invariant Counterexample: Do not assume that solid chains in LCT on the PAM fail tree map to contiguous intervals of start positions \(r_{\text{old}} - \operatorname{len}[u] + 1\)—unlike SAM (where a state covers all lengths in \([\operatorname{len}[\operatorname{link}[u]] + 1, \operatorname{len}[u]]\)), PAM states have discrete lengths separated by \(\operatorname{diff}[u]\)! Always use slink telescoping to bridge the gaps.

Problem 17.9 (W3A-38) — Online Encrypted Range Distinct Palindromes with Persistent Segment Tree & slink Jumps

  • Mathematical Statement: Given a string \(S[1..N]\), answer \(Q\) strictly online (encrypted) queries \((l_i \oplus \text{last\_ans},\, r_i \oplus \text{last\_ans})\) asking for the number of distinct non-empty palindromic substrings in \(S[l..r]\).
  • Constraints: \(1 \le N, Q \le 2 \times 10^5\), \(|\Sigma| = 26\), memory limit \(512\text{ MB}\), time limit \(2.5\text{ s}\).
NoteHint 1 — Diagnostic Signal

Because queries are encrypted online, we cannot answer them during the offline \(r = 1 \dots N\) Fenwick sweep of Problem 17.6 (LOJ #6071). How many point updates does step \(r\) of Theorem 17.3 perform?

NoteHint 2 — Combinatorial Word Invariant

By Theorem 17.3, step \(r\) performs at most \(2 \lceil \log_2 r \rceil\) point updates (one -1 and one +1 per slink chain)! Across all \(r = 1 \dots N\), the total number of point updates is bounded by \(2 N \log_2 N\) (and in practice \(\le 3N\))!

NoteHint 3 — Algorithmic Assembly

Replace the Fenwick Tree bit in sweep_range_distinct_palindromes (§4.3) with a Persistent Segment Tree (root[1..N])! During preprocessing \(r = 1 \dots N\), apply the -1 and +1 point updates to create version root[r], then answer each online query \((l, r)\) in \(O(\log N)\) time by querying the suffix sum [l, r] in root[r]!

TipFull Derivation & Solution (W3A-38)
  1. Diagnostic Signal: Online queries \([l, r]\) require random access to the state of the sweep at any historical right endpoint \(r \in [1..N]\).
  2. Combinatorial Word Invariant:
    • Because Theorem 17.3 collapses each slink chain update to at most 2 point updates, the total number of point modifications across the entire sweep \(r = 1 \dots N\) is \(U \le 2 N \log_2 N\).
    • Persisting a Segment Tree over \([1..N]\) across \(U\) point updates allocates at most \(U \lceil \log_2 N \rceil = O(N \log^2 N)\) nodes (and if nodes created during the same step \(r\) are modified in-place when node_id > prev_tot, memory drops by another \(2\times\)!).
  3. Algorithmic Compilation:
    • Preprocessing (\(r = 1 \dots N\)):
      • Set root[r] = root[r - 1] and prev_tot = pst_tot.
      • For u = pos[r]; u >= 2; u = slink[u]:
        • Query prev_r = seg_max.query(1, 1, tot, dfn[u], out[u]).
        • If prev_r > 0, root[r] = pst_add(root[r], 1, N, prev_r - len[u] + 1, -1, prev_tot).
        • root[r] = pst_add(root[r], 1, N, r - (len[slink[u]] + diff[u]) + 1, +1, prev_tot).
      • Update seg_max.update(1, 1, tot, dfn[pos[r]], r).
    • Online Query \((l, r)\): Return pst_query(root[r], 1, N, l, r) in \(O(\log N)\) time!
    • Complexity: \(O(N \log^2 N)\) preprocessing time and space, \(O(\log N)\) worst-case time per online query.
  4. Broken-Invariant Counterexample: Using in-place mutation if (u > prev_tot) inside pst_add is 100% safe because root[r] is only queried after all slink chains for step \(r\) have finished updating root[r], and saves \(> 50\%\) of persistent segment tree nodes!
