Blind Checkpoint VII — Word Equations, Inverse Strings, Wheeler/RLBWT, Tree Strings, SL2(Fp) & Morphic Words

Part VII Blind Diagnostic Assessment (Chapters 26–30 · Decoy Elimination & Untagged Contest Triage)

In Parts I through VI, our primary objects were linear strings analyzed through periodicity, Lyndon factorizations, suffix automata, palindromic trees, convolutions, or subsequence matrices. In Part VII (Ch 26–Ch 30), problems step beyond a single flat string: they present systems of word equations and lexicographical inequalities, Eulerian and Wheeler automaton graphs, tree-path strings and stack-cancellation groups, or infinite Sturmian, Thue–Morse, and morphic words at lengths up to \(N \le 10^{18}\).

In a live contest, these problems arrive completely untagged and are notorious for deceptive surface lookalikes. This final checkpoint tests blind diagnostic recognition across all five chapters of Part VII (Ch 26–Ch 30). None of the visible problem statements in Section 2 reveal which chapter or technique applies.

Problem CP-VII-01 — Symmetric Mirror Constraint Codes

A communication protocol transmits an unknown string \(S[1..N]\) of length \(N\) over an alphabet of size \(\sigma\), where \(1 \le N \le 2 \times 10^5\) and \(1 \le \sigma \le 10^9\). Before transmission, the protocol enforces \(M\) structural constraints (\(1 \le M \le 2 \times 10^5\)), each of one of two types:

  • 1 l1 r1 l2 r2 (\(r_1 - l_1 = r_2 - l_2\)): The substring \(S[l_1..r_1]\) must be identical to \(S[l_2..r_2]\) (\(S[l_1 + t] = S[l_2 + t]\) for all \(0 \le t \le r_1 - l_1\)).
  • 2 l1 r1 l2 r2 (\(r_1 - l_1 = r_2 - l_2\)): The substring \(S[l_1..r_1]\) must be the exact reversal of \(S[l_2..r_2]\) (\(S[l_1 + t] = S[r_2 - t]\) for all \(0 \le t \le r_1 - l_1\)).

Furthermore, \(K\) positions \(p_1, \dots, p_K \in \{1, \dots, N\}\) already have their characters fixed to known values \(c_1, \dots, c_K \in \{1, \dots, \sigma\}\). Compute the number of valid strings \(S[1..N]\) satisfying all \(M\) substring constraints and all \(K\) point assignments modulo \(10^9 + 7\) (outputting 0 if the fixed positions conflict).

  • Constraints: \(1 \le N, M \le 2 \times 10^5\), \(0 \le K \le N\), \(1 \le \sigma \le 10^9\), Time Limit \(2.0\text{ s}\), Memory Limit \(256\text{ MB}\).
NoteHint 1 — Diagnostic Signal & Decoy Elimination
  • Decoy Elimination: Do not confuse type-2 reversal constraints with stack cancellation (CP-VII-02) or PAM slink DP: here every constraint locks specific index pairs \(S[i] = S[j]\) in an unknown string of length \(N\).
  • Diagnostic Signal: Uniting \(r_1 - l_1 + 1\) character pairs one by one takes \(\Omega(NM)\) time. Because each constraint of length \(L = r_1 - l_1 + 1\) can be covered by two overlapping blocks of power-of-two length \(2^k\) (\(k = \lfloor \log_2 L \rfloor\)), we can merge intervals at layer \(k\) of a \(\lceil \log_2 N \rceil\)-layer DSU—provided we track orientation parity \(d \in \{0, 1\}\) (direct vs. reversed)!
NoteHint 2 — Combinatorial Word Invariant

In a Signed Binary-Lifting DSU where node \((k, i)\) represents the substring \(B_k(i) = S[i .. i + 2^k - 1]\):

  • A direct equality \(S[l_1..r_1] = S[l_2..r_2]\) of length \(L\) splits into \(B_k(l_1) = B_k(l_2)\) and \(B_k(r_1 - 2^k + 1) = B_k(r_2 - 2^k + 1)\) with relative orientation \(d = 0\).
  • A reversed equality \(S[l_1..r_1] = S[l_2..r_2]^R\) maps the prefix of \([l_1, r_1]\) to the reversed suffix of \([l_2, r_2]\): \(B_k(l_1) = B_k(r_2 - 2^k + 1)^R\) and \(B_k(r_1 - 2^k + 1) = B_k(l_2)^R\) with relative orientation \(d = 1\)!
  • Crucial Invariant: What happens if we unite \((x, y)\) at layer \(k\) with orientation \(d\), and find(k, x) and find(k, y) already share the same DSU root \(r\) with net relative orientation \(d_x \oplus d_y \oplus d = 1\)? Then \(B_k(r) = B_k(r)^R\): the root block itself is forced to be a self-palindrome, which must be recorded in a boolean flag is_pal[k][r] = 1!
NoteHint 3 — Algorithmic & Data-Structure Assembly
  1. Maintain parent[k][i], orientation-to-parent rel[k][i] \in \{0, 1\}, and is_pal[k][i] \in \{0, 1\} for \(0 \le k \le \lfloor \log_2 N \rfloor\) and \(1 \le i \le N - 2^k + 1\).
  2. Insert all \(M\) constraints at their respective layers \(k = \lfloor \log_2 L \rfloor\): when unite(k, x, y, d) finds rx == ry and (dx ^ dy ^ d) == 1, set is_pal[k][rx] = 1 (and when rx != ry, set is_pal[k][ry] |= is_pal[k][rx]).
  3. Push down from \(k = \lfloor \log_2 N \rfloor\) down to \(1\):
    • First, for every root \(r\) at layer \(k\) with is_pal[k][r] == 1, call unite(k - 1, r, r + (1 << (k - 1)), 1).
    • Second, for every \(i \ne r = \operatorname{find}(k, i)\) with orientation \(d = \operatorname{rel}[k][i]\):
      • If \(d == 0\): unite(k - 1, i, r, 0) and unite(k - 1, i + (1 << (k - 1)), r + (1 << (k - 1)), 0).
      • If \(d == 1\): cross-swap the two halves: unite(k - 1, i, r + (1 << (k - 1)), 1) and unite(k - 1, i + (1 << (k - 1)), r, 1).
  4. At layer \(k = 0\), check that no component contains two distinct fixed values \(c_a \ne c_b\); if \(C_{\text{free}}\) components have no fixed position, the answer is \(\sigma^{C_{\text{free}}} \bmod (10^9 + 7)\).
