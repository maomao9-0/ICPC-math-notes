Problem CP-III-01 — All-Path Substring Census on a Low-Leaf Tree

Statement: You are given an unrooted tree \(T = (V, E)\) with \(N\) vertices (\(1 \le N \le 10^5\)), where each vertex \(u \in V\) carries a character label \(c_u \in \{1, 2, \dots, |\Sigma|\}\) (\(1 \le |\Sigma| \le 10\)). It is guaranteed that the tree \(T\) has at most \(L \le 20\) leaves (vertices of degree \(1\)).

Every simple path \((u_1, u_2, \dots, u_k)\) in \(T\) spells a string \(c_{u_1} c_{u_2} \cdots c_{u_k}\) of length \(k\). Compute the total number of distinct non-empty strings that can be spelled by simple paths in \(T\).

Constraints: \(1 \le N \le 10^5\), \(1 \le |\Sigma| \le 10\), number of degree-\(1\) vertices \(L \le 20\), time limit \(1.5\text{ s}\), memory limit \(512\text{ MB}\).

NoteHint 1 — Diagnostic Signal & Decoy Elimination
  • Decoy Elimination: This is not an upward-tree suffix sorting problem (Ch 12), where paths only go toward a single fixed root, nor is it an online version-tree query problem (Ch 14). We must count distinct strings across all directed simple paths \(u \to v\) in an unrooted tree.
  • Diagnostic Signal: Look at the constraint \(L \le 20\) leaves! Any directed simple path \(u \to v\) in a tree can be extended backward from \(u\) until it starts at some leaf \(r\) of \(T\). Therefore, every simple-path string \(u \to v\) is a substring (in fact, a prefix of a root-to-node path, and conversely every substring of a leaf-rooted path is a simple path!) of the tree \(T\) when rooted at one of its \(L \le 20\) leaves!
NoteHint 2 — Combinatorial Word Invariant

Root the tree \(T\) independently at each of the \(L \le 20\) leaves \(r_1, \dots, r_L\). Every directed simple path \(u \to v\) in \(T\) can be extended backward from \(u\) to some leaf \(r_i\), making \(u \to v\) a suffix of the root-to-\(v\) path in \(T_{r_i}\). Conversely, every substring of a root-to-node path in \(T_{r_i}\) is a simple path in \(T\). Thus the set of all simple-path strings in \(T\) is identical to the set of all substrings of root-to-node paths across the \(L\) leaf-rooted trees \(T_{r_1}, \dots, T_{r_L}\)!

When inserting \(L\) trees of total vertex count \(\le L \cdot N \le 2 \times 10^6\) into a single automaton that merges shared prefixes/substrings without sentinel bloat, which Part III invariant prevents zero-length ghost states and avoids the \(\Theta(V^2)\) traversal trap?

NoteHint 3 — Algorithmic & Data-Structure Assembly
  1. Identify all leaves \(r_1, \dots, r_L\) (\(\text{deg}(r) = 1\), or \(N = 1\)).
  2. Either merge the \(L\) leaf-rooted trees into a single compressed Trie of size \(V \le L N\) and run Trie-BFS with the 3-Case extend_gsam(p, c) routine (Ch 09), OR run a BFS from each leaf \(r_i\) passing sam_node[u] = extend_gsam(sam_node[parent], c_u) along tree edges \(parent \to u\) in increasing order of depth.
  3. Once all \(L\) leaf-rooted trees are inserted into the shared automaton, every state \(u > 1\) represents \(\text{len}(u) - \text{len}(\text{link}(u))\) distinct simple-path strings. Sum \(\sum_{u > 1} (\text{len}(u) - \text{len}(\text{link}(u)))\) in \(O(L N |\Sigma|)\) time.

  • Target Chapter & Technique ID: Chapter 09 (T-2A-01: 3-Case Generalized SAM & Trie-BFS Construction).

  • Proof of Leaf-Rooted Completeness: Let \((u_1, u_2, \dots, u_k)\) be any simple path in \(T\). Extend the path backward from \(u_1\) away from \(u_2\) until it reaches a leaf \(r_i\). In the tree \(T_{r_i}\) rooted at \(r_i\), \((u_1, \dots, u_k)\) is a contiguous sub-path of the root-to-\(u_k\) path \(r_i \rightsquigarrow u_1 \to \dots \to u_k\), so its label is a suffix of the root-to-\(u_k\) string in \(T_{r_i}\). Conversely, every suffix of a root-to-\(v\) string in \(T_{r_i}\) corresponds to a simple path in \(T\). Thus the set of distinct simple-path strings in \(T\) equals the set of distinct substrings of the \(L\) leaf-rooted Tries \(T_{r_1}, \dots, T_{r_L}\).

  • Why 3-Case extend_gsam & BFS Are Mandatory (Boundary Pitfall Audit):

    1. Tree Branching (sam_node[parent]): When a tree vertex \(p\) has multiple children \(v_1, v_2\) with the same character \(c_{v_1} = c_{v_2} = c\), after processing \(v_1\), \(\delta(\text{sam\_node}[p], c)\) is already non-zero! Calling single-string extend on \(v_2\) creates a zero-length ghost clone (Counterexample 9.3 of Ch 09). The 3-case extend_gsam(sam_node[p], c) hits Case 2 (\(\text{len}(q) = \text{len}(p) + 1\)) and returns \(q\) in \(O(1)\) time (or Case 3 if a longer path from an earlier leaf already set \(\delta(p, c)\)).
    2. Defeating the \(\Theta(V^2)\) Trie-DFS Trap (Theorem 9.4): Merging the \(L\) leaf-rooted trees into a single Trie of \(V \le L N\) vertices and traversing it in BFS order processes vertices in non-decreasing depth \(\text{len}(p)\), guaranteeing \(O(V |\Sigma|) = O(L N |\Sigma|)\) total time and at most \(2 L N\) states.

  • Complexity: \(O(L N |\Sigma|)\) time and \(O(L N |\Sigma|)\) space (\(\le 4 \times 10^6\) states).

Problem CP-III-02 — Decreasing-Length Disjoint Substring Chain

Statement: You are given a string \(S[1..N]\) of lowercase English letters (\(1 \le N \le 5 \times 10^5\)). Find the maximum positive integer \(k\) such that there exist \(k\) non-overlapping substrings \(t_1, t_2, \dots, t_k\) appearing from left to right in \(S\) (\(t_i = S[l_i..r_i]\) with \(1 \le l_1 \le r_1 < l_2 \le r_2 < \dots < l_k \le r_k \le N\)) satisfying:

  1. \(|t_i| = k - i + 1\) for every \(i \in \{1, 2, \dots, k\}\) (so \(|t_1| = k, |t_2| = k-1, \dots, |t_k| = 1\));
  2. For every \(i \in \{1, 2, \dots, k-1\}\), \(t_{i+1}\) is a substring of \(t_i\).

Constraints: \(1 \le N \le 5 \times 10^5\), \(|\Sigma| = 26\), time limit \(5.0\text{ s}\), memory limit \(512\text{ MB}\).

NoteHint 1 — Diagnostic Signal & Decoy Elimination
  • Decoy Elimination: In CF 700E (Cool Slogans, Ch 10), \(s_{i-1}\) must occur twice inside \(s_i\), and substring lengths can jump by arbitrary amounts along the Link Tree. Here, \(|t_i| = k - i + 1\) decreases by exactly \(1\) at each step, and the chosen occurrences \(S[l_1..r_1], \dots, S[l_k..r_k]\) must be disjoint in position (\(r_i < l_{i+1}\)).
  • Diagnostic Signal: Since \(|t_i| = |t_{i+1}| + 1\) and \(t_{i+1}\) is a substring of \(t_i\), \(t_{i+1}\) must be either the prefix \(t_i[1..|t_i|-1]\) or the suffix \(t_i[2..|t_i|]\)! Furthermore, let \(dp[i]\) be the maximum chain length \(L\) starting with \(t_1 = S[i .. i + L - 1]\). If \(S[i .. i + L - 1]\) starts a valid chain of length \(L\), then dropping its first character \(S[i]\) leaves \(S[i + 1 .. i + L - 1]\), which still contains \(t_2\) (of length \(L - 1\), or its suffix of length \(L - 2\)) and starts a valid chain of length \(\ge L - 1\) at \(i + 1\)!
NoteHint 2 — Combinatorial Word Invariant

From the left-truncation observation above, \(dp[i]\) satisfies the 1-Lipchitz Right-to-Left Monotonicity Invariant: \[dp[i] \le dp[i + 1] + 1 \qquad \forall i \in \{1, \dots, N - 1\}.\] Consequently, if we sweep \(i\) from \(N\) down to \(1\), starting our candidate length at \(L = dp[i + 1] + 1\) and decrementing \(L\) until \(L\) is valid at \(i\):

  1. The pointer \(i + L\) (the minimum allowed starting position \(j \ge i + L\) of the non-overlapping next piece \(t_2 = S[j .. j + L - 2]\)) decreases monotonically across the entire sweep (\(O(N)\) decrements in total)!
  2. A candidate length \(L\) is valid at index \(i\) if and only if there exists \(j \ge i + L\) with \(dp[j] \ge L - 1\) such that \(S[j .. j + L - 2]\) equals either \(S[i .. i + L - 2]\) or \(S[i + 1 .. i + L - 1]\).
NoteHint 3 — Algorithmic & Data-Structure Assembly
  1. Build \(\text{SAM}(S^R)\) so that its Link Tree \(\mathcal{T}_{\text{link}}(\text{SAM}(S^R)) \cong \text{ST}(S)\) groups substrings of \(S\) by right-extension / common prefix (Ch 09 Blumer–Crochemore Duality). Compute the Euler-tour interval \([\text{dfn}[u], \text{out}[u]]\) of every state \(u\) on \(\mathcal{T}_{\text{link}}(\text{SAM}(S^R))\) (or equivalently use the Suffix Array interval on \(\text{SA}_S\)).
  2. A suffix starting at \(j\) has \(S[i .. i + L - 2]\) as a prefix of length \(L - 1\) iff the terminal state \(\text{pos}[j]\) lies in the Link-Tree subtree of the ancestor \(u_1\) of \(\text{pos}[i]\) at length \(L - 1\) (\(\text{len}(\text{link}(u_1)) < L - 1 \le \text{len}(u_1)\)). Similarly, \(S[j .. j + L - 2] = S[i + 1 .. i + L - 1]\) iff \(\text{pos}[j]\) lies in the subtree of the ancestor \(u_2\) of \(\text{pos}[i+1]\) at length \(L - 1\).
  3. Sweep \(i = N \dots 1\). Whenever \(L\) is decremented, the threshold \(j = i + L\) moves left by \(1\): insert \(dp[j]\) into a Range-Max Segment Tree at leaf \(\text{dfn}[\text{pos}[j]]\). Check \(L\) in \(O(\log N)\) time by querying whether the subtree of \(u_1\) or \(u_2\) has \(\max dp \ge L - 1\). Total time: \(O(N \log N)\).

// Assumes tag[1..n], h[1..n], min_h[1..n], ch[1..n][2] maintained in an alpha=0.75 Scapegoat BST
int query_bst_lcp(int x, int y) {
    if (!x || !y) return 0;
    if (x == y) return x;
    if (tag[x] > tag[y]) std::swap(x, y);
    int u = root;
    while (u) {
        if (tag[u] <= tag[x]) u = ch[u][1];
        else if (tag[u] > tag[y]) u = ch[u][0];
        else break; // u is the BST split node with tag[x] < tag[u] <= tag[y]
    }
    int ans = h[u];
    // Left walk from ch[u][0] to x: collect nodes strictly to the right of x
    for (int v = ch[u][0]; v; ) {
        if (tag[v] > tag[x]) {
            ans = std::min({ans, h[v], min_h[ch[v][1]]});
            v = ch[v][0];
        } else {
            v = ch[v][1];
        }
    }
    // Right walk from ch[u][1] to y: collect nodes <= y
    for (int v = ch[u][1]; v; ) {
        if (tag[v] <= tag[y]) {
            ans = std::min({ans, h[v], min_h[ch[v][0]]});
            v = ch[v][1];
        } else {
            v = ch[v][0];
        }
    }
    return ans;
}

int compute_adj_lcp(int x, int y) {
    if (!x || !y || S[x] != S[y]) return 0;
    return 1 + query_bst_lcp(x - 1, y - 1);
}
