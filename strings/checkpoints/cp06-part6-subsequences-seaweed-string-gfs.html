When solving an exercise at the end of Chapter 22 or Chapter 24, the chapter title itself hands you the governing mathematical structure before you read a single word of the problem statement. In a live contest, problems arrive completely untagged. You are presented with a story about subsequence extraction across substring intervals \([l, r]\), semi-local sequence comparison, or occurrence moments in random character streams of length \(n \le 10^{18}\), and you must determine on your own whether the transition matrix is invertible in \(O(|\Sigma|)\), requires a Segment Tree or Planar Uncrossing Permutation, or collapses via a generating-function shift.

This checkpoint tests blind diagnostic recognition across all four chapters of Part VI (Ch 22–Ch 25). None of the visible problem statements in Section 2 reveal which chapter or technique applies.

1. Blind Diagnostic Triage Guide & Decoy Elimination

Part VI contest problems frequently disguise themselves behind two classic Diagnostic Decoy Groups: (A) range subsequence queries on \(S[l..r]\) where four superficially similar recurrences require four completely different data structures, and (B) pattern-occurrence counting / expectation problems where small-\(N\) polynomial extraction, huge-\(n\) moment shifting, stopping-time martingales, and outer automaton enumeration look nearly identical at first glance.

Problem CP-VI-01 — High-Throughput Substring Subsequence Fingerprinting

You are given a string \(S[1..N]\) over the first \(\sigma\) lowercase English letters (\(1 \le \sigma \le 26\)) and \(Q\) independent range queries (\(1 \le N \le 2 \times 10^5\), \(1 \le Q \le 5 \times 10^5\)). Each query specifies a substring interval \([l, r]\) (\(1 \le l \le r \le N\)) and asks for the number of distinct non-empty subsequences of the substring \(S[l..r]\), modulo \(10^9 + 7\).

(Two subsequences drawn from different index tuples inside \([l, r]\) are considered identical if and only if they spell the exact same character string.)

  • Constraints: \(1 \le N \le 2 \times 10^5\), \(1 \le Q \le 5 \times 10^5\), \(1 \le \sigma \le 26\), Time Limit \(1.5\text{ s}\), Memory Limit \(256\text{ MB}\).
NoteHint 1 — Diagnostic Signal & Decoy Elimination
  • Decoy Elimination: With \(Q = 5 \times 10^5\) and \(\sigma = 26\), building a Segment Tree of \((\sigma + 1) \times (\sigma + 1)\) transition matrices (or running Divide-and-Conquer) requires at least \(O(Q \sigma^2 \log N) \approx 6 \times 10^9\) operations, which will TLE by a wide margin.
  • Diagnostic Signal: Write down the standard left-to-right DP state \(\mathbf{w} = (w_1, \dots, w_\sigma, w_{\sigma+1})^T\), where \(w_a\) counts distinct subsequences ending with character \(a \in \{1, \dots, \sigma\}\) and \(w_{\sigma+1} = 1\) represents the empty string \(\varepsilon\). When character \(c = S[i]\) is read, \(w'_c = \sum_{j=1}^{\sigma+1} w_j\) and \(w'_a = w_a\) (\(a \ne c\)). Because the old value \(w_c\) appears inside \(\sum_{j=1}^{\sigma+1} w_j\) with coefficient \(+1\), the transition matrix \(M_c\) is an elementary row-addition matrix with determinant \(\det(M_c) = 1\)—invertible over every commutative ring!
NoteHint 2 — Combinatorial Word Invariant

Let \(P_i = M_{S[i]} M_{S[i-1]} \cdots M_{S[1]}\) (\(P_0 = I_{\sigma+1}\)). The transition matrix over \(S[l..r]\) is \(M_{S[r]} \cdots M_{S[l]} = P_r P_{l-1}^{-1}\), so the total number of distinct subsequences of \(S[l..r]\) (including \(\varepsilon\)) is a 1D bilinear dot product: \[\operatorname{Ans}(l, r) + 1 = \mathbf{1}^T \bigl(P_r P_{l-1}^{-1}\bigr) \mathbf{e}_{\sigma+1} = \underbrace{\bigl(\mathbf{1}^T P_r\bigr)}_{\mathbf{u}_r^T \in \mathcal{R}^{1 \times (\sigma+1)}} \cdot \underbrace{\bigl(P_{l-1}^{-1} \mathbf{e}_{\sigma+1}\bigr)}_{\mathbf{v}_{l-1} \in \mathcal{R}^{(\sigma+1) \times 1}} = \sum_{k=1}^{\sigma+1} u_r[k] \cdot v_{l-1}[k].\] Even better, neither \(P_i\) nor \(P_i^{-1}\) needs to be stored as a \((\sigma+1)\times(\sigma+1)\) matrix at each index \(i\):

  1. Left-multiplying \(P_{i-1}\) by \(M_c\) (\(c = S[i]\)) replaces row \(c\) of \(P_{i-1}\) (which was set at the previous occurrence \(p = \operatorname{last}[c]\) to \(\mathbf{u}_{p-1}^T\), or \(\mathbf{e}_c^T\) if \(p = 0\)) with the sum of all rows \(\mathbf{1}^T P_{i-1} = \mathbf{u}_{i-1}^T\): \[\mathbf{u}_i^T = 2 \mathbf{u}_{i-1}^T - \begin{cases} \mathbf{u}_{\operatorname{last}[c]-1}^T & \text{if } \operatorname{last}[c] \ge 1, \\ \mathbf{e}_c^T & \text{if } \operatorname{last}[c] = 0. \end{cases}\]
  2. Right-multiplying \(P_{i-1}^{-1}\) by \(M_c^{-1} = I_{\sigma+1} - \mathbf{e}_c \sum_{k \ne c} \mathbf{e}_k^T\) leaves column \(c\) of \(P_{i-1}^{-1}\) unchanged and subtracts column \(c\) from every other column \(k \ne c\) (including column \(\sigma + 1\)).
NoteHint 3 — Algorithmic & Data-Structure Assembly
  1. Maintain the columns of \(P_i^{-1}\) lazily as \(\mathbf{c}_k = \tilde{\mathbf{c}}_k + \mathbf{g}\), where \(\mathbf{g} \in \mathcal{R}^{\sigma+1}\) is a global offset vector (initially \(\mathbf{g} = \mathbf{0}\) and \(\tilde{\mathbf{c}}_k = \mathbf{e}_k\)).
  2. At step \(i = 1, \dots, N\) with \(c = S[i]\):
    • Compute \(\mathbf{u}_i^T\) in \(O(\sigma)\) time using the two-term recurrence above, then set \(\operatorname{last}[c] = i\).
    • Read column \(c\) of \(P_{i-1}^{-1}\) as \(\mathbf{w} = \tilde{\mathbf{c}}_c + \mathbf{g}\); subtract \(\mathbf{w}\) from all columns via \(\mathbf{g} \leftarrow \mathbf{g} - \mathbf{w}\) and restore column \(c\) via \(\tilde{\mathbf{c}}_c \leftarrow \tilde{\mathbf{c}}_c + \mathbf{w}\).
    • Record \(\mathbf{v}_i = \mathbf{c}_{\sigma+1}^{(i)} = \mathbf{e}_{\sigma+1} + \mathbf{g}\) in \(O(\sigma)\) time.
  3. Answer each query \([l, r]\) in \(O(\sigma)\) time by computing \(\bigl(\sum_{k=1}^{\sigma+1} u_r[k] v_{l-1}[k] - 1\bigr) \bmod (10^9 + 7)\).

Adding the new row \(c\) and subtracting the old row \(c\) yields \(\mathbf{u}_i^T = \mathbf{u}_{i-1}^T + \mathbf{u}_{i-1}^T - \text{old\_row}_c = 2\mathbf{u}_{i-1}^T - \text{old\_row}_c\).

Failing to subtract \(\mathbf{e}_c^T\) when \(\operatorname{last}[c] = 0\) corrupts column \(c\) of \(\mathbf{u}_i^T\) for the entire remainder of the string.

int u[N + 1][27], v[N + 1][27], c_tilde[27][27], g[27], last_pos[27];
for (int k = 0; k <= 26; ++k) {
    u[0][k] = 1;
    v[0][k] = (k == 26 ? 1 : 0);
    c_tilde[k][k] = 1;
}
for (int i = 1; i <= n; ++i) {
    int c = S[i - 1] - 'a';
    int p = last_pos[c];

        int old_row = (p == 0) ? (k == c ? 1 : 0) : u[p - 1][k];
        u[i][k] = (2LL * u[i - 1][k] - old_row + MOD) % MOD;

    last_pos[c] = i;
    for (int r = 0; r <= 26; ++r) {
        int w_r = (c_tilde[c][r] + g[r]) % MOD;
        g[r] = (g[r] - w_r + MOD) % MOD;
        c_tilde[c][r] = (c_tilde[c][r] + w_r) % MOD;
        v[i][r] = (g[r] + (r == 26 ? 1 : 0)) % MOD;
    }
}

Problem CP-VI-02 — Substring Protocol Sanitization

You are given a digit string \(S[1..N] \in \{\texttt{'0'}, \dots, \texttt{'9'}\}^N\) and \(Q\) range queries (\(1 \le N, Q \le 2 \times 10^5\)). Each query specifies a substring \(S[l..r]\) (\(1 \le l \le r \le N\)) and asks for the minimum number of characters that must be deleted from \(S[l..r]\) so that the remaining string:

  1. Contains \(\texttt{"2017"}\) as a subsequence, and
  2. Does not contain \(\texttt{"2016"}\) as a subsequence.

If it is impossible to satisfy both conditions simultaneously for \(S[l..r]\), output -1.

  • Constraints: \(1 \le N, Q \le 2 \times 10^5\), Time Limit \(3.0\text{ s}\), Memory Limit \(256\text{ MB}\).
NoteHint 1 — Diagnostic Signal & Decoy Elimination
  • Decoy Elimination (CP-VI-02 vs. CP-VI-01): Just like CP-VI-01, we have a static string \(S[1..N]\) and \(Q = 2 \times 10^5\) range subsequence queries on \(S[l..r]\)! Why can’t we use prefix matrix inversion \(P_r P_{l-1}^{-1}\) here? Because the DP asks for a minimum deletion cost over the tropical semiring \((\mathbb{Z} \cup \{\infty\}, \min, +)\), and \(\min(a, b)\) has no additive inverse! Once two path costs merge via \(\min\), information about the larger branch is permanently erased.
  • Diagnostic Signal: Because prefix inversion is algebraically impossible over \((\min, +)\), we must maintain the \(5 \times 5\) tropical transition matrices in a Segment Tree over \([1, N]\).
