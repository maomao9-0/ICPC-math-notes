Instead, a grandmaster problem couples two to four distinct string-theoretic paradigms into a single unified pipeline:

  • You might enumerate the \(< 2N\) canonical square representatives of a string via Lyndon Arrays and the Bannai–Iryo–Inenaga Runs Theorem (Ch 07–Ch 08), map each square into the Suffix Automaton Link Tree, and answer range-clipped multiplicity queries via Persistent Segment Tree Merging on \(\text{endpos}\) (Ch 10).
  • You might compress the \(O(\log N)\) Significant Suffix candidates \(\text{Cand}_{\min}\) (Ch 06) across a Locally Consistent Parse Tree / Straight-Line Program (SLP) of length \(N \le 10^{18}\) (Ch 21), replacing array-based Z-function lookups with \(O(\log N)\) grammar-compressed LCE queries.
  • Or you might encode Tiskin’s Seaweed Matrix permutation via the 4-instruction Allison–Dix bit-parallel borrow identity (Ch 23) and feed it directly into the 4-Stage DP套DP Automaton Compiler with Hopcroft DFA Minimization (Ch 25).

This first capstone presents all 30 Grandmaster Synthesis Problems (Syn-01–Syn-30) synchronized with Capstone II — Master Problem Archive Guide. Every problem features a self-contained mathematical statement, exact asymptotic constraints, a 3-stage progressive hint ladder, and a Complete Multi-Chapter Derivation & Solution linking directly to its constituent chapters.

Syn-01 (W2B-36S) — CF 1043G: Speckled Band (Full 4-Engine Synthesis)

Statement. Given a string \(S[1..N]\) (\(N \le 2 \times 10^5\), \(|\Sigma| = 26\)) and \(Q \le 2 \times 10^5\) queries \((l, r)\), partition \(W = S[l..r]\) into segments \(W = w_1 w_2 \dots w_k\) such that the maximum multiplicity of any segment among \(\{w_1, \dots, w_k\}\) is minimized. Output this minimum possible maximum multiplicity for each query.

NoteHint 1 — Multi-Paradigm Diagnostic Signal

By a pigeonhole and exchange argument over the 26-letter alphabet, the answer is at most \(4\) (unless all characters in \(W\) are distinct, giving \(-1\)). Classifying whether the answer is \(1, 2, 3,\) or \(4\) requires testing four distinct periodic/border configurations inside \(W = S[l..r]\).

NoteHint 2 — Coupled Word Invariants
  • Answer \(= 1\): \(W = U^k\) (\(k \ge 2\)) is a full periodic power (Ch 01 prime-divisor LCE sieve).
  • Answer \(= 2\): Either \(W\) has a nonempty border \(U V U\) (Ch 15 dyadic IPM / \(\sqrt{N}\) border test), or \(W\) has a square prefix \(U U V\) or square suffix \(V U U\) (Ch 08 Runs boundary arrays min_sq_end[l], max_sq_start[r]).
  • Answer \(= 3\) vs. \(4\): Answer \(= 3\) iff \(W = V_1 c V_2 c V_3\) where \(c = W[1]\) or \(c = W[|W|]\), OR \(W\) contains any square \(V_1 U U V_2\) strictly inside \([l, r]\) (Ch 08 + Ch 13 RMQ over \(\min_{a \in [l, r]} R_{\text{sq}}[a] \le r\)).
NoteHint 3 — Unified Algorithmic Compilation

Precompute linear-sieve prime divisors (spf[L]) for Answer \(1\); enumerate all \(|\mathcal{R}(S)| < N\) runs via Ch 08 to populate shortest squares starting at \(i\) (sq_R[i] = i + 2p - 1) and ending at \(j\) (sq_L[j] = j - 2p + 1) via a DSU/segment tree; test substring borders via Ch 15 (\(\sqrt{N}\) SA-rank window + length check or \(O(\log N)\) dyadic IPM); and check internal squares for Answer \(3\) via Sparse Table RMQ over sq_R[l..r] <= r.

TipComplete Multi-Chapter Derivation & Solution

Constituent Chapters: Ch 01 (Fine–Wilf & Full-Period Lattice) + Ch 08 (Runs Theorem & Squares) + Ch 13 (Suffix Structures / RMQ) + Ch 15 (Internal Pattern Matching & Substring Borders).

  1. Impossibility (\(-1\)): If \(L = r - l + 1 > 26\), pigeonhole forces a duplicate letter. For \(L \le 26\), check prefix character counts; if all letters occur \(\le 1\) time, no cut can repeat a piece, so return \(-1\).
  2. Threshold 1 (Pure Power \(W = U^k, k \ge 2\)): By Ch 01, \(W\) is a power iff \(d = L/p\) is a full period of \(W\) for some prime \(p \mid L\), tested via \(\text{LCE}(l, l + L/p) \ge L - L/p\) in \(O(\omega(L))\) time.
  3. Threshold 2 (\(U V U\), \(U U V\), or \(V U U\)):
    • Using Bannai et al.’s Runs enumeration (Ch 08), each run \((l_R, r_R, p)\) covers squares of length \(2p\) starting at \(a \in [l_R, r_R - 2p + 1]\). Sorting runs by increasing \(p\) and Painting unassigned indices via DSU gives \(\text{min\_sq\_R}[a] = a + 2p_{\min}(a) - 1\) and symmetrically \(\text{min\_sq\_L}[b] = b - 2p_{\min}(b) + 1\). Then \(W = U U V \iff \text{min\_sq\_R}[l] \le r\), and \(W = V U U \iff \text{min\_sq\_L}[r] \ge l\).
    • Otherwise \(W = U V U\) iff \(\text{Border}(S[l..r]) \ne \emptyset\), tested in \(O(\log N)\) time via Ch 15’s dyadic \(P_m \cap Q_m\) IPM intersection (or \(O(\sqrt{N})\) threshold split).
  4. Threshold 3 vs. 4 (\(V_1 U U V_2\) or Boundary Letter Repeat):
    • If \(S[l]\) appears again in \(S[l+1..r]\) or \(S[r]\) appears in \(S[l..r-1]\), splitting around that single letter gives multiplicity \(\le 3\).
    • Otherwise, an internal square \(U U \subseteq S[l..r]\) exists iff \(\min_{a \in [l, r]} \text{min\_sq\_R}[a] \le r\), answered in \(O(1)\) by a Sparse Table RMQ. If neither holds, the answer is \(4\) (achieved by isolating the two occurrences of a repeated letter \(c\)).

Syn-02 (W1B-33S) — [集训队论文 2019 — 金策] Clipped Distinct Squares Weighted by Substring Occurrences

Statement. Given \(S[1..N]\) (\(N \le 10^5\)) and \(Q \le 10^5\) queries \((L_q, R_q, K)\), let \(\text{Sq}(S[L_q..R_q])\) be the set of distinct square substrings \(w^2\) occurring inside \(S[L_q..R_q]\). For each query, compute \(\sum_{w^2 \in \text{Sq}(S[L_q..R_q]), \text{occ}_{S[L_q..R_q]}(w^2) \ge K} |w|^2 \cdot \text{occ}_{S[L_q..R_q]}(w^2) \pmod{998244353}\).

NoteHint 1 — Multi-Paradigm Diagnostic Signal

A string has \(\Theta(N^2)\) square occurrences, so we cannot inspect occurrences individually. However, by the Runs & Three-Squares Theorem, \(S\) has strictly fewer than \(2N\) distinct square substrings globally, and each distinct square corresponds to a unique state locus on \(\text{SAM}(S)\).

NoteHint 2 — Coupled Word Invariants
  • From Ch 07–Ch 08, inside any run \(R = (l, r, p)\), only the first period window \(i \in [l, \min(l+p-1, r-2kp+1)]\) generates candidate new squares \(S[i..i+2kp-1]\), totaling \(\sum_R (e_R - 1) < 2N\) slices.
  • From Ch 10, the exact multiplicity of a square \(w^2\) (of length \(2L = 2kp\)) inside \(S[L_q..R_q]\) equals \(|\text{endpos}(u) \cap [L_q + 2L - 1, R_q]|\) on the persistent Segment Tree of its SAM state \(u\).
NoteHint 3 — Unified Algorithmic Compilation
