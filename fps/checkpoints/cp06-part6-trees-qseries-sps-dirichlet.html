Welcome to Checkpoint VI (CP-VI), the cumulative blind assessment for Part VI (Chapters 22–24) of the textbook.

In an actual contest or research setting, no problem statement arrives labeled “Use the Lagrange Inversion Formula” or “Apply 1D Bostan–Mori.” The true test of mastery over Part VI is blind diagnostic triage: reading a tree, permutation, schedule, bitwise-subset, or random-walk specification, spotting the structural bottleneck in the state space or convolution algebra, and selecting the right algebraic engine on your own.

Problem CP-VI.1 (#102) — Codeforces 1097G: Vladislav and a Great Legend

Problem Statement & Exact Constraints

You are given an unrooted tree \(T = (V, E)\) with \(n\) vertices labeled \(1, 2, \dots, n\) and an integer \(k\). For any non-empty subset of vertices \(X \subseteq V\) (\(X \ne \emptyset\)), let \(f(X)\) denote the number of edges in the minimal connected subgraph of \(T\) that contains all vertices in \(X\).

Compute the sum of the \(k\)-th powers of \(f(X)\) over all \(2^n - 1\) non-empty vertex subsets: \[S = \sum_{\emptyset \ne X \subseteq V} f(X)^k \pmod{10^9 + 7}.\]

  • Constraints: \(2 \le n \le 10^5\), \(1 \le k \le 200\), modulus \(P = 10^9 + 7\).
  • Target Complexity: \(O(n k)\) time and \(O(n k)\) space.

Sample Trace (\(N \le 4\))

Consider a path tree on \(n = 3\) vertices with edges \((1, 2)\) and \((2, 3)\), and exponent \(k = 2\). We inspect all \(2^3 - 1 = 7\) non-empty subsets \(X \subseteq \{1, 2, 3\}\):

  • Singletons \(\{1\}, \{2\}, \{3\}\): Each requires \(0\) edges to connect, so \(f(X) = 0\) and \(f(X)^2 = 0\).
  • Adjacent pairs \(\{1, 2\}, \{2, 3\}\): Each spans \(1\) edge, so \(f(X) = 1\) and \(f(X)^2 = 1\).
  • Endpoint pair and full set \(\{1, 3\}, \{1, 2, 3\}\): Both require both edges \((1, 2)\) and \((2, 3)\) to connect, so \(f(X) = 2\) and \(f(X)^2 = 4\).

Summing over all \(7\) subsets gives \(S = 3 \cdot 0^2 + 2 \cdot 1^2 + 2 \cdot 2^2 = 0 + 2 + 8 = 10\).

Hint 1 — Diagnostic Signal & Combinatorial Model (Spoiler-Free)

Why is \(f(X)^k\) difficult to maintain directly in a bottom-up subtree recursion? Because when an edge \(e\) is added to the minimal subgraph spanning \(X\), \((f(X) + 1)^k\) expands into all lower powers, and whether \(e\) belongs to the minimal subgraph of \(X\) depends on whether \(X\) has at least one vertex on both sides of \(e\).

Look at the small exponent bound \(k \le 200\) alongside \(n \le 10^5\). Instead of raising \(f(X)\) to the \(k\)-th power at the end, how can you rewrite \(m^k\) as a linear combination of choosing unordered subsets of \(j\) edges (\(0 \le j \le k\)) from the \(m = f(X)\) edges spanned by \(X\)?

Hint 2 — Algebraic Setup & Reverse-Engineering Scratchpad

Use the ordinary-power-to-binomial expansion via Stirling numbers of the second kind: \[f(X)^k = \sum_{j=0}^k \left\{\begin{matrix} k \\ j \end{matrix}\right\} j! \binom{f(X)}{j}.\] By swapping the order of summation, we only need to compute for each \(j \in \{0, 1, \dots, k\}\) the total count \[C_j = \sum_{\emptyset \ne X \subseteq V} \binom{f(X)}{j},\] which counts pairs \((X, F)\) where \(\emptyset \ne X \subseteq V\) is a non-empty vertex set and \(F \subseteq E\) is a set of \(j\) edges all contained inside the minimal connected subgraph spanning \(X\).

Root the tree at vertex \(1\). For a fixed pair \((X, F)\), let \(u = \operatorname{LCA}(X)\) be the lowest common ancestor of all vertices in \(X\). Then \(X\) lies entirely inside the subtree \(T_u\), and \(F\) lies inside \(E(T_u)\). To maintain this bottom-up, define the subtree polynomial \(P_u(x) = \sum_{j=0}^{\min(|E(T_u)|, k)} dp[u][j] x^j\), where \(dp[u][j]\) counts pairs \((X_u, F_u)\) with \(\emptyset \ne X_u \subseteq V(T_u)\) and \(F_u \subseteq E(T_u)\) of size \(j\) such that every edge in \(F_u\) has at least one vertex of \(X_u\) in its lower endpoint’s subtree.

Hint 3 — Coefficient Extraction & Complexity Contract

When attaching a child \(v\) to \(u\) via edge \(e = (u, v)\):

  1. If \(X \cap V(T_v) = \emptyset\), then no edge in \(T_v \cup \{e\}\) can be chosen at all (contribution \(1\)). If \(X \cap V(T_v) \ne \emptyset\), \(P_v(x)\) already counts non-empty choices inside \(T_v\), so multiplying \(P_v(x)\) by \((1 + x)\) accounts for either excluding (\(1\)) or including (\(x\)) the parent edge \(e = (u, v)\): \[Q_v(x) = P_v(x)(1 + x).\]
  2. Multiply \(1 + P_u(x)\) across all children \(v\) of \(u\), truncating to degree \(\min(\operatorname{sz}(u) - 1, k)\) at each step.
  3. Notice when a configuration is invalid at the global level: if \(X\) lies entirely inside a single child’s subtree \(T_v\) (so \(u\) is not in \(X\) and no other child of \(u\) contains a vertex of \(X\)), then edges in \(T_v \cup \{(u, v)\}\) lying above \(\operatorname{LCA}(X)\) are NOT in the minimal subgraph spanning \(X\). Specifically, any pair where \(X \subseteq V(T_v)\) and the edge \((u, v)\) is chosen above \(T_v\) is overcounted by \(Q_v(x) - P_v(x) = x P_v(x)\). Subtracting \(x P_v(x)\) from the global accumulator at each child \(v \ne 1\) and adding \(P_1(x)\) at the root eliminates all invalid upward extensions.
  4. Because each multiplication at \((u, v)\) has degrees bounded by \(\min(\operatorname{sz}_{\text{cur}}(u), k)\) and \(\min(\operatorname{sz}(v), k)\), the classical LCA pair-counting lemma bounds the total work across the entire tree by \(O(n k)\).

Problem CP-VI.2 (#121) — Codeforces 1553I: Stairs

Problem Statement & Exact Constraints

In a permutation \(p = (p_1, p_2, \dots, p_n)\) of \(\{1, 2, \dots, n\}\), a stair is a maximal contiguous subsegment \(p[l \dots r]\) (\(1 \le l \le r \le n\)) whose values are consecutive integers in either strictly increasing order (\(p_{i+1} = p_i + 1\) for all \(l \le i < r\)) or strictly decreasing order (\(p_{i+1} = p_i - 1\) for all \(l \le i < r\)). Because stairs are maximal, every index \(i \in \{1, \dots, n\}\) belongs to a unique stair; let its length be \(r - l + 1\).

You are given a target array \(a_1, a_2, \dots, a_n\). Count the number of permutations \(p\) of \(\{1, \dots, n\}\) whose stair lengths at every index \(i\) equal \(a_i\), modulo \(998244353\).

  • Constraints: \(1 \le n \le 10^5\), \(1 \le a_i \le n\), prime modulus \(P = 998244353\).
  • Target Complexity: \(O(n \log^2 n)\) time and \(O(n \log n)\) space.

Sample Trace (\(N \le 4\))

Let \(n = 3\) and \(a = (2, 2, 1)\).

  • Indices \(1\) and \(2\) must form a stair of length \(2\), and index \(3\) must form a stair of length \(1\).
  • Among all \(3! = 6\) permutations of \(\{1, 2, 3\}\):
    • \((1, 2, 3)\) and \((3, 2, 1)\) merge both segments into a single stair of length \(3\), giving stair lengths \((3, 3, 3) \ne a\).
    • \((1, 3, 2)\) and \((3, 1, 2)\) have stair lengths \((1, 2, 2) \ne a\).
    • \((2, 1, 3)\) has stairs \([2, 1]\) (length \(2\)) and \([3]\) (length \(1\)), giving \((2, 2, 1) = a\).
    • \((2, 3, 1)\) has stairs \([2, 3]\) (length \(2\)) and \([1]\) (length \(1\)), giving \((2, 2, 1) = a\).

Thus there are \(2\) valid permutations.

Hint 1 — Diagnostic Signal & Combinatorial Model (Spoiler-Free)

First check whether the array \(a_1, \dots, a_n\) can be partitioned into \(m\) contiguous base blocks of lengths \(s_1, s_2, \dots, s_m\) (\(\sum_{j=1}^m s_j = n\)) such that every element inside the \(j\)-th block equals \(s_j\). If not, the answer is immediately \(0\).

Once the \(m\) base blocks of lengths \(s_1, \dots, s_m\) are fixed, each base block \(j\) must be filled with a contiguous interval of \(s_j\) values arranged either in increasing or decreasing order (if \(s_j = 1\), both orientations are identical, giving \(1\) choice; if \(s_j \ge 2\), there are \(2\) orientations). Why can’t we simply multiply the orientations by \(m!\)? Because two adjacent base blocks might accidentally have consecutive values with compatible orientations and merge into a longer stair! How can you use inclusion–exclusion over which adjacent block boundaries are forced to merge?

Hint 2 — Algebraic Setup & Reverse-Engineering Scratchpad

Suppose we partition the \(m\) base blocks into \(k\) contiguous macro-blocks (\(1 \le k \le m\)) by merging \(m - k\) adjacent boundaries.

  • If we merge a contiguous range of \(r \ge 1\) base blocks into a single macro-block, how many internal ways can that macro-block be oriented?
    • If \(r = 1\) and the single base block has length \(s_j = 1\), the macro-block has total length \(1\), so it has only \(1\) orientation (increasing and decreasing coincide).
    • In all other cases (either \(r \ge 2\), or \(r = 1\) with \(s_j \ge 2\)), the macro-block has total length \(\ge 2\), so it has \(2\) orientations (either all its constituent base blocks are arranged to ascend overall, or to descend overall, with each internal base block’s orientation forced to match the macro-block’s direction!).
  • Once \(k\) macro-blocks are formed, assigning the \(k\) value-intervals to them in any permutation gives \(k!\) ways, weighted by the inclusion–exclusion sign \((-1)^{m - k}\).

To compute the sum of orientation products over all ways to form \(k\) macro-blocks for every \(k = 1, \dots, m\), what local boundary information is needed when merging the left half \([L, M]\) and right half \([M+1, R]\) of the base blocks?

Hint 3 — Coefficient Extraction & Complexity Contract

Track a \(2\)-state indicator \(b \in \{0, 1\}\) for the currently open macro-block as you sweep across the base blocks \(j = 1, \dots, m\), where \(b = 0\) indicates that the current macro-block consists of a single length-\(1\) base block (orientation weight \(1\)) and \(b = 1\) indicates that the current macro-block has total length \(\ge 2\) (orientation weight \(2\)).

Assign each base block \(j \ge 2\) a \(2 \times 2\) transition matrix \(\mathbf{T}_j(x)\) that either cuts before block \(j\) (starting a new macro-block, multiplying by \(x\) if \(s_j = 1\) or \(2x\) if \(s_j \ge 2\)) or merges block \(j\) into the current macro-block (no factor of \(x\), transitioning to \(b' = 1\) and upgrading the current macro-block’s orientation factor from \(1 \to 2\) if \(b = 0\), or keeping it at \(2\) if \(b = 1\)).

Multiply the \(m\) matrices of degree \(1\) using a divide-and-conquer product tree in \(O(m \log^2 m)\) time, extract the coefficient \(c_k = [x^k]\) for each \(k = 1, \dots, m\), and compute \[\text{Ans} = \sum_{k=1}^m (-1)^{m - k} k! \, c_k \pmod{998244353}.\]

Problem CP-VI.3 (#117) — Codeforces 1510H: Hard Optimization

Problem Statement & Exact Constraints

You are given \(n\) closed intervals \([L_i, R_i]\) (\(1 \le i \le n\)) on the real line such that all \(2n\) endpoints \(L_1, R_1, \dots, L_n, R_n\) are pairwise distinct, and for every pair \(i \ne j\), the two intervals are either disjoint (\([L_i, R_i] \cap [L_j, R_j] = \emptyset\)) or nested (\([L_i, R_i] \subset [L_j, R_j]\) or \([L_j, R_j] \subset [L_i, R_i]\)).

You must choose for each \(i \in \{1, \dots, n\}\) a non-empty sub-interval \([l_i, r_i] \subseteq [L_i, R_i]\) (\(l_i < r_i\)) such that no two chosen sub-intervals overlap in their interiors (i.e., \((l_i, r_i) \cap (l_j, r_j) = \emptyset\) for all \(i \ne j\)). Maximize the total length \(\sum_{i=1}^n (r_i - l_i)\) of the chosen sub-intervals.

  • Constraints: \(1 \le n \le 2000\), \(0 \le L_i < R_i \le 10^9\), all \(2n\) endpoints distinct.
  • Target Complexity: \(O(n^2)\) time and \(O(n^2)\) space.

Sample Trace (\(N \le 4\))

Let \(n = 2\) with \(I_1 = [0, 10]\) and \(I_2 = [3, 6] \subset I_1\).

  • Interval \(I_2\) must choose a sub-interval \([l_2, r_2] \subseteq [3, 6]\), and interval \(I_1\) must choose a sub-interval \([l_1, r_1] \subseteq [0, 10]\) disjoint from \((l_2, r_2)\).
  • Because \([l_1, r_1]\) is a single contiguous segment, it must lie either inside \([0, l_2]\) or inside \([r_2, 10]\).
  • Choosing \([l_2, r_2] = [3, 6]\) (length \(3\)) and \([l_1, r_1] = [6, 10]\) (length \(4\)) achieves total length \(3 + 4 = 7\), leaving \([0, 3]\) uncovered. No valid choice can cover more than \(7\) units because \([0, 3]\) and \([6, 10]\) lie on opposite sides of \(I_2\) and only one interval (\(I_1\)) is available to cover them.
Hint 1 — Diagnostic Signal & Combinatorial Model (Spoiler-Free)

Because the intervals are laminar (either disjoint or strictly nested), ordering them by inclusion forms a forest of rooted trees where the children of interval \(u\) are the maximal intervals \(v_1, \dots, v_d\) strictly contained inside \(u\), ordered from left to right: \[L_u < L_{v_1} < R_{v_1} < L_{v_2} < R_{v_2} < \dots < L_{v_d} < R_{v_d} < R_u.\] Notice that the regions \([L_u, R_u] \setminus \bigcup_{c=1}^d [L_{v_c}, R_{v_c}]\) consist of \(d + 1\) elementary “gaps” \(G_0, G_1, \dots, G_d\) inside \(u\).

Could \(u\)’s chosen sub-interval \([l_u, r_u]\) completely contain a child interval \([L_{v_c}, R_{v_c}]\)? No, because then \((l_u, r_u)\) would overlap \((l_{v_c}, r_{v_c})\), which is forbidden! Therefore, every chosen sub-interval \([l_w, r_w]\) inside \(T_u\) either lies inside a single gap \(G_c\), or lies inside some child subtree \(T_{v_c}\), or straddles the boundary endpoint \(L_{v_c}\) or \(R_{v_c}\) by shrinking \(v_c\)’s used region. How can you reformulate this without tracking continuous coordinates \(l_i, r_i\)?

Hint 2 — Algebraic Setup & Reverse-Engineering Scratchpad

By an exchange argument, in an optimal solution every chosen sub-interval \([l_w, r_w]\) has endpoints that are pushed outwards until they hit either an original endpoint \(L_u, R_u\) or another chosen sub-interval. Equivalently, if we decompose the union of chosen sub-intervals inside \([L_u, R_u]\) along the \(2\operatorname{sz}(u)\) original endpoints of \(T_u\), each elementary gap \(G_c\) between consecutive original endpoints is either completely covered (contributing its full length \(|G_c|\)) or completely empty (contributing \(0\))!

Why? Because if a gap \(G_c = [x, y]\) is even partially entered by an interval that starts at or to the left of \(x\) (or ends at or to the right of \(y\)), stretching that interval across the entire gap \([x, y]\) increases total length without violating any constraint; and if an interval is placed strictly inside \(G_c\), it might as well expand to fill all of \(G_c = [x, y]\)!

Thus, inside subtree \(T_u\), each node \(u\) generates \(1\) new interval demand (which can either be satisfied right now, or passed down/up—specifically, in a bottom-up view, a subtree \(T_u\) can pass \(j \in [0, \operatorname{sz}(u)]\) excess covered segments upward to be claimed by \(u\) and \(u\)’s ancestors, along with two boolean boundary flags \(b_L, b_R \in \{0, 1\}\) indicating whether the leftmost/rightmost covered segment in \(T_u\) touches \(L_u\) or \(R_u\) so it can seamlessly merge with the adjacent gap outside \(T_u\)!).

Hint 3 — Coefficient Extraction & Complexity Contract

At each tree node \(u\) with children \(v_1, \dots, v_d\) and gaps \(G_0, G_1, \dots, G_d\) of lengths \(g_0, g_1, \dots, g_d\):

  1. Represent the DP of a child \(v_c\) (or a prefix of children and gaps) as a \(2 \times 2\) matrix of sequences \(dp[b_L][b_R][j]\) for \(b_L, b_R \in \{0, 1\}\) and \(0 \le j \le \operatorname{sz}\), storing the maximum covered length inside the region when \(j\) active intervals remain unclaimed by ancestors and the left/right boundaries of the region are active (\(1\)) or inactive (\(0\)).
  2. Each gap \(G_c\) of length \(g_c\) can either be left empty (transitioning \((b_R = \text{any}) \to (b'_L = 0)\) with \(+0\) length) or covered (contributing \(+g_c\) length: if merged with the left neighbor \(b_R = 1\) and/or right neighbor \(b_L = 1\), the number of distinct segments adjusts by \(+1 - b_R - b_L\)!).
  3. Merging prefix state of size \(S_1\) with child \(v_c\) of size \(S_2\) is a \((+, \max)\) convolution of degree \(S_1\) and \(S_2\). By the tree knapsack size bound, doing this naively across all children of all nodes takes \(O(\operatorname{sz}(u)^2)\) total time, i.e., \(O(n^2)\)!
  4. Finally, at node \(u\), interval \(u\) itself claims one of the \(j \ge 1\) segments inside \([L_u, R_u]\) (shifting index \(j \to j - 1\)).

Problem CP-VI.4 (#170) — Luogu P5327: [ZJOI2019] 语言 (Language)

Problem Statement & Exact Constraints

A continent consists of \(n\) cities connected by \(n - 1\) bidirectional roads forming a tree \(T = (V, E)\). There are \(m\) languages spoken across the continent; the \(i\)-th language (\(1 \le i \le m\)) is spoken in every city along the unique simple path between city \(s_i\) and city \(t_i\) (inclusive).

Two distinct cities \(u \ne v\) can communicate if and only if there is at least one language spoken in both \(u\) and \(v\). Compute the total number of unordered pairs of distinct cities \(\{u, v\}\) that can communicate.

  • Constraints: \(1 \le n, m \le 10^5\).
  • Target Complexity: \(O(n \log n)\) time and \(O(n \log n)\) space.

Sample Trace (\(N \le 4\))

Fix a single city \(u \in V\). Which cities \(v\) can communicate with \(u\)? Exactly the union of all paths \(P_i = (s_i, t_i)\) that pass through \(u\).

Hint 2 — Algebraic Setup & Reverse-Engineering Scratchpad

A path \(P_i = (s_i, t_i)\) with \(w_i = \operatorname{LCA}(s_i, t_i)\) covers \(u\) if and only if \(w_i\) is an ancestor of \(u\) and at least one of \(s_i\) or \(t_i\) lies in the subtree \(T_u\). Thus, we can apply tree difference on the multisets \(E_u\):

  • At both \(s_i\) and \(t_i\): insert \(\{s_i, t_i\}\) with multiplicity \(+1\).
  • At \(w_i = \operatorname{LCA}(s_i, t_i)\): remove \(\{s_i, t_i\}\) once; and at \(\operatorname{parent}(w_i)\): remove \(\{s_i, t_i\}\) a second time!

Problem CP-VI.5 (#054) — AtCoder ARC 106 E: Medals

Problem Statement & Exact Constraints

There are \(N\) employees numbered \(1, 2, \dots, N\) and an integer \(K\). Employee \(i\) follows a strict periodic attendance schedule determined by a positive integer \(A_i\): starting from day \(1\), employee \(i\) comes to work for \(A_i\) consecutive days, then rests at home for \(A_i\) consecutive days, then works for \(A_i\) days, and so on indefinitely. Formally, employee \(i\) works on day \(d \ge 1\) if and only if \[((d - 1) \bmod 2A_i) < A_i.\]

On each day \(d = 1, 2, \dots, D\), you may choose at most one employee who is working on day \(d\) and award them one medal. Find the minimum number of days \(D\) required so that every employee \(1, \dots, N\) can receive at least \(K\) medals.

  • Constraints: \(1 \le N \le 18\), \(1 \le K \le 10^5\), \(1 \le A_i \le 10^5\).
  • Target Complexity: \(O(N K + N 2^N \log(N K))\) time and \(O(N K + 2^N)\) space.

Sample Trace (\(N \le 4\))

Let \(N = 2\), \(K = 2\), and \(A = (1, 2)\).

  • Employee \(1\) (\(A_1 = 1\)) works on days \(1, 3, 5, 7, \dots\).
  • Employee \(2\) (\(A_2 = 2\)) works on days \(1, 2, 5, 6, \dots\).
  • For \(D = 4\) days, the sets of working employees on days \(1, 2, 3, 4\) are \(\{1, 2\}, \{2\}, \{1\}, \emptyset\). Since day \(4\) has no working employees, at most \(3\) medals can be awarded in the first \(4\) days, which is less than \(N K = 4\).
  • On day \(5\), \(\{1, 2\}\) work again, allowing \(2\) medals for each employee (e.g., day \(1 \to 2\), day \(2 \to 2\), day \(3 \to 1\), day \(5 \to 1\)). Thus the minimum \(D\) is \(5\).
Hint 1 — Diagnostic Signal & Combinatorial Model (Spoiler-Free)

First establish an upper bound on the answer \(D\): even if we greedily focus on one employee at a time, within \(2 N K\) days every employee works at least \(N K\) days, so \(D \le 2 N K \le 3.6 \times 10^6\). Furthermore, feasibility is monotone in \(D\), suggesting binary search on \(D \in [N K, 2 N K]\).

For a fixed candidate number of days \(D\), we have a bipartite matching problem between the \(N\) employees (each needing \(K\) medals) and the \(D\) days (each capable of awarding \(1\) medal to a working employee). Under what exact condition on the \(2^N\) subsets of employees \(S \subseteq \{1, \dots, N\}\) does a valid assignment of medals exist?

Hint 2 — Algebraic Setup & Reverse-Engineering Scratchpad

By Hall’s Marriage Theorem (applied with each employee \(i\) replicated \(K\) times), a valid assignment exists within \(D\) days if and only if for every subset of employees \(S \subseteq \{1, \dots, N\}\), the number of days in \(\{1, \dots, D\}\) on which at least one employee in \(S\) is working is at least \(|S| \cdot K\): \[W_D(S) \ge |S| \cdot K \quad \text{for all } S \subseteq \{1, \dots, N\}.\]

For each day \(d \in \{1, \dots, D\}\), let \(M_d \in [0, 2^N - 1]\) be the bitmask of employees working on day \(d\), and let \(c(T)\) be the number of days \(d \in \{1, \dots, D\}\) with \(M_d = T\). How can you express \(W_D(S)\)—the count of days \(d\) where \(M_d \cap S \ne \emptyset\)—in terms of a subset sum of \(c(T)\)?

Hint 3 — Coefficient Extraction & Complexity Contract

A day \(d\) has \(M_d \cap S \ne \emptyset\) if and only if \(M_d\) is not a subset of the complement \(U \setminus S\) (where \(U = \{1, \dots, N\}\)). Therefore, \[W_D(S) = D - \sum_{T \subseteq U \setminus S} c(T).\] Notice that \(F(X) = \sum_{T \subseteq X} c(T)\) is the Fast Zeta / SOS (Sum Over Subsets) Transform of the frequency array \(c\)!

  1. Precompute the daily attendance bitmasks \(M_1, M_2, \dots, M_{2NK}\) in \(O(N K)\) time before starting the binary search.
  2. Inside each of the \(\approx 22\) binary search steps for \(D\):
    • Tally \(c(T)\) for \(d = 1, \dots, D\) in \(O(D + 2^N)\) time.
    • Run the \(N\)-bit SOS Transform \(F(X) = \sum_{T \subseteq X} c(T)\) in \(O(N 2^N)\) time.
    • Check whether \(D - F(U \setminus S) \ge |S| \cdot K\) for all \(S \subseteq U\) in \(O(2^N)\) time.

You are given \(n\) integers \(a_1, a_2, \dots, a_n\). Let \(n = 3\) and \(a = (1, 2, 3)\).

In other words, for each element \(a_i\), how many ways can it be assigned to \(A\), \(B\), or neither, what does each choice contribute to the combined XOR value \(X(A) \oplus X(B)\), and why can’t we combine these \(n = 10^6\) choices naively in \(O(n \cdot 2^{20})\) time?

Hint 2 — Algebraic Setup & Reverse-Engineering Scratchpad

In the XOR group algebra \(\mathbb{F}_P[\mathbb{Z}_2^b]\) (\(b = 20\)), the \(i\)-th element corresponds to the binomial \(1 + 2 x^{a_i}\), and we want the coefficient of \(x^0\) in the \(n\)-fold XOR convolution product: \[P(x) = \prod_{i=1}^n (1 + 2 x^{a_i}).\] Instead of transforming \(n\) separate arrays, examine what the XOR Walsh–Hadamard Transform (\(\operatorname{FWT}_{\oplus}\)) does to a single sparse factor \(1 + 2 x^{a_i}\) at frequency mask \(S \in [0, 2^b - 1]\): \[\widehat{(1 + 2 x^{a_i})}_S = 1 + 2(-1)^{\operatorname{popcount}(S \ \& \ a_i)} = \begin{cases} 3 & \text{if } \operatorname{popcount}(S \ \& \ a_i) \equiv 0 \pmod 2, \\ -1 & \text{if } \operatorname{popcount}(S \ \& \ a_i) \equiv 1 \pmod 2. \end{cases}\] Every factor evaluates to either \(3\) or \(-1\)! Hint 3 — Coefficient Extraction & Complexity Contract

Let \(C(x) = \sum_{i=1}^n x^{a_i}\) be the frequency polynomial of the input array, and apply a single forward XOR transform \(\widehat{C} = \operatorname{FWT}_{\oplus}(C)\) in \(O(b 2^b)\) time.

You are given \(Q\) queries. Sample Trace (\(N \le 4\))

  • If \(u \in T\), then \(E_u = 0\).
  • If \(u \notin T\), then \(E_u = 1 + \frac{1}{d(u)} \sum_{v \in N(u)} E_v\).

How can you solve this system of \(n\) linear equations on the tree \(T\) in \(O(n)\) time (rather than \(O(n^3)\) Gaussian elimination), and how can you precompute the subset sum \(\sum_{\emptyset \ne T \subseteq S} (-1)^{|T|-1} f(T)\) for all \(2^n\) query sets \(S\) simultaneously?

1. Stirling Edge-Subset Expansion

Using the identity \(m^k = \sum_{j=0}^k \left\{\begin{smallmatrix} k \\ j \end{smallmatrix}\right\} j! \binom{m}{j}\), where \(\left\{\begin{smallmatrix} k \\ j \end{smallmatrix}\right\}\) denotes the Stirling numbers of the second kind, we rewrite the target sum as: \[S = \sum_{\emptyset \ne X \subseteq V} f(X)^k = \sum_{j=0}^k \left\{\begin{matrix} k \\ j \end{matrix}\right\} j! \underbrace{\sum_{\emptyset \ne X \subseteq V} \binom{f(X)}{j}}_{C_j}.\] Here \(C_j\) counts ordered pairs \((X, F)\) where \(\emptyset \ne X \subseteq V\) is a non-empty subset of vertices, \(F \subseteq E\) is a subset of \(|F| = j\) edges, and every edge \(e \in F\) lies in the minimal connected subgraph (Steiner subtree) spanning \(X\).

2. Rooted Subtree Characterization & Subtraction of Invalid Upward Extensions

Root \(T\) arbitrarily at vertex \(1\). An edge \(e = (u, v)\) (with \(u = \operatorname{parent}(v)\)) lies in the Steiner subtree of \(X\) if and only if \(X\) contains at least one vertex inside \(V(T_v)\) and at least one vertex outside \(V(T_v)\): \[X \cap V(T_v) \ne \emptyset \quad \text{and} \quad X \setminus V(T_v) \ne \emptyset.\] Notice that the first condition (\(X \cap V(T_v) \ne \emptyset\)) is local to the subtree \(T_v\): every edge \(e = (w, c) \in F\) must have \(X \cap V(T_c) \ne \emptyset\). And when does a pair \((X, F)\) satisfy the local downward condition for every \(e \in F\), yet fail the global condition \(X \setminus V(T_c) \ne \emptyset\)? Precisely when all of \(X\) lies inside a single child subtree \(V(T_v)\) of \(u = \operatorname{LCA}(X \cup V(F))\), while \(F\) chooses at least one edge inside \(T_v \cup \{(u, v)\}\) above \(\operatorname{LCA}(X)\)!

Specifically, define the subtree polynomial at vertex \(u\): \[P_u(x) = \sum_{j=0}^{\min(\operatorname{sz}(u)-1, k)} dp[u][j] \, x^j,\] where \(dp[u][j]\) counts pairs \((X_u, F_u)\) with \(\emptyset \ne X_u \subseteq V(T_u)\) and \(F_u \subseteq E(T_u)\) of size \(|F_u| = j\) such that every edge \((w, c) \in F_u\) has \(X_u \cap V(T_c) \ne \emptyset\).

  • Base Case at Vertex \(u\) (before merging children): \(u\) alone can either be in \(X_u\) (\(1\) way, \(0\) edges) or not in \(X_u\) (\(0\) non-empty ways), so initially \(P_u(x) = 1\) (representing \(X_u = \{u\}\)) and the empty choice \(X_u = \emptyset\) has weight \(1\).
  • Transition across Child Edge \(e = (u, v)\): For a child \(v\) of \(u\), if \(X_u \cap V(T_v) \ne \emptyset\), the edge \((u, v)\) may be either omitted (\(1\)) or chosen (\(x\)) in \(F_u\), giving the shifted child polynomial \[Q_v(x) = P_v(x)(1 + x) \bmod x^{k+1}.\] Combined with the empty choice \(X_u \cap V(T_v) = \emptyset\) (which contributes \(1\)), merging child \(v\) into \(u\) updates \[1 + P_u^{\text{new}}(x) = \big(1 + P_u^{\text{old}}(x)\big)\big(1 + Q_v(x)\big) \bmod x^{k+1},\] or equivalently: \[P_u^{\text{new}}(x) = P_u^{\text{old}}(x) + Q_v(x) + P_u^{\text{old}}(x) Q_v(x) \bmod x^{k+1}.\]
  • Global Accumulation & Exact Cancellation: At the root \(1\), \(P_1(x)\) counts all pairs \((X, F)\) where \(\emptyset \ne X \subseteq V\) and every edge \((w, c) \in F\) satisfies \(X \cap V(T_c) \ne \emptyset\). Which of these pairs violate the upper condition \(X \setminus V(T_c) \ne \emptyset\)? For any pair \((X, F)\) counted in \(P_1(x)\), let \(u\) be the highest vertex touched by \(X\) or \(F\) (more precisely, if \(X\) is contained entirely inside \(V(T_v)\) for some child \(v\) of \(u\) while \(F\) contains edges above \(\operatorname{LCA}(X)\)). At each vertex \(u\) and each child \(v\) of \(u\), any configuration in \(Q_v(x)\) that uses at least one edge inside \(T_v \cup \{(u, v)\}\) above \(T_v\) when \(X \setminus V(T_v) = \emptyset\) is formed by taking a valid pair inside \(T_v\) (counted by \(P_v(x)\)) and appending the edge \((u, v)\) (contributing \(x P_v(x) = Q_v(x) - P_v(x)\)) with no vertices of \(X\) chosen outside \(T_v\)! Even more transparently: a pair \((X, F)\) is globally valid if and only if at the unique highest vertex \(u = \operatorname{LCA}(X \cup V(F))\), the set \(X\) is NOT confined to a single child subtree \(T_v\) of \(u\) (unless \(F = \emptyset\), which only affects \(j = 0\)). At vertex \(u\), the configurations where \(X \cup V(F)\) has highest vertex \(u\) are counted by \(P_u(x) - \sum_{v \in \text{ch}(u)} P_v(x)\), and among these, the invalid ones are precisely those where \(X \subseteq V(T_v)\) for a single child \(v\) and edge \((u, v) \in F\), which equals \(\sum_{v \in \text{ch}(u)} \big(Q_v(x) - P_v(x)\big)\)! Summing \(\Big(P_u(x) - \sum_{v \in \text{ch}(u)} Q_v(x)\Big)\) over all \(u \in V\) telescopes \(\sum_u P_u(x) - \sum_{v \ne 1} P_v(x) = P_1(x)\), leaving the remarkably clean formula: \[C(x) = \sum_{j=0}^k C_j x^j = P_1(x) - \sum_{v \in V \setminus \{1\}} \big(Q_v(x) - P_v(x)\big) = P_1(x) - x \sum_{v \in V \setminus \{1\}} P_v(x) \pmod{x^{k+1}}.\] Let us verify this identity! A pair \((X, F)\) satisfies the downward condition everywhere if and only if for the highest edge \(e_{\text{top}} = (u, v) \in F\) (if \(F \ne \emptyset\)), \(X \subseteq V(T_v)\) fails precisely when \(u\) is an ancestor of \(\operatorname{LCA}(X)\), i.e., \(X \subseteq V(T_v)\). And for each vertex \(v \ne 1\) with \(X \subseteq V(T_v)\), the pairs \((X, F')\) confined to \(T_v\) are counted by \(P_v(x)\), so adjoining the top edge \((u, v)\) gives \(x P_v(x)\), establishing \(C(x) = P_1(x) - x \sum_{v \ne 1} P_v(x)\) in a single line!

1. Base Block Partition & Merge Inclusion–Exclusion

First scan \(a_1, \dots, a_n\) from left to right: if \(a_i = s\), then the next \(s\) elements \(a_i, a_{i+1}, \dots, a_{i+s-1}\) must all exist and equal \(s\). If this fails at any point, output \(0\). Otherwise, we obtain \(m\) contiguous base blocks of sizes \(s_1, s_2, \dots, s_m\) with \(\sum_{j=1}^m s_j = n\).

In any valid permutation, the \(j\)-th base block must be filled with a set of \(s_j\) consecutive integers arranged either in increasing order or in decreasing order (giving \(1\) internal orientation if \(s_j = 1\), and \(2\) internal orientations if \(s_j \ge 2\)). Moreover, no two adjacent base blocks \(j\) and \(j+1\) may merge into a single longer stair.

By the Adjacent Block-Merge Inclusion–Exclusion Principle, we sum over all subsets of adjacent boundaries \(E' \subseteq \{1, \dots, m - 1\}\) that are forced to merge. If \(|E'| = m - k\) boundaries are merged, the \(m\) base blocks coalesce into \(k\) contiguous macro-blocks \(B_1, \dots, B_k\):

  • Relative to one another, the \(k\) macro-blocks can be assigned the \(k\) contiguous value-intervals in any of \(k!\) ways, weighted by the inclusion–exclusion sign \((-1)^{m - k}\).
  • Inside a macro-block formed by merging a range \(j \in [l, r]\) of base blocks:
    • If \(l = r\) and \(s_l = 1\), the macro-block has total length \(1\), so it has \(1\) orientation.
    • Otherwise (either \(r > l\), or \(l = r\) with \(s_l \ge 2\)), the macro-block has total length \(\ge 2\), so it has \(2\) orientations (globally increasing or globally decreasing, which uniquely fixes both the relative value order of the constituent base blocks and the internal orientation of each base block!).

2. \(2 \times 2\) Polynomial Transfer Matrix & Divide-and-Conquer NTT

Let \(c_k\) be the sum of orientation products over all ways to partition the \(m\) base blocks into \(k\) macro-blocks. We can process base blocks \(j = 1, \dots, m\) from left to right by tracking a binary state \(b \in \{0, 1\}\) for the currently open macro-block:

  • \(b = 0\): the current macro-block consists of a single base block of size \(s_j = 1\) (current orientation weight \(1\)).
  • \(b = 1\): the current macro-block has total size \(\ge 2\) (current orientation weight \(2\)).

When moving to the next base block \(j\) (\(2 \le j \le m\)), we either:

  1. Cut before block \(j\) (start a new macro-block, multiplying by \(x\)):
    • If \(s_j = 1\), we transition to state \(b' = 0\) with weight \(x\).
    • If \(s_j \ge 2\), we transition to state \(b' = 1\) with weight \(2x\).
  2. Merge block \(j\) into the current macro-block (no new macro-block, degree \(0\) in \(x\), always resulting in state \(b' = 1\) of total size \(\ge 2\)):
    • If the previous state was \(b = 0\) (weight \(1\)), merging upgrades its orientation weight from \(1\) to \(2\), so the transition multiplier is \(2\).
    • If the previous state was \(b = 1\) (already weight \(2\)), merging keeps its orientation weight at \(2\), so the transition multiplier is \(1\).

Thus, each base block \(j \in \{2, \dots, m\}\) is represented by a \(2 \times 2\) polynomial matrix \(\mathbf{T}_j(x)\) (rows indexed by old state \(b \in \{0, 1\}\), columns by new state \(b' \in \{0, 1\}\)): \[\mathbf{T}_j(x) = \begin{cases} \begin{pmatrix} x & 2 \\ x & 1 \end{pmatrix} & \text{if } s_j = 1, \\[10pt] \begin{pmatrix} 0 & 2x + 2 \\ 0 & 2x + 1 \end{pmatrix} & \text{if } s_j \ge 2, \end{cases}\] with initial row vector at \(j = 1\) given by \(\mathbf{v}_1(x) = (x, \, 0)\) if \(s_1 = 1\) and \(\mathbf{v}_1(x) = (0, \, 2x)\) if \(s_1 \ge 2\).

Multiplying \(\mathbf{P}(x) = \mathbf{v}_1(x) \mathbf{T}_2(x) \cdots \mathbf{T}_m(x)\) via a balanced binary divide-and-conquer tree of \(2 \times 2\) polynomial matrix multiplications gives \(C(x) = P_0(x) + P_1(x) = \sum_{k=1}^m c_k x^k\), and the final answer is: \[\text{Ans} = \sum_{k=1}^m (-1)^{m - k} k! \, [x^k] C(x) \pmod{998244353}.\]

Algorithm Contract

  • Input: Array \(a_1, \dots, a_n\) (\(1 \le n \le 10^5\)).
  • Output: Number of valid permutations modulo \(998244353\).
  • Algebraic Preconditions: Matrix ring \(M_{2 \times 2}(\mathbb{F}_{998244353}[x])\).
  • Index & Degree Boundaries: \(m \le n\) base blocks; \(\deg \mathbf{T}_j(x) = 1\); total product has degree \(m\).
  • Complexity & Correctness Invariant: At depth \(d\) of the D&C tree, \(2^d\) matrix multiplications of degree \(m / 2^d\) perform \(8\) NTTs of size \(O(m / 2^d)\), costing \(O(m \log^2 m) \subseteq O(n \log^2 n)\) time and \(O(n \log n)\) space. The state \(b \in \{0, 1\}\) guarantees every macro-block of total length \(1\) receives orientation factor \(1\) and every macro-block of total length \(\ge 2\) receives orientation factor \(2\).
  • Failure Modes & Edge Cases: If any required run of \(a_i = s\) consecutive identical values extends past \(n\) or contains an element \(\ne s\), immediately output \(0\); also distinguish \(s_j = 1\) (\(1\) internal orientation) from \(s_j \ge 2\) (\(2\) internal orientations) in both \(\mathbf{v}_1(x)\) and \(\mathbf{T}_j(x)\).

1. Laminar Containment Forest & Elementary Gap Decomposition

Sort the \(n\) intervals by increasing left endpoint \(L_i\). Because the intervals are laminar with distinct endpoints, each interval \(u\) directly contains a sequence of child intervals \(v_1, v_2, \dots, v_d\) ordered from left to right: \[L_u < L_{v_1} < R_{v_1} < L_{v_2} < R_{v_2} < \dots < L_{v_d} < R_{v_d} < R_u.\] Add a virtual super-root if there are multiple top-level intervals. The \(2n\) original endpoints partition \([L_u, R_u]\) into the child intervals \([L_{v_c}, R_{v_c}]\) and \(d + 1\) elementary gaps: \[G_0 = [L_u, L_{v_1}], \quad G_1 = [R_{v_1}, L_{v_2}], \quad \dots, \quad G_d = [R_{v_d}, R_u],\] with lengths \(g_c = |G_c| > 0\).

By pushing endpoints of chosen sub-intervals \([l_i, r_i]\) to original endpoints \(L_w, R_w\), every elementary gap \(G_c\) is either completely covered by a single chosen sub-interval \([l_w, r_w]\) or completely uncovered. Why? If two chosen sub-intervals met inside the interior of \(G_c\), one of them could be shrunk to an endpoint of \(G_c\) while the other expands across \(G_c\), preserving total length \(\sum (r_i - l_i)\) without creating any new overlap. Thus the union of chosen sub-intervals is a union of elementary gaps, and every chosen sub-interval \([l_w, r_w]\) is a contiguous run of covered elementary gaps inside \([L_w, R_w]\).

2. Bottom-Up \(2 \times 2\) Boundary-State Tree Knapsack

Inside a subtree \(T_u\), each of the \(\operatorname{sz}(u)\) intervals \(w \in T_u\) must be assigned a distinct non-empty covered sub-interval \([l_w, r_w] \subseteq [L_w, R_w]\). As we sweep across \([L_u, R_u]\) from left to right (alternating \(G_0, T_{v_1}, G_1, T_{v_2}, \dots, T_{v_d}, G_d\)), some covered segments inside \(T_u\) have already been claimed by intervals \(w \in T_u\), while \(j\) covered segments remain unclaimed so they can be claimed by \(u\) or by strict ancestors of \(u\) (or extended across adjacent gaps!).

Notice how many unclaimed segments can coexist at the boundary of \(T_u\): because at most one ancestor’s sub-interval can cross \(L_u\) and at most one can cross \(R_u\), any other unclaimed segment strictly inside \((L_u, R_u)\) can never be extended further, so it serves as a finished segment waiting to be claimed by \(u\) or an ancestor of \(u\). Since \(T_u\) plus its ancestors can claim at most \(\operatorname{sz}(u)\) segments originating inside \(T_u\), we only need to track \(0 \le j \le \operatorname{sz}(u)\) unclaimed segments!

Define at each node \(u\) the \(2 \times 2\) state table \[dp_u[b_L][b_R][j] \quad (b_L, b_R \in \{0, 1\}, \; 0 \le j \le \operatorname{sz}(u)),\] representing the maximum covered length inside \([L_u, R_u]\) after all intervals \(w \in T_u\) (including \(u\) itself) have claimed their sub-intervals, leaving \(j\) unclaimed segments for strict ancestors of \(u\), where \(b_L = 1\) (resp. \(b_R = 1\)) iff the leftmost (resp. rightmost) point \(L_u\) (resp. \(R_u\)) belongs to an unclaimed segment that may continue outside \([L_u, R_u]\).

  1. Sweeping across \(G_0, T_{v_1}, G_1, \dots, T_{v_d}, G_d\) inside \(u\):

    • Single Gap \(G_c\) of length \(g_c\): Represented by a \(2 \times 2\) table \(M_{G_c}[b_L][b_R][j]\) where:

      • Leaving \(G_c\) uncovered: \(M_{G_c}[0][0][0] = 0\).
      • Covering \(G_c\) as an unclaimed segment: \(M_{G_c}[1][1][1] = g_c\).

    • Concatenating two adjacent regions \(A\) and \(B\): When region \(A\) (state \((b_L, m, j_1)\)) abuts region \(B\) (state \((m', b_R, j_2)\)) at a shared point:

      • If \(m = 1\) and \(m' = 1\), we can either fuse the two boundary segments into a single contiguous segment (resulting in \(j = j_1 + j_2 - 1\) unclaimed segments) or split them at the boundary endpoint so they remain two separate adjacent segments (\(j = j_1 + j_2\)).
      • Otherwise (\(m = 0\) or \(m' = 0\)), the unclaimed segment count is simply \(j = j_1 + j_2\). This is a \((+, \max)\) convolution of sizes \(\operatorname{sz}(A)\) and \(\operatorname{sz}(B)\).

  2. Claiming Interval \(u\)’s Own Sub-Interval: Once the full region \([L_u, R_u]\) has been assembled into \(F_u[b_L][b_R][j]\) (\(0 \le j \le \operatorname{sz}(u)\)), interval \(u\) itself must claim one of the \(j \ge 1\) unclaimed segments inside \([L_u, R_u]\)!

    • If \(u\) claims an interior segment (or a boundary segment that terminates at \(L_u\) or \(R_u\)), \(j\) decreases to \(j - 1\), and if the claimed segment was the left/right boundary (\(b_L = 1\) or \(b_R = 1\)), that boundary flag resets to \(0\) (since \(u\)’s sub-interval cannot extend outside \([L_u, R_u]\)!): \[dp_u[b'_L][b'_R][j - 1] \stackrel{\max}{\longleftarrow} F_u[b_L][b_R][j] \quad \text{for } b'_L \le b_L, \; b'_R \le b_R, \; j \ge 1.\]

(To reconstruct the actual intervals \([l_i, r_i]\) as required by CF 1510H, store backpointers at each \((+, \max)\) merge and gap decision.)

1. Reachable Set as a Minimal Steiner Subtree

Fix a city \(u \in V\), and let \(\mathcal{P}_u = \{i \in \{1, \dots, m\} : u \in P_i\}\) be the set of languages spoken at \(u\). The set of cities \(v\) that can communicate with \(u\) is the union of the paths \(P_i = (s_i, t_i)\) for \(i \in \mathcal{P}_u\).

Because every path \(P_i\) (\(i \in \mathcal{P}_u\)) is connected and passes through the common vertex \(u\), their union \(\bigcup_{i \in \mathcal{P}_u} P_i\) is a connected subtree of \(T\) whose leaves are a subset of the endpoint multiset \[E_u = \bigcup_{i \in \mathcal{P}_u} \{s_i, t_i\}.\] Conversely, since \(u\) lies on every path \(P_i\) (\(i \in \mathcal{P}_u\)), the unique path between any two endpoints in \(E_u\) is contained in \(\bigcup_{i \in \mathcal{P}_u} P_i\). Therefore, \(\bigcup_{i \in \mathcal{P}_u} P_i\) is identical to the minimal connected subtree (Steiner subtree) spanning \(E_u\)! Furthermore, the number of cities \(v \ne u\) in this subtree is simply the number of edges in the Steiner subtree of \(E_u\).

2. DFS-Order Steiner Size & Bottom-Up Segment Tree Merging

Root \(T\) at vertex \(1\), and compute the DFS entry order \(\operatorname{dfn}[w] \in \{1, \dots, n\}\) and depth \(\operatorname{dep}(w)\) of every vertex \(w\). Precompute an Euler-tour RMQ table so that \(\operatorname{LCA}(x, y)\) can be answered in \(O(1)\) time.

If the distinct vertices in \(E_u\) are \(x_1, x_2, \dots, x_k\) sorted by \(\operatorname{dfn}[x_1] < \operatorname{dfn}[x_2] < \dots < \operatorname{dfn}[x_k]\), the number of edges in the minimal subtree spanning \(E_u\) is: \[\text{Edges}(E_u) = \sum_{j=1}^k \operatorname{dep}(x_j) - \sum_{j=1}^{k-1} \operatorname{dep}\big(\operatorname{LCA}(x_j, x_{j+1})\big) - \operatorname{dep}\big(\operatorname{LCA}(x_1, x_k)\big).\]

To maintain the multiset \(E_u\) across all \(u \in V\):

  1. For each path \(P_i = (s_i, t_i)\) with \(w_i = \operatorname{LCA}(s_i, t_i)\), \(P_i\) covers \(u\) iff at least one of \(s_i, t_i\) lies in \(T_u\) and \(w_i\) is an ancestor of \(u\). Thus we apply tree difference:
    • At \(s_i\): add \(+1\) to the multiplicity of \(\operatorname{dfn}[s_i]\) and \(+1\) to \(\operatorname{dfn}[t_i]\).
    • At \(t_i\): add \(+1\) to \(\operatorname{dfn}[s_i]\) and \(+1\) to \(\operatorname{dfn}[t_i]\).
    • At \(w_i\): add \(-1\) to \(\operatorname{dfn}[s_i]\) and \(-1\) to \(\operatorname{dfn}[t_i]\).
    • At \(\operatorname{parent}(w_i)\) (if \(w_i \ne 1\)): add \(-1\) to \(\operatorname{dfn}[s_i]\) and \(-1\) to \(\operatorname{dfn}[t_i]\).

1. Upper Bound on \(D\) & Hall’s Marriage Theorem

Within any \(2 A_i\) consecutive days, employee \(i\) works on exactly \(A_i\) days (at least half the days). For a fixed candidate \(D\), construct a bipartite graph where the left side has \(N\) employee nodes (each with demand \(K\)), the right side has \(D\) day nodes \(d \in \{1, \dots, D\}\) (each with capacity \(1\)), and an edge connects employee \(i\) to day \(d\) iff employee \(i\) works on day \(d\). By Hall’s Marriage Theorem, a valid assignment of \(K\) medals per employee exists if and only if for every subset of employees \(S \subseteq \{1, \dots, N\}\), the number of days \(W_D(S)\) in \(\{1, \dots, D\}\) on which at least one employee in \(S\) works satisfies: \[W_D(S) \ge |S| \cdot K \quad \text{for all } S \subseteq \{1, \dots, N\}.\]

2. Fast Zeta (SOS) Transform on Complement Masks

1. Reformulation in the XOR Group Ring

Two disjoint subsets \(A, B \subseteq \{1, \dots, n\}\) satisfy \(\bigoplus_{i \in A} a_i = \bigoplus_{j \in B} a_j\) if and only if their disjoint union \(U = A \sqcup B\) satisfies \(\bigoplus_{k \in U} a_k = 0\). Conversely, any subset \(U \subseteq \{1, \dots, n\}\) with XOR sum \(0\) can be partitioned into an ordered pair of disjoint subsets \((A, B)\) with \(A \sqcup B = U\) in \(2^{|U|}\) ways (each element \(k \in U\) goes to \(A\) or \(B\)).

Therefore, in the XOR group algebra \(\mathbb{F}_{998244353}[\mathbb{Z}_2^b]\) (\(b = 20\)) where monomials multiply via \(x^u \cdot x^v = x^{u \oplus v}\), the number of ordered pairs \((A, B)\) of disjoint subsets with equal XOR sum is the coefficient of \(x^0\) in \[P(x) = \prod_{i=1}^n \big(1 + 2 x^{a_i}\big).\]

2. Small-Support Walsh–Hadamard Eigenvalue Trick

Applying the \(b\)-bit XOR Fast Walsh–Hadamard Transform (\(\operatorname{FWT}_{\oplus}\)) turns XOR convolution into pointwise multiplication. For a single factor \(1 + 2 x^{a_i}\), its transform at frequency mask \(S \in [0, 2^b - 1]\) is: \[\widehat{(1 + 2 x^{a_i})}_S = 1 + 2(-1)^{\operatorname{popcount}(S \ \& \ a_i)} \in \{3, -1\}.\] Specifically, the value is \(3\) if \(\operatorname{popcount}(S \ \& \ a_i)\) is even, and \(-1\) if \(\operatorname{popcount}(S \ \& \ a_i)\) is odd.

To find how many \(i \in \{1, \dots, n\}\) give \(+1\) versus \(-1\) at each frequency \(S\) without transforming \(n\) polynomials separately, form the single frequency polynomial \[C(x) = \sum_{i=1}^n x^{a_i}\] and compute \(\widehat{C} = \operatorname{FWT}_{\oplus}(C)\) in \(O(b 2^b)\) time. At frequency \(S\), let \(k_S\) be the number of indices \(i\) with \((-1)^{\operatorname{popcount}(S \ \& \ a_i)} = +1\). Then: \[\begin{cases} k_S + (n - k_S) = n, \\ k_S - (n - k_S) = \widehat{C}_S, \end{cases} \implies k_S = \frac{n + \widehat{C}_S}{2}.\] Hence the Walsh–Hadamard spectrum of \(P(x)\) at frequency \(S\) is immediately: \[\widehat{P}_S = 3^{k_S} (-1)^{n - k_S} \pmod{998244353}.\] By the inverse XOR transform at index \(0\), \([x^0] P(x) = 2^{-b} \sum_{S=0}^{2^b - 1} \widehat{P}_S\). Subtracting \(1\) (to remove the empty pair \(A = B = \emptyset\)) and multiplying by \(2^{-1} \bmod 998244353\) (for unordered pairs \(\{A, B\}\)) yields the final answer: \[\text{Ans} = \frac{[x^0] P(x) - 1}{2} \pmod{998244353}.\]

1. Matrix-Tree Theorem over the Mixed Bitwise Group Algebra

Fix a large prime \(P\) (e.g., \(P = 998244353\) or \(10^9 + 9\)) so that non-zero spanning tree counts do not vanish modulo \(P\), and consider the \(2^w\)-dimensional commutative ring \[\mathcal{A} = \mathbb{F}_P[z^0, z^1, \dots, z^{2^w - 1}] \quad \text{with} \quad z^u \cdot z^v = z^{u \odot v},\] where \(u \odot v\) combines the \(r\)-th bits of \(u\) and \(v\) via \(\text{op}_r \in \{\text{\&}, \text{|}, \text{\^{}}\}\) for each \(0 \le r < w\).

Construct the \(n \times n\) Laplacian matrix \(L(z) \in M_{n \times n}(\mathcal{A})\) of the multigraph \(G\): for each edge \(e = (u, v) \in E\) with weight \(v_e\), add \(+z^{v_e}\) to \(L_{u, u}(z)\) and \(L_{v, v}(z)\), and add \(-z^{v_e}\) to \(L_{u, v}(z)\) and \(L_{v, u}(z)\). 1. Min–Max Inclusion–Exclusion Reduction

Let \(\tau_v\) be the first hitting time of vertex \(v\) starting from root \(x\). For any query subset \(S \subseteq V\), the time until all vertices in \(S\) have been visited is \(\max_{v \in S} \tau_v\). Applying the Min–Max Identity \(\max_{v \in S} \tau_v = \sum_{\emptyset \ne T \subseteq S} (-1)^{|T| - 1} \min_{v \in T} \tau_v\) and taking expectations gives: \[\mathbb{E}\!\left[\max_{v \in S} \tau_v\right] = \sum_{\emptyset \ne T \subseteq S} (-1)^{|T| - 1} f(T), \quad \text{where } f(T) = \mathbb{E}\!\left[\min_{v \in T} \tau_v\right].\] Here \(f(T)\) is the expected number of steps, starting from \(x\), to hit at least one vertex in \(T\).

2. \(O(n)\) Tree Linear Elimination for Fixed Target Set \(T\)

Root the tree \(T_{\text{tree}}\) at the starting vertex \(x\). For a fixed non-empty target subset \(T \subseteq V\), let \(E_u\) be the expected number of steps to hit \(T\) starting from \(u\). The Markov chain transitions satisfy:

  • If \(u \in T\): \(E_u = 0\).
  • If \(u \notin T\): \(E_u = 1 + \frac{1}{d(u)} \Big(E_{p(u)} + \sum_{v \in \text{ch}(u)} E_v\Big)\), where \(p(u)\) is the parent of \(u\) (omitted if \(u = x\)) and \(\text{ch}(u)\) is the set of children of \(u\).

We prove by bottom-up induction on the tree that every vertex \(u\) satisfies a linear relation \[E_u = A_u E_{p(u)} + B_u:\]

  • Target vertices (\(u \in T\)): Since \(E_u = 0\) regardless of \(E_{p(u)}\), we have \(A_u = 0\) and \(B_u = 0\).
  • Non-target vertices (\(u \notin T\)): Assuming \(E_v = A_v E_u + B_v\) has already been computed for every child \(v \in \text{ch}(u)\), substitute these into \(u\)’s equation: \[d(u) E_u = d(u) + [u \ne x] E_{p(u)} + \sum_{v \in \text{ch}(u)} \big(A_v E_u + B_v\big).\] Collecting the \(E_u\) terms on the left gives: \[\left(d(u) - \sum_{v \in \text{ch}(u)} A_v\right) E_u = [u \ne x] E_{p(u)} + d(u) + \sum_{v \in \text{ch}(u)} B_v.\] Setting \(D_u = \big(d(u) - \sum_{v \in \text{ch}(u)} A_v\big)^{-1} \bmod 998244353\), we obtain in \(O(\deg(u))\) time: \[A_u = [u \ne x] \cdot D_u \bmod P, \qquad B_u = D_u \cdot \left(d(u) + \sum_{v \in \text{ch}(u)} B_v\right) \bmod P.\]

At the root \(x\), \(A_x = 0\) and \(f(T) = E_x = B_x\)! Thus \(f(T)\) is computed in \(O(n)\) time per subset \(T\), and across all \(2^n - 1\) non-empty subsets \(T \subseteq V\) in \(O(n 2^n)\) total time.
