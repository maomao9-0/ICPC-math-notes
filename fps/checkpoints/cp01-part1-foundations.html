Blind Checkpoint I — Foundations of Formal Power Series & The Symbolic Method

Part I Diagnostic Assessment (Chapters 01–04 · No Topic Spoilers)

When you solve a practice problem at the end of Chapter 03 (“The Unlabeled Symbolic Method”) or Chapter 04 (“The Labeled Symbolic Method”), half of the battle has already been fought for you: the chapter heading tells you which ring to work in, whether to reach for an Ordinary Generating Function (OGF) or an Exponential Generating Function (EGF), and which algebraic engine (inv, ln, exp, or sparse prefix sums) will unlock the recurrence.

In a live contest, no problem comes with a chapter label. You are handed a raw combinatorial specification, a set of constraints (\(N \le 16\), \(N \le 60\), \(N \le 2 \times 10^5\), \(N \le 10^7\), or \(N \le 10^{13}\)), and a modulus. Your most critical skill is blind diagnostic routing: reading the structural clues in the statement to determine which generating function model applies and how to extract the answer within the time limit.

ImportantRules of Engagement for This Blind Checkpoint
  1. Zero Visible Spoilers: None of the eight problem headers or statements in Stage 1 reveal which chapter (Chapters 01–04) or which technique the problem belongs to.
  2. Work the Diagnostic First: Before opening any collapsible hint on a problem, spend 5–10 minutes classifying the problem along the Part I 3-Axis Diagnostic Rubric below. Write down on scratch paper:
    • What is the combinatorial object being counted or weighted, and what is its “size” index?
    • Does the composition of two sub-objects preserve order, forget order, relabel vertices, or depend on index differences?
    • What does the constraint regime (\(N\), \(M\), modulus \(P\)) permit algorithmically?
  3. Progressive Unmasking: If you get stuck, open Hint 1 (Diagnostic Signal) first. Only open Hint 2 (Chapter Routing & Initial GF Setup) after you have tried to translate the signal into an algebraic series yourself.

1. The Part I 3-Axis Diagnostic Rubric

NoteClick to Reveal Part I 3-Axis Diagnostic Rubric (Read AFTER Attempting Stage 1 Blind Diagnosis)

Every generating function problem in Part I (Chapters 01–04) can be routed to its canonical algebraic engine by asking three diagnostic questions in sequence.

Axis 1: Label Symmetry (OGF vs. EGF vs. Group Orbits)

Before writing a single summation sign, inspect how a composite object of size \(n\) is assembled from a left piece of size \(i\) and a right piece of size \(j = n - i\):

  1. Ordinary Generating Functions (OGFs — Chapters 01 & 03):
    • Combinatorial Signature: Each choice contributes a weight or count \(i\), and there is no relabeling of internal atoms when two pieces are combined — for each choice of the first piece (counted by \(a_i\)) and each choice of the second piece (counted by \(b_j\)), there is a unique combined configuration of total size \(i + j\).
    • Algebraic Translation: \(c_n = \sum_{i+j=n} a_i b_j = [x^n]\big(A(x) B(x)\big)\) where \(A(x) = \sum_{n \ge 0} a_n x^n\).
  2. Difference / Cross-Correlation Sums (Chapter 01):
    • Combinatorial Signature: The interaction between index \(i\) and index \(j\) depends on their directed displacement \(j - i\) or \(i - j\) rather than \(i + j\), so the sum has the form \(\sum_{i < j} a_i b_{j-i}\) or \(\sum_{i > j} a_i b_{i-j}\).
    • Algebraic Translation: A sum over \(j - i = k\) is already a standard Cauchy product \([x^j](A(x)B(x))\). A sum over \(i - j = k\) has indices moving in the same direction; reversing one array via \(a^R_k = a_{n-k}\) converts \((n - i) + (i - j) = n - j\) into a Cauchy product \([x^{n-j}](A^R(x)B(x))\).
  3. Exponential Generating Functions & Subset-Indexed Labeled \(\operatorname{SET}\) (EGFs — Chapter 04):
    • Combinatorial Signature: The object is built on \(n\) distinguishable labeled vertices \(\{1, 2, \dots, n\}\). Splitting the vertex set into a first part of size \(i\) and a second part of size \(j = n - i\) requires choosing which \(\binom{n}{i}\) labels go to the first part.
    • Algebraic Translation: \(c_n = \sum_{i+j=n} \binom{n}{i} a_i b_j \iff \frac{c_n}{n!} = \sum_{i+j=n} \frac{a_i}{i!} \frac{b_j}{j!}\), which is ordinary multiplication of \(A(x) = \sum_{n \ge 0} a_n \frac{x^n}{n!}\) and \(B(x) = \sum_{n \ge 0} b_n \frac{x^n}{n!}\).
    • Non-Symmetric Label Variant (\(N \le 20\)): If the \(N\) labeled elements are not interchangeable (because element \(i\) carries its own individual parameter \(D_i\)), univariate \(x^n/n!\) is too coarse: you apply the Greene–Wilf Boxed Product / Min-Label Component DP (Chapter 04 §4.3) directly over subsets \(S \subseteq \{1, \dots, N\}\) by anchoring the minimum label \(\min(S)\) in \(O(3^N)\) time (a preview of full \(O(N^2 2^N)\) Set Power Series \(\exp\) in Chapter 24 §24.2).
  4. Symmetry Group Orbits (Burnside / Pólya — Chapter 03):
    • Combinatorial Signature: Two configurations are considered identical if one can be obtained from the other by a permutation \(\sigma \in G\) of the underlying vertices or positions (e.g., unlabeled graphs up to vertex isomorphism \(G = S_n\), or necklaces up to cyclic rotation \(G = C_n\)).
    • Algebraic Translation: Average the number of configurations fixed by \(\sigma\) over all \(\sigma \in G\): \[|\mathcal{X} / G| = \frac{1}{|G|} \sum_{\sigma \in G} |\mathcal{X}^\sigma|,\] grouping permutations \(\sigma \in S_n\) by their cycle-type integer partition \(\lambda \vdash n\) whenever \(|\mathcal{X}^\sigma|\) depends only on cycle lengths.

Once the ring is chosen, identify the structural operator linking atomic pieces into a full configuration:

Axis 3: Sparsity & Constraint Regime (How to Extract the Coefficient)

Never call a black-box \(O(N \log N)\) NTT routine before checking the constraint regime:

  • Regime I (\(N \le 2 \times 10^5\), NTT-friendly prime \(P = 998244353\), dense polynomial): Use FFT/NTT convolution, Newton polynomial inversion inv, or ln/exp in \(O(N \log N)\) time.
  • Regime II (\(N, M \le 10^7\) or non-NTT prime \(10^9+7\), structured rational OGF): An \(O(M \log M)\) NTT will TLE or fail the modulus! Look for sparse numerator/denominator structure such as \((1 + x)^A (1 - x)^{-B} (1 - x^d)^{-C}\). You can extract coefficients in \(O(N + M)\) time via binomial expansions and linear prefix sums, or in \(O(M \log M)\) via harmonic series summation when summing over \(j \cdot d \le M\).
  • Regime III (\(N \le 10^{13}\) with lacunary/super-increasing weights, or \(N \le 60\) / \(N \le 16\) combinatorial explosions): Generating functions provide the exact algebraic identity (such as \(\prod (1 + x^{w_k})\), the Pólya cycle index over \(\lambda \vdash N\), or the \(\ln(1+x)\) connected-component sieve), while coefficient extraction uses recursive range-pruning, partition DFS (\(p(60) = 966{,}467\)), or \(O(3^N)\) min-label boxed-product subset DP.

Problem CP-I.1 (#078): RGB Balls 2 (AtCoder Typical90 #065)

Problem Statement

You have \(R\) distinguishable red balls, \(G\) distinguishable green balls, and \(B\) distinguishable blue balls. You want to choose exactly \(K\) balls in total such that:

  1. The number of chosen red balls \(r\) and chosen green balls \(g\) satisfies \(r + g \le X\).
  2. The number of chosen green balls \(g\) and chosen blue balls \(b\) satisfies \(g + b \le Y\).
  3. The number of chosen blue balls \(b\) and chosen red balls \(r\) satisfies \(b + r \le Z\).

Compute the number of valid ways to choose the \(K\) balls, modulo \(998244353\).

  • Constraints: \(1 \le R, G, B \le 2 \times 10^5\), \(1 \le K \le R + G + B\), \(0 \le X, Y, Z \le K\), modulus \(P = 998244353\).
  • Target Complexity: \(O((R + G) \log(R + G) + B)\) time and \(O(R + G + B)\) space.

Small Hand-Checkable Trace

Suppose \(R = 2, G = 2, B = 2\), \(K = 3\), and \(X = 2, Y = 2, Z = 2\). We must pick \(r \in [0, 2]\) red, \(g \in [0, 2]\) green, and \(b \in [0, 2]\) blue balls with \(r + g + b = 3\) and \(r+g \le 2, g+b \le 2, b+r \le 2\). Since \(r + g + b = 3\), the condition \(g + b \le 2\) is equivalent to \(r = 3 - (g + b) \ge 1\). By symmetry, \(r \ge 1, g \ge 1, b \ge 1\). Because \(r + g + b = 3\), the only valid count tuple is \((r, g, b) = (1, 1, 1)\), which yields \(\binom{2}{1}\binom{2}{1}\binom{2}{1} = 8\) ways.

Hint 1 — Diagnostic Signal (What structural clue is hiding in the statement?)

There are three variables \((r, g, b)\) constrained by a fixed total sum \(r + g + b = K\) and three coupled pairwise upper bounds \(r + g \le X\), \(g + b \le Y\), and \(b + r \le Z\). Whenever a fixed sum \(r + g + b = K\) is paired with \((n-1)\)-variable sum bounds like \(g + b \le Y\), you can decouple the inequality by substituting \(g + b = K - r\)!

Hint 2 — Chapter Routing & Initial Generating Function Setup
  • Routing: Chapter 01 (Section 1.3 — 2-Way Split Convolution & Coefficient Filtering).
  • Decoupling the Bounds: Using \(r + g + b = K\):
    • \(g + b \le Y \iff K - r \le Y \iff r \ge K - Y\).
    • \(b + r \le Z \iff K - g \le Z \iff g \ge K - Z\).
    • \(r + g \le X \iff K - b \le X \iff b \ge K - X\).
  • Now the constraints on \(r\), \(g\), and \(b\) are completely independent interval bounds: \[L_R = \max(0, K - Y) \le r \le R, \qquad L_G = \max(0, K - Z) \le g \le G, \qquad L_B = \max(0, K - X) \le b \le B.\]
  • Form the truncated OGFs for red, green, and blue choices: \[P_R(x) = \sum_{r=L_R}^R \binom{R}{r} x^r, \qquad P_G(x) = \sum_{g=L_G}^G \binom{G}{g} x^g, \qquad P_B(x) = \sum_{b=L_B}^B \binom{B}{b} x^b.\] (Note: Compare this with its dual problem CF 451E — Devu and Flowers, where indistinguishable items with upper bounds \(f_i\) give \(\prod_{i=1}^n \frac{1-x^{f_i+1}}{1-x}\); here the balls within each color are distinguishable, giving binomial coefficients \(\binom{R}{r}\) instead of \(1\), and there are only 3 colors with \(R, G, B \le 2 \times 10^5\).)
Hint 3 — Reverse-Engineering the Algebraic Manipulation & Extraction

We want \([x^K]\big(P_R(x) P_G(x) P_B(x)\big)\). Do we need to multiply all three polynomials via NTT? No! Once we compute the 2-way convolution \(C(x) = P_R(x) P_G(x)\) via a single NTT, the coefficient of \(x^K\) in \(C(x) P_B(x)\) is simply a linear dot product over \(s = r + g\): \[[x^K]\big(C(x) P_B(x)\big) = \sum_{s=0}^{\min(K, R+G)} [x^s]C(x) \cdot [x^{K-s}]P_B(x) = \sum_{s = \max(0, K - B)}^{\min(X, R + G)} c_s \binom{B}{K - s}.\] This saves an entire NTT call and avoids allocating a degree-\((R+G+B)\) buffer!

NoteComplete Derivation, Boundary Audit & Solution

1. Reverse-Engineering Scratchpad & Single-Step Derivation

Let \(\mathcal{S}\) be the set of valid triples \((r, g, b) \in \mathbb{Z}_{\ge 0}^3\) satisfying \(0 \le r \le R\), \(0 \le g \le G\), \(0 \le b \le B\), \(r + g + b = K\), \(r + g \le X\), \(g + b \le Y\), and \(b + r \le Z\). For a fixed triple \((r, g, b)\), there are \(\binom{R}{r}\) ways to choose the red balls, \(\binom{G}{g}\) ways to choose the green balls, and \(\binom{B}{b}\) ways to choose the blue balls. Because choices across colors are independent, the total number of valid \(K\)-subsets is: \[\text{Ans} = \sum_{(r, g, b) \in \mathcal{S}} \binom{R}{r} \binom{G}{g} \binom{B}{b}.\]

Step 1 (Eliminating Pairwise Couplings): Since \(r + g + b = K\) holds for every term in the sum, we substitute \(g + b = K - r\), \(b + r = K - g\), and \(r + g = K - b\) into the three upper-bound inequalities: \[\begin{aligned} g + b \le Y &\iff K - r \le Y \iff r \ge K - Y, \\ b + r \le Z &\iff K - g \le Z \iff g \ge K - Z, \\ r + g \le X &\iff K - b \le X \iff b \ge K - X. \end{aligned}\] Defining the lower bounds \(L_R = \max(0, K - Y)\), \(L_G = \max(0, K - Z)\), and \(L_B = \max(0, K - X)\), the coupled constraints reduce to three independent box constraints: \[r \in [L_R, R], \qquad g \in [L_G, G], \qquad b \in [L_B, B], \qquad r + g + b = K.\]

Step 2 (Encoding as an OGF Product): Define the three univariate polynomials in \(\mathbb{F}_{998244353}[x]\): \[P_R(x) = \sum_{r = L_R}^R \binom{R}{r} x^r, \qquad P_G(x) = \sum_{g = L_G}^G \binom{G}{g} x^g, \qquad P_B(x) = \sum_{b = L_B}^B \binom{B}{b} x^b.\] By the definition of polynomial multiplication (Cauchy product), the coefficient of \(x^K\) in \(P_R(x) P_G(x) P_B(x)\) sums \(\binom{R}{r}\binom{G}{g}\binom{B}{b}\) over all \(r + g + b = K\) lying in the respective intervals.

Step 3 (2-Way Split & Dot-Product Extraction): Let \(C(x) = P_R(x) P_G(x) = \sum_{s=0}^{R+G} c_s x^s\), where \(c_s = \sum_{r+g=s} [x^r]P_R(x) \cdot [x^g]P_G(x)\) counts the number of valid red-green pairs of combined size \(s = r + g\). Then the condition \(b = K - s \in [L_B, B]\) is equivalent to \(K - B \le s \le K - L_B = \min(K, X)\). Therefore: \[\text{Ans} = [x^K]\big(C(x) P_B(x)\big) = \sum_{s = \max(0, K - B)}^{\min(K, X, R + G)} c_s \binom{B}{K - s} \pmod{998244353}.\]

2. Verification on the Hand-Checkable Trace

For \(R = G = B = 2\), \(K = 3\), \(X = Y = Z = 2\):

  • \(L_R = \max(0, 3 - 2) = 1\), \(L_G = 1\), \(L_B = 1\).
  • \(P_R(x) = \binom{2}{1}x + \binom{2}{2}x^2 = 2x + x^2\), and \(P_G(x) = 2x + x^2\).
  • \(C(x) = P_R(x) P_G(x) = 4x^2 + 4x^3 + x^4\).
  • Summing over \(s \in [\max(0, 3-2), \min(3, 2, 4)] = [1, 2]\): \[\text{Ans} = c_1 \binom{2}{2} + c_2 \binom{2}{1} = 0 \cdot 1 + 4 \cdot 2 = 8.\] Matches our hand count of \(8\).
WarningFailure Mode & Remedy: Out-of-Range Lower Bounds and Degree Blowup
  1. Empty Interval Pitfall: If \(K - Y > R\) (or \(K - Z > G\), or \(K - X > B\)), the lower bound \(L_R\) exceeds the upper bound \(R\). A naive loop that allocates or indexes \(P_R[L_R \dots R]\) without checking \(L_R \le R\) will either crash or wrap around. Always return \(0\) immediately if \(L_R > R\), \(L_G > G\), or \(L_B > B\).
  2. Unnecessary 3-Way NTT: Computing \(P_R(x) P_G(x) P_B(x)\) via two full NTT convolutions requires padding to the next power of two above \(R + G + B \le 6 \times 10^5\) (\(2^{20} = 1{,}048{,}576\)). By shifting \(P_R(x)\) down by \(x^{L_R}\) and \(P_G(x)\) down by \(x^{L_G}\) before the single NTT and dot-producting with \(P_B\), the transform length is at most \(2^{\lceil \log_2((R - L_R) + (G - L_G) + 1) \rceil} \le 2^{19}\), cutting runtime and memory by more than half.
NoteAlgorithm Contract
  • Input: Integers \(R, G, B, K, X, Y, Z\) (\(0 \le X, Y, Z \le K \le R+G+B\), \(R, G, B \le 2 \times 10^5\)).
  • Preconditions: Modulus \(P = 998244353\) is NTT-friendly (\(P - 1 = 2^{23} \times 119\)). Factorials \(0!, \dots, \max(R,G,B)!\) are precomputed in \(O(\max(R,G,B))\).
  • Output: \([x^K]\big(P_R(x) P_G(x) P_B(x)\big) \bmod 998244353\).
  • Invariant: After the single NTT \(C(x) = P_R(x) P_G(x)\), for every \(s \in [0, R+G]\), \(c_s\) equals the exact number of pairs \((r, g)\) with \(r + g = s\), \(L_R \le r \le R\), and \(L_G \le g \le G\). Pairing each \(s\) with the unique \(b = K - s \in [L_B, B]\) partitions the solution space by \(s = r + g\) with zero omissions or double counts.
  • Complexity: \(O((R + G) \log(R + G) + B)\) time, \(O(R + G + B)\) auxiliary space.

Problem CP-I.2 (#144): 力 / Force (Luogu P3338 — ZJOI2014)

Problem Statement

In a 1D electrostatic field, \(n\) point charges \(q_1, q_2, \dots, q_n\) (\(q_i \in \mathbb{R}\)) are placed at integer coordinates \(1, 2, \dots, n\). The net electrostatic force on charge \(j\) is \(F_j = q_j E_j\), where the electric field strength \(E_j\) at position \(j \in \{1, 2, \dots, n\}\) is given by: \[E_j = \sum_{i = 1}^{j - 1} \frac{q_i}{(j - i)^2} - \sum_{i = j + 1}^{n} \frac{q_i}{(i - j)^2}.\] Compute \(E_1, E_2, \dots, E_n\).

  • Constraints: \(1 \le n \le 10^5\), \(0 < q_i < 10^9\). Output answers within relative or absolute error \(10^{-3}\).
  • Target Complexity: \(O(n \log n)\) time and \(O(n)\) space.

1. Reverse-Engineering Scratchpad & Single-Step Derivation

Step 1 (Burnside’s Lemma Grouped by Cycle Partition): Let \(\mathcal{G}_N\) be the set of all \(2^{\binom{N}{2}}\) labeled simple graphs on \(\{1, \dots, N\}\). Thus \(N(E)\) depends only on \(\Pi(E)\): \[N(E) = \prod_{r=1}^k \left\lfloor \frac{M}{\operatorname{lcm}(S_r)} \right\rfloor.\] Grouping the sum over \(E\) by the induced partition \(\Pi(E) = \{S_1, \dots, S_k\}\) factors the \((-1)^{|E|}\) sum across blocks: \[\text{Ans} = \sum_{\{S_1, \dots, S_k\} \vdash [N]} \prod_{r=1}^k \left( \left\lfloor \frac{M}{\operatorname{lcm}(S_r)} \right\rfloor \sum_{\substack{E_r \subseteq \binom{S_r}{2} \\ (S_r, E_r) \text{ connected}}} (-1)^{|E_r|} \right).\] To evaluate \(\mu_s = \sum_{(S, E_S) \text{ connected}} (-1)^{|E_S|}\) for \(|S| = s \ge 1\), observe that the EGF of all \((-1)^{|E|}\)-weighted graphs is: \[G(x) = \sum_{s = 0}^{\infty} \left( \sum_{E \subseteq \binom{[s]}{2}} (-1)^{|E|} \right) \frac{x^s}{s!} = \sum_{s = 0}^{\infty} (1 - 1)^{\binom{s}{2}} \frac{x^s}{s!} = 1 + x,\] since \(\binom{s}{2} = 0\) for \(s \in \{0, 1\}\) and \(\binom{s}{2} \ge 1\) for \(s \ge 2\). By the Labeled Exponential Formula \(G(x) = \exp(C(x))\): \[C(x) = \ln(1 + x) = \sum_{s = 1}^{\infty} (-1)^{s - 1} (s - 1)! \frac{x^s}{s!} \implies \mu_s = (-1)^{s - 1} (s - 1)!.\]

Step 3 (Greene–Wilf Boxed-Product Min-Label Subset DP): Define the connected weight of each non-empty subset \(S \subseteq [N]\) as: \[w(S) = (-1)^{|S| - 1} (|S| - 1)! \left( \left\lfloor \frac{M}{\operatorname{lcm}_{i \in S}(D_i)} \right\rfloor \bmod P \right) \pmod P.\] Because the multipliers \(D_1, \dots, D_N\) are distinct per index \(i\), we apply the Greene–Wilf Boxed Product / Min-Label Component Principle (Chapter 04 §4.3) on subsets \(mask \subseteq [N]\) instead of univariate sizes: to sum \(\prod_{r=1}^k w(S_r)\) over all unordered set partitions \(\{S_1, \dots, S_k\}\) of \([N]\) without counting each partition \(k!\) times, we anchor the minimum label \(v_0 = \min(mask)\) (pivot = mask & -mask) inside its unique connected block \(T \subseteq mask\): \[dp[\emptyset] = 1, \qquad dp[mask] = \sum_{\substack{T \subseteq mask \\ \min(mask) \in T}} w(T) \cdot dp[mask \setminus T].\] This computes \(dp[2^N - 1]\) in \(\sum_{k=1}^N \binom{N-1}{k-1} 2^{k-1} = \frac{1}{2} \cdot 3^N\) operations (and previews the \(O(N^2 2^N)\) Set Power Series \(\exp\) algorithm developed in Chapter 24 §24.2).

// Concise Greene-Wilf min-label subset DP anchoring lowbit(mask) to prevent k! overcounting:
dp[0] = 1;
for (int mask = 1; mask < (1 << N); ++mask) {
    int pivot = mask & -mask;          // anchor lowest set bit (min label in mask)
    int rem = mask ^ pivot;
    long long acc = 0;
    for (int sub = rem; ; sub = (sub - 1) & rem) {
        int T = sub | pivot;           // connected block containing pivot
        acc = (acc + 1LL * w[T] * dp[mask ^ T]) % MOD;
        if (sub == 0) break;
    }
    dp[mask] = acc;
}
