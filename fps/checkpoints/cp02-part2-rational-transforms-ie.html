The 3-Axis Part II Diagnostic Rubric (No Spoilers)

When faced with an unlabeled counting or summation problem, run it through three orthogonal diagnostic axes before writing down any algebra:

Axis 1: Constraint & Query Scale (\(N, K, S\) vs. Modulus \(P\))

The raw numerical magnitudes of the input parameters eliminate impossible techniques immediately:

  1. Tiny Dimension + Astronomical Target (e.g., \(n \le 20\), target degree \(\ge 10^{12}\)):
    • Dense polynomial arithmetic up to the target degree is impossible. Look for a sparse product of \(n\) factors that expands into \(2^n\) monomials, paired with an \(O(n)\) closed-form coefficient extraction on the remaining dense series.
  2. Moderate Dimension (\(N \le 2000\)) + Arbitrary / Non-NTT Prime (\(10^9+7, 10^9+9\)):
    • \(O(N^2)\) dynamic programming or \(O(N^2)\) precomputed binomial sums fit comfortably within 1 second without needing NTT. Look for a 2D combinatorial state space or a double sum that either runs in \(O(N^2)\) directly or collapses to \(O(N)\) via binomial absorption.
  3. Quasilinear Scale (\(N \le 10^5\) or \(10^6\)) + Prime Modulus:
    • \(O(N^2)\) is strictly TLE. Any double sum \(\sum_{i,j}\) must be decoupled into a 1D convolution \(\sum_{u+v=w} A_u B_v\) or collapsed in \(O(N)\) linear time via an algebraic identity.
  4. Huge Evaluation Point (\(N \le 10^9\)) + Moderate Parameter (\(K \le 10^6\)):
    • Iterating up to \(N\) is impossible, yet \(K\) is small enough for \(O(K)\) linear space and time. Check whether the target quantity \(F(N)\) is a polynomial or rational function in \(N\) of degree \(O(K)\) that can be reconstructed from \(O(K)\) small sample values.

Look at how the summation indices \((i, j, k)\) interact inside the summand:

Axis 3: Combinatorial Obstruction Keyword

Translate verbal constraints in the problem statement directly into algebraic operators:

  • “At most \(f_i\) items from box \(i\)”: Bounded geometric series \(\frac{1 - x^{f_i+1}}{1 - x}\).
  • “Exactly \(K\) occurrences / wins / matches”: Usually intractable to count directly because forbidding the remaining \(N-K\) positions from accidentally matching creates global dependencies. Relax to “designate at least \(j \ge K\) occurrences” (\(g_j\)), complete the remaining \(N-j\) elements freely, and recover \(f_K\) via Binomial Inversion.
  • “Number of labeled trees with prescribed degrees \(d_1, \dots, d_n\)”: Biject via Prüfer sequences to words of length \(n-2\) over alphabet \(\{1, \dots, n\}\) where label \(i\) appears \(d_i - 1\) times.
  • “Maximum nested depth of a bracket subsequence”: By split-point duality, equals \(\max_{0 \le i \le n} \min(\text{count of } \texttt{(} \text{ in } s[1..i],\, \text{count of } \texttt{)} \text{ in } s[i+1..n])\), occurring at the unique split point \(i\) where prefix \(\texttt{(}\) count equals suffix \(\texttt{)}\) count.

Stage 1: Spoiler-Free Blind Problem Set (CP-II.1 to CP-II.8)

Problem CP-II.1 (#085) — Devu and Flowers

  • Source: Codeforces 451E — Devu and Flowers

Problem Statement & Exact Constraints

Devu wants to decorate his garden with flowers. He has \(n\) boxes of flowers, numbered \(1\) through \(n\). All flowers inside a single box have the same color, and flowers in different boxes have distinct colors. Box \(i\) contains \(f_i\) indistinguishable flowers of color \(i\).

Devu wants to select a multiset of exactly \(s\) flowers in total from the \(n\) boxes. Two selections are considered distinct if and only if there is at least one box \(i \in \{1, \dots, n\}\) from which they take a different number of flowers. That is, we wish to count the number of integer tuples \((x_1, x_2, \dots, x_n)\) satisfying \[ \sum_{i=1}^n x_i = s \quad \text{and} \quad 0 \le x_i \le f_i \quad \text{for all } 1 \le i \le n. \] Output this count modulo \(10^9 + 7\).

  • Input Constraints:
    • \(1 \le n \le 20\)
    • \(0 \le s \le 10^{14}\)
    • \(0 \le f_i \le 10^{12}\) for each \(1 \le i \le n\)
    • Modulus: \(P = 10^9 + 7\) (prime)
  • Sample Trace (\(n = 2, s = 3, f = [1, 2]\)): The only integer pair \((x_1, x_2)\) satisfying \(x_1 + x_2 = 3\) with \(0 \le x_1 \le 1\) and \(0 \le x_2 \le 2\) is \((1, 2)\), so the output is 1.
  • Target Complexity: \(O(n 2^n)\) or \(O(2^n \log P)\) time, \(O(n)\) space.
Hint 1 — Diagnostic Signal (What to look for in the constraints)

Before looking for a generating function, ask what makes the upper bounds \(0 \le x_i \le f_i\) annoying compared to \(x_i \ge 0\). Because \(n \le 20\) is tiny while \(s \le 10^{14}\) is huge, any DP over the sum \(s\) is impossible. How can you trade the \(n\) upper-bound constraints \(x_i \le f_i\) for a small collection of simpler unbounded problems?

Hint 2 — Target Chapter Routing & Initial Setup
  • Primary Routing: Chapter 06 (§6.1 Bounded Compositions & Negative Binomial Extraction) and Chapter 08 (§8.1 Subset Inclusion–Exclusion).
  • Generating Function Setup: In \(K[[x]]\), the choice of \(x_i \in \{0, 1, \dots, f_i\}\) flowers from box \(i\) corresponds to the finite geometric polynomial \[ 1 + x + x^2 + \dots + x^{f_i} = \frac{1 - x^{f_i + 1}}{1 - x}. \] Multiplying across all \(n\) independent boxes gives the Ordinary Generating Function for the number of valid selections of size \(s\): \[ \text{Ans} = [x^s] \prod_{i=1}^n \frac{1 - x^{f_i + 1}}{1 - x} = [x^s] \left( \prod_{i=1}^n \left(1 - x^{f_i + 1}\right) \right) (1 - x)^{-n}. \]
Hint 3 — Key Algebraic Reduction & Edge Cases
  • Separating the Sparse Numerator from the Dense Denominator:
    1. The numerator \(N(x) = \prod_{i=1}^n (1 - x^{f_i+1})\) is a product of \(n \le 20\) binomials, so expanding it yields at most \(2^n\) nonzero terms indexed by subsets \(T \subseteq \{1, \dots, n\}\): \[ N(x) = \sum_{T \subseteq [n]} (-1)^{\lvert T \rvert} x^{d(T)}, \qquad \text{where } d(T) = \sum_{i \in T} (f_i + 1). \]
    2. The denominator \((1 - x)^{-n} = \sum_{m=0}^\infty \binom{m + n - 1}{n - 1} x^m\) has known coefficients for arbitrarily large \(m\).
  • Critical Modular Edge Case (\(s - d(T) \ge P\)): Because \(m = s - d(T)\) can be as large as \(10^{14} \gg P = 10^9 + 7\), you cannot precompute factorials up to \(m\). However, the lower index of \(\binom{m + n - 1}{n - 1}\) is \(n - 1 \le 19 < P\). Therefore, compute the falling factorial directly: \[ \binom{m + n - 1}{n - 1} \equiv \frac{\prod_{j=1}^{n-1} \big((m + j) \bmod P\big)}{(n - 1)!} \pmod P. \] (Note: Over \(\mathbb{Z}\), \(\binom{M}{k} = \frac{M(M-1)\cdots(M-k+1)}{k!}\) is an exact integer equality, and since \(\gcd(k!, P) = 1\) for \(k = n - 1 < P\), reducing the numerator and denominator modulo \(P\) in the localization ring \(\mathbb{Z}_{(P)}\) of rationals with denominator coprime to \(P\) is 100% exact for all integers \(M \ge 0\).)
NoteComplete Derivation, Algorithm Contract & Complexity Analysis

1. Combinatorial Model & Generating Function Formulation

We are counting weak compositions of \(s\) into \(n\) parts \((x_1, \dots, x_n)\) subject to upper capacity bounds \(0 \le x_i \le f_i\). In the formal power series ring \(\mathbb{Q}[[x]]\), let \(x^{x_i}\) record the contribution of box \(i\) to the total flower count. Since box \(i\) can contribute any integer amount in \(\{0, 1, \dots, f_i\}\), its generating polynomial is \[ P_i(x) = \sum_{x_i=0}^{f_i} x^{x_i} = \frac{1 - x^{f_i + 1}}{1 - x}. \] Here \(1 - x\) has constant term \([x^0](1 - x) = 1 \in \mathbb{Q}^\times\), so \((1 - x)^{-1}\) is a well-defined formal power series. Multiplying \(P_i(x)\) over \(i = 1, \dots, n\), the coefficient of \(x^s\) in the product counts all valid tuples \((x_1, \dots, x_n)\): \[ \text{Ans} = [x^s] \prod_{i=1}^n P_i(x) = [x^s] \left( \prod_{i=1}^n \left(1 - x^{f_i + 1}\right) \right) (1 - x)^{-n}. \]

2. Step-by-Step Coefficient Extraction (Distributivity + Negative Binomial Series)

We expand the finite product and the negative binomial series separately:

  1. Numerator Expansion (Combinatorial Meaning: Violated Box Capacities): By the distributive law of multiplication across \(n\) factors, choosing the \(-x^{f_i+1}\) term for a subset of boxes \(T \subseteq \{1, \dots, n\}\) and the \(1\) term for \([n] \setminus T\) gives \[ \prod_{i=1}^n \left(1 - x^{f_i + 1}\right) = \sum_{T \subseteq [n]} (-1)^{\lvert T \rvert} x^{d(T)}, \qquad d(T) := \sum_{i \in T} (f_i + 1). \] Combinatorially, \(d(T)\) is the minimum number of flowers required to violate the capacity bound (\(x_i \ge f_i + 1\)) simultaneously for every box \(i \in T\).

  2. Denominator Expansion (Unbounded Stars and Bars): By the negative binomial theorem in \(\mathbb{Q}[[x]]\), \[ (1 - x)^{-n} = \sum_{m=0}^\infty \binom{-n}{m} (-1)^m x^m = \sum_{m=0}^\infty \binom{m + n - 1}{n - 1} x^m. \]

  3. Cauchy Product Extraction at \([x^s]\): Applying the linearity of the coefficient extraction operator \([x^s]\): \[ \begin{aligned} [x^s] \left( \sum_{T \subseteq [n]} (-1)^{\lvert T \rvert} x^{d(T)} \right) (1 - x)^{-n} &= \sum_{T \subseteq [n]} (-1)^{\lvert T \rvert} [x^{s - d(T)}] (1 - x)^{-n} \\ &= \sum_{\substack{T \subseteq [n] \\ d(T) \le s}} (-1)^{\lvert T \rvert} \binom{s - d(T) + n - 1}{n - 1}. \end{aligned} \] Note that whenever \(d(T) > s\), the required degree \(s - d(T)\) is strictly negative, and since \((1 - x)^{-n} \in \mathbb{Q}[[x]]\) has no negative powers of \(x\), its coefficient is \(0\).

3. Hand-Checkable Concrete Trace (\(n = 2, s = 3, f = [1, 2]\))

Let \(n = 2\) boxes with capacities \(f_1 = 1, f_2 = 2\), and target \(s = 3\). Directly listing valid pairs \((x_1, x_2)\) with \(x_1 + x_2 = 3\), \(0 \le x_1 \le 1\), \(0 \le x_2 \le 2\):

  • \((x_1, x_2) = (1, 2)\) is the only valid solution, so the answer must be \(1\).

Let us verify the formula over the \(2^2 = 4\) subsets \(T \subseteq \{1, 2\}\), where \(f_1 + 1 = 2\) and \(f_2 + 1 = 3\):

  • \(T = \emptyset\): \(d(\emptyset) = 0 \le 3\), sign \(+1\), contribution \(+\binom{3 - 0 + 1}{1} = +\binom{4}{1} = +4\).
  • \(T = \{1\}\): \(d(\{1\}) = 2 \le 3\), sign \(-1\), contribution \(-\binom{3 - 2 + 1}{1} = -\binom{2}{1} = -2\).
  • \(T = \{2\}\): \(d(\{2\}) = 3 \le 3\), sign \(-1\), contribution \(-\binom{3 - 3 + 1}{1} = -\binom{1}{1} = -1\).
  • \(T = \{1, 2\}\): \(d(\{1, 2\}) = 2 + 3 = 5 > 3\), skipped (contribution \(0\)).

Summing the contributions: \(4 - 2 - 1 + 0 = 1\), matching our manual count.

WarningFailure Mode & Remedy: Evaluating \(\binom{M}{k} \bmod P\) When \(M \ge P\) vs. Negative Remainder Bugs
  1. Do Not Confuse \(M < 0\) with \(M \equiv r \pmod P\): The condition \(d(T) \le s\) is an exact integer inequality in \(\mathbb{Z}\) (representing \([x^{s-d(T)}]\) for a non-negative exponent), not a modular condition. You must test if (d_T <= s) using 64-bit signed integers (long long) before reducing \(s - d(T)\) modulo \(P\). If you reduce \(s - d(T) \pmod P\) when \(d(T) > s\), the polynomial \(\frac{M^{\underline{n-1}}}{(n-1)!}\) will evaluate at a negative integer \(M < 0\) where the algebraic polynomial \(\binom{M}{n-1}\) is nonzero even though \([x^{s-d(T)}](1-x)^{-n} = 0\)!
  2. Valid Division by \((n-1)!\): Because \(n \le 20 < P = 10^9 + 7\), \((n-1)!\) is a unit in \(\mathbb{F}_P^\times\). In the localization \(\mathbb{Z}_{(P)}\), the identity \(\binom{M}{n-1} = \frac{M(M-1)\cdots(M-n+2)}{(n-1)!}\) holds identically for all integers \(M \ge 0\), so reducing \((M - j) \bmod P\) inside the numerator product and multiplying by \(\big((n-1)!\big)^{-1} \bmod P\) is exact even when \(M \ge P\).

4. Algorithm Contract

  • Input: Integer \(n \in [1, 20]\), integer \(s \in [0, 10^{14}]\), array \(f[1..n]\) with \(f_i \in [0, 10^{12}]\).
  • Output: Number of bounded integer tuples \((x_1, \dots, x_n)\) summing to \(s\), modulo \(10^9 + 7\).
  • Core Invariant: Each bitmask \(\text{mask} \subseteq [n]\) represents the subset of boxes forced to violate their capacity bound (\(x_i \ge f_i + 1\)) with exact integer threshold \(d(\text{mask}) = \sum_{i \in \text{mask}} (f_i + 1) \le s\).
  • Precomputation: Compute \(\text{invFact} = \left((n - 1)!\right)^{P - 2} \bmod P\) in \(O(n + \log P)\) time.
  • Subset Iteration: For each bitmask \(\text{mask} \in [0, 2^n - 1]\):
    1. Compute \(d = \sum_{i : \text{bit } i \in \text{mask}} (f_i + 1)\) in 64-bit integer arithmetic (long long; maximum value \(20 \times (10^{12} + 1) \approx 2 \times 10^{13} < 2^{63} - 1\)).
    2. If \(d > s\), continue to the next mask.
    3. Let \(M = s - d + n - 1\). Compute \(\text{num} = \prod_{j=0}^{n-2} \big((M - j) \bmod P\big) \bmod P\), and \(\text{term} = \text{num} \cdot \text{invFact} \bmod P\).
    4. If \(\text{popcount}(\text{mask})\) is odd, subtract \(\text{term}\) from \(\text{ans} \bmod P\); otherwise add \(\text{term}\) to \(\text{ans} \bmod P\).
  • Complexity: \(O(n 2^n)\) time (or \(O(2^n)\) using Gray-code / DFS subset sum transitions and \(O(n)\) binomial evaluation), \(O(n)\) auxiliary space.

Problem CP-II.2 (#152) — [HEOI2016 / TJOI2016] Summation

  • Source: Luogu P4091 — [HEOI2016 / TJOI2016] 求和

Problem Statement & Exact Constraints

Given a positive integer \(n\), evaluate the double sum \[ f(n) = \sum_{i=0}^n \sum_{j=0}^i \left\{ \begin{matrix} i \\ j \end{matrix} \right\} 2^j \, j! \pmod{998244353}, \] where \(\left\{ \begin{matrix} i \\ j \end{matrix} \right\}\) denotes the Stirling number of the second kind (the number of ways to partition a set of \(i\) labeled elements into \(j\) non-empty unlabeled subsets, with the standard boundary conventions \(\left\{\begin{smallmatrix} 0 \\ 0 \end{smallmatrix}\right\} = 1\) and \(\left\{\begin{smallmatrix} i \\ 0 \end{smallmatrix}\right\} = 0\) for \(i \ge 1\)).

  • Input Constraints:
    • \(1 \le n \le 10^5\)
    • Modulus: \(P = 998244353\) (prime)
  • Sample Trace (\(n = 2\)): The row sums for \(i = 0, 1, 2\) are \(1\), \(0 + 2 = 2\), and \(0 + 2 + 8 = 10\), giving \(f(2) = 1 + 2 + 10 = 13\).
  • Target Complexity: \(O(n \log n)\) time, \(O(n)\) space.
Hint 1 — Diagnostic Signal (What to look for in the constraints)

Look at the inner sum \(\sum_{j=0}^i \left\{ \begin{matrix} i \\ j \end{matrix} \right\} 2^j j!\). Instead of evaluating \(\left\{ \begin{matrix} i \\ j \end{matrix} \right\}\) directly via an \(O(n^2)\) DP triangle, ask: what combinatorial structure on \(i\) labeled elements partitions them into \(j\) non-empty blocks and orders those \(j\) blocks (accounting for \(j!\)), and how does that help you decouple the row index \(i\) from the column index \(j\)?

Hint 2 — Target Chapter Routing & Initial Setup
  • Primary Routing: Chapter 06 (§6.4 Stirling Numbers, Falling Factorials & NTT Row/Column Convolution) and Chapter 08 (§8.1 Surjection Inclusion–Exclusion).
  • Initial Algebraic Setup:
    1. Because \(\left\{\begin{smallmatrix} i \\ j \end{smallmatrix}\right\} = 0\) whenever \(j > i\), we can extend the inner summation limit of \(j\) from \(i\) to \(n\) without changing the value of the sum, and then swap the \(i\) and \(j\) sums: \[ f(n) = \sum_{j=0}^n 2^j \sum_{i=0}^n j! \left\{ \begin{matrix} i \\ j \end{matrix} \right\}. \]
    2. Problem CP-II.4 (#252) — The Sum of the \(k\)-th Powers

  • Source: Codeforces 622F — The Sum of the k-th Powers

Problem Statement & Exact Constraints

Given two integers \(n\) and \(k\), evaluate the power sum \[ S_k(n) = \sum_{i=1}^n i^k = 1^k + 2^k + 3^k + \dots + n^k \pmod{10^9 + 7}. \]

  • Input Constraints:
    • \(1 \le n \le 10^9\)
    • \(0 \le k \le 10^6\)
    • Modulus: \(P = 10^9 + 7\) (prime)
  • Sample Trace (\(n = 4, k = 2\)): \(S_2(4) = 1^2 + 2^2 + 3^2 + 4^2 = 1 + 4 + 9 + 16 = 30\).
  • Target Complexity: \(O(k)\) or \(O(k \log k)\) time, \(O(k)\) space.
Hint 1 — Diagnostic Signal (What to look for in the constraints)

Consider \(S_k(x) = \sum_{i=1}^x i^k\) as a function of the upper limit \(x\). When \(x\) increases by \(1\), the discrete difference \(S_k(x) - S_k(x - 1) = x^k\) is a polynomial of degree \(k\). What does this imply about the algebraic form of \(S_k(x)\), and how many sample values \(S_k(0), S_k(1), \dots\) uniquely determine it for any \(x = n\)?

Hint 2 — Target Chapter Routing & Initial Setup
  • Primary Routing: Chapter 06 (§6.4 Faulhaber’s Power Sums, Multiplicative Euler Sieve for \(i^k\) & \(O(k)\) Consecutive Lagrange Interpolation).
  • Polynomial Degree via Finite Differences: Define \(S_k(0) = 0\) and \(S_k(x) = \sum_{i=1}^x i^k\) for integers \(x \ge 1\). Its forward difference is \[ \Delta S_k(x) = S_k(x + 1) - S_k(x) = (x + 1)^k, \] which is a polynomial in \(x\) of degree \(k\). Because taking the forward difference \(\Delta\) lowers the degree of any polynomial by \(1\), \(S_k(x)\) is a polynomial in \(x\) of degree \(d = k + 1\)!
  • Sampling Strategy: A polynomial of degree \(d = k + 1\) is uniquely determined by its values at \(d + 1 = k + 2\) consecutive integer points \(x = 0, 1, 2, \dots, k + 1\) (or \(x = 1, 2, \dots, k + 2\)).
Hint 3 — Key Algebraic Reduction & Edge Cases

  • \(O(k)\) Consecutive-Node Lagrange Interpolation Formula: Given sample values \(y_i = S_k(i)\) at nodes \(x_i = i\) for \(i = 0, 1, \dots, d\) (where \(d = k + 1\)), the Lagrange interpolation formula at \(x = n > d\) is \[ S_k(n) = \sum_{i=0}^{d} y_i \prod_{\substack{0 \le j \le d \\ j \neq i}} \frac{n - j}{i - j}. \] Notice how the numerator and denominator simplify for consecutive nodes \(j = 0, 1, \dots, d\):

    1. Denominator: For \(j < i\), the product of \((i - j)\) is \(i \cdot (i - 1) \cdots 1 = i!\). For \(j > i\), the product of \((i - j)\) is \((-1)(-2)\cdots(-(d - i)) = (-1)^{d - i} (d - i)!\).
    2. Numerator: Define prefix products \(\text{pref}[i] = \prod_{j=0}^{i-1} (n - j)\) and suffix products \(\text{suff}[i] = \prod_{j=i+1}^{d} (n - j)\). Then \(\prod_{j \neq i} (n - j) = \text{pref}[i] \cdot \text{suff}[i]\).

  • Linear-Time Evaluation of \(y_i = \sum_{m=1}^i m^k\): Because the function \(f(m) = m^k\) is completely multiplicative (\(f(ab) = (ab)^k = a^k b^k\)), we only need to call binary exponentiation \(p^k \bmod P\) on the \(\pi(d) = O\!\left(\frac{k}{\log k}\right)\) primes \(p \le k + 1\) inside an Euler linear sieve, achieving true \(O(k)\) total time!

  • Edge Case (\(k = 0\) and \(n \le k + 1\)):

    • When \(k = 0\), \(i^0 = 1\) for \(1 \le i \le n\) (and \(S_0(0) = 0\)), so \(S_0(n) = n\) has degree \(1 = k + 1\).
    • When \(n \le k + 1\), \((n - j)\) vanishes at \(j = n\), so simply return the precomputed sample \(y_n\) directly before building prefix/suffix products!
NoteComplete Derivation, Algorithm Contract & Complexity Analysis

1. Why \(S_k(n)\) Is a Degree-\((k+1)\) Polynomial in \(n\)

Let \(V_{k+1}\) be the \((k+2)\)-dimensional \(\mathbb{Q}\)-vector space of polynomials in \(x\) of degree at most \(k + 1\), and let \(V_{k+1}^0 = \{P \in V_{k+1} : P(0) = 0\}\) be the \((k+1)\)-dimensional subspace of polynomials with zero constant term. Consider the forward difference operator \(\Delta : V_{k+1}^0 \to V_k\) defined by \((\Delta P)(x) = P(x + 1) - P(x)\).

  • For any monomial \(x^m\) (\(m \ge 1\)), \(\Delta(x^m) = (x + 1)^m - x^m = m x^{m-1} + \binom{m}{2} x^{m-2} + \dots + 1\) has leading term \(m x^{m-1} \neq 0\) in characteristic \(0\) (and in \(\mathbb{F}_P\) whenever \(m \le k + 1 < P\)).
  • Therefore, \(\Delta : V_{k+1}^0 \to V_k\) is a linear isomorphism!
  • Since \((x + 1)^k \in V_k\), there exists a unique polynomial \(F_k(x) \in V_{k+1}^0\) such that \(F_k(x + 1) - F_k(x) = (x + 1)^k\) for all \(x\). By telescoping from \(x = 0\) to \(n - 1\), \(F_k(n) = \sum_{i=1}^n i^k = S_k(n)\) for every integer \(n \ge 0\).

Because \(k \le 10^6\) and \(P = 10^9 + 7 > k + 1\), all denominators \(1, 2, \dots, k + 1\) in the polynomial coefficients of \(F_k(x)\) are units in \(\mathbb{F}_P^\times\), so \(F_k(x) \bmod P\) is a well-defined polynomial in \(\mathbb{F}_P[x]\) of degree \(d = k + 1\).

2. Derivation of the \(O(d)\) Consecutive-Node Lagrange Formula

Let \(d = k + 1\). Since \(\deg F_k \le d\), \(F_k(x)\) is uniquely determined by its \(d + 1\) evaluations \(y_i = F_k(i) = \sum_{m=1}^i m^k \pmod P\) at the consecutive nodes \(x_i = i \in \{0, 1, \dots, d\}\) (with \(y_0 = 0\)). By Lagrange’s interpolation formula: \[ F_k(n) = \sum_{i=0}^{d} y_i \, \ell_i(n), \qquad \text{where } \ell_i(n) = \prod_{\substack{0 \le j \le d \\ j \neq i}} \frac{n - j}{i - j}. \] Splitting the product over \(j \in \{0, \dots, d\} \setminus \{i\}\) into \(j < i\) and \(j > i\):

  1. Numerator: \[ \prod_{j=0}^{i-1} (n - j) \cdot \prod_{j=i+1}^{d} (n - j) = \text{pref}[i] \cdot \text{suff}[i], \] where \(\text{pref}[0] = 1\), \(\text{pref}[i] = \text{pref}[i-1] \cdot (n - (i - 1))\) for \(1 \le i \le d\), and \(\text{suff}[d] = 1\), \(\text{suff}[i] = \text{suff}[i+1] \cdot (n - (i + 1))\) for \(d - 1 \ge i \ge 0\).
  2. Denominator: \[ \prod_{j=0}^{i-1} (i - j) \cdot \prod_{j=i+1}^{d} (i - j) = (i \cdot (i-1) \cdots 1) \cdot \big((-1)(-2)\cdots(-(d-i))\big) = (-1)^{d-i} \, i! \, (d - i)!. \]

Combining these pieces gives the division-free per-term evaluation: \[ F_k(n) = \sum_{i=0}^{d} (-1)^{d - i} \, y_i \cdot \text{pref}[i] \cdot \text{suff}[i] \cdot \text{invFact}[i] \cdot \text{invFact}[d - i] \pmod P. \]

3. Hand-Checkable Concrete Trace (\(n = 4, k = 2\))

Let \(n = 4, k = 2\). We want \(S_2(4) = 1^2 + 2^2 + 3^2 + 4^2 = 1 + 4 + 9 + 16 = 30\). Here \(d = k + 1 = 3\). We sample at \(i = 0, 1, 2, 3\):

  • \(y_0 = 0\), \(y_1 = 1^2 = 1\), \(y_2 = 1 + 4 = 5\), \(y_3 = 5 + 9 = 14\).
  • For \(n = 4\), the node differences \((4 - j)\) for \(j = 0, 1, 2, 3\) are \(4, 3, 2, 1\).
    • \(i = 0\): \(y_0 = 0 \implies \text{term}_0 = 0\).
    • \(i = 1\): \((-1)^{3-1} y_1 \frac{(4-0)(4-2)(4-3)}{1! \, 2!} = (+1) \cdot 1 \cdot \frac{4 \cdot 2 \cdot 1}{2} = +4\).
    • \(i = 2\): \((-1)^{3-2} y_2 \frac{(4-0)(4-1)(4-3)}{2! \, 1!} = (-1) \cdot 5 \cdot \frac{4 \cdot 3 \cdot 1}{2} = -30\).
    • \(i = 3\): \((-1)^{3-3} y_3 \frac{(4-0)(4-1)(4-2)}{3! \, 0!} = (+1) \cdot 14 \cdot \frac{4 \cdot 3 \cdot 2}{6} = +56\).
  • Sum: \(0 + 4 - 30 + 56 = 30\).
WarningFailure Mode & Remedy: Characteristic Collapse (\(P \le k + 1\)) & \(0/0\) when \(n \le d\)
  1. Early Return for \(n \le k + 1\): If you do not write the prefix/suffix products carefully and try to compute \(\prod_{j=0}^d (n - j)\) first and then divide by \((n - i)\), the total product is \(0\) whenever \(0 \le n \le d\), causing a \(0 \cdot 0^{-1}\) bug! Either return \(y_n\) immediately when \(n \le d\), or use the division-free \(\text{pref}[i] \cdot \text{suff}[i]\) arrays (which work even when \(n \le d\)).
  2. Characteristic Limit: Consecutive Lagrange interpolation on \(d + 1 = k + 2\) points divides by \(d! = (k + 1)!\), which requires \(P > k + 1\). Here \(P = 10^9 + 7 > 10^6 + 1\), so \((k+1)!\) is invertible.

4. Algorithm Contract

  • Input: \(n \in [1, 10^9]\), \(k \in [0, 10^6]\), prime \(P = 10^9 + 7\).
  • Output: \(S_k(n) = \sum_{i=1}^n i^k \bmod P\).
  • Core Invariant: \(F_k(x) = \sum_{i=1}^x i^k\) is the unique polynomial of degree \(d = k + 1\) with \(F_k(0) = 0\) and forward difference \(\Delta F_k(x) = (x + 1)^k\), determined by \(d + 1\) consecutive evaluations \(y_0, \dots, y_d\).
  • Step 1 (\(O(k)\) Multiplicative Sieve for \(m^k\) and Sample Values \(y_0..y_d\)): Set \(d = k + 1\), \(y_0 = 0\), \(\text{pw}[1] = 1\). Run a linear sieve up to \(d\): for each prime \(p \le d\), compute \(\text{pw}[p] = p^k \bmod P\) in \(O(\log k)\) time, and for composite \(m = i \cdot p\), set \(\text{pw}[i \cdot p] = \text{pw}[i] \cdot \text{pw}[p] \bmod P\). Accumulate \(y_i = (y_{i-1} + \text{pw}[i]) \bmod P\). (Since \(\pi(d) = O(k / \log k)\), the total time for all prime exponentiations is \(O\!\left(\frac{k}{\log k} \cdot \log k\right) = O(k)\)!)
  • Step 2 (Short-Circuit): If \(n \le d\), return \(y_n\).
  • Step 3 (\(O(k)\) Lagrange Evaluation):
    1. Precompute \(\text{invFact}[0..d]\) in \(O(d)\) time.
    2. Compute \(\text{pref}[0..d]\) and \(\text{suff}[0..d]\) in \(O(d)\) time.
    3. Sum \((-1)^{d-i} y_i \cdot \text{pref}[i] \cdot \text{suff}[i] \cdot \text{invFact}[i] \cdot \text{invFact}[d-i] \bmod P\) for \(0 \le i \le d\).
  • Complexity: \(\Theta(k)\) time and \(\Theta(k)\) space.

Problem CP-II.5 (#100) — Epic Convolution

  • Source: Codeforces 1054H — Epic Convolution

Problem Statement & Exact Constraints

You are given two integer arrays \(a_0, a_1, \dots, a_{n-1}\) and \(b_0, b_1, \dots, b_{m-1}\), together with an integer base \(c\). Evaluate the bilinear sum \[ S = \sum_{i=0}^{n-1} \sum_{j=0}^{m-1} a_i \, b_j \, c^{i^2 j^3} \pmod{490019}. \] Here \(0^0 = 1\), so whenever \(i = 0\) or \(j = 0\), the exponent \(i^2 j^3 = 0\) and \(c^{i^2 j^3} = c^0 = 1\).

  • Input Constraints:
    • \(1 \le n, m \le 10^5\)
    • \(0 \le a_i, b_j \le 490018\)
    • \(1 \le c \le 490018\)
    • Modulus: \(P = 490019\) (prime, with \(P - 1 = 490018 = 2 \times 491 \times 499\))
  • Sample Trace (\(P = 5, c = 2, a = [1, 2, 1], b = [1, 1, 2]\)): For \(i, j \in \{0, 1, 2\}\), the row sums for \(i = 0, 1, 2\) are \(4, 10, 4\), giving \(4 + 10 + 4 = 18 \equiv 3 \pmod 5\).
  • Target Complexity: \(O((n + m + P) \log P)\) time and \(O(P)\) space.
Hint 1 — Diagnostic Signal (What to look for in the constraints)

Why did the problem setter choose the bizarre modulus \(P = 490019\) instead of \(998244353\) or \(10^9 + 7\)? First, confirm that \(P = 490019\) is prime (\(\sqrt{490019} \approx 700\), and \(P - 1 = 490018 = 2 \times 491 \times 499\)). Because \(P\) is prime and \(1 \le c \le P - 1\), Fermat’s Little Theorem guarantees \(c^{P-1} \equiv 1 \pmod P\). Therefore, the huge exponent \(i^2 j^3\) only matters modulo \(P - 1 = 490018\)! Even better, the product \(i^2 j^3 \bmod (P - 1)\) separates into a function of \(i\) alone (\(I = i^2 \bmod (P - 1)\)) times a function of \(j\) alone (\(J = j^3 \bmod (P - 1)\)).

Hint 2 — Target Chapter Routing & Initial Setup
  • Primary Routing: Chapter 07 (§7.3 Bluestein’s Chirp-\(Z\) Transform & Index-Calculus Reductions).
  • Step 1 (Exponent Bucketing modulo \(P - 1\)): Since \(c \not\equiv 0 \pmod P\), for every \(i, j\) we have \[ c^{i^2 j^3} \equiv c^{(i^2 \bmod (P-1)) \cdot (j^3 \bmod (P-1))} \pmod P. \] Define two bucketed arrays \(A[0..P-2]\) and \(B[0..P-2]\) of length \(M = P - 1 = 490018\) by accumulating \[ A_I = \sum_{\substack{0 \le i < n \\ i^2 \bmod (P-1) = I}} a_i \pmod P, \qquad B_J = \sum_{\substack{0 \le j < m \\ j^3 \bmod (P-1) = J}} b_j \pmod P. \] Now the original sum becomes a clean bilinear form in \(I\) and \(J\): \[ S = \sum_{I=0}^{P-2} \sum_{J=0}^{P-2} A_I \, B_J \, c^{I \cdot J} \pmod P. \]
Hint 3 — Key Algebraic Reduction & Edge Cases

How do you turn the multiplicative exponent \(I \cdot J\) into an additive convolution index \(I + J\)? You have two canonical routes from Chapter 07:

  • Route 1 (Bluestein’s Chirp-\(Z\) Identity — Direct 1D Convolution): Use the triangular-number identity \[ I \cdot J = \binom{I + J}{2} - \binom{I}{2} - \binom{J}{2}. \] Because \(\binom{k}{2} = \frac{k(k-1)}{2}\) is an integer for every integer \(k \ge 0\), no division by \(2\) modulo \(P - 1\) is needed! Rewrite \(c^{IJ}\) as \[ c^{IJ} = c^{\binom{I+J}{2}} \cdot c^{-\binom{I}{2}} \cdot c^{-\binom{J}{2}} \pmod P. \] Then \(S = \sum_{K=0}^{2P-4} c^{\binom{K}{2}} \sum_{I+J=K} \left(A_I c^{-\binom{I}{2}}\right)\left(B_J c^{-\binom{J}{2}}\right) \pmod P\), which is a single 1D polynomial multiplication of degree \(P - 2 = 490017\)! (Since \(P = 490019\) is small, max coefficient before mod is \((P-1) P^2 \approx 1.18 \times 10^{17} < 2^{57}\), or after modding inputs by \(P\), max convolution sum is \(490018 \times 490018^2 \approx 1.17 \times 10^{17}\), which fits inside a 2-prime NTT or long double / split-radix FFT!)
  • Route 2 (CRT + 2D Index-Calculus over \(P - 1 = 2 \times 491 \times 499\)): Notice why \(P - 1 = 2 \times 491 \times 499\) was chosen: \(491\) and \(499\) are both primes! You can separate the \(i = 0\) or \(j = 0\) terms (or indices divisible by \(491\) or \(499\)), and map \(\mathbb{Z}_{491}^\times \times \mathbb{Z}_{499}^\times\) via primitive roots to a \(2 \times 490 \times 498\) 3D cyclic convolution of tiny length \(\approx 2.4 \times 10^5\). However, Route 1 (Bluestein’s CZT) avoids all zero-divisor casework of \(491 \mid I\) and \(499 \mid I\) completely!
NoteComplete Derivation, Algorithm Contract & Complexity Analysis

1. The Diagnostic Signal & Reverse-Engineering Scratchpad

  • Diagnostic Signal: The summand contains \(c^{i^2 j^3} \pmod P\) where \(P = 490019\) is a moderate prime (\(P \approx 5 \times 10^5\)). Whenever a prime modulus \(P \le 10^6\) appears with a variable exponent, Fermat’s Little Theorem (\(c^{P-1} \equiv 1 \pmod P\)) compresses the exponent space from \(\mathbb{Z}\) down to \(\mathbb{Z}_{P-1}\).
  • Reverse-Engineering Scratchpad: Once we compress \(I = i^2 \bmod (P - 1)\) and \(J = j^3 \bmod (P - 1)\), we have \[ S = \sum_{I=0}^{P-2} \sum_{J=0}^{P-2} A_I B_J c^{I J} \pmod P. \] To convert the product \(IJ\) in the exponent into a sum \(I + J\) suitable for Cauchy convolution, we cannot simply write \(2IJ = (I+J)^2 - I^2 - J^2\) and divide the exponent by \(2\) modulo \(P - 1\), because \(P - 1 = 490018\) is even (\(\gcd(2, P - 1) = 2 \neq 1\), so \(2^{-1} \bmod (P - 1)\) does not exist!). Instead, we use Bluestein’s Binomial Identity over the integers \(\mathbb{Z}\): \[ I \cdot J = \binom{I + J}{2} - \binom{I}{2} - \binom{J}{2} \qquad \text{for all } I, J \in \mathbb{Z}_{\ge 0}. \] Why does this bypass the parity obstruction? Because for every integer \(k\), \(k(k-1)\) is an even integer in \(\mathbb{Z}\), so \(\binom{k}{2} = \frac{k(k-1)}{2} \in \mathbb{Z}\) is already an exact integer before we ever reduce modulo \(P - 1\)!

2. Step-by-Step Algebraic Derivation

  1. Fermat Reduction & Bucketing: Since \(1 \le c \le P - 1\) and \(P = 490019\) is prime, \(\gcd(c, P) = 1\) and \(c^{P-1} \equiv 1 \pmod P\). For each \(0 \le i < n\) and \(0 \le j < m\), let \[ I(i) = i^2 \bmod (P - 1), \qquad J(j) = j^3 \bmod (P - 1). \] Then \(i^2 j^3 \equiv I(i) J(j) \pmod{P - 1}\), so \(c^{i^2 j^3} \equiv c^{I(i) J(j)} \pmod P\). Grouping terms with the same values of \(I \in [0, P-2]\) and \(J \in [0, P-2]\) gives \[ A_I = \sum_{I(i) = I} a_i \bmod P, \qquad B_J = \sum_{J(j) = J} b_j \pmod P. \]

  2. Bluestein Decoupling: For any \(I, J \in \{0, 1, \dots, P - 2\}\), the identity \(\binom{I+J}{2} = \frac{(I+J)(I+J-1)}{2} = \frac{I(I-1)}{2} + \frac{J(J-1)}{2} + IJ = \binom{I}{2} + \binom{J}{2} + IJ\) holds in \(\mathbb{Z}\). Since \(c \in \mathbb{F}_P^\times\) is invertible modulo \(P\), let \(c^{-1} = c^{P-2} \bmod P\). Then in \(\mathbb{F}_P\): \[ c^{IJ} \equiv c^{\binom{I+J}{2} \bmod (P-1)} \cdot (c^{-1})^{\binom{I}{2} \bmod (P-1)} \cdot (c^{-1})^{\binom{J}{2} \bmod (P-1)} \pmod P. \] Define modified coefficient arrays \(\widetilde{A}_I\) and \(\widetilde{B}_J\) for \(0 \le I, J \le P - 2\): \[ \widetilde{A}_I = A_I \cdot (c^{-1})^{\binom{I}{2} \bmod (P-1)} \bmod P, \qquad \widetilde{B}_J = B_J \cdot (c^{-1})^{\binom{J}{2} \bmod (P-1)} \bmod P. \]

  3. Cauchy Convolution: Let \(\widetilde{C}(x) = \widetilde{A}(x) \widetilde{B}(x) = \sum_{K=0}^{2P-4} \widetilde{C}_K x^K\), where \(\widetilde{C}_K = \sum_{I+J=K} \widetilde{A}_I \widetilde{B}_J\). Then \[ S = \sum_{K=0}^{2P-4} \left( \widetilde{C}_K \bmod P \right) \cdot c^{\binom{K}{2} \bmod (P-1)} \pmod P. \]

3. Hand-Checkable Concrete Trace (\(P = 5, c = 2, n = m = 3\))

    • \(I = i^2 \bmod 4\): \(I(0) = 0, I(1) = 1, I(2) = 0 \implies A = [a_0 + a_2, a_1, 0, 0] = [2, 2, 0, 0]\).

    • Convolution \(\widetilde{C} = \widetilde{A} * \widetilde{B}\): \(\widetilde{C}_0 = 6 \equiv 1\), \(\widetilde{C}_1 = 2 + 6 = 8 \equiv 3\), \(\widetilde{C}_2 = 2\).
    • Re-weighting by \(c^{\binom{K}{2}} = 2^{\binom{K}{2}}\):
      • \(K = 0\): \(\widetilde{C}_0 \cdot 2^0 = 1 \cdot 1 = 1\).
      • \(K = 1\): \(\widetilde{C}_1 \cdot 2^0 = 3 \cdot 1 = 3\).
      • \(K = 2\): \(\widetilde{C}_2 \cdot 2^1 = 2 \cdot 2 = 4\).

WarningFailure Mode & Remedy: Using \(\frac{k^2}{2}\) Instead of \(\binom{k}{2}\) When \(P - 1\) Is Even

  • Input: Arrays \(a[0..n-1]\), \(b[0..m-1]\), base \(c \in [1, 490018]\), prime \(P = 490019\).

Problem CP-II.6 (#029) — Yet Another RGB Sequence

Problem Statement & Exact Constraints

You are given four non-negative integers \(R, G, B,\) and \(K\). Count the number of strings of length \(R + G + B\) consisting of:

  • exactly \(R\) occurrences of the character R,
  • exactly \(G\) occurrences of the character G,
  • exactly \(B\) occurrences of the character B, and
  • exactly \(K\) occurrences of the contiguous two-character substring RG.

  • Input Constraints:
    • \(1 \le R, G, B \le 10^6\)
    • \(0 \le K \le \min(R, G)\)
    • Modulus: \(P = 998244353\)

Hint 1 — Diagnostic Signal (What to look for in the constraints)

We have letter counts \(R, G, B\) and an exact condition on the number of 'RG' substrings (\(= K\)). Why is it much easier to count strings where \(j\) chosen 'RG' pairs are glued together into single super-tokens \(\texttt{X} = \texttt{RG}\), while the remaining \(R - j\) 'R's and \(G - j\) 'G's are placed with no restriction at all?

Hint 2 — Target Chapter Routing & Initial Setup

  • Primary Routing: Chapter 08 (§8.1 Binomial Inversion “At Least \(j\)” \(\to\) “Exactly \(K\)” & §8.4 Non-Overlapping Substring Contraction) and Chapter 06 (§6.1 Multinomial & Vandermonde Identities).

  • Step 1 (The Relaxed Count \(g_j\)): Because two occurrences of RG cannot share any characters, selecting a set of \(j\) occurrences of RG in a valid string is equivalent to fusing \(j\) copies of R and \(j\) copies of G into \(j\) copies of a new atomic letter X. The remaining free characters are:

    • \(j\) copies of X,
    • \(R - j\) copies of R,
    • \(G - j\) copies of G,
    • \(B\) copies of B. The total number of tokens is \(j + (R - j) + (G - j) + B = R + G + B - j\), so the number of ways to arrange them with \(j\) designated occurrences of RG is the multinomial coefficient \[ g_j = \frac{(R + G + B - j)!}{j! \, (R - j)! \, (G - j)! \, B!}. \]
Hint 3 — Key Algebraic Reduction & Edge Cases

You can finish the problem in \(O(R + G + B)\) time via either of two equivalent routes:

  • Route A (Binomial Inversion from Chapter 08): If a string actually contains \(m\) occurrences of RG, it is counted \(\binom{m}{j}\) times in \(g_j\) (once for each subset of \(j\) occurrences we choose to fuse into X). Thus \[ g_j = \sum_{m=j}^{\min(R, G)} \binom{m}{j} f_m \quad \Longleftrightarrow \quad f_K = \sum_{j=K}^{\min(R, G)} (-1)^{j - K} \binom{j}{K} g_j. \]

  • Route B (Direct Combinatorial Insertion / Vandermonde Collapse): Notice that if we plug \(g_j\) into the Binomial Inversion sum, the sum over \(j\) actually collapses to a single product of binomial coefficients! Combinatorially:

    1. Fuse the exact \(K\) required copies of RG into \(K\) copies of X.
    2. Arrange all tokens except the \(R - K\) leftover Rs: that is, arrange \(K\) copies of X, \(G - K\) copies of G, and \(B\) copies of B. There are \(\frac{(G + B)!}{K! \, (G - K)! \, B!}\) such arrangements of length \(G + B\).
    3. Now insert the remaining \(R - K\) copies of R into this string of length \(G + B\). We cannot place any R immediately before one of the \(G - K\) free Gs (or we would create a new RG!). Of the \(G + B + 1\) gaps (with repetition allowed), the \(G - K\) gaps immediately preceding the \(G - K\) free Gs are forbidden, leaving \((G + B + 1) - (G - K) = B + K + 1\) allowed gaps! By stars-and-bars, placing \(R - K\) identical Rs into \(B + K + 1\) allowed gaps takes \(\binom{(R - K) + (B + K + 1) - 1}{R - K} = \binom{R + B}{R - K}\) ways!
NoteComplete Derivation, Algorithm Contract & Complexity Analysis

1. The Diagnostic Signal & Reverse-Engineering Scratchpad

  • Diagnostic Signal: We want to count arrangements of a multiset \(\{ \texttt{R}^R, \texttt{G}^G, \texttt{B}^B \}\) containing exactly \(K\) occurrences of a contiguous block RG. The pattern RG has period \(2\) and zero self-overlap (its autocorrelation polynomial in Chapter 08 is \(A_{\texttt{RG}}(x) = 1\), because a prefix R cannot match a suffix G).
  • Reverse-Engineering Scratchpad: Whenever target patterns cannot overlap, \(j\) simultaneous occurrences simply consume \(j\) disjoint copies of the pattern’s constituent letters (R and G) and replace each pair with a single fused token X. That makes the “at least \(j\) designated occurrences” count \(g_j\) a single multinomial coefficient, which Binomial Inversion converts into \(f_K\) immediately.

2. Derivation 1: Cluster Contraction + Binomial Inversion

Let \(f_m\) be the number of strings of \(\{\texttt{R}^R, \texttt{G}^G, \texttt{B}^B\}\) containing exactly \(m\) occurrences of RG. For each \(0 \le j \le \min(R, G)\), consider pairs \((S, T)\) where \(S\) is a valid string and \(T\) is a chosen subset of \(j\) occurrences of RG inside \(S\).

  1. Counting by \(S\) first: A string \(S\) with \(m\) occurrences of RG has \(\binom{m}{j}\) subsets \(T\) of size \(j\), so the number of pairs \((S, T)\) is \(\sum_{m=j}^{\min(R, G)} \binom{m}{j} f_m\).
  2. Counting by \(T\) first (Token Contraction): Contracting the \(j\) chosen occurrences of RG into \(j\) tokens of X establishes a bijection between pairs \((S, T)\) and words of length \(R + G + B - j\) composed of \(j\) Xs, \(R - j\) Rs, \(G - j\) Gs, and \(B\) Bs. Thus: \[ g_j = \frac{(R + G + B - j)!}{j! \, (R - j)! \, (G - j)! \, B!} = \sum_{m=j}^{\min(R, G)} \binom{m}{j} f_m. \]

Applying Binomial Inversion (Chapter 08, Theorem 8.1) to invert the upper-triangular matrix \(\left[\binom{m}{j}\right]\) gives: \[ f_K = \sum_{j=K}^{\min(R, G)} (-1)^{j - K} \binom{j}{K} \frac{(R + G + B - j)!}{j! \, (R - j)! \, (G - j)! \, B!}. \]

3. Derivation 2: Algebraic Equivalence to the Closed-Form Product

We can also collapse the sum over \(j\) algebraically using Chapter 06 coefficient extraction! Notice that \(\binom{j}{K} \frac{1}{j!} = \frac{1}{K! (j - K)!}\). Substituting \(r = j - K\) (so \(j = K + r\) and \(0 \le r \le \min(R, G) - K\)): \[ \begin{aligned} f_K &= \frac{1}{K! \, B! \, (G - K)!} \sum_{r=0}^{\min(R, G) - K} (-1)^r \binom{G - K}{r} \frac{(R + G + B - K - r)!}{(R - K - r)!} \\ &= \frac{(G + B)!}{K! \, B! \, (G - K)!} \sum_{r=0}^{\min(R, G) - K} (-1)^r \binom{G - K}{r} \binom{R + G + B - K - r}{G + B}. \end{aligned} \] Since \(\binom{G - K}{r} = [x^r] (1 + x)^{G - K}\) and \(\binom{R + G + B - K - r}{G + B} = [x^{R - K - r}] (1 - x)^{-(G + B + 1)}\): \[ \begin{aligned} \sum_{r \ge 0} (-1)^r \binom{G - K}{r} \binom{R + G + B - K - r}{G + B} &= [x^{R - K}] (1 - x)^{G - K} (1 - x)^{-(G + B + 1)} \\ &= [x^{R - K}] (1 - x)^{-(B + K + 1)} \\ &= \binom{(R - K) + (B + K + 1) - 1}{R - K} = \binom{R + B}{R - K}. \end{aligned} \] Thus the entire alternating sum collapses to the single non-negative closed form: \[ f_K = \frac{(G + B)!}{K! \, (G - K)! \, B!} \binom{R + B}{R - K}. \]

  • Check Formula 2 (Closed Form): \[ f_1 = \frac{(1 + 1)!}{1! \, 0! \, 1!} \binom{2 + 1}{2 - 1} = 2 \cdot \binom{3}{1} = 6. \] Both formulas agree with the manual enumeration.
WarningFailure Mode & Remedy: Applying Naive Token Contraction to Self-Overlapping Patterns

Why did \(g_j = \frac{(R+G+B-j)!}{j!(R-j)!(G-j)!B!}\) work without a cluster DP? Because the pattern \(P = \texttt{RG}\) has no non-trivial border (the prefix R does not match the suffix G).   • Core Invariant: Because RG is border-free (\(A_{\texttt{RG}}(x) = 1\)), \(j\) designated occurrences of RG are pairwise disjoint and contract bijectively into \(j\) atomic tokens X, making \(g_j = \binom{R+G+B-j}{j, R-j, G-j, B}\) the exact binomial-inversion dual of \(f_m\).

Problem CP-II.7 (#162) — Nothing Left to Fear

Problem Statement & Exact Constraints

You are given two integer arrays \(A = (A_1, A_2, \dots, A_n)\) and \(B = (B_1, B_2, \dots, B_n)\) of length \(n\), where all \(2n\) integers across \(A\) and \(B\) are pairwise distinct. You want to pair each element of \(A\) bijectively with an element of \(B\) via a permutation \(\pi \in S_n\).

A pairing \(\pi \in S_n\) is called valid if the number of indices \(i \in \{1, \dots, n\}\) with \(A_i > B_{\pi(i)}\) exceeds the number of indices \(i \in \{1, \dots, n\}\) with \(A_i < B_{\pi(i)}\) by exactly \(k\): \[ \#\{1 \le i \le n : A_i > B_{\pi(i)}\} - \#\{1 \le i \le n : A_i < B_{\pi(i)}\} = k. \] Count the number of valid permutations \(\pi \in S_n\) modulo \(10^9 + 9\).

  • Input Constraints:
    • \(1 \le n \le 2000\)
    • \(0 \le k \le n\)
    • \(1 \le A_i, B_i \le 10^9\), all \(2n\) values pairwise distinct
    • Modulus: \(P = 10^9 + 9\) (prime)
  • Sample Trace (\(n = 3, k = 1, A = [2, 4, 6], B = [1, 3, 5]\)): A valid pairing needs \(m = \frac{3 + 1}{2} = 2\) wins (\(A_i > B_{\pi(i)}\)) and \(1\) loss; among the \(3! = 6\) permutations of \(B\), 4 pairings achieve \(2\) wins—namely \((1, 5, 3)\), \((3, 1, 5)\), \((5, 1, 3)\), and \((5, 3, 1)\)—so the output is 4.
  • Target Complexity: \(O(n^2)\) time and \(O(n)\) (or \(O(n^2)\)) space.
Hint 1 — Diagnostic Signal (What to look for in the constraints)

Since all \(2n\) numbers are distinct, no tie is possible, so \(\text{wins} - (n - \text{wins}) = k\) uniquely fixes the exact number of wins \(m = \frac{n + k}{2}\). Why is it hard to enforce both “\(j\) designated pairs are wins” and “the remaining \(n - j\) pairs are non-wins” simultaneously, and what happens if we only enforce the \(j\) wins and pair the remaining \(n - j\) elements arbitrarily?

Hint 2 — Target Chapter Routing & Initial Setup

  • Step 1 (Sorting to Form a Ferrers Board): Sort \(A_1 < A_2 < \dots < A_n\) and \(B_1 < B_2 < \dots < B_n\) in ascending order. (Sorting \(A\) and \(B\) merely relabels the domain and codomain of \(\pi \in S_n\), which preserves the number of bijections!) For each \(1 \le i \le n\), let \[ c_i = \#\{1 \le r \le n : B_r < A_i\} \] be the number of elements in \(B\) strictly smaller than \(A_i\). 1. The Diagnostic Signal & Reverse-Engineering Scratchpad

  • Diagnostic Signal: We want the number of bijections \(\pi \in S_n\) satisfying a dominance relation \(A_i > B_{\pi(i)}\) on exactly \(m = \frac{n + k}{2}\) indices, with \(n \le 2000\).

  • Reverse-Engineering Scratchpad: Why is counting “exactly \(m\) wins and \(n - m\) losses” directly hard, while counting “at least \(j\) designated wins” is easy?

    • If we sort \(A_1 < \dots < A_n\) and \(B_1 < \dots < B_n\), the set of “winning” pairs \(\{(i, r) : B_r < A_i\}\) forms a Ferrers board where row \(i\) consists of the prefix of columns \(\{1, 2, \dots, c_i\}\) with \(c_1 \le c_2 \le \dots \le c_n\).
    • On a Ferrers board, any choice of \(j - 1\) winning pairs from rows \(1, \dots, i - 1\) occupies \(j - 1\) columns in \(\{1, \dots, c_{i-1}\} \subseteq \{1, \dots, c_i\}\). We do not need to know which specific columns were occupied—only how many (\(j - 1\)) were occupied!
    • By contrast, if we tried to place both “winning” rooks (\(r \le c_i\)) and “losing” rooks (\(r > c_i\)) in the same DP, a losing rook placed in row \(i' < i\) at some column \(r \in (c_{i'}, c_i]\) would block a winning column for row \(i\), destroying the state compression!
    • Therefore, we must use Binomial Inversion to eliminate the “losing” constraint: count only placements of \(j\) winning rooks (\(r_j = dp[n][j]\)), multiply by \((n - j)!\) to assign the remaining \(n - j\) rows arbitrarily, and invert!

2. Step-by-Step Mathematical Derivation

  1. Parity & Range Reduction: Since all \(2n\) values in \(A\) and \(B\) are distinct, for any \(\pi \in S_n\), let \(W(\pi) = \#\{i : A_i > B_{\pi(i)}\}\) and \(L(\pi) = \#\{i : A_i < B_{\pi(i)}\}\). Then \[ W(\pi) + L(\pi) = n \quad \text{and} \quad W(\pi) - L(\pi) = k \quad \Longleftrightarrow \quad W(\pi) = \frac{n + k}{2}. \] If \(n + k \not\equiv 0 \pmod 2\) or \(k > n\), no such permutation exists (output \(0\)). Otherwise, set \(m = \frac{n + k}{2} \in \{0, 1, \dots, n\}\).

  2. Ferrers Board Rook Polynomial Recurrence: Sort \(A\) and \(B\) in strictly increasing order, and let \(c_i = \#\{r \in [1, n] : B_r < A_i\}\). Let \(dp[i][j]\) denote the number of ways to select \(j\) rows from \(\{1, \dots, i\}\) and assign each selected row \(u\) a distinct column \(\pi(u) \in \{1, \dots, c_u\}\).

    • Base case: \(dp[0][0] = 1\), and \(dp[0][j] = 0\) for \(j \ge 1\).
    • Transition for row \(i \in \{1, \dots, n\}\) and \(0 \le j \le i\):
      • Do not select row \(i\): \(dp[i - 1][j]\) ways.
      • Select row \(i\): We first place \(j - 1\) rooks in rows \(1, \dots, i - 1\) in \(dp[i - 1][j - 1]\) ways. Since \(c_1 \le \dots \le c_{i-1} \le c_i\), all \(j - 1\) previously chosen columns lie inside \(\{1, \dots, c_i\}\), leaving \(c_i - (j - 1)\) valid choices in \(\{1, \dots, c_i\}\) for row \(i\). Thus: \[ dp[i][j] = dp[i - 1][j] + (c_i - j + 1) \, dp[i - 1][j - 1] \qquad (1 \le j \le c_i). \]

  3. Overcounting Sequence \(g_j\) and Binomial Inversion: For \(0 \le j \le n\), let \(g_j = dp[n][j] \cdot (n - j)!\). This counts pairs \((\pi, T)\) where \(\pi \in S_n\) is a complete permutation, \(T \subseteq [n]\) has size \(\lvert T \rvert = j\), and \(A_u > B_{\pi(u)}\) for all \(u \in T\). Every permutation \(\pi\) with \(W(\pi) = s\) contains \(\binom{s}{j}\) valid subsets \(T\) of size \(j\), so \[ g_j = \sum_{s=j}^n \binom{s}{j} f_s \quad \Longleftrightarrow \quad f_m = \sum_{j=m}^n (-1)^{j - m} \binom{j}{m} g_j \pmod{10^9 + 9}. \]

3. Hand-Checkable Concrete Trace (\(n = 3, k = 1, A = [2, 4, 6], B = [1, 3, 5]\))

  • Sorted arrays: \(A = [2, 4, 6]\), \(B = [1, 3, 5]\).
  • Threshold counts \(c_i = \#\{B_r < A_i\}\):
    • \(c_1 = \#\{B_r < 2\} = 1\) (\(B_1 = 1\)).
    • \(c_2 = \#\{B_r < 4\} = 2\) (\(B_1 = 1, B_2 = 3\)).
    • \(c_3 = \#\{B_r < 6\} = 3\) (\(B_1 = 1, B_2 = 3, B_3 = 5\)).
  • Rook DP table \(dp[i][j]\):
    • \(i = 0\): \([1, 0, 0, 0]\)
    • \(i = 1\) (\(c_1 = 1\)): \(dp[1][0] = 1\), \(dp[1][1] = 0 + 1 \cdot 1 = 1\). Row: \([1, 1, 0, 0]\).
    • \(i = 2\) (\(c_2 = 2\)): \(dp[2][0] = 1\), \(dp[2][1] = 1 + 2 \cdot 1 = 3\), \(dp[2][2] = 0 + (2 - 1) \cdot 1 = 1\). Row: \([1, 3, 1, 0]\).
    • \(i = 3\) (\(c_3 = 3\)): \(dp[3][0] = 1\), \(dp[3][1] = 3 + 3 \cdot 1 = 6\), \(dp[3][2] = 1 + (3 - 1) \cdot 3 = 7\), \(dp[3][3] = 0 + (3 - 2) \cdot 1 = 1\).
  • Sequence \(g_j = dp[3][j] \cdot (3 - j)!\):
    • \(g_0 = 1 \cdot 6 = 6\), \(g_1 = 6 \cdot 2 = 12\), \(g_2 = 7 \cdot 1 = 7\), \(g_3 = 1 \cdot 1 = 1\).
  • Binomial Inversion for \(m = 2\): \[ f_2 = (-1)^0 \binom{2}{2} g_2 + (-1)^1 \binom{3}{2} g_3 = 1 \cdot 7 - 3 \cdot 1 = 4. \] (Indeed, of the \(6\) permutations of \([1, 3, 5]\) paired against \([2, 4, 6]\), \([1, 3, 5]\) gives \(3\) wins, \([3, 5, 1]\) gives \(1\) win (\(6 > 1\)), and the other \(4\) permutations give \(2\) wins!)
WarningFailure Mode & Remedy: Forgetting the Parity Check \((n + k) \bmod 2 \neq 0\)

If \(n\) and \(k\) have opposite parities (for example \(n = 3, k = 0\)), integer division (n + k) / 2 in C++ truncates \(\frac{3}{2} \to 1\) and computes the answer for \(m = 1\) (\(k = -1\)) instead of returning \(0\)! Always check if ((n + k) % 2 != 0 || k > n) return 0; as the very first line of your solver.

4. Algorithm Contract

  • Input: \(n \in [1, 2000]\), \(k \in [0, n]\), arrays \(A[1..n], B[1..n]\).
  • Output: Number of permutations \(\pi \in S_n\) with \(\#\{i : A_i > B_{\pi(i)}\} - \#\{i : A_i < B_{\pi(i)}\} = k\) modulo \(10^9 + 9\).
  • Core Invariant: After sorting \(A\) and \(B\) ascending, the valid column prefixes \(\{1, \dots, c_i\}\) where \(B_r < A_i\) are nested (\(c_1 \le \dots \le c_n\)), so any \(j - 1\) rooks placed in rows \(1 \dots i-1\) consume \(j - 1\) columns inside \(\{1, \dots, c_i\}\), leaving \(c_i - (j - 1)\) choices for row \(i\).
  • Step 1 (Parity Guard): If \((n + k) \bmod 2 \neq 0\), return \(0\). Set \(m = (n + k) / 2\).
  • Step 2 (Sort & Two-Pointer Ferrers Thresholds): Sort \(A\) and \(B\) ascending in \(O(n \log n)\) time. Compute \(c_i = \#\{r : B_r < A_i\}\) via a two-pointer scan in \(O(n)\) time.
  • Step 3 (\(O(n^2)\) Rook DP): Initialize 1D rolling array \(dp[0..n] = \{1, 0, \dots, 0\}\). For \(i = 1 \dots n\): For \(j = \min(i, c_i)\) down to \(1\): dp[j] = (dp[j] + 1LL * (c[i] - j + 1) * dp[j - 1]) % 1000000009;
  • Step 4 (Binomial Inversion): Precompute factorials and binomial coefficients modulo \(P = 10^9 + 9\). Return \(\sum_{j=m}^n (-1)^{j-m} \binom{j}{m} dp[j] (n - j)! \bmod P\).
  • Complexity: \(O(n^2)\) time and \(O(n)\) space.

Problem CP-II.8 (#141) — Counting Labeled Trees with Prescribed Degrees

  • Source: Luogu P2290 — [HNOI2004] 树的计数

Problem Statement & Exact Constraints

You are given \(n\) labeled vertices \(1, 2, \dots, n\) and a sequence of prescribed vertex degrees \(d_1, d_2, \dots, d_n\). Count the number of distinct labeled trees on vertices \(\{1, 2, \dots, n\}\) in which each vertex \(i\) has degree exactly \(d_i\). It is guaranteed that the final answer fits inside a signed 64-bit integer (\(\le 10^{17}\)).

  • Input Constraints:
    • \(1 \le n \le 150\)
    • \(0 \le d_i \le n - 1\)
    • Output: Exact 64-bit integer count (\(\le 10^{17}\)).
  • Sample Trace (\(n = 4, d = [1, 1, 2, 2]\)): The \(2\) labeled trees on \(\{1, 2, 3, 4\}\) with leaves \(1, 2\) and degree-\(2\) internal vertices \(3, 4\) are 1-3-4-2 and 1-4-3-2, so the output is 2.
  • Target Complexity: \(O(n^2)\) or \(O(n)\) time, \(O(n)\) space.
Hint 1 — Diagnostic Signal (What to look for in the constraints)

Notice that not every problem in a mixed contest needs polynomial NTT! Think about how a labeled tree on \(n\) vertices can be bijectively encoded as a sequence of \(n - 2\) vertex labels in \(\{1, \dots, n\}\). How many times does vertex \(i\) appear in that sequence if its tree degree is \(d_i\)?

Hint 2 — Target Chapter Routing & Initial Setup
  • Primary Routing: Chapter 04 (§4.4 Labeled Trees, Prüfer Sequences & Degree-Distribution EGFs) and Chapter 06 (§6.1 Multinomial Coefficient Extraction).
  • Prüfer’s Bijection & EGF Formulation: For \(n \ge 2\), Prüfer’s bijection establishes a \(1\)-to-\(1\) correspondence between labeled trees on \(\{1, \dots, n\}\) and sequences \(P = (p_1, \dots, p_{n-2}) \in \{1, \dots, n\}^{n-2}\) of length \(n - 2\), under which vertex \(i\) has degree \(d_i\) in the tree if and only if label \(i\) appears in the Prüfer sequence exactly \(d_i - 1\) times! In the Exponential Generating Function ring \(K[[x]]\), choosing \(d_i - 1\) positions for label \(i\) is represented by the single-term EGF \(\frac{x^{d_i - 1}}{(d_i - 1)!}\). Therefore, the number of such sequences of length \(n - 2\) is \[ (n - 2)! \, [x^{n-2}] \prod_{i=1}^n \frac{x^{d_i - 1}}{(d_i - 1)!} = \frac{(n - 2)!}{\prod_{i=1}^n (d_i - 1)!}, \] provided \(d_i \ge 1\) for all \(i\) and \(\sum_{i=1}^n (d_i - 1) = n - 2\) (i.e., \(\sum_{i=1}^n d_i = 2n - 2\)).
Hint 3 — Key Algebraic Reduction & Edge Cases

Two classic traps catch almost every contestant on P2290:

  1. The \(n = 1\) Singularity (\(n - 2 = -1\)): Prüfer sequences have length \(n - 2\), which only exists for \(n \ge 2\)! When \(n = 1\), the unique tree on \(1\) vertex has \(0\) edges, so vertex \(1\) has degree \(d_1 = 0\) (not \(d_1 \ge 1\)).

    • If \(n = 1\) and \(d_1 = 0\), the answer is \(1\).
    • If \(n = 1\) and \(d_1 \neq 0\), the answer is \(0\).
    • If \(n \ge 2\), a tree is connected on \(\ge 2\) vertices, so every vertex must have degree \(d_i \ge 1\), and the sum of degrees must be \(\sum_{i=1}^n d_i = 2n - 2\). If any \(d_i = 0\) or \(\sum_{i=1}^n d_i \neq 2n - 2\), the answer is \(0\)!

  2. Avoiding 64-Bit Overflow in P2290 (\(n \le 150\), No Modulus): Even though the final multinomial coefficient \(\frac{(n-2)!}{\prod_{i=1}^n (d_i - 1)!}\) is guaranteed to be \(\le 10^{17}\), the numerator \(148! \approx 2.5 \times 10^{258}\) overflows long long and __int128 immediately!

    • Remedy A: Rewrite the multinomial coefficient as a product of binomial coefficients \(\prod_{i=1}^n \binom{S_i}{d_i - 1}\) where \(S_i = \sum_{j=1}^i (d_j - 1) \le n - 2\), and precompute Pascal’s triangle \(\binom{a}{b}\) for \(0 \le b \le a \le 150\).
    • Remedy B: Factorize each integer \(2 \le m \le n - 2\) into primes, accumulate prime exponents in the numerator minus the denominator, and multiply the remaining prime powers at the end.
NoteComplete Derivation, Algorithm Contract & Complexity Analysis

1. The Diagnostic Signal & Combinatorial Bijection

  • Diagnostic Signal: The input specifies a vertex count \(n\) and prescribed vertex degrees \(d_1, \dots, d_n\), asking for the number of labeled trees.

  • Prüfer Bijection Recap (Chapter 04, §4.4): For any integer \(n \ge 2\), let \(\mathcal{T}_n\) be the set of labeled trees on \(\{1, \dots, n\}\). The Prüfer encoding map \(\Phi : \mathcal{T}_n \to \{1, \dots, n\}^{n-2}\) iteratively deletes the leaf (vertex of degree \(1\)) with the smallest label and appends its unique neighbor’s label to the sequence until only \(2\) vertices remain.

    • Every time a vertex \(i\) is NOT a leaf and one of its neighbors is deleted as the smallest leaf, \(i\)’s degree decreases by \(1\) and \(i\) is written into the Prüfer code once.
    • Eventually, every vertex \(i\) is either deleted as a leaf (when its remaining degree reaches \(1\)) or is one of the final \(2\) vertices (which also have remaining degree \(1\) in the final single edge).
    • Consequently, a vertex \(i\) with initial degree \(d_i \ge 1\) appears in the Prüfer sequence \(\Phi(T)\) exactly \(d_i - 1\) times!

2. EGF Coefficient Extraction & Validity Conditions

Because \(\Phi\) is a bijection between labeled trees with degree sequence \((d_1, \dots, d_n)\) and words of length \(n - 2\) over \(\{1, \dots, n\}\) in which symbol \(i\) has multiplicity \(c_i = d_i - 1\):

  1. Necessary and Sufficient Feasibility Conditions:
    • Case \(n = 1\): A single isolated vertex has degree \(0\), so the count is \(\mathbf{1}[d_1 = 0]\).
    • Case \(n \ge 2\): Each multiplicity \(c_i = d_i - 1\) must be a non-negative integer (\(d_i \ge 1\)), and the total length of the word must equal \(n - 2\): \[ \sum_{i=1}^n (d_i - 1) = n - 2 \quad \Longleftrightarrow \quad \sum_{i=1}^n d_i = 2n - 2. \] If any \(d_i < 1\) or \(\sum_{i=1}^n d_i \neq 2n - 2\), the count is \(0\).
  2. Multinomial EGF Extraction (\(n \ge 2\)): In the EGF ring \(\mathbb{Q}[[x]]\), a set of \(c_i = d_i - 1\) positions occupied by label \(i\) has EGF \(\frac{x^{d_i - 1}}{(d_i - 1)!}\). Multiplying over \(i = 1, \dots, n\): \[ \begin{aligned} \text{Ans} &= (n - 2)! \, [x^{n-2}] \prod_{i=1}^n \frac{x^{d_i - 1}}{(d_i - 1)!} \\ &= (n - 2)! \, [x^{n-2}] \frac{x^{\sum_{i=1}^n (d_i - 1)}}{\prod_{i=1}^n (d_i - 1)!} \\ &= \frac{(n - 2)!}{\prod_{i=1}^n (d_i - 1)!} = \binom{c_1}{c_1} \binom{c_1 + c_2}{c_2} \cdots \binom{c_1 + \dots + c_n}{c_n}. \end{aligned} \] (Bonus Variant — Luogu P4430 猴猴吃香蕉: when \(n \le 10^6\) and the \(n - 1\) edges or internal construction steps are ordered modulo a prime \(P = 9999991\), we evaluate the same multinomial coefficient modulo \(P\) in \(O(n)\) time using precomputed factorials and inverse factorials, multiplied by the ordering factor \((n-1)!\).)

3. Hand-Checkable Concrete Trace (\(n = 4, d = [1, 1, 2, 2]\))

Let \(n = 4\) and \(d = (1, 1, 2, 2)\).

  • Feasibility check: \(n = 4 \ge 2\), all \(d_i \ge 1\), and \(\sum d_i = 1 + 1 + 2 + 2 = 6 = 2(4) - 2\). Valid!
  • Multiplicities \(c_i = d_i - 1\): \(c = (0, 0, 1, 1)\).
  • Formula: \[ \frac{(4 - 2)!}{0! \, 0! \, 1! \, 1!} = \frac{2!}{1} = 2. \]
  • Combinatorial check: A tree on \(\{1, 2, 3, 4\}\) where \(1, 2\) are leaves (\(d_1 = d_2 = 1\)) and \(3, 4\) have degree \(2\) must be a path of length \(3\) with endpoints \(1, 2\) and internal vertices \(3, 4\). The two such paths are \(1 - 3 - 4 - 2\) (Prüfer code \((3, 4)\)) and \(1 - 4 - 3 - 2\) (Prüfer code \((4, 3)\)). Count \(= 2\).
WarningFailure Mode & Remedy: Checking Only \(\sum_{i=1}^n d_i = 2n - 2\) Without Checking \(d_i \ge 1\)

Suppose \(n = 3\) and the input degrees are \(d = (0, 2, 2)\). Then \(\sum_{i=1}^3 d_i = 4 = 2(3) - 2\) holds, yet \(d_1 = 0\) means vertex \(1\) is isolated, which is impossible in a tree of size \(n \ge 2\)! Worse still, if your code blindly evaluates \(\text{invFact}[d_1 - 1] = \text{invFact}[-1]\), it will read out-of-bounds memory and crash or output garbage. Always enforce for (int i = 1; i <= n; ++i) if (d[i] < 1) return 0; whenever \(n \ge 2\).

4. Algorithm Contract

  • Input: Integer \(n \in [1, 150]\) and degree array \(d[1..n]\).
  • Output: Exact 64-bit integer count of labeled trees on \(\{1, \dots, n\}\) with degree sequence \((d_1, \dots, d_n)\).
  • Core Invariant: Under Prüfer’s bijection \(\Phi : \mathcal{T}_n \to \{1, \dots, n\}^{n-2}\) (\(n \ge 2\)), vertex \(i\) has degree \(d_i\) in \(T\) if and only if label \(i\) appears \(c_i = d_i - 1 \ge 0\) times in \(\Phi(T)\).
  • Step 1 (Boundary & Feasibility Guard):
    • If \(n = 1\): return \(1\) if \(d_1 == 0\), else return \(0\).
    • If \(n \ge 2\): if any \(d_i < 1\) or \(\sum_{i=1}^n (d_i - 1) \neq n - 2\), return \(0\).
  • Step 2 (Exact Integer Evaluation via Pascal’s Triangle, \(n \le 150\)):
    • Maintain running total of remaining positions \(R = n - 2\) and ans = 1.
    • Precompute Pascal’s triangle \(C[a][b] = \binom{a}{b}\) for \(0 \le b \le a \le n - 2\) (in 64-bit integers since every intermediate \(\binom{R}{d_i - 1}\) divides the final answer \(\le 10^{17}\)!).
    • For \(i = 1 \dots n\): set \(\text{ans} \leftarrow \text{ans} \times C[R][d_i - 1]\) and \(R \leftarrow R - (d_i - 1)\).
  • Complexity: \(O(n^2)\) time (Pascal’s triangle) or \(O(n)\) time (prime-exponent sieve / modular factorials), \(O(n)\) space.
