12 — Pointed Trees, Cacti, Deserts & Tutte’s Block-Cut Hierarchy

Part III · Online Algorithms, Implicit Equations & Graphical Enumeration

NoteLearning Objectives & Chapter Milestone

By the end of this chapter, you will be able to:

  1. Apply the Pointing Operator (\(\Theta = x D_x\)) and Unpointing (\(\Theta^{-1}\)) to break symmetry in labeled graph species, transitioning between vertex-rooted generating functions \(A^\bullet(x) = x A'(x)\) and unrooted generating functions via formal integration \(A(x) = \int_0^x \frac{A^\bullet(t)}{t}\,dt\) or Block-Cut Dissimilarity \(C(x) = R(x) + B(R(x)) - R(x) B'(R(x))\).
  2. Enumerate Rooted Labeled Cayley Trees, \(k\)-Component Forests, and Endofunctions (Functional Digraphs) via the implicit tree equation \(T(x) = x e^{T(x)}\) and Gessel’s Jacobian-Weighted Lagrange Inversion (Ch 11), proving the identities \([x^n] T(x)^k = \frac{k n^{n-k-1}}{(n-k)!}\) and \([x^n] \frac{T(x)^k}{1 - T(x)} = \frac{n^{n-k}}{(n-k)!}\).
  3. Model and Solve Husimi Cactus Graphs and Labeled Deserts (graphs in which every edge belongs to at most one simple cycle) via the pointed functional equation \(T(x) = x \exp\!\left(\frac{2T(x) - T(x)^2}{2(1 - T(x))}\right)\), extracting all \(n \le N\) in \(O(N \log N)\) time using Ch 10 Logarithmic Newton Iteration and a single \(n\) in \(O(n)\) time via Ch 11 Lagrange Inversion and a 3-term D-finite recurrence.
  4. Derive Tutte’s Block-Cut Tree Equation \(\ln\frac{R(x)}{x} = B'(R(x))\) for 2-Vertex-Connected (Biconnected) Labeled Graphs, and apply formal residue integration by parts to obtain the Log-Free Single-\(n\) Formula \(b_n = -(n-2)! [x^{n-1}] \big(C'(x)^{-(n-1)}\big)\) in \(O(n \log n)\) time.
  5. Derive the Bridge-Block Functional Equation \(R(x) = E\!\big(x e^{R(x)}\big)\) for 2-Edge-Connected (Bridgeless) Labeled Graphs, extracting a single \(n\) via \(e_{2,n} = -\frac{(n-1)!}{n} [x^n] \exp\!\big(-n x C'(x)\big)\) in \(O(n \log n)\) time and gluing \(k\) bridge-blocks via the generalized Cayley formula \(\frac{n!}{k!} n^{k-2} [z^n] E(z)^k\) to count connected graphs with a prescribed number of bridges.

In Chapter 4, we saw that the Exponential Generating Function (EGF) \(\exp/\ln\) bridge \[G(x) = \exp\!\big(C(x)\big) \iff C(x) = \ln G(x)\] splits an arbitrary labeled graph into its connected components—a decomposition across 0-cuts (disjoint vertex subsets with no edges between them). Once a graph is connected, however, its global cycles and local cut structures are tangled together. How do we count connected labeled graphs that have no articulation points (biconnected graphs), no bridge edges (2-edge-connected graphs), or whose biconnected blocks are restricted to single edges and simple cycles (Husimi cactus graphs)?

The unifying idea of this chapter is hierarchical block decomposition via pointing. Just as SET (\(\exp\)) glues connected components across \(0\)-cuts, functional composition \(A\big(R(x)\big)\) glues 2-connected blocks across 1-cuts (articulation vertices or bridge edges) when we first distinguish a root vertex using the pointing operator \(\Theta = x D_x\). Combining the implicit Newton engines of Chapter 10 with the Lagrange Inversion Formula (LIF) of Chapter 11 turns these recursive graph decompositions into \(O(N \log N)\) algorithms.

12.1 Pointing (\(\Theta = x D_x\)), Rooted Labeled Cayley Trees \(T(x) = x e^{T(x)}\), and Functional Digraphs

Concrete Combinatorial Motivation: Why Pointing Unlocks Recursive Graph Decomposition

Suppose we want to count unrooted labeled trees on \(n\) vertices with vertex labels \(\{1, 2, \dots, n\}\). In Chapter 4, Prüfer sequences gave a direct bijection to strings in \(\{1, \dots, n\}^{n-2}\), yielding \(u_n = n^{n-2}\). What if we want to derive \(u_n\)—and generalize it to cacti, functional digraphs, and biconnected graphs where Prüfer sequences do not directly apply—purely from the symbolic method?

An unrooted tree has no canonical starting vertex from which to peel off subtrees. However, if we point (or root) the tree by distinguishing one of its \(n\) labeled vertices as the root \(r\), then deleting \(r\) decomposes the remaining \(n - 1\) vertices into an unordered set of smaller rooted trees (the subtrees of the children of \(r\)).

The Pointing Operator \(\Theta = x D_x\) and Unpointing \(\Theta^{-1}\)

Let \(\mathcal{A}\) be a class of labeled combinatorial objects with EGF \[A(x) = \sum_{n=0}^{\infty} a_n \frac{x^n}{n!}, \qquad a_0 = 0.\] A pointed (or vertex-rooted) object in \(\mathcal{A}^\bullet\) is a pair \((\alpha, r)\) where \(\alpha \in \mathcal{A}\) is a labeled object on \(n\) vertices and \(r \in V(\alpha)\) is one distinguished vertex chosen as the root.

Because all \(n\) vertices carry distinct labels in \(\{1, 2, \dots, n\}\), there are never any automorphism symmetries identifying two different choices of \(r\): every unrooted labeled object \(\alpha\) of size \(n\) produces \(n\) distinct pointed objects \((\alpha, r)\), so \(a^\bullet_n = n \, a_n\). At the level of EGFs, multiplying the \(n\)-th coefficient by \(n\) corresponds to the pointing operator \(\Theta = x D_x\): \[A^\bullet(x) = \sum_{n=1}^{\infty} n \, a_n \frac{x^n}{n!} = x \sum_{n=1}^{\infty} a_n \frac{x^{n-1}}{(n-1)!} = x A'(x) = \Theta A(x).\]

Conversely, if we can solve a recursive functional equation for the pointed EGF \(A^\bullet(x)\), we recover the unrooted EGF \(A(x)\) via the unpointing operator \(\Theta^{-1}\) (formal integration after dividing by \(x\)), provided the characteristic \(p\) of our coefficient field \(K\) satisfies \(p > N\) (or \(p = 0\)): \[A(x) = \Theta^{-1} A^\bullet(x) = \int_0^x \frac{A^\bullet(t)}{t}\,dt \iff a_n = \frac{a^\bullet_n}{n} \quad (1 \le n < p).\]

NoteContrast with Unlabeled Trees (Ch 10.4 Otter’s Dissymmetry) and Leroux’s Labeled Dissymmetry

In Chapter 10.4, we could not divide the number of rooted unlabeled trees by \(n\) because unlabeled vertices in different automorphism orbits have different numbers of ways to be chosen as root. Instead, we used the topological identity \(|V(\tau)| - |E(\tau)| = 1\) (Otter’s Dissymmetry Theorem).

On labeled trees, both methods work and agree! Let \(T(x) = \sum_{n \ge 1} t_n \frac{x^n}{n!}\) be the EGF of rooted labeled trees (\(t_n = n^{n-1}\)) and \(U(x) = \sum_{n \ge 1} u_n \frac{x^n}{n!}\) be the EGF of unrooted labeled trees (\(u_n = n^{n-2}\)):

  1. Vertex-pointed trees (\(\mathcal{T}^\bullet_V\)): Picking any vertex of an unrooted tree roots it, so \(T_V(x) = T(x)\).
  2. Edge-pointed trees (\(\mathcal{T}^\bullet_E\)): Picking an undirected edge \(\{u, v\}\) and deleting it splits the tree into an unordered pair of rooted trees (rooted at \(u\) and \(v\)), which has EGF \(\frac{1}{2} T(x)^2\).

Since every tree satisfies \(|V| - |E| = 1\), summing over all labeled trees on \(n\) vertices gives \(t_n - \frac{1}{2} [x^n] n! T(x)^2 = u_n\), or at the EGF level (Leroux’s Labeled Dissymmetry Theorem): \[U(x) = T(x) - \frac{1}{2} T(x)^2.\] To check algebraically that this matches \(\int_0^x \frac{T(t)}{t}\,dt\), differentiate \(T(x) = x e^{T(x)}\) to get \(T'(x) = e^{T(x)} + x T'(x) e^{T(x)} = \frac{T(x)}{x} + T(x) T'(x)\), so \(T'(x)\big(1 - T(x)\big) = \frac{T(x)}{x}\). Therefore: \[\frac{d}{dx}\left(T(x) - \frac{1}{2} T(x)^2\right) = T'(x)\big(1 - T(x)\big) = \frac{T(x)}{x},\] which integrates to \(U(x) = \int_0^x \frac{T(t)}{t}\,dt\) without dividing by \(n\) (only by \(2\))! Taking the exponential gives the EGF of unrooted labeled forests: \[F_{\text{forest}}(x) = \exp\!\big(U(x)\big) = \exp\!\left(T(x) - \frac{1}{2} T(x)^2\right).\]

WarningFailure Mode & Remedy: The Pointed vs. Unpointed Symmetry & Unpointing Trap
  • Symptom: Off-by-\(n\) factor errors when exponentiating a pointed EGF (\(\exp(T(x))\) vs. \(\exp(U(x))\)), or substituting \(B(R(x))\) instead of \(B'(R(x))\) inside Tutte’s block-cut tree equation, or dividing by \(n \equiv 0 \pmod p\) when unpointing in small characteristic \(p \le N\).
  • Root Cause:
    1. Exponentiating a pointed species overcounts each component of size \(s\) by \(s\): \(\exp(T(x))\) counts forests of rooted trees (\(\prod s_i\) ways to pick roots), whereas \(\exp(U(x))\) counts forests of unrooted trees. You must unpoint (\(C(x) = \int_0^x \frac{T(t)}{t}\,dt\)) before taking \(\exp(C(x))\) to form disconnected graphs (such as deserts \(D(x) = \exp(C(x))\) in §12.2)!
    2. Shared root vs. external root in block composition: When a block of size \(k\) contains the already-distinguished root \(r\) (§12.3), \(r\) is not chosen from the \(k\) vertices of \(R(x)\)—only the \(k - 1\) non-root vertices receive factors of \(R(x)\), which requires the derivative \(B'(u) = \sum_{k \ge 2} b_k \frac{u^{k-1}}{(k-1)!}\) rather than the pointed EGF \(B^\bullet(u) = u B'(u)\). By contrast, across a bridge edge (§12.4), all \(k\) vertices of the child 2-ECC lie outside \(r\)’s component and one of those \(k\) vertices must be chosen as the bridge endpoint, which requires the pointed EGF \(E(z) = z B'_{\text{2-edge}}(z)\).
    3. Characteristic-\(p\) unpointing failure: Unpointing via \(a_n = a^\bullet_n / n\) fails when \(p \mid n\).
  • Remedy: Always check whether the root vertex of a sub-structure is shared with the parent (use \(B'(u)\)) or newly chosen inside the child (use \(u B'(u)\)), unpoint via \(\int_0^x \frac{T(t)}{t}\,dt\) before applying \(\exp\) for disconnected graphs, and use Dissymmetry (\(U(x) = T(x) - \frac{1}{2}T(x)^2\) or \(C(x) = R(x) + B(R(x)) - R(x)B'(R(x))\)) when division by \(n\) is forbidden!

Rooted Labeled Cayley Trees and \(k\)-Tree Forests via Lagrange Inversion

A rooted labeled tree (or Cayley tree) consists of a single labeled root vertex \(r\) (EGF \(x\)) together with an unordered set (\(\operatorname{SET}\)) of child subtrees, each of which is itself a rooted labeled tree: \[\mathcal{T} = \mathcal{Z} \times \operatorname{SET}(\mathcal{T}) \implies T(x) = x \exp\!\big(T(x)\big).\] This is directly in the implicit tree form \(T(x) = x \phi(T(x))\) with \(\phi(u) = e^u\) (Ch 11.2). By Composite Lagrange Inversion (Ch 11, Form 1) with \(H(u) = u^k\), for any integer \(k \ge 1\) and \(n \ge k\): \[\begin{aligned} [x^n] T(x)^k &= \frac{1}{n} [u^{n-1}] \left( \frac{d}{du}(u^k) \cdot \phi(u)^n \right) && \text{(by Ch 11 Form 1 LIF with } \phi(u) = e^u\text{)} \\ &= \frac{k}{n} [u^{n-k}] e^{n u} && \text{(computing } (u^k)' = k u^{k-1} \text{ and shifting index by } k-1\text{)} \\ &= \frac{k}{n} \cdot \frac{n^{n-k}}{(n-k)!} = \frac{k \, n^{n-k-1}}{(n-k)!}. && \text{(extracting } [u^{n-k}] e^{nu} = \frac{n^{n-k}}{(n-k)!}\text{)} \end{aligned}\] Multiplying by \(\frac{n!}{k!}\) gives the number of unordered \(k\)-component rooted labeled forests on \(n\) vertices: \[f_{n,k} = n! [x^n] \frac{T(x)^k}{k!} = \frac{n!}{k!} \cdot \frac{k \, n^{n-k-1}}{(n-k)!} = \binom{n-1}{k-1} n^{n-k}.\] In particular, setting \(k = 1\) gives \(t_n = n! [x^n] T(x) = n^{n-1}\) rooted labeled trees and \(u_n = t_n / n = n^{n-2}\) unrooted labeled trees (Cayley’s formula).

Endofunctions & Functional Digraphs via Gessel’s Jacobian-Weighted LIF

What combinatorial structure has EGF \(\frac{1}{1 - T(x)}\) or \(\frac{T(x)^k}{1 - T(x)}\)?

Consider an endofunction (or functional digraph) on \(\{1, 2, \dots, n\}\): a function \(f : \{1, \dots, n\} \to \{1, \dots, n\}\) where each vertex \(v\) has a single directed outgoing edge \(v \to f(v)\). Since there are \(n\) independent choices for \(f(v)\) at each of the \(n\) vertices, there are \(n^n\) endofunctions in total.

What does a functional digraph look like structurally? Following the directed path \(v \to f(v) \to f(f(v)) \to \dots\) from any vertex \(v\) must eventually repeat a vertex, entering a directed cycle. Every vertex not on a cycle has a unique directed path leading into a cycle vertex, so each cycle vertex acts as the root of a rooted labeled tree \(T(x)\) whose edges are oriented toward the root! Therefore:

  1. A connected functional digraph is a directed cycle (\(\operatorname{CYC}\)) of rooted labeled trees: \[C_{\text{func}}(x) = \operatorname{CYC}\big(\mathcal{T}\big)(x) = \ln\frac{1}{1 - T(x)}.\]
  2. An arbitrary functional digraph (an endofunction) is an unordered set (\(\operatorname{SET}\)) of connected functional digraphs: \[E_{\text{func}}(x) = \operatorname{SET}\big(\operatorname{CYC}(\mathcal{T})\big)(x) = \exp\!\left(\ln\frac{1}{1 - T(x)}\right) = \frac{1}{1 - T(x)} = \sum_{k=0}^{\infty} T(x)^k,\] where the \(k\)-th summand \(T(x)^k = \operatorname{SEQ}_k(\mathcal{T})(x)\) counts ordered \(k\)-tuples of rooted trees (equivalently, endofunctions whose cyclic vertices are linearly ordered, or bijectively by Joyal’s proof of Cayley’s formula, rooted trees with a second distinguished vertex).

Let us extract \([x^n] \frac{T(x)^k}{1 - T(x)}\) algebraically. Notice how the denominator \(1 - T(x)\) matches the Jacobian factor of \(T(x) = x e^{T(x)}\)!

The Diagnostic Signal

Whenever you need to extract \([x^n] G(T(x))\) where \(T(x) = x e^{T(x)}\) and \(G(u)\) contains a factor of \(\frac{1}{1 - u}\), reach for Gessel’s Jacobian-Weighted LIF (Ch 11, Form 3): the derivative of \(x = u e^{-u}\) is \(\frac{dx}{du} = (1 - u) e^{-u}\), so the \((1 - u)\) factor cancels the denominator \(\frac{1}{1 - u}\) directly!

The Reverse-Engineering Scratchpad

Recall Ch 11 Form 3 LIF (Change of Variables \(x = u / \phi(u)\) in the formal residue \(\operatorname{Res}_x G(T(x)) x^{-n-1} = \operatorname{Res}_u G(u) \big(1 - u \frac{\phi'(u)}{\phi(u)}\big) \phi(u)^n u^{-n-1}\)): \[\begin{aligned} [x^n] \frac{T(x)^k}{1 - T(x)} &= [u^n] \left( \frac{u^k}{1 - u} \cdot \left(1 - u \frac{(e^u)'}{e^u}\right) \cdot (e^u)^n \right) && \text{(applying Ch 11 Form 3 with } G(u) = \frac{u^k}{1-u},\, \phi(u) = e^u\text{)} \\ &= [u^n] \left( \frac{u^k}{1 - u} \cdot (1 - u) \cdot e^{n u} \right) && \text{(since } 1 - u \frac{e^u}{e^u} = 1 - u\text{)} \\ &= [u^{n-k}] e^{n u} = \frac{n^{n-k}}{(n-k)!}. && \text{(canceling } 1 - u \text{ and extracting } [u^{n-k}] e^{nu}\text{)} \end{aligned}\] Multiplying by \(n!\) gives the clean identity: \[n! [x^n] \frac{T(x)^k}{1 - T(x)} = \frac{n!}{(n-k)!} \, n^{n-k} = n^{\underline{k}} \, n^{n-k},\] which counts endofunctions on \(n\) vertices coupled with an ordered \(k\)-tuple of distinct cycle vertices (at \(k = 0\), this recovers \(n! [x^n] \frac{1}{1 - T(x)} = n^n\) total endofunctions).

TipEnrichment Bridge: Wright’s \(k\)-Excess Connected Graph Decomposition

What if a connected undirected graph on \(n\) vertices has \(n + k\) edges (excess \(k = |E| - |V|\))?

  • \(k = -1\) (Trees): \(C_{-1}(x) = U(x) = T(x) - \frac{1}{2} T(x)^2\).
  • \(k = 0\) (Unicyclic Connected Graphs): Repeatedly pruning vertices of degree \(1\) collapses a unicyclic simple graph onto its unique simple cycle of length \(m \ge 3\), so every vertex on that cycle acts as the root of an attached rooted tree \(T(x)\). Because an undirected simple cycle has length \(m \ge 3\) and dihedral symmetry of order \(2m\), we take the directed cycle \(\ln\frac{1}{1 - T(x)}\), strip \(m = 1, 2\), and divide by \(2\): \[C_0(x) = \sum_{m=3}^{\infty} \frac{T(x)^m}{2m} = \frac{1}{2} \ln\frac{1}{1 - T(x)} - \frac{T(x)}{2} - \frac{T(x)^2}{4}.\]
  • General \(k \ge 1\) (Wright’s Theorem): Contracting both degree-\(1\) trees and degree-\(2\) induced paths reduces any connected graph of excess \(k \ge 1\) to one of finitely many multigraph kernels of minimum degree \(\ge 3\), where every vertex is replaced by \(T(x)\) and every kernel edge is expanded into a path \(\frac{1}{1 - T(x)}\). Consequently, \(C_k(x) = \frac{W_k(T(x))}{(1 - T(x))^{3k}}\) for a polynomial \(W_k(u)\)!

12.2 Husimi Cactus Graphs (Edge-Disjoint Cycles) & Labeled Deserts

Concrete Combinatorial Objects: Cacti and Deserts

A connected simple undirected graph \(G\) is called a Husimi cactus graph (or simply a cactus) if every edge of \(G\) belongs to at most one simple cycle—equivalently, no two simple cycles share an edge, so every 2-vertex-connected block of \(G\) is either a single bridge edge (\(K_2\)) or a simple cycle (\(C_m\) with \(m \ge 3\)). A graph whose connected components are all cacti is called a desert (since a forest is a desert of trees!).

Let \(C(x) = \sum_{n \ge 1} c_n \frac{x^n}{n!}\) be the EGF of unrooted labeled cacti, \(T(x) = x C'(x) = \sum_{n \ge 1} t_n \frac{x^n}{n!}\) (\(t_n = n c_n\)) be the EGF of vertex-pointed labeled cacti, and \(D(x) = \exp(C(x)) = \sum_{n \ge 0} d_n \frac{x^n}{n!}\) be the EGF of labeled deserts.

Diagnostic Signal & Reverse-Engineering Scratchpad

The Diagnostic Signal

Whenever a graph family is defined by restricting the allowed shapes of its biconnected blocks (for example: only \(K_2\) edges for trees; only \(K_2\) edges and \(C_m\) cycles for cacti; or arbitrary biconnected blocks in Section 12.3), point the graph at a root vertex \(r\) and decompose the graph into the unordered set of blocks incident to \(r\).

The Reverse-Engineering Scratchpad

Let \((G, r)\) be a vertex-pointed cactus with root \(r\) (represented by \(x\)). What happens when we inspect the blocks of \(G\) that contain the root \(r\)? Because no two cycles share an edge, the blocks incident to \(r\) intersect only at \(r\) and partition the remaining vertices \(V(G) \setminus \{r\}\) into independent sub-cacti hanging off each block:

  1. Case 1: A bridge block (\(K_2\)) incident to \(r\). The edge \(\{r, v\}\) connects \(r\) to a single neighbor \(v\), and \(v\) serves as the root of a pointed sub-cactus. Thus a single bridge block incident to \(r\) has EGF: \[B^{\circ}_{K_2}\big(T(x)\big) = T(x).\]

  2. Case 2: A simple cycle block (\(C_m\), \(m \ge 3\)) incident to \(r\). Walking around the cycle starting and ending at \(r\) visits a sequence of \(m - 1 \ge 2\) distinct non-root vertices \((v_1, v_2, \dots, v_{m-1})\), each of which serves as the root of an independent pointed sub-cactus \(T(x)\). Because the cycle is undirected, walking \((v_1, \dots, v_{m-1})\) and walking \((v_{m-1}, \dots, v_1)\) produce the exact same undirected cycle block (and since \(m - 1 \ge 2\), the sequence and its reversal have distinct vertex labels and never coincide). Thus a cycle block of length \(m \ge 3\) incident to \(r\) has EGF \(\frac{T(x)^{m-1}}{2}\). Summing over all \(m \ge 3\) (or \(k = m - 1 \ge 2\)) yields: \[B^{\circ}_{\text{cycle}}\big(T(x)\big) = \sum_{m=3}^{\infty} \frac{T(x)^{m-1}}{2} = \sum_{k=2}^{\infty} \frac{T(x)^k}{2} = \frac{T(x)^2}{2\big(1 - T(x)\big)}.\]

  3. Combining all blocks incident to \(r\): Since the root \(r\) is incident to an arbitrary unordered set (\(\operatorname{SET} = \exp\)) of bridge blocks and cycle blocks, we add the two block generators: \[B'_{\text{cactus}}(u) = u + \frac{u^2}{2(1 - u)} = \frac{2u - u^2}{2(1 - u)},\] and obtain the Pointed Cactus Functional Equation: \[T(x) = x \exp\!\left(T(x) + \frac{T(x)^2}{2\big(1 - T(x)\big)}\right) = x \exp\!\left(\frac{2T(x) - T(x)^2}{2\big(1 - T(x)\big)}\right).\]

12.3 Tutte’s Block-Cut Tree Equation (\(\ln \frac{R(x)}{x} = B'(R(x))\)) & Biconnected (2-Vertex-Connected) Graphs

Concrete Combinatorial Objects: Blocks, Cut-Vertices, and the Block-Cut Tree

Let \(G\) be a connected simple undirected graph on \(n \ge 2\) labeled vertices. A vertex \(v \in V(G)\) is an articulation point (or cut-vertex) if deleting \(v\) and its incident edges disconnects \(G\). A connected graph on \(n \ge 2\) vertices with no articulation points is called biconnected (or 2-vertex-connected; by standard convention in Tutte’s block theory, \(K_2\) is the unique biconnected block on \(2\) vertices, so \(b_2 = 1\), while for \(n \ge 3\) biconnected means every pair of vertices is joined by two internally vertex-disjoint paths).

A maximal biconnected subgraph of \(G\) is called a block. The fundamental structural theorem of 2-vertex-connectivity states that:

  1. Every edge of \(G\) belongs to exactly one block (blocks partition the edge set \(E(G)\)).
  2. Two blocks can share at most one vertex, which must be a cut-vertex of \(G\).
  3. The bipartite incidence graph between the set of blocks \(\mathcal{B}(G)\) and the set of vertices \(V(G)\) is a tree—the block-cut tree of \(G\).

Let:

  • \(G(x) = \sum_{n=0}^{\infty} 2^{\binom{n}{2}} \frac{x^n}{n!}\) be the EGF of all simple labeled graphs;
  • \(C(x) = \ln G(x) = \sum_{n=1}^{\infty} c_n \frac{x^n}{n!}\) be the EGF of connected simple labeled graphs;
  • \(R(x) = \Theta C(x) = x C'(x) = \sum_{n=1}^{\infty} n c_n \frac{x^n}{n!}\) be the EGF of vertex-pointed connected graphs;
  • \(B(u) = \sum_{k=2}^{\infty} b_k \frac{u^k}{k!}\) be the EGF of biconnected labeled graphs (blocks).

Our goal is to express \(R(x)\) in terms of \(B(u)\) and then invert the relation to extract \(b_n = n! [u^n] B(u)\).

Diagnostic Signal & Reverse-Engineering Scratchpad

The Diagnostic Signal

We already know the connected graph EGF \(C(x) = \ln G(x)\) and its pointed version \(R(x) = x C'(x)\) in \(O(N \log N)\) time (Ch 04.3). Whenever we know the global connected EGF \(R(x)\) and want the local 2-vertex-connected block EGF \(B(u)\), we write the forward assembly \(R(x) = \dots\) via the block-cut tree and invert it using Ch 11 Lagrange Inversion!

The Reverse-Engineering Scratchpad

Let us trace what happens around the root vertex \(r\) in a vertex-pointed connected graph \((G, r)\) of EGF \(R(x)\):

  1. Step 1 (Isolating the blocks incident to the root \(r\)): In the block-cut tree of \((G, r)\), the root vertex \(r\) is adjacent to an unordered set (\(\operatorname{SET} = \exp\)) of blocks \(H_1, H_2, \dots, H_m\) that contain \(r\). Because the block-cut graph is a tree, deleting \(r\) disconnects \(G\) into \(m\) completely separate pieces—one for each block \(H_i\) incident to \(r\).

  2. Step 2 (Inside a single block \(H_i\) of size \(k \ge 2\) incident to \(r\)): Suppose block \(H_i\) has \(k\) vertices in total: the root \(r\) plus \(k - 1\) other vertices \(v_1, \dots, v_{k-1}\). How many ways can we form a biconnected block on \(\{r, v_1, \dots, v_{k-1}\}\) when \(r\) is already externally fixed? By definition, there are \(b_k\) biconnected graphs on \(k\) labeled vertices. Since \(r\) is fixed and the remaining \(k - 1\) vertices of the block carry labels, the EGF for choosing the block structure on the \(k - 1\) non-root vertices is: \[\sum_{k=2}^{\infty} b_k \frac{u^{k-1}}{(k-1)!} = \frac{d}{du} \left(\sum_{k=2}^{\infty} b_k \frac{u^k}{k!}\right) = B'(u).\]

  3. Step 3 (Substituting pointed connected subgraphs at the \(k - 1\) non-root block vertices): In the full connected graph \((G, r)\), each of the \(k - 1\) non-root vertices \(v_j\) of block \(H_i\) is not just a bare vertex—it is the root of the entire connected sub-component of \(G\) hanging off \(H_i\) at \(v_j\) in the block-cut tree! That sub-component is an arbitrary vertex-pointed connected graph with EGF \(u = R(x)\). Therefore, a single block incident to \(r\) together with all the subgraphs hanging off its non-root vertices has EGF: \[B'\big(R(x)\big).\]

  4. Step 4 (Taking the unordered set of blocks incident to \(r\) and multiplying by the root \(x\)): Since \(r\) itself contributes \(x\) and is incident to an unordered set (\(\exp\)) of such decorated blocks, we obtain Tutte’s Block-Cut Tree Equation: \[R(x) = x \exp\!\Big(B'\big(R(x)\big)\Big) \iff B'\big(R(x)\big) = \ln\!\left(\frac{R(x)}{x}\right) = \ln C'(x).\]

Single-\(n\) Extraction & The Log-Free Integration-by-Parts Formula (\(O(n \log n)\))

Suppose we want to compute \(b_n = n! [u^n] B(u) = (n - 1)! [u^{n-1}] B'(u)\) for a given \(n \ge 2\) (#183 Luogu P5827, #016 fps_24_w).

In Tutte’s Block-Cut Tree Equation \(B'\big(R(x)\big) = \ln C'(x)\), the inner series \(u = R(x) = x C'(x)\) has valuation \(1\) (\([x^0] R(x) = 0\) and \([x^1] R(x) = c_1 = 1\)), so \(R(x) = x \phi(x)^{-1}\) with \(\phi(x) = \frac{x}{R(x)} = \frac{1}{C'(x)}\). Let \(H(x) = \ln C'(x)\), so \(B'\big(R(x)\big) = H(x)\).

Applying Composite Lagrange Inversion (Ch 11, Form 2: Inverse Composition) to extract \([u^{n-1}] B'(u)\) from \(B'(R(x)) = H(x)\) for \(n \ge 2\) gives: \[\begin{aligned} [u^{n-1}] B'(u) &= \frac{1}{n - 1} [x^{n-2}] \left( H'(x) \left(\frac{x}{R(x)}\right)^{n-1} \right) && \text{(by Ch 11 LIF on } B'(R(x)) = H(x)\text{)} \\ &= \frac{1}{n - 1} [x^{n-2}] \left( \frac{C''(x)}{C'(x)} \cdot C'(x)^{-(n-1)} \right) && \text{(since } H(x) = \ln C'(x) \text{ and } \frac{x}{R(x)} = \frac{1}{C'(x)}\text{)} \\ &= \frac{1}{n - 1} [x^{n-2}] \Big( C''(x) \, C'(x)^{-n} \Big). && \text{(combining powers of } C'(x)\text{)} \end{aligned}\] Now observe the exact derivative inside the bracket: by the power rule of formal differentiation (Ch 02.1), \[\frac{d}{dx}\Big( C'(x)^{-(n-1)} \Big) = -(n - 1) \, C''(x) \, C'(x)^{-n} \implies C''(x) \, C'(x)^{-n} = -\frac{1}{n - 1} \frac{d}{dx}\Big( C'(x)^{-(n-1)} \Big).\] Using the coefficient-derivative identity \([x^{n-2}] F'(x) = (n - 1) [x^{n-1}] F(x)\), the factors of \(n - 1\) cancel and the logarithm \(H(x) = \ln C'(x)\) disappears completely: \[[u^{n-1}] B'(u) = -\frac{1}{(n - 1)^2} [x^{n-2}] \frac{d}{dx}\Big( C'(x)^{-(n-1)} \Big) = -\frac{1}{n - 1} [x^{n-1}] \Big( C'(x)^{-(n-1)} \Big).\] Multiplying both sides by \((n - 1)!\) yields the Log-Free Biconnected Graph Formula: \[b_n = (n - 1)! [u^{n-1}] B'(u) = -(n - 2)! [x^{n-1}] \left(\frac{x}{R(x)}\right)^{n-1} = -(n - 2)! [x^{n-1}] \Big( C'(x)^{-(n-1)} \Big) \qquad (n \ge 2).\]

  • Output: \(b_n \bmod p\), the number of labeled 2-vertex-connected (biconnected) simple graphs on \(n\) vertices.

12.4 Bridge-Block Trees & 2-Edge-Connected (Bridgeless) Labeled Graphs

Concrete Combinatorial Objects: Bridges and 2-Edge-Connected Components

An edge \(e \in E(G)\) of a connected graph \(G\) is called a bridge (or cut-edge) if deleting \(e\) disconnects \(G\). A connected simple undirected graph with no bridges is called 2-edge-connected (or bridgeless; note that \(K_1\) has no edges and therefore no bridges, so \(e_{2,1} = 1\), whereas \(K_2\) consists of a single bridge edge, so \(e_{2,2} = 0\)).

How does decomposing a connected graph across bridges (1-edge cuts) differ from decomposing across cut-vertices (1-vertex cuts)?

  • In vertex-biconnected decomposition (Section 12.3), blocks partition the edges \(E(G)\) and overlap at cut-vertices.
  • In 2-edge-connected decomposition, deleting all bridge edges of \(G\) partitions the vertices \(V(G)\) into disjoint maximal 2-edge-connected subgraphs \(H_1, \dots, H_k\) (the bridge-blocks or 2-ECCs). Contracting each \(H_i\) into a single super-vertex turns the bridge edges into a tree of 2-edge-connected components (the bridge-block tree)!

Let:

  • \(B_{\text{2-edge}}(z) = \sum_{n=1}^{\infty} e_{2,n} \frac{z^n}{n!}\) be the EGF of 2-edge-connected labeled graphs (\(e_{2,1} = 1, e_{2,2} = 0, e_{2,3} = 1, e_{2,4} = 10\));
  • \(E(z) = \Theta B_{\text{2-edge}}(z) = z B'_{\text{2-edge}}(z) = \sum_{n=1}^{\infty} n \, e_{2,n} \frac{z^n}{n!}\) be the EGF of vertex-pointed 2-edge-connected labeled graphs;
  • \(R(x) = x C'(x)\) be the EGF of vertex-pointed connected labeled graphs.

Diagnostic Signal & Reverse-Engineering Scratchpad

The Diagnostic Signal

Whenever a graph family is decomposed by contracting 2-edge-connected components into a tree of bridge edges, every vertex \(v\) inside the root 2-edge-connected component can sprout an arbitrary unordered set (\(\exp\)) of bridge edges leading to pointed connected components \(R(x)\). Consequently, each vertex \(z\) of the root 2-ECC is replaced by \(z = W(x) = x \exp\!\big(R(x)\big)\)!

The Reverse-Engineering Scratchpad

Let us trace a vertex-pointed connected graph \((G, r)\) of EGF \(R(x)\) from its root vertex \(r\):

  1. Step 1 (The root 2-edge-connected component \(H_0\)): Since bridge-blocks partition \(V(G)\), the root vertex \(r\) belongs to a unique 2-edge-connected component \(H_0\) of size \(k \ge 1\). Because \(r \in V(H_0)\) is distinguished as the root of \(G\), the pair \((H_0, r)\) is a vertex-pointed 2-edge-connected graph, which is enumerated by \(E(z) = z B'_{\text{2-edge}}(z)\).

  2. Step 2 (What hangs off each vertex \(v \in V(H_0)\) across bridge edges?): In the bridge-block tree of \(G\), deleting the edges of \(H_0\) leaves each of the \(k\) vertices \(v \in V(H_0)\) (including \(r\) itself!) incident to an unordered set (\(\operatorname{SET} = \exp\)) of bridge edges leaving \(H_0\) at \(v\). For each such bridge edge \(\{v, u\}\), deleting \(\{v, u\}\) separates a connected sub-component rooted at \(u\)—which is an arbitrary vertex-pointed connected graph with EGF \(R(x)\)! Therefore, a single vertex \(v \in V(H_0)\) together with the unordered set of bridge-attached pointed connected components hanging off \(v\) has EGF: \[z = W(x) = x \exp\!\big(R(x)\big) = x \exp\!\big(x C'(x)\big).\]

  3. Step 3 (Substituting \(z = W(x)\) into every vertex of the pointed root 2-ECC \(E(z)\)): Replacing every vertex \(z\) of the pointed 2-ECC \(E(z)\) by \(W(x) = x \exp(R(x))\) accounts for every vertex and edge of \((G, r)\) uniquely, yielding the Bridge-Block Functional Equation: \[E\!\Big(x \exp\!\big(R(x)\big)\Big) = R(x) \iff E\big(W(x)\big) = R(x), \qquad \text{where } W(x) = x \exp\!\big(R(x)\big).\]

NoteDual Viewpoint: Comparing \(z = x \exp\!\big(E(z)\big)\) with \(R(x) = x \exp\!\big(B'(R(x))\big)\)

Since \(z = W(x) = x \exp(R(x))\) and \(R(x) = E(W(x)) = E(z)\), substituting \(R(x) = E(z)\) into \(z = x \exp(R(x))\) yields the dual relation: \[z = x \exp\!\big(E(z)\big) \iff x = z \exp\!\big(-E(z)\big),\] where \(E(z) = z B'_{\text{2-edge}}(z)\) is the pointed 2-ECC generating function.

Why does the bridge-block equation have \(E(z) = z B'_{\text{2-edge}}(z)\) in the exponent of \(z = x \exp(E(z))\), whereas Tutte’s vertex-biconnected equation \(R(x) = x \exp(B'(R(x)))\) has \(B'(u)\) (without a factor of \(u\))?

  • In a vertex-biconnected block incident to \(r\), the root \(r\) is shared with the block, so only the \(k - 1\) non-root vertices of the block receive independent factors of \(R(x)\) (giving \(\frac{b_k}{(k-1)!} R(x)^{k-1}\), summed by \(B'(R(x))\)).
  • Across a bridge edge \(\{r, u\}\), the bridge connects \(r\) to a disjoint 2-edge-connected component rooted at \(u\), so all \(k\) vertices of that component (including \(u\)) lie outside \(r\)’s component (giving \(\frac{k \, e_{2,k}}{k!} z^k\), summed by \(E(z) = z B'_{\text{2-edge}}(z)\)).

Single-\(n\) Extraction via Ch 11 LIF (\(O(n \log n)\))

Suppose we want to compute \(e_{2,n} = n! [z^n] B_{\text{2-edge}}(z) = (n - 1)! [z^n] E(z)\) for a given \(n \ge 1\) (#184 Luogu P5828).

In the Bridge-Block Functional Equation \(E\big(W(x)\big) = R(x)\), the inner series \(z = W(x) = x \exp(R(x))\) has valuation \(1\) with \(\phi(x) = \frac{x}{W(x)} = \exp(-R(x))\). We can extract \([z^n] E(z)\) by either Form 3 or Form 2 of Chapter 11 LIF:

  1. Derivation via Formal Residue Change of Variables (Ch 11, Form 3): Since \(z = W(x) = x e^{R(x)}\), we have \(W'(x) = \big(1 + x R'(x)\big) e^{R(x)}\), so: \[\begin{aligned} [z^n] E(z) &= \operatorname{Res}_z \, E(z) z^{-n-1} = \operatorname{Res}_x \, E(W(x)) W(x)^{-n-1} W'(x) && \text{(change of variables } z = W(x)\text{)} \\ &= [x^n] \, R(x) \big(1 + x R'(x)\big) \exp\!\big(-n R(x)\big). && \text{(substituting } E(W(x)) = R(x),\, W(x) = x e^{R(x)}\text{)} \end{aligned}\]

  2. Derivative-Free Simplification via Integration by Parts (for \(n \ge 2\)): Alternatively, applying Standard Inverse LIF (Ch 11, Form 2) to \(E(W(x)) = R(x)\) gives for \(n \ge 1\): \[[z^n] E(z) = \frac{1}{n} [x^{n-1}] \Big( R'(x) \exp\!\big(-n R(x)\big) \Big).\] For \(n \ge 2\), notice that \(\frac{d}{dx}\Big(\exp(-n R(x))\Big) = -n R'(x) \exp(-n R(x))\). Using \([x^{n-1}] F'(x) = n [x^n] F(x)\) cancels the factor of \(n\) and eliminates \(R'(x)\): \[[z^n] E(z) = -\frac{1}{n^2} [x^{n-1}] \frac{d}{dx}\Big(\exp\!\big(-n R(x)\big)\Big) = -\frac{1}{n} [x^n] \exp\!\big(-n R(x)\big) \qquad (n \ge 2).\] Multiplying by \((n - 1)!\) yields the Derivative-Free 2-Edge-Connected Graph Formula: \[e_{2,n} = (n - 1)! [z^n] E(z) = -\frac{(n - 1)!}{n} [x^n] \exp\!\big(-n R(x)\big) = -\frac{(n - 1)!}{n} [x^n] \exp\!\big(-n x C'(x)\big) \qquad (n \ge 2).\]

Connected Graphs with a Prescribed Number of Bridges (#190 Luogu P6596)

What if a problem asks for the number of connected simple labeled graphs on \(n\) vertices that have at most \(m\) bridge edges (or exactly \(b = k - 1\) bridge edges)?

Deleting the \(b = k - 1\) bridge edges splits the graph into an unordered set of \(k\) 2-edge-connected components \(H_1, \dots, H_k\) of sizes \(s_1 + s_2 + \dots + s_k = n\). By the Generalized Cayley Component-Tree Formula (Chapter 4.5), the number of ways to place \(k - 1\) bridge edges between \(k\) fixed components of sizes \(s_1, \dots, s_k\) to form a tree of components is: \[n^{k-2} \prod_{i=1}^{k} s_i \qquad (\text{which also holds at } k = 1 \text{ since } n^{-1} s_1 = 1).\] Notice that multiplying the 2-ECC count \(e_{2,s_i}\) by its vertex size \(s_i\) produces the \(s_i\)-th coefficient of the pointed 2-ECC generating function \(E(z) = z B'_{\text{2-edge}}(z) = \sum_{s \ge 1} s \, e_{2,s} \frac{z^s}{s!}\)! Therefore, the number of connected labeled graphs on \(n\) vertices with exact \(k - 1\) bridge edges (\(k\) 2-edge-connected components) is: \[\text{ans}_{k-1} = \frac{n!}{k!} \, n^{k-2} \, [z^n] E(z)^k \qquad (1 \le k \le n).\]

WarningFailure Mode & Remedy: Confusing \(B_{\text{2-edge}}(z)\) with \(B_{\text{vertex}}(u)\) at \(n = 1, 2, 5\)

Symptom: Using \(b_2 = 1\) in a 2-edge-connected problem or \(e_{2,1} = 1\) in a 2-vertex-connected problem.

In any vertex-pointed connected graph \((G, r)\), the root \(r\) belongs to an unordered set of blocks incident to \(r\), and each of the \(k - 1\) non-root vertices in a block of size \(k\) roots an independent pointed connected graph \(u = R(x) = x C'(x)\): \[R(x) = x \exp\!\Big(B'\big(R(x)\big)\Big) \iff B'\big(x C'(x)\big) = \ln C'(x).\] Let \(u = R(x) = x C'(x)\). For \(n \ge 2\), by the Formal Residue Change-of-Variables Theorem (Ch 11.1): \[\begin{aligned} [u^{n-1}] B'(u) &= \frac{1}{n - 1} \operatorname{Res}_u \, B''(u) u^{-(n-1)} = \frac{1}{n - 1} \operatorname{Res}_x \, \frac{d}{dx}\Big(B'\big(R(x)\big)\Big) R(x)^{-(n-1)} \\ &= \frac{1}{n - 1} [x^{n-2}] \left( \frac{d}{dx}\big(\ln C'(x)\big) \cdot C'(x)^{-(n-1)} \right) \\ &= \frac{1}{n - 1} [x^{n-2}] \Big( C''(x) \, C'(x)^{-n} \Big) \\ &= -\frac{1}{(n - 1)^2} [x^{n-2}] \frac{d}{dx}\Big( C'(x)^{-(n-1)} \Big) \\ &= -\frac{1}{n - 1} [x^{n-1}] \Big( C'(x)^{-(n-1)} \Big). \end{aligned}\] Multiplying by \((n - 1)!\) gives the exact count of biconnected labeled graphs on \(n \ge 2\) vertices: \[b_n = (n - 1)! [u^{n-1}] B'(u) = -(n - 2)! [x^{n-1}] \exp\!\Big(-(n - 1) \ln C'(x)\Big) \pmod{998244353}.\]

// O(n log n) Single-n Biconnected Graph Extraction (Luogu P5827)
if (n == 1) return 1;
Poly G(n + 1);
for (int k = 0; k <= n; ++k)
    G[k] = power(2, 1LL * k * (k - 1) / 2 % (MOD - 1)) * ifac[k] % MOD;
Poly C_prime = G.Ln(n + 1).Deriv(); // C'(x) of degree n - 1, [x^0]C'(x) = 1
Poly P = (C_prime.Ln(n) * (MOD - (n - 1))).Exp(n); // C'(x)^{-(n-1)} mod x^n
long long ans = (MOD - fac[n - 2]) * P[n - 1] % MOD;

  • Preconditions: \(p > n\); \([x^0] G(x) = 1\) and \([x^0] C'(x) = 1\).
  • Postconditions: Outputs \(b_n \bmod p\), the exact number of labeled 2-vertex-connected graphs on \(n\) vertices (with boundary check \(n = 1 \implies 1\)).

  • Core Invariant: Formal residue integration by parts reduces \(\operatorname{Res}_x (\ln C'(x))' R(x)^{-(n-1)}\) to \(-(n-1) [x^{n-1}] \big(C'(x)^{-(n-1)}\big)\) for all \(2 \le n < p\).

Mastery 2 (#184) — Luogu P5828: 边双连通图计数 (2-Edge-Connected Labeled Graphs)

  • Source: Luogu P5828
  • Prerequisites: Bridge-Block Functional Equation \(E(x e^{R(x)}) = R(x)\) & Derivative-Free Single-\(n\) LIF (§12.4).
Problem Statement & Exact Constraints

Given a positive integer \(n\), compute the number of simple undirected 2-edge-connected (bridgeless) labeled graphs on \(n\) vertices (connected graphs with no bridge edges / cut-edges) modulo \(998244353\).

  • Constraints: \(1 \le n \le 2 \times 10^5\), modulus \(p = 998244353\). (Note: for \(n = 1\), \(K_1\) has \(0\) edges and thus \(0\) bridges, so \(e_{2,1} = 1\); for \(n = 2\), \(K_2\) is a single bridge, so \(e_{2,2} = 0\).)
  • Required Complexity: \(O(n \log n)\) time and \(O(n)\) space.
Small Hand-Checkable Trace (\(n \le 5\))
  • \(n = 1\): \(\mathbf{1}\) (\(K_1\) has \(0\) bridges).
  • \(n = 2\): \(\mathbf{0}\) (\(K_2\) is a bridge).
  • \(n = 3\): \(\mathbf{1}\) (\(K_3\)).
  • \(n = 4\): \(\mathbf{10}\) (same as biconnected graphs for \(n = 4\)).
  • \(n = 5\): \(\mathbf{253}\) (\(238\) biconnected graphs plus \(\binom{5}{1} \cdot \frac{1}{2}\binom{4}{2} = 15\) “bowtie” graphs consisting of two triangles sharing a single cut-vertex, which has no bridge edges!).
Hint 1 — Diagnostic Signal & Combinatorial Model

Contracting every 2-edge-connected component of a connected graph into a super-vertex turns the bridge edges into a tree of 2-ECCs. If we distinguish a root vertex \(r\), it belongs to a unique root 2-ECC \(H_0\); what hangs off each vertex \(v \in V(H_0)\) across the bridge edges incident to \(v\)?

Hint 2 — Algebraic Setup & Reverse-Engineering Scratchpad

Every vertex \(v \in V(H_0)\) (including \(r\)) sprouts an unordered set (\(\exp\)) of bridge edges leading to pointed connected components \(R(x) = x C'(x)\). Let \(E(z) = z B'_{\text{2-edge}}(z) = \sum_{k=1}^{\infty} k \, e_{2,k} \frac{z^k}{k!}\) be the EGF of vertex-pointed 2-edge-connected graphs. Replacing every vertex \(z\) of the root 2-ECC by \(W(x) = x \exp(R(x))\) yields: \[E\big(W(x)\big) = R(x), \qquad W(x) = x \exp\!\big(R(x)\big) = x \exp\!\big(x C'(x)\big).\]

Hint 3 — Coefficient Extraction & Complexity Contract

Applying Ch 11 LIF to \(E(W(x)) = R(x)\) and integrating by parts for \(n \ge 2\) gives: \[[z^n] E(z) = \frac{1}{n} [x^{n-1}] \Big( R'(x) \exp\!\big(-n R(x)\big) \Big) = -\frac{1}{n} [x^n] \exp\!\big(-n R(x)\big).\] Multiply by \((n - 1)!\) to obtain \(e_{2,n} = -\frac{(n - 1)!}{n} [x^n] \exp\!\big(-n x C'(x)\big)\) in \(O(n \log n)\) time!

NoteComplete Derivation & Solution
Step 1: Pointed Connected Graph EGF \(R(x) = x C'(x)\)

As in #183, form \(G(x) = \sum_{k=0}^{n} 2^{\binom{k}{2}} \frac{x^k}{k!} \bmod x^{n+1}\), compute \(C(x) = \ln G(x) \bmod x^{n+1}\) in \(O(n \log n)\) time, and apply the pointing operator \(\Theta = x D_x\) to obtain: \[R(x) = x C'(x) = \sum_{k=1}^{n} k \, c_k \frac{x^k}{k!} \pmod{x^{n+1}}.\]

Step 2: Bridge-Block Substitution and LIF Extraction

For \(n = 1\), output \(e_{2,1} = 1\). For \(n \ge 2\), let \(E(z) = \sum_{k=1}^{\infty} k \, e_{2,k} \frac{z^k}{k!}\) be the EGF of vertex-pointed 2-edge-connected graphs. By Section 12.4, \(E(W(x)) = R(x)\) where \(W(x) = x \exp(R(x))\).

Applying Ch 11 Inverse Lagrange Inversion (Form 2) with \(\phi(x) = \frac{x}{W(x)} = \exp(-R(x))\): \[\begin{aligned} [z^n] E(z) &= \frac{1}{n} [x^{n-1}] \left( R'(x) \left(\frac{x}{W(x)}\right)^n \right) \\ &= \frac{1}{n} [x^{n-1}] \Big( R'(x) \exp\!\big(-n R(x)\big) \Big) \\ &= -\frac{1}{n^2} [x^{n-1}] \frac{d}{dx}\Big( \exp\!\big(-n R(x)\big) \Big) \\ &= -\frac{1}{n} [x^n] \exp\!\big(-n R(x)\big). \end{aligned}\] Since \([z^n] E(z) = \frac{n \, e_{2,n}}{n!} = \frac{e_{2,n}}{(n - 1)!}\), multiplying both sides by \((n - 1)!\) yields the exact count of 2-edge-connected labeled graphs on \(n \ge 2\) vertices: \[e_{2,n} = -\frac{(n - 1)!}{n} [x^n] \exp\!\big(-n R(x)\big) = -\frac{(n - 1)!}{n} [x^n] \exp\!\big(-n x C'(x)\big) \pmod{998244353}.\]

// O(n log n) Single-n 2-Edge-Connected Graph Extraction (Luogu P5828)
if (n == 1) return 1;
Poly G(n + 1);
for (int k = 0; k <= n; ++k)
    G[k] = power(2, 1LL * k * (k - 1) / 2 % (MOD - 1)) * ifac[k] % MOD;
Poly R = G.Ln(n + 1);
for (int k = 0; k <= n; ++k) R[k] = R[k] * k % MOD; // R(x) = x C'(x)
Poly P = (R * (MOD - n)).Exp(n + 1);                // exp(-n R(x)) mod x^{n+1}
long long ans = (MOD - fac[n - 1]) * inv[n] % MOD * P[n] % MOD;
