24.1 Bitwise Group Algebras (OR, AND, XOR Fast Walsh–Hadamard / Möbius Transforms)

Every polynomial engine we have built in Chapters 1–23 operated inside the Cauchy convolution algebra \(K[[x]]\), where multiplying two monomials adds their integer exponents: \(x^i \cdot x^j = x^{i+j}\). Yet many combinatorial problems combine indices not by integer addition, but by bitwise boolean operations on \(n\)-bit masks \(S, T \in \{0, 1\}^n\) (identified with subsets of \(\{0, 1, \dots, n-1\}\) or integers in \([0, 2^n - 1]\)):

\[ (A *_{\oplus} B)_S = \sum_{\substack{T, R \in \{0, 1\}^n \\ T \oplus R = S}} A_T B_R, \qquad \oplus \in \{\mathbin{|}, \mathbin{\&}, \oplus_{\text{XOR}}\}. \]

Before writing down transform matrices, let us name the concrete combinatorial objects being counted and the exact algebraic structure behind them.

From Monoid Algebras to Coordinate-Wise \(2 \times 2\) Kronecker Products

Fix a commutative ring \(K\) and a finite commutative monoid \((M, \oplus)\) of size \(2^n\), where \(M = \{0, 1\}^n\) and \(\oplus\) acts independently on each of the \(n\) bit positions. The monoid algebra \(K[M]\) consists of formal linear combinations \(A = \sum_{S \in M} A_S \mathbf{e}_S\) with multiplication defined on basis elements by \(\mathbf{e}_T \cdot \mathbf{e}_R = \mathbf{e}_{T \oplus R}\).

Because the \(n\) bit coordinates do not carry into one another under \(\mathbin{|}\), \(\mathbin{\&}\), or \(\oplus_{\text{XOR}}\), the \(n\)-bit monoid decomposes as a direct product of \(n\) copies of the 1-bit monoid \((\{0, 1\}, \oplus_1)\). Consequently, the \(2^n\)-dimensional algebra \(K[\{0, 1\}^n]\) factors as the \(n\)-fold tensor product of the 2-dimensional 1-bit algebra:

\[ K[\{0, 1\}^n] \cong \underbrace{K[\{0, 1\}] \otimes_K K[\{0, 1\}] \otimes_K \cdots \otimes_K K[\{0, 1\}]}_{n \text{ times}}. \]

This tensor factorization means we only ever need to diagonalize a single bit (\(n = 1\), a \(2 \times 2\) matrix \(\mathcal{T}_1\)) and apply that \(2 \times 2\) butterfly across each of the \(n\) bit dimensions sequentially in \(n \cdot 2^{n-1}\) operations!

Its inverse subtracts the 0-coordinate from the 1-coordinate: \((a_0, a_1) = (\hat{a}_0, \hat{a}_1 - \hat{a}_0)\) (the Subset Fast Möbius Transform).
    2. Bitwise AND (\(\mathbin{\&}\)): Symmetrically, \(c_1 = a_1 b_1\) is already pointwise, and \(c_0 + c_1 = (a_0 + a_1)(b_0 + b_1)\). Thus \((\hat{a}_0, \hat{a}_1) = (a_0 + a_1, a_1)\) diagonalizes 1-bit AND. Over \(n\) bits, this sums over all supersets: \(\widehat{A}_S = \sum_{T \supseteq S} A_T\) (the Superset Fast Zeta Transform).
    3. Bitwise XOR (\(\oplus\)): Here \(c_0 = a_0 b_0 + a_1 b_1\) and \(c_1 = a_0 b_1 + a_1 b_0\). Adding and subtracting the two equations yields: \[ c_0 + c_1 = (a_0 + a_1)(b_0 + b_1), \qquad c_0 - c_1 = (a_0 - a_1)(b_0 - b_1). \] Thus \((\hat{a}_0, \hat{a}_1) = (a_0 + a_1, a_0 - a_1)\) is the Walsh–Hadamard butterfly. Over \(n\) bits, every mask \(S\) picks up a \(-1\) factor whenever both \(S\) and \(T\) have bit \(i\) set, giving \(\widehat{A}_S = \sum_{T} (-1)^{\operatorname{popcount}(S \mathbin{\&} T)} A_T\).

Hand-Checkable Trace (\(n = 2\) XOR Convolution)

Let \(n = 2\), and suppose \(A = [1, 2, 0, 3]\) and \(B = [0, 1, 2, 1]\) indexed by masks \(00_2, 01_2, 10_2, 11_2\). Let us trace \(C = A *_{\text{xor}} B\):

  1. Bit 0 butterfly (\(\text{len} = 1\), pairs \((0,1)\) and \((2,3)\)):
    • \(A^{(1)} = [1+2, 1-2, 0+3, 0-3] = [3, -1, 3, -3]\).
    • \(B^{(1)} = [0+1, 0-1, 2+1, 2-1] = [1, -1, 3, 1]\).
  2. Bit 1 butterfly (\(\text{len} = 2\), pairs \((0,2)\) and \((1,3)\)):
    • \(\widehat{A} = [3+3, -1+(-3), 3-3, -1-(-3)] = [6, -4, 0, 2]\).
    • \(\widehat{B} = [1+3, -1+1, 1-3, -1-1] = [4, 0, -2, -2]\).
  3. Pointwise product: \(\widehat{C} = \widehat{A} \odot \widehat{B} = [24, 0, 0, -4]\).
  4. Inverse FWT (apply the two butterflies, then divide by \(2^2 = 4\)):
    • After bit 0: \([24+0, 24-0, 0+(-4), 0-(-4)] = [24, 24, -4, 4]\).
    • After bit 1: \([24+(-4), 24+4, 24-(-4), 24-4] = [20, 28, 28, 20]\).
    • Divide by \(4\): \(C = [5, 7, 7, 5]\).
    • Direct check for \(C_{00_2}\): \(A_0 B_0 + A_1 B_1 + A_2 B_2 + A_3 B_3 = 1(0) + 2(1) + 0(2) + 3(1) = 5\). Exact match!

The Small-Support XOR Trick (\(O(m + n 2^n)\) Sparse Product Compression)

Suppose we must compute the XOR product of \(m\) sparse polynomials, each supported on at most two masks (for example, choosing whether to include or exclude each of \(m\) items with XOR weight \(u_i \in [0, 2^n - 1]\)):

\[ F(x) = \prod_{i=1}^m \left(a + b x^{u_i}\right) \quad \text{in } K[\mathbb{Z}_2^n], \]

where \(m \le 10^6\) and \(n \le 20\). Transforming \(m\) separate arrays of size \(2^n\) would take \(O(m n 2^n)\) time—an immediate TLE.

How do we collapse all \(m\) transforms into one FWT? Look at what the XOR transform does to a single factor \(P_i(x) = a + b x^{u_i}\) at frequency mask \(M\):

\[ \widehat{P_i}(M) = a (-1)^{\operatorname{popcount}(M \mathbin{\&} 0)} + b (-1)^{\operatorname{popcount}(M \mathbin{\&} u_i)} = \begin{cases} a + b & \text{if } \operatorname{popcount}(M \mathbin{\&} u_i) \equiv 0 \pmod 2, \\ a - b & \text{if } \operatorname{popcount}(M \mathbin{\&} u_i) \equiv 1 \pmod 2. \end{cases} \]

Notice that \(\widehat{P_i}(M)\) can only take two possible values: \(a+b\) or \(a-b\)! Therefore, for a fixed frequency mask \(M\), if \(c_{+1}(M)\) counts how many indices \(i \in \{1, \dots, m\}\) have \(\operatorname{popcount}(M \mathbin{\&} u_i)\) even, and \(c_{-1}(M)\) counts how many have \(\operatorname{popcount}(M \mathbin{\&} u_i)\) odd, then the product in frequency space is simply:

\[ \widehat{F}(M) = (a + b)^{c_{+1}(M)} (a - b)^{c_{-1}(M)}. \]

How do we find \(c_{+1}(M)\) and \(c_{-1}(M)\) for all \(M\) simultaneously? Build a single frequency array \(C\) of length \(2^n\) where \(C_u = \#\{i : u_i = u\}\), and apply a single forward XOR-FWT to \(C\)! By linearity of FWT:

\[ \widehat{C}_M = \sum_{i=1}^m (-1)^{\operatorname{popcount}(M \mathbin{\&} u_i)} = c_{+1}(M) - c_{-1}(M). \]

Combining this with the total count \(c_{+1}(M) + c_{-1}(M) = m\), we solve the \(2 \times 2\) linear system at each mask \(M\):

\[ c_{+1}(M) = \frac{m + \widehat{C}_M}{2}, \qquad c_{-1}(M) = \frac{m - \widehat{C}_M}{2}. \]

One forward FWT on \(C\), \(2^n\) modular exponentiations, and one inverse FWT on \(\widehat{F}\) solves the entire \(m\)-factor product in \(O(m + n 2^n)\) time! (This generalizes to \(k\)-sparse factors for \(k \le 3\) via \(2^{k-1}\) linear equations.)

WarningFailure Mode & Remedy: Characteristic-2 Collapse & Zero Factors in Pointwise FWT Products
  1. Characteristic-2 Collapse in XOR-FWT: The inverse XOR butterfly requires dividing by \(2\) at each of the \(n\) bit layers (or by \(2^n\) at the end). If you work over \(\mathbb{F}_2\) or \(\mathbb{Z}/2^k\mathbb{Z}\), \(2\) is not a unit! Remedy: Lift the coefficients to \(\mathbb{Z}\) (using 64-bit integers int64_t) or a prime field \(\mathbb{F}_p\) with \(p > 2\), execute the XOR-FWT and division by \(2^n\) in the lifted ring, and reduce modulo \(2\) or \(2^k\) only after the inverse transform completes.
  2. Vanishing Pointwise Values in Frequency Space (\(\widehat{P}_M = 0\)): When maintaining dynamic products \(\widehat{F}_M = \prod_i \widehat{P_i}(M) \bmod p\), a factor might evaluate to \(\widehat{P_i}(M) \equiv 0 \pmod p\) (for instance, when \(a \equiv b \pmod p\) and \(c_{-1}(M) > 0\)). You cannot later “remove” that factor by multiplying by \(\widehat{P_i}(M)^{-1} \bmod p\). Remedy: Either count the multiplicity of zero factors per mask \(M\) as a pair (nonzero_part, zero_count), or compute exponents \(c_{+1}(M), c_{-1}(M)\) directly over \(\mathbb{Z}\) before taking modular powers.

For the small-support XOR eigenvalue trick, the forward frequency FWT must be computed over exact 64-bit integers (int64_t), not modulo \(p\).
  • Postconditions (Output): Exact bitwise OR, AND, or XOR convolution \(C_S = \sum_{T \oplus R = S} A_T B_R\) for all \(S \in [0, 2^n - 1]\).
  • Time & Space Complexity: \(O(n 2^n)\) time and \(O(2^n)\) in-place space (or \(O(m + k 2^k + n 2^n)\) for \(k\)-sparse factors).
  • Loop / Algebraic Invariant: After processing bit stages \(0, 1, \dots, b - 1\), each block of size \(2^b\) holds the \(b\)-dimensional character evaluation along the lowest \(b\) bits while higher bits \(b \dots n - 1\) remain in the time domain.
  • Failure Modes & Edge Cases:
    1. Characteristic-2 Collapse: Dividing by \(2^n\) in IFWT-XOR fails when \(2\) is not a unit in \(K\) (e.g., \(\mathbb{F}_2\) or \(\mathbb{Z}/2^{64}\mathbb{Z}\) without extra precision bits).
    2. Modular Reduction of Frequency Counts: Reducing \(\widehat{C}_M\) modulo \(p\) before solving the linear system for multiplicity counts \(c_r(M)\) corrupts the integer exponents used in \(\prod_r \lambda_r^{c_r(M)} \bmod p\).
    3. Zero Point-Value Factors: When evaluating ratios or dynamic updates in the FWT domain, frequencies with \(\widehat{A}_M \equiv 0 \pmod p\) cannot be divided out naively and require \((a, c)\) zero-divisor tracking (Ch 22 §22.3).

24.2 The Set Power Series Ring \(\mathcal{R}_n = K[x_1, \dots, x_n]/(x_1^2, \dots, x_n^2)\) & Ranked Fast Zeta Transform

Bitwise OR convolution combines two subsets \(T, R \subseteq \{0, \dots, n-1\}\) into \(T \cup R\) even when \(T\) and \(R\) overlap. However, in almost all exact partition and graph component problems—such as building a disconnected graph out of vertex-disjoint connected components, or partitioning \(V\) into \(k\) independent sets—we need the disjoint-union subset convolution:

\[ (A *_{\text{sub}} B)_S = \sum_{\substack{T \cup R = S \\ T \cap R = \varnothing}} A_T B_R = \sum_{T \subseteq S} A_T B_{S \setminus T}. \]

Computing this naively by iterating over submasks for (int T = S; ; T = (T - 1) & S) takes \(\sum_{S} 2^{|S|} = 3^n\) operations. To accelerate this to \(O(n^2 2^n)\) and unlock \(\ln\), \(\exp\), and composition, we first formulate subset convolution as exact multiplication in a commutative quotient ring.

Algebraic Definition of the Set Power Series Ring \(\mathcal{R}_n\)

Fix an \(n\)-element ground set \(V = \{0, 1, \dots, n-1\}\) and a commutative ring \(K\). Introduce \(n\) formal commuting variables \(x_0, x_1, \dots, x_{n-1}\), one for each vertex in \(V\), and quotient out the square of every variable:

\[ \mathcal{R}_n = K[x_0, x_1, \dots, x_{n-1}] / (x_0^2, x_1^2, \dots, x_{n-1}^2). \]

For each subset \(S \subseteq V\), define the square-free monomial \(\mathbf{x}^S = \prod_{i \in S} x_i\). What happens when we multiply two monomials \(\mathbf{x}^T\) and \(\mathbf{x}^R\) inside \(\mathcal{R}_n\)?

  • If \(T \cap R = \varnothing\), no variable appears twice, so \(\mathbf{x}^T \cdot \mathbf{x}^R = \mathbf{x}^{T \cup R}\).
  • If \(T \cap R \neq \varnothing\), there is at least one element \(v \in T \cap R\), which produces a factor \(x_v^2 = 0\) in the quotient ring:

\[ \mathbf{x}^T \cdot \mathbf{x}^R = \begin{cases} \mathbf{x}^{T \cup R} & \text{if } T \cap R = \varnothing, \\ 0 & \text{if } T \cap R \neq \varnothing. \end{cases} \]

L1 Cache-Contiguous Memory Layout: [1<<n][n+1] vs. [n+1][1<<n]

Because \(O(n^2 2^n)\) at \(n = 20\) performs \(\approx 2.2 \times 10^8\) multiply-adds, memory layout determines whether your code runs in \(0.18\text{ s}\) or \(1.8\text{ s}\) (TLE).

ImportantHardware Reality Check: Why [1<<n][n+1] Beats [n+1][1<<n]
  • If you store the ranked array as P[n + 1][1 << n] (rank outer, mask inner), then during the pointwise \(O(n^2)\) polynomial product or ODE at a fixed mask \(M\), accessing P[0][M], P[1][M], ..., P[n][M] jumps by a stride of \(2^n \times 4\text{ bytes} = 4\text{ MB}\) per step! // Ranked Fast Zeta / Mobius Transform on L1-contiguous layout P[mask * (n + 1) + d]
void ranked_fzt(vector<mint>& P, int n, bool inv) {
    int S = n + 1;
    for (int i = 0; i < n; ++i)
        for (int mask = 0; mask < (1 << n); ++mask)
            if (mask & (1 << i)) {
                int u = (mask ^ (1 << i)) * S, v = mask * S;
                for (int d = 0; d <= n; ++d)
                    P[v + d] += inv ? -P[u + d] : P[u + d];
            }
}

24.3 Transcendental Operations on \(\mathcal{R}_n\) (\(\operatorname{inv}, \ln, \exp, P^\alpha\)), MSB Split & SPS Composition

Pointwise \(O(n^2)\) Truncated Polynomial ODEs in Ranked Zeta Space

A natural question arises: does a single Ranked FZT \(\to\) Pointwise \(\exp\)/\(\ln\) in \(K[t]/(t^{n+1})\) \(\to\) Ranked IFZT work without cleaning intermediate ranks? Yes! Why? Because for any formal power series \(G(y) = \sum_{d \ge 0} g_d y^d\) and any \(F(\mathbf{x}) = \sum_{S \neq \varnothing} F_S \mathbf{x}^S \in \mathcal{R}_n\), if we replace each variable \(x_i\) with \(t x_i\) (which multiplies \(\mathbf{x}^S\) by \(t^{|S|}\)), then \(\mathbf{x}^T \cdot \mathbf{x}^R = 0\) for overlapping \(T \cap R \neq \varnothing\) still occurs strictly in powers of \(t\) with exponent \(|T| + |R| > |T \cup R|\). Therefore, at each mask \(M \in [0, 2^n - 1]\) independently, let \(p(t) = \widehat{F}_M(t) = \sum_{k=0}^n p_k t^k \in K[t]/(t^{n+1})\). We compute \(q(t) = \sum_{k=0}^n q_k t^k\) using the exact \(O(n^2)\) recurrences from Chapter 2:

The Division-Free MSB Derivative Split (\(\exp\) and \(\ln\) in Any Characteristic)

Look closely at the table above: \(\ln F\) and \(\exp F\) via \(K[t]/(t^{n+1})\) ODEs appear to require \(1, 2, \dots, n \in K^\times\). Yet inside \(\mathcal{R}_n\), for any \(F\) with \(F_\varnothing = 0\), how can \(\exp(F) = \sum_{d=0}^n \frac{F^d}{d!}\) possibly require dividing by \(d!\) when multiplying \(d\) non-empty disjoint subsets \(T_1, \dots, T_d\) already counts each unordered partition \(\{T_1, \dots, T_d\}\) exactly \(d!\) times, canceling the \(d!\) in the denominator over \(\mathbb{Z}\)?!

Indeed, \(\exp(F)\) and \(\ln(1 + F)\) on \(\mathcal{R}_n\) are completely division-free! To see why—and to obtain an algorithm that is simultaneously \(2\times\) faster than full \(n\)-bit \(\exp/\ln\) and works over arbitrary commutative rings \(K\) (including \(\mathbb{F}_2\), \(\mathbb{Z}/2^{64}\mathbb{Z}\), and composite moduli)—isolate the highest-indexed variable \(x_v\).

Every \(F(\mathbf{x}) \in \mathcal{R}_{v+1}\) splits uniquely into terms not containing \(x_v\) and terms containing \(x_v\):

\[ F(\mathbf{x}) = F_0(\mathbf{x}) + x_v F_1(\mathbf{x}), \qquad F_0, F_1 \in \mathcal{R}_v. \]

Because \(x_v^2 = 0\) in \(\mathcal{R}_{v+1}\), the Taylor series for \(\exp(x_v F_1)\) truncates linearly at \(1 + x_v F_1\)! Therefore:

\[ \exp(F_0 + x_v F_1) = \exp(F_0) \cdot \exp(x_v F_1) = \exp(F_0) + x_v \big(\exp(F_0) *_{\text{sub}} F_1\big). \]

Let \(E_0 = \exp(F_0) \in \mathcal{R}_v\). Then transitioning from \(v\) variables to \(v+1\) variables requires only a single \(v\)-variable subset convolution \(E_0 *_{\text{sub}} F_1\)! Iterating \(v = 0, 1, \dots, n-1\) gives \(\exp(F)\) using only additions, subtractions, and multiplications in \(K\), with total work:

\[ \sum_{v=0}^{n-1} O(v^2 2^v) = O(n^2 2^n) \quad \text{(with half the constant factor of full $n$-bit $\exp$!)}. \]

Inverting this relation for \(E = E_0 + x_v E_1 = \exp(F_0 + x_v F_1)\) with \(E_\varnothing = 1\) gives \(F_0 = \ln(E_0)\) and \(E_1 = E_0 *_{\text{sub}} F_1 \implies F_1 = E_0^{-1} *_{\text{sub}} E_1\), where \(E_0^{-1}\) needs only \(E_\varnothing = 1 \in K^\times\)!

// Division-free SPS exp via MSB split: works in ANY commutative ring K!
vector<mint> sps_exp_msb(const vector<mint>& F, int n) {
    vector<mint> E(1 << n); E[0] = 1;
    for (int v = 0; v < n; ++v) { // E[0..2^v-1] already holds exp(F_0)
        vector<mint> F1(F.begin() + (1 << v), F.begin() + (2 << v));
        vector<mint> E1 = subset_conv(vector<mint>(E.begin(), E.begin() + (1 << v)), F1, v);
        copy(E1.begin(), E1.end(), E.begin() + (1 << v));
    }
    return E;
}

Elegia’s \(O(n^2 2^n)\) SPS Composition \(G(F(\mathbf{x}))\) via Taylor Shift Pyramid

What if we need a general composition \(G(F(\mathbf{x})) = \sum_{d=0}^n g_d \frac{F(\mathbf{x})^d}{d!}\) where \(F_\varnothing = 0\) and the input array g[0..n] stores the exponential generating function (EGF) derivatives \(g_d = G^{(d)}(0) \in K\) (if \(G(y) = \sum_{d=0}^n c_d y^d\) is given in ordinary generating function (OGF) form, simply pass \(g_d = c_d \cdot d!\); for example, \(g_d = [d = c]\) extracts the single divided power \(\frac{F(\mathbf{x})^c}{c!}\) without dividing by \(c!\), and \(g_d = d!\) evaluates the geometric series \((1 - F(\mathbf{x}))^{-1} = \sum_{d=0}^n F(\mathbf{x})^d\) for ordered sequences of components)?

Summing the cost of \(n - k\) subset convolutions of size \(2^k\) across \(k = 0, \dots, n-1\): \[ \sum_{k=0}^{n-1} (n - k) \cdot k^2 2^k = O(n^2 2^n). \]
// Elegia's O(n^2 2^n) SPS composition: g[d]=G^(d)(0) (EGF; pass c[d]*d! for OGF)
vector<mint> sps_compose(const vector<mint>& F, const vector<mint>& g, int n) {
    vector<vector<mint>> H(n + 1, vector<mint>(1));
    for (int d = 0; d <= n; ++d) H[d][0] = g[d];
    for (int k = 0; k < n; ++k) {
        vector<mint> Dk(F.begin() + (1 << k), F.begin() + (2 << k)); // MSB = k
        vector<vector<mint>> nxt(n - k, vector<mint>(2 << k));
        for (int d = 0; d < n - k; ++d) {
            auto prod = subset_conv(H[d + 1], Dk, k); // reuse Ranked FZT of Dk
            copy(H[d].begin(), H[d].end(), nxt[d].begin());
            copy(prod.begin(), prod.end(), nxt[d].begin() + (1 << k));
        } H.swap(nxt);
    }
    return H[0];
}

Pointed Vertex-by-Vertex Biconnected SPS \(\ln\) (#207 UOJ 94)

Taking \(C(\mathbf{x}) = \ln F(\mathbf{x})\) turns disconnected subgraphs \(F(\mathbf{x})\) into connected subgraphs \(C(\mathbf{x})\). How do we go one connectivity level deeper and strip away articulation points (cut vertices) to extract biconnected (2-vertex-connected) subgraphs on a fixed input graph \(G = (V, E)\)?

Suppose we fix a single vertex \(v \in V\) and look at all connected graphs on \(T \cup \{v\}\) (where \(T \subseteq V \setminus \{v\}\)). When is \(v\) an articulation point of a connected graph \(H\) on \(T \cup \{v\}\)? Precisely when deleting \(v\) splits \(H \setminus \{v\}\) into \(k \ge 2\) non-empty connected components on disjoint subsets \(T_1 \sqcup T_2 \sqcup \dots \sqcup T_k = T\), with each component independently attached to \(v\)!

Therefore, if we form the \((n-1)\)-variable pointed SPS at \(v\):

\[ C^{(v)}(\mathbf{x}) = \sum_{T \subseteq V \setminus \{v\}} C_{T \cup \{v\}} \mathbf{x}^T \in \mathcal{R}_{V \setminus \{v\}}, \]

then a graph on \(T \cup \{v\}\) is simply a disjoint union of \(v\)-blocks (connected graphs on \(T_i \cup \{v\}\) where \(v\) is not an articulation point)! Because the subsets \(T_i \subseteq V \setminus \{v\}\) are pairwise disjoint, taking the \((n-1)\)-variable subset logarithm

\[ \widetilde{C}^{(v)}(\mathbf{x}) = \ln C^{(v)}(\mathbf{x}) \quad \text{in } \mathcal{R}_{V \setminus \{v\}} \]

and writing its coefficients back into \(C_{T \cup \{v\}}\) exactingly strips away all graphs in which \(v\) is an articulation point, while leaving graphs where \(v \notin S\) untouched! Repeating this \((n-1)\)-variable SPS \(\ln\) sequentially for \(v = 0, 1, \dots, n-1\) eliminates every possible articulation point in \(O(n \cdot n^2 2^{n-1}) = O(n^3 2^n)\) time!

24.4 The Ring of Dirichlet Series \(\mathcal{D}_f\), Bell Series & The \(\Omega(n)\)-Derivation

Our third non-Cauchy algebra replaces \(x^i \cdot x^j = x^{i+j}\) with integer multiplication of indices \(n^{-s} \cdot m^{-s} = (nm)^{-s}\). A formal Dirichlet Generating Function (DGF) is a formal series

\[ F(s) = \sum_{n=1}^{\infty} \frac{f(n)}{n^s} \in \mathcal{D}_f, \]

equipped with Dirichlet convolution:

\[ (f *_D g)(n) = \sum_{d \mid n} f(d) \, g\!\left(\frac{n}{d}\right). \]

The multiplicative identity is \(\varepsilon(n) = [n = 1]\), and a series \(f \in \mathcal{D}_f\) is invertible (\(f \in \mathcal{D}_f^\times\)) if and only if \(f(1) \in K^\times\). By enumerating pairs \((d, k)\) with \(dk \le N\), a single Dirichlet convolution or inversion up to \(N\) takes \(\sum_{d=1}^N \lfloor N/d \rfloor = O(N \log N)\) time.

Algebraic Isomorphism with \(\mathcal{R}_n\) & Bell Series for Multiplicative Functions

By the Fundamental Theorem of Arithmetic, every integer \(n = p_1^{e_1} p_2^{e_2} \cdots p_k^{e_k}\) corresponds to a monomial \(\prod_i x_{p_i}^{e_i}\) in infinitely many prime variables \(x_2, x_3, x_5, \dots\):

  1. Square-Free Restriction: If we restrict \(f(n)\) to square-free integers (\(\mu(n) \neq 0\)) on the first \(n\) primes, then \(x_{p_i}^2 = 0\) and Dirichlet convolution becomes isomorphic to the Set Power Series ring \(\mathcal{R}_n\)!
  2. Multiplicative Functions & Bell Series: When \(f\) is multiplicative (\(f(mn) = f(m)f(n)\) for \(\gcd(m, n) = 1\)), the Dirichlet series factors as an Euler product over primes, where the behavior at prime \(p\) is captured by the 1D Bell series in \(K[[x]]\): \[ B_p(f; x) = \sum_{k=0}^{\infty} f(p^k) x^k, \qquad B_p(f *_D g; x) = B_p(f; x) \cdot B_p(g; x). \]

Diagnostic Signal & The Prime-Multiplicity \(\Omega(n)\)-Derivation

What if \(f(n)\) is not multiplicative, and we need \(\ln_D(f)\), \(\exp_D(f)\), or \(f^\alpha\) in \(\mathcal{D}_f\) up to \(N \le 10^6\)? In \(K[[x]]\), we reduced \(\exp\) and \(\ln\) to ODEs using the standard derivative \(\frac{d}{dx} x^n = n x^{n-1}\). What is the counterpart of \(\frac{d}{dx}\) inside the Dirichlet ring \(\mathcal{D}_f\)?

vector<mint> dgf_exp(const vector<mint>& f, const vector<int>& Om, int N) {
    vector<mint> g(N + 1); g[1] = 1;
    for (int d = 1; d <= N; ++d) {
        if (d >= 2) g[d] *= inv_small[Om[d]]; // finalize g[d] before pushing to multiples
        for (int k = 2; d * k <= N; ++k)
            g[d * k] += g[d] * f[k] * Om[k];
    }
    return g;
}

Mathematical Derivation

\[ F = \prod_{i=1}^m \left(\mathbf{e}_{\mathbf{1}} + \mathbf{e}_{a_i}\right) - \mathbf{e}_{\mathbf{1}} \quad \text{in } \mathbb{F}_p[(M, \mathbin{\&})], \]

Mathematical Derivation

Any forest on \(n\) vertices with \(k\) edges contains no cycles (and thus no duplicate edges) and consists of exactly \(c = n - k\) connected components, each of which is a spanning tree on its vertex subset. Furthermore, any unordered \(k\)-edge forest can be produced by \(k!\) distinct ordered sequences of \(k\) edge draws out of \(m^k\) total sequences. Thus, if \(F_k\) denotes the number of unordered \(k\)-edge spanning forests on \(V\), the desired probability is:

\[ \mathbb{P}(\text{forest at step } k) = F_k \cdot \frac{k!}{m^k} \pmod{998244353}. \]

To compute \(F_k\) for all \(k = 1, \dots, n - 1\):

  1. Spanning Trees per Subset \(T_S\): For each non-empty subset \(S \subseteq V\), build the \(|S| \times |S|\) Laplacian matrix \(L_S\) of the induced subgraph \(G[S]\) and take the \((|S|-1) \times (|S|-1)\) principal minor determinant via Gaussian elimination in \(O(|S|^3)\) (or compute \(T_S\) via SPS Matrix-Tree / edge-by-edge tree DP). In \(\mathcal{R}_n\), multiplying \(T(\mathbf{x})\) with itself \(c\) times counts ordered \(c\)-tuples of disjoint trees, so dividing by \(c!\) counts unordered \(c\)-component forests: \[ F_k = [\mathbf{x}^V] \frac{T(\mathbf{x})^{n-k}}{(n-k)!}. \]

\[ [\mathbf{x}^V] \frac{T(\mathbf{x})^c}{c!} = \frac{1}{c!} [t^n] \sum_{M=0}^{2^n - 1} (-1)^{n - \operatorname{popcount}(M)} \widehat{T}_M(t)^c. \]

Mathematical Derivation

Consider any valid outcome string on the \(m\) edges of \(G = (V, E)\). Define an equivalence relation on \(V\) where \(u \sim v\) if and only if they are connected by a path of = edges. Let \(B_1, B_2, \dots, B_r\) be the resulting equivalence classes (blocks of equal weight). For the outcome string to be consistent with real weights \(w_1, \dots, w_n\):

  1. Each block \(B_i\) must induce a connected subgraph \(G[B_i]\), and every edge of \(G\) with both endpoints in \(B_i\) must be assigned = (since all vertices in \(B_i\) have equal weight).
  2. Every edge of \(G\) between two distinct blocks \(B_i \neq B_j\) must be assigned < or >, and the resulting directed multigraph on the contracted blocks \(\{B_1, \dots, B_r\}\) must be acyclic (a DAG).

Crucially, once we know the orientation of every edge between distinct blocks \(B_i \neq B_j\), the outcome string on all \(m\) edges is uniquely determined! Now apply the standard DAG source-layer inclusion-exclusion recurrence (Chapter 13.3) to the contracted blocks: if we peel off a non-empty set of \(k\) blocks \(B_1, \dots, B_k\) that have no edges between them in \(G\) (so they are pairwise disconnected in \(G\) and can simultaneously serve as sources), inclusion-exclusion assigns weight \((-1)^{k-1}\).

\[ W_T = \begin{cases} 0 & \text{if } T = \varnothing, \\ (-1)^{c(T) - 1} & \text{if } T \neq \varnothing, \end{cases} \]

\[ C(\mathbf{x}) = \ln F(\mathbf{x}) \quad \text{in } \mathcal{R}_n \]

yields \(C_S\), the number of connected spanning subgraphs on \(S\).

Now we must eliminate all connected subgraphs that contain at least one articulation point (cut vertex). Order the vertices \(V = \{0, 1, \dots, n-1\}\). Consider how a graph \(H\) counted by \(C_{T \cup \{v\}}\) (where \(T \subseteq V \setminus \{v\}\)) behaves when we delete vertex \(v\):

\[ C^{(v)}(\mathbf{x}) = \sum_{T \subseteq V \setminus \{v\}} C_{T \cup \{v\}} \mathbf{x}^T \quad \big(\text{with } C^{(v)}_\varnothing = C_{\{v\}} = 1\big) \]

\[ C^{(v)}(\mathbf{x}) \leftarrow \ln_{\mathcal{R}_{V \setminus \{v\}}} C^{(v)}(\mathbf{x}) \]

and writing its coefficients back to \(C_{T \cup \{v\}}\) strips away all graphs where \(v\) is an articulation point. Problem Statement

Mathematical Derivation

\[ B_p(h; x) = \frac{B_p(f; x)}{B_p(g; x)} = \frac{1 + f(p) x + f(p^2) x^2 + \dots}{1 + g(p) x + g(p^2) x^2 + \dots} \quad \text{in } \mathbb{F}_p[[x]]. \]

Extracting \([x^1]\) from \(B_p(h; x) B_p(g; x) = B_p(f; x)\) gives:

\[ h(p) + g(p) h(1) = f(p) \implies h(p) = f(p) - g(p) = 0. \]

\[ h(p^k) = f(p^k) - \sum_{j=1}^{k-1} g(p^j) h(p^{k-j}) - g(p^k). \]

\[ \mathcal{P}(N) = \left\{ d \le N : p \mid d \implies p^2 \mid d \right\}. \]

\[ \sum_{n=1}^N f(n) = \sum_{n=1}^N \sum_{d \mid n} h(d) \, g\!\left(\frac{n}{d}\right) = \sum_{\substack{d \in \mathcal{P}(N)}} h(d) \, G\!\left(\left\lfloor \frac{N}{d} \right\rfloor\right). \]

        }

}

Hint 1 — Diagnostic Signal & Combinatorial Model

In any multiset of \(N\) integers \(\{A_1 \le A_2 \le \dots \le A_N\}\), the bitwise XOR \(A_1 \oplus \dots \oplus A_N\) depends only on the parity of the frequency of each value \(v \in [0, M]\)! Specifically, if \(k\) distinct values \(v_1 < v_2 < \dots < v_k\) appear an odd number of times and all other values appear an even number of times, then \(N \equiv k \pmod 2\) and the remaining \((N - k)/2\) pairs of identical elements can be assigned freely to any values in \([0, M]\)!

Mathematical Derivation

Every non-decreasing sequence \(0 \le A_1 \le A_2 \le \dots \le A_N \le M\) is uniquely identified by the multiplicity \(c_v \ge 0\) of each value \(v \in [0, M]\), where \(\sum_{v=0}^M c_v = N\). Because \(v \oplus v = 0\) in the XOR group \((\mathbb{Z}_2^{30}, \oplus)\), a value \(v\) with multiplicity \(c_v\) contributes \(x^v\) to the XOR product if \(c_v\) is odd, and \(x^0 = 1\) if \(c_v\) is even.

Therefore, in the formal power series ring \(\mathbb{F}_p[\mathbb{Z}_2^{30}][[u]]\) over the XOR group algebra, the bivariate OGF of non-decreasing sequences is:

\[ \Phi(x, u) = \prod_{v=0}^M \left(1 + x^v u + u^2 + x^v u^3 + \dots\right) = (1 - u^2)^{-(M+1)} \prod_{v=0}^M \left(1 + x^v u\right), \]

and we seek \([x^X u^N] \Phi(x, u)\).

On the other hand, let \(T_j\) be the number of ordered \(j\)-tuples \((B_1, \dots, B_j) \in [0, M]^j\) (with repetition allowed) such that \(B_1 \oplus \dots \oplus B_j = X\). By the exponential formula for labeled sequences, the EGF of ordered tuples in \(\mathbb{F}_p[\mathbb{Z}_2^{30}][[z]]\) is:

\[ \begin{aligned} \Psi(x, z) &= \sum_{j=0}^{\infty} \left(\sum_{v=0}^M x^v\right)^j \frac{z^j}{j!} = \exp\!\left(\sum_{v=0}^M x^v z\right) = \prod_{v=0}^M \exp(x^v z) \\ &= \prod_{v=0}^M \left(\sum_{m \ge 0} \frac{z^{2m}}{(2m)!} x^0 + x^v \sum_{m \ge 0} \frac{z^{2m+1}}{(2m+1)!}\right) \\ &= \prod_{v=0}^M \big(\cosh(z) + x^v \sinh(z)\big), \end{aligned} \]

where the last equality holds because \((x^v)^2 = x^{v \oplus v} = 1\) in \(\mathbb{F}_p[\mathbb{Z}_2^{30}]\)! Factoring out \(\cosh(z)\) from each of the \(M + 1\) terms yields:

\[ \Psi(x, z) = \cosh(z)^{M+1} \prod_{v=0}^M \big(1 + x^v \tanh(z)\big). \]

Now substitute \(z = \operatorname{artanh}(u) = u + \frac{u^3}{3} + \frac{u^5}{5} + \dots \in \mathbb{F}_p[[u]]\) (valid up to \(u^N\) since \(N \le 200 < p\)). Using the identity \(\cosh(\operatorname{artanh}(u)) = (1 - u^2)^{-1/2}\) and extracting \([x^X]\) on both sides gives:

\[ \sum_{j=0}^{\infty} T_j \frac{\operatorname{artanh}(u)^j}{j!} = (1 - u^2)^{-\frac{M+1}{2}} [x^X] \prod_{v=0}^M \left(1 + x^v u\right). \]

Comparing this with \(\Phi(x, u) = (1 - u^2)^{-(M+1)} \prod_{v=0}^M (1 + x^v u)\), we need only multiply by an extra factor of \((1 - u^2)^{-\frac{M+1}{2}}\) to obtain the exact OGF of our problem:

\[ \text{Ans} = [u^N] \left((1 - u^2)^{-\frac{M+1}{2}} \sum_{j=0}^N T_j \frac{\operatorname{artanh}(u)^j}{j!}\right) \pmod{998244353}. \]

To compute \(T_0, \dots, T_N\) in \(O(N^2 \log M)\): run a Digit DP from bit \(b = 29\) down to \(0\) tracking how many of the \(j\) elements remain tight to \(M\). Even simpler: classify the \(j\) elements by the highest bit \(b\) where at least one element drops strictly below \(M_b = 1\); below bit \(b\), that loose element’s bits are completely free in \(\{0, 1\}\), so the XOR of bit \(b' < b\) is automatically satisfied in exactly \(2^{j-1}\) ways per bit!

// Given T[0..N] (ordered j-tuples in [0, M]^j with XOR = X from O(N^2 log M) Digit DP):
vector<mint> A(N + 1), B(N + 1); // B(u) = artanh(u) = u + u^3/3 + u^5/5 + ...
for (int i = 1; i <= N; i += 2) B[i] = inv_small[i];
vector<mint> pw(N + 1, 0); pw[0] = 1;
for (int j = 0; j <= N; ++j) {
    mint c = T[j] * ifac[j];
    for (int i = 0; i <= N; ++i) A[i] += c * pw[i];
    pw = poly_mul_trunc(pw, B, N); // O(N^2) truncated multiplication
}
// Multiply A(u) by (1 - u^2)^{-(M+1)/2} and extract A[N]
