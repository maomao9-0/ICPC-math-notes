The Central Question

In Chapters 1 and 2, we built \(O(N \log N)\) Newton engines for specific closed-form primitives: inv solved \(F(x) G(x) - 1 = 0\), sqrt solved \(G(x)^2 - F(x) = 0\), and exp solved \(\ln G(x) - F(x) = 0\). In each case, the target series \(G(x)\) could be isolated as an explicit operation on a known series \(F(x)\).

What happens when a combinatorial class is defined recursively in terms of itself, so that \(F(x)\) cannot be isolated in closed form?

  • A rooted labeled tree is a root vertex attached to a \(\operatorname{SET}\) of rooted labeled subtrees: \(\widehat{T}(x) = x \exp(\widehat{T}(x))\).
  • A rooted unlabeled tree is a root vertex attached to an \(\operatorname{MSET}\) of rooted unlabeled subtrees: \(T(x) = x \exp\!\left(\sum_{k \ge 1} \frac{T(x^k)}{k}\right)\).
  • A two-player impartial game on rooted trees partitions trees into losing (\(\mathcal{P}\)) positions \(L(x)\) and winning (\(\mathcal{N}\)) positions \(W(x)\) satisfying a coupled exponential system \(L(x) = x \exp(W(x))\) and \(L(x) + W(x) = x \exp(L(x) + W(x))\).
  • A labeled chain-reaction tree (UOJ 50) satisfies a non-linear first-order differential equation \(F'(x) = \frac{1}{2}A(x)F(x)^2 + 1\).

In Chapter 9, we saw that CDQ divide-and-conquer FFT and online RelaxedConvolution can solve many self-referential recurrences in \(O(N \log^2 N)\) time. In this chapter, we upgrade Newton’s method into a universal \(O(N \log N)\) implicit equation solver—capable of handling general bivariate functional equations \(A(x, F(x)) = 0\), coupled multivariate systems \(\mathbf{\Phi}(x, \mathbf{F}(x)) = \mathbf{0}\), non-linear differential equations \(A(x, F(x), F'(x)) = 0\), and Pólya–Euler symmetries \(T(x^k)\)—and then pair it with Otter’s Dissimilarity Theorem to pass from rooted unlabeled trees to unrooted unlabeled trees without ever dividing by \(n\).

10.1 Upgrading from 1D Primitives to General Implicit Functional Equations \(A(x, F(x)) = 0\)

Concrete Combinatorial Motivation

Suppose we want to compute the first \(N\) coefficients \(f_0, f_1, \dots, f_{N-1}\) of a generating function \(F(x) \in K[[x]]\) that is specified implicitly by a functional equation \[A\big(x, F(x)\big) = 0.\] Concrete examples appear across all of enumerative combinatorics:

  1. Weighted Binary Trees (CF 438E — The Child and Binary Tree): A binary tree is either empty (\(1\)) or a root vertex whose weight comes from a polynomial \(C(x)\) (with \([x^0]C(x) = 0\)) attached to an ordered pair of binary trees: \[F(x) = 1 + C(x) F(x)^2 \quad \Longleftrightarrow \quad A\big(x, F(x)\big) = C(x) F(x)^2 - F(x) + 1 = 0.\]
  2. Rooted Labeled Trees with Degree Constraints: If every vertex in a rooted labeled tree has out-degree weighted by an EGF \(\Phi(y) = \sum_{d \ge 0} \frac{\phi_d}{d!} y^d\), then removing the root decomposes \(F(x)\) into \(x \cdot \Phi(F(x))\): \[F(x) = x \Phi\big(F(x)\big) \quad \Longleftrightarrow \quad A\big(x, F(x)\big) = F(x) - x \Phi\big(F(x)\big) = 0.\]
  3. Rooted Labeled Cacti (LOJ 6569 / Luogu P5434): Removing the root vertex splits a cactus into a \(\operatorname{SET}\) of edges (each carrying a rooted cactus \(F(x)\)) and simple cycles (each carrying a sequence of \(\ge 2\) rooted cacti up to reflection, \(\frac{F(x)^2}{2(1 - F(x))}\)): \[F(x) = x \exp\!\left(F(x) + \frac{F(x)^2}{2\big(1 - F(x)\big)}\right) = x \exp\!\left(\frac{2F(x) - F(x)^2}{2\big(1 - F(x)\big)}\right).\]

When is \(A(x, F(x))\) Algebraically Well-Defined?

Before differentiating or inverting anything, we must state what \(A(x, y)\) is and why substituting \(y = F(x)\) produces a well-defined formal power series in \(K[[x]]\) without infinite coefficient sums.

Write \(A(x, y) = \sum_{j=0}^{\infty} a_j(x) (y - f_0)^j \in K[[x]][[y - f_0]]\), where \(f_0 = [x^0]F(x) \in K\) is the constant term of \(F(x)\) and each \(a_j(x) \in K[[x]]\). When we substitute \(y = F(x)\), the difference \(\widetilde{F}(x) = F(x) - f_0\) has positive valuation \(\operatorname{val}(\widetilde{F}) \ge 1\), so \(\operatorname{val}\!\big((F(x) - f_0)^j\big) \ge j\). Consequently, for every target degree \(n \ge 0\), only terms with \(j \le n\) can contribute to \([x^n]A(x, F(x))\)! The infinite sum over \(j\) is therefore locally finite in the \(x\)-adic topology.

For the partial derivative with respect to the second slot \(y\), we define the formal partial derivative \(\frac{\partial A}{\partial y}(x, y)\) (also denoted \(A_y(x, y)\) or \(\partial_y A(x, y)\)) by differentiating term-by-term with respect to \(y\) while holding \(x\) fixed: \[\frac{\partial A}{\partial y}(x, y) := \sum_{j=1}^{\infty} j\, a_j(x) (y - f_0)^{j-1}.\]

Theorem 10.1 (Formal Implicit Function Theorem & 1D Newton Iteration over \(K[[x]]\))

Let \(K\) be a commutative ring, let \(f_0 \in K\), and let \(A(x, y) = \sum_{j \ge 0} a_j(x)(y - f_0)^j \in K[[x]][[y - f_0]]\). Suppose that the following two local algebraic hypotheses hold at \(x = 0\):

  1. Consistent Base Case: \([x^0]A(0, f_0) = a_0(0) = 0\).
  2. Invertible Initial Jacobian (Separability): \(\frac{\partial A}{\partial y}(0, f_0) = a_1(0) \in K^\times\) is a multiplicative unit in \(K\).

Then:

  • Uniqueness & Existence: There exists a unique formal power series \(F(x) \in K[[x]]\) with \([x^0]F(x) = f_0\) such that \(A(x, F(x)) = 0\) in \(K[[x]]\).
  • Quadratic Newton Doubling: Starting from the degree-\(1\) base approximation \(F_0(x) = f_0 \pmod{x^1}\), the sequence of polynomials \(F_k(x) \in K[x]\) (\(\deg F_k < 2^k\)) defined recursively by \[F_{k+1}(x) \equiv F_k(x) - \frac{A\big(x, F_k(x)\big)}{\frac{\partial A}{\partial y}\big(x, F_k(x)\big)} \pmod{x^{2^{k+1}}}\] is well-defined for all \(k \ge 0\) and satisfies \(F_k(x) \equiv F(x) \pmod{x^{2^k}}\).

Single-Step Verbalized Proof

We prove the theorem by induction on the precision exponent \(k\), simultaneously establishing existence, uniqueness, and the quadratic convergence of \(F_k(x)\).

  1. Bivariate Formal Taylor Expansion around \(y = F_k(x)\): For any two series \(F(x), F_k(x) \in K[[x]]\) sharing the constant term \(f_0\), expand each term \((y - f_0)^j = \big((F_k - f_0) + (F - F_k)\big)^j\) by the binomial theorem and collect powers of the error \(\Delta_k(x) := F(x) - F_k(x)\): \[A\big(x, F(x)\big) = A\big(x, F_k(x)\big) + \frac{\partial A}{\partial y}\big(x, F_k(x)\big)\big(F(x) - F_k(x)\big) + \sum_{r=2}^{\infty} A^{[r]}\big(x, F_k(x)\big)\big(F(x) - F_k(x)\big)^r,\] where \(A^{[r]}(x, y) = \sum_{j \ge r} \binom{j}{r} a_j(x) (y - f_0)^{j-r} \in K[[x]][[y - f_0]]\) is the \(r\)-th Hasse–Schmidt divided derivative of \(A\) with respect to \(y\) (note that \(\binom{j}{r}\) is an integer, so this expansion requires no division by \(r!\) and holds in arbitrary characteristic!).
  2. Vanishing of Higher-Order Terms Modulo \(x^{2^{k+1}}\): By the induction hypothesis, \(F(x) \equiv F_k(x) \pmod{x^{2^k}}\), which means \(\operatorname{val}(F - F_k) \ge 2^k\). Therefore, for every \(r \ge 2\), \[\operatorname{val}\!\Big(\big(F(x) - F_k(x)\big)^r\Big) = r \cdot \operatorname{val}(F - F_k) \ge 2 \cdot 2^k = 2^{k+1}.\] Reducing the Taylor expansion modulo \(x^{2^{k+1}}\) annihilates the entire sum over \(r \ge 2\), leaving the exact linear congruence: \[A\big(x, F(x)\big) \equiv A\big(x, F_k(x)\big) + \frac{\partial A}{\partial y}\big(x, F_k(x)\big)\big(F(x) - F_k(x)\big) \pmod{x^{2^{k+1}}}.\]
  3. Invertibility of the Denominator \(\frac{\partial A}{\partial y}(x, F_k(x))\): What is the constant term \([x^0]\frac{\partial A}{\partial y}(x, F_k(x))\)? Since \([x^0]F_k(x) = f_0\), evaluating at \(x = 0\) gives \[[x^0]\frac{\partial A}{\partial y}\big(x, F_k(x)\big) = \frac{\partial A}{\partial y}(0, f_0) = a_1(0) \in K^\times.\] By Theorem 1.1 of Chapter 1, a formal power series is a unit in \(K[[x]]\) (and hence in \(K[[x]]/(x^{2^{k+1}})\)) if and only if its constant term is a unit in \(K\).
  4. Solving for \(F(x) \bmod x^{2^{k+1}}\): Setting \(A(x, F(x)) = 0\) and multiplying both sides of the congruence by \(\left(\frac{\partial A}{\partial y}(x, F_k(x))\right)^{-1} \bmod x^{2^{k+1}}\) uniquely forces \[F(x) \equiv F_k(x) - \frac{A\big(x, F_k(x)\big)}{\frac{\partial A}{\partial y}\big(x, F_k(x)\big)} \equiv F_{k+1}(x) \pmod{x^{2^{k+1}}}. \qquad \blacksquare\]
TipThe Diagnostic Signal & Reverse-Engineering Scratchpad: 1D Implicit Newton & The Logarithmic Speedup

Diagnostic Signal: You have a recursive combinatorial specification for \(F(x)\) where all coefficients \(f_0, f_1, \dots, f_N\) are needed (or \(F(x)\) is not of the simple Lagrange form \(x\Phi(F)\)), and evaluating \(A(x, F_k)\) and \(\partial_y A(x, F_k)\) takes \(O(2^k \log(2^k))\) time using known FPS primitives (mul, inv, ln, exp).

Reverse-Engineering Scratchpad:

  1. Write the equation in zero-residual form \(A(x, y) = 0\): Treat \(x\) as a constant parameter and \(y = F(x)\) as the variable being solved for.

  2. Check the Constant-Term Jacobian before differentiating: Evaluate \(f_0 = F(0)\). Check that \(A(0, f_0) = 0\) and \(\partial_y A(0, f_0) \in K^\times\).

  3. The Logarithmic Newton Speedup for \(F(x) = x \exp\!\big(G(x, F(x))\big)\): Many labeled tree and graph specifications have the exponential form \(F(x) = x \exp\!\big(G(x, F(x))\big)\), where \(F(0) = 0\) and \([x^1]F(x) = \exp(G(0, 0)) = 1\).

    • Naive Form: \(A(x, y) = y - x \exp(G(x, y)) = 0\). Every doubling step \(2^k \to 2^{k+1}\) must compute \(\exp(G(x, F_k)) \bmod x^{2^{k+1}}\), calling polynomial exp inside the Newton loop!
    • Logarithmic Form: Write \(F(x) = x \widetilde{F}(x)\) with \(\widetilde{F}(0) = 1\), divide by \(x\), and take formal logarithms: \[\widetilde{A}(x, y) := \ln\!\left(\frac{y}{x}\right) - G(x, y) = 0.\] Differentiating with respect to \(y\) gives \(\frac{\partial \widetilde{A}}{\partial y}(x, y) = \frac{1}{y} - \frac{\partial G}{\partial y}(x, y) = \frac{1 - y G_y(x, y)}{y}\). Substituting into Newton’s formula \(F_{k+1} = F_k - \widetilde{A} / \widetilde{A}_y\) multiplies the \(1/F_k\) into the numerator: \[F_{k+1}(x) \equiv F_k(x) \left( 1 - \frac{\ln\!\big(F_k(x)/x\big) - G\big(x, F_k(x)\big)}{1 - F_k(x)\,\frac{\partial G}{\partial y}\big(x, F_k(x)\big)} \right) \pmod{x^{2^{k+1}}}.\] Notice what happened: polynomial exp has completely vanished from the Newton loop, replaced by a single call to ln on the unit series \(F_k(x)/x\), cutting the constant factor in half!

Worked Example & Hand-Checkable Trace (\(N = 4\)): CF 438E — The Child and Binary Tree Revisited

Let us trace Theorem 10.1 on the quadratic binary-tree equation \[A(x, y) = C(x) y^2 - y + 1 = 0,\] where \(C(x) = \sum_{i \ge 1} c_i x^i\) with \([x^0]C(x) = 0\).

  1. Base Case & Partial Derivative: At \(x = 0\), \(C(0) = 0\), so \(A(0, f_0) = -f_0 + 1 = 0 \implies f_0 = 1\). Differentiating \(A(x, y) = C(x)y^2 - y + 1\) with respect to \(y\) (holding \(x\) and therefore \(C(x)\) fixed) gives: \[\frac{\partial A}{\partial y}(x, y) = 2 C(x) y - 1.\] At \((0, f_0) = (0, 1)\), we have \(\frac{\partial A}{\partial y}(0, 1) = 2(0)(1) - 1 = -1 \in K^\times\), which is invertible in every ring \(K\) (even in characteristic \(2\)!).
  2. Newton Update Formula: Substituting \(A(x, F_k) = C F_k^2 - F_k + 1\) and \(\partial_y A(x, F_k) = 2 C F_k - 1\) into Theorem 10.1 yields: \[F_{k+1}(x) \equiv F_k(x) - \frac{C(x) F_k(x)^2 - F_k(x) + 1}{2 C(x) F_k(x) - 1} \equiv \frac{C(x) F_k(x)^2 - 1}{2 C(x) F_k(x) - 1} \pmod{x^{2^{k+1}}}.\]
  3. Explicit Coefficient Trace for \(C(x) = x\) (Catalan Numbers) up to \(x^4\):
    • Init (\(2^0 = 1\)): \(F_0(x) = 1 \pmod{x^1}\).
    • Step \(k = 0\) (\(1 \to 2\), working \(\bmod x^2\)): \[C(x)F_0(x)^2 - 1 = x(1)^2 - 1 = -1 + x, \qquad 2C(x)F_0(x) - 1 = 2x - 1 = -(1 - 2x).\] Since \((1 - 2x)^{-1} \equiv 1 + 2x \pmod{x^2}\), we get: \[F_1(x) \equiv \frac{1 - x}{1 - 2x} \equiv (1 - x)(1 + 2x) \equiv 1 + x \pmod{x^2}.\]
    • Step \(k = 1\) (\(2 \to 4\), working \(\bmod x^4\)): With \(F_1(x) = 1 + x\), we have \(F_1(x)^2 = 1 + 2x + x^2\), so: \[1 - C(x)F_1(x)^2 = 1 - x - 2x^2 - x^3, \qquad 1 - 2C(x)F_1(x) = 1 - 2x - 2x^2.\] Inverting \(1 - 2x(1 + x) \bmod x^4\) gives \(1 + 2x(1+x) + 4x^2(1+x)^2 + 8x^3 \equiv 1 + 2x + 6x^2 + 16x^3 \pmod{x^4}\). Multiplying by \(1 - x - 2x^2 - x^3 \bmod x^4\): \[F_2(x) \equiv (1 - x - 2x^2 - x^3)(1 + 2x + 6x^2 + 16x^3) \equiv 1 + x + 2x^2 + 5x^3 \pmod{x^4}.\] One more step gives \(F_3(x) \equiv 1 + x + 2x^2 + 5x^3 + 14x^4 + \dots \pmod{x^8}\), matching the Catalan numbers \(C_0 = 1, C_1 = 1, C_2 = 2, C_3 = 5, C_4 = 14\)!

10.2 Coupled \(2 \times 2\) / \(d \times d\) Multivariate Newton Systems & Integrating-Factor Differential Newton

Concrete Combinatorial Motivation

In many advanced enumeration problems, a single generating function is not enough:

  1. Multi-Colored / Multi-Type Trees (yukicoder 3029, fps_24_f): A rooted tree has two vertex colors (say Red \(F(x)\) and Blue \(G(x)\)) whose branching rules depend on each other, producing a coupled system \[\Phi_1\big(x, F(x), G(x)\big) = 0, \qquad \Phi_2\big(x, F(x), G(x)\big) = 0.\]
  2. Differential-Algebraic Specifications (#206 UOJ 50 — [UR #3] 链式反应): A recursive specification involves pointing or ordered-label insertion, which translates combinatorially into the derivative \(F'(x)\) paired with nonlinear powers \(F(x)^2\): \[F'(x) = \frac{1}{2} A(x) F(x)^2 + 1, \qquad F(0) = f_0\] (with \(f_0 = 0\) in UOJ 50 where trees have size \(\ge 1\), or \(f_0 = 1\) when an empty structure of weight \(1\) is included).

How do we lift our \(O(N \log N)\) Newton engine to coupled multivariate systems and nonlinear differential equations?

Theorem 10.2 (Coupled Multivariate Newton Iteration & Explicit \(2 \times 2\) Jacobian Inversion)

Let \(\mathbf{F}(x) = (F_1(x), \dots, F_d(x))^T \in K[[x]]^d\) be a vector of \(d\) formal power series with initial constant vector \(\mathbf{f}_0 = \mathbf{F}(0) \in K^d\), and let \(\mathbf{\Phi}(x, \mathbf{y}) = (\Phi_1(x, \mathbf{y}), \dots, \Phi_d(x, \mathbf{y}))^T \in K[[x]][[\mathbf{y} - \mathbf{f}_0]]^d\). Define the \(d \times d\) Jacobian matrix \[J_{\mathbf{\Phi}}(x, \mathbf{y}) := \begin{pmatrix} \frac{\partial \Phi_1}{\partial y_1} & \cdots & \frac{\partial \Phi_1}{\partial y_d} \\ \vdots & \ddots & \vdots \\ \frac{\partial \Phi_d}{\partial y_1} & \cdots & \frac{\partial \Phi_d}{\partial y_d} \end{pmatrix} \in M_d\big(K[[x]][[\mathbf{y} - \mathbf{f}_0]]\big).\] If \(\mathbf{\Phi}(0, \mathbf{f}_0) = \mathbf{0}\) and the scalar determinant at \(x = 0\) is a unit in \(K\): \[\det J_{\mathbf{\Phi}}(0, \mathbf{f}_0) \in K^\times,\] then there exists a unique solution \(\mathbf{F}(x) \in K[[x]]^d\) with \(\mathbf{F}(0) = \mathbf{f}_0\) satisfying \(\mathbf{\Phi}(x, \mathbf{F}(x)) = \mathbf{0}\). Moreover, starting from \(\mathbf{F}_0(x) = \mathbf{f}_0 \bmod x^1\), the iteration \[\mathbf{F}_{k+1}(x) \equiv \mathbf{F}_k(x) - J_{\mathbf{\Phi}}\big(x, \mathbf{F}_k(x)\big)^{-1} \mathbf{\Phi}\big(x, \mathbf{F}_k(x)\big) \pmod{x^{2^{k+1}}}\] doubles the number of correct coefficients at every step.

Explicit \(2 \times 2\) Cramér / Adjugate Update Formula

For a coupled \(2 \times 2\) system \(\Phi_1(x, F, G) = 0\) and \(\Phi_2(x, F, G) = 0\), let \(J_{11} = \partial_F \Phi_1\), \(J_{12} = \partial_G \Phi_1\), \(J_{21} = \partial_F \Phi_2\), and \(J_{22} = \partial_G \Phi_2\) evaluated at \((x, F_k(x), G_k(x)) \bmod x^{2^{k+1}}\). By the adjugate formula for a \(2 \times 2\) matrix, we need only one scalar polynomial inversion of the determinant \(\Delta_{\det}(x) := (J_{11} J_{22} - J_{12} J_{21}) \bmod x^{2^{k+1}}\): \[\begin{pmatrix} F_{k+1}(x) \\ G_{k+1}(x) \end{pmatrix} \equiv \begin{pmatrix} F_k(x) \\ G_k(x) \end{pmatrix} - \Delta_{\det}(x)^{-1} \begin{pmatrix} J_{22}(x) \Phi_1(x) - J_{12}(x) \Phi_2(x) \\ -J_{21}(x) \Phi_1(x) + J_{11}(x) \Phi_2(x) \end{pmatrix} \pmod{x^{2^{k+1}}}.\]

Why Naive Algebraic Newton Fails on \(F'(x) - \Phi(x, F(x)) = 0\)

Suppose we know \(F_k(x) \equiv F(x) \pmod{x^{2^k}}\) and write \(F(x) = F_k(x) + \Delta(x)\) where \(\operatorname{val}(\Delta) \ge 2^k\). Notice that \[\operatorname{val}\big(\Delta'(x)\big) \ge 2^k - 1, \qquad \operatorname{val}\big(\Delta(x)\big) \ge 2^k, \qquad \operatorname{val}\big(\Delta(x)^2\big) \ge 2^{k+1}.\] Both \(\Delta'(x)\) and \(\Delta(x)\) are first-order terms (having valuation \(< 2^{k+1}\))! If you ignore \(\Delta'(x)\) or treat \(F'(x)\) as an algebraic constant during the Newton step, you fail to cancel terms of degree \(2^k \dots 2^{k+1}-1\). Instead, we must keep both linear terms \(\Delta'(x)\) and \(\frac{\partial \Phi}{\partial y}(x, F_k)\Delta(x)\)!

Reverse-Engineering Scratchpad: Linearizing a Non-Linear ODE into a 1st-Order Linear ODE

Let us substitute \(F(x) = F_k(x) + \Delta(x)\) into \(F'(x) - \Phi(x, F(x)) = 0\) and expand in powers of \(\Delta(x)\):

  1. Taylor Expand the Right-Hand Side Modulo \(x^{2^{k+1}}\): Since \(\operatorname{val}(\Delta) \ge 2^k\), we have \(\Delta(x)^2 \equiv 0 \pmod{x^{2^{k+1}}}\). Thus: \[\Phi\big(x, F_k(x) + \Delta(x)\big) \equiv \Phi\big(x, F_k(x)\big) + \frac{\partial \Phi}{\partial y}\big(x, F_k(x)\big) \Delta(x) \pmod{x^{2^{k+1}}}.\]
  2. Collect First-Order Terms in \(\Delta'(x)\) and \(\Delta(x)\): Substituting \(F'(x) = F_k'(x) + \Delta'(x)\) gives: \[F_k'(x) + \Delta'(x) \equiv \Phi\big(x, F_k(x)\big) + \frac{\partial \Phi}{\partial y}\big(x, F_k(x)\big) \Delta(x) \pmod{x^{2^{k+1}}}.\] Rearranging all terms involving the unknown correction \(\Delta(x)\) to the left-hand side produces a first-order linear ODE for \(\Delta(x)\) modulo \(x^{2^{k+1}}\): \[\Delta'(x) + P_k(x) \Delta(x) \equiv Q_k(x) \pmod{x^{2^{k+1}}}, \qquad \Delta(0) = 0,\] where the known coefficient series are: \[P_k(x) := -\frac{\partial \Phi}{\partial y}\big(x, F_k(x)\big) \bmod x^{2^{k+1}}, \qquad Q_k(x) := \Big(\Phi\big(x, F_k(x)\big) - F_k'(x)\Big) \bmod x^{2^{k+1}}.\]
  3. Solve via the Ch 02 Integrating Factor \(\mu_k(x)\): By Section 2.4 of Chapter 2, define the integrating factor \[\mu_k(x) := \exp\!\left(\int_0^x P_k(t)\,dt\right) \bmod x^{2^{k+1}}.\] Since \(\mu_k'(x) = P_k(x) \mu_k(x)\), multiplying the linearized ODE by \(\mu_k(x)\) collapses the left-hand side by the product rule into an exact derivative: \[\big(\mu_k(x) \Delta(x)\big)' \equiv \mu_k(x) Q_k(x) \pmod{x^{2^{k+1}}-1}.\] Integrating term-by-term with \(\Delta(0) = 0\) and multiplying by \(\mu_k(x)^{-1}\) yields the Integrating-Factor Differential Newton Update: \[F_{k+1}(x) \equiv F_k(x) + \mu_k(x)^{-1} \int_0^x \mu_k(t)\Big(\Phi\big(t, F_k(t)\big) - F_k'(t)\Big)\,dt \pmod{x^{2^{k+1}}}.\] Alternatively, substituting \(\Delta(x) = F_{k+1}(x) - F_k(x)\) before integrating writes \(\big(\mu_k F_{k+1}\big)' \equiv \mu_k \big(\Phi(x, F_k) + P_k F_k\big)\), so: \[F_{k+1}(x) \equiv \mu_k(x)^{-1} \left( f_0 + \int_0^x \mu_k(t)\Big(\Phi\big(t, F_k(t)\big) - \frac{\partial \Phi}{\partial y}\big(t, F_k(t)\big) F_k(t)\Big)\,dt \right) \pmod{x^{2^{k+1}}}.\]

10.3 Pólya–Euler Unlabeled Rooted Trees & The Higher-Power Trick

Concrete Combinatorial Motivation

Let \(T_n\) be the number of non-isomorphic unlabeled rooted trees on \(n\) vertices (\(T_1 = 1, T_2 = 1, T_3 = 2, T_4 = 4, T_5 = 9\)), and let \[T(x) = \sum_{n=1}^{\infty} T_n x^n \in \mathbb{Q}[[x]]\] be its Ordinary Generating Function (OGF). Notice that \(\operatorname{val}(T) = 1\) because a rooted tree must have at least its root vertex (\(T_0 = 0, T_1 = 1\)).

How is an unlabeled rooted tree constructed? When we delete the root vertex, the remaining \(n - 1\) vertices split into an unordered multiset of unlabeled rooted subtrees! Because the vertices are unlabeled, two subtrees are indistinguishable if and only if they are isomorphic as rooted trees, and the order of the children does not matter. Therefore, by the Symbolic Method of Chapter 3 (Theorem 3.1, the Euler Transform \(\operatorname{MSET}\)), \(\mathcal{T} = \mathcal{Z} \times \operatorname{MSET}(\mathcal{T})\) translates directly into Cayley’s Unlabeled Rooted Tree Equation: \[T(x) = x \cdot \operatorname{MSET}(T)(x) = x \exp\!\left( \sum_{k=1}^{\infty} \frac{T(x^k)}{k} \right).\]

Look closely at the two equations above: \[T(x) - x \exp\!\left(T(x) + \sum_{k=2}^{\infty} \frac{T(x^k)}{k}\right) = 0 \quad \text{and} \quad A(x) - 1 - \frac{x}{6}\Big(A(x)^3 + 3A(x)A(x^2) + 2A(x^3)\Big) = 0.\] Unlike the equations in Section 10.1, these equations contain substituted higher powers \(T(x^2), T(x^3), \dots, T(x^k)\)! When we apply Newton’s method to lift our known approximation from \(x^{2^s}\) to \(x^{2^{s+1}}\), how do we differentiate \(T(x^k)\) with respect to \(T(x)\)?

Theorem 10.3 (Frobenius-Shift Decoupling in Newton Doubling): Suppose we are at step \(s \ge 0\) of Newton’s method (\(d = 2^s \ge 1\)), so we already know \(F_d(x) \in K[x]\) (\(\deg F_d < d\)) such that \[F(x) \equiv F_d(x) \pmod{x^d}.\] Then for every integer \(k \ge 2\): \[F(x^k) \equiv F_d(x^k) \pmod{x^{2d}}.\] Consequently, during the doubling step from \(\bmod x^d\) to \(\bmod x^{2d}\), every substituted series \(F(x^k)\) for \(k \ge 2\) is already completely known modulo \(x^{2d}\), and its variation with respect to the unknown upper half \(\Delta(x) = F(x) - F_d(x)\) is identically zero modulo \(x^{2d}\)!

10.4 Otter’s Dissimilarity Theorem for Unrooted Unlabeled Trees

Concrete Combinatorial Motivation (Unlabeled Tree Pitfall A: Why \(t_n \neq T_n / n\))

Suppose we have computed the OGF \(T(x) = \sum_{n \ge 1} T_n x^n\) of rooted unlabeled trees in \(O(N \log N)\) time using Section 10.3. Now we want the OGF \[t(x) = \sum_{n=1}^{\infty} t_n x^n\] of unrooted unlabeled trees (#186 Luogu P5900).

In Chapter 4 (Section 4.3), passing from rooted labeled trees to unrooted labeled trees was trivial: an unrooted labeled tree on \(n\) distinct vertices \(\{1, 2, \dots, n\}\) has \(n\) distinguishable vertices, so there are always exactly \(n\) ways to pick a root, and \(t_n^{\text{labeled}} = \frac{1}{n} T_n^{\text{labeled}} = \frac{1}{n} n^{n-1} = n^{n-2}\).

Why does dividing by \(n\) fail completely for unlabeled trees? Let us check \(n = 4\). As we just found, there are \(T_4 = 4\) rooted unlabeled trees on \(4\) vertices. If we divided by \(n = 4\), we would guess \(t_4 = 4 / 4 = 1\). Yet there are clearly \(t_4 = 2\) non-isomorphic unrooted unlabeled trees on \(4\) vertices: the path graph \(P_4\) and the star graph \(K_{1,3}\)!

Why did \(P_4\) and \(K_{1,3}\) produce only \(4\) rooted trees in total instead of \(2 \times 4 = 8\)? Because automorphisms identify symmetric vertices:

  • In the path \(P_4\) (\(v_1 - v_2 - v_3 - v_4\)), the reflection automorphism swaps \(v_1 \leftrightarrow v_4\) and \(v_2 \leftrightarrow v_3\). Rooting \(P_4\) at \(v_1\) or \(v_4\) yields the same unlabeled rooted tree, and rooting at \(v_2\) or \(v_3\) yields the same unlabeled rooted tree. Thus \(P_4\) contributes only \(2\) rooted trees (the number of vertex orbits under \(\operatorname{Aut}(P_4)\)), not \(4\)!
  • In the star \(K_{1,3}\) (center \(c\) connected to leaves \(l_1, l_2, l_3\)), any permutation in \(S_3\) of the three leaves is an automorphism. Rooting at \(l_1, l_2,\) or \(l_3\) produces the same unlabeled rooted tree, so \(K_{1,3}\) also contributes only \(2\) rooted trees (root at center vs. root at a leaf), not \(4\)!

How can we count each unrooted tree \(\tau\) with weight exactly \(1\) when we only know how to count rooted configurations (which weight \(\tau\) by its number of orbits)?

For any tree \(\tau\), Euler’s vertex-edge identity says \(|V(\tau)| - |E(\tau)| = 1\). In 1948, Richard Otter discovered a breathtaking generalization: Euler’s identity \(|V| - |E| = 1\) continues to hold at the level of automorphism orbits, after a tiny correction for edges whose two endpoints are swapped by a reflection symmetry!

Theorem 10.4 (Otter’s Dissimilarity / Dissymmetry Theorem, 1948)

Let \(\tau = (V, E)\) be any finite unrooted tree, and let \(\Gamma = \operatorname{Aut}(\tau)\) be its automorphism group. Define three orbit counts on \(\tau\):

  1. \(V^*(\tau) := |V / \Gamma|\) (the number of dissimilar vertices, or vertex orbits under \(\Gamma\)): the number of non-isomorphic ways to root \(\tau\) at a vertex.
  2. \(E^*(\tau) := |E / \Gamma|\) (the number of dissimilar undirected edges, or edge orbits under \(\Gamma\)): the number of non-isomorphic ways to distinguish an unordered edge of \(\tau\).
  3. \(E_{\text{sym}}(\tau)\) (the number of symmetric edge orbits): the number of edge orbits containing an edge \(e = \{u, v\} \in E\) for which there exists an automorphism \(\gamma \in \Gamma\) with \(\gamma(u) = v\) and \(\gamma(v) = u\) (equivalently, deleting \(e\) splits \(\tau\) into two isomorphic rooted subtrees \((T_u, u) \cong (T_v, v)\)).

Then for every finite tree \(\tau\), \[V^*(\tau) - \Big( E^*(\tau) - E_{\text{sym}}(\tau) \Big) = 1.\] Consequently, the ordinary generating function \(t(x)\) of unrooted unlabeled trees is given in terms of the OGF \(T(x)\) of rooted unlabeled trees by: \[t(x) = T(x) - \frac{1}{2}\Big( T(x)^2 - T(x^2) \Big).\]

Single-Step Verbalized Proof (Combinatorial Bijection on Tree Orbits + GF Translation)

Part 1: Proving the Orbit Identity \(V^*(\tau) - E^*(\tau) + E_{\text{sym}}(\tau) = 1\) for Every Tree \(\tau\)

Recall Jordan’s classical theorem on the center of a finite tree \(\tau\): if we simultaneously delete all leaves (vertices of degree \(1\)) of \(\tau\) and repeat until at most \(2\) vertices remain, we terminate at either a single central vertex \(c_0\) (if \(\operatorname{diam}(\tau)\) is even) or a single central edge \(e_0 = \{c_1, c_2\}\) (if \(\operatorname{diam}(\tau)\) is odd). Because leaf-stripping is purely structural, every automorphism \(\gamma \in \Gamma = \operatorname{Aut}(\tau)\) maps the center of \(\tau\) to itself!

First, notice that a tree can have at most one symmetric edge (\(E_{\text{sym}}(\tau) \in \{0, 1\}\)): if an automorphism \(\gamma\) swaps the endpoints of an edge \(e = \{u, v\}\), then the two subtrees \(T_u\) and \(T_v\) formed by deleting \(e\) must have the exact same height and size, forcing \(e\) to be the unique central edge \(e_0\) of \(\tau\)!

This splits all finite trees \(\tau\) into two mutually exclusive cases:

  • Case A: \(E_{\text{sym}}(\tau) = 1\) (Bicentered Tree with a Symmetric Central Edge \(e_0 = \{c_1, c_2\}\)): Since some automorphism swaps \(c_1 \leftrightarrow c_2\), the two central vertices \(c_1\) and \(c_2\) belong to the same vertex orbit \(c^* = \{c_1, c_2\} \in V^*(\tau)\). For every vertex \(v \notin \{c_1, c_2\}\), there is a unique first edge \(e(v)\) on the unique simple path from \(v\) toward the central edge \(e_0\). Because \(\Gamma\) preserves \(e_0\) and preserves graph distance to \(e_0\), the map \(v \mapsto e(v)\) induces a bijection between the non-central vertex orbits \(V^*(\tau) \setminus \{c^*\}\) and the non-central edge orbits \(E^*(\tau) \setminus \{[e_0]\}\): \[V^*(\tau) - 1 = E^*(\tau) - 1 \implies V^*(\tau) - E^*(\tau) = 0.\] Since \(E_{\text{sym}}(\tau) = 1\), adding \(E_{\text{sym}}(\tau)\) gives \(V^*(\tau) - E^*(\tau) + E_{\text{sym}}(\tau) = 0 + 1 = 1\).
  • Case B: \(E_{\text{sym}}(\tau) = 0\) (Unicentered Tree, or Bicentered Tree with an Asymmetric Central Edge): If \(\tau\) has a single center vertex \(c_0\), then \(\Gamma\) fixes \(c_0\). If \(\tau\) has a central edge \(e_0 = \{c_1, c_2\}\), then because \(E_{\text{sym}}(\tau) = 0\), no automorphism swaps \(c_1\) and \(c_2\) (the rooted subtrees \((T_{c_1}, c_1)\) and \((T_{c_2}, c_2)\) are non-isomorphic), so \(\Gamma\) fixes \(c_1\) and fixes \(c_2\) individually; we designate \(c_0 := c_1\) as the canonical root. In either subcase, \(c^* = \{c_0\} \in V^*(\tau)\) is a singleton vertex orbit fixed by all of \(\Gamma\). For every vertex \(v \neq c_0\), let \(e(v)\) be the unique first edge on the path from \(v\) to \(c_0\). Because \(\Gamma\) fixes \(c_0\), the map \(v \mapsto e(v)\) induces a bijection between \(V^*(\tau) \setminus \{c^*\}\) and all edge orbits \(E^*(\tau)\): \[V^*(\tau) - 1 = E^*(\tau) \implies V^*(\tau) - E^*(\tau) = 1.\] Since \(E_{\text{sym}}(\tau) = 0\), we again have \(V^*(\tau) - E^*(\tau) + E_{\text{sym}}(\tau) = 1 + 0 = 1\)!

Part 2: Translating the Orbit Identity into Generating Functions

Sum the identity \(1 = V^*(\tau) - E^*(\tau) + E_{\text{sym}}(\tau)\) over all unrooted unlabeled trees \(\tau\), weighted by \(x^{|\tau|}\): \[t(x) = \sum_{\tau} 1 \cdot x^{|\tau|} = \sum_{\tau} V^*(\tau) x^{|\tau|} - \sum_{\tau} E^*(\tau) x^{|\tau|} + \sum_{\tau} E_{\text{sym}}(\tau) x^{|\tau|}.\] Let us evaluate each of the three sums on the right-hand side:

  1. Vertex-Rooted Trees \(\sum_{\tau} V^*(\tau) x^{|\tau|}\): Choosing an unrooted tree \(\tau\) and one of its \(V^*(\tau)\) vertex orbits is bijectively equivalent to choosing an unlabeled vertex-rooted tree. Thus: \[\sum_{\tau} V^*(\tau) x^{|\tau|} = T(x).\]
  2. Unordered Edge-Rooted Trees \(\sum_{\tau} E^*(\tau) x^{|\tau|}\): Choosing an unrooted tree \(\tau\) and one of its \(E^*(\tau)\) undirected edge orbits \(e = \{u, v\}\), and then deleting \(e\), decomposes the tree into an unordered pair (multiset of size \(2\)) of nonempty vertex-rooted subtrees \(\{(T_u, u), (T_v, v)\}\). By the \(S_2\) Pólya cycle index \(Z(S_2; s_1, s_2) = \frac{1}{2}(s_1^2 + s_2)\) from Chapter 3: \[\sum_{\tau} E^*(\tau) x^{|\tau|} = Z\big(S_2; T(x), T(x^2)\big) = \frac{1}{2}\Big( T(x)^2 + T(x^2) \Big).\]
  3. Symmetric Edge-Rooted Trees \(\sum_{\tau} E_{\text{sym}}(\tau) x^{|\tau|}\): Deleting a symmetric edge \(e = \{u, v\}\) splits \(\tau\) into two isomorphic copies of the same nonempty vertex-rooted subtree \((T_u, u) \cong (T_v, v)\). Choosing one rooted tree of size \(k\) and duplicating it creates a symmetric edge-rooted tree of size \(2k\). Thus: \[\sum_{\tau} E_{\text{sym}}(\tau) x^{|\tau|} = \sum_{k=1}^{\infty} T_k x^{2k} = T(x^2).\]

Combining the three sums: \[t(x) = T(x) - \frac{1}{2}\Big(T(x)^2 + T(x^2)\Big) + T(x^2) = T(x) - \frac{1}{2}\Big(T(x)^2 - T(x^2)\Big). \qquad \blacksquare\]

NoteDiagnostic Signal & Reverse-Engineering Scratchpad: Otter’s Dissimilarity Theorem

  • Diagnostic Signal: You have already computed the OGF \(T(x)\) of vertex-rooted unlabeled trees (or a restricted tree family such as unrooted ternary / bounded-degree trees) and need to pass to unrooted unlabeled trees \(t(x)\) where dividing by \(n\) fails due to non-trivial tree automorphisms.

  • Reverse-Engineering Scratchpad (Why \(\frac{1}{2}\big(T(x)^2 - T(x^2)\big)\) Counts Asymmetric Edge Orbits Directly): Notice that \(E^*(\tau) - E_{\text{sym}}(\tau)\) is simply the number of asymmetric edge orbits of \(\tau\): edges \(e = \{u, v\}\) whose two sides \((T_u, u) \not\cong (T_v, v)\) are non-isomorphic rooted trees! Every non-central vertex orbit pairs uniquely with the edge orbit leading toward Jordan’s center, leaving a surplus of \(+1\) at the center unless the center is a symmetric edge (which is neither in \(E^* - E_{\text{sym}}\) nor fixes a unique vertex orbit, so \(V^* - (E^* - E_{\text{sym}}) = 1\) still holds!). How do we count unordered pairs \(\{(T_1, r_1), (T_2, r_2)\}\) of distinct (non-isomorphic) rooted trees?

    • An ordered pair of rooted trees has OGF \(T(x)^2\).
    • Subtracting the diagonal where the two rooted trees are identical (\(T(x^2)\)) leaves ordered pairs of distinct rooted trees: \(T(x)^2 - T(x^2)\).
    • Dividing by \(2\) forgets the order of the two distinct subtrees: \(\frac{1}{2}\big(T(x)^2 - T(x^2)\big)\)!

    Subtracting this directly from \(T(x)\) gives \(t(x) = T(x) - \frac{1}{2}\big(T(x)^2 - T(x^2)\big)\) in a single step!

WarningUnlabeled Tree Pitfall B (Degree-Cap Variant): Branch-Rooted \(A(x)\) vs. Vertex-Rooted \(P(x)\) in Bounded-Degree Trees

The Trap: In bounded-degree tree problems—such as Mas-1 (#191 Luogu P6598 — 烷烃计数), where we count unrooted unlabeled trees with maximum degree \(\le 4\)—we first solve for the OGF \(A(x) = 1 + x Z(S_3; A(x), A(x^2), A(x^3))\) of planted ternary branches (where the root has out-degree \(\le 3\) so that a parent edge can still be attached without exceeding degree \(4\), and \([x^0]A(x) = 1\) represents an empty branch). A classic mistake is to plug \(A(x)\) directly into \(A(x) - \frac{1}{2}(A(x)^2 - A(x^2))\)!

Why It Fails:

  1. At a vertex of an unrooted degree-\(\le 4\) tree, there are up to \(4\) incident branches (governed by \(S_4\)), not \(3\)! Thus the OGF of vertex-rooted degree-\(\le 4\) trees is \(P(x) = x Z\big(S_4; A(x), A(x^2), A(x^3), A(x^4)\big)\), NOT \(A(x)\)!
  2. At an edge \(e = \{u, v\}\) of an unrooted degree-\(\le 4\) tree, deleting \(e\) leaves two nonempty planted branches \(A_u, A_v\) of out-degree \(\le 3\). Because \(A(x)\) includes the empty tree \(1\) (\([x^0]A(x) = 1\)), the OGF of a nonempty planted branch at an endpoint of \(e\) is \(A(x) - 1\), NOT \(A(x)\)!

The Remedy: For any unrooted tree class with maximum degree \(\le d\):

  • Compute the planted branch series \(A(x) = 1 + x Z(S_{d-1}; A(x), \dots, A(x^{d-1}))\) (out-degree \(\le d - 1\), with \(A(0) = 1\)).
  • Compute vertex-rooted trees via \(S_d\): \(P(x) = x Z\big(S_d; A(x), \dots, A(x^d)\big)\).
  • Compute asymmetric edge-rooted trees using the nonempty branch series \(\widetilde{A}(x) := A(x) - 1\): \[Q(x) - S(x) = \frac{1}{2}\Big( \big(A(x) - 1\big)^2 - \big(A(x^2) - 1\big) \Big).\]
  • Subtract: \(U_{\le d}(x) = P(x) - \frac{1}{2}\Big(\big(A(x) - 1\big)^2 - \big(A(x^2) - 1\big)\Big)\).

Stepping Stone 1 (#186) — Counting Unlabeled Unrooted Trees (Luogu P5900 — 无标号无根树计数)

  • Source: Luogu P5900 — 无标号无根树计数
  • Prerequisite Tags: [Pólya-Euler-Rooted-Trees], [Higher-Power-Newton], [Otter-Dissimilarity-Theorem]

Problem Statement & Exact Constraints

Given a positive integer \(N\), compute the number of non-isomorphic unlabeled, unrooted trees on \(N\) vertices modulo \(998244353\).

  • Constraints: \(1 \le N \le 2 \times 10^5\), modulus \(p = 998244353\).
  • Required Complexity: \(O(N \log N)\) time and \(O(N)\) space.
  • Sample Trace (\(N \le 4\)): For \(N = 1, 2, 3, 4\), the rooted unlabeled tree counts are \(T_1 = 1, T_2 = 1, T_3 = 2, T_4 = 4\). Applying Otter’s formula \(t_N = T_N - \frac{1}{2}\big([x^N]T(x)^2 - [2 \mid N]T_{N/2}\big)\) yields the unrooted unlabeled tree counts \(t_1 = 1, t_2 = 1, t_3 = 1\), and \(t_4 = 4 - \frac{1}{2}(5 - 1) = 2\) (the path \(P_4\) and the star \(K_{1,3}\)).
Hint 1 — Diagnostic Signal & Combinatorial Model

An unrooted unlabeled tree cannot be unpointed by dividing by \(N\) because non-trivial automorphisms \(\operatorname{Aut}(\tau)\) reduce the number of distinct rootings of \(\tau\) from \(N\) to the vertex-orbit count \(V^*(\tau)\). First count rooted unlabeled trees \(T(x)\) via the Euler transform, and then unpoint \(T(x)\) using Otter’s Dissimilarity Theorem!

Hint 2 — Algebraic Setup & Reverse-Engineering Scratchpad
  1. Removing the root of an unlabeled rooted tree leaves an unordered multiset of unlabeled rooted trees, so \(T(x) = x \exp\!\left(\sum_{k=1}^{\infty} \frac{T(x^k)}{k}\right)\).
  2. By Theorem 10.3, when lifting \(T_d(x) \bmod x^d\) to \(T_{2d}(x) \bmod x^{2d}\), the higher-power sum \(S_{\ge 2}(x) = \sum_{k=2}^{2d-1} \frac{T_d(x^k)}{k} \bmod x^{2d}\) depends only on already-known coefficients of \(T_d(x)\) and has zero derivative with respect to \(T(x)\).
  3. Once \(T(x) \bmod x^{N+1}\) is computed, apply Theorem 10.4: \(t(x) = T(x) - \frac{1}{2}\big(T(x)^2 - T(x^2)\big)\).
Hint 3 — Coefficient Extraction & Complexity Contract

To extract the single coefficient \([x^N]t(x)\) after computing \(T(x) \bmod x^{N+1}\), you do not even need a full NTT for \(T(x)^2\): simply compute \([x^N]T(x)^2 = \sum_{i=1}^{N-1} T_i T_{N-i}\) in \(O(N)\) time, subtract \(T_{N/2}\) if \(N\) is even, multiply by \(\frac{p+1}{2} \bmod p\), and subtract from \(T_N\)!

NoteComplete Derivation & Solution

Step 1: Computing Rooted Unlabeled Trees \(T(x) \bmod x^{N+1}\)

Let \(T(x) = \sum_{n=1}^{\infty} T_n x^n\) be the OGF of unlabeled rooted trees. By the Euler transform (Theorem 3.1), \[T(x) = x \exp\!\left( T(x) + \sum_{k=2}^{\infty} \frac{T(x^k)}{k} \right).\] We apply Newton doubling starting from \(T_1(x) = x \bmod x^2\). Suppose at step \(d = 2^s \ge 2\) we have \(T_d(x) \equiv T(x) \pmod{x^d}\) and wish to compute \(T_{2d}(x) \equiv T(x) \pmod{x^{2d}}\) (capped at \(N + 1\)):

  1. By Theorem 10.3, since \(\operatorname{val}(T - T_d) \ge d\), we have \(T(x^k) \equiv T_d(x^k) \pmod{x^{2d}}\) for all \(k \ge 2\). We construct the known polynomial \[S_{\ge 2}(x) = \sum_{j=1}^{d-1} T_j \sum_{\substack{k \ge 2 \\ j k < 2d}} \frac{x^{jk}}{k} \pmod{x^{2d}}\] in \(O(d \log d)\) harmonic time.
  2. Define \(\Phi(x, y) = y - x \exp\big(y + S_{\ge 2}(x)\big) = 0\). Setting \(E_d(x) := x \exp\big(T_d(x) + S_{\ge 2}(x)\big) \bmod x^{2d}\) (computed by calling exp on \(T_d(x) + S_{\ge 2}(x) \bmod x^{2d-1}\) and shifting by \(x\)), we have \[\Phi(x, T_d) \equiv T_d(x) - E_d(x) \pmod{x^{2d}}, \qquad \frac{\partial \Phi}{\partial y}(x, T_d) \equiv 1 - E_d(x) \pmod{x^{2d}}.\]
  3. Since \([x^0](1 - E_d(x)) = 1 \in \mathbb{F}_p^\times\), we invert \(1 - E_d(x) \bmod x^{2d}\) and update: \[T_{2d}(x) \equiv T_d(x) - \frac{T_d(x) - E_d(x)}{1 - E_d(x)} \equiv \frac{E_d(x)\big(1 - T_d(x)\big)}{1 - E_d(x)} \pmod{x^{2d}}.\]

By the Master Theorem, \(T(N) = T(N/2) + O(N \log N) = O(N \log N)\).

Step 2: Applying Otter’s Dissimilarity Theorem

By Theorem 10.4, the OGF \(t(x) = \sum_{n=1}^{\infty} t_n x^n\) of unrooted unlabeled trees satisfies \[t(x) = T(x) - \frac{1}{2}\Big( T(x)^2 - T(x^2) \Big).\] Extracting \([x^N]\) on both sides yields the exact formula: \[t_N = T_N - \frac{1}{2}\left( \sum_{i=1}^{N-1} T_i T_{N-i} - [2 \mid N]\, T_{N/2} \right) \pmod{998244353}.\]

Step 3: Boundary & Small-\(N\) Verification

  • For \(N = 1\): \(T_1 = 1\), sum is empty (\(0\)), \([2 \mid 1] = 0 \implies t_1 = 1\).
  • For \(N = 2\): \(T_2 = 1\), \(\sum_{i=1}^1 T_i T_{2-i} = T_1^2 = 1\), \([2 \mid 2] T_1 = 1 \implies t_2 = 1 - \frac{1}{2}(1 - 1) = 1\).
  • For \(N = 4\): \(T_4 = 4\), \(\sum_{i=1}^3 T_i T_{4-i} = 2 T_1 T_3 + T_2^2 = 2(1)(2) + 1^2 = 5\), \([2 \mid 4] T_2 = 1 \implies t_4 = 4 - \frac{1}{2}(5 - 1) = 2\).

Stepping Stone 2 (#226) — Counting Alkyl Radicals (LOJ 6538 — 烷基计数 加强版 加强版)

Problem Statement & Exact Constraints

In organic chemistry, an alkyl radical (\(-C_n H_{2n+1}\)) is modeled as a rooted unlabeled tree on \(n\) carbon vertices in which the root vertex has degree (number of children) at most \(3\), and every non-root vertex also has out-degree (number of children away from the root) at most \(3\) (so total degree \(\le 4\)). Two alkyl radicals are identical if they are isomorphic as unlabeled rooted trees. Given \(N\), compute the number of alkyl radicals with \(N\) carbon atoms modulo \(998244353\) (or for all \(1 \le n \le N\)).

  • Constraints: \(1 \le N \le 10^5\) (up to \(2 \times 10^5\)), modulus \(p = 998244353\).
  • Required Complexity: \(O(N \log N)\) via Pólya \(S_3\) Newton Iteration (or \(O(N \log^2 N)\) via Ch 09 Chained RelaxedConvolution).
  • Sample Trace (\(N \le 4\)): For \(N = 1, 2, 3, 4\), the numbers of alkyl radicals \(-C_N H_{2N+1}\) (rooted unlabeled trees with root degree \(\le 3\) and child out-degree \(\le 3\)) are \(a_1 = 1\) (methyl), \(a_2 = 1\) (ethyl), \(a_3 = 2\) (\(n\)-propyl, isopropyl), and \(a_4 = 4\) (\(n\)-butyl, sec-butyl, isobutyl, tert-butyl).
Hint 1 — Diagnostic Signal & Combinatorial Model

Let \(A(x) = \sum_{n=0}^{\infty} a_n x^n\) with \(a_0 = 1\) (representing a hydrogen atom / empty branch). A carbon atom \(x\) is attached to an unordered multiset of size \(3\) chosen from \(A(x)\) (since choosing \(k \le 3\) nonempty carbon subtrees is equivalent to choosing \(3\) subtrees from \(A(x)\) when \(a_0 = 1\) pads the remaining \(3 - k\) slots with empty branches!). Apply Pólya’s cycle index \(Z(S_3)\)!

Hint 2 — Algebraic Setup & Reverse-Engineering Scratchpad

By the cycle index \(Z(S_3; s_1, s_2, s_3) = \frac{1}{6}(s_1^3 + 3s_1 s_2 + 2s_3)\), the OGF \(A(x)\) satisfies \[\Phi\big(x, A(x)\big) = A(x) - 1 - \frac{x}{6}\Big( A(x)^3 + 3 A(x) A(x^2) + 2 A(x^3) \Big) = 0.\] By Theorem 10.3, during the Newton step from \(\bmod x^d\) to \(\bmod x^{2d}\), both \(P_2(x) = A_d(x^2)\) and \(P_3(x) = A_d(x^3)\) are already determined modulo \(x^{2d}\) (especially since they are multiplied by \(x\)!) and have zero derivative with respect to \(A(x)\).

Hint 3 — Coefficient Extraction & Complexity Contract

Differentiating \(\Phi(x, y)\) with respect to \(y = A(x)\) while freezing \(P_2(x) = A_d(x^2)\) and \(P_3(x) = A_d(x^3)\) gives \(\partial_y \Phi = 1 - \frac{x}{2}(A_d(x)^2 + P_2(x))\), yielding the simplified update \[A_{2d}(x) \equiv \frac{1 - \frac{x}{3}\big(A_d(x)^3 - A_d(x^3)\big)}{1 - \frac{x}{2}\big(A_d(x)^2 + A_d(x^2)\big)} \pmod{x^{2d}}.\]

NoteComplete Derivation & Solution

Step 1: Combinatorial Specification via \(Z(S_3)\)

Include the empty tree (\(a_0 = 1\)) in \(A(x) = \sum_{n=0}^{\infty} a_n x^n\). Every nonempty rooted ternary tree consists of a root vertex (\(x\)) together with an unordered triple of branches from \(A(x)\) under the action of \(S_3\). The cycle types of the \(6\) permutations in \(S_3\) are:

  • \(1\) identity permutation \((1)(2)(3)\) contributing \(A(x)^3\),
  • \(3\) transpositions \((12)(3), (13)(2), (23)(1)\) each contributing \(A(x) A(x^2)\),
  • \(2\) \(3\)-cycles \((123), (132)\) each contributing \(A(x^3)\).

Averaging over \(|S_3| = 6\) and adding the empty tree \(1\) gives: \[A(x) = 1 + \frac{x}{6}\Big( A(x)^3 + 3 A(x) A(x^2) + 2 A(x^3) \Big).\]

Step 2: \(O(N \log N)\) Newton Doubling

Let \(\Phi(x, y) = y - 1 - \frac{x}{6}\big(y^3 + 3 y P_2(x) + 2 P_3(x)\big) = 0\), where \(P_2(x) = A_d(x^2) \bmod x^{2d}\) and \(P_3(x) = A_d(x^3) \bmod x^{2d}\). Note that because \(\Phi\) multiplies \(P_2(x)\) and \(P_3(x)\) by \(x\), we only need \(A(x^2)\) and \(A(x^3)\) modulo \(x^{2d-1}\), which only queries \([x^j]A(x)\) for \(j \le \lfloor (2d-1)/2 \rfloor = d - 1 < d\). Thus \(P_2(x)\) and \(P_3(x)\) are exact modulo \(x^{2d}\)!

Differentiating \(\Phi(x, y)\) with respect to \(y\) gives: \[\frac{\partial \Phi}{\partial y}(x, A_d) = 1 - \frac{x}{2}\Big( A_d(x)^2 + P_2(x) \Big).\] At \(x = 0\), \(\frac{\partial \Phi}{\partial y}(0, 1) = 1 \in \mathbb{F}_p^\times\). Applying Newton’s update \(A_{2d} = \frac{A_d \cdot \partial_y \Phi - \Phi}{\partial_y \Phi}\), the numerator simplifies to: \[A_d(x) \frac{\partial \Phi}{\partial y}(x, A_d) - \Phi(x, A_d) = \left(A_d - \frac{x}{2}A_d^3 - \frac{x}{2}A_d P_2\right) - \left(A_d - 1 - \frac{x}{6}A_d^3 - \frac{x}{2}A_d P_2 - \frac{x}{3}P_3\right) = 1 - \frac{x}{3}\Big(A_d(x)^3 - P_3(x)\Big).\] Therefore, the exact simplified Newton step is: \[A_{2d}(x) \equiv \frac{1 - \frac{x}{3}\big(A_d(x)^3 - A_d(x^3)\big)}{1 - \frac{x}{2}\big(A_d(x)^2 + A_d(x^2)\big)} \pmod{x^{2d}}.\]

Step 3: Hand-Checkable Trace (\(N = 4\))

  • Init (\(d = 1\)): \(A_1(x) = 1 \pmod{x^1}\).
  • Step \(1 \to 2\) (\(\bmod x^2\)): \(A_1(x)^3 = 1\), \(A_1(x^3) = 1\), so numerator is \(1 - \frac{x}{3}(1 - 1) = 1\). Denominator is \(1 - \frac{x}{2}(1 + 1) = 1 - x\), whose inverse \(\bmod x^2\) is \(1 + x\). Thus \(A_2(x) = 1 + x \pmod{x^2}\).
  • Step \(2 \to 4\) (\(\bmod x^4\)): With \(A_2(x) = 1 + x\):

  2. Every Red vertex has an arbitrary number of children, all of which must be colored Blue.
  3. Every Blue vertex has at most \(K\) children (\(0 \le \text{children} \le K\)), all of which must be colored Red.

  • Constraints: \(1 \le K \le N \le 2.5 \times 10^5\), modulus \(p = 998244353\).
  • Required Complexity: \(O(N \log N)\) time and \(O(N)\) space.
  • Sample Trace (\(N = 3, K = 1\)):

  • Source: AtCoder fps_24_s — Game

Problem Statement & Exact Constraints

Consider a normal-play two-player impartial game on a rooted tree \(T\) with \(N\) labeled vertices \(\{1, 2, \dots, N\}\) (rooted at vertex \(1\), or at a chosen root vertex). A token starts at the root. On each turn, the current player moves the token from its current vertex to one of its children; the player unable to move loses. Given \(N\), compute the number of labeled trees on \(N\) vertices for which the first player has a winning strategy, modulo \(998244353\).

  • Constraints: \(1 \le N \le 2.5 \times 10^5\), modulus \(p = 998244353\).
  • Required Complexity: \(O(N \log N)\) time and \(O(N)\) space.
  • Sample Trace (\(N \le 4\)): For \(N = 1\), the single-vertex tree has no moves, so the first player loses (\(\mathcal{P}\)-position, \(0\) winning trees). For \(N = 2\), the unique tree has \(1\) edge from the root to its child, moving to a leaf with no moves, so the first player wins (\(2^{2-1} = 2\) rooted winning trees, or \(1\) with root fixed at \(1\)). For \(N = 3\) with root fixed at \(1\), the star \(1 - \{2, 3\}\) and the two paths \(1 - 2 - 3, 1 - 3 - 2\) give \(1\) winning tree (the star, where moving to either leaf wins) and \(2\) losing trees (the paths, where moving to the middle vertex lets the second player move to the leaf and win).
Hint 1 — Diagnostic Signal & Combinatorial Model

In any finite normal-play impartial game without cycles, every rooted tree is either a \(\mathcal{P}\)-position (second player wins; EGF \(L(x)\)) or an \(\mathcal{N}\)-position (first player wins; EGF \(W(x)\)). A rooted tree is a \(\mathcal{P}\)-position (\(L(x)\)) if and only if every child subtree of the root is an \(\mathcal{N}\)-position (\(W(x)\))!

Hint 2 — Algebraic Setup & Reverse-Engineering Scratchpad
  1. Since a \(\mathcal{P}\)-tree has only \(\mathcal{N}\)-children, \(L(x) = x \exp(W(x))\). Meanwhile, the sum \(T(x) = L(x) + W(x)\) is the EGF of all rooted labeled trees, so \(L(x) + W(x) = x \exp(L(x) + W(x)) = x \exp(W(x)) \exp(L(x)) = L(x) e^{L(x)}\)!
  2. Subtracting \(L(x)\) eliminates \(W(x)\) completely: \[W(x) = L(x)\big(e^{L(x)} - 1\big) \implies L(x) = x \exp\!\Big( L(x)\big(e^{L(x)} - 1\big) \Big).\]
Hint 3 — Coefficient Extraction & Complexity Contract

Apply the Logarithmic Newton Speedup from Section 10.1 to solve \(\ln(L(x)/x) - L(x)(e^{L(x)} - 1) = 0\) for all \(1 \le n \le N\) in \(O(N \log N)\) time: \[L_{2d}(x) \equiv L_d(x)\left(1 - \frac{\ln(L_d(x)/x) - L_d(x)\big(e^{L_d(x)} - 1\big)}{1 - L_d(x)\big(e^{L_d(x)} - 1 + L_d(x) e^{L_d(x)}\big)}\right) \pmod{x^{2d}}.\] Then subtract the losing trees from the total number of trees (\(N^{N-1}\) for arbitrarily rooted trees, or \(N^{N-2}\) when the root label is fixed at vertex \(1\)). (Forward Pointer: In Chapter 11, we will also extract \([x^N]L(x) = \frac{1}{N}[u^{N-1}]\exp\big(Nu(e^u - 1)\big)\) for a single \(N\) via Lagrange Inversion!)

NoteComplete Derivation & Solution

Part 1: Rooted Tree Game via Coupled System Elimination & Logarithmic Newton

  1. Deriving the Coupled Exponential System: Let \(L(x)\) be the EGF of \(\mathcal{P}\)-position (second-player-winning) rooted labeled trees, and let \(W(x)\) be the EGF of \(\mathcal{N}\)-position (first-player-winning) rooted labeled trees:

    • By the rule of normal-play games, a root is losing (\(\mathcal{P}\)) iff it has zero losing children, meaning its children form an arbitrary \(\operatorname{SET}\) of winning (\(\mathcal{N}\)) subtrees: \[L(x) = x \exp\big(W(x)\big).\]
    • A root is winning (\(\mathcal{N}\)) iff it has at least one losing (\(\mathcal{P}\)) child, plus an arbitrary \(\operatorname{SET}\) of winning (\(\mathcal{N}\)) children: \[W(x) = x \exp\big(W(x)\big) \big(\exp(L(x)) - 1\big).\]

  2. Eliminating \(W(x)\): Substituting \(x \exp(W(x)) = L(x)\) into the second equation immediately gives: \[W(x) = L(x)\big(e^{L(x)} - 1\big).\] Plugging this back into \(L(x) = x \exp(W(x))\) yields the single implicit equation: \[L(x) = x \exp\!\Big( L(x)\big(e^{L(x)} - 1\big) \Big).\] (Note: If the game rule instead specifies 2-layer coupled winning branches \(W(x) = L(x)^2 e^{L(x)}\), then \(L(x) = x \exp\big(L(x)^2 e^{L(x)}\big)\).)

  3. Solving via Logarithmic Newton in \(O(N \log N)\): Set \(G(y) = y(e^y - 1)\). Differentiating with respect to \(y\) gives \(G'(y) = e^y - 1 + y e^y\). Starting from \(L_1(x) = x \pmod{x^2}\), at each doubling step \(d \to 2d\) we compute \(E_d(x) = \exp(L_d(x)) \bmod x^{2d}\) and \(\ln(L_d(x)/x) \bmod x^{2d}\), then evaluate: \[G(L_d) = L_d(E_d - 1), \qquad G'(L_d) = E_d - 1 + L_d E_d,\] and update: \[L_{2d}(x) \equiv L_d(x) \left( 1 - \frac{\ln(L_d(x)/x) - L_d(x)(E_d(x) - 1)}{1 - L_d(x)\big(E_d(x) - 1 + L_d(x) E_d(x)\big)} \right) \pmod{x^{2d}}.\]

  4. Extracting Winning Counts:

    • If the root can be any of the \(N\) vertices, the total number of rooted labeled trees is \(N^{N-1}\), and the number of first-player winning rooted trees is \(N^{N-1} - N! [x^N]L(x) \pmod{998244353}\).
    • If the root label is fixed at vertex \(1\), dividing both counts by \(N\) gives \(N^{N-2} - (N - 1)! [x^N]L(x) \pmod{998244353}\).

Part 2: Bonus Extension — Unrooted Vertex-Choice Game via Otter’s Dissimilarity

  1. Characterizing Trees Where Alice Loses Every Starting Vertex: Suppose instead that on an unrooted labeled tree \(T\), Alice picks any starting vertex \(v_0 \in V(T)\) and thereafter players alternate moving along an incident edge to an unvisited neighbor. Then Alice wins if and only if there exists at least one vertex \(v_0\) such that \((T, v_0)\) is a \(\mathcal{P}\)-position of the rooted game. Conversely, Bob wins (second player wins) if and only if \((T, v_0)\) is an \(\mathcal{N}\)-position for every \(v_0 \in V(T)\). Direct every edge \(\{u, v\}\) as \(u \to v\) whenever the subtree at \(v\) (away from \(u\)) is a \(\mathcal{P}\)-branch (\(L\)). For \((T, v_0)\) to be in \(\mathcal{N}\), \(v_0\) must have at least one outgoing edge toward a \(\mathcal{P}\)-branch, while the complementary branch at \(u\) is also a \(\mathcal{P}\)-branch only when \(u\) has no other \(\mathcal{P}\)-children. This forces the \(\mathcal{P}\)-branches \(L(x)\) and \(\mathcal{N}\)-branches \(W(x)\) to satisfy \(W(x) = L(x)^2\) (an \(\mathcal{N}\)-branch is a vertex matched to a unique \(\mathcal{P}\)-leaf/branch \(L(x)\)), so: \[L(x) = x \exp\big(W(x)\big) = x \exp\!\big(L(x)^2\big).\]
  2. Closed-Form Coefficient Extraction Without LIF: Notice how special \(L(x) = x \exp(L(x)^2)\) is! Squaring both sides gives: \[L(x)^2 = x^2 \exp\!\big(2 L(x)^2\big) \implies 2 L(x)^2 = 2x^2 \exp\!\big(2 L(x)^2\big).\] Compare this with the standard Cayley rooted-tree EGF \(\widehat{T}(z) = z \exp(\widehat{T}(z)) = \sum_{m=1}^{\infty} \frac{m^{m-1}}{m!} z^m\) from Chapter 4! Setting \(z = 2x^2\), we have \(2 L(x)^2 = \widehat{T}(2x^2)\), and by Otter’s dissimilarity subtraction over the alternating \((\mathcal{P}, \mathcal{P})\)-matching edges, the unrooted losing EGF is \(\frac{1}{2} L(x)^2 = \frac{1}{4} \widehat{T}(2x^2)\)! Therefore, for \(N = 2m\) even, \([x^{2m}] \frac{1}{2} L(x)^2 = \frac{1}{4} [z^m] \widehat{T}(z) \cdot 2^m = \frac{2^{m-2} m^{m-1}}{m!}\), and for \(N\) odd, Bob never wins (\(0\) losing trees), computable in \(O(1)\) per \(N\)!

Problem Statement & Exact Constraints

An infinite full ternary rooted tree (with child directions 0, 1, 2) has a token initially at the root. You are given a finite command string \(S\) over {0, 1, 2, U} (where 0, 1, 2 move to the corresponding child and U moves to the parent) that stays within a finite explored subtree \(T_0\) of \(|V(T_0)| \le 2000\) vertices and ends at a displacement root \(r \in V(T_0)\). Repeating \(S\) infinitely many times (S + S + S + ...) traces an infinite periodic tree \(T_\infty = T_0 \cup (r + T_0) \cup (2r + T_0) \cup \dots\) in which every node of \(T_\infty\) has a subtree isomorphic to one of finitely many states. Find the minimum number of steps required to visit all vertices of the finite minimized tree (equivalence classes of subtree isomorphism), and analyze the companion generating-function problem of computing the rooted series \(F(z) = z \Phi(F(z))\) and unrooted dissimilarity series \(U(z) = H(F(z)) \bmod z^{N+1}\) for cloned \(k\)-ary tree grammars.

  • Constraints: \(|S| \le 2000\) (\(|V(T_0)| \le 2001\)); for the enumerative dissimilarity extension, \(N \le 2 \times 10^5\), modulus \(p = 998244353\).
  • Required Complexity: \(O(|V(T_0)|^2)\) for automaton minimization; \(O(N \log N)\) via Implicit Newton + Dissimilarity ODE for the enumerative extension.
  • Sample Trace (\(N \le 4\)): Suppose \(S = \text{`0U1`}\) (\(m = 3\) vertices: root \(o\), leaf 0, and displacement root \(r = \text{`1`}\)). Repeating \(S\) infinitely attaches a copy of leaf 0 and child 1 at every depth along the 1-spine; since every spine node has the exact same infinite subtree structure, all spine nodes collapse into \(1\) state and all 0-leaves collapse into \(1\) state, giving \(2\) minimized automaton states.
Hint 1 — Diagnostic Signal & Combinatorial Model
  • Tree Automaton Minimization: Executing \(S\) once explores a finite tree \(T_0\) of size \(m \le 2000\) and shifts the current position from the root \(o\) to a node \(r \in V(T_0)\). Repeating \(S\) infinitely means we identify \(r\) with a fresh copy of \(o\), turning \(T_0\) into a recursive tree automaton (DFA) where transitions out of \(T_0\) wrap around along the path \(o \leadsto r\)!
  • Dissimilarity Generating Function: When a rooted tree grammar satisfies \(F(z) = z \Phi(F(z))\), how does Otter’s \(|V| - |E| = 1\) identity express the unrooted series \(U(z) = H(F(z))\) purely as an algebraic/integral function of \(F(z)\)?
Hint 2 — Algebraic Setup & Reverse-Engineering Scratchpad
  1. Subset Construction along the Spine \(o \leadsto r\): Every vertex \(u\) in the infinite repeated tree \(T_\infty\) is determined by its projection onto the finite base tree \(T_0\): specifically, a state in \(T_\infty\) is the union of the subtrees rooted at a sequence of nodes \((u_0, u_1, \dots)\) in \(T_0\) formed by lifting \(u\) back by multiples of the shift vector \(o \leadsto r\). Because the depth of \(T_0\) is \(\le m\), at most \(O(m)\) shifts can reach inside \(T_0\)! Thus every reachable node in \(T_\infty\) corresponds to a canonical tuple of vertices in \(T_0\), which we can minimize bottom-up (or via Hopcroft/DFA state hashing).
  2. Dissimilarity ODE: By pointing (\(\Theta U(z) = z U'(z) = F(z)\)), the unrooted series \(U(z) = H(F(z))\) satisfies \(z H'(F(z)) F'(z) = F(z)\). Differentiating \(F(z) = z \Phi(F(z))\) gives \(F'(z) = \frac{\Phi(F)}{z(1 - z\Phi'(F))} = \frac{\Phi(F)^2}{F(\Phi(F) - F\Phi'(F))}\), which forces \[H'(u) = 1 - u \frac{\Phi'(u)}{\Phi(u)}.\]

Step 3: Applying Otter’s Dissimilarity Theorem for Unrooted Alkanes

When we root an alkane at an edge \(e = \{u, v\}\) and delete \(e\), the two endpoints \(u\) and \(v\) must each carry a nonempty carbon tree (since \(e\) is a carbon–carbon bond, neither endpoint can be an empty hydrogen atom!). The OGF of a nonempty planted alkyl branch is \[\widetilde{A}(x) := A(x) - 1 = x + x^2 + 2x^3 + 4x^4 + 8x^5 + \dots.\] Therefore:

  • The OGF of unordered edge-rooted alkanes is \(Q(x) = \sum_{\tau} E^*(\tau) x^{|\tau|} = \frac{1}{2}\big(\widetilde{A}(x)^2 + \widetilde{A}(x^2)\big)\).
  • The OGF of symmetric edge-rooted alkanes is \(S(x) = \sum_{\tau} E_{\text{sym}}(\tau) x^{|\tau|} = \widetilde{A}(x^2) = A(x^2) - 1\).

By Theorem 10.4 (\(V^*(\tau) - E^*(\tau) + E_{\text{sym}}(\tau) = 1\)), the OGF of unrooted alkanes is: \[\operatorname{Alkanes}(x) = P(x) - Q(x) + S(x) = P(x) - \frac{1}{2}\Big( \big(A(x) - 1\big)^2 - \big(A(x^2) - 1\big) \Big).\]

Step 4: Hand-Checkable Trace (\(N = 1 \dots 6\), Chemical Isomers!)

Let us verify the first six coefficients against classic organic chemistry, paying special attention to \(n = 5\) where \(A_5 = 8\) differs from \(P_5 = 9\):

  1. Planted Alkyl Radicals \(A(x)\) (root has \(\le 3\) children): \[A(x) = 1 + x + x^2 + 2x^3 + 4x^4 + 8x^5 + 17x^6 + \dots\] Why is \(a_5 = 8\) whereas \(T_5 = 9\)? On \(5\) vertices, the only rooted tree in which the root has \(> 3\) children is the star \(K_{1,4}\) rooted at its degree-\(4\) center (which has \(4\) children, violating the alkyl root limit of \(3\)).

  2. Vertex-Rooted Alkanes \(P(x)\) (root has \(\le 4\) children): Let us compute \([x^5]P(x) = [x^4] Z\big(S_4; A(x), A(x^2), A(x^3), A(x^4)\big)\) from \(A(x) \equiv 1 + x + x^2 + 2x^3 + 4x^4 \pmod{x^5}\) and \(A(x)^2 \equiv 1 + 2x + 3x^2 + 6x^3 + 13x^4 \pmod{x^5}\):

    • \([x^4] A(x)^4 = [x^4]\big(A(x)^2\big)^2 = 2(13) + 2(2)(6) + 3^2 = 59\),
    • \(6 [x^4] A(x)^2 A(x^2) = 6\big([x^4]A^2 + [x^2]A^2 + [x^0]A^2\big) = 6(13 + 3 + 1) = 102\),
    • \(3 [x^4] A(x^2)^2 = 3(3) = 9\),
    • \(8 [x^4] A(x) A(x^3) = 8\big([x^4]A + [x^1]A \cdot [x^1]A\big) = 8(4 + 1) = 40\),
    • \(6 [x^4] A(x^4) = 6(1) = 6\). Summing and dividing by \(|S_4| = 24\) gives: \[[x^5]P(x) = \frac{59 + 102 + 9 + 40 + 6}{24} = \frac{216}{24} = 9,\] because when \(K_{1,4}\) is rooted at its center, the \(S_4\) root allows \(4\) children (neopentane rooted at its central quaternary carbon)! Thus \(P(x) = x + x^2 + 2x^3 + 4x^4 + 9x^5 + 20x^6 + \dots\).

  3. Asymmetric Edge-Rooted Alkanes \(Q(x) - S(x)\): At \(n = 5\), \([x^5]\frac{1}{2}\big((A(x) - 1)^2 - (A(x^2) - 1)\big) = \frac{1}{2}\big(2 a_1 a_4 + 2 a_2 a_3 - 0\big) = 1(4) + 1(2) = 6\). Subtracting from \(P_5 = 9\) gives \(\operatorname{Alkanes}_5 = 9 - 6 = 3\)!

This yields the exact sequence of alkane constitutional isomers: \[\operatorname{Alkanes}(x) = x + x^2 + x^3 + 2x^4 + 3x^5 + 5x^6 + 9x^7 + 18x^8 + \dots\]

  • \(n = 1\): \(1\) (methane, \(CH_4\))
  • \(n = 2\): \(1\) (ethane, \(C_2 H_6\))
  • \(n = 3\): \(1\) (propane, \(C_3 H_8\))
  • \(n = 4\): \(2\) (\(n\)-butane and isobutane, \(C_4 H_{10}\))
  • \(n = 5\): \(3\) (\(n\)-pentane, isopentane, and neopentane, \(C_5 H_{12}\))
  • \(n = 6\): \(5\) (the \(5\) hexane isomers, \(C_6 H_{14}\)).

Mastery 2 (#192) — Counting Alkenes (Luogu P6597 — 烯烃计数)

  • Source: Luogu P6597 — 烯烃计数
  • Prerequisite Tags: [Pólya-Cycle-Index-D2-S2], [Double-Bond-Canonical-Center], [Alkyl-Radical-Newton]

Problem Statement & Exact Constraints

In organic chemistry, an alkene (\(C_n H_{2n}\), \(n \ge 2\)) is an acyclic hydrocarbon containing exactly one carbon–carbon double bond (\(C=C\)) and single bonds everywhere else, such that every carbon atom has total bond valence \(\le 4\) (with remaining valences filled by hydrogen atoms). Thus the carbon skeleton is an unlabeled, unrooted tree on \(n\) carbon vertices with one distinguished edge (the \(C=C\) double bond), where the two endpoints of the double bond each have at most \(2\) additional single-bond carbon neighbors (since the double bond already uses \(2\) of their \(4\) valences), and all other carbon atoms have degree at most \(4\). Given \(N\), compute the number of non-isomorphic alkenes with \(n\) carbon atoms for \(2 \le n \le N\) modulo \(998244353\). (Note: Structural / constitutional isomers are counted without cis-trans stereoisomerism, so each endpoint of the \(C=C\) bond holds an unordered pair of alkyl/hydrogen groups, and the two endpoints of the \(C=C\) bond can themselves be swapped.)

  • Constraints: \(2 \le N \le 10^5\), modulus \(p = 998244353\).
  • Required Complexity: \(O(N \log N)\) time and \(O(N)\) space.
  • Sample Trace (\(N \le 4\)): For \(N = 2, 3, 4\), the numbers of alkene constitutional isomers \(C_n H_{2n}\) are \(1\) (ethene, \(n = 2\)), \(1\) (propene, \(n = 3\)), and \(3\) (1-butene, 2-butene, isobutylene, \(n = 4\)).
Hint 1 — Diagnostic Signal & Combinatorial Model

Why is counting alkenes (\(C_n H_{2n}\), with a unique \(C=C\) double bond) actually simpler than unrooting alkanes? Because the unique \(C=C\) double bond acts as a canonical center! Every automorphism of an alkene must map the unique \(C=C\) double bond to itself—so we do not need Otter’s Dissimilarity Theorem at all; we only need Pólya’s Cycle Index for the symmetries of the \(C=C\) bond and its two endpoints!

Hint 2 — Algebraic Setup & Reverse-Engineering Scratchpad

Decompose an alkene around its unique \(C=C\) double bond in two nested Pólya steps using the alkyl radical series \(A(x)\) from Stepping Stone 2 (LOJ 6538):

  1. One Endpoint of the Double Bond (\(B(x)\)): A single carbon endpoint of the \(C=C\) bond uses \(2\) valences for the double bond, leaving \(2\) valences to attach an unordered pair (\(S_2\)) of alkyl/hydrogen branches from \(A(x)\): \[B(x) = x Z\big(S_2; A(x), A(x^2)\big) = \frac{x}{2}\Big( A(x)^2 + A(x^2) \Big).\]
  2. The Whole Alkene (\(C=C\) Bond Join): An alkene consists of an unordered pair (\(S_2\)) of double-bond endpoints chosen from \(B(x)\)!
Hint 3 — Coefficient Extraction & Complexity Contract

Applying \(Z(S_2)\) to \(B(x)\) yields the entire alkene generating function in one line: \[\operatorname{Alkenes}(x) = Z\big(S_2; B(x), B(x^2)\big) = \frac{1}{2}\Big( B(x)^2 + B(x^2) \Big).\] (Equivalently, this is the cycle index of the wreath product \(S_2[S_2] \cong D_4\) of order \(8\) acting on the \(4\) branches attached to \(C=C\): \(\frac{x^2}{8}\big(A(x)^4 + 2A(x)^2 A(x^2) + 3A(x^2)^2 + 2A(x^4)\big)\)!)

NoteComplete Derivation & Solution

Step 1: Canonical Decomposition at the Unique \(C=C\) Double Bond

In an alkene \(C_n H_{2n}\), there is exactly one double bond \(e_{=} = \{u, v\}\). Because any graph isomorphism preserving bond multiplicities must map \(e_{=}\) to \(e_{=}\), the alkene is already canonically edge-rooted at \(e_{=}\)!

Let \(A(x) = \sum_{n=0}^{\infty} a_n x^n\) (\(a_0 = 1\)) be the OGF of alkyl radicals (computed in \(O(N \log N)\) time in Stepping Stone 2).

  1. Step 1A — Half-Alkene Endpoint Series \(B(x)\): Consider one carbon endpoint \(u\) of the \(C=C\) double bond. The double bond consumes \(2\) of \(u\)’s \(4\) valences. The remaining \(2\) valences of \(u\) are occupied by an unordered pair of branches chosen from \(A(x)\) (where \(a_0 = 1\) represents \(-H\)). By the cycle index \(Z(S_2; s_1, s_2) = \frac{1}{2}(s_1^2 + s_2)\): \[B(x) = x Z\big(S_2; A(x), A(x^2)\big) = \frac{x}{2}\Big( A(x)^2 + A(x^2) \Big).\]
  2. Step 1B — Joining the Two Endpoints Across \(C=C\): The entire alkene is formed by joining two endpoints \(\{u, v\}\) via the \(C=C\) double bond. Since the double bond is undirected, swapping the two endpoints \(u \leftrightarrow v\) gives an isomorphic alkene. Thus the alkene is an unordered pair of half-alkenes from \(B(x)\): \[\operatorname{Alkenes}(x) = Z\big(S_2; B(x), B(x^2)\big) = \frac{1}{2}\Big( B(x)^2 + B(x^2) \Big).\] Expanding \(B(x)^2 = \frac{x^2}{4}\big(A(x)^4 + 2 A(x)^2 A(x^2) + A(x^2)^2\big)\) and \(B(x^2) = \frac{x^2}{2}\big(A(x^2)^2 + A(x^4)\big)\) also gives the direct \(8\)-element dihedral / wreath-product \(S_2[S_2]\) cycle index: \[\operatorname{Alkenes}(x) = \frac{x^2}{8}\Big( A(x)^4 + 2 A(x)^2 A(x^2) + 3 A(x^2)^2 + 2 A(x^4) \Big).\]

Step 2: Hand-Checkable Trace (\(N = 2 \dots 5\), Constitutional Alkene Isomers!)

From \(A(x) = 1 + x + x^2 + 2x^3 + 4x^4 + \dots\), we compute \(B(x) = \frac{x}{2}\big(A(x)^2 + A(x^2)\big)\):

  • \(A(x)^2 = 1 + 2x + 3x^2 + 6x^3 + 13x^4 + \dots\)
  • \(A(x^2) = 1 + x^2 + x^4 + \dots\)
  • \(\frac{1}{2}\big(A(x)^2 + A(x^2)\big) = 1 + x + 2x^2 + 3x^3 + 7x^4 + \dots\)
  • Multiplying by \(x\): \[B(x) = x + x^2 + 2x^3 + 3x^4 + 7x^5 + \dots\]

Now we compute \(\operatorname{Alkenes}(x) = \frac{1}{2}\big(B(x)^2 + B(x^2)\big)\):

  • \(B(x)^2 = x^2 + 2x^3 + 5x^4 + 10x^5 + 22x^6 + \dots\)
  • \(B(x^2) = x^2 + x^4 + 2x^6 + \dots\)
  • Averaging the two: \[\operatorname{Alkenes}(x) = x^2 + x^3 + 3x^4 + 5x^5 + 12x^6 + \dots\]

Let us verify these counts against chemistry:

  • \(n = 2\) (\(C_2 H_4\), ethene): \(1\) isomer (\(CH_2 = CH_2\)).
  • \(n = 3\) (\(C_3 H_6\), propene): \(1\) isomer (\(CH_3 - CH = CH_2\)).
  • \(n = 4\) (\(C_4 H_8\), butenes): \(3\) constitutional isomers: 1-butene (\(CH_2=CH-CH_2-CH_3\)), 2-butene (\(CH_3-CH=CH-CH_3\)), and isobutylene / 2-methylpropene (\((CH_3)_2 C = CH_2\)).
  • \(n = 5\) (\(C_5 H_{10}\), pentenes): \(5\) constitutional isomers (1-pentene, 2-pentene, 2-methyl-1-butene, 3-methyl-1-butene, 2-methyl-2-butene).
