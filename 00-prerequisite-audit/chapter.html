00 — Mathematical Foundations and Proof

Why this topic matters

A fast implementation solves the model you gave it. Mathematics helps you decide whether that model describes the problem. This chapter develops the habits behind a correct reduction: specifying objects, proving both directions, counting each object once, and distinguishing evidence from a proof.

You already know algorithms and programming. No prior course in proofs or algebra is required. If notation is familiar, use the exercises to locate gaps; you do not need to pass a mathematical entrance examination.

Prerequisites and learning objectives

Prerequisite: arithmetic with integers and fractions. The notation reference collects conventions used later. After this chapter you should be able to translate a quantified claim, choose an appropriate proof method, derive Bézout’s identity, and justify a counting formula or state invariant without relying on small-case evidence.

Definitions and notation

The sets \(\mathbb Z\), \(\mathbb Q\), and \(\mathbb R\) contain integers, rational numbers (fractions of integers with nonzero denominator), and real numbers. Write \(\mathbb Z_{\ge0}\) for nonnegative integers. A set has no repeated elements; a sequence has order and may repeat. The empty set is \(\varnothing\), and \(|S|\) is the number of elements of a finite set \(S\).

The interval \([0,n)\) means the integers \(0,\ldots,n-1\) when used for indices. An indexed sum \(\sum_{i=0}^{n-1}a_i\) adds one term for each such index. An empty sum is zero; an empty product is one. These conventions make recurrences work at size zero: there is one empty sequence, even though it contains no elements.

A function \(f:A\to B\) assigns one output in \(B\) to each input in \(A\). It is injective if different inputs have different outputs, surjective if every output is reached, and bijective if both hold. A bijection proves \(|A|=|B|\) for finite sets because it pairs their elements one for one.

An indicator \([P]\) is \(1\) if a proposition \(P\) is true and \(0\) otherwise. For example, \(\sum_{i=1}^{10}[2\mid i]=5\) counts even integers in that range. The symbol \(a\mid b\) means \(b=ak\) for some integer \(k\); its negation is \(a\nmid b\). The floor \(\lfloor x\rfloor\) is the greatest integer at most \(x\), so \(\lfloor-3/2\rfloor=-2\), which differs from truncation toward zero.

Logic: what exactly must be proved?

The statement \(P\Rightarrow Q\) means every instance satisfying \(P\) also satisfies \(Q\). Its converse \(Q\Rightarrow P\) is a different claim. The notation \(P\Longleftrightarrow Q\) requires both directions. A reduction claiming that feasible solutions correspond must prove both directions unless it explicitly needs only a bound.

The quantifiers \(\forall\) and \(\exists\) mean “for every” and “there exists.” Their order matters. For every integer \(x\) there exists an integer \(y>x\); there does not exist one integer \(y\) larger than every integer \(x\). To disprove a universal claim, one counterexample suffices. To negate “for every \(x\) there exists \(y\) with \(P(x,y)\),” say “there exists \(x\) for which every \(y\) fails \(P(x,y)\).”

Worked failure: an invalid converse. If a positive integer is divisible by \(6\), it is divisible by \(3\). The reverse implication fails at \(3\). Thus checking a necessary condition can reject impossible instances, but passing it does not construct a solution.

For implication proofs, the contrapositive \(\neg Q\Rightarrow\neg P\) is equivalent to \(P\Rightarrow Q\). For example, to prove that \(n^2\) even forces \(n\) even, take odd \(n=2k+1\). Then \(n^2=2(2k^2+2k)+1\) is odd. A proof by contradiction instead assumes the claim is false and derives an impossibility.

Induction: a recurrence for correctness

To prove \(P(n)\) for all integers \(n\ge n_0\), prove the base \(P(n_0)\) and prove \(P(n)\Rightarrow P(n+1)\). The base starts a chain that reaches every allowed index. In strong induction, the step may use all smaller valid indices. Both are natural for dynamic programming: the mathematical dependency graph must reach already proved states.

Worked example: a sum. Let \(S_n=1+\cdots+n\), with \(S_0=0\). We claim \(S_n=n(n+1)/2\). It holds at \(0\). Assuming it at \(n\),

\[S_{n+1}=S_n+(n+1) =\frac{n(n+1)}2+(n+1) =\frac{(n+1)(n+2)}2.\]

Each equality uses the definition, the induction hypothesis, or ordinary algebra. This proof is over the integers/rationals. When computing modulo \(m\), divide the even integer factor by \(2\) before reduction; \(2\) need not have an inverse modulo \(m\).

Worked example: prime factorization exists. A prime is an integer \(p\ge2\) whose only positive divisors are \(1,p\). By strong induction, every \(n\ge2\) is a product of primes. If \(n\) is prime, we are done. Otherwise \(n=ab\) with \(2\le a,b<n\), so the induction hypotheses factor both \(a\) and \(b\). This proves existence, not yet uniqueness; uniqueness follows below.

Failed induction. “All objects in every set have the same color” has a true one-element base. Comparing the first \(n\) and last \(n\) elements of an \((n+1)\)-element set would transfer color through their overlap only when \(n\ge2\). The step from one to two has empty overlap. An induction step must work at the first boundary, not only for large indices.

Invariants, potential functions, and extremal choice

An invariant is a property preserved by every allowed transition. Prove it initially and after one arbitrary transition. A potential function assigns a value to a state that moves in a controlled direction. A nonnegative integer potential that strictly decreases proves termination; a real-valued decrease alone need not, as \(1,1/2,1/4,\ldots\) illustrates.

Worked impossibility and construction. On a binary board, one move flips exactly two cells. The parity of the number of ones is invariant: a move changes it by \(-2,0,\) or \(2\). Hence a board with one one cannot become all zero. Even parity is only a necessary condition until the allowed pairs are specified. If the allowed-pair graph is connected, it is also sufficient: take a spanning tree, process leaves upward, and flip a leaf with its parent exactly when the leaf is one. Cleared leaves never change again. The root is finally zero because total parity is even. This gives an \(O(V+E)\) construction using a graph traversal, where \(V\) counts cells and \(E\) allowed pairs.

An extremal argument selects a smallest, largest, or otherwise optimal object and exploits what it cannot do. Every finite nonempty set of integers has a minimum. Every nonempty set of nonnegative integers has a minimum even if infinite.

Worked example: a tree has a leaf. In a finite tree with at least two vertices, take a longest simple path. An endpoint cannot have another neighbor: a neighbor off the path extends it, while a neighbor elsewhere on the path creates a cycle. Thus each endpoint has degree one. This is why repeatedly removing leaves supports induction in the matrix-tree theorem.

Euclid and Bézout: deriving a central algebraic tool

For nonnegative \(a,b\), not both zero, their greatest common divisor \(g=\gcd(a,b)\) is the greatest positive integer dividing both. Division with remainder gives \(a=qb+r\) with \(0\le r<b\) when \(b>0\). A number divides both \(a,b\) exactly when it divides both \(b,r=a-qb\). Therefore \(\gcd(a,b)=\gcd(b,r)\). The positive remainders decrease, so Euclid’s algorithm terminates, and its last nonzero remainder is \(g\).

Every remainder is an integer linear combination of \(a,b\): the starting values are, and subtracting \(q\) times one combination from another preserves that property. Consequently there exist integers \(u,v\) such that

\[au+bv=g.\]

This is Bézout’s identity. For \(a=30,b=18\), the remainders are \(12,6,0\), and back substitution gives \(6=18-(30-18)=2\cdot18-30\). It follows that \(30x+18y=6\) has \((x,y)=(-1,2)\) as one solution.

For arbitrary integer \(c\), the equation \(ax+by=c\) has integer solutions iff \(g\mid c\). Necessity holds because \(g\) divides every left side; sufficiency comes from multiplying Bézout’s coefficients by \(c/g\). When \(a,b>0\), all solutions from one \((x_0,y_0)\) are

\[x=x_0+\frac bg t,\qquad y=y_0-\frac ag t,\qquad t\in\mathbb Z.\]

To prove completeness, subtract two solutions: \((a/g)\Delta x=-(b/g)\Delta y\). The coefficients \(a/g,b/g\) are coprime. Bézout then implies \(b/g\mid\Delta x\), which forces exactly the parameterization above. Zero coefficients are handled directly; if both coefficients are zero, solvability is exactly \(c=0\).

Euclid uses \(O(\log\max(a,b))\) integer divisions for positive inputs: in two remainder steps the larger argument at least halves. This counts arithmetic operations; large-integer division has its own bit cost.

Why prime factorization is unique. If prime \(p\) divides \(ab\) but not \(a\), then \(\gcd(p,a)=1\). Multiply a Bézout equation for \(p,a\) by \(b\) to conclude \(p\mid b\). Thus a prime appearing in one factorization must appear in any other factorization of the same integer. Cancel that prime and repeat. This proves uniqueness up to the order of the factors.

Double counting and bijections

Before rearranging a sum, name the objects represented by its terms. In a finite undirected graph, count incidences \((v,e)\) where vertex \(v\) is an endpoint of edge \(e\). Summing by vertex gives \(\sum_v\deg(v)\); summing by edge gives \(2|E|\). Thus the two expressions agree. Here edges have two distinct endpoints; with loops, define degree by endpoint occurrences instead.

For subsets, let \(\binom nk\) count \(k\)-element subsets of an \(n\)-element set; it is zero when \(k<0\) or \(k>n\). Count ordered lists of \(k\) distinct elements: there are \(n(n-1)\cdots(n-k+1)\). Each subset has exactly \(k!\) orderings, so

\[\binom nk=\frac{n!}{k!(n-k)!},\qquad 0\le k\le n.\]

The quotient is exact in the integers. The factorial \(n!\) is the product of \(1,\ldots,n\), with \(0!=1\). Choosing whether a distinguished element is present also gives \(\binom nk=\binom{n-1}k+\binom{n-1}{k-1}\) for \(n\ge1\).

Worked example: choose a team and captain. From \(n\ge1\) people choose a nonempty subset and distinguish one member. Choosing size first gives \(\sum_{k=1}^n k\binom nk\). Choosing the captain first gives \(n\) choices, then every other person independently joins or does not: \(2^{n-1}\) choices. Therefore \(\sum_k k\binom nk=n2^{n-1}\). For \(n=3\), \(3+6+3=12=3\cdot4\). The power of two counts subsets, not permutations.

Contest translation and checklist

Use a library routine only after the reduction has an input/output contract. Keep four statements separate: the model is correct, every solution is represented, the algorithm finds the required result, and the resource bound fits the constraints. Exhaustive tests can refute any of these claims on a small case; passing tests does not replace the proof for arbitrary inputs.

  • What is the domain, including empty and zero cases?
  • Is the proposed condition necessary, sufficient, or both?
  • Which object does one summand or DP state represent?
  • What is preserved by a transition, and what ensures termination?
  • Are counted fibers all the same size before dividing?
  • Does the complexity count arithmetic operations or actual machine work?

Exercises, hints, and solutions

1. Quantifiers and a counterexample — concept check

Negate “every pair of nonzero residues modulo \(m\) has a nonzero product.” Find the smallest \(m\ge2\) where the original claim fails.

TipHint and solution

Seek two nonzero factors of the modulus. The negation says that there exist two nonzero residues whose product is zero. Modulo \(4\), \(2\cdot2=0\); modulo \(2\) and \(3\), direct multiplication shows no such pair. The answer is \(4\). This is the first warning that a nonzero element need not be invertible.

2. Count the same marked subset twice — derivation

For \(n\ge2\), derive \(\sum_{k=0}^n k(k-1)\binom nk=n(n-1)2^{n-2}\).

TipHint and solution

Mark an ordered pair of distinct members in the chosen subset. For a \(k\)-element subset there are \(k(k-1)\) such pairs. Alternatively choose the ordered marked pair first in \(n(n-1)\) ways, then choose any of the remaining \(n-2\) elements. Both counts describe exactly the same objects. For \(n=3\), the left side is \(2\cdot3+6\cdot1=12\).

3. All bounded solutions — modelling

Find all nonnegative integer pairs satisfying \(6x+9y=45\) and \(x\le6\).

TipHint and solution

Divide by \(3\). The equation \(2x+3y=15\) has one solution \((0,5)\). Every solution is \(x=3t,y=5-2t\). Bounds imply \(0\le t\le2\). The pairs are \((0,5),(3,3),(6,1)\). Guessing one solution would miss two; the parameterization proves completeness.

4. Flip graph — synthesis

Extend the two-cell flip model to a graph that may be disconnected. Give a necessary and sufficient condition for reaching all zero and a construction.

TipHint and solution

Each move stays inside one connected component, so parity in every component is invariant. Even parity in each component is sufficient by the spanning-tree leaf procedure applied independently. An isolated vertex must already be zero. Components plus the construction cost \(O(V+E)\), with at most \(V-1\) tree-edge flips overall when the graph is nonempty. This proof combines an obstruction with a construction, which is stronger than either alone.

Summary and reference sheet

An implication needs one direction; an equivalence needs two. Induction needs a valid base and a step at every boundary. An invariant proves preservation; a decreasing nonnegative integer potential proves termination. A bijection or double count proves equality by describing the same finite objects twice.

For integers \(a,b\) not both zero, Bézout gives \(au+bv=\gcd(a,b)\). Thus \(ax+by=c\) is solvable exactly when the gcd divides \(c\). Binomial coefficients count unordered subsets; factorial division is exact over integers and needs separate justification modulo a modulus.

Continue with modular algebra. Later, combinatorics, linear algebra, and probability develop the other former entrance diagnostics from their mathematical definitions.
