05 — Group Actions, Burnside, and Pólya

Symmetry problems are not “divide by the number of symmetries” problems: some objects have stabilizers. This chapter supplies the correct averaging machinery.

1. From equivalence to an action

A finite group (G) acts on a set (X) if (ex=x) and ((gh)x=g(hx)). The orbit (Gx) is one equivalence class; the stabilizer (G_x={g:gx=x}). Orbit–stabilizer says (|Gx||G_x|=|G|), explaining why naive division fails when stabilizer sizes differ.

Recognition. Build G explicitly:

  • necklaces: cyclic group (C_n);
  • bracelets: dihedral group (D_n) (rotations and reflections);
  • grids under rotation: a small geometric permutation group;
  • colors themselves interchangeable: a second action, often handled by cycle types or another Burnside layer.

2. Burnside’s lemma

Let ((g)={x:gx=x}). Then

[ |X/G|=_{gG}|(g)|. ]

Proof. Count pairs ((g,x)) with (gx=x). Summing by g gives the numerator. Summing by each orbit gives (_{xO}|G_x|=|O|,|G|/|O|=|G|). Thus every orbit contributes (|G|).

For unrestricted c-colorings of positions, if permutation g has z(g) cycles, a fixed coloring is constant on each cycle and contributes (c^{z(g)}).

Necklace derivation

Rotation by r has ((n,r)) position cycles. Therefore

[ N(n,c)=1n{r=0}{n-1}c{(n,r)} =1n{dn}(n/d)c^d. ]

Group rotations by their gcd instead of iterating to n; this is often the difference between (O(n)) and (O(n)) after factoring n.

For bracelets, add reflections. If n is odd, each reflection has one fixed position and (n-1)/2 pairs. If n is even, half have two fixed positions and half have none. Re-derive these cycles rather than memorising the final formula.

3. Pólya’s cycle index

Burnside counts unrestricted colors. To track how many times each color occurs, define

[ Z_G(s_1,s_2,)={gG} {j}s_j^{c_j(g)}, ]

where (c_j(g)) is the number of length-j cycles. Substitute (s_jy_1j++y_cj). The coefficient of (y_1^{a_1}y_c^{a_c}) counts orbits with exact color multiplicities.

Weighted inventory. If a color/object of weight w has inventory (A(x)=_w a_wx^w), substitute (s_j=A(x^j)). Truncate every polynomial to the requested total. This is the operational form most useful in ICPC.

4. Fixed objects under constraints

Burnside is only the outer loop. For each group element:

  1. Compute its cycles on atomic positions.
  2. Contract every cycle: all its positions must receive the same state.
  3. Count valid assignments to weighted contracted nodes using DP/GF.
  4. Sum and divide by (|G|).

If adjacency constraints are present, contraction may create self-loops or multi-edges. A self-loop can make a proper coloring impossible. For grid states, sometimes it is cheaper to apply the symmetry to transfer-matrix states rather than individual cells.

Thus Burnside over (S_n) can be a sum over integer partitions of n, not n! permutations. Generate partitions as multiplicities, compute cycle-induced constraints, and weight by the class size.

6. Modular arithmetic pitfalls

  • Division by (|G|) modulo prime p requires (p|G|). If not, compute the integer numerator in a larger ring or use problem-specific cancellation.
  • The action must preserve validity; otherwise its orbits are irrelevant.
  • Reflection cycle structures differ by parity.
  • If colors are indistinguishable, ordinary position Burnside alone still treats color names as distinct.
  • Exact multiplicities mean coefficient extraction, not simply colors^cycles.
