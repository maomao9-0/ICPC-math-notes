05 — Group Actions, Burnside, and Pólya

Symmetry problems ask when two drawings, colorings, or arrangements should be considered the same after an allowed move. They are not “divide by the number of symmetries” problems: one object can be fixed by several moves while another is fixed only by doing nothing. This chapter develops the averaging rule that accounts for that difference.

1. From an equivalence relation to an action

A finite group \(G\) is a set of allowed moves with an associative composition, an identity move, and an inverse for every move. It acts on a set \(X\) of objects when every \(g\in G\) gives a map \(x\mapsto g\cdot x\), the identity fixes every object, and \(g\cdot(h\cdot x)=(gh)\cdot x\). This last law says that group multiplication and applying moves in sequence use the same convention.

The orbit \(Gx\) is every version of \(x\) reachable by allowed moves. Thus an orbit is one object “up to symmetry.” The stabilizer \(G_x\) is the set of moves leaving \(x\) visually unchanged. They satisfy

\[|Gx|\,|G_x|=|G|. \tag{1}\]

This immediately explains why naive division fails. Under rotation, the three-bead coloring AAA has orbit size \(1\), while AAB has orbit size \(3\). The raw colorings cannot all be assigned weight \(1/3\).

Recognition. First write the actual move set.

  • necklaces use rotations \(C_n\);
  • bracelets use rotations and reflections \(D_n\);
  • a square grid under quarter turns uses a small geometric permutation group;
  • interchangeable colors introduce another action, usually handled through cycle types or another Burnside layer.

The moves must preserve the problem’s validity condition. If they do not, their orbits are irrelevant to the requested count.

2. Burnside’s lemma: average fixed objects, not raw objects

Assume here that both \(G\) and the object set \(X\) are finite. For a move \(g\), let \(\operatorname{Fix}(g)=\{x:g\cdot x=x\}\) be the objects unchanged by that move. Burnside’s lemma says

\[\boxed{|X/G|={1\over|G|}\sum_{g\in G}|\operatorname{Fix}(g)|}. \tag{2}\]

It looks surprising because it counts a different quantity for every move. Here is the proof and the meaning. Count pairs \((g,x)\) such that \(gx=x\). Counting by \(g\) gives the numerator. Now look at one orbit \(O\). By (1), each object in \(O\) has \(|G|/|O|\) fixing moves, so the objects of that orbit contribute

\[|O|\cdot {|G|\over|O|}=|G|\]

pairs. Every orbit contributes exactly \(|G|\); dividing by \(|G|\) counts one per orbit.

For a coloring with \(c\) available colors, a move permutes positions into cycles. A fixed coloring must be constant along one cycle, and each cycle independently chooses a color. Thus a move with \(z(g)\) cycles fixes exactly \(c^{z(g)}\) unrestricted colorings.

Example: necklaces

Rotation by \(r\) on \(n\) positions repeatedly jumps by \(r\). Starting at one position, it returns after \(n/\gcd(n,r)\) jumps, so there are \(\gcd(n,r)\) cycles. Applying (2) gives

\[ N(n,c)={1\over n}\sum_{r=0}^{n-1}c^{\gcd(n,r)} ={1\over n}\sum_{d\mid n}\varphi(n/d)c^d. \tag{3} \]

For \(n=3,c=2\), the identity fixes \(2^3=8\) colorings and each nontrivial rotation fixes the two constant colorings. Hence there are \((8+2+2)/3=4\) binary necklaces. The divisor form groups rotations with the same cycle count; it is normally preferable after factoring \(n\).

For bracelets, include reflections too. Derive their cycles from the axis: if \(n\) is odd, each reflection has one fixed position and \((n-1)/2\) pairs. If \(n\) is even, half have two fixed positions and \((n-2)/2\) pairs, while half have no fixed positions and \(n/2\) pairs. This parity split is why a memorized necklace formula does not automatically answer a bracelet task.

3. Pólya: remember color counts while averaging

Burnside with \(c^{z(g)}\) only counts all colors as freely available. To require, say, exactly three red and two blue beads, attach a marker \(y_i\) to color \(i\). A length-\(j\) cycle painted color \(i\) contributes \(y_i^j\), because that choice uses color \(i\) exactly \(j\) times.

The cycle index records this for every group element:

\[ Z_G(s_1,s_2,\ldots)={1\over|G|}\sum_{g\in G}\prod_{j\ge1}s_j^{c_j(g)}, \tag{4} \]

where \(c_j(g)\) is the number of length-\(j\) cycles. Substitute

\[s_j\leftarrow y_1^j+\cdots+y_c^j.\]

Then the coefficient of \(y_1^{a_1}\cdots y_c^{a_c}\) is the number of symmetry classes using exactly \(a_i\) positions of color \(i\). For a two-position segment under reflection, the cycle index is

\[\frac12(s_1^2+s_2).\]

After substitution it becomes \(\tfrac12((y_1+y_2)^2+y_1^2+y_2^2)\). The coefficient of \(y_1y_2\) is \(1\): the two raw mixed colorings form one reflection class. The swap itself fixes no mixed coloring, which is why its term is \(y_1^2+y_2^2\) rather than \((y_1+y_2)^2\).

For weighted states with inventory \(A(x)=\sum_w a_wx^w\), where \(a_w\) counts the available states of weight \(w\), use \(s_j\leftarrow A(x^j)\). A cycle of length \(j\) repeats the chosen component \(j\) times, which is exactly why its weight variable becomes \(x^j\). Truncate to the requested total weight throughout.

4. Constraints belong inside the fixed-point count

Burnside is an outer average, not a replacement for the inner combinatorics. For every group element:

  1. find its cycles on the atomic positions;
  2. contract each cycle, because a fixed object must have one state on it;
  3. count valid assignments to those contracted, possibly weighted nodes;
  4. add the result to the Burnside numerator.

For example, a proper coloring fixed by a reflection identifies mirrored vertices. If an edge’s endpoints collapse to one node, that self-loop makes a proper coloring impossible. Other contractions may create parallel edges, which usually do not add a new proper-coloring constraint but may matter for weights. This method cleanly combines symmetry with DP, generating functions, or graph constraints.

5. Symmetric groups and conjugacy classes

For \(S_n\), listing all \(n!\) vertex relabelings is impossible. In problems whose fixed count depends only on cycle lengths, all permutations with the same cycle type behave alike. A type \(1^{m_1}2^{m_2}\cdots\) with \(\sum_i i m_i=n\) has class size

\[\frac{n!}{\prod_i i^{m_i}m_i!}. \tag{5}\]

The denominator has a concrete purpose: rotating a cycle of length \(i\) does not change the cycle, and permuting the \(m_i\) equal-length cycles does not change the permutation. Burnside can therefore sum over integer partitions of \(n\), not over \(n!\) permutations. For each type, construct the induced action on the objects of interest (for unlabeled graphs, on unordered vertex pairs), count its cycles, and multiply by (5). If vertices are colored as well as joined by edges, there are two induced actions: a fixed coloring is constant on each vertex cycle, while a fixed edge set is constant on each unordered-pair cycle. Enforce a requirement such as “every color is used” inside that fixed count, for example by inclusion–exclusion over missing colors.

6. Arithmetic and modelling checks

  • Division by \(|G|\) modulo prime \(p\) requires \(p\nmid |G|\). Otherwise divide exactly before reduction, or use a problem-specific integral rearrangement.
  • A reflection and a rotation with the same order need not have the same cycles.
  • If colors are themselves indistinguishable, ordinary position Burnside still treats color names as distinct; model the color symmetry too.
  • Exact multiplicities require coefficient extraction from (4), not simply colors ^ cycles.
  • On a two- or three-position toy case, enumerate raw objects, group their orbits by hand, and compare with the Burnside numerator before coding.
