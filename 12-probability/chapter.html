12 — Probability and Expectation

The hard part is never the arithmetic

“Expected number of inversions in a random permutation of \(n\) elements.”

A natural first instinct is to simulate the process: think about how the permutation is built, set up a DP over prefixes, worry about dependence between pairs. All unnecessary. Ask instead, for each pair of positions, whether it is inverted — probability \(1/2\) by symmetry — and add up:

\[E[\text{inversions}] = \binom n2 \cdot \frac12 .\]

No process, no DP, no independence assumption. That gap between the complicated thing you first imagine and the one-line answer is what this chapter is about. Probability problems in contests are rarely hard because of the algebra; they are hard because the model is stated imprecisely, and almost every wrong answer traces back to one of four things:

  • what exactly is random, and what is uniform over which objects;
  • whether a quantity can be decomposed into one indicator per contribution;
  • whether the chosen state really determines the future;
  • whether the process terminates with probability one.

So: say what is random and what is fixed, define a state, write one-step equations, and only then solve the DAG, linear system, or generating function.

Prerequisites and learning objectives

Use finite counting and sums; cyclic models need linear systems. The generating function section uses generating functions and can be read later.

You should finish able to state the random experiment precisely, replace a count by indicators, justify a compressed state, diagnose an infinite hitting time, and derive both first and second moments. Recognition signals: random orders, expected counts, repeated attempts, revisited states.

0. Outcomes, events, and averages

A sample space \(\Omega\) is the set of possible outcomes; each outcome \(\omega\) gets a probability \(p_\omega \ge 0\) with \(\sum_\omega p_\omega = 1\). An event is a subset, with \(P(A) = \sum_{\omega\in A}p_\omega\). A random variable assigns a number \(X(\omega)\) to each outcome, and

\[E[X] = \sum_{\omega\in\Omega}p_\omega X(\omega).\]

For a countably infinite space this is a series; nonnegative variables may have infinite expectation, and for signed variables we use the formula when \(E[|X|] < \infty\).

NoteUniform always refers to specified objects

For one fair die, \(E[X] = 7/2\) — and there is no outcome \(3.5\). An expectation is an average, not a prediction.

For two dice the \(36\) ordered pairs are equally likely, but the \(11\) possible sums are not: sum \(2\) happens once, sum \(7\) six times. Before using the word uniform, name the objects it applies to.

When \(P(B) > 0\), the conditional probability \(P(A\mid B) = P(A\cap B)/P(B)\) restricts the space to \(B\) and renormalizes. Events are independent when \(P(A\cap B) = P(A)P(B)\). Sampling without replacement usually destroys independence.

A contest modulus is a representation of an exact rational answer, applied at the end. It is not what probability means, and it cannot rescue a model whose real-valued answer is infinite.

1. Indicators and linearity: the first thing to try

For an event \(A\) let \(I_A\) be \(1\) when \(A\) occurs and \(0\) otherwise, so \(E[I_A] = P(A)\). Whenever a quantity is a count, write it as one indicator per possible contribution:

\[X = \sum_i I_{A_i}, \qquad E[X] = \sum_i P(A_i).\]

The crucial point: this needs no independence whatsoever. It uses only that expectation distributes over addition:

\[E\Bigl[\sum_i I_{A_i}\Bigr] = \sum_\omega p_\omega\sum_i I_{A_i}(\omega) = \sum_i\sum_{\omega\in A_i}p_\omega = \sum_i P(A_i).\]

(The exchange of two finite sums is valid; for nonnegative infinite sums it remains valid with value possibly infinite.)

This one tool handles expected inversions, occupied boxes, surviving edges, distinct values, selected ancestors — anything phrased as “how many”.

Second example, with heavily dependent indicators. Throw \(m\) balls independently into \(n\) equally likely boxes and let \(I_j\) mean box \(j\) is occupied. Box \(j\) is empty with probability \((1-1/n)^m\), so

\[E[\text{occupied}] = n\left(1 - (1-1/n)^m\right).\]

Check \(m = n = 2\): the four ordered placements occupy \(1,2,2,1\) boxes, mean \(3/2\), and the formula gives \(2(1 - 1/4) = 3/2\). ✓ The occupancy indicators are strongly dependent, and it does not matter at all.

Products are different. \(E[XY] = E[X]E[Y]\) requires independence. When dependence is awkward, condition instead of multiplying.

2. Conditioning and the law of total expectation

Partition the outcomes by the next random choice. Since the events \(Y = y\) are disjoint and exhaustive,

\[E[X] = \sum_{y:\,P(Y=y)>0}P(Y=y)\,E[X \mid Y=y],\]

which is just the original expectation sum regrouped into classes. (Zero-probability values are omitted: discrete conditioning is undefined there.)

The self-loop pattern

The most common shape in contests: an action leaves the state unchanged with probability \(p < 1\), and otherwise moves to state \(i\) with probability \(q_i\), where \(p + \sum_i q_i = 1\). Then

\[E = s + pE + \sum_i q_iE_i \quad\Longrightarrow\quad E = \frac{s + \sum_i q_iE_i}{1-p},\]

with \(s\) the expected immediate cost. Read the right-hand side as “cost until something actually happens”: the division conditions on eventually leaving the self-loop, and it sums the entire infinite tail of failed attempts — nothing is truncated.

Never implement the self-reference directly. Memoized recursion on E = ... + p*E never terminates; remove the self-loop algebraically first. And if \(p = 1\) at a nonterminal state from which the target is only reachable after leaving, the target is unreachable and the expectation is infinite, not large.

Check: reroll a fair die until it shows \(4\), \(5\), or \(6\). Each roll costs \(1\) and fails with probability \(1/2\), so \(E = 1 + E/2\) and \(E = 2\).

TipAn independent way to confirm finiteness

For a nonnegative integer time \(T\), the outcome-wise identity \(T = \sum_{k\ge0}[T>k]\) gives the tail-sum formula

\[E[T] = \sum_{k\ge0}P(T>k).\]

In the die example \(P(T>k) = 2^{-k}\), summing to \(2\) — obtained without rearranging any equation that presupposes finiteness. This is the honest way to check that an expectation exists before you start solving for it.

Conditioning also reduces state: reveal the first special object, the maximum sampled index, or the number of successful trials — whatever makes the rest of the process symmetric.

3. Probability DP: choosing the state

Two dual formulations; pick the one with the easier transition and the more obvious terminal condition.

  • p[state] — probability of reaching the state. Push mass forward, sum rewards at terminals. Good for acyclic processes and whole distributions.
  • E[state] — expected remaining cost. Pull from successors. Good when you need one moment.

State aggregation is the hard part. Two histories may be merged only if they have the same distribution of futures. Exchangeable objects should be represented by counts, never identities.

NoteWhy total size is not a valid state

Plates of sushi: let \(E(a,b,c)\) be the expected time to empty everything when \(a\), \(b\), \(c\) plates hold one, two, three pieces, choosing one of \(n\) plates uniformly each step. Then

\[\begin{aligned} E(a,b,c) &= 1 + \frac{n-a-b-c}{n}E(a,b,c)\\ &\quad + \frac anE(a-1,b,c) + \frac bnE(a+1,b-1,c) + \frac cnE(a,b+1,c-1), \end{aligned}\]

keeping only terms with positive numerators, with \(E(0,0,0) = 0\); move the self-loop term left, i.e. divide by \((a+b+c)/n\). Every real transition decreases \(a + 2b + 3c\), so evaluation is acyclic. There are \(O(n^3)\) states.

Now take \(n = 2\): \(E(1,0,0) = 2\) and \(E(2,0,0) = 3\), but \(E(0,1,0) = 4\). The last two states have the same total sushi and different answers — so “total remaining” is not a state. The plate labels are irrelevant, but the profile of counts is not.

If a measure strictly decreases along transitions, topologically order the states. If not, you have cycles and need simultaneous equations — the subject of the next section.

4. Markov chains and absorbing systems

In a Markov chain the current state determines the next-state distribution; history adds nothing.

Before writing any matrix, do the modelling hygiene: restrict to states reachable from the start, make the intended terminal set absorbing, and check that every remaining state can reach it through positive-probability edges. In a finite chain that check exactly rules out a closed nonterminal class, which is the situation producing infinite answers.

Then order the states as transient and absorbing:

\[P = \begin{pmatrix}Q & R\\ 0 & I\end{pmatrix}.\]

From a transient state you spend one step and then move according to \(Q\); writing that for all states simultaneously gives the expected hitting times

\[t = \mathbf 1 + Qt, \qquad (I - Q)t = \mathbf 1 .\]

For the probability of absorbing in a chosen target class, \((I-Q)h = Rb\) where \(b\) is the indicator of the target absorbing states. The fundamental matrix \(N = (I-Q)^{-1} = I + Q + Q^2 + \cdots\) has \(N_{ij}\) equal to the expected number of visits to transient \(j\) starting from \(i\) (counting the initial visit), since \(Q^r\) records being there after \(r\) steps.

NoteWhy \((I-Q)\) is invertible

Give every nonterminal state a positive-probability path to absorption. Finitely many states give a common length bound \(L\) and a common success probability \(\varepsilon > 0\), so surviving \(kL\) steps has probability at most \((1-\varepsilon)^k\). This geometric tail gives finite expectation and \(Q^k \to 0\), and \((I-Q)(I + \cdots + Q^k) = I - Q^{k+1} \to I\) justifies the series.

On an infinite state space there may be no common \(L\) and \(\varepsilon\): almost-sure termination alone does not imply a finite mean.

NoteA two-state cycle, and when it breaks

From \(A\): stop with probability \(1/2\), else go to \(B\). From \(B\): go to \(A\) with probability \(1/4\), else stop. Then \(t_A = 1 + t_B/2\) and \(t_B = 1 + t_A/4\), giving \(t_A = 12/7\), \(t_B = 10/7\).

Memoized recursion \(A \to B \to A\) never finishes — the equations must be solved together. And if both transition probabilities were \(1\), the equations \(t_A = 1+t_B\), \(t_B = 1+t_A\) have no finite solution: the expectation is genuinely infinite, and any “answer” produced by elimination is meaningless.

In practice, solve the linear system rather than inverting: \(O(S^3)\) dense, far less with banded, tridiagonal, monotone, or graph structure. For a finite chain, the hitting time of the chosen absorbing set is finite in expectation exactly when that set is reached with probability one — reaching some other absorbing state does not count as success.

5. Generating-function connections

For a nonnegative-integer variable, the probability generating function stores the entire distribution:

\[G_X(z) = E[z^X] = \sum_k P(X=k)z^k .\]

Independent sums multiply PGFs, because \(z^{X+Y} = z^Xz^Y\) and expectation of a product factors under independence — this turns “repeat an independent step many times” into polynomial multiplication. Moments come from derivatives: \(G_X'(1) = E[X]\) and \(G_X''(1) = E[X(X-1)]\), so

\[\operatorname{Var}(X) = G_X''(1) + G_X'(1) - G_X'(1)^2 .\]

A first-step recurrence becomes a rational PGF. Suppose each round continues with probability \(r < 1\), contributing an independent step with PGF \(A(z)\), and stops otherwise. The number of steps is geometric, so

\[\sum_{k\ge0}(1-r)r^kA(z)^k = \frac{1-r}{1 - rA(z)},\]

whose value at \(z = 1\) is \(1\), as a PGF must be. Contrast \(1/(1-A(z))\) with \(A(1) = 1\): that is a renewal count, not a PGF. Formal inversion needs only a unit constant term; a real probability statement needs the corresponding convergence argument. Keep the two contracts separate.

6. Variance, covariance, and second moments

\(\operatorname{Var}(X) = E[(X - E[X])^2] = E[X^2] - E[X]^2\), and \(\operatorname{Cov}(X,Y) = E[XY] - E[X]E[Y]\). Expanding a square of a sum,

\[\operatorname{Var}\Bigl(\sum_iX_i\Bigr) = \sum_i\operatorname{Var}(X_i) + 2\sum_{i<j}\operatorname{Cov}(X_i,X_j).\]

Variance is not linear. Independence kills the covariances; linearity of expectation does not. If \(X\) is a fair-coin indicator and \(Y = X\), then \(\operatorname{Var}(X+Y) = 1\) while \(\operatorname{Var}(X) + \operatorname{Var}(Y) = 1/2\). (For an indicator with probability \(p\), \(I^2 = I\) gives variance \(p(1-p)\).)

For a unit-cost absorbing process, second moments reuse the first-moment system. With \(m_i = E[T_i^2]\) and terminal \(t_i = m_i = 0\), conditioning on the next state \(j\) where \(T_i = 1 + T_j\) gives

\[m_i = 1 + 2\sum_jP_{ij}t_j + \sum_jP_{ij}m_j .\]

Solve for \(t\) first, then reuse the same coefficient matrix for \(m\); the variance is \(m_i - t_i^2\). Check on the die: \(t = 2\) and \(m = 1 + (2t + m)/2\) gives \(m = 6\), variance \(2\).

7. Choosing actions by expected cost

Suppose action \(a\) costs \(c_a > 0\), stays put with probability \(p_{0,a} < 1\), and otherwise moves to already-solved states \(j\). Repeating it while stuck has value

\[V_a = \frac{c_a + \sum_j p_{j,a}E_j}{1 - p_{0,a}},\]

and the optimum is \(V = \min_a V_a\). Why the minimum is the Bellman solution: in \(E = \min_a\bigl(c_a + p_{0,a}E + \sum_jp_{j,a}E_j\bigr)\), every action’s right-hand side evaluated at \(V\) is at least \(V\), and the minimizing action gives equality; positive costs and guaranteed progress make the policy proper.

Concretely: action A costs \(1\) and succeeds with probability \(1/4\), so its value is \(4\). Action B costs \(2\) and succeeds with probability \(3/4\), value \(8/3\). B wins — even though it costs twice as much per attempt, which is why you must normalize before comparing.

General cycles with action choices form a Markov decision process; neither a self-loop division nor a fixed-policy linear solve optimizes every such graph.

8. Modelling and numerical pitfalls

  • “Uniformly select an available action” means the probabilities change as the set of available actions changes.
  • The expected ratio is not the ratio of expectations.
  • Modular probabilities need every denominator invertible. Field values have no ordering and cannot make an infinite real expectation finite.
  • With double, pivot in cyclic systems and avoid subtracting nearly equal probabilities.
  • Invertible transition denominators do not guarantee a nonsingular modular system. For \(Q = \left(\begin{smallmatrix}0&1/2\\1/2&0\end{smallmatrix}\right)\), \(\det(I-Q) = 3/4\), which vanishes modulo \(3\) even though \(2\) is a unit there. The rational answers are both \(2\), but the modular system has multiple solutions and elimination cannot identify the intended one.
  • An unreachable absorbing state means infinite expectation, not a large finite DP value.
  • Memoized recursion on a cyclic state graph never resolves the cycle.

9. Practice, in order

  1. Foundation — Sushi, Educational DP J. Symmetry compression and a self-loop. Official editorial.
    Hints
    1. Keep only the counts of plates with 1, 2, and 3 pieces.
    2. Choosing an empty plate is a self-loop.
    3. Move that term to the left; evaluate states by total sushi count.
  2. Advanced — Game on Tree, CF 280C. Indicators and symmetry.
    Hints
    1. A vertex contributes exactly when it is chosen directly.
    2. Among the vertices on its root path, which one must be chosen first?
    3. Each is equally likely; sum the reciprocal depths.
  3. Advanced — Roulettes, AtCoder ABC314 E. Optimal expected-cost DP with zero outcomes.
    Hints
    1. Let dp[x] be the minimum expected extra cost from score \(x\).
    2. Evaluate each roulette by conditioning on its outcomes.
    3. Remove the zero-outcome self-loop algebraically before taking the minimum.
  4. Mastery — Intergalaxy Trips, CF 605E. Greedy ordering of expectation equations.
    Hints
    1. Suppose a set of vertices already has finalized expectations to the target.
    2. For each remaining vertex track the probability that all tried finalized destinations fail, plus its accumulated expected cost.
    3. Finalize the smallest current expectation, Dijkstra-style, and update the rest.
  5. Mastery — Broken Robot, CF 24D. Banded linear equations.
    Hints
    1. Write the expectation equation for every cell of one row.
    2. Processing rows bottom-up makes the next row known.
    3. Each row is then a tridiagonal system; solve by elimination.

Exercises with solutions

1. Concept check: a biased average

\(X\) is \(0\) with probability \(1/2\), \(1\) with probability \(1/3\), and \(3\) with probability \(1/6\). Find its mean and variance.

TipHint

Compute \(E[X^2]\) from the same weights; do not average the squared values uniformly.

NoteSolution

\(E[X] = 1/3 + 3/6 = 5/6\) and \(E[X^2] = 1/3 + 9/6 = 11/6\), so the variance is \(11/6 - 25/36 = 41/36\).

Averaging the three listed values equally would use the wrong sample-space weights — the values are given, the weights are the model.

2. Application: collect two different coupons

Each draw independently picks one of two types uniformly. Find the mean and variance of the number of draws needed to see both.

TipHint

The first draw always finds a new type; afterwards each draw succeeds with probability \(1/2\).

NoteSolution

Write \(T = 1 + G\) where \(G\) counts further draws through the first success. From the die computation in Section 6, \(E[G] = 2\) and \(\operatorname{Var}(G) = 2\), so \(E[T] = 3\) and \(\operatorname{Var}(T) = 2\) — a constant shift moves the mean but never the variance.

For \(n\) types, splitting into phases by the number \(k\) already seen gives \(\sum_{k=0}^{n-1}n/(n-k)\). The phases are not independent, and the expectation sum does not care.

3. Advanced: target probability versus target time

At state \(S\) an action succeeds with probability \(1/4\), fails permanently with probability \(1/4\), and otherwise returns to \(S\). Find the success probability, the expected time to reach either terminal, and the expected time to success.

TipHint

Each question has a different terminal set.

NoteSolution

\(h = 1/4 + h/2\) gives \(h = 1/2\). Time to either terminal: \(t = 1 + t/2 = 2\).

Time to success alone is infinite: on the permanent-failure event, which has probability \(1/2\), success never happens. Giving failure the value zero is correct for the first two questions and wrong for the third — a distinction contests exploit deliberately.

4. Synthesis: expected selected ancestors

Give the vertices of a rooted tree independent distinct random priorities and select a vertex when its priority is smallest on its root path. Find the expected number selected.

TipHint

One indicator per vertex — not one state per surviving subset.

NoteSolution

If the root path of \(v\) has \(d_v\) vertices, each is equally likely to hold the minimum, so \(P(v \text{ selected}) = 1/d_v\) and the answer is \(\sum_v 1/d_v\), computed by one DFS in \(O(n)\).

The indicators are strongly dependent, and no product of expectations was used. To apply this to a deletion process such as CF 280C, first justify that assigning priorities in advance induces the same relative-choice distribution as the process; the formula only follows after that modelling bridge.

Contest checklist and reference

  • What are the equally likely objects, and what exactly is the reward?
  • Can each contribution be an indicator? Does any step need a product of dependent variables?
  • Does the state determine every future transition probability?
  • Does some measure rank the states, or are simultaneous equations needed?
  • Which absorbing set is intended, and is it reached almost surely?
  • Are all real expectations finite and all modular divisions licensed?
