1.2 Difficulty Tier Calibration (SS / Int / Adv / Mas)

Every chapter ladder (Ch 01–Ch 24) contains exactly 8 curated problems ordered strictly across four calibrated difficulty tiers:

  • SS — Stepping Stone (2 per chapter, 48 total + 12 in Checkpoints): Clean, canonical non-template problems that isolate a single modelling transformation (e.g., translating a 2D grid conflict into parity bipartite MIS, or differencing a linear inequality system into conservation equations). Typical rating: CF 1700–2000 / AtCoder ABC-F,G / Luogu 提高+/省选-.
  • Int — Intermediate (2 per chapter, 48 total + 12 in Checkpoints): Requires combining the chapter’s core transformation with a secondary structural invariant (e.g., binary search on bottlenecks, residual SCC edge classification, or Tarjan topological pruning before project selection). Typical rating: CF 2100–2400 / AtCoder ARC-E,F / Luogu 省选/NOI-.
  • Adv — Advanced (2 per chapter, 48 total + 12 in Checkpoints): Non-obvious algebraic compilation where the problem statement contains zero graph terminology, or requires rescuing a broken submodularity/convexity condition via variable inversion, complement counting, or persistent data structures. Typical rating: CF 2500–2800 / AtCoder AGC-C,D,E / NOI / Provincial Selection.
  • Mas — Mastery (2 per chapter, 48 total + 12 in Checkpoints + 16 Synthesis): Research-grade or Olympiad flagship benchmarks (CF 2900–3500, AtCoder AGC-F, ICPC World Finals, NOI / CTSC / WC) requiring multi-layer compilation, continuous Coarea decomposition, simulated MCMF on trees/segment trees, or \(L_p\) Isotonic Regression.

1.3 Master Failure Mode Taxonomy (FM-01 to FM-25)

Throughout the textbook, every gadget construction is paired with an explicit Broken Gadget Counterexample. The table below indexes all 25 canonical failure modes referenced across Sections 2–5:

Code Failure Mode Name What Goes Wrong in the Naive Graph / Algorithm Canonical Fix & Home Chapter
FM-01 Directed vs. Undirected Residual Trap Adding an undirected edge \(\{u,v\}\) of capacity \(c\) as two independent directed arcs without shared residual coupling, or setting reverse capacity to \(0\) instead of \(c\). Couple \((u,v)\) and \((v,u)\) in the residual pair (e and e^1), initializing both forward capacities to \(c\) (Ch 01).
FM-02 Greedy / Naive “\(S\)-Reachable = All Min-Cut” Fallacy Assuming every edge crossing from the \(S\)-reachable residual set \(R_S\) to \(V \setminus R_S\) is mandatory in every minimum cut, or that any saturated edge is a cut edge. Run Tarjan SCC on \(G_f\): \((u,v)\) is in some min-cut iff \(f(u,v)=c(u,v)\) and \(\text{scc}(u) \neq \text{scc}(v)\); in all min-cuts iff \(\text{scc}(u)=\text{scc}(S)\) and \(\text{scc}(v)=\text{scc}(T)\) (Ch 02).
FM-03 Un-Split Vertex / Two-Commodity Merging Trap Placing vertex capacity on incident edges, or testing two-commodity routing by only checking \(S_1 \to T_1, S_2 \to T_2\) without testing the swapped \(S_1 \to T_2, S_2 \to T_1\) run. Split \(v \to (v_{\text{in}}, v_{\text{out}})\) (Ch 03); run second max-flow with \(S_2 \leftrightarrow T_2\) swapped ([CQOI2014] 危桥, Ch 02).
FM-04 Missing Companion Edge \((t, s, \infty)\) in Lower-Bound Flow Running max-flow from \(S^*\) to \(T^*\) in a lower-bound \(s\)-\(t\) network without adding the feedback arc \((t, s, \infty)\), violating conservation at \(s\) and \(t\). Add \((t, s, \infty)\) to convert \(s\)-\(t\) flow into a closed circulation before saturating \(S^* \to T^*\) (Ch 04).
FM-05 König Duality on Non-Bipartite Graphs (Odd-Cycle Trap) Applying \(\text{MVC} = \text{MaxMatching}\) or \(\text{MIS} = |V| - \text{MaxMatching}\) to a graph containing an odd cycle \(C_{2k+1}\), where \(\text{MVC} > \nu(G)\). Verify bipartiteness first, or pass to the complement of a two-clique graph / use general Blossom matching (Ch 05, Ch 22).
FM-06 Un-Reset Visited Array in Alternating-Path Game Simulation Failing to unmatch or update Dulmage–Mendelsohn status dynamically as multi-move grid games progress ([NOI2011] 兔兔与蛋蛋). Treat each move as moving the blank token along an alternating path and re-test augmenting paths from the current vertex after deleting the previous node (Ch 06).
FM-07 Unreachable Positive-Weight Cycles in Project Selection Feeding a dependency graph with directed cycles (or nodes reachable from cycles) directly into a closure min-cut ([NOI2009] 植物大战僵尸), allowing the solver to “buy” mutually deadlocked positive-weight nodes. Prune all vertices with in-degree \(>0\) after Kahn’s topological sort on the prerequisite graph before building the closure network (Ch 09).
FM-08 Submodularity Violation (\(A + D > B + C\)) on Un-Flipped Graphs Attempting to compile a pairwise reward/penalty table with \(A + D > B + C\) directly into \(s\)-\(t\) cut arcs, producing negative edge capacities \(c_{uv} < 0\). Check if the interaction graph is bipartite; if so, apply Bipartite Variable Inversion \(y_v = 1 - x_v\) on one side to negate the cross-difference into \(B+C-A-D \ge 0\) (Ch 10, Ch 11).
FM-09 Odd-Cycle Collision in Bipartite Variable Inversion Attempting to rescue a supermodular penalty (\(A+D > B+C\)) when the conflict graph contains an odd cycle (e.g., a triangle of “same-color bonus” edges). Recognize that same-state penalties on non-bipartite graphs are NP-hard (Max-Cut); either reformulate via complement / line graph or dualize if planar (Ch 11).
FM-10 Missing Reverse \(\infty\)-Constraint Arcs in Multi-State Chains Omitting the backward \((z_{i,t}, z_{i,t-1}, \infty)\) monotonicity arcs in a unary chain ([HNOI2013] 切糕), allowing an \(s\)-\(t\) cut to sever multiple edges of the same variable and create fractured indicator states \(z_{i,1}=0, z_{i,2}=1\). Always wire \((v_{i,t}, v_{i,t-1}, \infty)\) so any finite cut intersects each variable’s chain in at most one transition edge (Ch 12).
FM-11 Non-Convex Interaction Function in Ishikawa / Coarea Compilation Applying the Ishikawa cross-edge formula \(w = \frac{1}{2}\Delta_i \Delta_j g < 0\) when \(g(a_i - a_j)\) is concave rather than convex, producing negative capacities. Verify discrete convexity \(g(d+1) - 2g(d) + g(d-1) \ge 0\) before compiling cross-edges (Ch 13).
FM-12 Empty-Subgraph (\(S' = \emptyset\)) Zero-Cut Trap in Density Subgraph Formulating \(\max |E(S')|/|S'|\) as a standard closure cut without shifting by a large constant \(U\), where the trivial cut \(S' = \emptyset\) has cost \(0\) and masks whether a positive-excess non-empty subgraph exists. Use the shifted degree-Regularization cut or enforce \(|S'| \ge 1\) via binary search validation (Ch 14).
FM-13 Un-Split Exterior Face in Planar \(s\)-\(t\) Dual Shortest Path Dualizing a planar graph into faces when \(s\) and \(t\) do not both lie on the outer boundary face, or forgetting to split the outer face into \(F_{\text{top}}\) and \(F_{\text{bottom}}\) along the \((t \to s)\)虛arc. Embed \(s, t\) on the outer boundary, add virtual arc \((t,s)\), and split the unbounded face into \(S^*\) and \(T^*\) (Ch 15).
FM-14 Adding Residual Edges Instead of Rebuilding in Gomory–Hu Gusfield Running Gusfield’s \(N-1\) max-flows on the modified residual graph from the previous iteration instead of resetting flow values to zero before each pair. Reset all edge flows to \(0\) before each of the \(N-1\) \(s\)-\(t\) max-flow calls (Ch 16).
FM-15 Un-Initialized Negative Costs in Dijkstra SSP without Johnson Potentials Running Dijkstra directly on an MCMF network with initial negative-cost edges, or failing to saturate negative-cost edges / cycles via lower-bound initialization. Compute initial potentials \(\pi\) via Bellman–Ford/DAG DP, or pre-saturate negative-cost arcs \((u,v,c,w<0)\) and balance excesses via \(S^* \to T^*\) (Ch 17).
FM-16 Concave Edge Cost Splitting / Zero-Length Vertical Segment Loop Splitting a concave cost function (\(\Delta c_1 > \Delta c_2\)) into parallel arcs (where MCMF greedily picks the second unit before the first!), or adding a zero-length interval \([x, x]\) with \(w > 0\) (最长k可重线段集) creating a positive-weight self-loop. Only convex costs split into parallel arcs; for vertical segments \(x_1 = x_2\), double coordinates \(x \gets 2x\) and map vertical segments to \([2x, 2x+1]\) vs. open intervals \((2x_1, 2x_2)\) (Ch 18, Ch 19).
FM-17 Sign Inversion in Consecutive Equation Differencing (\(\Delta_i = E_i - E_{i-1}\)) Getting the orientation of slack variables \(s_i \ge 0\) or interval variables \(x_j\) backwards when subtracting consecutive linear equations \(E_i - E_{i-1}\). Strictly enforce conservation \(\sum_{\text{in}} - \sum_{\text{out}} = b_i - b_{i-1}\): an interval covering \([l_j, r_j]\) enters at \(+x_j\) in \(\Delta_{l_j}\) and exits at \(-x_j\) in \(\Delta_{r_j+1}\), hence forms an arc \(r_j+1 \to l_j\) (or \(l_j \to r_j+1\) under reversed sign convention) (Ch 19).
FM-18 Upfront \(O(NM^2)\) Graph Materialization in Dynamic Scheduling Building all \(M \times P\) chef-position vertices and \(N \times M \times P\) edges before running MCMF ([NOI2012] 美食节), causing TLE during SPFA/Dijkstra scans. Materialize only the first reverse-position slot \((j, 1)\) per chef initially; dynamically spawn \((j, k+1)\) only after the augmenting path saturates \((j, k)\) (Ch 20).
FM-19 Contaminated vs. Clean Resource Confusion in Napkin Reuse Allowing “dirty” resources at day \(i_{\text{out}}\) to flow directly to “clean” demand at day \((i+1)_{\text{in}}\) without passing through a wash delay edge (餐巾计划问题). Separate each day into dirty supply (\(S \to i_{\text{dirty}}\)) and clean demand (\(i_{\text{clean}} \to T\)); only dirty nodes can postpone for free (\(i_{\text{dirty}} \to (i+1)_{\text{dirty}}\)) or wash (\(i_{\text{dirty}} \to (i+d)_{\text{clean}}\)) (Ch 20).
FM-20 Missing Regret Push (反悔边) in Simulated MCMF Heaps Pushing only the raw item cost into a greedy heap without pushing the residual cancellation cost \(2\text{val}_{\text{chosen}} - \text{val}_{\text{prev}}\) after matching (Buy Low Sell High, CF 802 O). Maintain the exact residual cycle invariant: every match \((u, v)\) must insert the reverse residual marginal cost into the opposite priority queue (Ch 23).
FM-21 Shared Mutable Nodes Across Versions in Persistent Segment Tree Flow Linking historical prefix queries directly to an in-place mutated segment tree (BZOJ 3218), allowing flow from time \(t\) to leak backward and reach targets inserted at time \(t' > t\). Allocate new persistent tree nodes along the updated path at step \(i\), linking \(\text{new\_node} \to \text{old\_node}\) with capacity \(\infty\) so flow only travels to earlier indices \(j < i\) (Ch 22).
FM-22 Bipartite Assumption on Odd-Cycle General Matching Graphs Running Hopcroft–Karp or Dinic on a general matching problem ([WC2016] 挑战 NPC, CF 1089 B), where odd alternating cycles cause augmenting paths to self-intersect. Contract odd cycles via Edmonds’ Blossom algorithm (带花树) or test algebraic rank via the skew-symmetric Tutte matrix (Ch 22).
FM-23 Incomplete 5-Queue Cross-Cancel Transitions in Bipartite Simulated Flow Maintaining only direct match heaps when simulating a \(K\)-bounded common-element constraint ([NOI2019] 序列), missing the 3-hop augmenting paths that free a shared slot by swapping an already-paired element. Enumerate all elementary augmenting path types in the constant-size residual gadget and maintain a dedicated priority queue for each valid state transition (Ch 23).
FM-24 Non-Convex or Discontinuous Derivative Split in \(L_p\) Isotonic Regression Attempting to binary search a single threshold \([f_i > \text{mid}]\) for \(L_p\) Isotonic Regression when the node weight functions \(w_i(x)\) are non-convex, violating the nested cut-tree monotonicity property. Ensure each penalty \(w_i(x)\) is convex so its discrete derivative \(w_i(\text{mid}+\epsilon) - w_i(\text{mid})\) is monotone in \(\text{mid}\), enabling Divide-and-Conquer + Closure Min-Cut (Ch 24).
FM-25 Forcing Network Flow Onto a Non-Flow Lookalike Problem Building an exponential or malformed flow network for a problem that lacks flow conservation or submodularity—such as bitmask shortest paths (孤岛营救), DAG DP, or greedy exchange—simply because it appeared in 网络流 24 题. Audit conservation and TU/submodularity first; see the Non-Flow Decoys in Sections 4 and 5 (CP-I–CP-VI).

3.1 Deep-Dive Cross-Reference: The Four User-Highlighted Flagship Benchmarks

These four flagship problems represent the pinnacle of modern non-graph-to-cut compilation. Each appears in its home chapter in Part III and in the cross-paradigm synthesis comparison in Capstone I:

Flagship Benchmark Canonical ID & Home Chapter Non-Graph English Surface Statement Why DP / Greedy Fails Key Algebraic-to-Graph Compilation Breakthrough
1. AtCoder AGC 038 F
Two Permutations		 #087 (Ch 11) & Syn-03 (Capstone I) Given two permutations \(P, Q\) of \(\{0..N-1\}\) (\(N \le 10^5\)), form \(A_i \in \{i, P_i\}\) and \(B_i \in \{i, Q_i\}\) so \(A, B\) are valid permutations maximizing \(|\{i : A_i \neq B_i\}|\). \(P\)-cycles and \(Q\)-cycles intersect arbitrarily, creating a general bipartite hypergraph of cycle-shift decisions with no treewidth bound. 1. Cycle Locking: Every cycle \(c\) of \(P\) has a single binary state \(x_c \in \{0,1\}\) (\(A_i = i\) vs. \(A_i = P_i\)).
2. Bipartite Variable Inversion: Flip \(Q\)-cycle indicators \(y_d = 1 - x'_d\) so the 5 collision cases (\(i = P_i = Q_i\), \(P_i = Q_i \neq i\), etc.) all compile into submodular \(x_c(1-y_d)\) and \(y_d(1-x_c)\) cut edges!
2. AtCoder ARC 107 F
Sum of Abs		 #095 (Ch 12) & Syn-04 (Capstone I) Delete a subset of vertices (paying \(A_v\)) so remaining connected components \(C\) maximize \(\sum_C |\sum_{v \in C} B_v|\) (\(N, M \le 300\)). Absolute value \(|\sum_{v \in C} B_v|\) depends globally on component connectivity; general graphs cannot be solved by tree DP. 1. Linearizing \(|X|\): Replace \(|\sum_{v \in C} B_v|\) by choosing a uniform sign \(\sigma_v \in \{+1, -1\}\) for every vertex in \(C\).
2. 3-State Split Chain: Assign each vertex \(v\) state \(\sigma_v \in \{+1, 0 (\text{deleted}), -1\}\) via a 2-node split \((v_{\text{in}}, v_{\text{out}})\), and forbid \(+1\) adjacent to \(-1\) via \(u_{\text{in}} \xrightarrow{\infty} v_{\text{out}}\) and \(v_{\text{in}} \xrightarrow{\infty} u_{\text{out}}\)!
3. AtCoder ARC 142 E
Pairing Wizards		 #096 (Ch 12) & Syn-05 (Capstone I) Increment \(a_i\) (+1 costs 1) so every pair \((u,v)\) satisfies \(\min(a_u,a_v) \ge \min(b_u,b_v)\) and \(\max(a_u,a_v) \ge \max(b_u,b_v)\) (\(N \le 100, b_i \le 100\)). \(\max(a_u, a_v) \ge B\) is a logical OR constraint (\(a_u \ge B \lor a_v \ge B\)), which on a general graph is NP-hard Vertex Cover! 1. Deterministic Floor: Force \(a_u \gets \max(a_u, \min(b_u,b_v))\) immediately.
2. Hidden Bipartiteness: After floor raising, if \(\max(a_u,a_v) < B = \max(b_u,b_v)\), one endpoint has \(a_u \ge b_u\) (“satisfied”) and the other has \(a_v < b_v < B\) (“unsatisfied”). Thus all OR-edges strictly cross between two disjoint vertex sets \(V_{\text{sat}}\) and \(V_{\text{unsat}}\)!
4. Codeforces 1427 G
One Billion Shades of Grey		 #103 (Ch 13) & Syn-06 (Capstone I) Fill interior cells of an \(N \times N\) grid (\(N \le 200\)) with fixed border values \(\le 10^9\) to minimize \(\sum_{(u,v) \in E} |x_u - x_v|\). Value domain \(V_{\max} = 10^9\) makes unary chains (\(200^2 \times 10^9\) vertices) impossible by 7 orders of magnitude. 1. Coarea Decomposition: \(\sum |x_u - x_v| = \int_{-\infty}^\infty \sum |[x_u > \lambda] - [x_v > \lambda]| d\lambda\), which is constant on each interval \((v_k, v_{k+1})\) between sorted boundary values.
2. Parametric Rollback: Sweep \(\lambda\) across \(4N\) boundary values, flipping one border tile from \(S\) to \(T\) by un-pushing \(\le 4\) units of flow and re-augmenting in \(O(N^3)\) total!

NoteDeep-Dive Audit: Why the 4 Classic Boundary Traps (R-61 to R-64) Break Network Flow

  1. Why Concave / Fixed-Charge Edge Costs (R-61) Fail MCMF (FM-16): Suppose transporting \(f \ge 1\) units along edge \(e\) costs \(C(f) = 100 + 2f\) (a fixed opening fee of \(100\) plus \(2\) per unit), while \(C(0) = 0\). The marginal increments are:

    \[ \Delta_1 = C(1) - C(0) = 102, \qquad \Delta_2 = C(2) - C(1) = 2, \qquad \Delta_3 = 2, \dots \]

    Because \(\Delta_1 > \Delta_2\), if you place two parallel arcs \(e_1 = (\text{cap } 1, \text{cost } 102)\) and \(e_2 = (\text{cap } \infty, \text{cost } 2)\), any shortest-path augmentation in MCMF will greedily route flow along \(e_2\) (cost \(2\)) without ever saturating \(e_1\) (cost \(102\))! Even worse, Fixed-Charge Network Flow subsumes the Directed Steiner Tree problem (send 1 unit to each terminal \(t_i\), paying \(F_e\) per used edge and \(0\) per additional unit), which is NP-hard.

    • When CAN a fixed setup cost be modelled? Only when it is a 0-1 decision without volume conservation, compiled as a Maximum Weight Closure (Ch 09) where selecting project \(i\) forces paying fixed cost \(F_j\) (\(i \xrightarrow{\infty} j \xrightarrow{F_j} T\), as in #069 [六省联考2017] 寿司餐厅).

  2. Why 3-Part Chaining \(S \to X \to Y \to Z \to T\) (R-62) Fails 3D Matching (FM-03): Suppose valid triples are \((x_1, y_1, z_1)\) and \((x_2, y_1, z_2)\). If you build directed edges \(x_1 \to y_1\), \(x_2 \to y_1\) and \(y_1 \to z_1\), \(y_1 \to z_2\) (even splitting \(y_{1,\text{in}} \xrightarrow{1} y_{1,\text{out}}\)), a unit of flow from \(x_1\) can enter \(y_1\) and exit to \(z_2\), hallucinating the invalid triple \((x_1, y_1, z_2)\)! Flow networks are memoryless at intermediate vertices.

    • When CAN a 3-layer hypergraph be solved?
      • If every valid choice pairs one resource from \(A\) and one from \(B\) independently for a middle agent \(G\) (i.e., \(G_k\) is compatible with \(A_i\) and independently compatible with \(B_j\)), place the agent in the middle: \(A_i \to G_{k,\text{in}} \xrightarrow{1} G_{k,\text{out}} \to B_j\) (#017 酒店之王).
      • If \(A \times B \times C \le 5000\) in a 3D grid cover, \(\min(A,B,C) \le 17\): brute-force the \(2^{\min}\) bitmask of slices in the shortest dimension and solve 2D König MVC on the other two (#052 [HNOI2013] 消毒).

  3. Why Non-Bipartite Same-Color Penalties (R-63) Fail Min-Cut (FM-08, FM-09): Penalizing \(x_u = x_v\) (or rewarding \(x_u \neq x_v\)) has \(A = C(0,0) > 0, D = C(1,1) > 0, B = C = 0\), so \(A + D > B + C\) (strictly supermodular). On a bipartite graph \(V = L \cup R\), substituting \(y_v = 1 - x_v\) for \(v \in R\) converts \(x_u \neq x_v\) into \(x_u = y_v\) (submodular!). On a graph with an odd cycle (such as \(K_3\)), minimizing same-color edges is equivalent to Maximum Cut, which is APX-hard on general graphs (and solvable via dual matching only if planar).

  4. Why General 2-SAT (R-64) Is Not an \(s\)-\(t\) Min-Cut (FM-25): In an \(s\)-\(t\) cut, an \(\infty\)-capacity arc \(u \xrightarrow{\infty} v\) encodes the implication \(x_u = 1 \implies x_v = 1\) (equivalently \(\bar{x}_u \lor x_v\), a Horn / 2-monotone clause). A clause \((x_u \lor x_v)\) is \(\bar{x}_u \implies x_v\), which requires flipping one variable (\(y_u = 1 - x_u\)). If the clause graph of \((x_u \lor x_v)\) and \((\bar{x}_u \lor \bar{x}_v)\) is not bipartite, no global variable flip can turn all clauses into \(z_u \implies z_v\) Simultaneously! Thus pure feasibility of mixed 2-CNF clauses belongs to Tarjan SCC (2-SAT), whereas weighted optimization of 2-CNF requires the conflict graph of same-polarity clauses to be bipartite (as rescued in Flagship Benchmark #3, ARC 142 E Pairing Wizards #096).

5. Complete Pedagogical Audit of the Classic Chinese “24 Network Flow Problems” (网络流 24 题)

Compiled in the early 2000s for Chinese NOI/CTSC training and hosted on LibreOJ (LOJ #6000–#6023) and Luogu, the “24 Network Flow Problems” (网络流 24 题) is the single most famous problem collection in competitive programming flow literature. However, studying the raw list in numerical order without a pedagogical map is notoriously hazardous for two reasons:

  1. Four of the 24 Problems Are Not Network Flow Problems (FM-25): Because the list was originally assembled around “Linear Programming and Network Flow” broadly, four problems (孤岛营救问题, 汽车加油行驶问题, 软件补丁问题, and one variant slot) have zero multi-unit flow conservation and are actually solved by Bitmask 0-1 BFS, Layered Fuel-State Dijkstra, or Bitmask Shortest Path. Generations of students have wasted hours trying to force Dinic or MCMF onto bitmask state transitions!
  2. Seven Problems Are Bare Templates or Near-Identical Clones: Problems like 分配问题 (P4014), 运输问题 (P4015), and 飞行员配对 (P2756) hand the bipartite graph directly to the solver, while 圆桌问题 (P3254) and 试题库问题 (P2763) are word-for-word isomorphic.

5.2 Forensic Deconstruction of the Non-Flow Impostors (R-51, R-52, R-53)

Why did these three problems appear in 网络流 24 题, and how do you immediately recognize in a contest that Dinic / MCMF is the wrong tool?

  1. R-51 — Luogu P4011 孤岛营救问题 (Island Rescue, 24题 #14):
    • Statement: An \(N \times M\) grid (\(N, M \le 10\)) has walls, doors of types \(1 \dots P\) (\(P \le 10\)), and keys of types \(1 \dots P\) scattered on cells. Find the shortest time from \((1,1)\) to \((N,M)\).
    • Why Network Flow Fails: Once you pick up a key of type \(k\), you retain that key forever and can open any number of type-\(k\) doors. In a standard flow network, a unit of flow cannot “remember” which vertices it previously visited without expanding the vertex space by \(2^P\). Once you expand the state space to \((r, c, \text{mask} \in [0, 2^P))\), you only need 1 path of minimum length—which is a standard shortest-path problem, not a multi-unit flow problem!
    • Correct Algorithm: 0-1 BFS (or BFS) on the layered state graph \((r, c, \text{mask})\) with \(10 \times 10 \times 2^{10} \approx 10^5\) states in \(O(NM 2^P)\) time.
  2. R-52 — Luogu P4009 汽车加油行驶问题 (Car Refueling, 24题 #13):
    • Statement: Drive a single car from \((1,1)\) to \((N,N)\) (\(N \le 100\)) with fuel tank capacity \(K \le 10\). Moving decreases fuel by \(1\); moving left/up costs \(B\); gas stations force refuel for \(A\); building a new station costs \(C + A\).
    • Why Network Flow Is Redundant Overhead: Although a single shortest path is technically a 1-unit min-cost flow (\(\text{flow} = 1\)), there are no edge capacity bottlenecks shared across multiple cars. Running SPFA/Dijkstra MCMF on \((r, c, k)\) with capacity \(1\) does the exact same work as 1 run of Dijkstra on the layered state graph \((r, c, k \in [0, K])\) with \(100 \times 100 \times 11 = 1.1 \cdot 10^5\) states!
  3. R-53 — Luogu P2761 软件补丁问题 (Software Patches, 24题 #22):

    • Statement: A program has \(N \le 20\) bugs (initial mask \(2^N - 1\)). Each of \(M \le 100\) patches requires certain bugs to be present (\(B_1\)) and absent (\(B_2\)), takes time \(t_j\), and fixes subset \(F_1\) while introducing subset \(F_2\):

      \[ \text{mask}_{\text{next}} = (\text{mask} \setminus F_1) \cup F_2 \]

    • Why Network Flow Fails: Bitwise set-union and set-difference on \(N\) coupled bits cannot be expressed as additive flow conservation \(\sum f_{\text{in}} - \sum f_{\text{out}} = 0\) on \(O(N)\) vertices. Instead, the state space is the \(2^{20} \approx 10^6\) hypercube of bug masks, solved by Dijkstra’s Algorithm on \(2^N\) states from \(\text{mask} = 2^N - 1\) to \(\text{mask} = 0\).
