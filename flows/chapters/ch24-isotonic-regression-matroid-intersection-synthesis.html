1. \(L_p\) Isotonic Regression on Posets (保序回归): Continuous-to-Discrete Contraction via 整体二分 + Max-Weight Closure

In Ch 11, we compiled discrete multi-state choices \(x_i \in \{1, 2, \dots, K\}\) with convex penalties and partial-order constraints \(x_u \le x_v\) into layered unary threshold chains (Burn-Bury / 切糕模型) of size \(O(NK)\) vertices and \(O(MK)\) edges. What happens when the coordinate domain \(U = [L, R]\) is huge (\(R - L \le 10^9\)) or continuous (\(x_i \in \mathbb{R}\))? Building \(10^9\) layers explicitly is impossible. Yet in his landmark 2018 China National Team paper (《浅谈保序回归问题》), Zhi-Rui Gao (高睿泉) showed that convexity and submodularity allow us to probe a single threshold slice \(\{M, M+1\}\) using one standard Ch 09 Maximum-Weight Closure cut, and that the resulting optimal binary cut exact-partitions the global continuous optima \(x^*\) into \((\le M)\) and \((\ge M+1)\)!

1.1 The General \(L_p\) Isotonic Regression Problem (Step 1 & Step 2)

Step 1: Non-Graph Diagnostic Signal (Recognition)

You are given \(N\) items (\(N \le 10^3\)), each with an initial target value \(y_i \in \mathbb{Z}\) and weight \(w_i > 0\). You must choose modified values \(x_1, x_2, \dots, x_N\) to minimize the total \(L_p\) modification penalty (\(1 \le p < \infty\)):

\[ \min_{x \in \mathbb{R}^V} \sum_{i \in V} w_i |x_i - y_i|^p \quad \text{subject to} \quad x_u \le x_v \quad \forall (u, v) \in E \]

where \(G = (V, E)\) is a directed graph of \(M\) partial-order constraints (often induced implicitly by an optimal spanning tree, shortest-path tree, or XOR linear basis condition). Naive greedy rounding fails because raising \(x_u\) forces all descendants \(v\) of \(u\) in \(G\) to satisfy \(x_v \ge x_u\), creating cascading multi-path conflicts across the DAG.

Step 2: Intermediate Algebraic / Logical Representation (The Two-Level Threshold Slice)

Generalizing the 1D penalty function \(f_i(x_i) = w_i |x_i - y_i|^p\), suppose each vertex \(i \in V\) has an arbitrary convex cost function \(f_i : \mathbb{R} \to \mathbb{R}\). Instead of solving for \(x_i \in [L, R]\) all at once, fix a midpoint \(M = \lfloor (L + R) / 2 \rfloor\) (or for continuous \(L_p\), a step size \(M\) and \(M + \epsilon\)) and restrict every variable to the two-point set \(\{M, M+1\}\).

Define the binary indicator variable \(z_i \in \{0, 1\}\) for each \(i \in V\):

\[ z_i = [x_i = M + 1] \quad \Longleftrightarrow \quad x_i = M + z_i \]

Let us check both the constraints and the objective under this restriction:

  1. Poset Constraint Preservation: For every directed edge \((u, v) \in E\), the inequality \(x_u \le x_v\) becomes \(M + z_u \le M + z_v \iff z_u \le z_v\), which is the exact algebraic closure condition:

    \[ z_u = 1 \implies z_v = 1 \quad \Longleftrightarrow \quad z_u(1 - z_v) = 0 \quad \forall (u, v) \in E \]

  2. Linearized Slice Objective: Since \(z_i \in \{0, 1\}\), we can write \(f_i(M + z_i) = f_i(M) + \big(f_i(M+1) - f_i(M)\big) z_i\). Defining the marginal promotion reward \(\Delta_i(M)\) of shifting \(x_i\) from \(M\) up to \(M+1\):

    \[ \Delta_i(M) := f_i(M) - f_i(M+1) = w_i |M - y_i|^p - w_i |M + 1 - y_i|^p \]

    minimizing \(\sum_{i \in V} f_i(M + z_i)\) is algebraically equivalent to maximizing the total promotion reward of the closed set \(Z_1 = \{i \in V : z_i = 1\}\):

    \[ \min_{z \in \{0,1\}^V : z_u \le z_v} \sum_{i \in V} f_i(M + z_i) = \underbrace{\sum_{i \in V} f_i(M)}_{\text{Constant } C(M)} - \max_{\substack{z \in \{0,1\}^V \\ z_u \le z_v \;\forall (u,v)\in E}} \sum_{i \in V} \Delta_i(M) z_i \]

This restricted \(\{M, M+1\}\) problem is a textbook Maximum-Weight Closure (Ch 09) instance!

1.2 The Contiguous Two-Level Threshold Contraction Theorem

Why does solving the \(\{M, M+1\}\) binary slice tell us anything about the unconstrained global optimum \(x^* \in [L, R]^V\)? The bridge is one of the deepest structural results in combinatorial optimization.

ImportantTheorem 24.1 (Contiguous Two-Level Threshold Contraction / Uncrossing Monotonicity)

Let \(f_i : \mathbb{R} \to \mathbb{R}\) be convex functions for all \(i \in V\), and let \(z^* \in \{0, 1\}^V\) be an optimal solution to the restricted \(\{M, M+1\}\) Maximum-Weight Closure problem on \(G = (V, E)\). Then there exists an unconstrained global optimal solution \(x^* \in \mathbb{R}^V\) to the full Isotonic Regression problem such that for every vertex \(i \in V\):

\[ z_i^* = 0 \implies x_i^* \le M, \qquad \text{and} \qquad z_i^* = 1 \implies x_i^* \ge M + 1 \text{ (in integers)} \]

In the continuous setting where we test \(\{M, M + \epsilon\}\) as \(\epsilon \to 0^+\), the directional derivative reward is \(\Delta_i^{\text{cont}}(M) = -f_i'(M^+)\), and \(z_i^* = 0 \implies x_i^* \le M\) while \(z_i^* = 1 \implies x_i^* \ge M\).

Proof via Submodular Lattice Uncrossing and Convexity

Let \(x^* \in \mathbb{Z}^V\) be a global integer optimum on \([L, R]^V\), and let \(z^* \in \{0, 1\}^V\) be an optimum of the restricted \(\{M, M+1\}\) slice. Define the set of vertices that \(z^*\) promotes to \(M+1\) as \(U_1 = \{i \in V : z_i^* = 1\}\), and define the set of vertices where the global optimum \(x^*\) strictly misses this lower bound as \(W = \{i \in V : x_i^* \le M\}\).

Suppose for contradiction (or toward constructing an aligned optimum) that the bad overlap \(B = U_1 \cap W = \{i \in V : z_i^* = 1 \text{ and } x_i^* \le M\}\) is non-empty.

  1. Lattice Closure of \(U_1\) and \(W^c\): Because \(x^*\) is poset-feasible (\(x_u^* \le x_v^*\)), its upper threshold set \(W^c = \{i \in V : x_i^* \ge M + 1\}\) is a valid upper closure in \(G\). Similarly, \(U_1\) is a valid upper closure in \(G\). Since upper closures are closed under union and intersection:

    • \(U_1 \setminus B = U_1 \cap W^c\) is a valid upper closure for the \(\{M, M+1\}\) slice problem (demoting \(B\) from \(M+1\) back to \(M\)).
    • Conversely, for any \(i \in B\), since \(x_i^* \le M\), if we shift \(x_i^*\) upward by \(+1\) (or to \(M+1\)) along a suitable level set inside \(B\), poset feasibility is governed by the same directed arcs.

  2. Convex Marginal Inequality: For every \(i \in B\), we have \(x_i^* \le M\). By the convexity of \(f_i\), the marginal cost of increasing \(i\) from \(M\) to \(M+1\) is at least as large as the marginal cost of increasing \(i\) from \(x_i^*\) to \(x_i^* + 1\):

    \[ f_i(M+1) - f_i(M) \ge f_i(x_i^* + 1) - f_i(x_i^*) \quad \Longleftrightarrow \quad \Delta_i(M) \le f_i(x_i^*) - f_i(x_i^* + 1) \]

  3. Optimality Contradiction / Alignment: Because \(z^*\) is optimal for the \(\{M, M+1\}\) slice, demoting the subset \(B\) from \(M+1\) to \(M\) cannot improve the slice objective, so \(\sum_{i \in B} \Delta_i(M) \ge 0\). Combining this with the convexity inequality above yields:

    \[ \sum_{i \in B} \big(f_i(x_i^* + 1) - f_i(x_i^*)\big) \le -\sum_{i \in B} \Delta_i(M) \le 0 \]

    Thus, incrementing \(x_i^*\) on the maximal level set of \(B\) preserves poset feasibility and does not increase the global objective \(\sum f_i(x_i^*)\)! Repeating this uncrossing for both \(U_1 \cap \{x^* \le M\}\) and \(U_0 \cap \{x^* \ge M+1\}\) transforms \(x^*\) into an equally optimal (or strictly better, if \(f_i\) is strictly convex as in \(p > 1\)) solution that satisfies \(x_i^* \le M\) on \(z_i^* = 0\) and \(x_i^* \ge M+1\) on \(z_i^* = 1\). \(\blacksquare\)

1.3 Step 3: Mechanical Graph Compilation & Parallel Divide-and-Conquer (整体二分)

Theorem 24.1 gives us a recursive divide-and-conquer algorithm (solve(V_cur, E_cur, L, R)) that finds the exact integer (or discretized) vector \(x^* \in [L, R]^V\) in \(\lceil \log_2(R - L + 1) \rceil\) depth levels:

  1. Base Case: If \(L = R\), set \(x_i^* = L\) for all \(i \in V_{\text{cur}}\) and return.
  2. Midpoint Cut Construction: Set \(M = \lfloor (L + R) / 2 \rfloor\). Build a flow network strictly on the active vertex subset \(V_{\text{cur}}\) with source \(S\) and sink \(T\):
    • For each \(i \in V_{\text{cur}}\), compute \(\Delta_i(M) = f_i(M) - f_i(M+1) = w_i |M - y_i|^p - w_i |M + 1 - y_i|^p\).
    • If \(\Delta_i(M) > 0\) (promoting \(i\) to \(M+1\) strictly reduces cost), add directed edge \(S \to i\) with capacity \(\Delta_i(M)\).
    • If \(\Delta_i(M) < 0\) (keeping \(i\) at \(M\) is strictly cheaper), add directed edge \(i \to T\) with capacity \(-\Delta_i(M)\).
    • For each active poset edge \((u, v) \in E_{\text{cur}}\) (where both \(u, v \in V_{\text{cur}}\)), add directed edge \(u \to v\) with capacity \(\infty\).
  3. Partition & Edge Contraction: Run Dinic’s algorithm on \((V_{\text{cur}} \cup \{S, T\}, E_{\text{cur}})\). Let \(S_{\min} \subseteq V_{\text{cur}}\) be the vertices reachable from \(S\) in the final residual graph (\(z_i^* = 1 \implies x_i^* \in [M+1, R]\)), and \(T_{\min} = V_{\text{cur}} \setminus S_{\min}\) be the unreachable vertices (\(z_i^* = 0 \implies x_i^* \in [L, M]\)).
    • Why Cross-Edges Vanish Forever: Any original poset edge \((u, v) \in E_{\text{cur}}\) with \(u \in S_{\min}\) and \(v \in T_{\min}\) is impossible (since it has capacity \(\infty\), it cannot cross a finite \(S\)-\(T\) cut). Any edge \((u, v) \in E_{\text{cur}}\) with \(u \in T_{\min}\) and \(v \in S_{\min}\) is permanently satisfied for all future recursive calls because every \(u \in T_{\min}\) will be assigned \(x_u^* \le M\) while every \(v \in S_{\min}\) will be assigned \(x_v^* \ge M + 1\), guaranteeing \(x_u^* < x_v^*\) automatically!
    • Therefore, we partition \(E_{\text{cur}}\) into \(E_L = \{(u, v) \in E_{\text{cur}} : u, v \in T_{\min}\}\) and \(E_R = \{(u, v) \in E_{\text{cur}} : u, v \in S_{\min}\}\), discard all cross-edges, and recurse on solve(T_min, E_L, L, M) and solve(S_min, E_R, M + 1, R).
TipComplexity Guarantee of Parallel Divide-and-Conquer

At every depth level \(d \in \{0, 1, \dots, \lceil \log_2 U \rceil\}\) of the recursion tree, the active vertex sets \(V_{\text{cur}}\) across all calls at depth \(d\) are pairwise disjoint (\(\sum |V_{\text{cur}}| = N\)), and the active edge sets \(E_{\text{cur}}\) are pairwise disjoint (\(\sum |E_{\text{cur}}| \le M\)). Because Dinic’s runtime is super-additive (\(\sum \text{Dinic}(N_k, M_k) \le \text{Dinic}(\sum N_k, \sum M_k)\)), the total work at each depth is bounded by a single global max-flow on \((N, M)\), giving a total complexity of:

\[ O\big(\text{Dinic}(N, M) \log U\big) \]

1.4 Flagship Walkthrough: [省选联考 2020 A卷] 魔法商店 (Luogu P6621) — Compiling Matroid Basis Exchanges into Poset Edges

In contest problems, the poset \(G = (V, E)\) is rarely handed to you explicitly; you must extract it from an optimality condition. The crowning example is [省选联考 2020 A卷] 魔法商店 (Luogu P6621):

  • Problem Statement: There are \(N \le 1000\) magic cards. Card \(i\) has an attribute integer \(c_i < 2^m\) (\(m \le 64\)) and an initial price \(v_i \le 10^6\). A subset of \(m\) cards is a valid basis if their attributes \(c_i\) are XOR-linearly independent. You are given two specific valid bases: \(A\) (size \(m\)) and \(B\) (size \(m\)). You want to modify the prices from \(v_i\) to integers \(x_i\) at total cost \(\sum_{i=1}^N (x_i - v_i)^2\) (\(L_2\) norm, \(p = 2\)) so that \(A\) becomes a minimum-weight valid basis and \(B\) becomes a maximum-weight valid basis under the new prices \(x\).

  • Step 2 (Extracting the Poset via Basis Exchange): By the Matroid Basis Optimality Theorem (recall Kruskal’s greedy algorithm on a linear matroid), a basis \(A\) is a minimum-weight basis under weights \(x\) if and only if no single-element exchange can strictly decrease its weight. For each card \(j \notin A\), since \(A\) spans the \(m\)-dimensional \(\mathbb{F}_2^m\) space of \(A\), \(c_j\) can be written uniquely as the XOR sum of a subset of cards in \(A\):

    \[ c_j = \bigoplus_{i \in S_A(j)} c_i \qquad (S_A(j) \subseteq A) \]

    Removing any \(i \in S_A(j)\) from \(A\) and inserting \(j\) yields a new valid basis \((A \setminus \{i\}) \cup \{j\}\). For \(A\) to be a minimum-weight basis, every such local swap must be non-improving:

    \[ x_i \le x_j \qquad \forall j \notin A, \; \forall i \in S_A(j) \quad \Longrightarrow \quad \text{Directed poset edge } i \to j \]

    Symmetrically, for \(B\) to be a maximum-weight basis, representing each \(j \notin B\) as \(c_j = \bigoplus_{i \in S_B(j)} c_i\) (\(S_B(j) \subseteq B\)) forces every swap \((B \setminus \{i\}) \cup \{j\}\) to have weight \(\le w(B)\), which requires:

    \[ x_j \le x_i \qquad \forall j \notin B, \; \forall i \in S_B(j) \quad \Longrightarrow \quad \text{Directed poset edge } j \to i \]

    Notice that this creates at most \(2 \times m(N - m) \le 64 \times 1000 \times 2 \approx 1.28 \times 10^5\) directed edges! Once these \(O(Nm)\) poset edges are extracted via Gaussian elimination over \(\mathbb{F}_2^{64}\), the problem is a pure \(L_2\) Isotonic Regression instance on \(N \le 1000\) vertices with \(\Delta_i(M) = (M - v_i)^2 - (M + 1 - v_i)^2 = 2(v_i - M) - 1\).

1.5 Step 4: Toy Trace & Broken-Gadget Counterexample (FM-24 \(\leftrightarrow\) H-24B)

Toy Trace (\(N = 3\), \(p = 2\), Path Poset \(1 \to 2 \to 3\))

Suppose \(N = 3\) with edges \(1 \to 2\) (\(x_1 \le x_2\)) and \(2 \to 3\) (\(x_2 \le x_3\)), initial prices \(y = (6, 1, 2)\), and weights \(w_i = 1\) on \([L, R] = [1, 6]\):

  1. Root Call (L = 1, R = 6, M = 3):
    • \(\Delta_i(3) = (3 - y_i)^2 - (4 - y_i)^2 = 2(y_i - 3) - 1\):
      • \(\Delta_1(3) = 2(6 - 3) - 1 = +5 > 0 \implies\) edge \(S \to 1\) cap \(5\).
      • \(\Delta_2(3) = 2(1 - 3) - 1 = -5 < 0 \implies\) edge \(2 \to T\) cap \(5\).
      • \(\Delta_3(3) = 2(2 - 3) - 1 = -3 < 0 \implies\) edge \(3 \to T\) cap \(3\).
    • Poset edges: \(1 \to 2\) (\(\infty\)), \(2 \to 3\) (\(\infty\)).
    • Min-Cut Analysis: If \(1 \in S_{\min}\), the \(\infty\)-chain \(1 \to 2 \to 3\) forces \(2, 3 \in S_{\min}\), cutting \(2 \to T\) (cap \(5\)) and \(3 \to T\) (cap \(3\)) for total cut \(8\). If \(1 \in T_{\min}\), we cut \(S \to 1\) for cost \(5 < 8\). Thus \(S_{\min} = \emptyset\) and \(T_{\min} = \{1, 2, 3\}\): all three variables contract to \([1, 3]\)!
  2. Left Child Call (L = 1, R = 3, M = 2):
    • \(\Delta_i(2) = 2(y_i - 2) - 1\): \(\Delta_1(2) = +7\), \(\Delta_2(2) = -3\), \(\Delta_3(2) = -1\).
    • Promoting \(\{1, 2, 3\}\) to \(M+1 = 3\) gains \(+7 - 3 - 1 = +3 > 0\) (cut cost \(3 + 1 = 4 < 7\)). Thus \(S_{\min} = \{1, 2, 3\}\), contracting all three variables to \([3, 3]\), yielding the unique global optimum \(x^* = (3, 3, 3)\) with cost \((3-6)^2 + (3-1)^2 + (3-2)^2 = 9 + 4 + 1 = 14\).

When \(y_i > M\), moving from \(M\) toward \(y_i\) (to \(M+1\)) decreases penalty, so \(\Delta_i(M) > 0\) and \(i\) attaches to \(S\).

2. Weighted Matroid Intersection, Polymatroid Flows, and the Exact Boundary of Network Flow

Throughout Chapters 1–23, we compiled dozens of seemingly unrelated combinatorial constraints into Max-Flow, Min-Cut, and MCMF. Why did network flow succeed on Bipartite Matching (Ch 06), Nested Tree/Hierarchy Capacities (Ch 07), and Project Selection (Ch 09), yet fail when asked to find a Spanning Tree with degree bounds on all vertices or a Rainbow Spanning Tree (CF 1284G, CF 1556H)? The mathematical answer lies in Matroid Intersection Theory and Polymatroid Flows.

2.1 Matroids and the Four Competitive Programming Matroid Classes

A matroid is a pair \(\mathcal{M} = (E, \mathcal{I})\), where \(E\) is a finite ground set and \(\mathcal{I} \subseteq 2^E\) is a family of independent sets satisfying:

  1. Non-emptiness: \(\emptyset \in \mathcal{I}\).
  2. Hereditary Property: If \(I \in \mathcal{I}\) and \(J \subseteq I\), then \(J \in \mathcal{I}\).
  3. Exchange Axiom: If \(I, J \in \mathcal{I}\) with \(|I| < |J|\), there exists \(e \in J \setminus I\) such that \(I \cup \{e\} \in \mathcal{I}\).

Equivalently, a matroid is uniquely determined by its rank function \(r : 2^E \to \mathbb{Z}_{\ge 0}\), \(r(S) = \max \{|I| : I \subseteq S, I \in \mathcal{I}\}\), which is monotone, normalized (\(r(\emptyset) = 0, r(S) \le |S|\)), and submodular:

\[ r(A) + r(B) \ge r(A \cup B) + r(A \cap B) \qquad \forall A, B \subseteq E \]

Almost every matroid encountered in competitive programming belongs to one of four canonical classes:

Matroid Class Ground Set \(E\) Independence Condition \(I \in \mathcal{I}\) Independence Oracle Cost
1. Partition Matroid Disjoint groups \(E = \bigsqcup_{k=1}^p E_k\) \(|I \cap E_k| \le c_k\) for all \(k = 1, \dots, p\) \(O(1)\) per element (group counter)
2. Laminar Matroid Nested family \(\mathcal{F} \subseteq 2^E\) (\(A \cap B \in \{\emptyset, A, B\}\)) \(|I \cap A| \le c_A\) for all \(A \in \mathcal{F}\) (tree of subsets) \(O(\text{depth}(\mathcal{F}))\)
3. Graphic Matroid Edges \(E(G)\) of an undirected graph \(G\) \(I\) is a forest (contains no cycle in \(G\)) \(O(|V|)\) or \(O(\alpha(|V|))\) via DSU / tree path
4. Linear (XOR) Matroid Vectors \(v_e \in \mathbb{F}_2^d\) (or \(\mathbb{F}_p^d\)) \(\{v_e : e \in I\}\) are linearly independent \(O(d)\) via Gaussian / XOR basis

2.2 Boundary 1: Why Partition \(\cap\) Partition and Laminar \(\cap\) Laminar ARE Network Flows

Suppose we want to find a maximum-weight (or maximum-cardinality) common independent set \(I \in \mathcal{I}_1 \cap \mathcal{I}_2\) of two matroids \(\mathcal{M}_1 = (E, \mathcal{I}_1)\) and \(\mathcal{M}_2 = (E, \mathcal{I}_2)\) on the same ground set \(E\).

  • Case A: Partition \(\cap\) Partition = Bipartite \(b\)-Matching (Ch 06): If \(\mathcal{M}_1\) partitions \(E = \bigsqcup_{u \in L} E_u\) with capacities \(c_u\) and \(\mathcal{M}_2\) partitions \(E = \bigsqcup_{v \in R} E'_v\) with capacities \(d_v\), then each element \(e \in E\) belongs to exactly one left group \(u(e) \in L\) and one right group \(v(e) \in R\). Representing \(e\) as a directed edge \(u(e) \to v(e)\) with capacity \(1\), the network \(S \xrightarrow{c_u} u \xrightarrow{e} v \xrightarrow{d_v} T\) enforces \(|I \cap E_u| \le c_u\) via flow conservation at \(u\) and \(|I \cap E'_v| \le d_v\) via flow conservation at \(v\).

  • Case B: Laminar \(\cap\) Laminar = Tree-Hierarchy Max-Flow / MCMF (Ch 07): Because a laminar family \(\mathcal{F}_1\) forms a rooted forest of subsets, flow conservation through the tree nodes of \(\mathcal{F}_1\) (from \(S\) down to leaves \(E\)) and up through the inverted tree nodes of \(\mathcal{F}_2\) (from leaves \(E\) up to \(T\)) enforces \(|I \cap A| \le c_A\) for all \(A \in \mathcal{F}_1 \cup \mathcal{F}_2\) simultaneously. The underlying constraint matrix is Totally Unimodular (TU) (Ch 20).

  • Case C: Polymatroid Flows & Edmonds’ Min-Cut Theorem: More generally, in a Polymatroid Network (Edmonds 1970, Lawler–Martel 1982), the bundle of edges exiting vertex \(u\) is constrained by a submodular rank function \(f(\delta^+(u)) \le r_u^+\), and the bundle entering \(u\) is constrained by \(f(\delta^-(u)) \le r_u^-\). By Edmonds’ Matroid Intersection Duality Theorem:

    \[ \max_{I \in \mathcal{I}_1 \cap \mathcal{I}_2} |I| = \min_{S \subseteq E} \Big( r_1(S) + r_2(E \setminus S) \Big) \]

    Notice that this is the exact submodular generalization of the Max-Flow Min-Cut Theorem! When \(r_1\) and \(r_2\) are cut capacities or laminar tree capacities, a single static residual graph suffices because any swap inside a partition/laminar group can be routed through the group’s shared hub vertex \(u\).

2.3 Boundary 2: When Static Flow Networks Fail — Edmonds’ Augmenting Exchange Digraph

Why can we not represent a Graphic Matroid (forest constraint) or Linear XOR Matroid as a static flow gadget? In a partition matroid, if group \(E_u\) is at full capacity \(|I \cap E_u| = c_u\), inserting a new element \(y \in E_u \setminus I\) allows us to evict any existing element \(x \in I \cap E_u\) — the valid swaps \((x, y)\) depend only on static group membership, which a single hub vertex \(u\) can route. In a Graphic Matroid, however, adding a non-tree edge \(y = (a, b) \notin I\) creates a unique fundamental cycle \(C(I, y)\) in the current forest \(I\); we may only evict an edge \(x \in C(I, y) \setminus \{y\}\). Worse yet, which edges belong to \(C(I, y)\) changes dynamically every time the forest \(I\) changes! No fixed static graph of vertices and capacities can encode a state-dependent cycle membership relation.

Instead, Matroid Intersection rebuilds the residual exchange graph dynamically at every augmentation step!

ImportantAlgorithm 24.1 (Edmonds’ Weighted & Unweighted Matroid Intersection)

Given two matroids \(\mathcal{M}_1 = (E, \mathcal{I}_1)\) and \(\mathcal{M}_2 = (E, \mathcal{I}_2)\) with element weights \(w : E \to \mathbb{R}\) (to maximize \(\sum_{e \in I} w(e)\)), maintain a common independent set \(I \in \mathcal{I}_1 \cap \mathcal{I}_2\) (initially \(I = \emptyset\)). At each step, construct the bipartite Exchange Digraph \(G(I) = (I \sqcup (E \setminus I), A_1 \cup A_2)\):

  1. Source Set \(X_1\) (\(\mathcal{M}_1\)-free insertions) and Sink Set \(X_2\) (\(\mathcal{M}_2\)-free insertions):

    \[ X_1 = \{y \in E \setminus I : I \cup \{y\} \in \mathcal{I}_1\}, \qquad X_2 = \{y \in E \setminus I : I \cup \{y\} \in \mathcal{I}_2\} \]

  2. Exchange Arcs \(A_1\) (from \(I\) to \(E \setminus I\), governed by \(\mathcal{M}_1\)) and \(A_2\) (from \(E \setminus I\) to \(I\), governed by \(\mathcal{M}_2\)):

    \[ A_1 = \big\{ (x \to y) : x \in I, \; y \in E \setminus I, \; (I \setminus \{x\}) \cup \{y\} \in \mathcal{I}_1 \big\} \]

    \[ A_2 = \big\{ (y \to x) : x \in I, \; y \in E \setminus I, \; (I \setminus \{x\}) \cup \{y\} \in \mathcal{I}_2 \big\} \]

  3. Shortest Augmenting Path & Symmetric Difference Update: Assign vertex weights \(\tilde{w}(y) = +w(y)\) for \(y \in E \setminus I\) and \(\tilde{w}(x) = -w(x)\) for \(x \in I\). Find an augmenting path \(P = (y_0, x_1, y_1, \dots, x_k, y_k)\) in \(G(I)\) from some \(y_0 \in X_1\) to some \(y_k \in X_2\) that maximizes total vertex weight \(\tilde{w}(P)\), breaking ties by minimum number of edges (shortest hop count)!

    • In the unweighted case (\(w(e) = 1\)), a simple BFS from \(X_1\) to \(X_2\) finds the shortest hop-count path \(P\).
    • In the weighted case, Bellman-Ford / SPFA finds the maximum-weight path with minimum hop count among tied maximum-weight paths.
    • Update \(I \gets I \oplus V(P) = (I \setminus \{x_1, \dots, x_k\}) \cup \{y_0, y_1, \dots, y_k\}\). Notice \(|I|\) increases by \(+1\). Stop when no \(X_1\)-to-\(X_2\) path exists.
WarningWhy Hop-Count Tie-Breaking Is Mandatory (Chordless Path Invariant)

Suppose a path \(P\) in \(G(I)\) has a shortcut chord \((x_i \to y_j) \in A_1\) or \((y_i \to x_j) \in A_2\) with \(i < j\). Then performing multiple simultaneous exchanges along \(P\) can violate independence in \(\mathcal{M}_1\) or \(\mathcal{M}_2\) (\(I \oplus V(P) \notin \mathcal{I}_1 \cap \mathcal{I}_2\))! Choosing a path of minimum hop count in the unweighted case (or maximum weight, then minimum hop count in the weighted case) mathematically guarantees that \(P\) has no shortcut chords of non-negative weight, which by the Strong Basis Exchange Lemma ensures \(I \oplus V(P) \in \mathcal{I}_1 \cap \mathcal{I}_2\).

2.4 Boundary 3: Why 3-Matroid Intersection Is NP-Hard & The “Flow Amnesia” Anti-Pattern

What happens when an English problem imposes three independent partition/matroid constraints on each chosen item \(e \in E\)?

  • NP-Hardness Barrier: Intersecting three Partition Matroids is 3-Dimensional Matching (3DM); intersecting a Graphic Matroid with two Partition Matroids (e.g., degree bounds \(\le 2\) on all vertices of a general graph) is Hamiltonian Path! Both are NP-hard.
  • The 3-Layer Flow Amnesia Trap (流量失忆): Novice solvers frequently attempt to solve 3-attribute matching \((a_e, x_e, b_e)\) by building a 3-layer flow network \(S \to A \to X \to B \to T\), adding edge \(a_e \to x_e\) and edge \(x_e \to b_e\) for each triple \(e = (a_e, x_e, b_e)\). Why this is broken: Vertex \(x \in X\) has Flow Amnesia! If triple \(e_1 = (a_1, x, b_1)\) adds \(a_1 \to x \to b_1\) and triple \(e_2 = (a_2, x, b_2)\) adds \(a_2 \to x \to b_2\), then a unit of flow from \(S \to a_1 \to x\) can exit along \(x \to b_2 \to T\), fabricating a hallucinated hybrid triple \((a_1, x, b_2) \notin E\)! A 3-layer network \(S \to A \to X \to B \to T\) is valid if and only if the problem allows arbitrary recombination at \(x\) (or each \(x \in X\) represents a single indivisible item with capacity \(1\) via vertex-splitting \(x_{\text{in}} \xrightarrow{1} x_{\text{out}}\) where any \(a \in N^-(x)\) and any \(b \in N^+(x)\) form a valid choice, as in [SCOI2007] 修车 / [USACO07OPEN] Dining).

3. Combinatorial Game Invariants & The LGV Lemma Boundary

Even when a problem lives on a bipartite grid or asks for vertex-disjoint paths in a DAG, jumping straight into a flow solver without checking algebraic invariants can be fatal. In this section, we study two classic boundary phenomena:

  1. Bipartite Parity Invariants Before Binary-Search Flow ([SCOI2012] 奇怪的游戏): Where a conservation law on \((r+c) \bmod 2\) either uniquely pins the target value \(X\) (making binary search invalid!) or proves that feasibility is monotone in \(X\).
  2. The Lindström–Gessel–Viennot (LGV) Determinant Lemma ([NOI2021] 路径交点, CF 348D Turtles): Where the problem asks to count (or compute the parity of) \(K\)-tuples of vertex-disjoint DAG paths rather than simply finding one maximum-cardinality or minimum-cost tuple (Ch 02, Ch 14).

3.1 Chessboard Increment Invariants ([SCOI2012] 奇怪的游戏, Luogu P5038)

Step 1: Non-Graph Diagnostic Signal

You are given an \(N \times M\) grid (\(N, M \le 40\)) of initial non-negative integers \(a_{r,c}\). In one operation, you may pick any two orthogonally adjacent cells \((r_1, c_1)\) and \((r_2, c_2)\) and increment both by \(+1\). Find the minimum number of operations required to make all cells equal to some common final value \(X\), or report -1 if impossible.

  • Why Naive Binary Search Fails Immediately: Suppose \(N = 1, M = 3\) with initial grid \([1, 2, 1]\). Raising all cells to \(X = 2\) takes \(1 + 0 + 1 = 2\) cell increments (\(1\) operation on \((1,1)-(1,2)\)? No, that makes \([2, 3, 1]\)!). In fact, for \(X = 2\), the two black cells \((1,1)\) and \((1,3)\) need \((2-1) + (2-1) = 2\) increments, while the single white cell \((1,2)\) needs \(2 - 2 = 0\) increments — impossible because every domino operation increments one black cell and one white cell! Worse still, if \(X = 3\), black cells need \((3-1)+(3-1) = 4\) and white needs \(3-2 = 1\) (\(4 \ne 1\)). Feasibility is not monotonic in \(X\) when \(N \times M\) is odd!

Step 2: Intermediate Algebraic Representation (The Bipartite Parity Equation)

2-color the \(N \times M\) grid like a chessboard: let \(B = \{(r, c) : (r + c) \equiv 0 \pmod 2\}\) be the black cells and \(W = \{(r, c) : (r + c) \equiv 1 \pmod 2\}\) be the white cells. Let:

\[ c_B = |B|, \quad s_B = \sum_{u \in B} a_u, \qquad c_W = |W|, \quad s_W = \sum_{v \in W} a_v \]

If all cells reach final value \(X \ge \max_{r,c} a_{r,c}\), then each cell \(u\) must be incremented exactly \(X - a_u \ge 0\) times. Since every operation increments one cell in \(B\) and one cell in \(W\), the total number of operations \(K(X)\) must simultaneously equal the sum of black deficits and the sum of white deficits:

\[ K(X) = \sum_{u \in B} (X - a_u) = c_B X - s_B = \sum_{v \in W} (X - a_v) = c_W X - s_W \]

Rearranging terms yields the fundamental Linear Parity Invariant:

\[ (c_B - c_W) X = s_B - s_W \]

This equation splits into two completely different algorithmic regimes depending on whether \(N \times M\) is odd or even:

  1. Case 1: \(N \times M\) is Odd (\(c_B - c_W = 1\), assuming \((1,1) \in B\)): The invariant forces a unique candidate target value:

    \[ X = s_B - s_W \]

    There is no monotonicity and no binary search! We simply check whether \(X \ge \max_{r,c} a_{r,c}\) and run one single Max-Flow for this exact \(X\). If that flow saturates \(K(X) = c_B X - s_B\), the answer is \(K(X)\); otherwise, the answer is -1.

  2. Case 2: \(N \times M\) is Even (\(c_B = c_W\)): Now \(c_B - c_W = 0\), so the invariant requires \(s_B = s_W\) (if \(s_B \ne s_W\), output -1 immediately!). When \(s_B = s_W\), every \(X \ge \max a_{r,c}\) satisfies \(c_B X - s_B = c_W X - s_W\). Moreover, why is feasibility monotonic in \(X\)? Because when \(N \times M\) is even, the \(N \times M\) grid always admits a perfect domino tiling (a collection of \(c_B = c_W = NM/2\) disjoint adjacent pairs covering every cell once). If \(X\) is feasible, then firing every domino in the perfect tiling once increases every cell by \(+1\), proving that \(X + 1\) is also feasible! Thus we binary search \(X \in [\max a_{r,c}, \infty)\).

Step 3: Mechanical Graph Compilation (check(X))

To test whether a candidate \(X\) is achievable, let \(x_{uv} \in \mathbb{Z}_{\ge 0}\) be the number of operations applied to adjacent pair \((u, v)\) with \(u \in B, v \in W\). We need:

\[ \sum_{v \in N(u)} x_{uv} = X - a_u \quad (\forall u \in B), \qquad \sum_{u \in N(v)} x_{uv} = X - a_v \quad (\forall v \in W) \]

This is a standard Bipartite Supply-Demand Feasibility problem (Ch 06):

  • Source \(S \to u\) with capacity \(X - a_u\) for all \(u \in B\).
  • Directed edge \(u \to v\) with capacity \(\infty\) for all adjacent \(u \in B, v \in W\).
  • Directed edge \(v \to T\) with capacity \(X - a_v\) for all \(v \in W\).
  • Target \(X\) is feasible iff \(\text{MaxFlow}(S, T) = \sum_{u \in B} (X - a_u) = c_B X - s_B\).

3.2 Non-Intersecting DAG Paths & The LGV Lemma Boundary ([NOI2021] 路径交点, CF 348D)

Suppose we are given a Directed Acyclic Graph (DAG) \(G = (V, E)\) with \(K\) sources \(A = \{a_1, \dots, a_K\}\) and \(K\) sinks \(B = \{b_1, \dots, b_K\}\).

  • If the problem asks for the maximum number of vertex-disjoint paths from \(A\) to \(B\) (or minimum cost), we use Vertex-Split Max-Flow / MCMF (Ch 02, Ch 14): split each \(v \in V\) into \(v_{\text{in}} \xrightarrow{1} v_{\text{out}}\).
  • What if the problem asks for the number of \(K\)-tuples of vertex-disjoint paths (or the signed parity of crossings, as in [NOI2021] 路径交点 Luogu P7736, or the count of non-intersecting lattice paths in CF 348D Turtles)? Max-Flow only finds one augmenting flow; it cannot count all valid path systems. Here we cross the boundary into Algebraic Combinatorics via the Lindström–Gessel–Viennot (LGV) Lemma.
ImportantTheorem 24.2 (Lindström–Gessel–Viennot Lemma, 1969 / 1985)

Let \(G = (V, E)\) be a finite edge-weighted Directed Acyclic Graph. For any path \(P\), define its weight \(\omega(P) = \prod_{e \in P} \omega(e)\) (for unweighted path counting, \(\omega(e) = 1\)). Let \(e(u, v) = \sum_{P : u \leadsto v} \omega(P)\) denote the total weight of all directed paths from \(u\) to \(v\). Given \(K\) sources \(A = (a_1, \dots, a_K)\) and \(K\) sinks \(B = (b_1, \dots, b_K)\), define the \(K \times K\) path-count matrix:

\[ M = \begin{bmatrix} e(a_1, b_1) & e(a_1, b_2) & \cdots & e(a_1, b_K) \\ e(a_2, b_1) & e(a_2, b_2) & \cdots & e(a_2, b_K) \\ \vdots & \vdots & \ddots & \vdots \\ e(a_K, b_1) & e(a_K, b_2) & \cdots & e(a_K, b_K) \end{bmatrix} \]

Then the determinant of \(M\) equals the signed weighted sum over all \(K\)-tuples of vertex-disjoint path systems \(\mathcal{P} = (P_1, \dots, P_K)\) where \(P_i : a_i \leadsto b_{\pi(i)}\) for some permutation \(\pi \in S_K\):

\[ \det(M) = \sum_{\pi \in S_K} \operatorname{sgn}(\pi) \sum_{\substack{\mathcal{P} = (P_1, \dots, P_K) \\ P_i : a_i \leadsto b_{\pi(i)} \\ P_i \cap P_j = \emptyset \; (\forall i \ne j)}} \prod_{i=1}^K \omega(P_i) \]

Proof Sketch (The First-Intersection Path-Swapping Involution)

Expanding the determinant by Leibniz’s formula gives \(\det(M) = \sum_{\pi \in S_K} \operatorname{sgn}(\pi) \sum_{P_i : a_i \leadsto b_{\pi(i)}} \prod_{i=1}^K \omega(P_i)\), which sums over all path tuples (both vertex-disjoint and intersecting). For any path tuple \(\mathcal{P} = (P_1, \dots, P_K)\) that has at least one shared vertex, pick the lexicographically first intersecting vertex \(v\) along a fixed topological order of the DAG, and let \(i < j\) be the two smallest indices of paths passing through \(v\). Split \(P_i = P_i[a_i \leadsto v] \circ P_i[v \leadsto b_{\pi(i)}]\) and \(P_j = P_j[a_j \leadsto v] \circ P_j[v \leadsto b_{\pi(j)}]\), and swap their tails after \(v\):

\[ P'_i = P_i[a_i \leadsto v] \circ P_j[v \leadsto b_{\pi(j)}], \qquad P'_j = P_j[a_j \leadsto v] \circ P_i[v \leadsto b_{\pi(i)}] \]

This mapping \(\Phi(\mathcal{P}) = \mathcal{P}'\) is a weight-preserving, sign-reversing involution (\(\Phi(\Phi(\mathcal{P})) = \mathcal{P}\), \(\prod \omega(P'_k) = \prod \omega(P_k)\), and \(\pi' = \pi \circ (i \; j)\) so \(\operatorname{sgn}(\pi') = -\operatorname{sgn}(\pi)\)). Hence all intersecting path tuples cancel out in pairs, leaving only vertex-disjoint path tuples! \(\blacksquare\)

Two Canonical Consequences for Contest Problem Solving

  1. Planar Non-Crossing Source/Sink Order (CF 348D Turtles): If \(G\) is a planar DAG (such as a grid where paths move right/down) and the sources \(a_1, \dots, a_K\) and sinks \(b_1, \dots, b_K\) lie on the boundary in order such that any path system for a non-identity permutation \(\pi \ne \text{id}\) must topologically cross (and therefore share a grid vertex), then every \(\pi \ne \text{id}\) has zero vertex-disjoint tuples! Thus \(\det(M)\) counts the exact number of non-intersecting path tuples \(P_i : a_i \leadsto b_i\).

  2. Multi-Layer Planar Intersection Parity ([NOI2021] 路径交点, Luogu P7736): In [NOI2021] 路径交点, a layered graph has \(L\) layers (\(n_1 = n_L = K\)), with bipartite adjacency matrices \(A_1, A_2, \dots, A_{L-1}\) between consecutive layers where crossings of edges between layer \(t\) and \(t+1\) occur only at the endpoints or in the planar drawing. For any vertex-disjoint path system \(\mathcal{P}\) from layer \(1\) to layer \(L\) inducing permutation \(\pi \in S_K\), the parity of the total number of geometric edge crossings \(c(\mathcal{P})\) is governed by the inversion parity of \(\pi\): \((-1)^{c(\mathcal{P})} = \operatorname{sgn}(\pi)\)! Even better: if paths can intersect at intermediate layer vertices, the LGV involution cancels all vertex-intersecting tuples, and by the Cauchy–Binet / matrix multiplication identity, the total path matrix from layer \(1\) to layer \(L\) is simply the matrix product of the layer adjacency matrices:

    \[ M = A_1 A_2 \cdots A_{L-1} \quad \Longrightarrow \quad \text{Signed Answer} = \det(A_1 A_2 \cdots A_{L-1}) \pmod{998244353} \]

#include <bits/stdc++.h>
using namespace std;

const long long INF = 1e16;

struct Dinic {
    struct Edge { int to, rev; long long cap; };
    int n, s, t;
    vector<vector<Edge>> adj;
    vector<int> level, ptr;

    Dinic(int n, int s, int t) : n(n), s(s), t(t), adj(n), level(n), ptr(n) {}

    void add_edge(int from, int to, long long cap) {
        adj[from].push_back({to, (int)adj[to].size(), cap});
        adj[to].push_back({from, (int)adj[from].size() - 1, 0});
    }

    bool bfs() {
        fill(level.begin(), level.end(), -1);
        level[s] = 0;
        queue<int> q;
        q.push(s);
        while (!q.empty()) {
            int v = q.front(); q.pop();
            for (auto& edge : adj[v]) {
                if (edge.cap > 0 && level[edge.to] == -1) {
                    level[edge.to] = level[v] + 1;
                    q.push(edge.to);
                }
            }
        }
        return level[t] != -1;
    }

    long long dfs(int v, long long pushed) {
        if (pushed == 0 || v == t) return pushed;
        for (int& cid = ptr[v]; cid < (int)adj[v].size(); ++cid) {
            auto& edge = adj[v][cid];
            int tr = edge.to;
            if (level[v] + 1 != level[tr] || edge.cap == 0) continue;
            long long tr_pushed = dfs(tr, min(pushed, edge.cap));
            if (tr_pushed == 0) continue;
            edge.cap -= tr_pushed;
            adj[tr][edge.rev].cap += tr_pushed;
            return tr_pushed;
        }
        level[v] = -1; // FM-03: Dead-node pruning
        return 0;
    }

    long long max_flow() {
        long long flow = 0;
        while (bfs()) {
            fill(ptr.begin(), ptr.end(), 0);
            while (long long pushed = dfs(s, INF)) flow += pushed;
        }
        return flow;
    }
};

void solve() {
    int n, m;
    if (!(cin >> n >> m)) return;
    vector<vector<long long>> a(n, vector<long long>(m));
    long long cB = 0, cW = 0, sB = 0, sW = 0, mx = 0;
    for (int r = 0; r < n; ++r) {
        for (int c = 0; c < m; ++c) {
            cin >> a[r][c];
            mx = max(mx, a[r][c]);
            if ((r + c) % 2 == 0) { cB++; sB += a[r][c]; }
            else { cW++; sW += a[r][c]; }
        }
    }

    auto check = [&](long long X) -> bool {
        if (X < mx) return false;
        int S = n * m, T = n * m + 1;
        Dinic dinic(n * m + 2, S, T);
        long long need = 0;
        int dr[4] = {-1, 1, 0, 0}, dc[4] = {0, 0, -1, 1};
        for (int r = 0; r < n; ++r) {
            for (int c = 0; c < m; ++c) {
                int u = r * m + c;
                if ((r + c) % 2 == 0) {
                    dinic.add_edge(S, u, X - a[r][c]);
                    need += X - a[r][c];
                    for (int d = 0; d < 4; ++d) {
                        int nr = r + dr[d], nc = c + dc[d];
                        if (nr >= 0 && nr < n && nc >= 0 && nc < m)
                            dinic.add_edge(u, nr * m + nc, INF);

struct LeftistNode {
    long long val;

};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    if (!(cin >> n)) return 0;
    vector<long long> b(n + 1);
    vector<LeftistNode> pool(n + 1);
    for (int i = 1; i <= n; ++i) {
        long long a;
        cin >> a;
        b[i] = a - i;
        pool[i] = {b[i], 0, 0, 0};
    }

    auto merge = [&](auto& self, int x, int y) -> int {
        if (!x || !y) return x | y;
        if (pool[x].val < pool[y].val) swap(x, y); // Max-heap root is median
        pool[x].r = self(self, pool[x].r, y);
        if (pool[pool[x].l].dist < pool[pool[x].r].dist)
            swap(pool[x].l, pool[x].r);
        pool[x].dist = pool[pool[x].r].dist + 1;
        return x;
    };

    struct Block { int root, l, r, sz; };
    vector<Block> st;
    for (int i = 1; i <= n; ++i) {
        Block cur = {i, i, i, 1};
        while (!st.empty() && pool[st.back().root].val > pool[cur.root].val) {
            Block prev = st.back();
            st.pop_back();
            cur.root = merge(merge, prev.root, cur.root);
            cur.l = prev.l;
            cur.sz += prev.sz;
            int target_sz = (cur.r - cur.l + 2) / 2;
            while (cur.sz > target_sz) {
                cur.root = merge(merge, pool[cur.root].l, pool[cur.root].r);
                cur.sz--;
            }
        }
        st.push_back(cur);
    }

    vector<long long> x(n + 1);
    long long ans = 0;
    for (auto& blk : st) {
        long long med = pool[blk.root].val;
        for (int i = blk.l; i <= blk.r; ++i) {
            x[i] = med;
            ans += llabs(x[i] - b[i]);
        }
    }

        cout << (x[i] + i) << (i == n ? '\n' : ' ');
    return 0;

    • Perspective A (\(L_1\) Isotonic Regression Poset, Ch 24.1): A spanning tree \(T_0\) is an MST under weights \(x\) if and only if for every non-tree edge \(f = (u, v) \notin T_0\) and every tree edge \(e \in P_{T_0}(u, v)\) on the unique path between \(u\) and \(v\) in \(T_0\), we have:

      \[ x_e \le x_f \qquad \forall f \notin T_0, \; \forall e \in P_{T_0}(f) \]

      Notice this is a bipartite poset between the \(N-1\) tree edges \(e \in T_0\) (which only ever decrease, \(x_e \le w_e\)) and the \(M - N + 1\) non-tree edges \(f \notin T_0\) (which only ever increase, \(x_f \ge w_f\)).

      \[ d_e + d_f \ge \max(0, w_e - w_f) \qquad \forall f \notin T_0, \; e \in P_{T_0}(f) \]

    vector<int> V_all(n), local_id(n);
    iota(V_all.begin(), V_all.end(), 0);

    auto solve = [&](auto& self, vector<int>& V, vector<pair<int, int>>& E, long long L, long long R) -> void {
        if (V.empty()) return;
        if (L == R) {
            for (int u : V) ans[u] = L;
            return;
        }
        long long M = L + (R - L) / 2;
        int k = V.size();
        for (int i = 0; i < k; ++i) local_id[V[i]] = i;
        int S = k, T = k + 1;
        Dinic dinic(k + 2, S, T);
        for (int i = 0; i < k; ++i) {
            int u = V[i];
            long long delta = 2LL * (v[u] - M) - 1;
            if (delta > 0) dinic.add_edge(S, i, delta);
            else dinic.add_edge(i, T, -delta);
        }
        for (auto [u, w] : E)
            dinic.add_edge(local_id[u], local_id[w], INF);
        dinic.max_flow();

        vector<int> VL, VR;
        for (int i = 0; i < k; ++i) {
            if (dinic.level[i] != -1) VR.push_back(V[i]);
            else VL.push_back(V[i]);
        }
        vector<pair<int, int>> EL, ER;
        for (auto [u, w] : E) {
            bool uR = (dinic.level[local_id[u]] != -1);
            bool wR = (dinic.level[local_id[w]] != -1);
            if (!uR && !wR) EL.push_back({u, w});
            else if (uR && wR) ER.push_back({u, w});
        }
        self(self, VL, EL, L, M);
        self(self, VR, ER, M + 1, R);
    };

    solve(solve, V_all, edges, 0, 1000000);
    unsigned long long total = 0;
    for (int i = 0; i < n; ++i) {
        long long diff = ans[i] - v[i];
        total += (unsigned long long)(diff * diff);
    }
    cout << total << "\n";
    return 0;
}

struct DSU {
    vector<int> p;
    DSU(int n) : p(n) { iota(p.begin(), p.end(), 0); }
    int find(int x) { return p[x] == x ? x : p[x] = find(p[x]); }
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;
        p[a] = b; return true;
    }
};

struct Edge { int u, v, b_node, r1, c1, r2, c2; };

void solve() {

    for (int i = 0; i < n; ++i) cin >> s[i];

                all_edges.push_back(e);
                if (bn != -1) edges.push_back(e);
            }
        }
    }

    while (true) {
        vector<int> deg(num_B, 0);
        DSU dsu_full(n * m);
        for (int i = 0; i < E; ++i) {
            if (in_I[i]) {
                deg[edges[i].b_node]++;
                dsu_full.unite(edges[i].u, edges[i].v);
            }

        vector<int> X1(E, 0), X2(E, 0);

            if (!in_I[x]) continue;

            for (int i = 0; i < E; ++i)
                if (in_I[i] && i != x) dsu_no_x.unite(edges[i].u, edges[i].v);
            for (int y = 0; y < E; ++y) {
                if (in_I[y]) continue;

    for (int i = 0; i < E; ++i) {
        if (in_I[i]) {
            dsu_final.unite(edges[i].u, edges[i].v);
            chosen.push_back(edges[i]);
        }
    }
    for (auto& e : all_edges) {
        if (dsu_final.unite(e.u, e.v)) chosen.push_back(e);

        out[e.r1 + e.r2][e.c1 + e.c2] = 'O';

}

#include <bits/stdc++.h>
using namespace std;

const long long MOD = 998244353;

long long power(long long base, long long exp) {
    long long res = 1;
    base %= MOD;
    while (exp > 0) {
        if (exp & 1) res = res * base % MOD;
        base = base * base % MOD;
        exp >>= 1;
    }
    return res;
}

long long det_mod(vector<vector<long long>> A, int n) {
    long long det = 1;
    for (int i = 0; i < n; ++i) {
        int pivot = -1;
        for (int r = i; r < n; ++r) {
            if (A[r][i] != 0) { pivot = r; break; }
        }
        if (pivot == -1) return 0;
        if (pivot != i) {
            swap(A[i], A[pivot]);
            det = (MOD - det) % MOD;
        }
        det = det * A[i][i] % MOD;
        long long inv = power(A[i][i], MOD - 2);
        for (int r = i + 1; r < n; ++r) {
            if (A[r][i] == 0) continue;
            long long factor = A[r][i] * inv % MOD;
            for (int c = i; c < n; ++c)
                A[r][c] = (A[r][c] - factor * A[i][c]) % MOD;
        }
    }
    return (det + MOD) % MOD;
}

void solve() {
    int K;
    if (!(cin >> K)) return;
    vector<int> n(K), m(K - 1);
    for (int i = 0; i < K; ++i) cin >> n[i];
    for (int i = 0; i < K - 1; ++i) cin >> m[i];

    // M starts as n[0] x n[0] identity matrix
    vector<vector<long long>> M(n[0], vector<long long>(n[0], 0));
    for (int i = 0; i < n[0]; ++i) M[i][i] = 1;

    for (int layer = 0; layer < K - 1; ++layer) {
        vector<vector<long long>> A(n[layer], vector<long long>(n[layer + 1], 0));
        for (int e = 0; e < m[layer]; ++e) {
            int u, v;
            cin >> u >> v;
            --u; --v;
            A[u][v] = (A[u][v] + 1) % MOD;
        }
        vector<vector<long long>> nxt(n[0], vector<long long>(n[layer + 1], 0));
        for (int i = 0; i < n[0]; ++i) {
            for (int k = 0; k < n[layer]; ++k) {
                if (!M[i][k]) continue;
                for (int j = 0; j < n[layer + 1]; ++j)
                    nxt[i][j] = (nxt[i][j] + M[i][k] * A[k][j]) % MOD;
            }
        }
        M = move(nxt);
    }
    cout << det_mod(M, n[0]) << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    if (cin >> T) while (T--) solve();
    return 0;
}

#include <bits/stdc++.h>
using namespace std;

const double INF = 1e18;
const double EPS = 1e-9;

struct DinicDouble {
    struct Edge { int to, rev; double cap; };
    int n, s, t;
    vector<vector<Edge>> adj;
    vector<int> level, ptr;
    DinicDouble(int n, int s, int t) : n(n), s(s), t(t), adj(n), level(n), ptr(n) {}
    void add_edge(int u, int v, double cap) {
        adj[u].push_back({v, (int)adj[v].size(), cap});
        adj[v].push_back({u, (int)adj[u].size() - 1, 0.0});
    }
    bool bfs() {
        fill(level.begin(), level.end(), -1);
        level[s] = 0;
        queue<int> q; q.push(s);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (auto& e : adj[u])
                if (e.cap > EPS && level[e.to] == -1) {
                    level[e.to] = level[u] + 1;
                    q.push(e.to);
                }
        }
        return level[t] != -1;
    }
    double dfs(int u, double pushed) {
        if (pushed <= EPS || u == t) return pushed;
        for (int& cid = ptr[u]; cid < (int)adj[u].size(); ++cid) {
            auto& e = adj[u][cid];
            if (level[u] + 1 != level[e.to] || e.cap <= EPS) continue;
            double tr = dfs(e.to, min(pushed, e.cap));
            if (tr <= EPS) continue;
            e.cap -= tr; adj[e.to][e.rev].cap += tr;
            return tr;
        }
        level[u] = -1;
        return 0.0;
    }
    double max_flow() {
        double f = 0;
        while (bfs()) {
            fill(ptr.begin(), ptr.end(), 0);
            while (double p = dfs(s, INF)) f += p;
        }
        return f;
    }
};

// Solves continuous L_p Isotonic Regression: min sum w_i |x_i - y_i|^p s.t. x_u <= x_v
vector<double> solve_lp_isotonic(int n, double p, const vector<double>& y, const vector<double>& w,
                                 const vector<pair<int, int>>& poset_edges, double L, double R) {
    vector<double> ans(n, 0.0);
    vector<int> V_all(n), local_id(n);
    iota(V_all.begin(), V_all.end(), 0);

    auto rec = [&](auto& self, vector<int>& V, vector<pair<int, int>>& E, double lo, double hi, int depth) -> void {
        if (V.empty()) return;
        if (depth >= 50 || hi - lo < 1e-9) {
            double mid = 0.5 * (lo + hi);
            for (int u : V) ans[u] = mid;
            return;
        }
        double mid = 0.5 * (lo + hi);
        int k = V.size();
        for (int i = 0; i < k; ++i) local_id[V[i]] = i;
        int S = k, T = k + 1;
        DinicDouble dinic(k + 2, S, T);
        for (int i = 0; i < k; ++i) {
            int u = V[i];
            double diff = y[u] - mid;
            double delta = (diff >= 0 ? 1.0 : -1.0) * w[u] * pow(fabs(diff), p - 1.0);
            if (delta > 0) dinic.add_edge(S, i, delta);
            else dinic.add_edge(i, T, -delta);
        }
        for (auto [u, v] : E)
            dinic.add_edge(local_id[u], local_id[v], INF);
        dinic.max_flow();

        vector<int> VL, VR;
        for (int i = 0; i < k; ++i) {
            if (dinic.level[i] != -1) VR.push_back(V[i]);
            else VL.push_back(V[i]);
        }
        vector<pair<int, int>> EL, ER;
        for (auto [u, v] : E) {
            bool uR = (dinic.level[local_id[u]] != -1);
            bool vR = (dinic.level[local_id[v]] != -1);
            if (!uR && !vR) EL.push_back({u, v});
            else if (uR && vR) ER.push_back({u, v});
        }
        self(self, VL, EL, lo, mid, depth + 1);
        self(self, VR, ER, mid, hi, depth + 1);
    };

    rec(rec, V_all, poset_edges, L, R, 0);
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m; double p;
    if (!(cin >> n >> m >> p)) return 0;
    vector<double> y(n), w(n);
    double L = 1e18, R = -1e18;
    for (int i = 0; i < n; ++i) { cin >> y[i]; L = min(L, y[i]); R = max(R, y[i]); }
    for (int i = 0; i < n; ++i) cin >> w[i];
    vector<pair<int, int>> edges(m);
    for (int i = 0; i < m; ++i) { cin >> edges[i].first >> edges[i].second; --edges[i].first; --edges[i].second; }

    auto x = solve_lp_isotonic(n, p, y, w, edges, L, R);
    double total = 0;
    for (int i = 0; i < n; ++i) total += w[i] * pow(fabs(x[i] - y[i]), p);
    cout << fixed << setprecision(6) << total << "\n";
    return 0;
}
