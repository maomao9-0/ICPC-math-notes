1. Unifying Spine: Compressing an Exponential Cut Space (\(2^N \to \text{DP States or } N-1 \text{ Tree Edges}\))

Across Chapters 9 through 14, we used the Max-Flow Min-Cut Theorem in Direction A (\(\text{Combinatorial Optimization} \to \text{Flow Solver}\)): we began with a non-flow optimization problem over \(2^N\) binary configurations, compiled its objective into the capacity of an \(s\)-\(t\) cut, and handed the resulting graph to Dinic’s algorithm.

In this chapter, we confront the two fundamental scaling walls where Direction A breaks down:

  1. The Single-Pair Scale Wall (\(N \ge 10^4 \text{ to } 5 \cdot 10^5\), or \(Q \ge 10^5\) Dynamic Updates): Suppose a problem explicitly asks for the maximum flow from \(s\) to \(t\), or compiles into an \(s\)-\(t\) cut network, on \(N = 10^4\) vertices with \(\binom{N}{2} \approx 5 \cdot 10^7\) complete DAG edges (CF 724E), or on a pipeline of \(N = 5 \cdot 10^5\) vertices with \(Q = 5 \cdot 10^5\) online capacity updates (CF 1919F2), or on a bipartite chain with \(M, Q = 2 \cdot 10^5\) cross-edges and updates (CF 903G). No augmenting-path solver can touch these constraints.
  2. The All-Pairs Scale Wall (\(\binom{N}{2}\) Pairwise Minimum Cuts on \(N \le 850\) Vertices): Suppose we are given an undirected capacitated graph \(G = (V, E, w)\) with \(N = 850, M = 8500\) and must evaluate a function of the minimum cut \(\lambda_G(u, v) = \operatorname{MinCut}_G(u, v)\) across all \(\binom{N}{2} \approx 3.6 \cdot 10^5\) unordered pairs \(\{u, v\}\) (Luogu P4123, Luogu P3329, CF 343E), or find the global minimum cut over all \(2^{N-1} - 1\) non-trivial vertex partitions (POJ 2914). Running Dinic \(\binom{N}{2}\) times exceeds the time limit by three orders of magnitude.

What unifies the resolution of both walls is Cut-Space Compression—exploiting algebraic symmetry, bounded cut-interface width, or submodular uncrossing to collapse an exponential family of cuts into a compact polynomial representation:

2. Direction B Flow Elimination: Solving Max-Flow by Optimizing the Dual \(s\)-\(t\) Cut Directly (最大流转最小割 DP)

2.1 The Exact Algebraic \(s\)-\(t\) Cut Functional

Consider a directed flow network on vertex set \(\{s, t\} \cup \{1, 2, \dots, N\}\) with three families of non-negative capacities:

  • Source supply arcs: \(s \to i\) with capacity \(p_i \ge 0\) for each \(i \in \{1, \dots, N\}\).
  • Sink demand arcs: \(i \to t\) with capacity \(s_i \ge 0\) for each \(i \in \{1, \dots, N\}\).
  • Internal transit arcs: \(i \to j\) with capacity \(c_{i,j} \ge 0\) for ordered pairs \((i, j)\).

By the Max-Flow Min-Cut Theorem, the maximum flow from \(s\) to \(t\) equals the minimum capacity of an \(s\)-\(t\) cut. Any \(s\)-\(t\) cut is uniquely determined by the subset of internal vertices \(S \subseteq \{1, 2, \dots, N\}\) placed on the source side (with \(s \in S_{\text{full}} = \{s\} \cup S\)), while the remaining vertices \(\bar{S} = \{1, \dots, N\} \setminus S\) are placed on the sink side (with \(t \in T_{\text{full}} = \{t\} \cup \bar{S}\)).

Let us count the exact capacity \(C(S)\) of the directed arcs severed by the partition \((S, \bar{S})\):

  1. Severed source arcs (\(s \to i\)): Since \(s\) is on the source side, arc \(s \to i\) crosses from source side to sink side if and only if \(i \notin S\) (\(i \in \bar{S}\)), contributing \(\sum_{i \notin S} p_i\).
  2. Severed sink arcs (\(i \to t\)): Since \(t\) is on the sink side, arc \(i \to t\) crosses from source side to sink side if and only if \(i \in S\), contributing \(\sum_{i \in S} s_i\).
  3. Severed internal transit arcs (\(i \to j\)): A directed arc \(i \to j\) crosses from source side to sink side if and only if its tail lies in \(S\) (\(i \in S\)) and its head lies in \(\bar{S}\) (\(j \notin S\)), contributing \(\sum_{i \in S, j \notin S} c_{i,j}\).

Summing these three disjoint edge sets yields the Master Direction B Cut Equation:

\[ \operatorname{MaxFlow}(s, t) = \min_{S \subseteq \{1, \dots, N\}} C(S), \qquad C(S) = \sum_{i \notin S} p_i + \sum_{i \in S} s_i + \sum_{i \in S,\; j \notin S} c_{i,j}. \]

When the internal transit arcs form a directed acyclic graph (DAG) respecting the natural vertex order \(1 < 2 < \dots < N\) (so \(c_{i,j} > 0\) only when \(i < j\)), the cross-term restricts to ordered pairs \(i < j\):

\[ C(S) = \sum_{i \notin S} p_i + \sum_{i \in S} s_i + \sum_{\substack{i \in S,\; j \notin S \\ 1 \le i < j \le N}} c_{i,j}. \]

Equivalently, introducing binary state variables \(x_i \in \{0, 1\}\) where \(x_i = 1 \iff i \in S\) (source side) and \(x_i = 0 \iff i \notin S\) (sink side), we seek to minimize the pseudo-Boolean polynomial:

\[ C(\mathbf{x}) = \sum_{i=1}^N p_i (1 - x_i) + \sum_{i=1}^N s_i x_i + \sum_{1 \le i < j \le N} c_{i,j}\, x_i (1 - x_j). \]

Whenever the interaction matrix \((c_{i,j})\) has low rank, uniform structure, bounded bandwidth (path/tree), or monotone prefix thresholds, we can minimize \(C(\mathbf{x})\) over \(\{0, 1\}^N\) combinatorially—eliminating the flow solver entirely.

2.2 Uniform Prefix DAGs: From \(O(N^2)\) Cardinality DP to \(O(N \log N)\) Slope-Difference Greedy (CF 724E — Goods Transportation)

Suppose every earlier vertex \(i\) can ship goods to every later vertex \(j > i\) with the same uniform arc capacity \(c_{i,j} = c > 0\) for all \(1 \le i < j \le N\) (Codeforces 724E — Goods Transportation, where \(N \le 10^4\)).

Substituting \(c_{i,j} = c\) into the Master Direction B Cut Equation collapses the quadratic cross-term into a pure inversion-like pair count:

\[ C(S) = \sum_{i \notin S} p_i + \sum_{i \in S} s_i + c \cdot \big|\{(i, j) : 1 \le i < j \le N,\; i \in S,\; j \notin S\}\big|. \]

Level 1 Compilation: \(O(N^2)\) Cardinality-Interface Dynamic Programming

Scan the vertices sequentially from \(i = 1\) to \(N\). When we decide whether to place vertex \(i\) into \(S\) (\(x_i = 1\)) or \(\bar{S}\) (\(x_i = 0\)), how much information about the prefix choices \((x_1, \dots, x_{i-1})\) do we need to charge all newly severed edges incident to \(i\)?

  • If we place \(i \in S\) (\(x_i = 1\)): we sever the sink arc \(i \to t\) of capacity \(s_i\). Do any arcs \(j \to i\) from earlier vertices \(j < i\) cross the cut? No: if \(j \in S\), both endpoints are in \(S\); if \(j \notin S\), the arc \(j \to i\) points from \(\bar{S}\) to \(S\) (backward across the cut!), which costs zero in a directed \(s\)-\(t\) cut.
  • If we place \(i \notin S\) (\(x_i = 0\)): we sever the source arc \(s \to i\) of capacity \(p_i\), and for every earlier vertex \(j < i\) that was placed in \(S\), the forward arc \(j \to i\) crosses from \(S\) to \(\bar{S}\) and is severed at cost \(c\)!

Notice the crucial structural invariant: the cost of placing \(i \notin S\) does not depend on which prefix vertices are in \(S\), but only on their cardinality \(k = \big|S \cap \{1, \dots, i-1\}\big|\)!

Define \(dp[i][k]\) as the minimum cut cost contributed by the prefix \(\{1, \dots, i\}\) (counting all source/sink arcs in \(\{1, \dots, i\}\) and all transit arcs \(u \to v\) with \(1 \le u < v \le i\)) given that \(\big|S \cap \{1, \dots, i\}\big| = k\). For each \(i = 1, \dots, N\) and \(0 \le k \le i\):

\[ dp[i][k] = \min\Big(\underbrace{dp[i-1][k] + p_i + k \cdot c}_{\text{place } i \notin S \text{ (sink side)}},\;\; \underbrace{dp[i-1][k-1] + s_i}_{\text{place } i \in S \text{ (source side)}}\Big), \]

with base case \(dp[0][0] = 0\) and invalid states set to \(+\infty\). After \(N\) steps, \(\operatorname{MaxFlow}(s, t) = \min_{0 \le k \le N} dp[N][k]\) in \(O(N^2)\) time and \(O(N)\) rolling-array space.

Level 2 Compilation: Exact Algebraic Decoupling & \(O(N \log N)\) Slope-Difference Greedy

Can we compress the \(O(N^2)\) DP all the way to \(O(N \log N)\)? Yes—by counting the cross-pairs \(\{(i, j) : i < j, i \in S, j \notin S\}\) globally!

Fix the total cardinality \(k = |S|\). Every vertex \(i \in S\) has exactly \(N - i\) vertices \(j > i\) after it in total. Every such \(j > i\) lies either in \(\bar{S}\) (a cross-pair \(i \in S, j \notin S\)) or in \(S\) (an internal pair \(i \in S, j \in S\) with \(i < j\)). Summing over all \(i \in S\):

\[ \sum_{i \in S} (N - i) = \big|\{(i, j) : i < j,\; i \in S,\; j \notin S\}\big| + \big|\{(i, j) : i < j,\; i \in S,\; j \in S\}\big|. \]

Look at the second term on the right-hand side: how many ordered pairs \((i, j)\) with \(i < j\) have both endpoints in \(S\)? Since \(|S| = k\), any two distinct elements of \(S\) form exactly one pair with \(i < j\), so that count is always \(\binom{k}{2} = \frac{k(k-1)}{2}\), completely independent of which \(k\) indices form \(S\)!

Rearranging gives the exact Prefix-DAG Cross-Cut Identity:

\[ \big|\{(i, j) : 1 \le i < j \le N,\; i \in S,\; j \notin S\}\big| = \sum_{i \in S} (N - i) - \binom{|S|}{2}. \]

Substitute this identity into \(C(S)\) and rewrite \(\sum_{i \notin S} p_i = \sum_{i=1}^N p_i - \sum_{i \in S} p_i\):

\[ \begin{aligned} C(S) &= \sum_{i=1}^N p_i + \sum_{i \in S} (s_i - p_i) + c \left(\sum_{i \in S} (N - i) - \binom{|S|}{2}\right) \\ &= \sum_{i=1}^N p_i - \binom{|S|}{2} c + \sum_{i \in S} \underbrace{\big(s_i - p_i + (N - i)c\big)}_{w_i}. \end{aligned} \]

This equation is a minor miracle: once the cardinality \(k = |S|\) is fixed, the interactions between vertices in \(S\) vanish into the constant \(-\binom{k}{2}c\), and each vertex \(i \in S\) contributes an independent scalar weight \(w_i = s_i - p_i + (N - i)c\)! Therefore, for any fixed \(k \in \{0, 1, \dots, N\}\), the optimal subset \(S\) of size \(k\) simply selects the \(k\) vertices with the smallest values of \(w_i\). Sorting \(w_{(1)} \le w_{(2)} \le \dots \le w_{(N)}\) reduces the \(5 \cdot 10^7\)-edge max-flow problem to a single prefix-sum sweep in \(O(N \log N)\) time:

\[ \operatorname{MaxFlow}(s, t) = \min_{0 \le k \le N} \left[ \sum_{i=1}^N p_i - \frac{k(k-1)}{2}c + \sum_{r=1}^k w_{(r)} \right]. \]

WarningBroken-Gadget Counterexample FM-16a: Undirected / Bidirectional Overcounting on a Directed Prefix DAG

A classic implementation bug when writing dp[i][k] or the algebraic sum for CF 724E is treating the transit arcs as undirected or charging \(c\) whenever \(i \in S\) and \(j \notin S\) for both \(i < j\) and \(i > j\):

  • The Buggy Recurrence: When placing \(i \in S\) (\(x_i = 1\)), a solver notices that \(i - 1 - (k - 1) = i - k\) earlier vertices in \(\{1, \dots, i-1\}\) were placed on the sink side \(\bar{S}\), and writes: \[dp_{\text{bug}}[i][k] = \min\big(dp_{\text{bug}}[i-1][k] + p_i + k \cdot c,\;\; dp_{\text{bug}}[i-1][k-1] + s_i + (i - 1 - (k - 1)) \cdot c\big).\]
  • Concrete Counterexample (\(N = 2, c = 10\)): Let \(p = [0, 100]\), \(s = [100, 0]\).
    • In the true directed graph, the only internal arc is \(1 \xrightarrow{10} 2\). If we set \(1 \notin S\) (\(1 \in \bar{S}\)) and \(2 \in S\), the severed arcs are \(s \to 1\) (\(p_1 = 0\)) and \(2 \to t\) (\(s_2 = 0\)), while the arc \(1 \to 2\) goes from \(\bar{S}\) to \(S\) (backward across the cut, paying \(0\)!). Thus the true minimum cut (and max-flow) is \(0\) (indeed, \(s \to 1\) has capacity \(0\) and \(2 \to t\) has capacity \(0\), so no positive flow can ever leave \(s\) or enter \(t\)!).
    • Under the buggy recurrence that charges \((i - k)c\) when \(2 \in S\) and \(1 \notin S\), the state \(S = \{2\}\) falsely pays \(c = 10\) for the non-existent reverse arc \(2 \to 1\), reporting a phantom flow of \(10\) on a network with zero capacity out of \(s\)!
  • Invariant to Enforce: In any directed \(s\)-\(t\) cut, an arc \(u \to v\) is severed if and only if \(u \in S\) and \(v \notin S\). Never charge arcs pointing from \(\bar{S}\) to \(S\).

2.3 Dynamic Pipeline Networks & \(2 \times 2\) \((\min, +)\) Tropical Matrix Segment Trees (CF 1919F1/F2 — Wine Factory)

Now suppose the internal transit network is a directed linear pipeline \(1 \xrightarrow{c_1} 2 \xrightarrow{c_2} \dots \xrightarrow{c_{N-1}} N\), where each node \(i\) has source supply \(s \xrightarrow{a_i} i\) and sink demand \(i \xrightarrow{b_i} t\), and we must process \(Q \le 5 \cdot 10^5\) online point updates to \((a_i, b_i, c_i)\) (Codeforces 1919F2 — Wine Factory (Hard Version)).

Let us apply the Master Direction B Cut Equation to this 1D chain. Assign each vertex \(i \in \{1, \dots, N\}\) a binary cut label \(x_i \in \{0, 1\}\), where we adopt the state convention:

  • State \(0\) (\(i \in \bar{S}\), sink side): Severs source arc \(s \to i\), paying \(a_i\).
  • State \(1\) (\(i \in S\), source side): Severs sink arc \(i \to t\), paying \(b_i\).
  • Pipe Transition (\(i \to i+1\) of capacity \(c_i\)): Because the pipe is directed from \(i\) to \(i+1\), it is severed if and only if \(x_i = 1\) (\(i \in S\)) and \(x_{i+1} = 0\) (\(i+1 \in \bar{S}\)), paying \(c_i\). All three other state transitions \((0 \to 0)\), \((0 \to 1)\), and \((1 \to 1)\) pay \(0\)!

Thus, the exact minimum cut of the pipeline is the minimum-cost path through a 2-state Markov chain of length \(N\):

\[ \operatorname{MaxFlow}(s, t) = \min_{\mathbf{x} \in \{0, 1\}^N} \left[ \sum_{i=1}^N \big(a_i [x_i = 0] + b_i [x_i = 1]\big) + \sum_{i=1}^{N-1} c_i [x_i = 1 \land x_{i+1} = 0] \right]. \]

Special Case (CF 1919F1): Infinite Pipe Capacities (\(c_i = \infty\))

When \(c_i = \infty\) for all \(1 \le i < N\), the transition \((x_i = 1 \to x_{i+1} = 0)\) is forbidden. Consequently, once the sequence \(\mathbf{x}\) enters state \(1\) (\(S\)), it can never return to state \(0\) (\(\bar{S}\)). Every finite-cost cut must consist of a prefix \(1 \dots k\) in state \(0\) (\(\bar{S}\)) followed by a suffix \(k+1 \dots N\) in state \(1\) (\(S\)) for some split index \(k \in \{0, 1, \dots, N\}\):

\[ \operatorname{MaxFlow}_{c=\infty}(s, t) = \min_{0 \le k \le N} \left( \sum_{i=1}^k a_i + \sum_{i=k+1}^N b_i \right) = \sum_{i=1}^N b_i + \min_{0 \le k \le N} \sum_{i=1}^k (a_i - b_i). \]

Maintaining prefix sums of \((a_i - b_i)\) in a Segment Tree resolves CF 1919F1 in \(O((N + Q) \log N)\) time.

General Case (CF 1919F2): Finite Pipe Capacities (\(c_i < \infty\)) via \((\min, +)\) Matrices

When \(c_i\) is finite, the optimal cut can alternate between \(0\) (\(\bar{S}\)) and \(1\) (\(S\)) arbitrarily many times. Define the tropical \((\min, +)\) matrix product \(A \otimes B\) of two \(2 \times 2\) matrices by:

\[ (A \otimes B)_{u, v} = \min_{w \in \{0, 1\}} \big(A_{u, w} + B_{w, v}\big), \qquad u, v \in \{0, 1\}. \]

There are two equally clean ways to represent intervals in a Segment Tree:

  1. Interval Endpoint-State Matrix \(D_{[L, R]}\) (Recommended for Implementation): For any contiguous subsegment \([L, R]\), let \(D_{[L, R]}(u, v)\) (\(u, v \in \{0, 1\}\)) be the minimum cut cost of all vertices and internal pipes strictly inside \([L, R]\) given that the left boundary vertex has state \(x_L = u\) and the right boundary vertex has state \(x_R = v\).
    • Single-vertex leaf \([i, i]\): Since \(x_i\) cannot simultaneously be \(0\) and \(1\), the off-diagonal entries are \(+\infty\): \[D_{[i, i]} = \begin{pmatrix} a_i & +\infty \\ +\infty & b_i \end{pmatrix}.\]
    • Merging \([L, M]\) and \([M+1, R]\) across pipe \(M \xrightarrow{c_M} M+1\): When \(x_M = x \in \{0, 1\}\) and \(x_{M+1} = y \in \{0, 1\}\), the connecting pipe \(M \to M+1\) adds \(c_M\) if and only if \((x, y) = (1, 0)\): \[D_{[L, R]}(u, v) = \min_{x \in \{0, 1\}} \min_{y \in \{0, 1\}} \Big( D_{[L, M]}(u, x) + D_{[M+1, R]}(y, v) + c_M \cdot [x = 1 \land y = 0] \Big).\]
  2. Vertex-Plus-Outgoing-Pipe Transfer Matrix \(M_i\): Alternatively, absorb the outgoing pipe \(c_i\) (with \(c_N = 0\)) directly into vertex \(i\)’s transition matrix \(M_i(x_i, x_{i+1})\): \[M_i = \begin{pmatrix} a_i & a_i \\ b_i + c_i & b_i \end{pmatrix}, \qquad \operatorname{MaxFlow}(s, t) = \min_{u, v \in \{0, 1\}} \big(M_1 \otimes M_2 \otimes \dots \otimes M_N\big)_{u, v}.\]

Both formulations perform at most \(8\) to \(16\) additions and comparisons per Segment Tree node, solving dynamic max-flow on \(5 \cdot 10^5\) vertices in \(O((N + Q) \log N)\) time!

2.4 Coupled Forward Chains & Complete Bipartite Thresholds (CF 903G, ARC 125E, & Tree HLD-DDP)

The Direction B philosophy extends immediately to three further structural topologies that appear regularly in ICPC and OI competition:

  1. Coupled Forward Chains (CF 903G — Yet Another MaxFlow Problem, #128): Suppose \(s = A_1 \xrightarrow{x_1} A_2 \xrightarrow{x_2} \dots \xrightarrow{x_{N-1}} A_N\) is a source chain, \(B_1 \xrightarrow{y_1} B_2 \xrightarrow{y_2} \dots \xrightarrow{y_{N-1}} B_N = t\) is a sink chain, and \(M \le 2 \cdot 10^5\) directed cross-edges \(A_u \xrightarrow{z_{uv}} B_v\) connect the two chains.
    • Why the Cut Space Collapses from \(2^{2N}\) to \(N^2\): Suppose a cut severs \(A_i \to A_{i+1}\) (so \(A_i \in S, A_{i+1} \in \bar{S}\)). If any later vertex \(A_k\) (\(k > i\)) were placed back in \(S\), it would only increase the number of severed cross-edges \(A_k \to B_v\) and chain edges without helping \(s = A_1\)! Formally, because all edges on \(A\) point forward from \(s = A_1\), replacing \(S_A\) by the contiguous prefix \(\{A_1, \dots, A_i\}\) (where \(i\) is the first index with \(A_{i+1} \notin S_A\)) never increases the cut capacity. By symmetry, \(T_B\) can always be chosen as a contiguous suffix \(\{B_{j+1}, \dots, B_N\}\).
    • Thus every minimal cut is indexed by a pair \((i, j) \in \{1, \dots, N\} \times \{0, \dots, N-1\}\) with cost: \[\operatorname{Cut}(i, j) = x_i + y_j + \sum_{u \le i,\; v > j} z_{uv} \qquad (x_N = y_0 = 0),\] which is precomputed for all \(i\) in \(O((N + M) \log N)\) via a sweep-line over \(i\) and a Lazy Range-Add Range-Min Segment Tree over \(j\)!
  2. Complete Bipartite Degree-Sorted Cuts (AtCoder ARC 125E — Snack): Suppose \(s \to i\) has capacity \(A_i\) (\(1 \le i \le N\)), \(j \to t\) has capacity \(C_j\) (\(1 \le j \le M\)), and every pair \((i, j) \in \{1, \dots, N\} \times \{1, \dots, M\}\) has directed arc \(i \to j\) of capacity \(B_j\) (\(N, M \le 2 \cdot 10^5\)).
    • If we fix the cardinality \(k = |S_{\text{left}}| \in \{0, \dots, N\}\), each right vertex \(j\) either joins \(S\) (paying \(C_j\) on \(j \to t\)) or joins \(\bar{S}\) (paying \(k \cdot B_j\) on the \(k\) arcs from \(S_{\text{left}}\) to \(j\)), so right vertex \(j\) independently pays \(\min(C_j, k B_j)\)! Meanwhile, to minimize \(\sum_{i \notin S_{\text{left}}} A_i\), \(S_{\text{left}}\) must consist of the \(k\) left vertices with the largest \(A_i\): \[\operatorname{MaxFlow}(s, t) = \min_{0 \le k \le N} \left[ \sum_{r=k+1}^N A_{(r)} + \sum_{j=1}^M \min\big(C_j,\; k \cdot B_j\big) \right] \qquad (A_{(1)} \ge \dots \ge A_{(N)}).\]
  3. Tree Networks via Dynamic DP (Tree Max-Flow, Checkpoint CP-IV #217): On an arbitrary tree \(T = (V, E)\) with source capacities \(a_u\), sink capacities \(b_u\), and undirected tree edge capacities \(c_{uv}\), the minimum cut is solved in \(O(N)\) time by a 2-state bottom-up Tree DP (dp[u][0] for \(u \in \bar{S}\), dp[u][1] for \(u \in S\)): \[dp[u][0] = a_u + \sum_{v \in \text{ch}(u)} \min\big(dp[v][0],\; dp[v][1] + c_{uv}\big), \qquad dp[u][1] = b_u + \sum_{v \in \text{ch}(u)} \min\big(dp[v][1],\; dp[v][0] + c_{uv}\big).\] Under online updates to \((a_u, b_u)\), Heavy-Light Decomposition (HLD) compiles each heavy chain into the exact same \(2 \times 2\) \((\min, +)\) matrix Segment Tree as CF 1919F2, answering dynamic tree max-flow queries in \(O(Q \log^2 N)\) time!

3. Global Undirected Minimum Cut: Stoer–Wagner & Maximum Adjacency Search (MAS)

3.1 The Global Minimum Cut Problem & The Dichotomy of a Vertex Pair

Let \(G = (V, E, w)\) be an undirected graph with \(N = |V|\) vertices, \(M = |E|\) edges, and non-negative edge weights \(w_{uv} = w_{vu} \ge 0\). For any subset \(S \subseteq V\), write \(\delta(S) = \{\{u, v\} \in E : u \in S, v \notin S\}\) for the boundary cut edges and \(c(\delta(S)) = \sum_{u \in S, v \notin S} w_{uv}\) for the cut capacity. For any two disjoint subsets \(X, Y \subseteq V\), write \(w(X, Y) = \sum_{x \in X, y \in Y} w_{xy}\).

The Global Minimum Cut Problem asks for a non-empty proper subset \(\emptyset \subsetneq S \subsetneq V\) minimizing \(c(\delta(S))\):

\[ \lambda(G) = \min_{\emptyset \subsetneq S \subsetneq V} c(\delta(S)) = \min_{\{u, v\} \subset V} \lambda_G(u, v), \]

where \(\lambda_G(u, v) = \min_{S \subseteq V : u \in S, v \notin S} c(\delta(S))\) denotes the pairwise minimum \(u\)-\(v\) cut.

Suppose we manage to pick any two distinct vertices \(s, t \in V\) for which we can easily compute their pairwise minimum cut \(\lambda_G(s, t)\). Then every global minimum cut \((S^*, V \setminus S^*)\) falls into one of two mutually exclusive cases:

  1. Case 1 (\(S^*\) separates \(s\) and \(t\)): Then \(\lambda(G) = c(\delta(S^*)) = \lambda_G(s, t)\), which we just computed!
  2. Case 2 (\(s\) and \(t\) lie on the same side of \(S^*\)): Then contracting \(s\) and \(t\) into a single supernode \(v_{st}\) (summing parallel edge weights \(w(v_{st}, u) = w(s, u) + w(t, u)\) for all \(u \notin \{s, t\}\) and deleting self-loops) preserves \(c(\delta(S^*))\) and every other cut that keeps \(s\) and \(t\) together: \[\lambda(G) = \min\Big(\lambda_G(s, t),\;\; \lambda\big(G / \{s, t\}\big)\Big).\]

Repeating this contraction \(N - 1\) times reduces \(G\) to a single vertex and guarantees finding \(\lambda(G)\)—provided we have a fast way to find some pair \((s, t)\) and its exact minimum cut \(\lambda_G(s, t)\) in each phase without running a max-flow algorithm!

3.2 Maximum Adjacency Search (MAS) & The Stoer–Wagner Theorem

In 1997, Mechthild Stoer and Frank Wagner proved a remarkable structural theorem (simplifying an earlier 1992 result of Nagamochi and Ibaraki): if we order the vertices of \(G\) by greedily pulling in the vertex most tightly connected to the already-visited prefix—an ordering called Maximum Adjacency Search (MAS)—then the last two vertices \(s = v_{N-1}\) and \(t = v_N\) of the ordering automatically satisfy \(\lambda_G(s, t) = c(\delta(\{t\})) = w(V \setminus \{t\}, t)\)!

Definition (Maximum Adjacency Ordering)

Fix an arbitrary starting vertex \(v_1 \in V\), and set \(A_1 = \{v_1\}\). For \(i = 2, 3, \dots, N\), define \(A_{i-1} = \{v_1, \dots, v_{i-1}\}\) and choose the next vertex \(v_i \in V \setminus A_{i-1}\) to maximize the total edge weight to \(A_{i-1}\):

\[ v_i \in \arg\max_{u \in V \setminus A_{i-1}} w(A_{i-1}, u). \]

Notice that MAS is structurally identical to Prim’s Minimum Spanning Tree algorithm, except that the priority key of each unvisited vertex \(u \notin A_{i-1}\) is the sum \(w(A_{i-1}, u) = \sum_{x \in A_{i-1}} w_{xu}\) rather than \(\min_{x \in A_{i-1}} w_{xu}\).

ImportantTheorem 16.1 (Stoer–Wagner Theorem, 1997)

Let \(v_1, v_2, \dots, v_N\) be any Maximum Adjacency Ordering of an undirected non-negatively weighted graph \(G = (V, E, w)\), and let \(s = v_{N-1}\) and \(t = v_N\) be the last two vertices of the ordering. Then the singleton cut \((A_{N-1}, \{t\}) = (V \setminus \{t\}, \{t\})\) is an exact minimum \(s\)-\(t\) cut in \(G\):

\[ \lambda_G(s, t) = \min_{\substack{S \subseteq V \\ s \in S,\; t \notin S}} c(\delta(S)) = w(A_{N-1}, t). \]

Complete Self-Contained Proof via Active-Vertex Cut Induction

Since \(s = v_{N-1} \in A_{N-1}\) and \(t = v_N \notin A_{N-1}\), the cut \((A_{N-1}, \{t\})\) is a valid \(s\)-\(t\) cut of capacity \(w(A_{N-1}, t)\), which immediately gives the upper bound \(\lambda_G(s, t) \le w(A_{N-1}, t)\).

To prove the reverse inequality \(\lambda_G(s, t) \ge w(A_{N-1}, t)\), fix any \(s\)-\(t\) cut \((C, \bar{C})\) with \(s = v_{N-1} \in C\) and \(t = v_N \in \bar{C}\). We must prove that \(c(\delta(C)) \ge w(A_{N-1}, v_N)\).

Call a vertex \(v_i\) (\(i \ge 2\)) active with respect to the cut \((C, \bar{C})\) if \(v_i\) and its immediate predecessor \(v_{i-1}\) in the MAS ordering lie on opposite sides of the cut \((C, \bar{C})\). Notice that since \(v_{N-1} \in C\) and \(v_N \in \bar{C}\), the last vertex \(v_N = t\) is always active!

For each vertex \(v_i\), let \(C_{v_i}\) denote the cut induced by \((C, \bar{C})\) on the prefix subgraph \(A_i = \{v_1, \dots, v_i\}\), so its capacity inside \(A_i\) is:

\[ c(C_{v_i}) = w\big(A_i \cap C,\; A_i \cap \bar{C}\big). \]

Claim: For every active vertex \(v_i\), the prefix cut capacity satisfies:

\[ w(A_{i-1}, v_i) \le c(C_{v_i}). \]

Proof of Claim by Induction on the Active Vertices:

  1. Base Case (First active vertex \(v_i\)): Since \(v_i\) is the first active vertex, all predecessors \(v_1, \dots, v_{i-1}\) lie on the same side of \((C, \bar{C})\), while \(v_i\) lies on the opposite side! Therefore, inside \(A_i = A_{i-1} \cup \{v_i\}\), the cut \(C_{v_i}\) separates \(A_{i-1}\) from \(\{v_i\}\), which means every edge between \(A_{i-1}\) and \(v_i\) crosses \(C_{v_i}\): \[c(C_{v_i}) = w(A_{i-1}, v_i).\]
  2. Inductive Step: Suppose the Claim holds for an active vertex \(v_i\), and let \(v_j\) (\(j > i\)) be the next active vertex after \(v_i\).
    • Because no vertex in \(\{v_{i+1}, \dots, v_{j-1}\}\) is active, all vertices in \(\{v_i, v_{i+1}, \dots, v_{j-1}\}\) lie on the same side of \((C, \bar{C})\) as \(v_i\), while \(v_j\) lies on the opposite side!
    • Consider the prefix \(A_{j-1} = A_{i-1} \cup \{v_i\} \cup (A_{j-1} \setminus A_i)\). We can decompose \(w(A_{j-1}, v_j)\) into two parts: \[w(A_{j-1}, v_j) = w(A_{i-1}, v_j) + w(A_{j-1} \setminus A_{i-1}, v_j).\]
    • First, at step \(i\) of MAS, both \(v_i\) and \(v_j\) were unvisited candidates outside \(A_{i-1}\), and MAS greedily selected \(v_i\) over \(v_j\)! Therefore: \[w(A_{i-1}, v_j) \le w(A_{i-1}, v_i) \le c(C_{v_i}) \qquad (\text{by the greedy choice of } v_i \text{ and IH}).\]
    • Second, every vertex in \(A_{j-1} \setminus A_{i-1} = \{v_i, \dots, v_{j-1}\}\) lies on the opposite side of \((C, \bar{C})\) from \(v_j\)! Thus all edges between \(A_{j-1} \setminus A_{i-1}\) and \(v_j\) are newly added cross-edges of the cut \(C_{v_j}\) that were not present in \(C_{v_i}\) (since \(j > i\)). Because edge weights are non-negative, the cut capacity inside \(A_j\) satisfies: \[c(C_{v_j}) \ge c(C_{v_i}) + w(A_{j-1} \setminus A_{i-1}, v_j).\]
    • Combining these two inequalities yields the inductive step: \[w(A_{j-1}, v_j) = w(A_{i-1}, v_j) + w(A_{j-1} \setminus A_{i-1}, v_j) \le c(C_{v_i}) + w(A_{j-1} \setminus A_{i-1}, v_j) \le c(C_{v_j}).\]

Applying the Claim to the final vertex \(v_N = t\) (which is always active and has \(A_N = V\), so \(c(C_{v_N}) = c(\delta(C))\)) gives:

\[ w(A_{N-1}, v_N) \le c(C_{v_N}) = c(\delta(C)). \]

Since \((C, \bar{C})\) was an arbitrary \(s\)-\(t\) cut, \(\lambda_G(s, t) = w(A_{N-1}, v_N)\). \(\blacksquare\)

3.3 Algorithmic Contract, Complexity & Hand-Checkable Trace

Algorithmic Contract (Stoer–Wagner Global Minimum Cut)

  • Input: Undirected graph \(G = (V, E, w)\) with \(N = |V| \ge 2\) and non-negative weights \(w_e \ge 0\) (parallel edges summed into \(w_{uv}\)).
  • Execution:
    1. Initialize \(\text{best\_cut} \gets +\infty\) and mark all \(N\) vertices as alive.
    2. For phase \(r = 1, 2, \dots, N - 1\) (while \(k = N - r + 1 \ge 2\) vertices remain alive):
      • Run MAS on the \(k\) alive vertices to produce \(v_1, \dots, v_{k-1}, v_k\).
      • Set \(s \gets v_{k-1}\) and \(t \gets v_k\). Update \(\text{best\_cut} \gets \min\big(\text{best\_cut},\; w(A_{k-1}, t)\big)\).
      • Contract \(t\) into \(s\): mark alive[t] = false, and for every alive vertex \(u \neq s\), set \(w_{su} \gets w_{su} + w_{tu}\) and \(w_{us} \gets w_{us} + w_{ut}\).
    3. Return \(\text{best\_cut}\).
  • Complexity:
    • Dense \(O(V^3)\) Array Implementation: Each of the \(V - 1\) phases runs \(O(V)\) iterations of scanning all alive vertices in \(O(V)\) time, taking \(O(V^3)\) time and \(O(V^2)\) space with an extraordinarily tiny constant factor (\(\approx \frac{1}{6} V^3\) additions, running in \(< 40\text{ ms}\) for \(V = 500\)).
    • Sparse \(O(VE + V^2 \log V)\) Heap Implementation: Using a Fibonacci heap (or \(O((V + E) \log V)\) per phase with a binary heap), the total time across \(V - 1\) phases is \(O(VE + V^2 \log V)\).

Hand-Checkable Toy Trace (\(N = 4\) Weighted Diamond)

Consider \(V = \{1, 2, 3, 4\}\) with edges \((1, 2) = 2\), \((1, 3) = 5\), \((2, 3) = 4\), \((2, 4) = 3\), \((3, 4) = 1\).

  • Phase 1 (\(4\) alive vertices \(\{1, 2, 3, 4\}\)):
    • Start at \(v_1 = 1\): keys to \(A_1 = \{1\}\) are \(w(1, 2) = 2, w(1, 3) = 5, w(1, 4) = 0\). Pick \(v_2 = 3\).
    • Now \(A_2 = \{1, 3\}\): keys are \(w(\{1, 3\}, 2) = 2 + 4 = 6\) and \(w(\{1, 3\}, 4) = 0 + 1 = 1\). Pick \(v_3 = 2\).
    • Last vertex is \(v_4 = 4\) with key \(w(\{1, 3, 2\}, 4) = 1 + 3 = 4\).
    • Phase 1 records \(\lambda(2, 4) = 4\) (cut \((\{1, 2, 3\}, \{4\})\)), and contracts \(t = 4\) into \(s = 2\): new edge weights are \((1, 2) = 2, (1, 3) = 5, (2, 3) = 4 + 1 = 5\).
  • Phase 2 (\(3\) alive vertices \(\{1, 2, 3\}\)):
    • Start at \(v_1 = 1\): keys are \(w(1, 2) = 2, w(1, 3) = 5\). Pick \(v_2 = 3\).
    • Last vertex is \(v_3 = 2\) with key \(w(\{1, 3\}, 2) = 2 + 5 = 7\).
    • Phase 2 records \(\lambda(3, 2) = 7\) (cut \((\{1, 3\}, \{2, 4\})\)), and contracts \(2\) into \(3\): new edge weight \((1, 3) = 5 + 2 = 7\).
  • Phase 3 (\(2\) alive vertices \(\{1, 3\}\)):
    • Start at \(v_1 = 1\), last vertex \(v_2 = 3\) with key \(w(1, 3) = 7\) (cut \((\{1\}, \{2, 3, 4\})\)).
  • Global Minimum Cut: \(\min(4, 7, 7) = \mathbf{4}\), achieved by separating \(\{4\}\) from \(\{1, 2, 3\}\).
NoteTheoretical Horizon: Karger’s \(\binom{N}{2}\) Bound & The DKL Cactus of All Global Minimum Cuts

How many distinct global minimum cuts of weight \(\lambda^* = \lambda(G)\) can an undirected connected graph \(G\) possess?

  1. Karger’s \(\binom{N}{2}\) Theorem (1993): In any undirected graph with global minimum cut \(\lambda^*\), every vertex \(v\) has weighted degree \(\deg_w(v) \ge \lambda^*\), so total edge weight is \(W \ge \frac{N \lambda^*}{2}\). If we pick a random edge with probability proportional to \(w_e\) and contract it, any fixed global minimum cut \(C^*\) is hit with probability \(\le \frac{\lambda^*}{N \lambda^* / 2} = \frac{2}{N}\), surviving the first contraction with probability \(\ge \frac{N-2}{N}\). Telescoping across \(N - 2\) contractions down to \(2\) supernodes shows that \(C^*\) survives with probability \(\ge \prod_{n=3}^N \frac{n-2}{n} = \frac{2}{N(N-1)} = \binom{N}{2}^{-1}\). Because survival to the final 2-supernode multigraph is mutually exclusive for distinct cuts, \(G\) has at most \(\binom{N}{2}\) global minimum cuts (tight on the cycle \(C_N\))!
  2. Dinits–Karzanov–Lomonosov (1976) Cactus \(\mathcal{K}(G)\) (最小割仙人掌): While a single tree cannot represent crossing global minimum cuts (such as cutting opposite pairs of edges on \(C_4\)), any two crossing global minimum cuts \((A, \bar{A})\) and \((B, \bar{B})\) must have empty diagonal edge sets \(w(A \cap B, \bar{A} \cap \bar{B}) = w(A \setminus B, B \setminus A) = 0\) and cycle-link weights \(\frac{\lambda^*}{2}\). Consequently, all global minimum cuts of \(G\) are represented by a canonical cactus graph \(\mathcal{K}(G)\) (where every edge lies in at most one simple cycle, bridges have weight \(\lambda^*\), and cycle edges have weight \(\frac{\lambda^*}{2}\)).

4. All-Pairs Minimum Cuts & Gusfield’s Gomory–Hu Cut Tree (最小割树)

What if we need not just the single global minimum cut \(\lambda(G)\), but the pairwise minimum cut \(\lambda_G(u, v) = \operatorname{MinCut}_G(u, v)\) for all \(\binom{N}{2}\) unordered pairs \(\{u, v\} \subset V\)?

In 1961, Ralph Gomory and T. C. Hu proved one of the crown jewels of combinatorial optimization: in any undirected capacitated graph \(G = (V, E, w)\), the \(\binom{N}{2}\) pairwise minimum cuts are completely encoded by a single weighted tree \(T_{\text{GH}}\) on the exact vertex set \(V\) (requiring zero extra Steiner vertices), constructible using only \(N - 1\) maximum-flow calls! Furthermore, in 1990, Dan Gusfield showed that all \(N - 1\) max-flow calls can be executed directly on the original unmodified graph \(G\) in a 15-line loop with zero vertex contractions.

4.1 Submodularity, Posimodularity, and the Ultrametric Triangle Inequality

Let \(f(S) = c(\delta(S)) = w(S, V \setminus S)\) be the undirected cut capacity function on \(G = (V, E, w)\) with \(w_{uv} \ge 0\). Because \(G\) is undirected, \(f\) is symmetric: \(f(S) = f(V \setminus S)\) for all \(S \subseteq V\).

ImportantTheorem 16.2 (Symmetric Submodularity & Posimodularity of Undirected Cuts)

For any two subsets \(A, B \subseteq V\) in an undirected graph \(G = (V, E, w)\) with \(w \ge 0\):

  1. Submodularity: \[c(\delta(A)) + c(\delta(B)) \ge c(\delta(A \cap B)) + c(\delta(A \cup B)).\]
  2. Posimodularity: \[c(\delta(A)) + c(\delta(B)) \ge c(\delta(A \setminus B)) + c(\delta(B \setminus A)).\]

Proof via Four-Quadrant Partition

Partition \(V\) into the four disjoint Venn-diagram quadrants:

\[ Q_1 = A \cap B, \qquad Q_2 = A \setminus B, \qquad Q_3 = V \setminus (A \cup B), \qquad Q_4 = B \setminus A. \]

Expand both sides of the submodular inequality in terms of the six pairwise inter-quadrant edge sums \(w(Q_i, Q_j)\):

  • On the left-hand side, \(A = Q_1 \cup Q_2\) and \(B = Q_1 \cup Q_4\), so: \[\begin{aligned} c(\delta(A)) &= w(Q_1, Q_3) + w(Q_1, Q_4) + w(Q_2, Q_3) + w(Q_2, Q_4), \\ c(\delta(B)) &= w(Q_1, Q_2) + w(Q_1, Q_3) + w(Q_4, Q_2) + w(Q_4, Q_3). \end{aligned}\]
  • On the right-hand side, \(A \cap B = Q_1\) and \(A \cup B = V \setminus Q_3\), so: \[\begin{aligned} c(\delta(A \cap B)) &= w(Q_1, Q_2) + w(Q_1, Q_3) + w(Q_1, Q_4), \\ c(\delta(A \cup B)) &= w(Q_1, Q_3) + w(Q_2, Q_3) + w(Q_4, Q_3). \end{aligned}\]

Subtracting the right-hand side from the left-hand side cancels every term except the diagonal crossing between \(Q_2 = A \setminus B\) and \(Q_4 = B \setminus A\):

\[ c(\delta(A)) + c(\delta(B)) - c(\delta(A \cap B)) - c(\delta(A \cup B)) = 2\,w(A \setminus B,\; B \setminus A) \ge 0, \]

which proves submodularity! Applying submodularity to \(A\) and \(\bar{B} = V \setminus B\) and using symmetry \(c(\delta(\bar{B})) = c(\delta(B))\) and \(c(\delta(A \cup \bar{B})) = c(\delta(V \setminus (A \cup \bar{B}))) = c(\delta(B \setminus A))\) immediately yields posimodularity:

\[ c(\delta(A)) + c(\delta(B)) - c(\delta(A \setminus B)) - c(\delta(B \setminus A)) = 2\,w(A \cap B,\; \bar{A} \cap \bar{B}) \ge 0. \quad \blacksquare \]

Before proving Cut Uncrossing, observe a direct consequence of simple cut partitioning for any three vertices:

ImportantCorollary 16.3 (The Submodular Ultrametric Triangle Inequality)

For any three distinct vertices \(u, v, w \in V\) in an undirected graph \(G\):

\[ \lambda_G(u, w) \ge \min\big(\lambda_G(u, v),\;\; \lambda_G(v, w)\big). \]

Equivalently, among the three pairwise minimum cuts \(\{\lambda_G(u, v), \lambda_G(v, w), \lambda_G(u, w)\}\), the two smallest values must be equal (there cannot be a unique minimum among the three!). Consequently, across all \(\binom{N}{2}\) pairs, \(\lambda_G(u, v)\) can take at most \(N - 1\) distinct values.

Proof: Let \((S, \bar{S})\) be a minimum \(u\)-\(w\) cut with \(u \in S\), \(w \in \bar{S}\), and \(c(\delta(S)) = \lambda_G(u, w)\). Where does the third vertex \(v\) lie?

  • If \(v \in S\), then \((S, \bar{S})\) separates \(v \in S\) from \(w \in \bar{S}\), so it is a valid \(v\)-\(w\) cut: \(\lambda_G(u, w) = c(\delta(S)) \ge \lambda_G(v, w)\).
  • If \(v \in \bar{S}\), then \((S, \bar{S})\) separates \(u \in S\) from \(v \in \bar{S}\), so it is a valid \(u\)-\(v\) cut: \(\lambda_G(u, w) = c(\delta(S)) \ge \lambda_G(u, v)\).

In either case, \(\lambda_G(u, w) \ge \min(\lambda_G(u, v), \lambda_G(v, w))\). \(\blacksquare\)

4.2 The Submodular Cut Uncrossing Lemma

Why don’t we need to cross previous minimum cuts when finding new ones?

ImportantLemma 16.4 (The Cut Uncrossing Lemma — Gomory & Hu, 1961)

Let \((S, \bar{S})\) be any minimum \(s\)-\(t\) cut in an undirected graph \(G = (V, E, w)\) with \(s \in S\) and \(t \in \bar{S}\). For any two vertices \(u, v \in S\) that lie on the same side of \((S, \bar{S})\), there exists a minimum \(u\)-\(v\) cut \((A, \bar{A})\) in \(G\) that does not cross \((S, \bar{S})\)—specifically, assuming \(u \in A\) and \(v \in \bar{A}\), whichever side of \((A, \bar{A})\) does not contain \(t\) is a subset of \(S\) (\(A \subseteq S\) or \(\bar{A} \subseteq S\)).

Proof via Submodularity and Posimodularity

Let \((B, \bar{B})\) be any minimum \(u\)-\(v\) cut in \(G\), labeled so that \(u \in B\), \(v \in \bar{B}\), and \(c(\delta(B)) = \lambda_G(u, v)\). Since \(t \in \bar{S}\), the sink \(t\) lies either in \(\bar{B}\) or in \(B\):

  1. Case 1 (\(t \in \bar{B}\), on the same side of \(B\) as \(v\)): Apply submodularity (Theorem 16.2(1)) to \(S\) and \(B\): \[c(\delta(S)) + c(\delta(B)) \ge c(\delta(S \cap B)) + c(\delta(S \cup B)).\] Examine the two sets on the right-hand side:
    • Since \(s \in S \subseteq S \cup B\) and \(t \notin S, t \notin B \implies t \notin S \cup B\), the cut \((S \cup B, \overline{S \cup B})\) separates \(s\) from \(t\)! Because \((S, \bar{S})\) is a minimum \(s\)-\(t\) cut, we must have: \[c(\delta(S \cup B)) \ge \lambda_G(s, t) = c(\delta(S)).\]
    • Subtracting \(c(\delta(S \cup B)) \ge c(\delta(S))\) from the submodular inequality forces: \[c(\delta(S \cap B)) \le c(\delta(B)) = \lambda_G(u, v).\]
    • Furthermore, since \(u \in S\) and \(u \in B\), we have \(u \in S \cap B\); and since \(v \notin B\), we have \(v \notin S \cap B\). Thus \(A = S \cap B \subseteq S\) separates \(u\) from \(v\), has capacity \(c(\delta(A)) = \lambda_G(u, v)\), and is completely contained inside \(S\)!
  2. Case 2 (\(t \in B\), on the same side of \(B\) as \(u\)): Simply swap the roles of \(B\) and \(\bar{B}\) (applying submodularity to \(S\) and \(\bar{B}\), or equivalently posimodularity to \(S\) and \(B\)): since \(s \in S \cup \bar{B}\) and \(t \notin S \cup \bar{B}\), we have \(c(\delta(S \cup \bar{B})) \ge c(\delta(S))\), which forces \(c(\delta(S \cap \bar{B})) \le c(\delta(\bar{B})) = \lambda_G(u, v)\). Here \(\bar{A} = S \cap \bar{B} \subseteq S\) is an uncrossed minimum \(u\)-\(v\) cut contained inside \(S\)! \(\blacksquare\)

Canonical Source-Side Uncrossing Without Case Distinction: What if we want \(A = S \cap B \subseteq S\) to work even when \(s \notin B\) and \(t \in B\)? Notice that if \((S, \bar{S})\) is the minimal source-side cut (the set of vertices reachable from \(s\) in \(G_f(s, t)\)), or more generally by symmetry of \(s\) and \(t\), if \(s \in B\) and \(t \in \bar{B}\) then Case 1 holds; if \(s \in \bar{B}\) and \(t \in B\), then swapping \(u \leftrightarrow v\) and \(B \leftrightarrow \bar{B}\) reduces back to Case 1; and if \(s, t\) lie on the same side of \(B\) (say \(s, t \in \bar{B}\)), then \(S \setminus B\) separates \(s \in S \setminus B\) from \(t \notin S \setminus B\), so posimodularity \(c(\delta(S)) + c(\delta(B)) \ge c(\delta(S \setminus B)) + c(\delta(B \setminus S))\) together with \(c(\delta(S \setminus B)) \ge c(\delta(S))\) gives \(c(\delta(B \setminus S)) \le c(\delta(B))\), where \(\overline{B \setminus S} \supseteq S\)! Thus in all four placements of \((s, t)\) relative to \((B, \bar{B})\), an uncrossed minimum \(u\)-\(v\) cut exists.

4.3 Structure of the Gomory–Hu Tree & Gusfield’s (1990) 15-Line Algorithm

Definition (Flow-Equivalent Tree vs. Cut-Equivalent Gomory–Hu Tree)

Let \(T = (V, E_T, w_T)\) be a weighted tree on the vertex set \(V\) of \(G\). For every tree edge \(e = (x, y) \in E_T\), removing \(e\) from \(T\) splits \(V\) into two connected components \((C_x(e), C_y(e))\).

  1. Flow-Equivalent Tree (Value Property): For all pairs \(u, v \in V\), the minimum \(u\)-\(v\) cut value in \(G\) equals the minimum edge weight on the unique path \(P_T(u, v)\) between \(u\) and \(v\) in \(T\): \[\lambda_G(u, v) = \min_{e \in P_T(u, v)} w_T(e).\]
  2. Gomory–Hu Tree (Value + Partition Property): In addition to the Value Property, for every tree edge \(e = (x, y) \in E_T\), the tree bipartition \((C_x(e), C_y(e))\) is an actual minimum \(x\)-\(y\) cut in \(G\) of capacity \(c_G(\delta(C_x(e))) = w_T(e) = \lambda_G(x, y)\). Consequently, for any pair \(u, v \in V\), removing the minimum-weight bottleneck edge \(e^* \in \arg\min_{e \in P_T(u, v)} w_T(e)\) from \(T\) yields an actual minimum \(u\)-\(v\) cut partition in \(G\)!

Why \(N - 1\) Uncrossed Cuts Suffice

By Induction on \(N\) using the Cut Uncrossing Lemma (Lemma 16.4), we maintain a collection of supernodes (initially a single block \(V\)) connected by already-computed tree edges. At each step, we pick a block containing at least two vertices \(s, t\), compute a minimum \(s\)-\(t\) cut \((S, \bar{S})\) in \(G\), and split that block along \((S, \bar{S})\) into two sub-blocks connected by a tree edge \((s, t)\) of weight \(\lambda_G(s, t)\).

In 1990, Dan Gusfield discovered that we never need to contract supernodes in \(G\)! Instead, we represent the evolving tree using a simple parent array p[1..N] (initialized to a star p[2..N] = 1 rooted at vertex \(1\)) and split stars in \(N - 1\) iterations \(s = 2, 3, \dots, N\):

// Gusfield's (1990) 15-Line Gomory-Hu Cut Tree Construction
// Assumes: dinic_solve(s, t) resets all edge flows to 0 and returns MaxFlow_G(s, t),
//          and vis[u] == true iff u is reachable from s in the residual graph G_f(s, t).
vector<int> p(N + 1, 1);
vector<long long> w_tree(N + 1, 0);
p[1] = 0;

for (int s = 2; s <= N; ++s) {
    int t = p[s];
    w_tree[s] = dinic_solve(s, t);            // 1. Run s-t MaxFlow on the ORIGINAL graph G
    for (int u = s + 1; u <= N; ++u) {
        if (p[u] == t && vis[u]) {            // 2. ONLY re-parent u > s in t's current star
            p[u] = s;                         //    that lie on s's side of the cut!
        }
    }
    if (p[t] > 0 && vis[p[t]]) {              // 3. Cut-Equivalence Upgrade: if t's own parent
        p[s] = p[t];                          //    lies on s's side of the cut, invert (s, t)
        p[t] = s;                             //    so tree-edge removal matches the cut in G!
        swap(w_tree[s], w_tree[t]);
    }
}
// Resulting tree has N - 1 edges: (i, p[i]) with weight w_tree[i] for i = 2 .. N.

Why Gusfield’s Star-Splitting Works (And Why if (vis[p[t]]) Matters)

In iteration \(s \in \{2, \dots, N\}\), vertices \(\{1, \dots, s-1\}\) are the centers of the already-separated supernode blocks, while every unprocessed vertex \(u \in \{s, \dots, N\}\) is attached as a leaf (p[u] = center) to the unique supernode center in \(\{1, \dots, s-1\}\) whose block contains \(u\).

  1. When we pick \(s\) and its current block center \(t = p[s] < s\), running \(\operatorname{MaxFlow}_G(s, t)\) on the original uncontracted graph \(G\) produces a minimum \(s\)-\(t\) cut \((S, \bar{S})\) with \(s \in S, t \in \bar{S}\) (vis[u] == 1 \(\iff u \in S\)).
  2. Every future vertex \(u > s\) currently attached to \(t\) (p[u] == t) belongs to the supernode block being split by \((s, t)\). If \(u \in S\) (vis[u] == true), \(u\) moves into \(s\)’s new half of the block (p[u] = s); if \(u \in \bar{S}\), \(u\) stays in \(t\)’s half (p[u] = t).
  3. What about the existing tree edge \((t, p[t])\) connecting \(t\)’s block to the rest of the tree? If \(p[t] \in S\) (vis[p[t]] == true), then the exterior component containing \(p[t]\) lies on the \(s\)-side of the cut \((S, \bar{S})\) rather than the \(t\)-side!
    • Without step 3 (if (vis[p[t]])): The tree leaves \((t, p[t])\) attached to \(t\) and attaches \(s\) as a leaf to \(t\). As Gusfield (1990) proved, this 3-line version still satisfies the Value Property (\(\lambda_G(u, v) = \min_{e \in P_T(u, v)} w_T(e)\) for all \(u, v\), i.e., a Flow-Equivalent Tree)!
    • With step 3 (if (vis[p[t]])): Whenever \(p[t] \in S\), we re-attach \(p[t]\) to \(s\) instead of \(t\) (p[s] = p[t]; p[t] = s; swap(w_tree[s], w_tree[t])), which guarantees by Lemma 16.4 that the resulting tree is a true Cut-Equivalent Gomory–Hu Tree (deleting any tree edge yields the exact physical cut partition in \(G\))!

4.4 Hand-Checkable Trace & Broken-Gadget Counterexamples (FM-16)

Hand-Checkable Trace of Gusfield’s Algorithm (\(N = 4\))

Let \(G\) have \(V = \{1, 2, 3, 4\}\) and undirected edges \((1, 2) = 3, (2, 3) = 4, (3, 4) = 5, (4, 1) = 2, (2, 4) = 1\).

  • Initialization: p = [_, 1, 1, 1, 1], w_tree = [_, 0, 0, 0, 0].
  • Iteration \(s = 2\) (\(t = p[2] = 1\)):
    • \(\operatorname{MaxFlow}_G(2, 1) = 5\), with residual reachable set \(S = \{2, 3, 4\}\) and \(\bar{S} = \{1\}\) (severing \((1,2)=3\) and \((1,4)=2\)).
    • Set w_tree[2] = 5. For \(u \in \{3, 4\}\), since p[u] == 1 and \(u \in S\), update p[3] = 2, p[4] = 2.
  • Iteration \(s = 3\) (\(t = p[3] = 2\)):
    • \(\operatorname{MaxFlow}_G(3, 2) = 7\), with \(S = \{3, 4\}\) and \(\bar{S} = \{1, 2\}\) (severing \((2,3)=4, (2,4)=1, (1,4)=2\) of total capacity \(4 + 1 + 2 = 7\), whereas \((\{3\}, \{1, 2, 4\})\) has capacity \(4 + 5 = 9\)).
    • Set w_tree[3] = 7. For \(u = 4\), since p[4] == 2 and \(4 \in S\), update p[4] = 3. Since \(p[t] = p[2] = 1 \notin S\), step 3 does not trigger.
  • Iteration \(s = 4\) (\(t = p[4] = 3\)):
    • \(\operatorname{MaxFlow}_G(4, 3) = 8\), with \(S = \{4\}\) and \(\bar{S} = \{1, 2, 3\}\) (severing \((3,4)=5, (2,4)=1, (1,4)=2\), total capacity \(5+1+2 = 8\)).
    • Set w_tree[4] = 8. Since \(p[3] = 2 \notin S\), step 3 does not trigger.
  • Final Gomory–Hu Tree: Path \(1 \stackrel{5}{\longleftrightarrow} 2 \stackrel{7}{\longleftrightarrow} 3 \stackrel{8}{\longleftrightarrow} 4\).
    • Check \(\lambda_G(2, 4)\): path \(2 - 3 - 4\) has bottleneck \(\min(7, 8) = 7\), and removing edge \((2, 3)\) gives partition \((\{1, 2\}, \{3, 4\})\) of capacity \(7\)!
    • Distinct pairwise min-cut values: \(\{5, 7, 8\}\) (\(3\) distinct values across \(\binom{4}{2} = 6\) pairs).
WarningBroken-Gadget Counterexamples FM-16: The Three Classic Gomory–Hu Failures
  1. Unconditional Re-Parenting Bug (Omitting p[u] == t in Gusfield’s Loop): Suppose a solver writes if (vis[u]) p[u] = s; without checking p[u] == t. Because the max-flow between \(s\) and \(t\) is computed on the uncontracted graph \(G\), the raw cut \((S, \bar{S})\) may cross another already-separated supernode block \(B'\)! Re-parenting vertices \(u \in B'\) that have p[u] != t tears apart previously constructed tree branches and destroys both the Value and Partition properties. Rule: Only vertices \(u > s\) currently belonging to \(t\)’s star (p[u] == t) may be re-parented to \(s\).
  2. Subgraph Deletion / Naive Contraction Corruption (FM-16): In the recursive bucket version of Gomory–Hu (solve(vector<int> B)), when splitting bucket \(B\) into \(B_L = B \cap S\) and \(B_R = B \setminus S\), a common bug is running future max-flows on the induced subgraph \(G[B_L]\) (deleting \(V \setminus B_L\))! Deleting \(V \setminus B_L\) destroys valid flow paths between \(u, v \in B_L\) that route through \(V \setminus B_L\). In the example above, inside \(B_L = \{3, 4\}\), the induced edge is only \((3, 4) = 5\), missing the path \(3 - 2 - 4\) (\(1\)) and \(3 - 2 - 1 - 4\) (\(2\)) that raise \(\lambda_G(3, 4)\) from \(5\) to \(8\)! Always run Dinic on the entire original graph \(G\).
  3. Applying Gomory–Hu to a Directed Graph (Failure of Symmetry & Posimodularity): Gomory–Hu trees exist only for undirected graphs. Consider the 3-vertex directed cycle \(1 \xrightarrow{10} 2 \xrightarrow{1} 3 \xrightarrow{10} 1\).
    • First, directed min-cuts are asymmetric: \(\lambda(1, 2) = 10\) (via \(1 \to 2\)), whereas \(\lambda(2, 1) = 1\) (limited by \(2 \to 3\)).
    • Second, even if you only look at \(\min(\lambda(u, v), \lambda(v, u))\) or outgoing cuts \(f(S) = c(\delta^+(S))\), posimodularity fails because \(f(S) \neq f(V \setminus S)\)! For \(A = \{1, 2\}\) (\(f(A) = c(2 \to 3) = 1\)) and \(B = \{2, 3\}\) (\(f(B) = c(3 \to 1) = 10\)), we have \(f(A) + f(B) = 11\), whereas \(A \setminus B = \{1\}\) (\(f(\{1\}) = c(1 \to 2) = 10\)) and \(B \setminus A = \{3\}\) (\(f(\{3\}) = c(3 \to 1) = 10\)) have \(f(A \setminus B) + f(B \setminus A) = 20 > 11\)! Directed all-pairs min-cuts require Schnorr’s (1979) \(N(N-1)\)-flow directed cut cactus, never Gusfield’s tree.

5. The 4-Step Cut-Compression Diagnostic Protocol

Whenever a problem involves maximum flows or minimum cuts at a scale where standard single-run Dinic cannot directly answer the query—either because \(N, M, Q\) are too large for even one flow call (Module 16A), or because the query ranges over all \(\binom{N}{2}\) terminal pairs (Module 16B)—apply the following 4-Step Protocol:

Step 1: Non-Graph Diagnostic Signal (Classify the Bottleneck)

  1. Single \(s\)-\(t\) Pair, Huge \(N \ge 10^4\) or Online Queries \(Q \ge 10^5\) (Direction B Flow Elimination):
    • Does the problem ask for \(\operatorname{MaxFlow}(s, t)\) on a linear pipeline, tree, complete DAG \(i < j\), complete bipartite graph, or two coupled directed chains?
    • Action: Abandon augmenting paths. Switch to \(\operatorname{MinCut}(s, t) = \min_{S \subseteq V} C(S)\).
  2. Undirected Graph, No Fixed Terminals, Global Disconnection (Stoer–Wagner):
    • Does the problem ask for \(\min_{\emptyset \subsetneq S \subsetneq V} c(\delta(S))\) with \(N \le 500\)?
    • Action: Run \(N - 1\) phases of Maximum Adjacency Search (MAS) + vertex contraction in \(O(N^3)\) or \(O(NM + N^2 \log N)\).
  3. Undirected Graph, All-Pairs \(\binom{N}{2}\) Function of \(\lambda_G(u, v)\) (Gomory–Hu / Gusfield):
    • Does the problem ask to count pairs with \(\lambda_G(u, v) \le X\), count distinct values in \(\{\lambda_G(u, v)\}\), find a permutation maximizing \(\sum \lambda_G(p_i, p_{i+1})\), or test if a matrix \(M_{uv}\) is realizable as an all-pairs min-cut matrix (\(N \le 850\))?
    • Action: Build \(T_{\text{GH}}\) in \(N - 1\) Dinic runs on the uncontracted graph \(G\) via Gusfield’s star-splitting algorithm.

Step 2: Intermediate Algebraic or Polyhedral Representation

  • For Direction B (Module 16A): Write down the exact directed cut polynomial: \[C(\mathbf{x}) = \sum_{i=1}^N p_i (1 - x_i) + \sum_{i=1}^N s_i x_i + \sum_{(i \to j) \in E} c_{i,j}\, x_i (1 - x_j), \qquad x_i = [i \in S] \in \{0, 1\}.\] Identify the interface width between prefix \(\{1, \dots, i\}\) and suffix \(\{i+1, \dots, N\}\):
    • Width \(1\) (Pipeline): Only \(x_i(1 - x_{i+1})\) appears \(\implies 2 \times 2\) \((\min, +)\) tropical matrix.
    • Symmetric Cardinality (Complete DAG): \(\sum_{i < j} x_i(1 - x_j) = \sum_{i \in S}(N - i) - \binom{|S|}{2} \implies O(N^2)\) DP or \(O(N \log N)\) sorted slope-difference greedy.
    • Monotone Prefix Chains: Only one edge \(A_i \to A_{i+1}\) and one edge \(B_j \to B_{j+1}\) are severed \(\implies\) 2D prefix-suffix sweep \((i, j)\).
  • For Gomory–Hu (Module 16B): Replace \(\lambda_G(u, v)\) with the tree path bottleneck: \[\lambda_G(u, v) = \min_{e \in P_{T_{\text{GH}}}(u, v)} w_T(e).\]

Step 3: Mechanical Compilation into Data Structures or Tree Traversals

  • Compile 1D Markov cut transitions into a Segment Tree of \(2 \times 2\) \((\min, +)\) matrices (CF 1919F2) or prefix-minimum Segment Tree (CF 1919F1, CF 903G).
  • Compile tree-bottleneck queries on \(T_{\text{GH}}\) into Kruskal/DSU edge-weight sorting (processing edges of \(T_{\text{GH}}\) from heaviest to lightest!).

Step 4: Broken-Gadget Audit (FM-16a & FM-16)

  • Verify that backward transit edges (\(x_i = 0, x_j = 1\) on \(i \to j\)) pay \(0\), never \(c_{i,j}\) (FM-16a).
  • Verify that Gusfield’s loop checks p[u] == t before re-parenting p[u] = s and resets all residual capacities to their original undirected weights before each of the \(N - 1\) Dinic runs (FM-16).

#121 (SS-1) — Codeforces 1919F1: Wine Factory (Easy Version)

  • Judge / URL: Codeforces 1919F1 ([EN])
  • Constraints: \(N, Q \le 5 \cdot 10^5\), water tower supplies \(a_i \in [0, 10^9]\), wizard capacities \(b_i \in [0, 10^9]\), forward pipe capacities \(c_i = 10^{18}\) (\(\infty\)) for \(1 \le i \le N - 1\). Given \(Q\) point updates to \((a_p, b_p, c_p)\) (with \(c_p = 10^{18}\)), output the total wine produced after each update.

Step 1: Non-Graph Diagnostic Signal

Each tower \(i\) receives up to \(a_i\) water from the source \(s\), converts up to \(b_i\) water into wine (sent to the sink \(t\)), and sends any leftover water forward to tower \(i + 1\) through a pipe of capacity \(c_i = \infty\). Because \(N, Q \le 5 \cdot 10^5\), we cannot run a flow solver or even simulate greedy carry-propagation per query. By Max-Flow Min-Cut Duality in Direction B, we minimize the capacity of an \(s\)-\(t\) cut over \(\{1, \dots, N\}\).

Step 2: Intermediate Algebraic Representation

Let \(x_i \in \{S, T\}\) denote the side of vertex \(i\) in an \(s\)-\(t\) cut:

  • Placing \(i \in T\) severs \(s \to i\) at cost \(a_i\).
  • Placing \(i \in S\) severs \(i \to t\) at cost \(b_i\).
  • Placing \(i \in S\) and \(i + 1 \in T\) severs the pipe \(i \to i + 1\) at cost \(c_i = \infty\)!

Because \(c_i = \infty\), no index \(i\) can have \(x_i = S\) and \(x_{i+1} = T\). Thus, once the sequence \((x_1, \dots, x_N)\) switches to \(S\), every subsequent vertex must also be in \(S\). Every finite-cost cut is uniquely parameterized by the split index \(k \in \{0, 1, \dots, N\}\) such that \(\{1, \dots, k\} \subseteq T\) and \(\{k + 1, \dots, N\} \subseteq S\):

\[ \operatorname{Cut}(k) = \sum_{i=1}^k a_i + \sum_{i=k+1}^N b_i = \sum_{i=1}^N b_i + \sum_{i=1}^k (a_i - b_i), \qquad k \in \{0, 1, \dots, N\}. \]

    • sum: the interval sum \(\sum_{i=L}^R d_i\),
    • min_pref: the minimum non-empty prefix sum \(\min_{L \le k \le R} \sum_{i=L}^k d_i\), merged via: \[\text{node.sum} = \text{left.sum} + \text{right.sum}, \qquad \text{node.min\_pref} = \min\big(\text{left.min\_pref},\;\; \text{left.sum} + \text{right.min\_pref}\big).\]
  • Including the empty prefix \(k = 0\) (which has sum \(0\), corresponding to all vertices in \(S\)), the global minimum cut after each query is: \[\operatorname{Ans} = \sum_{i=1}^N b_i + \min\big(0,\;\; \text{root.min\_pref}\big).\]

struct Dinic {
    struct Edge {
        int to, rev;
        long long cap, init_cap;
    };
    int n;
    vector<vector<Edge>> adj;
    vector<int> level, ptr;

    Dinic(int n) : n(n), adj(n + 1), level(n + 1), ptr(n + 1) {}

    void add_undirected_edge(int u, int v, long long c) {
        adj[u].push_back({v, (int)adj[v].size(), c, c});
        adj[v].push_back({u, (int)adj[u].size() - 1, c, c});
    }

    void reset() {
        for (int i = 1; i <= n; ++i)
            for (auto& e : adj[i]) e.cap = e.init_cap;
    }

        fill(level.begin(), level.end(), -1);
        level[s] = 0;
        queue<int> q;
        q.push(s);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (auto& e : adj[u]) {
                if (e.cap > 0 && level[e.to] == -1) {
                    level[e.to] = level[u] + 1;
                    q.push(e.to);
                }
            }
        }
        return level[t] != -1;
    }

        if (pushed == 0 || u == t) return pushed;
        for (int& cid = ptr[u]; cid < (int)adj[u].size(); ++cid) {
            auto& e = adj[u][cid];
            if (level[u] + 1 != level[e.to] || e.cap == 0) continue;

            if (tr == 0) continue;
            e.cap -= tr;
            adj[e.to][e.rev].cap += tr;
            return tr;
        }
        return 0;
    }

        reset();
        long long flow = 0;
        while (bfs(s, t)) {
            fill(ptr.begin(), ptr.end(), 0);
            while (long long pushed = dfs(s, t, INF)) flow += pushed;
        }
        return flow;

#include <bits/stdc++.h>
using namespace std;

const long long INF = 4e18;

struct Mat {
    long long d[2][2];
    Mat() {
        d[0][0] = d[0][1] = d[1][0] = d[1][1] = INF;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    if (!(cin >> n >> q)) return 0;

    vector<long long> a(n + 1), b(n + 1), c(n + 1, 0);
    for (int i = 1; i <= n; ++i) cin >> a[i];
    for (int i = 1; i <= n; ++i) cin >> b[i];
    for (int i = 1; i < n; ++i) cin >> c[i];

    vector<Mat> tree(4 * n + 4);

    auto merge_nodes = [&](const Mat& L, const Mat& R, long long pipe_c) {
        Mat res;
        for (int u = 0; u < 2; ++u) {
            for (int x = 0; x < 2; ++x) {
                if (L.d[u][x] >= INF) continue;
                for (int y = 0; y < 2; ++y) {
                    long long cross = (x == 1 && y == 0) ? pipe_c : 0;
                    for (int v = 0; v < 2; ++v) {
                        if (R.d[y][v] >= INF) continue;
                        res.d[u][v] = min(res.d[u][v], L.d[u][x] + R.d[y][v] + cross);
                    }
                }
            }
        }
        return res;
    };

    auto build = [&](auto& self, int u, int l, int r) -> void {
        if (l == r) {
            tree[u] = Mat();
            tree[u].d[0][0] = a[l]; // l in T (sink side)
            tree[u].d[1][1] = b[l]; // l in S (source side)
            return;
        }
        int mid = (l + r) / 2;
        self(self, 2 * u, l, mid);
        self(self, 2 * u + 1, mid + 1, r);
        tree[u] = merge_nodes(tree[2 * u], tree[2 * u + 1], c[mid]);
    };

    auto update = [&](auto& self, int u, int l, int r, int p) -> void {
        if (l == r) {
            tree[u] = Mat();
            tree[u].d[0][0] = a[l];
            tree[u].d[1][1] = b[l];
            return;
        }
        int mid = (l + r) / 2;
        if (p <= mid) self(self, 2 * u, l, mid, p);
        else self(self, 2 * u + 1, mid + 1, r, p);
        tree[u] = merge_nodes(tree[2 * u], tree[2 * u + 1], c[mid]);
    };

    build(build, 1, 1, n);

    while (q--) {
        int p;
        long long x, y, z;
        cin >> p >> x >> y >> z;
        a[p] = x;
        b[p] = y;
        if (p < n) c[p] = z;
        update(update, 1, 1, n, p);

        long long ans = INF;
        for (int u = 0; u < 2; ++u)
            for (int v = 0; v < 2; ++v)
                ans = min(ans, tree[1].d[u][v]);
        cout << ans << '\n';
    }
    return 0;
}

#127 (Mas-1) — Codeforces 343E: Pumping Stations

  • Judge / URL: Codeforces 343E ([EN])
  • Constraints: Undirected weighted graph with \(N \le 200\) vertices and \(M \le 1000\) edges. Find a permutation \(\pi = (\pi_1, \pi_2, \dots, \pi_N)\) of \(\{1, \dots, N\}\) maximizing \(\sum_{i=1}^{N-1} \operatorname{MinCut}_G(\pi_i, \pi_{i+1})\), and output both the maximum sum and the optimal permutation \(\pi\).

Step 1: Non-Graph Diagnostic Signal

We want a maximum-weight Hamiltonian path in the complete graph of pairwise minimum cuts \(\lambda_G(u, v)\). While Maximum Travelling Salesman is NP-hard on general metrics, \(\lambda_G(u, v)\) is an ultrametric tree-bottleneck function on the Gomory–Hu tree \(T_{\text{GH}}\)!

Step 2: Intermediate Algebraic Representation & Exact Upper Bound Proof

Let \(T_{\text{GH}} = (V, E_T, w_T)\) be the Gomory–Hu tree of \(G\). We prove that for any permutation \(\pi\), its objective is bounded above by the total weight of \(T_{\text{GH}}\), and that this upper bound is always achievable:

\[ \max_{\pi \in S_N} \sum_{i=1}^{N-1} \lambda_G(\pi_i, \pi_{i+1}) = \sum_{e \in E_T} w_T(e). \]

Proof of Upper Bound & Constructive Equality:

  1. Upper Bound (\(\le\)): Consider the minimum-weight edge \(e_{\min} \in \arg\min_{e \in E_T} w_T(e)\) of \(T_{\text{GH}}\). Removing \(e_{\min}\) splits \(T_{\text{GH}}\) into two subtrees \(T_1\) and \(T_2\). Any permutation \(\pi_1, \dots, \pi_N\) must step between \(V(T_1)\) and \(V(T_2)\) at least once, and that step uses \(e_{\min}\) on its tree path, paying \(\le w_T(e_{\min})\). More generally, mapping each adjacent step \((\pi_i, \pi_{i+1})\) to a bottleneck edge on \(P_T(\pi_i, \pi_{i+1})\) via induction on \(|V|\) shows \(\sum_{i=1}^{N-1} \lambda_G(\pi_i, \pi_{i+1}) \le \sum_{e \in E_T} w_T(e)\).
  2. Constructive Equality (\(=\)): Suppose we order all vertices of \(T_1\) first, followed by all vertices of \(T_2\). Because \(e_{\min}\) is the globally lightest edge in the entire tree \(T_{\text{GH}}\), for any last vertex \(x \in V(T_1)\) and any first vertex \(y \in V(T_2)\), the path \(P_T(x, y)\) crosses \(e_{\min}\) and every other edge on \(P_T(x, y)\) has weight \(\ge w_T(e_{\min})\)! Therefore, the boundary transition \((x, y)\) between \(T_1\) and \(T_2\) achieves bottleneck exactly \(w_T(e_{\min})\)! Applying the exact same rule recursively to \(T_1\) and \(T_2\) achieves \(\sum_{e \in E_T} w_T(e)\)! \(\blacksquare\)

Step 3: Reverse-Engineering Scratchpad (Kruskal DSU Concatenation)

Splitting \(T_{\text{GH}}\) top-down at the minimum-weight edge \(e_{\min}\) is bottom-up equivalent to Kruskal’s DSU in descending order of edge weights!

  • Build \(T_{\text{GH}}\) in \(N - 1\) Dinic calls using Gusfield’s algorithm.
  • Sort the \(N - 1\) edges of \(T_{\text{GH}}\) in descending order of \(w_T(e)\).
  • Maintain a DSU where each component \(c\) stores an ordered list order[c] of its vertices (initially order[u] = {u}).
  • For each tree edge \(e = (u, v)\) from heaviest to lightest: append order[find(v)] to the end of order[find(u)] and unite the two components! At the end, the single list order[find(1)] is the exact optimal permutation \(\pi\)!

Step 4: Toy Trace & Failure-Mode Guard

  • Failure Guard: Splitting at an arbitrary edge (or sorting edges ascending instead of descending in DSU) fails because when two components are concatenated across a heavy edge \(e\), a lighter edge already inside one of the components would become the bottleneck on \(P_T(x, y)\) instead of \(e\)!
Note3-Tier Progressive Hints for #127 (CF 343E)
  • Hint 1 (Diagnostic): Build the Gomory–Hu tree \(T_{\text{GH}}\). Why can no permutation ever exceed the sum of the \(N - 1\) edge weights of \(T_{\text{GH}}\)?
  • Hint 2 (Algebraic): Let \(e_{\min}\) be the lightest edge in \(T_{\text{GH}}\), splitting \(T_{\text{GH}}\) into \(T_1\) and \(T_2\).   • Hint 3 (Compilation): Sort the \(N - 1\) edges of \(T_{\text{GH}}\) in descending order of weight and merge component vertex lists using a Disjoint Set Union (DSU)!

#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9;

struct Dinic {
    struct Edge {
        int to, rev, cap, init_cap;
    };
    int n;
    vector<vector<Edge>> adj;
    vector<int> level, ptr;

    Dinic(int n) : n(n), adj(n + 1), level(n + 1), ptr(n + 1) {}

    void add_undirected_edge(int u, int v, int c) {
        adj[u].push_back({v, (int)adj[v].size(), c, c});
        adj[v].push_back({u, (int)adj[u].size() - 1, c, c});
    }

    void reset() {
        for (int i = 1; i <= n; ++i)
            for (auto& e : adj[i]) e.cap = e.init_cap;
    }

    bool bfs(int s, int t) {
        fill(level.begin(), level.end(), -1);
        level[s] = 0;
        queue<int> q;
        q.push(s);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (auto& e : adj[u]) {
                if (e.cap > 0 && level[e.to] == -1) {
                    level[e.to] = level[u] + 1;
                    q.push(e.to);
                }
            }
        }
        return level[t] != -1;
    }

    int dfs(int u, int t, int pushed) {
        if (pushed == 0 || u == t) return pushed;
        for (int& cid = ptr[u]; cid < (int)adj[u].size(); ++cid) {
            auto& e = adj[u][cid];
            if (level[u] + 1 != level[e.to] || e.cap == 0) continue;
            int tr = dfs(e.to, t, min(pushed, e.cap));
            if (tr == 0) continue;
            e.cap -= tr;
            adj[e.to][e.rev].cap += tr;
            return tr;
        }
        return 0;
    }

    int max_flow(int s, int t) {
        reset();
        int flow = 0;
        while (bfs(s, t)) {
            fill(ptr.begin(), ptr.end(), 0);
            while (int pushed = dfs(s, t, INF)) flow += pushed;
        }
        return flow;
    }
};

struct TreeEdge {
    int u, v, w;
    bool operator<(const TreeEdge& other) const {
        return w > other.w; // Sort descending!
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;

    Dinic dinic(n);
    for (int i = 0; i < m; ++i) {
        int u, v, w;
        cin >> u >> v >> w;
        dinic.add_undirected_edge(u, v, w);
    }

    vector<int> p(n + 1, 1);
    vector<TreeEdge> tree_edges;
    long long total_weight = 0;

    for (int s = 2; s <= n; ++s) {
        int t = p[s];
        int w = dinic.max_flow(s, t);
        total_weight += w;
        tree_edges.push_back({s, t, w});
        for (int u = s + 1; u <= n; ++u) {
            if (p[u] == t && dinic.level[u] != -1) {
                p[u] = s;
            }
        }
    }

    sort(tree_edges.begin(), tree_edges.end());

    vector<int> dsu(n + 1);
    vector<vector<int>> comp_order(n + 1);
    for (int i = 1; i <= n; ++i) {
        dsu[i] = i;
        comp_order[i] = {i};
    }

    auto find_set = [&](auto& self, int x) -> int {
        return dsu[x] == x ? x : dsu[x] = self(self, dsu[x]);
    };

    for (const auto& e : tree_edges) {
        int ru = find_set(find_set, e.u);
        int rv = find_set(find_set, e.v);
        if (ru != rv) {
            comp_order[ru].insert(comp_order[ru].end(),
                                  comp_order[rv].begin(), comp_order[rv].end());
            comp_order[rv].clear();
            dsu[rv] = ru;
        }
    }

    int root = find_set(find_set, 1);
    cout << total_weight << '\n';
    for (int i = 0; i < n; ++i) {
        cout << comp_order[root][i] << (i + 1 == n ? '\n' : ' ');
    }
    return 0;
}

For a chosen left cut index \(i \in \{1, \dots, N\}\) (\(A_1 \dots A_i \in S\)) and right cut index \(j \in \{0, \dots, N - 1\}\) (\(B_1 \dots B_j \in S\), \(B_{j+1} \dots B_N \in T\)), a cross-edge \(A_u \to B_v\) of capacity \(z_{uv}\) crosses from \(S\) to \(T\) if and only if \(u \le i\) and \(v > j\) (i.e., \(j \in [0, v - 1]\)):

\[ \operatorname{Cut}(i, j) = x_i + \underbrace{\left( y_j + \sum_{u \le i,\; v > j} z_{uv} \right)}_{f_i(j)}, \qquad \operatorname{MaxFlow}(A_1, B_N) = \min_{1 \le i \le N} \big(x_i + C_i\big), \]

where \(C_i = \min_{0 \le j \le N - 1} f_i(j)\) is completely independent of \(x\) and can be precomputed once for all \(i = 1, \dots, N\)!

Step 3: Reverse-Engineering Scratchpad (Sweep-Line Lazy Segment Tree)

  • Phase 1 (Precomputing \(C_1, \dots, C_N\) in \(O((N + M) \log N)\)):
    • Build a Lazy Range-Add Range-Min Segment Tree over \(j \in [0, N - 1]\), initialized at leaf \(j\) with \(y_j\) (\(y_0 = 0\)).
    • Sweep \(i\) from \(1\) to \(N\): for each cross-edge \(A_i \to B_v\) of weight \(z\), add \(+z\) to the prefix range \(j \in [0, v - 1]\) in the Segment Tree!
    • After processing all cross-edges out of \(A_i\), query the global minimum of the Segment Tree and store it as \(C_i = \text{seg.root\_min}()\).
  • Phase 2 (Answering \(Q\) Updates to \(x_i\) in \(O(Q \log N)\)):
    • Maintain the \(N\) values \(x_i + C_i\) in a std::multiset<long long> (or a second point-update Segment Tree), updating \(x_i + C_i\) in \(O(\log N)\) per query!

Step 4: Toy Trace & Failure-Mode Guard

  • Failure Guard: Do not forget \(j = 0\) (\(y_0 = 0\), placing all \(B_1, \dots, B_N\) on the sink side \(T\)) and \(i = N\) (\(x_N = 0\), placing all \(A_1, \dots, A_N\) on the source side \(S\))! If \(j = 0\) is omitted from the Segment Tree domain \([0, N - 1]\), any cut that leaves \(B_1 \in T\) (which is required whenever \(A_i \to B_1\) is severed!) will be missed.

#include <bits/stdc++.h>
using namespace std;

const long long INF = 4e18;

struct LazySegTree {
    int n;
    vector<long long> mn, lz;

    LazySegTree(int n) : n(n), mn(4 * n + 4, 0), lz(4 * n + 4, 0) {}

    void build(int u, int l, int r, const vector<long long>& y) {
        if (l == r) {
            mn[u] = y[l];
            return;
        }
        int mid = (l + r) / 2;
        build(2 * u, l, mid, y);
        build(2 * u + 1, mid + 1, r, y);
        mn[u] = min(mn[2 * u], mn[2 * u + 1]);
    }

    void apply(int u, long long v) {
        mn[u] += v;
        lz[u] += v;
    }

    void push(int u) {
        if (lz[u] != 0) {
            apply(2 * u, lz[u]);
            apply(2 * u + 1, lz[u]);
            lz[u] = 0;
        }
    }

    void range_add(int u, int l, int r, int ql, int qr, long long v) {
        if (ql <= l && r <= qr) {
            apply(u, v);
            return;
        }
        push(u);
        int mid = (l + r) / 2;
        if (ql <= mid) range_add(2 * u, l, mid, ql, qr, v);
        if (qr > mid) range_add(2 * u + 1, mid + 1, r, ql, qr, v);
        mn[u] = min(mn[2 * u], mn[2 * u + 1]);
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, q;
    if (!(cin >> n >> m >> q)) return 0;

    vector<long long> x(n + 1, 0), y(n, 0);
    for (int i = 1; i < n; ++i) {
        cin >> x[i] >> y[i];
    }

    vector<vector<pair<int, long long>>> cross(n + 1);
    for (int i = 0; i < m; ++i) {
        int u, v;
        long long z;
        cin >> u >> v >> z;
        cross[u].push_back({v, z});
    }

    // Phase 1: Sweep i = 1 .. N to precompute optimal B-cut C[i]
    LazySegTree seg_b(n);
    seg_b.build(1, 0, n - 1, y);

    vector<long long> C(n + 1, 0);
    for (int i = 1; i <= n; ++i) {
        for (auto& [v, z] : cross[i]) {
            seg_b.range_add(1, 0, n - 1, 0, v - 1, z);
        }
        C[i] = seg_b.mn[1];
    }

    // Phase 2: Maintain min_{1 <= i <= N} (x[i] + C[i]) under point updates to x[i]
    multiset<long long> active_cuts;
    for (int i = 1; i <= n; ++i) {
        active_cuts.insert(x[i] + C[i]);
    }

    cout << *active_cuts.begin() << '\n';
    while (q--) {
        int idx;
        long long w;
        cin >> idx >> w;
        active_cuts.erase(active_cuts.find(x[idx] + C[idx]));
        x[idx] = w;
        active_cuts.insert(x[idx] + C[idx]);
        cout << *active_cuts.begin() << '\n';
    }
    return 0;
}
