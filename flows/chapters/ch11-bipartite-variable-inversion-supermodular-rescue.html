Bipartite Variable Inversion — Rescuing Supermodular Costs (\(A + D > B + C\))

Phase 3, Chapter 11: Column-Flip Transformations, Harary Signed Balance, Parity Partitioning, and Flagship Two-Permutation Min-Cut

NotePrerequisites & Learning Objectives

Prerequisites:

  • Chapter 2: Minimum \(s\)-\(t\) Cut as Binary Partition (\(x_u \in \{0, 1\}\), cut penalty \(c_{uv} x_u (1 - x_v)\)).
  • Chapter 6: Grid Parity Bipartition (黑白染色, \((r + c) \bmod 2\)) and Maximum Weight Independent Set on Bipartite Graphs.
  • Chapter 9: Maximum Weight Closure (Picard 1976) and Implication Chains (\(x_u \le x_v \iff u \xrightarrow{\infty} v\)).
  • Chapter 10: Pseudo-Boolean Submodular Minimization (Kolmogorov–Zabih 2004, 燃やす埋める), where a pairwise cost table \(\begin{pmatrix} A & B \\ C & D \end{pmatrix}\) is directly \(s\)-\(t\) cut-representable if and only if \(A + D \le B + C\).

Learning Objectives:

  1. Diagnose Supermodular Failure: Immediately recognize when an English rule (“penalize when \(x_u = x_v\)”, “reward when \(x_u \ne x_v\)”, “forbid \(x_u = x_v = 1\)”, or “at least one of \(x_u, x_v\) must be \(1\)”) produces a supermodular cost table with \(A + D > B + C\) (\(\Delta = B + C - A - D < 0\)).
  2. Apply Bipartite Variable Inversion (二部グラフの片側反転): Rescue supermodular pairwise tables on a bipartite interaction graph \(G = (L \sqcup R, E)\) by substituting \(y_v = 1 - x_v\) for all \(v \in R\), swapping columns \(0 \leftrightarrow 1\) of the \(2 \times 2\) payoff matrix to restore submodularity (\(A' + D' \le B' + C'\)).
  3. Test Mixed Graphs via Harary’s Signed Balance Theorem: Reduce arbitrary mixed submodular/supermodular pairwise systems to an XOR-2-SAT gauge-switching system \(\sigma_u \oplus \sigma_v = [\Delta_{uv} < 0]\), and understand the odd-cycle barrier (\(K_3\)) and QPBO Roof Duality when balance fails.
  4. Master Three Canonical Inversion Geometries:
    • Chessboard Parity \((r + c) \bmod 2\) on grids (Luogu P2774, Luogu P1935, ABC 193 F).
    • Row-vs-Column Operations on matrices (ABC 259 G, ARC 176 E).
    • Two-Family Disjoint Object Pairs such as horizontal/vertical bricks or two permutations’ cycle decompositions (Flagship Case Study: AtCoder AGC 038 F — Two Permutations).

In Chapter 10, we established the foundational law of pseudo-Boolean cut compilation: a binary energy function \(E(x_1, \dots, x_n) = \sum_u \phi_u(x_u) + \sum_{(u,v)} \psi_{uv}(x_u, x_v)\) can be compiled directly into an \(s\)-\(t\) minimum cut network with non-negative capacities if and only if every pairwise interaction table

\[ \psi_{uv}(x_u, x_v) = \begin{pmatrix} \psi_{uv}(0,0) & \psi_{uv}(0,1) \\ \psi_{uv}(1,0) & \psi_{uv}(1,1) \end{pmatrix} = \begin{pmatrix} A & B \\ C & D \end{pmatrix} \]

satisfies the submodularity inequality

\[ A + D \le B + C \iff \Delta_{uv} \coloneqq B + C - A - D \ge 0. \]

Intuitively, submodularity demands that agreement is cheaper than disagreement: placing \(u\) and \(v\) on the same side of the cut (\(x_u = x_v \in \{0, 1\}\), diagonals \(A\) and \(D\)) must cost no more than separating them (\(x_u \ne x_v\), off-diagonals \(B\) and \(C\)).

Yet in competitive programming, half of all binary decision problems ask for the exact opposite!

  • “Adjacent cells cannot both be chosen” (Maximum Weight Independent Set): choosing both (\(x_u = x_v = 1\)) incurs penalty \(D = \infty\), while \(A = B = C = 0\). Here \(A + D = \infty > 0 = B + C\).
  • “Adjacent cells painted the same color incur a penalty / different colors earn a bonus” (Zebraness, 圈地计划): \(A + D > B + C\).
  • “Two permutations \(P\) and \(Q\) collide at index \(i\) when both cycles make the same shift choice” (AGC 038 F — Two Permutations): minimizing collisions penalizes \(x_u = x_v = 0\) or \(x_u = x_v = 1\), yielding \(A + D > B + C\).

Whenever a solver mechanically applies the Chapter 10 polynomial decomposition to such a problem, the cross-term coefficient \(\Delta_{uv} = B + C - A - D\) comes out strictly negative, demanding an illegal directed edge of capacity \(-\Delta_{uv} < 0\).

This chapter develops the single most important algebraic rescue tool in minimum-cut modelling: Bipartite Variable Inversion (known in the Japanese 燃やす埋める literature as 二部グラフの片側反転 — one-sided inversion on a bipartite graph, and in Chinese national team papers as 二分图反演 / 黑白染色状态翻转). Whenever the supermodular edges form a bipartite graph \(G = (L \sqcup R, E)\)—or, more generally, whenever the signed interaction graph is balanced in the sense of Harary (1953)—inverting the boolean encoding \(y_v \coloneqq 1 - x_v\) on one shore \(R\) swaps columns \(0 \leftrightarrow 1\) of every cross-shore payoff matrix, flipping the sign of \(\Delta_{uv}\) from negative to positive and restoring exact polynomial-time \(s\)-\(t\) cut solvability.

1. When Submodularity Fails (\(A + D > B + C\)) — Same-State Conflicts and Mutual Exclusion

1.1 The Submodularity Wall Revisited

Let us recall from Chapter 10 how any pairwise cost table \(\psi_{uv}(x_u, x_v) = \begin{pmatrix} A & B \\ C & D \end{pmatrix}\) over binary indicators \(x_u, x_v \in \{0, 1\}\) (with convention \(x_i = 1 \iff i \in S\text{-side}\) and \(x_i = 0 \iff i \in T\text{-side}\)) expands into a multi-linear polynomial:

\[ \begin{aligned} \psi_{uv}(x_u, x_v) &= A(1 - x_u)(1 - x_v) + B(1 - x_u)x_v + C x_u(1 - x_v) + D x_u x_v \\ &= A + (C - A)x_u + (B - A)x_v - \underbrace{(B + C - A - D)}_{\Delta_{uv}} x_u x_v. \end{aligned} \]

To express the quadratic term \(-\Delta_{uv} x_u x_v\) as a directed cut penalty \(c_{uv} x_u (1 - x_v)\), we substitute \(x_u x_v = x_u - x_u(1 - x_v)\):

\[ \psi_{uv}(x_u, x_v) = A + (C - A - \Delta_{uv})x_u + (B - A)x_v + \Delta_{uv} x_u (1 - x_v). \]

Because an \(s\)-\(t\) cut separator between \(u\) and \(v\) can only penalize the event \((x_u = 1, x_v = 0)\) with a non-negative edge capacity \(c(u \to v) = \Delta_{uv} \ge 0\) (or \((x_u = 0, x_v = 1)\) with \(c(v \to u) \ge 0\)), direct compilation succeeds if and only if \(\Delta_{uv} = B + C - A - D \ge 0\).

1.2 Four Archetypes Where \(A + D > B + C\)

Why does \(\Delta_{uv} < 0\) arise so frequently in contest problems? Because natural problem statements often express repulsion, conflict, or covering rather than attraction/homophily. Table 11.1 catalogs the four canonical supermodular archetypes.

Table 11.1: The four canonical supermodular pairwise archetypes that violate \(A + D \le B + C\).
Archetype English Statement Rule Cost Table \(\begin{pmatrix} A & B \\ C & D \end{pmatrix}\) Cross-Term \(\Delta_{uv} = B + C - A - D\)
1. Mutual Exclusion (NAND) “Cannot pick both \(u\) and \(v\) (\(x_u + x_v \le 1\))” \(\begin{pmatrix} 0 & 0 \\ 0 & \infty \end{pmatrix}\) \(\Delta_{uv} = -\infty < 0\)
2. Mandatory Covering (OR) “Must pick at least one of \(u, v\) (\(x_u + x_v \ge 1\))” \(\begin{pmatrix} \infty & 0 \\ 0 & 0 \end{pmatrix}\) \(\Delta_{uv} = -\infty < 0\)
3. Soft Co-Selection Penalty “If both \(u\) and \(v\) are picked, pay penalty \(w > 0\)” \(\begin{pmatrix} 0 & 0 \\ 0 & w \end{pmatrix}\) \(\Delta_{uv} = -w < 0\)
4. Anti-Ferromagnetic / Zebra Penalty “If \(x_u = x_v\), pay penalty \(w > 0\) (or lose bonus \(w\))” \(\begin{pmatrix} w & 0 \\ 0 & w \end{pmatrix}\) \(\Delta_{uv} = -2w < 0\)

Notice the common structural signature across all four rows of Table 11.1: the diagonal entries \((0,0)\) and \((1,1)\) are heavier than the off-diagonal entries \((0,1)\) and \((1,0)\). In the language of statistical physics, submodular potentials (\(A + D < B + C\)) are ferromagnetic (neighbors prefer to align in the same spin state), whereas supermodular potentials (\(A + D > B + C\)) are anti-ferromagnetic (neighbors prefer to anti-align in opposite spin states).

1.3 Impossibility of Non-Negative Auxiliary-Vertex Gadgets Without Variable Inversion

A natural question every student asks when first encountering \(\Delta_{uv} < 0\) is:

“In Chapter 10, when we needed to penalize a higher-order conjunction \(x_1 = x_2 = \dots = x_k = 1\), we introduced an auxiliary project vertex \(p\) with edges \(S \to p\) and \(p \to v_i\). Can we similarly build a clever auxiliary-vertex gadget with non-negative capacities that represents \(\psi_{uv}(x_u, x_v) = w \cdot x_u x_v\) (penalty \(w > 0\) when \(x_u = x_v = 1\)) while keeping \(x_u = 1 \iff u \in S\) and \(x_v = 1 \iff v \in S\)?”

The answer is an unconditional No. Understanding why this is impossible prevents hours of futile gadget tinkering during a contest.

ImportantTheorem 11.1 (Submodularity of Schur-Complement Cut Projections — Kolmogorov & Zabih 2004; Freedman & Drineas 2005)

Let \(\mathcal{N} = (V, E, c \ge 0)\) be any directed flow network with source \(S\), sink \(T\), primary decision vertices \(U \subseteq V \setminus \{S, T\}\), and arbitrary auxiliary vertices \(W = V \setminus (U \cup \{S, T\})\). For any binary assignment \(x \in \{0, 1\}^U\) (where \(x_u = 1 \iff u \in S\text{-side}\) and \(x_u = 0 \iff u \in T\text{-side}\)), define the projected minimum cut cost over all choices of the auxiliary vertices \(W\):

\[ f(x) \coloneqq \min_{y \in \{0, 1\}^W} \operatorname{cut}_{\mathcal{N}}(x, y). \]

Then \(f : \{0, 1\}^U \to \mathbb{R}_{\ge 0} \cup \{\infty\}\) is always submodular on \(\{0, 1\}^U\): for every pair \(u, v \in U\) and fixed assignment to \(U \setminus \{u, v\}\),

\[ f(0, 0) + f(1, 1) \le f(0, 1) + f(1, 0). \]

NoteProof of Theorem 11.1 (Closure of Submodularity Under Partial Minimization)

First, the total cut cost \(\operatorname{cut}_{\mathcal{N}}(x, y) = \sum_{(p,q) \in E} c_{pq} z_p (1 - z_q)\) is a nonnegative linear combination of basic cut functions \(z_p(1 - z_q)\), each of which has \(\Delta = 1 + 0 - 0 - 0 = 1 \ge 0\) and is therefore submodular on \(\{0, 1\}^{U \cup W}\).

Now let \(y^{01} \in \{0, 1\}^W\) be the optimal auxiliary assignment achieving \(f(0, 1) = \operatorname{cut}_{\mathcal{N}}((0, 1), y^{01})\), and let \(y^{10} \in \{0, 1\}^W\) achieve \(f(1, 0) = \operatorname{cut}_{\mathcal{N}}((1, 0), y^{10})\). By the lattice submodularity of \(\operatorname{cut}_{\mathcal{N}}\) on the product boolean lattice \(\{0, 1\}^U \times \{0, 1\}^W\):

\[ \begin{aligned} f(0, 1) + f(1, 0) &= \operatorname{cut}_{\mathcal{N}}((0, 1), y^{01}) + \operatorname{cut}_{\mathcal{N}}((1, 0), y^{10}) \\ &\ge \operatorname{cut}_{\mathcal{N}}\big((0, 1) \wedge (1, 0),\, y^{01} \wedge y^{10}\big) + \operatorname{cut}_{\mathcal{N}}\big((0, 1) \vee (1, 0),\, y^{01} \vee y^{10}\big) \\ &= \operatorname{cut}_{\mathcal{N}}\big((0, 0),\, y^{01} \wedge y^{10}\big) + \operatorname{cut}_{\mathcal{N}}\big((1, 1),\, y^{01} \vee y^{10}\big) \\ &\ge \min_{y \in \{0,1\}^W} \operatorname{cut}_{\mathcal{N}}((0, 0), y) + \min_{y \in \{0,1\}^W} \operatorname{cut}_{\mathcal{N}}((1, 1), y) \\ &= f(0, 0) + f(1, 1). \qquad \square \end{aligned} \]

Consequence of Theorem 11.1: As long as \(x_u = 1\) and \(x_v = 1\) both mean “placed on the \(S\)-side of the cut,” no arrangement of auxiliary vertices and non-negative directed edges can ever penalize \(x_u = x_v = 1\) more than \(x_u \ne x_v\). The only way to cross the submodularity wall is to change what the cut sides mean for one of the two variables!

2. The Bipartite Variable Inversion Theorem (二部グラフの片側反転)

2.1 The Column-Flip Algebraic Identity (\(y_v = 1 - x_v\))

Suppose our pairwise interaction between \(u\) and \(v\) is supermodular:

\[ \psi_{uv}(x_u, x_v) = \begin{pmatrix} A & B \\ C & D \end{pmatrix} \quad \text{with} \quad A + D > B + C \iff \Delta_{uv} = B + C - A - D < 0. \]

Instead of encoding both \(x_u\) and \(x_v\) by the standard convention (\(1 \iff S\text{-side}\), \(0 \iff T\text{-side}\)), suppose we keep \(x_u\)’s convention unchanged on \(u\), but invert the cut convention on \(v\) by defining the complemented indicator variable

\[ y_v \coloneqq 1 - x_v \in \{0, 1\} \quad \Longleftrightarrow \quad x_v = 1 - y_v. \]

In geometric cut terms:

  • For an unflipped vertex \(u \in L\):
    • \(u \in S \iff x_u = 1\) (“state 1 / chosen / True”),
    • \(u \in T \iff x_u = 0\) (“state 0 / unchosen / False”).
  • For an inverted vertex \(v \in R\):
    • \(v \in S \iff y_v = 1 \iff x_v = 0\) (“state 0 / unchosen / False”),
    • \(v \in T \iff y_v = 0 \iff x_v = 1\) (“state 1 / chosen / True”).

What happens to the \(2 \times 2\) cost matrix when we rewrite \(\psi_{uv}(x_u, x_v)\) as a function \(\widetilde{\psi}_{uv}(x_u, y_v) \coloneqq \psi_{uv}(x_u, 1 - y_v)\)? Substituting \(x_v = 1 - y_v\) swaps Column 0 and Column 1 of the matrix:

\[ \psi_{uv}(x_u, x_v) = \begin{array}{c|cc} x_u \setminus x_v & 0 & 1 \\ \hline 0 & A & B \\ 1 & C & D \end{array} \quad \xrightarrow{y_v = 1 - x_v} \quad \widetilde{\psi}_{uv}(x_u, y_v) = \begin{array}{c|cc} x_u \setminus y_v & 0 \;(x_v=1) & 1 \;(x_v=0) \\ \hline 0 & B & A \\ 1 & D & C \end{array} = \begin{pmatrix} A' & B' \\ C' & D' \end{pmatrix}. \]

Now let us compute the new submodularity margin \(\widetilde{\Delta}_{uv} = B' + C' - A' - D'\) of the transformed table \(\widetilde{\psi}_{uv}(x_u, y_v)\):

\[ \widetilde{\Delta}_{uv} = B' + C' - A' - D' = (A + D) - (B + C) = -\Delta_{uv} > 0! \]

Look at the physical meaning of this transformation:

  • Previously, the event \((x_u = 1, x_v = 1)\) (“both \(u\) and \(v\) are in state 1”) placed both vertices on the \(S\)-side of the cut, so no \(u \to v\) edge was severed.
  • After inverting \(y_v = 1 - x_v\), the event \((x_u = 1, x_v = 1)\) corresponds to \((x_u = 1, y_v = 0)\), which places \(u \in S\) and \(v \in T\)! That is a directed \(S \to T\) cut separation across the edge \(u \to v\)!
  • Similarly, the event \((x_u = 0, x_v = 0)\) corresponds to \((x_u = 0, y_v = 1)\), which places \(v \in S\) and \(u \in T\)—a directed \(S \to T\) cut separation across the reverse edge \(v \to u\)!

When we have a whole system of variables \(V\) and pairwise interactions \(E\), we can apply this column flip simultaneously to all edges in \(E\) whenever we can partition \(V = L \sqcup R\) into two shores such that every supermodular edge \((u, v) \in E\) has one endpoint \(u \in L\) (unflipped, \(x_u\)) and one endpoint \(v \in R\) (flipped, \(y_v = 1 - x_v\)).

ImportantTheorem 11.2 (Bipartite Variable Inversion / 二部グラフの片側反転)

Let \(E(x) = \sum_{i \in V} \phi_i(x_i) + \sum_{(u,v) \in E} \psi_{uv}(x_u, x_v)\) be a quadratic pseudo-Boolean energy where every pairwise interaction \((u, v) \in E\) is supermodular (\(A_{uv} + D_{uv} \ge B_{uv} + C_{uv}\)) and the interaction graph \(G = (V, E)\) is bipartite with bipartition \(V = L \sqcup R\).

Define the inverted coordinates \((x_u)_{u \in L} \in \{0, 1\}^L\) and \((y_v)_{v \in R} \in \{0, 1\}^R\) via \(y_v \coloneqq 1 - x_v\) for all \(v \in R\). Then the transformed energy

\[ \widetilde{E}(x_L, y_R) \coloneqq \sum_{u \in L} \phi_u(x_u) + \sum_{v \in R} \phi_v(1 - y_v) + \sum_{(u,v) \in E,\, u \in L,\, v \in R} \psi_{uv}(x_u, 1 - y_v) \]

is ** purely submodular** across every edge \((u, v) \in E\), with non-negative cross-term capacity

\[ \widetilde{\Delta}_{uv} = A_{uv} + D_{uv} - B_{uv} - C_{uv} \ge 0, \]

and can be minimized in polynomial time via a single minimum \(s\)-\(t\) cut.

2.2 Mechanical Cut Compilation Dictionary Under Bipartite Inversion

To make Theorem 11.2 effortless to execute under contest pressure, let us record the exact algebraic-to-graph dictionary for a bipartite pair \((u \in L, v \in R)\) where \(u\) uses standard encoding (\(x_u = [u \in S]\)) and \(v\) uses inverted encoding (\(y_v = [v \in S] = 1 - x_v\), so \(x_v = [v \in T]\)).

1. Unary Terms on \(L\) vs. \(R\) (Crucial Orientation Flip!)

  • Left Shore (\(u \in L\), unflipped: \(x_u = 1 \iff u \in S\), \(x_u = 0 \iff u \in T\)):
    • Penalty \(p > 0\) when \(x_u = 0\): \(p(1 - x_u) \implies\) edge \(S \xrightarrow{p} u\) (severed if \(u \in T\)).
    • Penalty \(q > 0\) when \(x_u = 1\): \(q x_u \implies\) edge \(u \xrightarrow{q} T\) (severed if \(u \in S\)).
  • Right Shore (\(v \in R\), inverted: \(x_v = 1 \iff v \in T\), \(x_v = 0 \iff v \in S\)):
    • Penalty \(p > 0\) when \(x_v = 0\) (i.e., \(y_v = 1 \iff v \in S\)): \(p y_v \implies\) edge \(v \xrightarrow{p} T\) (severed if \(v \in S\)).
    • Penalty \(q > 0\) when \(x_v = 1\) (i.e., \(y_v = 0 \iff v \in T\)): \(q(1 - y_v) \implies\) edge \(S \xrightarrow{q} v\) (severed if \(v \in T\)).

Notice how inverting \(v \in R\) swaps the roles of \(S \to v\) and \(v \to T\)! On \(L\), paying a penalty for \(x_u = 0\) attaches \(u\) to \(S\); on \(R\), paying a penalty for \(x_v = 0\) attaches \(v\) to \(T\).

2. Pairwise Terms Between \(u \in L\) and \(v \in R\)

Because \((x_u = 1, x_v = 1) \iff (x_u = 1, y_v = 0) \iff (u \in S, v \in T)\) and \((x_u = 0, x_v = 0) \iff (x_u = 0, y_v = 1) \iff (v \in S, u \in T)\), each individual cell of \(\psi_{uv}(x_u, x_v)\) compiles directly:

or symmetrically by splitting \(\widetilde{\Delta}_{uv} = \alpha + \beta\) with \(\alpha, \beta \ge 0\) across \(u \xrightarrow{\alpha} v\) and \(v \xrightarrow{\beta} u\).

2.3 Mixed Submodular/Supermodular Graphs: Harary’s Signed Balance Theorem and XOR-2-SAT Gauge Switching

What if a problem contains both submodular edges (\(\Delta_{uv} > 0\), preferring \(x_u = x_v\)) and supermodular edges (\(\Delta_{uv} < 0\), preferring \(x_u \ne x_v\))?

Suppose we allow each vertex \(i \in V\) to choose a binary inversion gauge \(\sigma_i \in \{0, 1\}\), where:

  • \(\sigma_i = 0\) means we keep the standard variable \(z_i = x_i\) (\(i \in S \iff x_i = 1\)),
  • \(\sigma_i = 1\) means we invert the variable \(z_i = 1 - x_i\) (\(i \in S \iff x_i = 0\)).

How does applying gauges \((\sigma_u, \sigma_v)\) affect the cross-term \(\Delta_{uv}\) of edge \((u, v)\)?

  • If \(\sigma_u = \sigma_v\) (either neither endpoint is flipped, or both endpoints are flipped by swapping both rows and columns of the \(2 \times 2\) matrix), the diagonal entries \(\{A, D\}\) stay on the diagonal and the off-diagonal entries \(\{B, C\}\) stay off the diagonal! Thus the new cross-term is \(+\Delta_{uv}\).
  • If \(\sigma_u \ne \sigma_v\) (exactly one endpoint is flipped), the diagonal and off-diagonal entries swap, so the new cross-term is \(-\Delta_{uv}\).

In compact algebraic form, for every edge \((u, v) \in E\):

\[ \widetilde{\Delta}_{uv}(\sigma) = (-1)^{\sigma_u \oplus \sigma_v} \Delta_{uv}. \]

Therefore, a gauge assignment \(\sigma \in \{0, 1\}^V\) makes every edge simultaneously submodular (\(\widetilde{\Delta}_{uv}(\sigma) \ge 0\)) if and only if \(\sigma\) satisfies the XOR-2-SAT linear system over \(\mathbb{F}_2\):

\[ \begin{cases} \sigma_u \oplus \sigma_v = 0 & \text{for every strictly submodular edge } (u, v) \text{ with } \Delta_{uv} > 0, \\ \sigma_u \oplus \sigma_v = 1 & \text{for every strictly supermodular edge } (u, v) \text{ with } \Delta_{uv} < 0. \end{cases} \]

(Edges with \(\Delta_{uv} = 0\) are modular/linear and impose no constraint on \(\sigma_u \oplus \sigma_v\).)

In graph theory, assigning signs \(+\) to submodular edges (\(\Delta_{uv} > 0\)) and \(-\) to supermodular edges (\(\Delta_{uv} < 0\)) turns \((V, E)\) into a signed graph \((G, \operatorname{sgn})\). A classical theorem of Frank Harary characterizes exactly when this XOR-2-SAT system is satisfiable:

ImportantTheorem 11.3 (Harary’s Signed Graph Balance Theorem 1953 & Gauge Switching)

For any quadratic pseudo-Boolean energy \(E(x)\) with non-degenerate pairwise interactions \(E = E^+ \sqcup E^-\) (where \(E^+ = \{(u,v) : \Delta_{uv} > 0\}\) are submodular edges and \(E^- = \{(u,v) : \Delta_{uv} < 0\}\) are supermodular edges), the following three conditions are equivalent:

  1. Variable-Inversion Reducibility: There exists a subset of vertices \(R \subseteq V\) (with gauge \(\sigma_i = [i \in R]\)) such that substituting \(y_v = 1 - x_v\) for all \(v \in R\) makes every pairwise interaction in \(E\) submodular (\(\widetilde{\Delta}_{uv} \ge 0\)).
  2. Harary Balance (No Odd-Negative Cycles): Every simple cycle \(C\) in \((V, E^+ \cup E^-)\) contains an even number of supermodular edges from \(E^-\).
  3. 2-Colorability of Contracted Components: After contracting each connected component of submodular edges \(E^+\) into a single supernode, the remaining supermodular edges \(E^-\) form a bipartite multigraph (with no self-loops).

Moreover, testing this condition and computing the subset \(R = \{i \in V : \sigma_i = 1\}\) takes \(O(|V| + |E|)\) time via a single BFS/DFS 2-coloring on \((V, E^+ \cup E^-)\).

Note that Theorem 11.2 is simply the special case of Theorem 11.3 where \(E^+ = \emptyset\) (all edges are supermodular), so Condition 2 (“every cycle has an even number of edges from \(E^-\)”) reduces to “every cycle has even length”—i.e., \(G\) is bipartite!

2.4 Broken-Gadget Counterexample (FM-11): The Odd-Cycle Barrier (\(K_3\)), QPBO Roof Duality, and Unflipped Unary Attachments

What goes wrong if we violate Theorem 11.2 or 11.3, or if we forget to flip the unary edges on \(R\)? Let us examine both failure modes explicitly.

Failure Mode FM-11a: The Odd-Cycle Barrier (\(K_3\)) and NP-Hardness

Suppose three mutually adjacent items \(\{1, 2, 3\}\) form a triangle \(K_3\), each has selection reward \(+10\), and no two adjacent items may both be selected (\(x_u + x_v \le 1\) for \((u,v) \in \{(1,2), (2,3), (3,1)\}\)).

Each edge is supermodular (\(\Delta_{uv} = -\infty < 0\)). Because \(K_3\) is an odd cycle of length \(3\), the XOR-2-SAT system

\[ \sigma_1 \oplus \sigma_2 = 1, \quad \sigma_2 \oplus \sigma_3 = 1, \quad \sigma_3 \oplus \sigma_1 = 1 \]

sums modulo \(2\) to \(0 = 1\), a contradiction! Regardless of how we Partition \(\{1, 2, 3\} = L \sqcup R\), at least one of the three edges has both endpoints on the same shore (\(\sigma_u = \sigma_v\)), leaving a supermodular interaction \(\Delta_{uv} = -\infty\) that cannot be represented by any non-negative \(s\)-\(t\) cut (Theorem 11.1). Indeed, Maximum Weight Independent Set and Anti-Ferromagnetic Ising Minimization (Max-Cut) on general graphs with odd cycles are NP-hard.

TipBeyond Bipartite Graphs: A Brief Glimpse of QPBO / Roof Duality (Hammer–Hansen–Simeone 1984, Boros & Hammer 2002)

What if a problem or LP relaxation asks us to run a flow/cut algorithm on a non-bipartite supermodular graph anyway? The Quadratic Pseudo-Boolean Optimization (QPBO) construction (Hammer, Hansen, and Simeone 1984; Kolmogorov and Rother 2007) creates two literal nodes for every variable \(i \in V\): an unflipped node \(i^+ \in L\) representing \(x_i\) and a flipped node \(i^- \in R\) representing \(\bar{x}_i = 1 - x_i\).

  • Every submodular edge \((u, v) \in E^+\) is duplicated symmetrically as \(u^+ \to v^+\) and \(v^- \to u^-\).
  • Every supermodular edge \((u, v) \in E^-\) crosses between shores as \(u^+ \to v^-\) and \(v^+ \to u^-\).

Running a single minimum \(s\)-\(t\) cut on this doubled \(2|V|\)-vertex network \(\mathcal{N}_{\text{QPBO}}\) solves the half-integral LP Roof Dual relaxation (\(x_i \in \{0, \frac{1}{2}, 1\}\)), and satisfies two remarkable properties:

  1. Completeness on Balanced Graphs: If \((V, E^+, E^-)\) satisfies Harary’s Balance Theorem 11.3, the doubled network \(\mathcal{N}_{\text{QPBO}}\) disconnects into two isomorphic copies of our Bipartite Variable Inversion cut network, yielding the exact integer optimum!
  2. Persistencies (Strong Autarky): Even on non-bipartite graphs with odd cycles, any variable \(i\) whose two copies land on opposite sides of the minimum cut (\(x_{i^+} = 1 - \bar{x}_{i^-}\), i.e., \(x_i \in \{0, 1\}\) rather than \(\frac{1}{2}\)) is provably fixed to that exact boolean value in at least one global integer optimum! (In Luogu P2774 or HDU 3657, since the grid is bipartite, we never need to double the vertices—we simply place even-parity cells in \(L\) and odd-parity cells in \(R\).)

Failure Mode FM-11b: Toy Trace of Unflipped Unary Attachments on \(R\)

Suppose we have just \(N = 2\) adjacent cells \(u \in L\) (weight \(w_u = 10\)) and \(v \in R\) (weight \(w_v = 7\)) with mutual exclusion \(\neg(x_u = 1 \land x_v = 1)\). Clearly the optimal independent set picks \(u\) alone for profit \(10\) (penalty \(7\) from baseline \(10 + 7 = 17\)).

  • Correct Bipartite Inversion:
    • \(u \in L\): \(x_u = 1 \iff u \in S\). Dropping \(u\) (\(x_u = 0 \iff u \in T\)) costs \(10 \implies\) edge \(S \xrightarrow{10} u\).
    • \(v \in R\): \(y_v = 1 - x_v = 1 \iff v \in S\). Dropping \(v\) (\(x_v = 0 \iff y_v = 1 \iff v \in S\)) costs \(7 \implies\) edge \(v \xrightarrow{7} T\).
    • Mutual exclusion \(\neg(x_u = 1 \land x_v = 1) \iff \neg(u \in S \land v \in T) \implies\) edge \(u \xrightarrow{\infty} v\).
    • The network is a single path \(S \xrightarrow{10} u \xrightarrow{\infty} v \xrightarrow{7} T\). Its minimum cut severs \(v \xrightarrow{7} T\) (capacity \(7\)), leaving \(u, v \in S \implies (x_u = 1, y_v = 1) \implies (x_u = 1, x_v = 0)\), profit \(17 - 7 = 10\). Correct!
  • Broken Gadget (Forgetting to Flip \(v\)’s Unary Attachment):
    • A careless solver writes \(u \xrightarrow{\infty} v\) for the mutual exclusion, but attaches both \(S \xrightarrow{10} u\) and \(S \xrightarrow{7} v\) from the source \(S\) (and nothing to \(T\)!).
    • Now \(T\) is completely unreachable from \(S\), so the minimum \(s\)-\(t\) cut is \(0\), claiming we can pick both \(u\) and \(v\) for profit \(17 - 0 = 17\)! Why? Because attaching \(S \xrightarrow{7} v\) encodes \(v \in S \iff x_v = 1\), under which the edge \(u \xrightarrow{\infty} v\) forbids \((x_u = 1, x_v = 0)\) (an implication \(x_u \le x_v\)) instead of forbidding \((x_u = 1, x_v = 1)\)!

3. Three Canonical Bipartite Inversion Geometries in Non-Graph Problems

In contest problems, the problem statement almost never announces “Here is a bipartite graph \(G = (L \sqcup R, E)\) with supermodular costs.” Instead, the variables represent grid cells, matrix rows and columns, geometric segments, or permutation cycles. Recognizing which of the three canonical bipartite geometries hides inside the statement is half the battle.

3.1 Geometry 1: Chessboard Parity \((r + c) \bmod 2\) on 2D Grids

Whenever binary decisions \(x_{r,c} \in \{0, 1\}\) live on the cells of a 2D grid and every pairwise interaction connects 4-connected orthogonal neighbors \((r, c) \sim (r', c')\) with \(|r - r'| + |c - c'| = 1\), the interaction graph is automatically bipartite via chessboard parity:

\[ L = \{(r, c) : (r + c) \equiv 0 \pmod 2\}, \qquad R = \{(r, c) : (r + c) \equiv 1 \pmod 2\}. \]

Every orthogonal adjacency crosses between an even cell \(u \in L\) and an odd cell \(v \in R\). However, we must distinguish two completely opposite grid regimes:

  1. Supermodular Grid Regime (Same-State Penalty / Mutual Exclusion \(\implies\) INVERT ODD CELLS):
    • Examples: Maximum Weight Independent Set on a grid (Luogu P2774 — 方格取数, HDU 3657 — Game), anti-ferromagnetic zebra coloring where adjacent cells want different colors (AtCoder ABC 193 F — Zebraness), or industrial vs. commercial zoning where differing neighbors earn a bonus (Luogu P1935 — 圈地计划, mixed with submodular terms!).
    • Action: Invert \(y_{r,c} = 1 - x_{r,c}\) on all odd-parity cells \((r + c) \equiv 1 \pmod 2\).
  2. Submodular Grid Regime (Different-State Boundary Penalty \(\implies\) DO NOT INVERT):
    • Examples: Image segmentation (Boykov–Jolly 2001), terrain leveling, or fencing where adjacent cells of different states pay a boundary perimeter penalty \(w \cdot |x_u - x_v|\).
    • Action: Here \(A = D = 0 < B = C = w\) (\(\Delta = 2w > 0\)) is already submodular! Inverting odd cells would destroy submodularity and turn it supermodular!
TipThe Golden Rule of Grid Parity Inversion

Never invert odd grid cells by reflex just because a problem lives on a chessboard! First compute \(\Delta_{uv} = B + C - A - D\) for a single pair of adjacent cells:

  • If \(\Delta_{uv} \ge 0\) (neighbors prefer the same state), keep standard variables on all cells.
  • If \(\Delta_{uv} < 0\) (neighbors prefer opposite states, or cannot both be \(1\)), invert odd-parity cells \((r+c) \equiv 1 \pmod 2\).

3.2 Geometry 2: Row-vs-Column Operations on Matrices

In a second major family of problems, we have an \(H \times W\) matrix \(A_{r,c}\), a binary decision \(x_r \in \{0, 1\}\) for each row \(r \in \{1, \dots, H\}\), and a binary decision \(c_j \in \{0, 1\}\) for each column \(j \in \{1, \dots, W\}\). Every cell \((r, j)\) creates a pairwise interaction between row \(r\) and column \(j\).

Here the interaction graph is the complete bipartite graph \(K_{H, W}\) with \(L = \{\text{Rows } 1..H\}\) and \(R = \{\text{Columns } 1..W\}\).

  • In AtCoder ABC 259 G — Grid Card Game (#086), selecting row \(r\) (\(x_r = 1\)) and column \(j\) (\(c_j = 1\)) simultaneously means cell \((r, j)\) is double-counted (or forbidden if \(A_{r,j} < 0\)). In standard coordinates, the \((x_r, c_j)\) interaction table has \(\Delta_{r,j} = A_{r,j}\) when \(A_{r,j} < 0\) (\(\Delta = -\infty < 0\)) and double-selection overlap \(\Delta = -A_{r,j} < 0\) when \(A_{r,j} > 0\). By inverting the column variables \(y_j = 1 - c_j\) (\(r \in S \iff \text{Row } r \text{ picked}\), \(j \in T \iff \text{Col } j \text{ picked}\)), the joint event \((\text{Row } r \text{ picked}, \text{Col } j \text{ picked})\) becomes the cut event \((r \in S, j \in T)\), which is penalized by a single directed edge \(r \to j\)!
  • In AtCoder ARC 176 E — Max Vector (#088), we have two vectors \(X, Y \in \{1, \dots, V\}^N\) and clauses of the form \((\forall i, X_i \ge A_{k,i}) \lor (\forall i, Y_i \ge A_{k,i})\). By placing the unary threshold chains of \(X\) on the unflipped Left shore (\(x_{i,t} = [X_i \ge t] = 1 \iff (i,t)_X \in S\)) and the unary threshold chains of \(Y\) on the inverted Right shore (\(y_{i,t} = [Y_i < t] = 1 \iff (i,t)_Y \in S\)), every clause disjunction turns into an implication from \(R\) to \(L\) via a single clause vertex!

3.3 Geometry 3: Two-Family Disjoint Object Pairs (Segments & Permutation Cycles)

The subtlest and most rewarding geometry occurs when the vertices of \(L\) and \(R\) are emergent structural objects that must first be extracted from the problem’s constraints:

  1. Horizontal vs. Vertical Dominoes (Codeforces 1404 E — Bricks): Merging adjacent black cells vertically along shared horizontal edges vs. horizontally along shared vertical edges. No unit cell may be merged both vertically and horizontally, creating a bipartite conflict graph between horizontal inner borders \(L\) and vertical inner borders \(R\).
  2. Cycle Decompositions of Two Permutations (AtCoder AGC 038 F — Two Permutations, #087): Given two permutations \(P\) and \(Q\) of \(\{0, \dots, N-1\}\), each permutation decomposes \(\{0, \dots, N-1\}\) into disjoint directed cycles \(\mathcal{C}_P\) and \(\mathcal{C}_Q\). As we now prove in our flagship case study, the independent binary choices live on the \(P\)-cycles \(L = \mathcal{C}_P\) and \(Q\)-cycles \(R = \mathcal{C}_Q\), and each index \(i \in \{0, \dots, N-1\}\) induces a supermodular interaction between the unique cycle \(C \in \mathcal{C}_P\) containing \(i\) and the unique cycle \(D \in \mathcal{C}_Q\) containing \(i\).

4. Flagship Deep-Dive Case Study: AtCoder AGC 038 F — Two Permutations (#087)

NoteProblem Statement — AtCoder AGC 038 F: Two Permutations

Judge: AtCoder agc038_f | Constraints: \(N \le 10^5\), Time Limit \(2.0\text{ s}\), Memory \(1024\text{ MB}\).

You are given two permutations \(P = (P_0, P_1, \dots, P_{N-1})\) and \(Q = (Q_0, Q_1, \dots, Q_{N-1})\) of \(\{0, 1, \dots, N-1\}\).

You must construct two new permutations \(A = (A_0, \dots, A_{N-1})\) and \(B = (B_0, \dots, B_{N-1})\) of \(\{0, 1, \dots, N-1\}\) satisfying:

  • For every \(i \in \{0, \dots, N-1\}\), either \(A_i = i\) or \(A_i = P_i\).
  • For every \(i \in \{0, \dots, N-1\}\), either \(B_i = i\) or \(B_i = Q_i\).

Maximize the number of indices \(i \in \{0, \dots, N-1\}\) such that \(A_i \ne B_i\).

Let us apply our mandatory 4-Step English-to-Graph Compilation Pipeline from first principles.

4.1 Step 1: Non-Graph Diagnostic Signal (Recognition)

  1. Constraint & Structural Clues:
    • \(N \le 10^5\): A general dense flow network would be too slow, so if this is a minimum-cut problem, the resulting network must have \(O(N)\) vertices and \(O(N)\) unit-capacity edges so Dinic’s algorithm runs in \(O(N \sqrt{N})\) time.
    • At each index \(i\), \(A_i \in \{i, P_i\}\) and \(B_i \in \{i, Q_i\}\) look like \(2N\) local binary choices. However, \(A\) and \(B\) must be valid permutations (bijections)!
  2. Why Naive Greedy and DP Fail:
    • Choosing \(A_i = P_i\) at index \(i\) consumes the value \(P_i\) in the image of \(A\), forcing \(A_{P_i}\) to also shift to \(P_{P_i}\), and so on around the entire cycle of \(P\).
    • Meanwhile, \(B_i \in \{i, Q_i\}\) propagates around the cycle of \(Q\) containing \(i\). Because \(P\) and \(Q\) are completely arbitrary permutations, their cycle decompositions \(\mathcal{C}_P\) and \(\mathcal{C}_Q\) intersect in an arbitrary bipartite multigraph of treewidth \(\Omega(N)\), ruling out tree DP or greedy cycle-by-cycle assignment.

4.2 Step 2A: The Cycle Rigidity Lemma (Intermediate Algebraic Representation)

First, let us characterize all valid permutations \(A\) satisfying \(A_i \in \{i, P_i\}\) for all \(i\). Decompose the permutation \(P\) into disjoint directed cycles \(\mathcal{C}_P = \{C_1, C_2, \dots, C_{|\mathcal{C}_P|}\}\).

ImportantLemma 11.4 (Cycle Rigidity of Sub-Permutations)

A function \(A : \{0, \dots, N-1\} \to \{0, \dots, N-1\}\) satisfying \(A_i \in \{i, P_i\}\) for all \(i\) is a valid permutation (bijection) if and only if, on every cycle \(C \in \mathcal{C}_P\), either:

  • Choice \(x_C = 0\) (Identity / Stay): \(A_i = i\) for all \(i \in C\), or
  • Choice \(x_C = 1\) (Shift / Rotate): \(A_i = P_i\) for all \(i \in C\).
NoteProof of Lemma 11.4

Consider any cycle \(C = (i_0 \to i_1 \to \dots \to i_{k-1} \to i_0)\) of \(P\), where \(P_{i_t} = i_{(t+1) \bmod k}\). For every \(i \in C\), both \(i\) and \(P_i\) belong to \(C\), so \(A\) maps \(C\) into \(C\), and since \(C\) is finite, \(A|_C : C \to C\) must be a bijection.

Suppose \(A_{i_t} = P_{i_t} = i_{t+1}\) for some \(i_t \in C\). Since \(A|_C\) is injective and the only two elements of \(C\) whose allowed targets include \(i_{t+1}\) are \(i_t\) (via \(P_{i_t} = i_{t+1}\)) and \(i_{t+1}\) (via \(i_{t+1} = i_{t+1}\)), consuming \(A_{i_t} = i_{t+1}\) forbids \(A_{i_{t+1}} = i_{t+1}\)! Thus \(A_{i_{t+1}}\) is forced to equal \(P_{i_{t+1}} = i_{t+2}\). Inducting around the finite cycle \(C\), if any element \(i \in C\) shifts (\(A_i = P_i \ne i\)), then every element \(i \in C\) must shift (\(A_i = P_i\)). Conversely, if no element shifts, \(A_i = i\) for all \(i \in C\). \(\square\)

By Lemma 11.4, the entire problem reduces to choosing:

  • One binary variable \(x_C \in \{0, 1\}\) for each \(P\)-cycle \(C \in \mathcal{C}_P\): \[ x_C = 0 \implies \forall i \in C,\; A_i = i; \qquad x_C = 1 \implies \forall i \in C,\; A_i = P_i. \]
  • One binary variable \(y_D \in \{0, 1\}\) for each \(Q\)-cycle \(D \in \mathcal{C}_Q\): \[ y_D = 0 \implies \forall i \in D,\; B_i = i; \qquad y_D = 1 \implies \forall i \in D,\; B_i = Q_i. \]

4.3 Step 2B: The 5-Case Collision Penalty Table and Why It Is Supermodular

We want to maximize the number of indices \(i\) where \(A_i \ne B_i\). Equivalently, starting from the baseline of \(N\) total indices, we want to minimize the number of collisions (indices \(i\) where \(A_i = B_i\)):

\[ \max_{x, y} \sum_{i=0}^{N-1} [A_i \ne B_i] \;=\; N - \min_{x, y} \sum_{i=0}^{N-1} \psi_i(x_{C(i)}, y_{D(i)}), \]

where \(C(i) \in \mathcal{C}_P\) and \(D(i) \in \mathcal{C}_Q\) denote the unique \(P\)-cycle and \(Q\)-cycle containing index \(i\), and \(\psi_i(x_C, y_D) \coloneqq [A_i(x_C) = B_i(y_D)] \in \{0, 1\}\) is the collision indicator at index \(i\).

Let us classify every index \(i \in \{0, \dots, N-1\}\) into 5 mutually exclusive cases based on whether \(P_i = i\), \(Q_i = i\), and \(P_i = Q_i\), and write out the \(2 \times 2\) collision matrix \(\psi_i(x_C, y_D) = \begin{pmatrix} \psi_i(0,0) & \psi_i(0,1) \\ \psi_i(1,0) & \psi_i(1,1) \end{pmatrix}\):

  1. Case 1: \(P_i = i\) and \(Q_i = i\):
    • Regardless of \(x_C \in \{0, 1\}\) and \(y_D \in \{0, 1\}\), we always have \(A_i = i\) and \(B_i = i\), so \(A_i = B_i\) is unavoidable!
    • Collision matrix: \(\begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix}\) (constant penalty \(+1\) for all choices; \(\Delta_i = 0\)).
  2. Case 2: \(P_i = i\) and \(Q_i \ne i\):
    • Here \(A_i = i\) always, while \(B_i = i\) if \(y_D = 0\) and \(B_i = Q_i \ne i\) if \(y_D = 1\).
    • Collision occurs iff \(y_D = 0\): penalty \(1 - y_D\).
    • Collision matrix: \(\begin{pmatrix} 1 & 0 \\ 1 & 0 \end{pmatrix}\) (pure unary penalty on \(y_D = 0\); \(\Delta_i = 0\)).
  3. Case 3: \(P_i \ne i\) and \(Q_i = i\):
    • Here \(B_i = i\) always, while \(A_i = i\) if \(x_C = 0\) and \(A_i = P_i \ne i\) if \(x_C = 1\).
    • Collision occurs iff \(x_C = 0\): penalty \(1 - x_C\).
    • Collision matrix: \(\begin{pmatrix} 1 & 1 \\ 0 & 0 \end{pmatrix}\) (pure unary penalty on \(x_C = 0\); \(\Delta_i = 0\)).
  4. Case 4: \(P_i \ne i\), \(Q_i \ne i\), and \(P_i \ne Q_i\):
    • If \((x_C, y_D) = (0, 0)\), then \(A_i = i\) and \(B_i = i \implies\) collision (\(+1\))!
    • In all other three states \((0, 1), (1, 0), (1, 1)\), the values are \((i, Q_i)\), \((P_i, i)\), and \((P_i, Q_i)\), none of which are equal!
    • Collision matrix: \[ \psi_i(x_C, y_D) = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix} \quad \Longrightarrow \quad \Delta_i = 0 + 0 - 1 - 0 = -1 < 0 \quad (\textbf{SUPERMODULAR!}). \]
  5. Case 5: \(P_i \ne i\), \(Q_i \ne i\), and \(P_i = Q_i\):
    • If \((x_C, y_D) = (0, 0)\), then \(A_i = i = B_i \implies\) collision (\(+1\))!
    • If \((x_C, y_D) = (1, 1)\), then \(A_i = P_i = Q_i = B_i \implies\) collision (\(+1\))!
    • If \((x_C, y_D) \in \{(0, 1), (1, 0)\}\), then \(A_i \ne B_i\) (no collision).
    • Collision matrix: \[ \psi_i(x_C, y_D) = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix} \quad \Longrightarrow \quad \Delta_i = 0 + 0 - 1 - 1 = -2 < 0 \quad (\textbf{SUPERMODULAR!}). \]

Look at Cases 4 and 5: both have strictly negative submodularity margins (\(\Delta_i = -1\) and \(\Delta_i = -2\)) because collisions happen when \(x_C\) and \(y_D\) agree (\(x_C = y_D = 0\) or \(x_C = y_D = 1\))!

4.4 Step 3: Rescuing Submodularity via Bipartite Variable Inversion (\(\tilde{y}_D = 1 - y_D\)) and the 1-Cycle Aliasing Trick

Why can we rescue Cases 4 and 5 immediately? Because every pairwise interaction at index \(i\) connects a \(P\)-cycle \(C(i) \in \mathcal{C}_P\) and a \(Q\)-cycle \(D(i) \in \mathcal{C}_Q\)! There is never an interaction between two \(P\)-cycles or between two \(Q\)-cycles. Thus the interaction graph is naturally bipartite with Left shore \(L = \mathcal{C}_P\) and Right shore \(R = \mathcal{C}_Q\)!

Applying Theorem 11.2, we keep standard encoding on \(L = \mathcal{C}_P\) and invert the encoding on \(R = \mathcal{C}_Q\):

  • For \(C \in \mathcal{C}_P\): \[ C \in S \iff x_C = 1 \text{ (shift } A_i = P_i\text{)}, \qquad C \in T \iff x_C = 0 \text{ (stay } A_i = i\text{)}. \]
  • For \(D \in \mathcal{C}_Q\), define \(\tilde{y}_D \coloneqq 1 - y_D\): \[ D \in S \iff \tilde{y}_D = 1 \iff y_D = 0 \text{ (stay } B_i = i\text{)}, \qquad D \in T \iff \tilde{y}_D = 0 \iff y_D = 1 \text{ (shift } B_i = Q_i\text{)}. \]

Look at what happens to the collision events under \((x_C, \tilde{y}_D)\):

  • Collision at \((x_C = 0, y_D = 0)\) (“both stay at \(i\)”) \(\iff (x_C = 0, \tilde{y}_D = 1) \iff (D \in S, C \in T) \implies\) a directed unit-capacity edge \(D(i) \xrightarrow{1} C(i)\)!
  • Collision at \((x_C = 1, y_D = 1)\) (“both shift to \(P_i = Q_i\)”) \(\iff (x_C = 1, \tilde{y}_D = 0) \iff (C \in S, D \in T) \implies\) a directed unit-capacity edge \(C(i) \xrightarrow{1} D(i)\)!

TipThe 1-Cycle Aliasing Trick (Unifying All 5 Cases into 2 Rules!)

Notice something magical in Table 11.3:

  • What if \(P_i = i\)? Then \(C(i) = \{i\}\) is a 1-cycle (fixed point) of \(P\), so \(A_i = i\) regardless of whether \(x_{C(i)} = 0\) or \(1\). In our cut interpretation, \(C(i)\) acts as if it is permanently fixed to \(x_{C(i)} = 0\) (\(C(i) \equiv T\))!
  • What if \(Q_i = i\)? Then \(D(i) = \{i\}\) is a 1-cycle (fixed point) of \(Q\), so \(B_i = i\) regardless of \(y_{D(i)}\). In our inverted cut interpretation, \(D(i)\) acts as if it is permanently fixed to \(y_{D(i)} = 0 \iff \tilde{y}_{D(i)} = 1\) (\(D(i) \equiv S\))!

Look at what happens if we simply alias every 1-cycle of \(P\) directly to the sink \(T\) (\(C(i) \gets T\) whenever \(P_i = i\)) and alias every 1-cycle of \(Q\) directly to the source \(S\) (\(D(i) \gets S\) whenever \(Q_i = i\)):

  • Rule A (Stay-Stay Collision \(A_i = B_i = i\)): For every \(i \in \{0, \dots, N-1\}\), add a unit edge \(D(i) \xrightarrow{1} C(i)\)!
    • In Case 1 (\(P_i = Q_i = i\)), this is \(S \xrightarrow{1} T\) (unavoidable \(+1\) cut!).
    • In Case 2 (\(P_i = i, Q_i \ne i\)), since \(C(i) = T\), this automatically becomes \(D(i) \xrightarrow{1} T\)!
    • In Case 3 (\(P_i \ne i, Q_i = i\)), since \(D(i) = S\), this automatically becomes \(S \xrightarrow{1} C(i)\)!
    • In Cases 4 & 5 (\(P_i \ne i, Q_i \ne i\)), this is \(D(i) \xrightarrow{1} C(i)\)!
  • Rule B (Shift-Shift Collision \(A_i = P_i = Q_i = B_i \ne i\)): Whenever \(P_i = Q_i \ne i\) (Case 5), also add a unit edge \(C(i) \xrightarrow{1} D(i)\)!

This 1-cycle aliasing trick collapses all 5 cases into 4 lines of code with zero casework bugs!

Complexity Proof: Why Dinic Runs in \(O(N \sqrt{N})\) Time

How many vertices and edges are in \(\mathcal{N}\)?

  • Every cycle of length \(\ge 2\) in \(P\) or \(Q\) creates \(1\) vertex, so \(|V| \le 2 + \lfloor N/2 \rfloor + \lfloor N/2 \rfloor = N + 2\).
  • Each index \(i \in \{0, \dots, N-1\}\) creates at most \(2\) directed edges of unit capacity \(1\), so \(|E| \le 2N\) and total capacity from \(S\) is at most \(N\).
  • Even more strongly, every internal vertex \(C \in \mathcal{C}_P\) has \(|C|\) incident indices, and on a network with \(O(N)\) vertices and \(O(N)\) unit-capacity edges, Dinic’s blocking-flow algorithm terminates in at most \(O(\sqrt{N})\) phases, taking \(O(N \sqrt{N})\) worst-case time (running in < 35 ms for \(N = 10^5\)).
// AtCoder AGC 038 F — Two Permutations (#087)
// Bipartite Variable Inversion on Cycle Decompositions + 1-Cycle Aliasing
// Time Complexity: O(N sqrt(N)) via Dinic on unit-capacity network
#include <bits/stdc++.h>
using namespace std;

struct Dinic {
    struct Edge { int to, rev, cap; };
    int n;
    vector<vector<Edge>> adj;
    vector<int> level, ptr;

    Dinic(int n) : n(n), adj(n), level(n), ptr(n) {}

    void add_edge(int u, int v, int cap) {
        adj[u].push_back({v, (int)adj[v].size(), cap});
        adj[v].push_back({u, (int)adj[u].size() - 1, 0});
    }

    bool bfs(int s, int t) {
        fill(level.begin(), level.end(), -1);
        level[s] = 0;
        queue<int> q;
        q.push(s);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (auto &e : adj[u]) {
                if (e.cap > 0 && level[e.to] == -1) {
                    level[e.to] = level[u] + 1;
                    q.push(e.to);
                }
            }
        }
        return level[t] != -1;
    }

    int dfs(int u, int t, int pushed) {
        if (pushed == 0 || u == t) return pushed;
        for (int &cid = ptr[u]; cid < (int)adj[u].size(); ++cid) {
            auto &e = adj[u][cid];
            if (level[u] + 1 != level[e.to] || e.cap == 0) continue;
            int tr = dfs(e.to, t, min(pushed, e.cap));
            if (tr == 0) continue;
            e.cap -= tr;
            adj[e.to][e.rev].cap += tr;
            return tr;
        }
        return 0;
    }

    int max_flow(int s, int t) {
        int flow = 0;
        while (bfs(s, t)) {
            fill(ptr.begin(), ptr.end(), 0);
            while (int pushed = dfs(s, t, 1e9)) flow += pushed;
        }
        return flow;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    if (!(cin >> N)) return 0;
    vector<int> P(N), Q(N);
    for (int i = 0; i < N; ++i) cin >> P[i];
    for (int i = 0; i < N; ++i) cin >> Q[i];

    int S = 0, T = 1, nodes = 2;
    vector<int> cycP(N, -1), cycQ(N, -1);

    // 1-Cycle Aliasing:
    // Fixed points of P (P[i] == i) always stay at i (x_C = 0 <=> aliased to T).
    // Fixed points of Q (Q[i] == i) always stay at i (y_D = 0 <=> y_tilde_D = 1 <=> aliased to S).
    for (int i = 0; i < N; ++i) {
        if (P[i] == i) cycP[i] = T;
        else if (cycP[i] == -1) {
            int id = nodes++;
            for (int cur = i; cycP[cur] == -1; cur = P[cur]) cycP[cur] = id;
        }
        if (Q[i] == i) cycQ[i] = S;
        else if (cycQ[i] == -1) {
            int id = nodes++;
            for (int cur = i; cycQ[cur] == -1; cur = Q[cur]) cycQ[cur] = id;
        }
    }

    Dinic dinic(nodes);
    int unavoidable = 0;
    for (int i = 0; i < N; ++i) {
        if (P[i] == i && Q[i] == i) {
            unavoidable++; // Case 1: S -> T direct collision
            continue;
        }
        // Rule A: Stay-stay collision (A_i = i and B_i = i) <=> D(i) in S and C(i) in T
        dinic.add_edge(cycQ[i], cycP[i], 1);
        // Rule B: Shift-shift collision (A_i = P_i = Q_i = B_i != i) <=> C(i) in S and D(i) in T
        if (P[i] == Q[i] && P[i] != i) {
            dinic.add_edge(cycP[i], cycQ[i], 1);
        }
    }

    int min_collisions = unavoidable + dinic.max_flow(S, T);
    cout << (N - min_collisions) << "\n";
    return 0;
}

Compute \(\Delta_{uv} = B + C - A - D\).
  2. Step 2 — Form the Signed Interaction Graph & Solve the XOR-2-SAT Gauge System: Mark every edge with \(\Delta_{uv} > 0\) as even (\(0\)) and every edge with \(\Delta_{uv} < 0\) as odd (\(1\)). Check whether the variables can be partitioned into \(V = L \sqcup R\) (\(\sigma_u = 0\) on \(L\), \(\sigma_v = 1\) on \(R\)) via Harary’s Balance Theorem 11.3:
    • 2D Grid with 4-connected supermodular interactions: \(L = \{\text{even } (r+c)\}\), \(R = \{\text{odd } (r+c)\}\).
    • Matrix with row-vs-column interactions: \(L = \{\text{Rows}\}\), \(R = \{\text{Columns}\}\).
    • Two families of objects (bricks, cycles, clauses): \(L = \text{Family 1}\), \(R = \text{Family 2}\).
  3. Step 3 — Flip the Right Shore (\(y_v = 1 - x_v\)) on Both Unary and Pairwise Terms:
    • On \(u \in L\): \(u \in S \iff x_u = 1\), \(u \in T \iff x_u = 0\).
      • Penalty for \(x_u = 0 \implies S \to u\); penalty for \(x_u = 1 \implies u \to T\).
    • On \(v \in R\): \(v \in S \iff y_v = 1 \iff x_v = 0\), \(v \in T \iff y_v = 0 \iff x_v = 1\).
      • Penalty for \(x_v = 0 \implies v \to T\); penalty for \(x_v = 1 \implies S \to v\).
    • Across \((u \in L, v \in R)\):
      • Penalty for \((x_u = 1, x_v = 1) \iff (u \in S, v \in T) \implies u \to v\).
      • Penalty for \((x_u = 0, x_v = 0) \iff (v \in S, u \in T) \implies v \to u\).
  4. Step 4 — Verify the All-Zero and All-One Cut Sanity Checks on a \(N \le 4\) Trace: Before coding, test two trivial cuts on paper:
    • If \(V_S = \{S\}\) (all nodes in \(T\)), then \(x_u = 0\) on \(L\) and \(x_v = 1\) on \(R\). Does the sum of severed \(S \to \cdot\) edges equal the true cost of choosing \(R\) and dropping \(L\)?
    • If \(V_T = \{T\}\) (all nodes in \(S\)), then \(x_u = 1\) on \(L\) and \(x_v = 0\) on \(R\). Does the sum of severed \(\cdot \to T\) edges equal the true cost of choosing \(L\) and dropping \(R\)?

#081 (SS-1): Luogu P2774 — 方格取数问题 (Grid Number Selection)

  • Judge: Luogu P2774 ([BJWC2008 / 网络流24题])
  • Constraints: \(1 \le M, N \le 100\), cell values \(w_{r,c} \in [0, 10^5]\). Time Limit: \(1.0\text{ s}\).
  • Statement Summary: Given an \(M \times N\) grid of non-negative integers \(w_{r,c}\), select a subset of cells such that no two selected cells share a common edge, maximizing the sum of values of the selected cells.

1. Non-Graph Diagnostic Signal (Step 1)

With \(M, N \le 100\), bitmask profile DP takes \(O(N \cdot 2^M)\) time, which explodes for \(M = 100\). Because the grid has \(V = MN \le 10^4\) cells and the conflict constraint (“cannot pick two orthogonally adjacent cells”) only links cells of opposite chessboard parity \((r + c) \bmod 2\), this is Maximum Weight Independent Set on a bipartite graph.

2. Intermediate Algebraic Representation (Step 2)

Let \(x_{r,c} \in \{0, 1\}\) indicate whether cell \((r, c)\) is selected (\(1\)) or dropped (\(0\)). Starting from the ideal baseline \(\sum_{r,c} w_{r,c}\), we minimize the lost weight plus hard conflict penalties:

\[ \max_{x \in \{0,1\}^{MN}} \sum_{u} w_u x_u \;=\; \sum_{u} w_u - \min_{x \in \{0,1\}^{MN}} \left( \sum_{u} w_u (1 - x_u) + \sum_{(u,v) \in E} \infty \cdot x_u x_v \right). \]

For each adjacent pair \((u, v) \in E\), the penalty table \(\psi_{uv}(x_u, x_v) = \begin{pmatrix} 0 & 0 \\ 0 & \infty \end{pmatrix}\) has \(\Delta_{uv} = -\infty < 0\) (supermodular).

3. Reverse-Engineering Scratchpad (Step 3)

Partition the grid by chessboard parity: \(L = \{(r, c) : (r + c) \bmod 2 = 0\}\) and \(R = \{(r, c) : (r + c) \bmod 2 = 1\}\). Invert \(y_v = 1 - x_v\) for all \(v \in R\):

\[ \min_{x_L, y_R} \left( \sum_{u \in L} w_u (1 - x_u) + \sum_{v \in R} w_v y_v + \sum_{(u,v) \in E,\, u \in L,\, v \in R} \infty \cdot x_u (1 - y_v) \right). \]

  • For each \(u \in L\): \(w_u(1 - x_u) \implies\) edge \(S \xrightarrow{w_u} u\).
  • For each \(v \in R\): \(w_v y_v \implies\) edge \(v \xrightarrow{w_v} T\).
  • For each orthogonal adjacency \((u \in L, v \in R)\): \(\infty \cdot x_u(1 - y_v) \implies\) directed edge \(u \xrightarrow{\infty} v\).

4. Hand-Checkable Toy Trace (Step 4)

Consider a \(2 \times 2\) grid \(\begin{pmatrix} 10 & 8 \\ 7 & 12 \end{pmatrix}\) with total weight \(37\).

  • \(L = \{(1,1)=10,\; (2,2)=12\}\) (even sum \(22\)), \(R = \{(1,2)=8,\; (2,1)=7\}\) (odd sum \(15\)).
  • Minimum cut severs \((1,2) \xrightarrow{8} T\) and \((2,1) \xrightarrow{7} T\) of total capacity \(15\), leaving all four cells in \(S\), which decodes to \(x_{1,1} = x_{2,2} = 1\) and \(x_{1,2} = x_{2,1} = 0\), achieving maximum sum \(37 - 15 = 22\).

How can you make “both \(u\) and \(v\) are chosen” correspond to opposite sides of the cut?

NoteHint 3 — Edge Capacities and Direction

using namespace std;

const long long INF = 1e18;

struct Dinic {
    struct Edge { int to, rev; long long cap; };
    int n;
    vector<vector<Edge>> adj;
    vector<int> level, ptr;

    Dinic(int n) : n(n), adj(n), level(n), ptr(n) {}

    void add_edge(int u, int v, long long cap) {
        adj[u].push_back({v, (int)adj[v].size(), cap});
        adj[v].push_back({u, (int)adj[u].size() - 1, 0});
    }

    bool bfs(int s, int t) {
        fill(level.begin(), level.end(), -1);
        level[s] = 0;
        queue<int> q;
        q.push(s);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (auto &e : adj[u]) {
                if (e.cap > 0 && level[e.to] == -1) {
                    level[e.to] = level[u] + 1;
                    q.push(e.to);
                }
            }
        }
        return level[t] != -1;
    }

    long long dfs(int u, int t, long long pushed) {
        if (pushed == 0 || u == t) return pushed;
        for (int &cid = ptr[u]; cid < (int)adj[u].size(); ++cid) {
            auto &e = adj[u][cid];
            if (level[u] + 1 != level[e.to] || e.cap == 0) continue;

            if (tr == 0) continue;
            e.cap -= tr;
            adj[e.to][e.rev].cap += tr;
            return tr;
        }
        return 0;
    }

        long long flow = 0;
        while (bfs(s, t)) {
            fill(ptr.begin(), ptr.end(), 0);
            while (long long pushed = dfs(s, t, INF)) flow += pushed;
        }
        return flow;
    }

#083 (Int-1): Luogu P1935 / P1791 [国家集训队] — 圈地计划 (Fencing Plan)

  • Judge: Luogu P1935 / Luogu P1791
  • Constraints: \(N, M \le 100\). Time Limit: \(1.0\text{ s}\).
  • Statement Summary: Each cell \((r, c)\) of an \(N \times M\) grid must be zoned as either Industrial (\(x_u = 1\)), earning profit \(A_u\), or Commercial (\(x_u = 0\)), earning profit \(B_u\). Furthermore, for every orthogonally adjacent pair of cells \((u, v)\), if they receive different zones (\(x_u \ne x_v\)), they earn an additional synergy bonus \(C_u + C_v\). 1. Non-Graph Diagnostic Signal (Step 1)

At first glance, this looks like standard 2-label image segmentation (Boykov–Jolly). Look closely at the neighbor condition: the bonus \(w_{uv} = C_u + C_v\) is awarded when \(x_u \ne x_v\) (different zones), which means choosing the same zone (\(x_u = x_v\)) loses the bonus \(w_{uv}\)!

2. Intermediate Algebraic Representation (Step 2)

Starting from the maximum theoretical baseline

\[ \text{Total} = \sum_{u} (A_u + B_u) + \sum_{(u,v) \in E} (C_u + C_v), \]

every cell \(u\) loses \(B_u\) if \(x_u = 1\) and loses \(A_u\) if \(x_u = 0\), while every adjacent edge \((u, v) \in E\) with weight \(w_{uv} = C_u + C_v\) has the lost-bonus penalty matrix:

\[ \psi_{uv}(x_u, x_v) = \begin{array}{c|cc} x_u \setminus x_v & 0 & 1 \\ \hline 0 & w_{uv} & 0 \\ 1 & 0 & w_{uv} \end{array} \quad \Longrightarrow \quad \Delta_{uv} = 0 + 0 - w_{uv} - w_{uv} = -2w_{uv} < 0 \quad (\textbf{SUPERMODULAR!}). \]

3. Reverse-Engineering Scratchpad (Step 3)

Because all interactions are 4-connected grid adjacencies, we partition by chessboard parity \(L = \{(r+c) \text{ even}\}\), \(R = \{(r+c) \text{ odd}\}\), and invert \(y_v = 1 - x_v\) on \(R\):

  • On \(u \in L\) (\(u \in S \iff x_u = 1\) Industrial, \(u \in T \iff x_u = 0\) Commercial):
    • Choosing Industrial (\(u \in S\)) forfeits Commercial profit \(B_u \implies\) edge \(u \xrightarrow{B_u} T\).
    • Choosing Commercial (\(u \in T\)) forfeits Industrial profit \(A_u \implies\) edge \(S \xrightarrow{A_u} u\) (or equivalently connect \(S \xrightarrow{A_u} u\) and \(u \xrightarrow{B_u} T\)).
  • On \(v \in R\) (\(v \in S \iff y_v = 1 \iff x_v = 0\) Commercial, \(v \in T \iff y_v = 0 \iff x_v = 1\) Industrial):
    • Choosing Commercial (\(v \in S\)) forfeits Industrial profit \(A_v \implies\) edge \(v \xrightarrow{A_v} T\) ( role of \(A_v, B_v\) swapped!).
    • Choosing Industrial (\(v \in T\)) forfeits Commercial profit \(B_v \implies\) edge \(S \xrightarrow{B_v} v\).
  • Across \((u \in L, v \in R)\):
    • Same original zone \((x_u = x_v)\) now means opposite cut sides \((x_u \ne y_v)\)!
    • Penalty \(w_{uv} = C_u + C_v\) for \((u \in S, v \in T)\) and \((v \in S, u \in T) \implies\) bidirectional edge \(u \xleftrightarrow{C_u + C_v} v\)!

4. Hand-Checkable Toy Trace (Step 4)

For a \(1 \times 2\) grid with \(u = (1,1) \in L\) (\(A_u = 10, B_u = 2\)) and \(v = (1,2) \in R\) (\(A_v = 9, B_v = 1\)), and \(C_u + C_v = 5\):

  • Total baseline \(= (10 + 2) + (9 + 1) + 5 = 27\).
  • If both are Industrial (\(x_u = x_v = 1\)), true profit is \(10 + 9 + 0 = 19\). In our cut, \(u \in S\) and \(v \in T\), which severs \(u \xrightarrow{B_u=2} T\), \(S \xrightarrow{B_v=1} v\), and \(u \xrightarrow{5} v\), for cut cost \(2 + 1 + 5 = 8 \implies 27 - 8 = 19\).
  • If \(u\) is Industrial (\(x_u = 1 \iff u \in S\)) and \(v\) is Commercial (\(x_v = 0 \iff v \in S\)), both \(u, v \in S\)! Only \(u \xrightarrow{B_u=2} T\) and \(v \xrightarrow{A_v=9} T\) are severed, for cut cost \(2 + 9 = 11 \implies 27 - 11 = 16\). Wait—why wasn’t \(u \leftrightarrow v\) severed? Because \(u\) and \(v\) have different original zones, so they keep the synergy bonus \(5\) (\(10 + 1 + 5 = 16\))!
NoteHint 1 — Spot the Anti-Ferromagnetic Trap

In standard segmentation, adjacent cells pay a penalty when they have different labels. Here, adjacent cells lose the bonus \(C_u + C_v\) when they have the same label! Why does that make \(\Delta_{uv} < 0\)?

NoteHint 2 — Invert Odd Chessboard Cells

On even cells \((r+c) \equiv 0 \pmod 2\), let \(S\) mean Industrial and \(T\) mean Commercial. On odd cells \((r+c) \equiv 1 \pmod 2\), flip the meaning: let \(S\) mean Commercial and \(T\) mean Industrial!

NoteHint 3 — Swap Source/Sink Capacities on Odd Cells

Because the meaning of \(S\) and \(T\) is reversed on odd cells, an odd cell \(v\) has \(S \xrightarrow{B_v} v\) and \(v \xrightarrow{A_v} T\) (whereas an even cell \(u\) has \(S \xrightarrow{A_u} u\) and \(u \xrightarrow{B_u} T\)), and every adjacent pair \((u, v)\) gets a bidirectional edge of capacity \(C_u + C_v\).

#084 (Int-2): Luogu P5038 [SCOI2012] — 奇怪的游戏 (Strange Game)

  • Judge: Luogu P5038
  • Constraints: \(T \le 10\) testcases, \(N, M \le 40\), initial integers \(a_{r,c} \in [1, 10^9]\). Time Limit: \(1.0\text{ s}\).
  • Statement Summary: Given an \(N \times M\) grid with initial integers \(a_{r,c}\), in one operation you may pick any two orthogonally adjacent cells and increment both of their values by \(+1\). Find the minimum number of operations required to make all cells in the grid equal to the same final integer \(X\), or output -1 if impossible.

1. Non-Graph Diagnostic Signal (Step 1)

Every operation increments two orthogonally adjacent cells by \(+1\). On a chessboard coloring \(B = \{(r+c) \text{ even}\}\) and \(W = \{(r+c) \text{ odd}\}\), every operation adds \(+1\) to one black cell and one white cell! This immediately couples a global linear parity invariant with a bipartite flow/cut feasibility test.

2. Intermediate Algebraic Representation (Step 2)

Let \(n_B = |B|\), \(n_W = |W|\) be the counts of black and white cells, and \(S_B = \sum_{u \in B} a_u\), \(S_W = \sum_{v \in W} a_v\) be their initial sums. Suppose all cells reach final value \(X \ge \max_{r,c} a_{r,c}\). Then the total increments on \(B\) and \(W\) must be equal:

\[ \sum_{u \in B} (X - a_u) = \sum_{v \in W} (X - a_v) \quad \Longleftrightarrow \quad (n_B - n_W) X = S_B - S_W, \]

and the total number of operations is \(\sum_{u \in B} (X - a_u) = n_B X - S_B\) (which increases strictly with \(X\)).

This splits into two cases based on the parity of \(N \times M\):

  1. Case A: \(N \times M\) is Odd (\(n_B - n_W = 1\)):
    • The equation \((n_B - n_W)X = S_B - S_W\) uniquely determines \(X = S_B - S_W\)!
    • If \(X < \max_{r,c} a_{r,c}\), it is immediately impossible (-1); otherwise we just test feasibility of this single \(X\)!
  2. Case B: \(N \times M\) is Even (\(n_B = n_W\)):
    • First, we must have \(S_B = S_W\) (otherwise -1).
    • Second, why is feasibility monotone in \(X\) when \(N \times M\) is even? Because any even-area \(N \times M\) rectangle can be tiled by disjoint \(1 \times 2\) dominoes! #include <bits/stdc++.h>
using namespace std;

const long long INF = 1e16;

struct Dinic {
    struct Edge { int to, rev; long long cap; };
    int n;
    vector<vector<Edge>> adj;
    vector<int> level, ptr;

    Dinic(int n) : n(n), adj(n), level(n), ptr(n) {}

    void add_edge(int u, int v, long long cap) {
        adj[u].push_back({v, (int)adj[v].size(), cap});
        adj[v].push_back({u, (int)adj[u].size() - 1, 0});
    }

    bool bfs(int s, int t) {
        fill(level.begin(), level.end(), -1);
        level[s] = 0;
        queue<int> q;
        q.push(s);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (auto &e : adj[u]) {
                if (e.cap > 0 && level[e.to] == -1) {
                    level[e.to] = level[u] + 1;
                    q.push(e.to);
                }
            }
        }
        return level[t] != -1;
    }

    long long dfs(int u, int t, long long pushed) {
        if (pushed == 0 || u == t) return pushed;
        for (int &cid = ptr[u]; cid < (int)adj[u].size(); ++cid) {
            auto &e = adj[u][cid];
            if (level[u] + 1 != level[e.to] || e.cap == 0) continue;
            long long tr = dfs(e.to, t, min(pushed, e.cap));
            if (tr == 0) continue;
            e.cap -= tr;
            adj[e.to][e.rev].cap += tr;
            return tr;
        }
        return 0;
    }

    long long max_flow(int s, int t) {
        long long flow = 0;
        while (bfs(s, t)) {
            fill(ptr.begin(), ptr.end(), 0);
            while (long long pushed = dfs(s, t, INF)) flow += pushed;
        }
        return flow;
    }
};

    int N, M;
    cin >> N >> M;
    vector<vector<long long>> a(N, vector<long long>(M));
    long long nB = 0, nW = 0, sB = 0, sW = 0, mx = 0;
    for (int r = 0; r < N; ++r) {
        for (int c = 0; c < M; ++c) {
            cin >> a[r][c];
            mx = max(mx, a[r][c]);
            if ((r + c) % 2 == 0) { nB++; sB += a[r][c]; }
            else { nW++; sW += a[r][c]; }
        }
    }

    auto check = [&](long long X) -> bool {
        if (X < mx) return false;
        int S = 0, T = N * M + 1;
        Dinic dinic(T + 1);
        auto id = [&](int r, int c) { return r * M + c + 1; };
        int dr[4] = {-1, 1, 0, 0}, dc[4] = {0, 0, -1, 1};
        long long need = 0;
        for (int r = 0; r < N; ++r) {
            for (int c = 0; c < M; ++c) {
                int u = id(r, c);
                if ((r + c) % 2 == 0) {
                    need += X - a[r][c];
                    dinic.add_edge(S, u, X - a[r][c]);
                    for (int d = 0; d < 4; ++d) {
                        int nr = r + dr[d], nc = c + dc[d];
                        if (nr >= 0 && nr < N && nc >= 0 && nc < M)
                            dinic.add_edge(u, id(nr, nc), INF);

                    dinic.add_edge(u, T, X - a[r][c]);
                }
            }
        }
        return dinic.max_flow(S, T) == need;
    };

    if (nB != nW) {
        long long X = (sB - sW) / (nB - nW);
        if (check(X)) cout << (nB * X - sB) << "\n";
        else cout << -1 << "\n";
    } else {

            cout << -1 << "\n";
            return;
        }

        while (lo <= hi) {
            long long mid = lo + (hi - lo) / 2;
            if (check(mid)) { ans = mid; hi = mid - 1; }
            else lo = mid + 1;
        }
        if (ans == -1) cout << -1 << "\n";
        else cout << (nB * ans - sB) << "\n";
    }

1. Non-Graph Diagnostic Signal (Step 1)

2. Intermediate Algebraic Representation (Step 2)

\[ \min_{x \in \{0,1\}^{N^2}} \sum_{(u,v) \in E} \big( x_u x_v + (1 - x_u)(1 - x_v) \big) \quad \text{subject to pre-colored cells.} \]

  • Define unified variable \(z_{r,c} \in \{0, 1\}\) by:
    • On even cells \((r+c) \equiv 0 \pmod 2\): \(z_u = 1 \iff \texttt{'B'}\), \(z_u = 0 \iff \texttt{'W'}\).
    • On odd cells \((r+c) \equiv 1 \pmod 2\): \(z_v = 1 \iff \texttt{'W'}\), \(z_v = 0 \iff \texttt{'B'}\).

    • If \(z_u\) is forced to \(0\), add \(u \xrightarrow{\infty} T\) (cannot be placed in \(S\)).

#088 (Mas-2): AtCoder ARC 176 E — Max Vector

  • Judge: AtCoder arc176_e
  • Constraints: \(1 \le N, M \le 100\), threshold values \(A_{k,i} \in [1, 500]\). Time Limit: \(2.0\text{ s}\).
  • Statement Summary: Choose two positive integer vectors \(X = (X_1, \dots, X_N)\) and \(Y = (Y_1, \dots, Y_N)\) in \(\{1, \dots, 500\}^N\) to minimize \(\sum_{i=1}^N (X_i + Y_i)\), subject to \(M\) constraints. The \(k\)-th constraint specifies a target vector \(A_k = (A_{k,1}, \dots, A_{k,N})\) and requires that for every \(i \in \{1, \dots, N\}\), \(\max(X_i, Y_i) \ge A_{k,i}\)—WAIT: even stronger, the constraint states that at step \(k\), either we replace \(X_i \gets \max(X_i, A_{k,i})\) for all \(i\) OR we replace \(Y_i \gets \max(Y_i, A_{k,i})\) for all \(i\)! Equivalently, for each clause \(k \in \{1, \dots, M\}\), either \((\forall i,\, X_i \ge A_{k,i})\) OR \((\forall i,\, Y_i \ge A_{k,i})\)!

1. Non-Graph Diagnostic Signal (Step 1)

Look at the two equivalent formulations of ARC 176 E:

  • Primal Clause View: For each clause \(k \in \{1, \dots, M\}\), we must satisfy the disjunction \((\forall i, X_i \ge A_{k,i}) \lor (\forall i, Y_i \ge A_{k,i})\).
  • Dual Assignment View: Each clause \(k\) is assigned either to vector \(X\) (\(z_k = 1\)) or to vector \(Y\) (\(z_k = 0\)), and then \(X_i = \max_{k : z_k = 1} A_{k,i}\) and \(Y_i = \max_{k : z_k = 0} A_{k,i}\)!

With \(N, M \le 100\) and \(V = \max A_{k,i} \le 500\), both views lead to a sleek Bipartite Variable Inversion cut!

2. Intermediate Algebraic Representation (Step 2)

Represent each coordinate \(X_i, Y_i \in \{1, \dots, V\}\) using unary threshold indicators (as in Chapter 10, previewing Chapter 12):

  • For \(X_i\): let \(x_{i,t} = [X_i \ge t] \in \{0, 1\}\) for \(t \in \{2, \dots, V\}\), with monotonicity \(x_{i,2} \ge x_{i,3} \ge \dots \ge x_{i,V}\) and unary cost \(X_i = 1 + \sum_{t=2}^V x_{i,t}\).
  • For \(Y_i\): if we used standard indicators \([Y_i \ge t]\), then clause \(k\)’s requirement \((\forall i, x_{i, A_{k,i}} = 1) \lor (\forall j, [Y_j \ge A_{k,j}] = 1)\) would forbid \((x_{i, A_{k,i}} = 0 \land [Y_j \ge A_{k,j}] = 0)\), which is a covering clause (\(A = \infty, \Delta = -\infty < 0\), supermodular!) between the \(X\)-chains and \(Y\)-chains!

3. Reverse-Engineering Scratchpad (Step 3)

Because every clause connects the \(X\)-chains (\(L\)) to the \(Y\)-chains (\(R\)), we apply Bipartite Variable Inversion to all \(Y\)-variables by defining \(y_{i,t} \coloneqq [Y_i < t] = 1 - [Y_i \ge t]\):

  • Left Shore (\(X\)-chains, unflipped: \((i, t)_X \in S \iff X_i \ge t\)):
    • Cost \(+1\) for \(X_i \ge t \implies\) edge \((i, t)_X \xrightarrow{1} T\) for \(t \in \{2, \dots, V\}\).
    • Monotonicity \(X_i \ge t \implies X_i \ge t - 1\): edge \((i, t)_X \xrightarrow{\infty} (i, t-1)_X\).
  • Right Shore (\(Y\)-chains, inverted: \((i, t)_Y \in S \iff Y_i < t\), \((i, t)_Y \in T \iff Y_i \ge t\)):
    • Cost \(+1\) for \(Y_i \ge t\) (i.e., \((i, t)_Y \in T\)) \(\implies\) edge \(S \xrightarrow{1} (i, t)_Y\) for \(t \in \{2, \dots, V\}\).
    • Monotonicity \(Y_i < t - 1 \implies Y_i < t\): edge \((i, t-1)_Y \xrightarrow{\infty} (i, t)_Y\).
  • Clause \(k\) Disjunction via a Single Clause Hub \(C_k\):
    • Clause \(k\) forbids having some \(j\) with \(Y_j < A_{k,j}\) (meaning \((j, A_{k,j})_Y \in S\)) AND some \(i\) with \(X_i < A_{k,i}\) (meaning \((i, A_{k,i})_X \in T\)).
    • Instead of adding \(N^2\) edges \((j, A_{k,j})_Y \xrightarrow{\infty} (i, A_{k,i})_X\), introduce one clause vertex \(C_k\) (where \(C_k \in S \iff\) clause \(k\) is assigned to \(X\), and \(C_k \in T \iff\) clause \(k\) is assigned to \(Y\)):
      • For each \(j\) with \(A_{k,j} \ge 2\): add \((j, A_{k,j})_Y \xrightarrow{\infty} C_k\).
      • For each \(i\) with \(A_{k,i} \ge 2\): add \(C_k \xrightarrow{\infty} (i, A_{k,i})_X\).

4. Hand-Checkable Toy Trace & Complexity Analysis (Step 4)

// AtCoder ARC 176 E — Max Vector (#088)
// Bipartite Variable Inversion on Unary Threshold Chains + Clause Hub Gadget
#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9;

struct Dinic {
    struct Edge { int to, rev, cap; };
    int n;
    vector<vector<Edge>> adj;
    vector<int> level, ptr;

    Dinic(int n) : n(n), adj(n), level(n), ptr(n) {}

    void add_edge(int u, int v, int cap) {
        adj[u].push_back({v, (int)adj[v].size(), cap});
        adj[v].push_back({u, (int)adj[u].size() - 1, 0});
    }

    bool bfs(int s, int t) {
        fill(level.begin(), level.end(), -1);
        level[s] = 0;
        queue<int> q;
        q.push(s);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (auto &e : adj[u]) {
                if (e.cap > 0 && level[e.to] == -1) {
                    level[e.to] = level[u] + 1;
                    q.push(e.to);
                }
            }
        }
        return level[t] != -1;
    }

    int dfs(int u, int t, int pushed) {
        if (pushed == 0 || u == t) return pushed;
        for (int &cid = ptr[u]; cid < (int)adj[u].size(); ++cid) {
            auto &e = adj[u][cid];
            if (level[u] + 1 != level[e.to] || e.cap == 0) continue;
            int tr = dfs(e.to, t, min(pushed, e.cap));
            if (tr == 0) continue;
            e.cap -= tr;
            adj[e.to][e.rev].cap += tr;
            return tr;
        }
        return 0;
    }

    int max_flow(int s, int t) {
        int flow = 0;
        while (bfs(s, t)) {
            fill(ptr.begin(), ptr.end(), 0);
            while (int pushed = dfs(s, t, INF)) flow += pushed;
        }
        return flow;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M;
    if (!(cin >> N >> M)) return 0;
    const int V = 500;
    // Node indexing:
    // S = 0, T = 1
    // X-chain (i, v) for i in [0..N-1], v in [2..V]: 2 + i*(V-1) + (v-2)
    // Y-chain (i, v) for i in [0..N-1], v in [2..V]: 2 + N*(V-1) + i*(V-1) + (v-2)
    // Clause hub k in [0..M-1]: 2 + 2*N*(V-1) + k
    int S = 0, T = 1;
    int baseX = 2;
    int baseY = baseX + N * (V - 1);
    int baseC = baseY + N * (V - 1);
    int total_nodes = baseC + M;

    auto nodeX = [&](int i, int v) { return baseX + i * (V - 1) + (v - 2); };
    auto nodeY = [&](int i, int v) { return baseY + i * (V - 1) + (v - 2); };
    auto nodeC = [&](int k) { return baseC + k; };

    Dinic dinic(total_nodes);

    for (int i = 0; i < N; ++i) {
        for (int v = 2; v <= V; ++v) {
            // X_i >= v <=> nodeX(i, v) in S (costs 1 if in S)

            if (v > 2) {

            dinic.add_edge(S, nodeY(i, v), 1);

                dinic.add_edge(nodeY(i, v - 1), nodeY(i, v), INF);

        }

                dinic.add_edge(c_hub, nodeX(i, a), INF);
            }
        }
    }

    cout << (2 * N + dinic.max_flow(S, T)) << "\n";
    return 0;

Before submitting any solution that uses Bipartite Variable Inversion, run through this 5-point FM-11 audit:

  1. Sign Audit of \(\Delta_{uv}\): Did you verify \(\Delta_{uv} = B + C - A - D < 0\) in the minimization penalty table before inverting? (Remember: if adjacent cells pay a penalty for having different states, \(\Delta_{uv} > 0\) is already submodular—do not invert!)

  3. Right-Shore Unary Attachment Flip: On the inverted shore \(R\) (\(v \in S \iff x_v = 0\), \(v \in T \iff x_v = 1\)), did you swap \(S \to v\) and \(v \to T\)?     • Penalizing \((x_u = 1, x_v = 1) \iff (u \in S, v \in T)\) requires a directed edge \(u \to v\) (from \(L\) to \(R\)).
    • Penalizing \((x_u = 0, x_v = 0) \iff (v \in S, u \in T)\) requires a directed edge \(v \to u\) (from \(R\) to \(L\)).
  5. 64-Bit Overflow & \(\infty\) Guard: Ensure INF exceeds the sum of all finite unary capacities (use 1e18 for long long capacities) so an \(\infty\)-edge is never severed in any minimum cut.
