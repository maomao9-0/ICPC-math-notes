Study Plan, 3-Axis Diagnostic Protocol & Mastery Gates

How to Train Recognition Reflexes, Navigate the 6-Part Curriculum, and Self-Audit with Blind Checkpoints

Because flow algorithms themselves are black-box library calls (Dinic, MCMF, Blossom), studying network flows requires a fundamentally different training protocol from algorithmic domains like string structures or polynomial algebra. Reading a solution that begins “Construct a graph where we connect \(S \to u\) with capacity \(a_u + b_u \dots\)” teaches you almost nothing unless you learn how the author knew to build a graph in the first place, and how those capacities were derived.

1. The 3-Axis Recognition Diagnostic Protocol

Whenever you encounter a new competitive programming problem—especially one with no graphs mentioned in the statement—run through these three diagnostic axes before writing a single line of code:

Axis 1: Scale & Complexity Regime (\(N, M \implies \text{Target Paradigm}\))

Input Constraint Regime Viable Flow / Cut / Duality Paradigms
\(N, M \le 50\) or Grid \(H, W \le 30\) Multi-state unary chains (切糕模型, \(O(N K)\) vertices, Ch 12), Ishikawa convex penalties (Ch 13), dynamic scheduling MCMF (Ch 20), or 2D rank-slot MCMF (AGC 031 E, Ch 20).
\(N \le 300 \text{–} 500,\; M \le 5\,000\) Standard Max-Flow / Min-Cut (Ch 01–Ch 04), Project Selection (Ch 09), Pseudo-Boolean & Bipartite Flip Cuts (Ch 10–Ch 11), Fractional Dinkelbach + Min-Cut (Ch 14), Gomory–Hu Trees (Ch 16), MCMF & LP Duals (Ch 17–Ch 21), General Blossom (Ch 22), Isotonic Regression (Ch 24).
\(N \le 3\,000 \text{–} 10\,000\) Unit-capacity bipartite matching (\(O(E\sqrt{V})\), Ch 05–Ch 08), incremental parametric flow rollback (退流, CF 1427 G, Ch 13), or DS-accelerated flow graphs (线段树/主席树优化建图, Ch 22).
\(N, M \le 10^5 \text{–} 5 \times 10^5\) Direction B (Flow Elimination): Segment-tree Hall Marriage (Ch 08), Planar Dual Dijkstra (Ch 15), Min-Cut DP / \((\min,+)\) Tropical Matrix SegTree (Ch 16), or Simulated MCMF via Regret Heaps / Slope Trick (Ch 23).

Axis 2: Objective & Constraint Structure (\(\text{Algebraic Signature} \implies \text{Compilation Family}\))

  1. “Conservation / Routing / Redistributing Quantities with Bounds”:
    • Fixed supplies/demands, degree bounds, row/column sums \(\implies\) Standard Flow, Vertex/Time Splitting, or Lower-Bound Circulations (Part I, Ch 01–Ch 04).
  2. “Pairing / Independent Selection / Grid Coverage / Precedence Chains”:
    • Pairwise conflicts on a parity-bipartite domain, grid lines, or DAG chains \(\implies\) Bipartite Matching, König MVC/MIS, DM Decomposition, or Dilworth (Part II, Ch 05–Ch 08).
  3. “Binary Choices \(x_i \in \{0,1\}\) or Discrete Levels \(h_i \in \{1..K\}\) with Pairwise Penalties”:
    • Logical implications \(x_u \implies x_v\), “all-same bonus”, \(|x_u - x_v|\), or \(\max(0, h_u - h_v)\) \(\implies\) The Minimum Cut Compiler (Part III, Ch 09–Ch 13).
    • Check the Submodularity Determinant \(A + D - (B + C)\):
      • If \(A + D \le B + C\): compile directly (Ch 10).
      • If \(A + D > B + C\) on a bipartite conflict graph: apply Bipartite Variable Inversion \(\bar{x}_j = 1 - x_j\) (Ch 11, AGC 038 F).
  4. “Ratio Optimization, Planar Grids, or \(N \le 2 \times 10^5\) Cut Recurrences”:
    • Ratio \(\frac{\sum w}{\sum c}\), planar separation, or all-pairs min-cut \(\implies\) Fractional Dinkelbach, Planar Dual Dijkstra, Min-Cut DP, or Gomory–Hu (Part IV, Ch 14–Ch 16).
  5. “Weighted Assignment, Convex Penalties \(x^2\), Contiguous Interval Coverage, or Linear Inequalities”:
    • Costs per unit of flow, \(\sum \binom{d_i}{2}\), interval coverage \(\ge D_i\), or dualizing shortest paths/MST \(\implies\) MCMF, Convex Edge Splitting, Equation Differencing, or LP Duality (Part V, Ch 17–Ch 21).
  6. “Range Edges, Non-Bipartite General Pairing, \(N \le 2 \times 10^5\) Convex Matching, or Monotone \(L_p\) Regression”:
    • Range-to-range capacity, odd-cycle matching, online pairing with regret, or \(y_u \le y_v\) regression \(\implies\) DS-Sparsified Graphs, Blossom, Simulated MCMF, or Isotonic Regression (Part VI, Ch 22–Ch 24).

Axis 3: Mandatory Pre-Coding Sanity Check (Failure Mode Inoculation)

Before coding any flow model, verify: - Are all edge capacities \(\ge 0\)? (Check FM-11, FM-14, FM-15.) - Can a chain be cut more than once? (Check reverse \(\infty\)-arcs FM-13.) - Is the underlying conflict graph actually bipartite? (Check FM-07, FM-12.) - Are internal data-structure or implication arcs assigned capacity \(+\infty\)? (Check FM-09, FM-23.)

3. Per-Part Mastery Gates

Do not advance to the next Part until you can pass the corresponding Mastery Gate:

Part Checkpoint File Mastery Gate Criteria
Part I CP-I (#193–#200) Classify feasible vs. essential cut edges in \(O(M)\) via SCC condensation; formulate any lower-bound circulation (LOJ #115–#117) and extract a Hoffman violation certificate without looking up formulas.
Part II CP-II (#201–#208) Constructively recover MVC, MIS, and Maximum Antichains via alternating reachability; win impartial bipartite walk games via DM decomposition; eliminate Hall matching on intervals into a segment tree.
Part III CP-III (#209–#216) Compile any submodular 2-variable table or bipartite supermodular table (AGC 038 F) into normal-form cut edges; build multi-state unary chains (ARC 107 F, ARC 142 E) with reverse \(\infty\)-arcs; apply the Discrete Coarea Formula (CF 1427 G).
Part IV CP-IV (#217–#224) Formulate Maximum Density Subgraph in \(|V|\) vertices; dualize \(s\)-\(t\) and \(k\)-terminal planar cuts into shortest paths + interval DP; eliminate max-flow via min-cut DP (CF 724 E); build a Gusfield Gomory–Hu tree in \(N-1\) flows.
Part V CP-V (#225–#232) Eliminate negative cycles via initial saturation; split convex marginal costs; transform contiguous range inequalities into flow conservation via \(\Delta_i = \text{Eq}_i - \text{Eq}_{i-1}\); dualize any primal LP into an MCMF network.
Part VI CP-VI (#233–#240) Sparsify 1D/2D range edges via persistent/out-in segment trees; reduce degree-\(\le 2\) general matching via 2-vertex bins (CF 1089 B); design 1-push and 2-push regret-heap transitions (模拟费用流); solve \(L_p\) isotonic regression via parallel binary search + closure min-cut.
