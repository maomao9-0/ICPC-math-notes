Notation, Canonical Conventions & Failure Mode Atlas

Unified Algebraic Symbols, Cut Orientation Rosetta Stone, and the 24 Structural Failure Modes (FM-01–FM-24)

Every chapter, checkpoint, and capstone in this textbook adheres to a single set of algebraic conventions for flow networks, residual graphs, minimum-cut binary indicator polynomials, and linear programming duals. Bookmark this reference page whenever you need to verify a sign convention, cut orientation, or failure mode.

1. Networks, Flows, Residual Graphs, and Cuts

Symbol / Notation Formal Definition & Meaning
\(\mathcal{N} = (V, E, s, t, c)\) Directed capacitated network with vertex set \(V\), arc set \(E\), source \(s \in V\), sink \(t \in V \setminus \{s\}\), and capacity function \(c : E \to \mathbb{R}_{\ge 0} \cup \{+\infty\}\).
\(n = |V|,\; m = |E|\) Number of vertices and directed arcs in the compiled network \(\mathcal{N}\) (distinct from the problem input dimensions \(N, M\)).
\(\delta^+(v),\; \delta^-(v)\) Set of outgoing arcs \(\{(v, u) \in E\}\) and incoming arcs \(\{(u, v) \in E\}\) incident to vertex \(v\). For a subset \(S \subseteq V\), \(\delta^+(S) = \{(u, v) \in E : u \in S, v \notin S\}\).
\(f(u, v)\) Net flow on directed pair \((u, v)\). In the skew-symmetric formulation, \(f(v, u) = -f(u, v) \le c(u, v)\), and conservation holds at every internal vertex \(v \in V \setminus \{s, t\}\): \(\sum_{u} f(v, u) = 0\).
\(|f|\) Value of the \(s\)-\(t\) flow \(f\): \(|f| = \sum_{e \in \delta^+(s)} f(e) - \sum_{e \in \delta^-(s)} f(e) = \sum_{e \in \delta^-(t)} f(e) - \sum_{e \in \delta^+(t)} f(e)\).
\(c_f(u, v)\) Residual capacity of directed pair \((u, v)\) with respect to \(f\): \(c_f(u, v) = c(u, v) - f(u, v) + f(v, u)\) (where \(c(u, v)\) is the forward capacity and \(f(v, u)\) is the current flow on the reverse arc that can be canceled).
\(G_f = (V, E_f)\) Residual graph induced by \(f\), where \(E_f = \{(u, v) \in V \times V : c_f(u, v) > 0\}\).
\((S, T)\) An \(s\)-\(t\) cut partitioning \(V = S \sqcup T\) with \(s \in S\) and \(t \in T\). Its capacity is \(c(S, T) = \sum_{(u, v) \in E:\, u \in S, v \in T} c(u, v)\) (forward arcs only; reverse arcs \(T \to S\) do not subtract from \(c(S, T)\)).
\(S_{\min},\; S_{\max}\) Unique inclusion-minimal and inclusion-maximal minimum-cut source sets in \(G_{f^*}\) at any maximum flow \(f^*\): \(S_{\min} = \{v \in V : s \rightsquigarrow_{G_{f^*}} v\}\) and \(S_{\max} = \{v \in V : v \not\rightsquigarrow_{G_{f^*}} t\}\).

2. Lower-Bound Circulations (上下界网络流)

When every arc \(e = (u, v) \in E\) has both a lower bound \(l(e)\) and an upper bound \(u(e)\) (\(0 \le l(e) \le u(e)\)):

  • Affine Slack Decomposition: Write \(f(e) = l(e) + \tilde{f}(e)\), where \(\tilde{f}(e) \in [0, u(e) - l(e)]\) is the free slack flow in the shifted network \(\tilde{\mathcal{N}}\) with capacity \(\tilde{c}(e) = u(e) - l(e)\).
  • Pre-Injected Vertex Balance (Net Excess): \[M(v) = \sum_{e \in \delta^-(v)} l(e) - \sum_{e \in \delta^+(v)} l(e) - b(v)\] where \(b(v)\) is any external net outflow requirement at \(v\) (\(b(v) = 0\) for standard conservation).
  • Auxiliary Super-Terminals \((S^*, T^*)\):
    • If \(M(v) > 0\) (mandatory inflow exceeds mandatory outflow), add arc \((S^*, v)\) of capacity \(M(v)\).
    • If \(M(v) < 0\) (mandatory outflow exceeds mandatory inflow), add arc \((v, T^*)\) of capacity \(-M(v)\).
    • Total required auxiliary saturation: \(\Sigma_+ = \sum_{v : M(v) > 0} M(v)\). Feasibility holds if and only if \(\text{MaxFlow}_{\tilde{\mathcal{N}}}(S^*, T^*) = \Sigma_+\).
  • Feedback Arc \((t \to s, [0, \infty))\): Added to convert an \(s\)-\(t\) flow with lower bounds into a circulation before connecting \(S^*\) and \(T^*\). Its flow \(f(t \to s)\) equals the value \(|f|\) of the original \(s\)-\(t\) flow.

3. Bipartite Matching, Posets, and Decomposition

For a graph \(G = (V, E)\) (often bipartite with \(V = L \sqcup R\)):

Symbol Name Dual Partner & Identity
\(\nu(G)\) Maximum Matching Size \(\nu(G) = \tau(G)\) in bipartite graphs (König’s Theorem)
\(\tau(G)\) Minimum Vertex Cover Size (MVC) \(\alpha(G) + \tau(G) = |V|\) in all graphs (Gallai’s First Identity)
\(\alpha(G)\) Maximum Independent Set Size (MIS) \(\alpha(G) = |V| - \nu(G)\) in bipartite graphs
\(\rho(G)\) Minimum Edge Cover Size (MEC, no isolated vertices) \(\nu(G) + \rho(G) = |V|\) in all graphs without isolated vertices (Gallai’s Second Identity)
\(\text{def}(G)\) Hall Defect \(\max_{A \subseteq L} (|A| - |N_G(A)|)\) \(\nu(G) = |L| - \max(0, \text{def}(G))\) (Ore’s Defect Theorem)
\(V_E \sqcup V_O \sqcup V_U\) Dulmage–Mendelsohn (DM) Coarse Partition \(V_E\): Even-alternating reachable from unmatched vertices (non-essential); \(V_O\): Odd-alternating neighbors of \(V_E\) (essential); \(V_U\): Unreachable matched core (essential).
\(\text{width}(P)\) Maximum Antichain Size of Poset \((P, \prec)\) \(\text{width}(P) = \min \text{ChainCover}(P) = |P| - \nu(G_{\text{split}}(P))\) (Dilworth’s Theorem)

4. Minimum-Cut Binary Variables & Cut Polynomials (燃やす埋める)

In Part III (Ch 09–Ch 13), an \(s\)-\(t\) cut \((S, T)\) is treated as a binary variable assignment to each vertex \(v \in V \setminus \{s, t\}\). Because both conventions (\(x_v = 1 \iff v \in S\) and \(x_v = 1 \iff v \in T\)) appear across the English, Chinese, and Japanese literature, we standardize on the following canonical convention throughout the textbook and provide the translation rule below:

ImportantCanonical Textbook Cut Convention (Source = 0 / Sink = 1 in Penalty Minimization; Source = 1 in Closure)
  1. In Project Selection / Maximum Weight Closure (Ch 09):
    • \(v \in S\) means project \(v\) is selected (\(y_v = [v \in S] = 1\)), and \(v \in T\) means \(v\) is not selected (\(y_v = 0\)).
    • An implication “if \(u\) is selected, \(v\) must be selected” (\(y_u \implies y_v\), i.e., forbidding \(u \in S, v \in T\)) is compiled as a directed arc \(u \to v\) with capacity \(+\infty\).
  2. In Pseudo-Boolean Cut Polynomial Minimization (Ch 10–Ch 13, 燃やす埋める):
    • Each binary variable \(x_i \in \{0, 1\}\) is encoded by placing \(i \in S \iff x_i = 0\) and \(i \in T \iff x_i = 1\) (equivalently, \(x_i = [i \in T]\)).
    • Under this encoding, the elementary cut monomials are:
      • Unary cost of \(x_i = 1\) (\(i \in T\)): an arc \(s \to i\) of capacity \(w\) is severed iff \(i \in T\), contributing \(w \cdot x_i\).
      • Unary cost of \(x_i = 0\) (\(i \in S\)): an arc \(i \to t\) of capacity \(w\) is severed iff \(i \in S\), contributing \(w \cdot (1 - x_i)\).
      • Pairwise divergence penalty for \((x_i = 0, x_j = 1)\) (\(i \in S, j \in T\)): an arc \(i \to j\) of capacity \(w\) is severed iff \(x_i = 0 \land x_j = 1\), contributing \(w \cdot (1 - x_i) x_j\).
    • Dual Convention Translation (Rosetta Stone): If you prefer \(x_i = 1 \iff i \in S\) and \(x_i = 0 \iff i \in T\), simply swap the roles of \(x_i\) and \(1 - x_i\): an arc \(u \to v\) always severs when \(u \in S\) and \(v \in T\).
  • Multi-State Threshold Indicators (Ch 12–Ch 13): For a discrete variable \(h_v \in \{0, 1, \dots, K\}\), we introduce \(K\) binary threshold vertices \(z_{v, 1}, \dots, z_{v, K}\) where \(z_{v, k} = [h_v \ge k] \in \{0, 1\}\), chained by infinite-capacity monotonicity arcs forcing \(z_{v, 1} \ge z_{v, 2} \ge \dots \ge z_{v, K}\).

5. Min-Cost Max-Flow (MCMF) & LP Duality

  • Arc Cost & Total Cost: Each arc \(e = (u, v)\) carries unit cost \(w(e) \in \mathbb{R}\) (with reverse residual cost \(w(v, u) = -w(u, v)\)). Total cost is \(C(f) = \sum_{e \in E} w(e) f(e)\).
  • Johnson Potentials & Reduced Cost: Given vertex potentials \(\pi : V \to \mathbb{R}\), the reduced cost of a residual arc \((u, v) \in E_f\) is: \[w_\pi(u, v) = w(u, v) + \pi(u) - \pi(v)\] By telescoping along any cycle \(C\), \(\sum_{e \in C} w_\pi(e) = \sum_{e \in C} w(e)\). If \(w_\pi(u, v) \ge 0\) for all \((u, v) \in E_f\), then \(G_f\) has no negative-cost cycles and \(f\) is a minimum-cost flow of value \(|f|\).
  • Slope Function \(C^*(F)\): The minimum cost \(C^*(F)\) as a function of flow value \(F \in [0, F_{\max}]\) is piecewise-linear and convex; its discrete derivative \(\Delta C^*(F) = C^*(F) - C^*(F-1)\) is non-decreasing.

6. Master Atlas of the 24 Structural Failure Modes (FM-01–FM-24)

Throughout the textbook, every chapter explicitly tests and inoculates against a specific set of modelling bugs. The table below indexes all 24 Failure Modes (FM-01–FM-24):

ID Failure Mode Name Broken Symptom / Trap Correct Rescue & Primary Chapter
FM-01 Greedy Augmenting Path Trap Sending paths greedily without reverse residual arcs \((v, u)\) gets trapped at suboptimal flow Always maintain skew-symmetric residual arcs \(c_f(v, u) = f(u, v)\) (Ch 01)
FM-02 Cut Capacity Reverse-Arc Subtraction Subtracting capacities of \(T \to S\) arcs when computing \(c(S, T)\) (confusing net flow with cut capacity) Net flow across \((S,T)\) subtracts \(f(T,S)\), but cut capacity \(c(S,T)\) sums only forward arcs \(S \to T\) (Ch 01)
FM-03 Saturated \(\implies\) Cut Edge Fallacy Assuming every saturated arc (\(c_f(u,v)=0\)) belongs to some minimum cut or is essential Use Picard–Queyranne SCC condensation: feasible iff \(u \not\rightsquigarrow_{G_f} v\); essential iff \(s \rightsquigarrow_{G_f} u\) and \(v \rightsquigarrow_{G_f} t\) (Ch 02)
FM-04 Undirected Vertex-Split Bypass Adding an undirected edge between \(u_{\text{in}}\) and \(v_{\text{out}}\) allows flow to traverse \(u_{\text{out}} \to u_{\text{in}}\) backwards, bypassing \(c(u)\) Every undirected edge \(\{u, v\}\) must expand into two directed arcs \(u_{\text{out}} \to v_{\text{in}}\) and \(v_{\text{out}} \to u_{\text{in}}\) (Ch 03)
FM-05 Lower-Bound Slack Offset Omission Reporting \(\tilde{f}(t \to s)\) or \(\text{MaxFlow}_{\tilde{\mathcal{N}}}(s, t)\) without adding \(l(e)\) or tearing down \(S^*, T^*\) Delete \(S^*, T^*, (t \to s)\) after Phase 1 and reconstruct \(f(e) = l(e) + \tilde{f}(e)\) on every arc (Ch 04)
FM-06 Mixed Eulerian Parity Omission Setting up lower-bound flow for mixed Eulerian tour without checking \(d^+(v) - d^-(v) \equiv 0 \pmod 2\) Each flipped undirected edge changes net degree by \(\pm 2\); odd degree imbalance is immediately infeasible (Ch 04)
FM-07 Non-Bipartite König / MIS Application Computing \(|V| - \text{MaxFlow}\) on a graph containing odd cycles (\(C_{2k+1}\) has \(\nu = k < \tau = k+1\), LP gives \(k + 1/2\)) Verify bipartiteness first (FM-07); if odd cycles exist, use Blossom (Ch 22) or check if vertex cover is NP-hard (Ch 05)
FM-08 DAG Path Cover Transitive Shortcut Omission Running bipartite matching \(V_{\text{out}} \to V_{\text{in}}\) on raw DAG edges when paths are allowed to share vertices Vertex-sharing path cover (Dilworth) requires transitive closure (or vertex-bypass capacities \(\infty\)) first (Ch 08)
FM-09 Closure Implication Direction Reversal Adding \(\infty\)-arc \(v \to u\) instead of \(u \to v\) for “if \(u \in S\) then \(v \in S\)” Check which assignment \((u \in S, v \in T)\) is forbidden: only an arc \(u \to v\) crosses \((S, T)\) to pay \(+\infty\) (Ch 09)
FM-10 Topological Cycle Trap in Closure Feeding mutually protecting vertices or directed cycles directly into Project Selection ([NOI2009] 植物大战僵尸) Prune all vertices not reachable from zero-indegree roots in the protection/prerequisite graph via Kahn’s BFS first (Ch 09)
FM-11 Supermodular Penalty Direct Compilation Compiling a “same-state penalty” (\(A + D > B + C\)) into a cut network, yielding negative arc capacities Check \(A + D \le B + C\); if violated on a bipartite conflict graph, apply Bipartite Variable Inversion \(\bar{x}_j = 1 - x_j\) (Ch 10, Ch 11)
FM-12 Non-Bipartite Supermodular Flip Failure Attempting Bipartite Variable Inversion on a conflict graph with an odd cycle of anti-ferromagnetic edges Odd cycles of supermodular penalties are frustrated (Max-Cut / Ising spin glass); test signed balance first (Ch 11)
FM-13 Missing Reverse-\(\infty\) Chain Arcs (切糕模型) Omitting \((u, i) \to (u, i-1)\) with capacity \(\infty\) in a multi-state chain, allowing multiple cuts on one chain to “buy” negative/cheap states twice Always include reverse \(\infty\)-arcs \((u, i) \to (u, i-1)\) so the cut can sever the chain at most once (Ch 12)
FM-14 Negative Unary Base Shift in Multi-State Cuts Leaving \(M - w_{u, i} < 0\) when converting node rewards into cut penalties (e.g., negative \(A_v\) in ARC 107 F) Choose per-vertex shift \(M_v > \max_i |w_{v, i}|\) so every chain edge capacity is strictly non-negative (Ch 12)
FM-15 Non-Convex Pairwise Distance Penalty Applying Ishikawa’s cross-edge gadget to a concave distance penalty like \(\sqrt{|h_u - h_v|}\) Ishikawa capacities equal \(-\Delta_a \Delta_b \Phi(a, b) = \Phi(a+1,b) + \Phi(a,b+1) - \Phi(a,b) - \Phi(a+1,b+1)\), which is \(\ge 0\) iff \(\Phi\) is convex (Ch 13)
FM-16 Fractional Programming Sign Flip Treating \((+w_e)\) in the denominator \(B(x)\) as submodular when minimizing \(A(x)/B(x)\) (\(A(x) - \lambda B(x)\) flips the sign of \(B(x)\)) Verify that \(A(x) - \lambda B(x)\) remains submodular for all \(\lambda > 0\) (Ch 14)
FM-17 Non-\(s\)-\(t\)-Planar Dual Shortest Path Trap Using simple dual shortest path \(F_{\text{top}} \to F_{\text{bot}}\) when \(s\) and \(t\) do not lie on the outer face of the planar graph Interior \(s\)-\(t\) planar min-cut requires a minimum cycle separating \(s\) and \(t\) in \(G^*\) (Reif’s divide-and-conquer or tree-cut trick) (Ch 15)
FM-18 Gusfield vs. Gomory–Hu Subtree Extraction Updating vertex labels in Gusfield’s simplified algorithm using all vertices instead of the current connected component of \(G_f\) Follow Gusfield’s exact label-update invariant: for all \(v \in T \cap \{v : p[v] = t\}\), set \(p[v] \gets s\) (Ch 16)
FM-19 Zkw MCMF Zero-Cost Cycle Infinite Loop Running DFS-based primal–dual (zkw) without a vis[] guard when zero-reduced-cost cycles exist Maintain vis[u] = true on the active DFS stack and clear on backtrack, or use Dijkstra SSP (Ch 17)
FM-20 Concave Marginal Cost Edge Splitting Splitting an edge with decreasing marginal costs (\(\Delta c_1 > \Delta c_2 > \dots\)) into parallel arcs MCMF greedily picks the cheapest parallel arc \(\Delta c_K\) first before \(\Delta c_1\) is used! Concave costs require fixed-charge/DP methods (Ch 18)
FM-21 Equation-Difference Non-Unit Column Violation Applying consecutive row differencing \(\Delta_i = \text{Eq}_i - \text{Eq}_{i-1}\) when a variable’s 1s do not form a single contiguous interval A column with \(k > 1\) disjoint intervals of 1s produces \(k\) \(+1\)s and \(k\) \(-1\)s after differencing, violating flow conservation (Ch 19, Ch 21)
FM-22 Manhattan Hub Linearization for Minimization Using the \(2^d\) sign-hub trick \(|x_u - x_v| = \max_{\sigma \in \{\pm 1\}^d} \sigma \cdot (x_u - x_v)\) when minimizing distance \(\max_{\sigma}\) linearizes maximization (Max-Cost Flow, AGC 034 D); in minimization, hubs would pick \(\min_\sigma = -|x_u - x_v|\) (Ch 20)
FM-23 Binary-Lifting / SegTree Non-Idempotent Flow Inflation Using overlapping range covers (like Sparse Table or binary lifting with finite capacities) for range-to-vertex flow edges Overlapping paths double-count capacity! Internal data-structure spine edges must have capacity \(+\infty\), and range decompositions must partition into disjoint canonical nodes (Ch 22)
FM-24 Single-Push Regret Heap Stale Virtual Twin Pushing a regret token \(2p_i - p_j\) in simulated MCMF without handling whether the intermediate item \(i\) itself can be re-paired (Double-Push vs. Single-Push) Verify the exact residual state machine on the small explicit MCMF graph before writing heap transitions (Ch 23)
