Checkpoint V — Part V Blind Recognition: Min-Cost Max-Flow, Equation Differencing, Hubs & LP Duality

Part V Blind Diagnostic Assessment (Chapters 17–21 · Untagged Contest Problems, Decoy Discrimination & Failure-Mode Triage)

When you solve an exercise at the end of Chapter 18 (“Separable Convex Marginal Splitting, Degree Penalties, and Tournament Orientation”) or Chapter 19 (“\(K\)-Interval Coverage and the Consecutive Equation Difference Method”), the chapter heading itself hands you the critical modelling transformation. Before reading the constraints, you already expect to split a quadratic cost \(\Phi(f) = a f^2 + b f\) into parallel unit-capacity arcs of marginal cost \(\Delta\Phi(k) = a(2k-1) + b\), or to subtract adjacent prefix equations \(\Delta E_i = E_i - E_{i-1}\) so each interval column \([l_j, r_j]\) collapses to a single \(+1\) inflow at \(l_j\) and \(-1\) outflow at \(r_j + 1\).

In a live ICPC World Finals, NOI, Codeforces, or AtCoder contest, problems arrive completely untagged—and worse, problem setters deliberately disguise simple binary-search bottlenecks, \(O(N)\) difference arrays, or NP-hard fixed-charge traps inside “cost flow” narratives. Your decisive competitive advantage in Part V is blind algebraic-to-graph recognition: looking at a multi-period inventory schedule, a two-tree quota system, a subtask-waiting queue, or a linear program and immediately knowing whether to compile it into a Min-Cost Max-Flow (MCMF) network, dualize it into a closed-form sweep, or reject MCMF altogether before falling into any of the five Part V failure modes (FM-17–FM-21).

Drill 1.1 — The Stale Johnson Potential & Negative-Arc Saturation Trap (FM-17)

A contestant implements Primal–Dual Successive Shortest Path (SSP) with Dijkstra and Johnson potentials \(\pi_v\). 1. In each phase, after running Dijkstra on reduced costs \(c^\pi(u, v) = c(u, v) + \pi_u - \pi_v \ge 0\) to obtain shortest-path distances \(d_v\), they update \(\pi_v \gets \pi_v + d_v\) only for vertices \(v\) lying on the chosen augmenting path \(P\), claiming that vertices outside \(P\) did not have their flow changed. 2. On a second problem where the input directed graph has cycles and some edges have negative costs \(c(u, v) < 0\) (CF 708D Incorrect Flow), they initialize \(\pi_v\) with SPFA; when SPFA loops infinitely on a negative cycle, they conclude the problem is unsolvable.

Identify both bugs (FM-17), construct a 3-vertex counterexample for Bug 1, and state the exact mechanical protocol for Bug 2.

TipAnswer & Diagnosis — Drill 1.1
  • Failure Mode: FM-17 (Stale Johnson Potentials & Un-Saturated Negative Cycles, Chapter 17).
  • Bug 1 Counterexample (Updating \(\pi\) Only on \(P\)): Suppose \(S = 1, T = 3\) with edges \(1 \xrightarrow{(1, 0)} 2\), \(1 \xrightarrow{(1, 2)} 3\), and \(2 \xrightarrow{(1, 0)} 3\), starting at \(\pi = (0, 0, 0)\).
    • Shortest distances from \(1\) are \(d_1 = 0, d_2 = 0, d_3 = 0\) via \(P = (1 \to 2 \to 3)\), and wait: suppose there is also a side vertex \(4\) with \(1 \xrightarrow{(1, 0)} 4\) and \(4 \xrightarrow{(1, 0)} 2\), so \(d_4 = 0\), or suppose \(1 \xrightarrow{(1, 5)} 2\), \(2 \xrightarrow{(1, 0)} 3\) (\(d_2 = 5, d_3 = 5\)) and another vertex \(4\) has \(1 \xrightarrow{(1, 0)} 4\) (\(d_4 = 0\)) and \(2 \xrightarrow{(1, 0)} 4\)!
    • If we augment along \(P = (1 \to 2 \to 3)\) and update \(\pi\) only on \(P\) (\(\pi_1 \gets 0, \pi_2 \gets 5, \pi_3 \gets 5\)) while leaving \(\pi_4 = 0\) untouched, then the forward residual edge \(2 \to 4\) now has reduced cost \(c^\pi(2, 4) = 0 + \pi_2 - \pi_4 = +5\), Wait: what if edge \((4 \to 2)\) had cost \(2\) (\(d_4 = 0, d_2 = 2, d_3 = 2\)), and \(P = (1 \to 2 \to 3)\) came from \(1 \xrightarrow{(1, 2)} 2 \xrightarrow{(1, 0)} 3\)? After augmenting \(1 \to 2 \to 3\), the reverse residual arc \((2 \to 1)\) opens with cost \(-2\). For \((4 \to 2)\), if \(\pi_2\) is updated to \(2\) while \(\pi_4\) was \(0\) (okay), what if \(d_4 = 1\) (via \(1 \xrightarrow{(1, 1)} 4\)) and \(4 \xrightarrow{(1, 0)} 2\) gave \(d_2 = 1\)? If we update \(\pi_2 \gets 1\) on \(P = (1 \to 4 \to 2 \to 3)\) vs. if \(P = (1 \to 2 \to 3)\) (cost \(1\)) is chosen and \(\pi_4\) is not updated (\(\pi_4 = 0\) instead of \(d_4 = 1\)), then the reverse arc \((2 \to 4)\) or forward arc \((4 \to 2)\) violates \(c^\pi \ge 0\)! Specifically, if \(2 \xrightarrow{(1, 0)} 4\) exists, \(d_2 = 1 \implies d_4 = 1\); leaving \(\pi_4 = 0\) while setting \(\pi_3 = 1\) on \(P=(1\to 2\to 3)\) and then opening reverse arc \((3 \to 2)\) or \((4 \to 3)\) with cost \(0\) creates \(c^\pi(4, 3) = 0 + \pi_4 - \pi_3 = -1 < 0\)!
    • Invariant (Ch 17.1): You must update \(\pi_v \gets \pi_v + d_v\) for every vertex \(v\) reachable from \(S\) in \(G_f\) during Dijkstra so that \(d_v \le d_u + c^\pi(u, v) \iff c^{\pi'}(u, v) \ge 0\) holds across the entire residual network, including newly opened reverse arcs \((v \to u)\) along shortest-path trees where \(d_v = d_u + c^\pi(u, v) \implies c^{\pi'}(v, u) = 0\).
  • Bug 2 Fix (Mandatory Negative-Arc Pre-Saturation Ch 17.3): When an edge \(e = (u \to v)\) has capacity \([0, u(e)]\) and negative cost \(c(e) < 0\) inside a potentially cyclic graph, pre-saturate it before running MCMF:
    1. Force \(f(e) = u(e)\), adding \(u(e) \cdot c(e)\) to the base cost and incrementing nodal balance \(M(v) \mathrel{+}= u(e), M(u) \mathrel{-}= u(e)\).
    2. Replace \(e\) with its reverse cancellation arc \(v \xrightarrow{\text{cap } u(e),\; \text{cost } -c(e) > 0} u\).
    3. Now every arc in the network has non-negative cost \(-c(e) \ge 0\), so \(\pi \equiv 0\) is immediately valid for Dijkstra, and super-terminal rebalancing \(S^* \to T^*\) (Ch 04 + Ch 17.3) cancels any unprofitable flow around non-negative cycles!

Drill 1.2 — Convex Quadratic Shipping vs. The Concave Fixed-Charge Setup Trap (FM-18)

Compare two factory-to-warehouse shipping problems (\(N, M \le 50\), maximum road capacity \(U = 10\)): - Scenario A (#227 Stage 1): Shipping \(f \in \{0, 1, \dots, 10\}\) units along road \(e\) costs \(\Phi_A(f) = a_e f^2 + b_e f\) where \(a_e > 0, b_e \ge 0\). - Scenario B (#228 Stage 1): Shipping \(f \in \{0, 1, \dots, 10\}\) units along road \(e\) costs \(0\) if \(f = 0\), and costs a fixed setup fee plus linear shipping \(\Phi_B(f) = F_e + b_e f\) if \(f \ge 1\), where \(F_e > 0, b_e \ge 0\).

A contestant compiles both scenarios into MCMF by replacing each road \(e\) with \(10\) parallel unit-capacity arcs where the \(k\)-th arc (\(k = 1, \dots, 10\)) has cost \(\Delta\Phi(k) = \Phi(k) - \Phi(k-1)\). Why does Scenario A succeed while Scenario B fails catastrophically?

TipAnswer & Diagnosis — Drill 1.2
  • Failure Mode: FM-18 (Unrolling Non-Convex / Concave Marginals into Parallel Arcs, Chapter 18).
  • Scenario A (Genuine Ch 18.1 — Strictly Convex Marginals): The \(k\)-th marginal cost is: \[\Delta\Phi_A(k) = a_e\big(k^2 - (k-1)^2\big) + b_e = a_e(2k - 1) + b_e.\] Because \(a_e > 0\), the second difference \(\Delta^2 \Phi_A(k) = \Delta\Phi_A(k+1) - \Delta\Phi_A(k) = 2a_e > 0\) is positive: \[\Delta\Phi_A(1) < \Delta\Phi_A(2) < \dots < \Delta\Phi_A(10).\] A minimum-cost flow solver greedily saturates the cheapest parallel arcs between \(u\) and \(v\) first, so sending \(f\) units is guaranteed to use precisely arcs \(1, 2, \dots, f\), whose costs telescope to \(\sum_{k=1}^f \Delta\Phi_A(k) = \Phi_A(f)\).
  • Scenario B (Decoy — Concave Fixed-Charge Network Flow is NP-Hard): For \(\Phi_B(f) = F_e \cdot [f \ge 1] + b_e f\), the marginal costs are: \[\Delta\Phi_B(1) = F_e + b_e, \qquad \Delta\Phi_B(2) = \Delta\Phi_B(3) = \dots = \Delta\Phi_B(10) = b_e.\] Because \(F_e > 0\), \(\Delta\Phi_B(1) > \Delta\Phi_B(2)\) (concave!). If you place parallel arcs of costs \((F_e + b_e, b_e, b_e, \dots)\) in an MCMF network, the shortest-path solver will route the first unit of flow through the second arc of cost \(b_e\), completely dodging the setup fee \(F_e\)! Fixed-charge network flow contains Steiner Tree / Set Cover as a special case and is NP-Hard.

Drill 1.3 — The Off-by-One Interval Endpoint Trap & Doubly-Bounded Coverage (FM-19)

Consider two interval problems: 1. Doubly-Bounded Interval Coverage: Given \(M \le 400\) intervals \(I_j = [l_j, r_j] \subseteq \{1, \dots, N\}\) with profit \(w_j > 0\), select a subset \(x_j \in \{0, 1\}\) such that each point \(i \in \{1, \dots, N\}\) is covered at least \(A_i\) and at most \(B_i\) times (\(0 \le A_i \le B_i\)), maximizing \(\sum_j w_j x_j\). A contestant writes \(E_i - E_{i-1}\) and wires each interval \(I_j = [l_j, r_j]\) as an arc \(l_j \to r_j\) instead of \(l_j \to r_j + 1\), and says doubly-bounded constraints \([A_i, B_i]\) cannot be handled by equation differencing. 2. Contiguous \(\pm 1\) Subarray Zeroing: Given \(a_1, \dots, a_N\) (\(N \le 2 \cdot 10^5\)), each operation adds \(+1\) or \(-1\) to any \([l, r]\) at cost \(1\); find the minimum cost to make all \(a_i = 0\).

Fix both flaws in Problem 1 (FM-19) and explain why Problem 2 is an \(O(N)\) decoy.

TipAnswer & Diagnosis — Drill 1.3
  • Failure Mode: FM-19 (Off-by-One \(l_j \to r_j + 1\) Interval Endpoint & Unbounded-Only Slack Assumption, Chapter 19).
  • Problem 1 Fix (Doubly-Bounded Equation Differencing Ch 19.1–19.2):
    • For each point \(i \in \{1, \dots, N\}\), the double bound \(A_i \le \sum_{j: i \in [l_j, r_j]} x_j \le B_i\) becomes an exact equality by subtracting a bounded slack variable \(y_i \in [0, B_i - A_i]\): \[E_i : \quad \sum_{j:\, l_j \le i \le r_j} x_j - y_i = A_i \qquad (i = 1, \dots, N),\] with boundary dummy equations \(E_0 : 0 = 0\) and \(E_{N+1} : 0 = 0\).
    • Take consecutive differences \(\Delta E_i = E_i - E_{i-1}\) for \(i = 1, \dots, N+1\):
      • Variable \(x_j\) (covering \(i \in \{l_j, \dots, r_j\}\)) enters at \(i = l_j\) with coefficient \(+1\) (in \(\Delta E_{l_j}\)) and exits at \(i = r_j + 1\) with coefficient \(-1\) (in \(\Delta E_{r_j+1}\))! Wiring \(l_j \to r_j\) instead of \(l_j \to r_j + 1\) drops point \(r_j\) from the interval (FM-19).
      • Slack variable \(y_i \in [0, B_i - A_i]\) has coefficient \(-1\) in \(\Delta E_i\) and \(+1\) in \(\Delta E_{i+1}\), which compiles directly to a capacitated backward spine arc \(i + 1 \xrightarrow{[0, B_i - A_i],\; \text{cost } 0} i\)!
  • Problem 2 Diagnosis (\(O(N)\) Difference-Array Decoy): When every interval \([l, r]\) is available at uniform cost \(1\) with unbounded capacity, setting \(b_i = a_i - a_{i-1}\) (\(i = 1, \dots, N+1\), with \(a_0 = a_{N+1} = 0\)) means one operation on \([l, r]\) changes \((b_l, b_{r+1})\) by \((\pm 1, \mp 1)\). Pairing positive and negative entries of \(b\) takes zero graph search: the minimum cost is simply \(\frac{1}{2}\sum_{i=1}^{N+1} |a_i - a_{i-1}|\) in \(O(N)\) time!

Drill 1.4 — Merged Dirty/Clean Inventory Nodes & Forward Queue Indexing (FM-20)

Audit two classic Chapter 20 compilations: 1. Napkin Laundering (餐巾计划): Day \(i\) requires \(r_i\) clean napkins. A solver creates a single vertex \(v_i\) per day, wires \(S \xrightarrow{r_i} v_i \xrightarrow{r_i} T\), and adds laundry arcs \(v_i \to v_{i+d}\)! Why does this always output cost \(0\)? 2. Multi-Machine Total Completion Time (修车): \(N\) cars and \(M\) technicians (\(T_{i,j}\) = time for technician \(j\) to fix car \(i\)). A solver splits each technician \(j\) into \(N\) slots \((j, 1), \dots, (j, N)\) where \((j, p)\) denotes the \(p\)-th car repaired from the start of technician \(j\)’s shift, and assigns edge cost \(p \cdot T_{i,j}\) to \(\text{Car}_i \to (j, p)\). Why is this weight formula wrong?

TipAnswer & Diagnosis — Drill 1.4
  • Failure Mode: FM-20 (Merged Dirty/Clean State Nodes & Forward vs. Reverse Queue Indexing, Chapter 20).
  • Bug 1 (Merged Dirty/Clean Node Short-Circuit): If day \(i\) is a single node \(v_i\) with \(S \xrightarrow{r_i, 0} v_i \xrightarrow{r_i, 0} T\), flow injected from \(S\) into \(v_i\) (representing used/dirty napkins generated on day \(i\)) immediately exits \(v_i \to T\) (satisfying day \(i\)’s clean napkin demand) at cost \(0\) without ever buying a single napkin or waiting for laundry! You must split day \(i\) into two disjoint states:
    • Dirty Supply Node \(D_i\) (\(S \xrightarrow{r_i, 0} D_i\), emitting dirty napkins to \(D_{i+1}\) or to clean nodes \(C_{i+d}\) via laundry);
    • Clean Demand Node \(C_i\) (\(C_i \xrightarrow{r_i, 0} T\), receiving clean napkins only from fresh purchases \(S \to C_i\) or completed laundry \(D_{i-d} \to C_i\)).
  • Bug 2 (Forward vs. Reverse Queue Position Indexing): Suppose technician \(j\) repairs \(k\) cars in order \(i_1, i_2, \dots, i_k\).
    • The \(1\)-st car \(i_1\) delays all \(k\) cars (\(i_1, \dots, i_k\)) on technician \(j\), contributing \(k \cdot T_{i_1, j}\) to total waiting time—which depends on the unknown total number \(k\) of cars assigned to technician \(j\)!
    • Conversely, if we index slots backward from the end of technician \(j\)’s schedule (\(p = 1\) = last car repaired, \(p = 2\) = second-to-last car repaired, etc.), then the \(p\)-th car from the end delays exactly \(p\) cars (itself and the \(p-1\) cars after it), so its contribution to total completion time is statically \(p \cdot T_{i,j}\) regardless of how many cars precede it!

Drill 1.5 — Dual Sign Orientation & Non-TU Odd Cycles (FM-21)

  1. DAG Project Crashing (#229 Stage 1): Given a DAG \(G = (V, E)\) with edge lengths \(w_e\), you can pay \(c_e > 0\) per unit to increase edge \(e\)’s length by \(x_e \ge 0\) (Wait: or pay \(c_e > 0\) per unit to shorten edge \(e\)’s length to \(w_e - x_e\)) so that every \(S \leadsto T\) path has length \(\le D\) (i.e., potential difference \(\pi_T - \pi_S \le D\) with \(\pi_v - \pi_u \ge w_e - x_e\)). Derive the LP Dual and explain why getting a single inequality sign wrong destroys Kirchhoff flow conservation.
  2. Non-TU Odd Cycle Trap: Why can you not solve Minimum Vertex Cover on a triangle \(C_3 = \{1, 2, 3\}\) by compiling its LP relaxation into an MCMF / Min-Cut network without Bipartite Variable Inversion failing?
TipAnswer & Diagnosis — Drill 1.5
  • Failure Mode: FM-21 (LP Dual Sign Inversion & Non-TU Odd-Cycle Half-Integrality, Chapter 21).
  • Part 1 (Exact LP Dual of DAG Crashing Ch 21.2): Set \(\pi_S = 0\). The Primal LP minimizes \(\sum_{e \in E} c_e x_e\) subject to: \[\pi_u - \pi_v + x_e \ge -w_e \quad (\forall e = (u \to v) \in E), \qquad -\pi_T \ge -D, \qquad x_e \ge 0.\] Introduce non-negative dual flow variables \(f_e \ge 0\) for each edge constraint and \(F \ge 0\) for \(-\pi_T \ge -D\):
    • Dual constraint for \(x_e \ge 0\): \(0 \le f_e \le c_e\) (edge capacity \(c_e\)!).
    • Dual constraint for unconstrained \(\pi_v\) (\(v \notin \{S, T\}\)): \(\sum_{e \in \delta^+(v)} f_e - \sum_{e \in \delta^-(v)} f_e = 0\) (exact Kirchhoff flow conservation!).
    • Dual constraint for \(\pi_T\): \(\sum_{e \in \delta^+(T)} f_e - \sum_{e \in \delta^-(T)} f_e - F = 0 \implies \text{net flow into } T \text{ equals } F\).
    • Dual objective: \(\max \big(-D \cdot F + \sum_{e \in E} w_e f_e\big) = -\min_{F \ge 0} \big(D \cdot F + \sum_{e \in E} (-w_e) f_e\big)\), which is a parametric Minimum-Cost \(S\)-\(T\) Flow with edge capacities \(c_e\) and edge costs \(-w_e\)! Reversing \(\pi_u - \pi_v\) on a single edge turns \(\delta^+(v) - \delta^-(v)\) into \(\delta^+(v) + \delta^-(v)\), which has two \(+1\)s in one column and breaks flow conservation.
  • Part 2 (Odd Cycle Non-TU Determinant \(\pm 2\)): The vertex-edge incidence matrix of the triangle \(C_3\) is: \[A = \begin{pmatrix} 1 & 0 & 1 \\ 1 & 1 & 0 \\ 0 & 1 & 1 \end{pmatrix} \implies \det(A) = 1(1) + 1(1) = 2 \notin \{-1, 0, +1\}.\] Because \(\det(A) = \pm 2\) on every odd cycle \(C_{2k+1}\), \(A\) is not Totally Unimodular, and its LP relaxation has the unique fractional optimum \(x^* = (1/2, 1/2, 1/2)\) of cost \(1.5 < 2\).

Drill 1.6 — Decoy Discrimination: Minimum Mean Cycle vs. Minimum-Cost Circulation (#226 Stage 1)

You are given a directed graph \(G = (V, E)\) (\(N \le 300, M \le 2000\)) with edge weights \(w_e \in \mathbb{R}\) and asked to find a single directed cycle \(C\) minimizing the average edge weight \(\mu(C) = \frac{1}{|C|}\sum_{e \in C} w_e\). A contestant binary searches \(\lambda\), assigns shifted edge costs \(w'_e = w_e - \lambda\) and unit capacities \(c_e = 1\), and runs Minimum-Cost Circulation (Ch 17.3) to check if the minimum circulation cost is \(< 0\).

Is this overkill, and what happens if they instead ask for the cycle \(C\) with the smallest total shifted weight \(\sum_{e \in C} (w_e - \lambda)\)?

TipAnswer & Diagnosis — Drill 1.6
  • Verdict: Decoy (Ch 17 vs. Karp’s Algorithm / Binary Search + Bellman–Ford).
  • Why MCMF Is Wrong / Overkill Here:
    1. For fixed \(\lambda\), \(\min_C \frac{1}{|C|}\sum_{e \in C} w_e < \lambda \iff \exists \text{ cycle } C \text{ with } \sum_{e \in C} (w_e - \lambda) < 0\). Testing whether \(G\) contains at least one negative cycle under edge weights \(w_e - \lambda\) requires only Bellman–Ford / SPFA negative-cycle detection in \(O(VE)\) (or Karp’s Minimum Mean Cycle DP \(\mu^* = \min_{v \in V} \max_{0 \le k < N} \frac{d_N(v) - d_k(v)}{N - k}\) in \(O(VE)\) without binary search!).
    2. Furthermore, a Minimum-Cost Circulation solver saturates the disjoint union of all negative cycles simultaneously, whereas finding a single minimum-weight simple cycle is NP-hard in general and only the sign of the minimum cycle weight (\(\ge 0\) vs. \(< 0\)) is needed for the binary search predicate \(\mu^* \le \lambda\).

In \(\Delta E_i = E_i - E_{i-1}\), an indicator covering \(i \in \{l_j, \dots, r_j\}\) has \(+1\) at \(i = l_j\) and \(-1\) at \(i = r_j + 1\); subtracting nested descendants \(w \prec v \prec u\) subtracts \(E_w\) multiple times. For closed integer intervals \([l_j, r_j]\), always wire \(l_j \leftrightarrow r_j + 1\) (with dummy node \(N+1\)); for half-open \([s_j, t_j)\), wire \(\text{id}(s_j) \leftrightarrow \text{id}(t_j)\); on trees, subtract only \(v \in \text{ch}^*(u)\) with \(\text{anc}(\text{parent}(v)) = u\) (Ch 19 §19.1–19.3).
FM-20 Merged Dirty/Clean Inventory Nodes & Forward Queue-Slot Indexing Using a single node \(v_i\) per day in 餐巾计划 (Drill 1.4), or indexing machine queue slots forward from the start of shift instead of backward from the end (#227 修车 / 美食节). A single day node lets dirty inflow from \(S \to v_i\) exit directly to clean demand \(v_i \to T\) at cost \(0\); forward position \(q\) delays \(k_j - q + 1\) jobs where \(k_j\) is unknown beforehand. Split day \(i\) into Dirty Supply \(D_i\) (\(S \to D_i\)) and Clean Demand \(C_i\) (\(C_i \to T\)); index machine slots by reverse position \(p \in \{1, \dots, N\}\) from the end with static cost \(p \cdot T_{i,j}\), and spawn slot \((j, p+1)\) lazily when \((j, p)\) saturates (Ch 20 §20.2–20.3).
FM-21 LP Dual Sign Inversion & Non-TU Odd-Cycle Half-Integrality Mixing \(\ge\) and \(\le\) constraints when taking the LP dual of path-crashing or covering LPs (Drill 1.5), or assuming vertex-edge incidence LP relaxations are integral on general graphs with odd cycles. Flipping a primal inequality sign turns a \([-1, +1]\) conservation column into \([+1, +1]\); odd cycles \(C_{2k+1}\) have submatrix determinant \(\pm 2\), producing \(1/2\)-integral optima. Normalize all primal constraints to standard form before dualizing so each potential difference \(\pi_v - \pi_u\) produces exact Kirchhoff conservation \(\delta^+(v) - \delta^-(v) = 0\); verify Total Unimodularity (bipartite / network matrix) before asserting LP integrality (Ch 21 §21.1–21.3).

  1. (FM-17) In an MCMF network with negative edge costs on a DAG (#226 CF 164C, #230 CF 818G), why can you initialize \(\pi_v\) in \(O(V + E)\) without SPFA, and why does that fail if the initial graph contains a directed cycle?

  2. (FM-18) Given edge cost \(\Phi(f) = c_e \cdot f^2\) vs. \(\Phi(f) = c_e \cdot \sqrt{f}\) for integer flow \(f \in \{0, 1, \dots, U\}\) (\(c_e > 0\)), which one can be compiled into \(U\) parallel unit-capacity MCMF arcs?
    • Check: Only \(\Phi(f) = c_e f^2\) (\(\Delta\Phi(k) = c_e(2k-1)\) is strictly increasing). The square-root cost \(\Phi(f) = c_e \sqrt{f}\) has strictly decreasing marginals (\(\sqrt{1}-0 > \sqrt{2}-\sqrt{1} > \dots\), concave!), so MCMF would pick the \(U\)-th arc before the \(1\)-st arc.
  3. (FM-19) In Consecutive Equation Differencing \(\Delta E_i = E_i - E_{i-1}\) (Ch 19.2), how does changing a point coverage constraint from \(\ge A_i\) to an interval \([A_i, B_i]\) modify the spine arc between \(i\) and \(i+1\)?
    • Check: Instead of an unbounded slack variable \(y_i \ge 0\) (capacity \(\infty\) on \(i+1 \to i\)), the slack variable is bounded by \(y_i \in [0, B_i - A_i]\), which simply changes the capacity of the backward spine arc \(i+1 \to i\) from \(\infty\) to \(B_i - A_i\)!
  4. (FM-20) In Luogu P2050 [NOI2012] 美食节 (\(N \le 40\) dishes, total orders \(P = \sum p_i \le 800\), \(M \le 100\) chefs), why do we not pre-allocate all \(M \times P = 80,000\) chef-slot vertices before running MCMF?
    • Check: Because for any chef \(j\), \(\text{Slot}(j, p)\) has strictly smaller cost \(p \cdot T_{i,j}\) than \(\text{Slot}(j, p+1)\) for every dish \(i\). Thus Dijkstra will never augment through \(\text{Slot}(j, p+1)\) until \(\text{Slot}(j, p)\) is saturated! Lazily adding \(\text{Slot}(j, p+1)\) (and its \(N\) incoming dish edges) only when \(\text{Slot}(j, p)\) is matched keeps the active graph at \(\le M + P = 900\) slot nodes instead of \(80,000\).
  5. (FM-21) After solving a Maximum-Weight Bipartite Perfect Matching via MCMF (#228 Luogu P3967), how do you determine in \(O(N^2)\) time which matched edges belong to every optimal perfect matching?
    • Check: Build the zero-reduced-cost residual subgraph \(G_{f^*}^{(0)}\) containing all positive-capacity residual arcs with \(c(u, v) + \pi_u - \pi_v = 0\), and run Tarjan’s SCC algorithm; a matched edge \((L_i, R_j) \in M^*\) is mandatory iff \(\operatorname{scc}(L_i) \neq \operatorname{scc}(R_j)\) in \(G_{f^*}^{(0)}\).
