07 — Linear Algebra over Finite Fields

Coordinates you can eliminate

Three contest situations, apparently unrelated:

  • You may XOR together any subset of \(n\) given numbers. Which values are reachable, and how many ways is each one reachable?
  • Count the spanning trees of a weighted graph, modulo a prime.
  • A sequence is defined by a huge state machine, and you need its \(10^{18}\)-th term.

All three become easy the moment the objects are written as vectors and the problem is attacked with reversible row operations. Subsets of XORs are a vector space over the two-element field; spanning trees are a determinant; a finite-dimensional transition forces a linear recurrence you can exponentiate.

One warning before anything else, because it invalidates more solutions than any other mistake here: name the scalar domain first. Real numbers, \(\mathbb F_p\), and \(\mathbb F_2\) support the same algebra but have completely different hazards, and a composite modulus is not a field at all — Gaussian elimination can silently produce a wrong answer there.

Prerequisites and learning objectives

Read proofs and invariants and fields and units; the recurrence sections also use polynomial division.

You should finish able to count solutions from a rank, prove why XOR representations are uniformly distributed, turn a spanning-tree count into a determinant, and explain why a finite-dimensional transition yields a linear recurrence. Your library supplies elimination and polynomial arithmetic; this chapter supplies the meaning and the preconditions.

1. Vectors, coordinates, and reversible equations

Fix a field \(K\). A vector in \(K^c\) is a list of \(c\) field elements, added and scaled coordinatewise. A linear combination of \(v_1,\ldots,v_n\) is \(\sum_i a_iv_i\); their span is the set of all such combinations. A list is independent when the only combination equal to zero has all coefficients zero. A basis is an independent spanning list, and its length is the dimension.

Why a basis is worth having: \((1,0)\) and \((1,1)\) form a basis of \(K^2\), and \((x,y) = (x-y)(1,0) + y(1,1)\) — uniquely. Uniqueness is automatic: two different coefficient lists for the same vector would subtract to a nonzero dependence. So a basis is a lossless coordinate system, the linear-algebra analogue of compressing a DP state down to its genuinely independent parameters.

A matrix \(A \in K^{r\times c}\) encodes the map \(x \mapsto Ax\). Its kernel is \(\{x : Ax = 0\}\), its image is \(\{Ax\}\), and the dimension of the image is the rank. Solving \(Ax = b\) asks whether \(b\) is in the image, and if so for all preimages.

Elimination, and the count it produces

Row operations do not change the solution set, because each one replaces an equation by an equivalent combination of equations — and each is reversible (undo a swap, divide by the nonzero scalar, subtract back the added row).

Run the usual loop: maintain a pivot row, and for each column find a nonzero entry, swap it up, normalize, eliminate the rest. The invariant after processing a column is that every pivot column has a single leading entry and all later rows are zero in earlier pivot columns — which is what guarantees no equation is lost and each pivot pins down exactly one new variable.

The number of pivots is \(\operatorname{rank}(A)\). After elimination:

  • a zero row with a nonzero augmented entry means the system is inconsistent;
  • otherwise there are \(c - \operatorname{rank}(A)\) free variables, and every assignment of them extends to exactly one solution (solve the pivot variables backwards).

Over \(\mathbb F_q\) that gives exactly \(q^{\,c-\operatorname{rank}(A)}\) solutions; over an infinite field, a solution set of that dimension. The same argument with \(b = 0\) is the rank–nullity identity \(\dim\ker A = c - \operatorname{rank}(A)\). And if \(x_0\) is any solution, every solution is \(x_0 + z\) with \(z \in \ker A\), since \(A(x - x_0) = 0\): the solution set is a translated subspace, an affine space — note it usually does not contain \(0\).

NoteRank counts equations, not rows

Over \(\mathbb F_5\), the system \(x+y+z = 2\), \(2x+2y+2z = 4\) has two rows but rank one. Pick \(y,z\) freely and set \(x = 2-y-z\): \(5^{3-1} = 25\) solutions.

Change the second right-hand side to \(3\) and the system becomes inconsistent — not rank two. Subtracting twice the first row leaves \(0 = 3 - 4 = 4 \ne 0\) in \(\mathbb F_5\).

Dense elimination costs \(O(rc\min(r,c))\). For a determinant, do not normalize the pivot row: instead multiply the running answer by each pivot, negate on each row swap, and eliminate using the ratio to the pivot.

WarningComposite moduli are not fields

A nonzero entry modulo a composite number need not be invertible, so elimination may divide by a non-unit and lose solutions. Modulo \(6\), the equation \(2x = 2\) has solutions \(x = 1\) and \(x = 4\); “dividing by \(2\)” reports one. Rank-based counting formulas do not apply. Use prime-factor methods, fraction-free (Bareiss) elimination, or exact integer algorithms.

What the determinant is

For an \(n\times n\) matrix,

\[\det A = \sum_{\sigma \in S_n}\operatorname{sgn}(\sigma)\prod_{i=1}^{n}A_{i,\sigma(i)},\]

where the sign is \((-1)^{\#\text{inversions}}\). Each summand picks one entry from every row and every column. From this definition: swapping two rows flips the sign; adding a multiple of one row to another changes nothing (the extra terms cancel in pairs with repeated rows); and a triangular matrix has determinant equal to its diagonal product. Those three facts are exactly what make the elimination procedure above valid.

Over a field, \(\det A \ne 0\) iff every column has a pivot, iff \(Ax = b\) has a unique solution for every \(b\). The permutation definition also makes sense over any commutative ring, even when division-based elimination does not. The empty matrix has determinant \(1\).

2. XOR basis: elimination over \(\mathbb F_2\)

A machine word is a vector of bits, and XOR is vector addition — so “which values can I reach by XORing a subset?” is the span of a set of vectors over \(\mathbb F_2\), and Gaussian elimination applies verbatim.

Keep at most one basis vector per leading (highest set) bit. To insert a word, XOR away the leading bits you already have; if something remains, it is a new independent direction, and if nothing remains the word was already in the span. Insertion costs \(O(B)\) for \(B\)-bit words.

With rank \(r\) from \(n\) inputs:

  • the span has exactly \(2^r\) distinct values;
  • every reachable value has exactly \(2^{\,n-r}\) subsets producing it.

Why the representations are uniform: the map from a subset (a vector in \(\mathbb F_2^n\)) to the XOR it produces is linear with rank \(r\), so its kernel has \(2^{n-r}\) elements, and every nonempty fiber is a translate of the kernel. Concretely, for the words \(1, 2, 3\) the rank is \(2\), and each of \(0,1,2,3\) has two representations — zero comes from the empty subset and from all three words.

Getting the \(k\)-th smallest span value (\(0 \le k < 2^r\)) requires more than a triangular basis: fully reduce, so each pivot bit appears in only one basis vector, sort by increasing pivot bit, and XOR the vectors selected by the bits of \(k\). Then the numeric order of results matches the order of coefficient masks, because two masks first differ at some pivot bit, and lower basis vectors cannot touch that bit. Failure case: the triangular vectors \(1, 3\) in pivot order enumerate \(0, 1, 3, 2\) — not sorted. Reducing \(3\) by \(1\) gives the basis \(1, 2\), which does enumerate in order.

Recognition: XOR on graphs

Root a DFS tree and give each vertex its XOR distance dist[v] from the root. Each non-tree edge \((u,v,w)\) contributes the cycle value dist[u] ^ w ^ dist[v]. Then for \(s, t\) in the same undirected component, the set of XORs of walks from \(s\) to \(t\) is

\[\texttt{dist[s]} \oplus \texttt{dist[t]} \;+\; \operatorname{span}(\text{cycle values of that component}).\]

Proof sketch. XOR any walk with the fixed tree path from \(s\) to \(t\): every vertex now has even edge-incidence, so the remaining edge multiset decomposes into cycles, and each cycle is a combination of the fundamental cycles. Conversely, to realize any cycle value, walk to the cycle along tree edges, go around, and come back the same way — the connector edges appear twice and cancel.

WarningWalks, not simple paths

The statement is about walks. A triangle hanging off the \(s\)–\(t\) path can be inserted into a walk, but a simple path cannot enter and leave it through a single articulation vertex. If a problem says “simple path”, this characterization does not apply.

Building all component bases costs \(O((n+m)B)\) time. Never reuse one component’s cycle space for endpoints in another component.

3. Kirchhoff’s matrix-tree theorem

Spanning trees are combinatorial objects with no obvious algebraic form, yet their total weight is a single determinant. Form the Laplacian of a weighted undirected graph:

\[L_{ii} = \sum_{j \ne i}w_{ij}, \qquad L_{ij} = -w_{ij}\ (i \ne j),\]

adding parallel-edge weights first. Delete any one row and the matching column; the determinant of the remaining \((n-1)\times(n-1)\) matrix equals the sum over spanning trees of the product of their edge weights.

NoteWhy it is true

Orient each edge arbitrarily and let \(B\) be the incidence matrix: each column has \(+1\) at one endpoint and \(-1\) at the other. With \(W\) the diagonal matrix of edge weights, \(L = BWB^{T}\) — an edge contributes its weight to both diagonal entries and its negative to the two off-diagonal ones. Delete the root row from \(B\) to get \(\bar B\).

The Cauchy–Binet expansion of a determinant of a product gives

\[\det(\bar B W \bar B^{T}) = \sum_{\substack{S \subseteq E\\ |S| = n-1}}\det(\bar B_{[:,S]})^2\prod_{e \in S}w_e .\]

Now classify the subsets \(S\). If \(S\) contains a cycle, its incidence columns are dependent and the determinant is \(0\). If \(S\) is disconnected, some component avoids the deleted root and its rows sum to zero — again \(0\). If \(S\) is a spanning tree, repeatedly remove a non-root leaf and expand along its single entry, reaching the empty matrix with determinant \(\pm 1\); squaring kills the sign. Only spanning trees survive, each with its weight product.

Directed versions need a convention, and getting it backwards is a classic bug. With out-degree on the diagonal, \(L_{ii} = \sum_{i \to j} w_{ij}\) and \(L_{ij} = -\sum_{i \to j}w_{ij}\), the root cofactor counts arborescences pointing toward the root. For trees pointing away, use the in-degree convention \(L_{ii} = \sum_{j \to i}w_{ji}\), \(L_{ij} = -\sum_{j\to i}w_{ji}\). Test on the single-edge graph \(r \to v\): deleting \(r\)’s row and column gives determinant \(1\) only under the in-degree convention, matching the unique tree pointing away from \(r\). Two vertices are enough to catch a transposed matrix.

Checks. A unit-weight triangle leaves \(\begin{pmatrix}2&-1\\-1&2\end{pmatrix}\) with determinant \(3\) — the three trees obtained by deleting one edge. With weights \(a, b, c\) the cofactor is \(ab+ac+bc\); for \((2,3,5)\) it is \(31\).

Cost is \(O(n^3)\) by dense elimination. Parallel edges add their weights; self-loops contribute nothing. Under a modulus you get the count modulo that modulus — and a zero determinant does not certify disconnection, it may be a genuine count that happens to be divisible by the prime (as \(31\) is, modulo \(31\)).

4. Linear recurrences: reduce \(x^N\), don’t multiply matrices

Suppose \(s_n = c_1s_{n-1} + \cdots + c_ks_{n-k}\) holds for every \(n \ge k\), with \(s_0,\ldots,s_{k-1}\) given in a commutative ring. The polynomial

\[C(x) = x^k - c_1x^{k-1} - \cdots - c_k\]

annihilates the sequence: it encodes “replace \(x^k\) by the combination of lower powers”. So reduce \(x^N\) modulo \(C\); the remainder’s coefficients tell you exactly how to combine \(s_0, \ldots, s_{k-1}\) to get \(s_N\).

Why this is legitimate, rather than a suggestive coincidence: define the linear functional \(\Lambda(x^j) = s_j\), extended linearly. The recurrence says precisely \(\Lambda(x^jC(x)) = 0\) for all \(j \ge 0\). Writing \(x^N = Q(x)C(x) + R(x)\) with \(\deg R < k\) and applying \(\Lambda\) gives \(s_N = \Lambda(R)\). Note that dividing by the monic \(C\) uses no inverses, so this works even modulo a composite number — unlike most of this chapter.

Concretely: for Fibonacci, \(C(x) = x^2 - x - 1\), and \(x^5 \equiv 5x + 3\), so every sequence with this recurrence satisfies \(s_5 = 3s_0 + 5s_1\). (Fibonacci: \(3\cdot 0 + 5 \cdot 1 = 5\). ✓)

Binary exponentiation with reduction after each step costs \(O(k^2\log N)\) ring operations (Kitamasa) and \(O(k)\) memory; NTT-based products or Bostan–Mori do better for large \(k\). This replaces \(k\times k\) matrix power, which is \(O(k^3\log N)\).

Discovering the recurrence: Berlekamp–Massey

Often you can compute a prefix of the sequence but do not know the recurrence. Berlekamp–Massey maintains the shortest recurrence consistent with the prefix read so far.

Its central quantity is the discrepancy: the actual next term minus the one predicted by the current recurrence. Zero discrepancy means the prefix extends for free. A nonzero discrepancy is a new independent constraint; the algorithm cancels it by subtracting a shifted copy of a saved earlier recurrence that had nonzero discrepancy, scaled by the ratio of the two discrepancies. The shift is what keeps all previously satisfied constraints intact, and the saved state comes from the last time the required order increased. That ratio is also why the algorithm needs a field.

Contract: \(O(T^2)\) field operations and \(O(T)\) space on a prefix of \(T\) terms (often stated as \(O(TL)\) for linear complexity \(L\)).

How many terms are enough? If the sequence genuinely has shortest recurrence order \(L\) valid from index \(L\), then \(2L\) terms determine it. One argument: such a sequence has a rational generating function with denominator degree \(\le L\) and numerator degree \(< L\); two such functions agreeing through degree \(2L-1\) give a cross-multiplied numerator of degree \(< 2L\) with \(2L\) leading zero coefficients, hence zero. (The all-zero sequence has order zero.)

But no finite prefix proves anything about an unknown future — the sequence \(0,0,0,0,1,\ldots\) defeats any inference from its first four terms. Establish that a recurrence exists, with a bound on its order, before extrapolating. The next subsection is how you usually do that.

Matrices and Cayley–Hamilton

The characteristic polynomial is \(\chi_A(x) = \det(xI - A)\); the minimal polynomial \(m_A\) is the monic polynomial of least degree with \(m_A(A) = 0\). Cayley–Hamilton says \(\chi_A(A) = 0\).

A clean way to see it: the cofactor identity \((xI - A)\operatorname{adj}(xI-A) = \chi_A(x)I\), compared coefficient by coefficient in \(x\) and then multiplied by successive powers of \(A\), telescopes to \(\chi_A(A) = 0\). (This avoids simply “substituting \(x = A\)”, which is not a valid step for matrix-coefficient polynomials.)

The consequence you use in contests: for any vectors \(u, v\), the scalar sequence \(u^{T}A^{n}v\) satisfies a linear recurrence of order at most the matrix dimension — so if your DP is a fixed linear transition on \(d\) states, any observed scalar sequence has order \(\le d\), and Berlekamp–Massey on \(2d\) terms is justified.

The observed order can be smaller: for \(A = \operatorname{diag}(2,3)\) with \(u = v = (1,0)^T\), the sequence is \(2^n\), order one, even though \(\chi_A = (x-2)(x-3)\).

5. Characteristic polynomials and black-box methods

For a dense matrix over a field, similarity \(A \mapsto S^{-1}AS\) preserves \(\det(xI - A)\). Hessenberg reduction uses paired row/column operations — the column operation is the inverse of the row operation, which is what preserves the characteristic polynomial — to zero everything below the first subdiagonal in \(O(n^3)\). For upper Hessenberg \(H\), the leading minors \(D_i = \det(xI_i - H_{1:i,1:i})\), with \(D_0 = 1\), satisfy

\[D_i = (x - h_{ii})D_{i-1} - \sum_{k=1}^{i-1}h_{ki}\left(\prod_{j=k}^{i-1}h_{j+1,j}\right)D_{k-1}.\]

Expanding the last column, a non-diagonal choice forces the whole intervening subdiagonal chain and leaves the leading minor of size \(k-1\) — which is why no minors are missing. Accumulating the polynomials costs \(O(n^3)\) overall. The alternative — computing determinants at \(n+1\) points and interpolating — costs \(O(n^4)\) naively and needs a field with enough points.

For a huge sparse matrix, dense elimination wastes work on zeros. Wiedemann’s method picks random \(u, v\), generates \(a_i = u^{T}A^{i}v\), and runs Berlekamp–Massey on it. The scalar sequence’s minimal polynomial divides the matrix’s, and random projection makes them equal with high probability. Generating \(2n\) terms costs \(O(n\mathcal V + n^2)\), where \(\mathcal V\) is one matrix-vector product.

Assumptions and failure modes, which matter because this is a randomized black box:

  • A projection can miss invariant factors; repeat with fresh randomness.
  • Over a small field you may need an extension field and a proved projection strategy. Switching primes changes the problem, and helps only when integer reconstruction was the goal.
  • It pays off only when one matrix-vector multiply is genuinely fast; otherwise prefer dense elimination.
  • Getting a determinant out needs more than the scalar recurrence: use a proven preconditioning recipe and account for the preconditioner’s own determinant.
  • Testing a returned annihilator on extra random vectors has an error probability; a deterministic certificate requires checking a spanning set.

6. Common pitfalls

  • Dividing modulo a composite number silently invalidates elimination.
  • Floating-point partial pivoting is about numerical stability; “largest pivot” has no meaning in a finite field, and no pivoting rule repairs an ill-conditioned model.
  • A determinant flips sign on every row swap — track it.
  • A graph XOR basis is built from cycle values, not raw edge weights.
  • Kirchhoff treats parallel edges separately; merging them without adding weights changes the answer.
  • Berlekamp–Massey sign and ordering conventions differ between templates. Verify yours on Fibonacci before the contest, not during it.

Exercises and solution workshop

1. Concept check: a fiber count

Over \(\mathbb F_3\), how many triples satisfy \(x+y+z = 1\) and \(x + 2y = 0\)?

TipHint

Choose one coordinate freely and count the completions.

NoteSolution

The second equation gives \(x = y\) (since \(2 = -1\)), and the first then gives \(z = 1 + y\). Three solutions, one per value of \(y\) — matching \(3^{\,3-2} = 3\), since the two rows are independent.

Note the solution set is a translate of the kernel, not a subspace: the zero vector does not satisfy the first equation.

2. Application: a partition objective

Given nonnegative \(B\)-bit words, split them into two groups to maximize the sum of the two group XORs — the reduction behind ABC141 F.

TipHint

Let \(T\) be the XOR of all inputs and examine one bit of \(X + (T \oplus X)\).

NoteSolution

At a bit where \(T\) is set, exactly one group has it, contributing a fixed amount. At a bit where \(T\) is clear, the groups agree, so the bit contributes twice if \(X\) has it. Hence the objective is

\[T + 2\,(X \mathbin{\&} \lnot T),\]

with the complement restricted to the \(B\) input bits.

So mask every input by \(\lnot T\) and maximize the subset XOR with a basis, greedily improving from the highest pivot down. Cost \(O(nB)\) time, \(O(B)\) space. For inputs \(3, 6, 5\): \(T = 0\), the maximum masked XOR is \(6\), and the answer is \(12\). Maximizing the unmasked \(X\) would waste effort optimizing bits whose contribution is already fixed.

Edge case: if both groups must be nonempty and \(n \ge 2\), an optimum with positive masked XOR is automatically proper; if the maximum is zero every partition attains \(T\), so any proper one works.

3. Synthesis: a cheapest basis

Prove that sorting vectors by nonnegative cost and accepting each one exactly when it raises the rank yields a cheapest basis of the span.

TipHint

Exchange one vector of an optimal basis when greedy accepts its next vector.

NoteSolution

Maintain the invariant that some optimal basis contains the greedy prefix accepted so far. When greedy accepts \(v\), write \(v\) in that optimal basis. Since \(v\) is independent of the prefix, some \(w\) with nonzero coefficient lies outside the prefix. Swapping \(w\) for \(v\) still gives a basis, because the same expression solves for \(w\).

Moreover \(w\) cannot be a vector greedy rejected earlier — rejected vectors lie in the prefix span — so \(w\) comes later in cost order and \(\operatorname{cost}(w) \ge \operatorname{cost}(v)\). The exchange therefore does not increase the total, and the invariant survives. (This is the matroid greedy argument.)

Cost \(O(n\log n + nB)\) for XOR vectors. With costs \(c_1 = 4\), \(c_2 = 5\), \(c_3 = 3\), greedy accepts vectors \(3\) then \(1\) for total \(7\); processing in index order would pick the more expensive pair.

4. Advanced: a modular determinant is not a certificate

A triangle has edge weights \(2, 3, 5\). Count its weighted spanning trees modulo \(31\). Does the result certify that the graph is disconnected?

TipHint

Enumerate which edge is deleted.

NoteSolution

The three trees weigh \(2\cdot 3\), \(2 \cdot 5\), and \(3 \cdot 5\), totalling \(31\) — so the determinant is \(0\) modulo \(31\) even though the graph is connected.

Exact counting and residue-field computation answer different questions. Any determinant used as a randomized existence certificate needs its own error analysis; see algebraic graph methods.

Contest checklist and reference sheet

  • Identify the scalar field or ring before choosing a routine.
  • Say out loud what the columns, the equations, or the bit coordinates represent.
  • Count independent parameters; do not confuse the number of solutions with the number of distinct images.
  • Check whether the statement is about walks, simple paths, or trees.
  • Prove a recurrence exists (and bound its order) before extrapolating a sampled prefix.
  • Verify determinant signs, orientation conventions, and the empty/zero case.
