11 — Probability and Expectation

Competitive-programming probability is usually deterministic algebra wearing a random story. First say what is random and what is fixed, then define a state, write a one-step equation, and solve the resulting DAG, linear system, or generating function. A probability formula is useful only once its events are unambiguous.

1. Indicator variables and linearity

For an event \(A\), let \(I_A=[A]\) be 1 when it occurs and 0 otherwise. Its average is therefore \(E[I_A]=P(A)\). If a quantity is a count, try to express it as a sum of one indicator per possible contribution:

\[X=\sum_i [A_i],\qquad E[X]=\sum_iP(A_i),\]

whether the events are independent is irrelevant. We use only distributivity of expectation over addition, not a product rule. This is the first tool for expected inversions, occupied boxes, surviving edges, and distinct values.

Worked example. In a uniformly random permutation of \(n\) items, each pair is inverted with probability \(1/2\). Hence the expected inversion count is \(\binom n2/2\), without describing any transition process.

For products, independence does matter: \(E[XY]=E[X]E[Y]\) is not generally true. Condition instead when dependence is awkward.

2. Conditioning and the law of total expectation

Partition outcomes by the next random choice. The events \(Y=y\) are disjoint and cover all outcomes, so averaging in two stages gives

\[E[X]=\sum_y P(Y=y)E[X\mid Y=y].\]

The common self-loop pattern comes from an action that leaves the state unchanged with probability \(p\), while the other outcomes have probabilities \(q_i\) with \(p+\sum_iq_i=1\):

\[E=s+pE+\sum_iq_iE_i \quad\Longrightarrow\quad E=\frac{s+\sum_iq_iE_i}{1-p}.\]

The numerator is the immediate cost plus the expected cost after a genuine state change; division conditions on eventually leaving the self-loop. Never implement an iterative self-reference before algebraically removing it. If \(p=1\) in a nonterminal state whose target can be reached only after leaving, the target is unreachable and the hitting expectation is infinite.

For a fair die that is rerolled until it shows \(4,5,\) or \(6\), one roll costs one and fails with probability \(1/2\). Thus \(E=1+E/2\), so \(E=2\). The division does not assume that attempts are bounded; it sums the entire self-loop tail.

Conditioning can also reduce state: reveal the first special object, the maximum sampled index, or the number of successful trials—whatever makes the remaining process symmetric.

3. Probability DP

Two equivalent state choices are common. Choose the one whose transition is easier to state and whose terminal condition is obvious:

  • p[state]: probability of reaching the state; push mass forward and sum terminal rewards.
  • E[state]: expected remaining cost; pull from successor expectations.

Use probability mass for acyclic processes and distributions; use expectation states when only one moment is needed. State aggregation is the hard part. Two histories may be merged only when they have the same distribution of future outcomes. Exchangeable objects should be represented by counts, not identities: e.g. \((c1,c2,c3)\) plates containing 1, 2, or 3 sushi. The plate labels do not affect a future random choice, but the counts do.

If transitions strictly increase/decrease a measure, topologically order states. Otherwise you have cycles and need equations.

4. Markov chains and absorbing systems

Partition a finite Markov chain into transient states and absorbing states. A transient state may be revisited; an absorbing state, once entered, remains forever:

\[P=\begin{pmatrix}Q&R\\0&I\end{pmatrix}.\]

Starting from a transient state costs one step, then moves according to \(Q\). Writing that first-step equation simultaneously for all states gives expected hitting times

\[t=\mathbf1+Qt,\qquad (I-Q)t=\mathbf1.\]

For absorption in a chosen target class, the probability vector satisfies \((I-Q)h=Rb\), where \(b\) is \(1\) on target absorbing states and \(0\) on the other absorbing states. The fundamental matrix \(N=(I-Q)^{-1}=I+Q+Q^2+\cdots\) has N[i][j] equal to the expected number of visits to transient state \(j\) starting at \(i\), counting the initial visit when \(i=j\): \(Q^r\) records being there after \(r\) transitions.

You do not normally invert a matrix explicitly: solve linear systems. Dense cost is \(O(S^3)\). Exploit banded, tridiagonal, monotone, or graph structure. For a finite chain, the hitting time of the chosen absorbing set has finite expectation precisely when that set is reached with probability one from the start state. Reaching some other absorbing class does not count as success.

5. Generating-function connections

For a nonnegative integer-valued random variable \(X\), the probability generating function stores the whole distribution as coefficients:

\[G_X(z)=E[z^{X}]=\sum_kP(X=k)z^{k}.\]

Independent sums multiply PGFs because \(z^{X+Y}=z^Xz^Y\) and expectation of a product factors under independence. Moreover \(G'_X(1)=E[X]\) and \(G''_X(1)=E[X(X-1)]\) when those moments are finite, so

\[\operatorname{Var}(X)=G''_X(1)+G'_X(1)-G'_X(1)^2.\]

This turns repeated independent dice/steps into polynomial multiplication.

First-step recurrences translate into rational GFs. For a renewal process with step PGF \(A(z)\), geometric repetition often produces \(1/(1-A(z))\). This connects probability DP to formal power series and linear recurrences.

6. Numerical and modeling pitfalls

  • “Uniformly select an available action” changes probabilities as the state changes.
  • Expected ratio is not ratio of expectations.
  • Modulo probabilities require all denominators invertible; this evaluates the same rational equations in a field, but field values have no ordering and do not make an infinite real expectation finite.
  • For double, use pivoting in cyclic systems and avoid subtracting nearly equal probabilities.
  • An unreachable absorbing state means infinite expectation, not a large finite DP value.
  • Memoized recursion on a cyclic state graph never resolves the cycle.

7. Practice, in order

  1. Foundation — Sushi, Educational DP J (English). Symmetry compression and a self-loop. Official editorial.
    Hints
    1. Keep only counts of plates with 1, 2, and 3 pieces.
    2. Choosing an empty plate is a self-loop.
    3. Move that term to the left; evaluate states by total sushi count.
  2. Advanced — Game on Tree, CF 280C (English, 2200). Indicators and symmetry. Official tutorial.
    Hints
    1. A vertex contributes exactly when it is removed directly.
    2. Among the vertices on its root path, which must be selected first?
    3. Each is equally likely; sum the reciprocal depth contributions.
  3. Advanced — Roulettes, AtCoder ABC314 E (English, 500). Optimal expected-cost DP with zero outcomes. Official editorial.
    Hints
    1. Let dp[x] be minimum expected extra cost from score \(x\).
    2. Evaluate each roulette by conditioning on its outcomes.
    3. Remove zero-outcome self-loops algebraically before taking the minimum.
  4. Mastery — Intergalaxy Trips, CF 605E (English, 2700). Greedy ordering of expectation equations. Official tutorial.
    Hints
    1. Suppose a set of vertices already has finalized expectations to the target.
    2. Maintain for every other vertex the probability that all tried finalized destinations fail and its accumulated expected cost.
    3. Finalize the smallest current expectation, Dijkstra-style, and update all remaining vertices.
  5. Mastery — Broken Robot, CF 24D (English, 2400). Banded linear equations. Official tutorial.
    Hints
    1. Write the expectation equation for every cell in one row.
    2. The next row is already known if rows are processed bottom-up.
    3. Each row becomes a tridiagonal system; solve it by elimination.
