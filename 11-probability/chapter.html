11 — Probability and Expectation

Probability turns uncertain outcomes into quantities we can count and compare. First say what is random and what is fixed, then define a state, write a one-step equation, and solve the resulting DAG, linear system, or generating function. A probability formula is useful only once its events are unambiguous.

Prerequisites and learning objectives

Use finite counting and sums; cyclic models need linear systems. The PGF section uses generating functions, and can be read later. You should finish able to define the random experiment precisely, replace a count by indicators, justify a compressed state, diagnose infinite hitting time, and derive both first and second moments. Recognition signals include random orders, expected counts, repeated attempts, and revisited states.

0. Outcomes, events, and averages

A sample space \(\Omega\) is the set of possible outcomes. For a finite space assign each outcome \(\omega\) a probability \(p_\omega\ge0\) with \(\sum_{\omega\in\Omega}p_\omega=1\). An event \(A\) is a subset of \(\Omega\), with \(P(A)=\sum_{\omega\in A}p_\omega\). A random variable \(X\) assigns a real number \(X(\omega)\) to each outcome; its expectation is

\[E[X]=\sum_{\omega\in\Omega}p_\omega X(\omega).\]

For a countably infinite space, use a series. Nonnegative variables may have infinite expectation; for signed variables we use the formula when \(E[|X|]<\infty\). A contest modulus is a later representation of an exact rational answer, not the original meaning of probability.

For one fair die, \(\Omega=\{1,\ldots,6\}\) and each outcome has probability \(1/6\). The variable \(X(\omega)=\omega\) has mean \(7/2\). There is no outcome “3.5”: expectation is an average, not a prediction of a possible result. For two dice, the 36 ordered pairs are equally likely; their 11 possible sums are not. Sum 2 occurs once and sum 7 occurs six times. “Uniform” always refers to specified objects.

When \(P(B)>0\), conditional probability is \(P(A\mid B)=P(A\cap B)/P(B)\): restrict the space to \(B\) and renormalize. Events are independent when \(P(A\cap B)=P(A)P(B)\). Random variables are independent when events specifying their values factor this way. Choosing objects without replacement usually creates dependence.

1. Indicator variables and linearity

For an event \(A\), let \(I_A=[A]\) be 1 when it occurs and 0 otherwise. Its average is therefore \(E[I_A]=P(A)\). If a quantity is a count, try to express it as a sum of one indicator per possible contribution:

\[X=\sum_i [A_i],\qquad E[X]=\sum_iP(A_i),\]

whether the events are independent is irrelevant. We use only distributivity of expectation over addition, not a product rule. This is the first tool for expected inversions, occupied boxes, surviving edges, and distinct values.

The proof explicitly exchanges two finite sums:

\[E\!\left[\sum_i I_{A_i}\right] =\sum_\omega p_\omega\sum_i I_{A_i}(\omega) =\sum_i\sum_{\omega\in A_i}p_\omega =\sum_iP(A_i).\]

The inner sum is the probability mass where contribution \(i\) exists. For nonnegative infinite sums the exchange remains valid, possibly with value infinity; arbitrary signed infinite sums need convergence control.

Worked example. In a uniformly random permutation of \(n\) items, each pair is inverted with probability \(1/2\). Hence the expected inversion count is \(\binom n2/2\), without describing any transition process.

For a second model, throw \(m\) balls independently into \(n\ge1\) equally likely boxes. Let \(I_j\) indicate that box \(j\) is occupied. Its complement means all balls missed it, with probability \((1-1/n)^m\), so the expected occupied count is \(n(1-(1-1/n)^m)\). With \(m=n=2\), the four ordered placements occupy \(1,2,2,1\) boxes, averaging \(3/2\). Occupancy indicators are dependent; linearity avoids needing their joint distribution.

For products, independence does matter: \(E[XY]=E[X]E[Y]\) is not generally true. Condition instead when dependence is awkward.

2. Conditioning and the law of total expectation

Partition outcomes by the next random choice. The events \(Y=y\) are disjoint and cover all outcomes, so averaging in two stages gives

\[E[X]=\sum_{y:P(Y=y)>0} P(Y=y)E[X\mid Y=y].\]

Each term equals \(\sum_{\omega:Y(\omega)=y}p_\omega X(\omega)\); the disjoint classes partition the original expectation sum. Zero-probability events are omitted because discrete conditioning there is undefined.

The common self-loop pattern comes from an action that leaves the state unchanged with probability \(p\), while the other outcomes have probabilities \(q_i\) with \(p+\sum_iq_i=1\):

\[E=s+pE+\sum_iq_iE_i \quad\Longrightarrow\quad E=\frac{s+\sum_iq_iE_i}{1-p}.\]

Here \(s\) is the finite expected immediate cost and \(p<1\). The numerator is the immediate cost plus the expected cost after a genuine state change; division conditions on eventually leaving the self-loop. Never implement an iterative self-reference before algebraically removing it. If \(p=1\) in a nonterminal state whose target can be reached only after leaving, the target is unreachable and the hitting expectation is infinite.

For a fair die that is rerolled until it shows \(4,5,\) or \(6\), one roll costs one and fails with probability \(1/2\). Thus \(E=1+E/2\), so \(E=2\). The division does not assume that attempts are bounded; it sums the entire self-loop tail.

An independent finiteness check is the tail-sum formula. For a nonnegative integer time \(T\), the outcome-wise identity \(T=\sum_{k\ge0}[T>k]\) gives \(E[T]=\sum_{k\ge0}P(T>k)\). In the die example \(P(T>k)=2^{-k}\), giving 2 before rearranging any equation involving expectations.

Conditioning can also reduce state: reveal the first special object, the maximum sampled index, or the number of successful trials—whatever makes the remaining process symmetric.

3. Probability DP

Two equivalent state choices are common. Choose the one whose transition is easier to state and whose terminal condition is obvious:

  • p[state]: probability of reaching the state; push mass forward and sum terminal rewards.
  • E[state]: expected remaining cost; pull from successor expectations.

Use probability mass for acyclic processes and distributions; use expectation states when only one moment is needed. State aggregation is the hard part. Two histories may be merged only when they have the same distribution of future outcomes. Exchangeable objects should be represented by counts, not identities: e.g. \((c1,c2,c3)\) plates containing 1, 2, or 3 sushi. The plate labels do not affect a future random choice, but the counts do.

For \(n\) uniformly chosen plates, let \(E(a,b,c)\) be the time to empty all plates when \(a,b,c\) contain one, two, three pieces. One step gives

\[\begin{aligned} E(a,b,c)&=1+\frac{n-a-b-c}{n}E(a,b,c)\\ &\quad+\frac anE(a-1,b,c)+\frac bnE(a+1,b-1,c) +\frac cnE(a,b+1,c-1). \end{aligned}\]

Include only terms with positive numerators; negative coordinates are never queried. Set \(E(0,0,0)=0\) and divide by \((a+b+c)/n\) at nonterminal states. Every remaining transition decreases \(a+2b+3c\) by one, proving an acyclic evaluation order. There are \(O(n^3)\) states with constant transitions each. For two plates, \(E(1,0,0)=2\), \(E(2,0,0)=3\), but \(E(0,1,0)=4\). Total sushi alone is therefore an invalid state: equal totals can have different future distributions.

If transitions strictly increase/decrease a measure, topologically order states. Otherwise you have cycles and need equations.

4. Markov chains and absorbing systems

In a Markov chain, the current state determines the next-state distribution; history has no additional effect. First restrict to states reachable from the start, make the chosen terminal set absorbing, and check that every remaining state can reach it along positive-probability edges. For a finite chain this excludes a closed nonterminal recurrent class. Only then partition into transient states and absorbing states. A transient state may be revisited; an absorbing state, once entered, remains forever:

\[P=\begin{pmatrix}Q&R\\0&I\end{pmatrix}.\]

Starting from a transient state costs one step, then moves according to \(Q\). Writing that first-step equation simultaneously for all states gives expected hitting times

\[t=\mathbf1+Qt,\qquad (I-Q)t=\mathbf1.\]

For absorption in a chosen target class, the probability vector satisfies \((I-Q)h=Rb\), where \(b\) is \(1\) on target absorbing states and \(0\) on the other absorbing states. The fundamental matrix \(N=(I-Q)^{-1}=I+Q+Q^2+\cdots\) has N[i][j] equal to the expected number of visits to transient state \(j\) starting at \(i\), counting the initial visit when \(i=j\): \(Q^r\) records being there after \(r\) transitions.

Why is the inverse legitimate over the reals? For each nonterminal state choose a positive-probability path to absorption. Finitely many states give a common path-length bound \(L\) and lower success probability \(\varepsilon>0\). The chance of surviving \(kL\) steps is at most \((1-\varepsilon)^k\). This geometric tail proves finite expectation and \(Q^k\to0\). Now \((I-Q)(I+\cdots+Q^k)=I-Q^{k+1}\) tends to \(I\), justifying the inverse series. An infinite state space need not have common \(L,\varepsilon\): almost-sure termination alone then need not imply finite mean.

NoteExample: a two-state cycle

From \(A\), stop with probability \(1/2\) and move to \(B\) otherwise. From \(B\), move to \(A\) with probability \(1/4\) and stop otherwise. Then \(t_A=1+t_B/2\) and \(t_B=1+t_A/4\), giving \(t_A=12/7\), \(t_B=10/7\). Memoized calls \(A\to B\to A\) never finish; solve the equations together. If both transitions instead have probability one, the equations become \(t_A=1+t_B\), \(t_B=1+t_A\), inconsistent for finite times. The hitting expectation is infinity.

You do not normally invert a matrix explicitly: solve linear systems. Dense cost is \(O(S^3)\). Exploit banded, tridiagonal, monotone, or graph structure. For a finite chain, the hitting time of the chosen absorbing set has finite expectation precisely when that set is reached with probability one from the start state. Reaching some other absorbing class does not count as success.

5. Generating-function connections

For a nonnegative integer-valued random variable \(X\), the probability generating function stores the whole distribution as coefficients:

\[G_X(z)=E[z^{X}]=\sum_kP(X=k)z^{k}.\]

Independent sums multiply PGFs because \(z^{X+Y}=z^Xz^Y\) and expectation of a product factors under independence. Moreover \(G'_X(1)=E[X]\) and \(G''_X(1)=E[X(X-1)]\) when those moments are finite. The variance \(\operatorname{Var}(X)=E[(X-E[X])^2]\), derived in the next section, is therefore

\[\operatorname{Var}(X)=G''_X(1)+G'_X(1)-G'_X(1)^2.\]

This turns repeated independent dice/steps into polynomial multiplication.

First-step recurrences translate into rational GFs. Suppose we independently continue with probability \(r<1\) and stop with probability \(1-r\), accumulating an independent step with PGF \(A(z)\) each time we continue. The number \(K\) of steps has \(P(K=k)=(1-r)r^k\), so the total has PGF

\[\sum_{k\ge0}(1-r)r^k A(z)^k=\frac{1-r}{1-rA(z)}.\]

The normalization gives value one at \(z=1\). In contrast, \(1/(1-A(z))\) with \(A(1)=1\) typically counts renewal visits and is not a PGF. Formal inversion requires a unit constant term; real probability calculations require the corresponding convergence justification. These are distinct contracts.

6. Variance, covariance, and second-moment states

The variance \(\operatorname{Var}(X)=E[(X-E[X])^2]\) measures squared deviation from the mean. Expanding gives \(\operatorname{Var}(X)=E[X^2]-E[X]^2\). Define \(\operatorname{Cov}(X,Y)=E[XY]-E[X]E[Y]\) for finite-second-moment variables. Expanding the square of a sum gives

\[\operatorname{Var}\!\left(\sum_i X_i\right) =\sum_i\operatorname{Var}(X_i)+2\sum_{i<j}\operatorname{Cov}(X_i,X_j).\]

Independence makes covariance zero; linearity alone does not. If \(X\) is one fair-coin indicator and \(Y=X\), then \(\operatorname{Var}(X+Y)=1\), while \(\operatorname{Var}(X)+\operatorname{Var}(Y)=1/2\). For an indicator with probability \(p\), \(I^2=I\) gives variance \(p(1-p)\).

For a unit-cost absorbing process, let \(m_i=E[T_i^2]\), with terminal values \(t_i=m_i=0\). Conditional on next state \(j\), \(T_i=1+T_j\), so

\[m_i=1+2\sum_jP_{ij}t_j+\sum_jP_{ij}m_j.\]

Solve the first-moment system first, then reuse its coefficient matrix for the second moment; variance is \(m_i-t_i^2\). For fair-die stopping, \(t=2\) and \(m=1+(2t+m)/2\), giving \(m=6\) and variance 2. The geometric tail bound for a finite absorbing chain ensures these moments exist.

7. Choosing actions by expected cost

Suppose action \(a\) costs \(c_a>0\), stays at the state with probability \(p_{0,a}<1\), and otherwise moves only to already solved states \(j\) with probabilities \(p_{j,a}\). Repeating it whenever still here has value

\[V_a=\frac{c_a+\sum_jp_{j,a} E_j}{1-p_{0,a}}.\]

The optimal value is \(V=\min_a V_a\). Indeed, in the Bellman equation \(E=\min_a(c_a+p_{0,a}E+\sum_jp_{j,a}E_j)\), each action’s right side at \(V\) is at least \(V\), and an action attaining the minimum gives equality. Positive costs and progress justify the proper policy. Comparing unnormalized numerators would confuse cost per attempt with cost per progress.

Action A costing 1 with success probability \(1/4\) has completion cost 4. Action B costing 2 with success probability \(3/4\) has completion cost \(8/3\), so B wins. General cycles with action choices form a Markov decision process; a self-loop division or a fixed-policy linear solve does not optimize every such graph.

8. Numerical and modeling pitfalls

  • “Uniformly select an available action” changes probabilities as the state changes.
  • Expected ratio is not ratio of expectations.
  • Modulo probabilities require all denominators invertible; this evaluates the same rational equations in a field, but field values have no ordering and do not make an infinite real expectation finite.
  • For double, use pivoting in cyclic systems and avoid subtracting nearly equal probabilities.
  • Invertible transition denominators do not guarantee a nonsingular modular system. For \(Q=\left(\begin{smallmatrix}0&1/2\\1/2&0\end{smallmatrix}\right)\), \(\det(I-Q)=3/4\), zero modulo 3 although 2 is a unit. The rational expected times both simplify to 2, but the modular equations have multiple solutions; field elimination alone cannot identify the intended rational specialization.
  • An unreachable absorbing state means infinite expectation, not a large finite DP value.
  • Memoized recursion on a cyclic state graph never resolves the cycle.

9. Practice, in order

  1. Foundation — Sushi, Educational DP J (English). Symmetry compression and a self-loop. Official editorial.
    Hints
    1. Keep only counts of plates with 1, 2, and 3 pieces.
    2. Choosing an empty plate is a self-loop.
    3. Move that term to the left; evaluate states by total sushi count.
  2. Advanced — Game on Tree, CF 280C. Indicators and symmetry.
    Hints
    1. A vertex contributes exactly when it is removed directly.
    2. Among the vertices on its root path, which must be selected first?
    3. Each is equally likely; sum the reciprocal depth contributions.
  3. Advanced — Roulettes, AtCoder ABC314 E. Optimal expected-cost DP with zero outcomes.
    Hints
    1. Let dp[x] be minimum expected extra cost from score \(x\).
    2. Evaluate each roulette by conditioning on its outcomes.
    3. Remove zero-outcome self-loops algebraically before taking the minimum.
  4. Mastery — Intergalaxy Trips, CF 605E. Greedy ordering of expectation equations.
    Hints
    1. Suppose a set of vertices already has finalized expectations to the target.
    2. Maintain for every other vertex the probability that all tried finalized destinations fail and its accumulated expected cost.
    3. Finalize the smallest current expectation, Dijkstra-style, and update all remaining vertices.
  5. Mastery — Broken Robot, CF 24D. Banded linear equations.
    Hints
    1. Write the expectation equation for every cell in one row.
    2. The next row is already known if rows are processed bottom-up.
    3. Each row becomes a tridiagonal system; solve it by elimination.

Exercises with solutions

1. Concept check: a biased average

A random variable is 0 with probability \(1/2\), 1 with probability \(1/3\), and 3 with probability \(1/6\). Find its mean and variance. Hint: compute \(E[X^2]\) separately rather than averaging squared probabilities.

NoteSolution

\(E[X]=1/3+3/6=5/6\) and \(E[X^2]=1/3+9/6=11/6\). Thus the variance is \(11/6-25/36=41/36\). Uniformly averaging the three listed values would give the wrong sample-space weights.

2. Application: collect two different coupons

Each independent draw chooses either of two types uniformly. Find the mean and variance of the draws needed to see both. Hint: the first draw always finds a new type; after that the success probability is \(1/2\).

NoteSolution

Write \(T=1+G\), where \(G\) is the number of further draws through the first success. Its mean is 2 and variance 2 by the self-loop second-moment example. Thus \(E[T]=3\) and \(\operatorname{Var}(T)=2\). The constant first draw changes the mean but not the variance. For \(n\) equally likely types, decomposing into phases with \(k\) seen gives mean \(\sum_{k=0}^{n-1}n/(n-k)\); independence of phases is unnecessary for this expectation sum.

3. Advanced: target probabilities versus target times

At state \(S\), an action reaches success with probability \(1/4\), permanent failure with probability \(1/4\), and returns to \(S\) otherwise. Find the success probability, the time to either terminal, and the unconditional time to success. Hint: distinguish the terminal set in each question.

NoteSolution

\(h=1/4+h/2\) gives \(h=1/2\). The time to either terminal is \(t=1+t/2=2\). The hitting time of success is infinite on the failure event, which has positive probability, so its unconditional expectation is infinite. Assigning failure value zero is correct for the success probability and the time to either terminal, but incorrect for the time to success alone.

4. Synthesis: expected selected ancestors

Give vertices of a rooted tree independent distinct random priorities, and select a vertex exactly when its priority is least on its root path. Derive the expected number selected. Hint: define one indicator per vertex, not one state per subset of surviving vertices.

NoteSolution

If the root path contains \(d_v\) vertices, each is equally likely to have the least priority. Hence \(P(v\text{ selected})=1/d_v\) and the expectation is \(\sum_v1/d_v\). A DFS computes all \(d_v\) in \(O(n)\) time. The indicators strongly depend on each other, but no product of expectations was used. To apply this to a deletion process such as CF280 C, first justify that assigning random priorities in advance produces the same relative-choice distribution as the process; the formula follows only after that model bridge.

Contest checklist and reference

  • What are the equally likely objects, and what exactly is the reward?
  • Can each contribution be an indicator? Do any products require dependence?
  • Does the state determine every future transition probability?
  • Does a ranking function remove cycles, or are simultaneous equations needed?
  • Which absorbing set is intended, and is it reached almost surely?
  • Are all real expectations finite and all modular operations licensed?
