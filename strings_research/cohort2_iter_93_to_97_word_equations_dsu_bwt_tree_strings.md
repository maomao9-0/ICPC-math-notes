## Iteration 93: Word Equations, Binary-Lifting DSU (`倍增并查集`) & Huge-Length Fine–Wilf Contractions

### 1. The Diagnostic Signal (Why Naive String Structures & Point-By-Point DSU Fail)

Consider an unknown string $S[1..N]$ over an alphabet $\Sigma$ subject to $M$ bulk equality constraints of two flavors:
1. **Substring Equality (Orientation-Preserving)**: $S[l_1 .. l_1 + L - 1] = S[l_2 .. l_2 + L - 1]$, meaning $S[l_1 + d] = S[l_2 + d]$ for all $0 \le d < L$.
2. **Substring Reversal / Palindrome Equality (Orientation-Reversing)**: $S[l_1 .. l_1 + L - 1] = S[l_2 .. l_2 + L - 1]^R$, meaning $S[l_1 + d] = S[l_2 + L - 1 - d]$ for all $0 \le d < L$. (In particular, requiring $S[l..r]$ to be a palindrome is the self-reversal constraint $S[l..r] = S[l..r]^R$.)

After all $M$ constraints are imposed, we must either count the number of valid strings $S \in \Sigma^N$ ( typically $|\Sigma|^{C}$ where $C$ is the number of independent connected components of character positions, adjusted for fixed boundary characters as in `[SCOI2016] 萌萌哒`), check consistency with point inequalities $S[i] \ne S[j]$, or reconstruct the lexicographically smallest valid string.

**Why Naive Approaches Fail**:
- **Naive Pointwise DSU ($O(NM \alpha(N))$)**: A single constraint of length $L = \Theta(N)$ forces $L$ parallel character merges $\text{union}(l_1 + d, l_2 + d)$. Performing this loop for $M$ queries takes $O(NM \alpha(N))$ time, which TLEs when $N, M \le 10^5$ or $10^6$.
- **Segment Tree / Treap Interval Splitting**: Unlike range-update / range-query problems where an interval $[l, r]$ receives a uniform scalar tag, a word equation $S[l_1..r_1] = S[l_2..r_2]$ couples each offset $l_1 + d$ with a *distinct* partner $l_2 + d$. Two overlapping constraints of lengths $L_1, L_2$ creates a translational group generated by shifts $s_1 = l_2 - l_1$ and $s_2 = l'_2 - l'_1$, which cannot be maintained as lazy tags on a single segment tree.
- **Huge-Length Regime ($N \le 10^{18}, M \le 10^3$)**: When $N \le 10^{18}$ (e.g., counting valid strings of length $10^{18}$ under a small number of long substring/palindrome equations), even $O(N \log N)$ states cannot be materialized in memory.

### 2. The Combinatorial Word Invariant (Power-of-Two Block Decomposition & Potential Amortization)

#### 2.1 Sparse-Table Block Decomposition of Translational Equalities
Every interval equality $S[l_1 .. l_1 + L - 1] = S[l_2 .. l_2 + L - 1]$ of arbitrary length $L \ge 1$ is equivalent to **at most two** overlapping power-of-two block equalities of length $2^k$, where $k = \lfloor \log_2 L \rfloor$:
$$S[l_1 .. l_1 + 2^k - 1] = S[l_2 .. l_2 + 2^k - 1] \quad \text{and} \quad S[l_1 + L - 2^k .. l_1 + L - 1] = S[l_2 + L - 2^k .. l_2 + L - 1].$$
Why is this an exact logical equivalence (no information lost, no extra constraints introduced)?
- **Soundness ($\implies$)**: Since $2^k \le L$, both sub-blocks $[l_1, l_1 + 2^k - 1]$ and $[l_1 + L - 2^k, l_1 + L - 1]$ lie entirely inside $[l_1, l_1 + L - 1]$, and their shifts to $l_2$ match the offset $l_2 - l_1$.
- **Completeness ($\impliedby$)**: Because $2^k > L/2$, we have $2^k + 2^k \ge L$, so the prefix block of length $2^k$ and the suffix block of length $2^k$ cover every offset $d \in [0, L-1]$. Any offset $d$ falling in the overlap $[L - 2^k, 2^k - 1]$ simply asserts $S[l_1 + d] = S[l_2 + d]$ twice, and equality is idempotent!

Let $K = \lfloor \log_2 N \rfloor$. We define $K+1$ levels of Disjoint Set Unions $\text{DSU}_0, \text{DSU}_1, \dots, \text{DSU}_K$. In $\text{DSU}_k$, node $i \in [1, N - 2^k + 1]$ represents the **block** $B_k(i) = S[i .. i + 2^k - 1]$.
An edge/equivalence $B_k(i) \equiv B_k(j)$ in $\text{DSU}_k$ asserts the block word equation $S[i .. i + 2^k - 1] = S[j .. j + 2^k - 1]$.

#### 2.2 The Pushdown Compatibility Invariant
A block equality of length $2^k$ at level $k > 0$ is algebraically equivalent to **two** half-block equalities of length $2^{k-1}$ at level $k-1$:
$$B_k(i) \equiv B_k(j) \iff B_{k-1}(i) \equiv B_{k-1}(j) \;\land\; B_{k-1}(i + 2^{k-1}) \equiv B_{k-1}(j + 2^{k-1}).$$
Furthermore, if $B_k(i_1), B_k(i_2), \dots, B_k(i_m)$ form a single connected component in $\text{DSU}_k$ with canonical representative $r = \text{find}_k(i_t)$, then pushing down the component requires **only** $m-1$ spanning-tree unions at level $k-1$: for each $i \ne r$, we merge $(i, r)$ and $(i + 2^{k-1}, r + 2^{k-1})$ in $\text{DSU}_{k-1}$. By transitivity of $\text{DSU}_{k-1}$, all $\binom{m}{2}$ pairwise equalities on both halves are preserved!

```
Level k:     [----- B_k(i) -----]   ===   [----- B_k(r) -----]
                      |                            |
                 split into                   split into
               /             \              /             \
Level k-1: [ B_{k-1}(i) ][ B_{k-1}(i+2^{k-1}) ] === [ B_{k-1}(r) ][ B_{k-1}(r+2^{k-1}) ]
```

#### 2.3 Online Recursive Splitting & Potential Function Bound
What if we need to maintain $\text{DSU}_0$ **online** (e.g., to check whether a new equality violates a known inequality $S[x] \ne S[y]$ before accepting it)?
Define $\text{merge}(k, i, j)$ recursively:
1. Find roots $u = \text{find}_k(i)$ and $v = \text{find}_k(j)$ in $\text{DSU}_k$.
2. **Short-Circuit Base Case**: If $u = v$, return immediately! The equality $B_k(i) \equiv B_k(j)$ is already implied by $\text{DSU}_k$ (and therefore already pushed down to $\text{DSU}_{k-1}, \dots, \text{DSU}_0$).
3. Otherwise, unite $u$ and $v$ in $\text{DSU}_k$. If $k > 0$, recursively call $\text{merge}(k-1, i, j)$ and $\text{merge}(k-1, i + 2^{k-1}, j + 2^{k-1})$.

**Theorem 93.1 (Amortized Complexity of Online Binary-Lifting DSU)**.
*Across any sequence of $M$ arbitrary substring equality queries on a string of length $N$, the total number of recursive calls to $\text{merge}$ is $O(M + N \log N)$, taking $O((M + N \log N)\alpha(N))$ total time.*

*Proof*. Define the potential function $\Phi = \sum_{k=0}^{\lfloor \log_2 N \rfloor} c_k$, where $c_k \le N$ is the number of connected components in $\text{DSU}_k$. Initially $\Phi \le N(\lfloor \log_2 N \rfloor + 1) = O(N \log N)$, and always $\Phi \ge 0$.
Every recursive call $\text{merge}(k, i, j)$ is either:
- **Productive**: $\text{find}_k(i) \ne \text{find}_k(j)$. It merges two components in $\text{DSU}_k$, strictly decreasing $c_k$ by $1$ (so $\Delta \Phi = -1$), and spawns at most $2$ child calls at level $k-1$. Since $\Phi$ can decrease at most $N(\lfloor \log_2 N \rfloor + 1)$ times in total, there are at most $N \log_2 N + N$ productive calls across the entire execution!
- **Unproductive (Short-Circuited)**: $\text{find}_k(i) = \text{find}_k(j)$. It terminates in $O(\alpha(N))$ time without spawning children. Every unproductive call is either one of the $2M$ top-level calls initiated by the queries, or a direct child of a productive call at level $k+1$.
Hence total calls $\le 2M + 3 \cdot (\text{productive calls}) \le 2M + 3N(\lfloor \log_2 N \rfloor + 1) = O(M + N \log N)$. $\blacksquare$

### 3. The Reverse-Engineering Scratchpad (Offline Pushdown, Reversals & Huge-$N$ Contractions)

#### 3.1 Offline Top-Down Sweep (`[SCOI2016] 萌萌哒` Paradigm)
When all $M$ constraints are given offline, we avoid recursion entirely:
- For each query $(l_1, l_2, L)$, compute $k = \lfloor \log_2 L \rfloor$ and execute two unions in $\text{DSU}_k$: $\text{union}_k(l_1, l_2)$ and $\text{union}_k(l_1 + L - 2^k, l_2 + L - 2^k)$.
- Sweep $k$ downward from $\lfloor \log_2 N \rfloor$ down to $1$: for each $i \in [1, N - 2^k + 1]$, let $r = \text{find}_k(i)$. If $r \ne i$, execute:
  $$\text{union}_{k-1}(i, r) \quad \text{and} \quad \text{union}_{k-1}(i + 2^{k-1}, r + 2^{k-1}).$$
- At the end of the sweep, $\text{DSU}_0$ holds the exact connected components of individual indices $1 \dots N$.

#### 3.2 Handling Palindromes & Reversed Substring Equalities
How do we incorporate $S[l_1 .. l_1 + L - 1] = S[l_2 .. l_2 + L - 1]^R$?
There are two clean isomorphic formulations:
1. **Concatenated String Formulation ($S' = S \cdot S^R$ of length $2N$)**:
   Map index $i \in [1, N]$ of $S^R$ to $2N + 1 - i$ in $S'$. First, lock the global reversal symmetry at level $0$: for each $i \in [1, N]$, $\text{union}_0(i, 2N + 1 - i)$. Then any reversed constraint $S[l_1 .. r_1] = S[l_2 .. r_2]^R$ becomes an ordinary orientation-preserving substring equality in $S'$:
   $$S'[l_1 .. r_1] = S'[2N + 1 - r_2 .. 2N + 1 - l_2],$$
   which is handled directly by the standard 1-directional binary-lifting DSU on length $2N$!
2. **Signed / Parity-Edge DSU on Blocks**:
   Keep node indices $1 \dots N$ at each level $k$, but attach an orientation bit $\text{rev} \in \{0, 1\}$ to each DSU edge: $(u, v, 0)$ means $B_k(u) = B_k(v)$, whereas $(u, v, 1)$ means $B_k(u) = B_k(v)^R$. When pushing down $(i, r, \text{rev})$ from level $k$ to $k-1$:
   - If $\text{rev} = 0$: merge $(i, r, 0)$ and $(i + 2^{k-1}, r + 2^{k-1}, 0)$ at level $k-1$.
   - If $\text{rev} = 1$: the left half of $B_k(i)$ equals the reversed *right* half of $B_k(r)$, and the right half of $B_k(i)$ equals the reversed *left* half of $B_k(r)$! Thus we merge:
     $$\text{union}_{k-1}(i, r + 2^{k-1}, 1) \quad \text{and} \quad \text{union}_{k-1}(i + 2^{k-1}, r, 1).$$
   Notice that at level $k=0$ ($2^0 = 1$), a single character equals its own reversal, so the orientation bit $\text{rev}$ is ignored at $\text{DSU}_0$. The signed-edge formulation halves the memory footprint compared to $S \cdot S^R$!

#### 3.3 Huge-Length Word Equations ($N \le 10^{18}, M \le 10^3$) via Fine–Wilf Block Contraction
Suppose $N \le 10^{18}$ and we are given $M \le 10^3$ substring or palindrome equations. How do we count the number of independent character degrees of freedom?
1. **Endpoint Coordinate Compression into Atomic Intervals**:
   Initially, the domain $[1, N]$ is partitioned into elementary intervals by query endpoints. However, an equation $S[l_1..r_1] = S[l_2..r_2]$ with $l_1 < l_2 \le r_1$ induces a **period** $p = l_2 - l_1$ on the union interval $[l_1, r_2]$.
2. **Iterative Block-Aligned Splitting & Euclidean Period Reduction (Plandowski / Rytter / Fine–Wilf Engine)**:
   Consider a bipartite/translational graph of intervals. Whenever two intervals $I_1 = [a_1, b_1]$ and $I_2 = [a_2, b_2]$ of equal length $L$ are equated:
   - **Disjoint Case ($I_1 \cap I_2 = \emptyset$)**: Simply contract $I_2$ into $I_1$ (every position $x \in I_2$ is replaced by $x - a_2 + a_1 \in I_1$).
   - **Overlapping Translation Case ($a_1 < a_2 \le b_1$, shift $p = a_2 - a_1$)**: The interval $[a_1, b_2]$ has period $p$. By division with remainder, every position in $[a_2, b_2]$ is congruent $\bmod p$ to a canonical representative inside the prefix $[a_1, a_1 + p - 1]$. If $[a_1, b_2]$ already had another period $q$, by the **Fine–Wilf Theorem**, on any overlap of length $\ge p + q - \gcd(p, q)$, the two periods collapse into a single period $g = \gcd(p, q)$! On shorter overlaps ($< p + q - \gcd(p, q)$), replacing the larger period $q$ by $q \bmod p$ shifts the active prefix of length $q - p$, mimicking the Euclidean algorithm in $O(\log(\max L))$ steps.
   - **Overlapping Reversal (Palindrome) Case**: A palindrome constraint on $[a, b]$ folds the right half $[ \lfloor (a+b)/2 \rfloor + 1, b ]$ onto the reversed left half $[a, \lceil (a+b)/2 \rceil ]$, halving the active length immediately.

### 4. Boundary Pitfalls & Broken-Invariant Counterexamples

1. **The Midpoint-Split Pitfall in Signed Palindrome Pushdown**:
   In the signed-edge DSU (Section 3.2), when pushing down $(i, r, \text{rev}=1)$ from level $k$ to $k-1$, a common bug is merging $(i, r, 1)$ and $(i+2^{k-1}, r+2^{k-1}, 1)$.
   - *Counterexample*: Let $k=1$ ($2^k = 2$). $B_1(1) = S[1..2]$ and $B_1(3) = S[3..4]$ with $\text{rev}=1$ means $S[1..2] = (S[3..4])^R = S[4]S[3]$, so $S[1]=S[4]$ and $S[2]=S[3]$. Merging $(1, 3, 1)$ and $(2, 4, 1)$ at level $0$ would instead force $S[1]=S[3]$ and $S[2]=S[4]$, turning a reversal into a translation! Always swap the half-offsets when $\text{rev}=1$.
2. **Leading-Zero Asymmetry (`[SCOI2016] 萌萌哒`)**:
   When counting valid decimal strings of length $N$ where $S[1] \ne \text{'0'}$, the connected component containing index $1$ in $\text{DSU}_0$ has $9$ choices ($\text{'1'}..\text{'9'}$), whereas every other component has $10$ choices ($\text{'0'}..\text{'9'}$), yielding $9 \times 10^{C-1} \bmod (10^9+7)$. If any constraint forces $S[1] = \text{'0'}$, the answer drops to $0$.

## Iteration 94: String Inequality Graphs, Lexicographical Constraints & Inverse String Reconstruction

### 1. The Diagnostic Signal (Why Substring Inequalities Cannot Be Pushed Down Like Equalities)

Suppose we are given a system of **lexicographical substring constraints** on an unknown string $S[1..N]$:
- Strict inequalities: $S[l_1 .. r_1] < S[l_2 .. r_2]$,
- Non-strict inequalities: $S[l_1 .. r_1] \le S[l_2 .. r_2]$,
- Or an entire auxiliary string structure—such as a KMP prefix-function array $\pi[1..N]$, a Z-array $Z[1..N]$, a Manacher radius array $R[1..2N-1]$, or a Suffix Array $\text{SA}[1..N]$ (optionally with its LCP array $\text{height}[2..N]$)—and asked to decide whether a valid string $S$ over an alphabet of size $|\Sigma| \le K$ exists, find the minimum required alphabet size $K_{\min}$, or construct the lexicographically smallest valid $S$.

**Why Binary-Lifting Pushdown Fails for `$<$`**:
Unlike equality ($AB = CD \iff A=C \land B=D$), lexicographical inequality is **non-decomposable**:
$$AB < CD \iff (A < C) \;\lor\; (A = C \;\land\; B < D).$$
This disjunction means we cannot split $S[l_1..r_1] < S[l_2..r_2]$ into independent power-of-two block inequalities without knowing the exact **Longest Common Prefix (LCP)** $d = \text{LCP}(S[l_1..r_1], S[l_2..r_2])$.

---

### 2. The Combinatorial Word Invariant (LCP Witness Decomposition & Inverse Automaton Dualities)

#### 2.1 Decomposition of Lexicographical Inequalities
By definition of lexicographical order on strings $U = S[l_1..r_1]$ of length $L_1$ and $V = S[l_2..r_2]$ of length $L_2$:
$$U < V \iff \begin{cases} \text{either } L_1 < L_2 \text{ and } U = V[1..L_1], \\ \text{or } \exists d \in [0, \min(L_1, L_2) - 1] \text{ such that } U[1..d] = V[1..d] \text{ and } U[d+1] < V[d+1]. \end{cases}$$

This yields a fundamental bridge between **Wave 5A's Binary-Lifting DSU** and **Directed Constraint Graphs**:
- **Case A (Known LCP / Prefix-Array / SA + LCP Restoration)**: When the LCP length $d$ between $U$ and $V$ is fixed by the problem input (e.g., given $\text{SA}$ and $\text{height}$, or given $Z[i]$ / $\pi[i]$), every substring comparison compiles deterministically into:
  1. One **bulk equality constraint** $S[l_1 .. l_1 + d - 1] = S[l_2 .. l_2 + d - 1]$ of length $d$ (fed into Binary-Lifting DSU), and
  2. At most one **point character inequality** $S[l_1 + d] < S[l_2 + d]$ (or $S[l_1 + d] \ne S[l_2 + d]$) at the mismatch index $d+1$!
- **Case B (Unknown LCP, Fixed Alphabet $|\Sigma| = 2$ or Small $|\Sigma|$)**: No generally efficient decomposition exists for arbitrary unanchored $S[l_1..r_1] < S[l_2..r_2]$ without fixing $d$ (in fact, general substring inequality feasibility with arbitrary overlaps is NP-hard!), *unless* the inequalities are anchored by a Suffix Array, Lyndon factorization, or already-resolved prefix equalities, or we greedily resolve characters from left to right.

#### 2.2 Inverse String Reconstruction Dualities (KMP $\pi$, Z-Array, Manacher, SA)
Every classic linear-time string array is the exact transcript of $O(N)$ equality constraints and $O(N)$ mismatch inequalities:

#### 2.3 Proof of the Suffix Array Adjacency Theorem (Burrows–Wheeler / ISA Rank Criterion)
Why does $S[\text{SA}[1..N]]$ sort the suffixes in the exact order $\text{SA}[1], \dots, \text{SA}[N]$ if and only if for every $i \in [1, N-1]$ with $u = \text{SA}[i]$ and $v = \text{SA}[i+1]$:
$$S[u] \le S[v] \quad (\text{when } \text{rk}[u+1] < \text{rk}[v+1]), \qquad S[u] < S[v] \quad (\text{when } \text{rk}[u+1] > \text{rk}[v+1])\text{?}$$
*Proof*:
1. **Necessity ($\implies$)**: Because suffix $S[u..N]$ precedes $S[v..N]$ in $\text{SA}$, their first characters must satisfy $S[u] \le S[v]$. If $S[u] = S[v]$, comparing $S[u..N]$ and $S[v..N]$ strips the common first character and reduces to comparing the remaining suffixes $S[u+1..N]$ and $S[v+1..N]$. Thus $S[u] = S[v]$ is permitted **only** if $\text{rk}[u+1] < \text{rk}[v+1]$; whenever $\text{rk}[u+1] > \text{rk}[v+1]$, we must have the strict inequality $S[u] < S[v]$.
2. **Sufficiency ($\impliedby$)**: Proceed by backward induction on suffix length (or equivalently, suppose for contradiction that some adjacent pair $u = \text{SA}[i], v = \text{SA}[i+1]$ is inverted: $S[u..N] > S[v..N]$, picking the pair maximizing $\min(|S[u..N]|, |S[v..N]|)$). Since $S[u] \le S[v]$ by construction, $S[u..N] > S[v..N]$ forces $S[u] = S[v]$ and $S[u+1..N] > S[v+1..N]$. Because $S[u] = S[v]$ was allowed, we have $\text{rk}[u+1] < \text{rk}[v+1]$ in the target array $\text{SA}$. Thus in the target ordering between $\text{rk}[u+1]$ and $\text{rk}[v+1]$, there must be at least one adjacent pair $(\text{SA}[j], \text{SA}[j+1])$ that is also inverted in $S$, and since $u+1, v+1$ are strictly shorter suffixes (or we trace the first mismatch depth $d$), at the mismatch depth $d$ the pair $(\text{SA}[j], \text{SA}[j+1])$ has distinct first characters $S[u+d] > S[v+d]$, contradicting the monotonically non-decreasing condition $S[\text{SA}[1]] \le S[\text{SA}[2]] \le \dots \le S[\text{SA}[N]]$! $\blacksquare$

### 3. The Reverse-Engineering Scratchpad (SCCs, DAG Longest Path & 2-SAT Compilation)

#### 3.1 Compiling Equalities + Inequalities ($<$ and $\le$) into SCC + DAG Longest Path
Given a system of substring equalities, strict inequalities $S[u] < S[v]$, and weak inequalities $S[u] \le S[v]$:
1. **Phase 1 (Equality Contraction via Binary-Lifting DSU)**:
   Push all substring equalities through the Binary-Lifting DSU (`Iter 93`) down to $\text{DSU}_0$. Replace every index $i \in [1, N]$ by its component root $r(i) = \text{find}_0(i)$.
2. **Phase 2 (Directed Inequality Graph & Tarjan SCC)**:
   Build a directed weighted graph $G = (V, E)$ on the $\text{DSU}_0$ roots:
   - Each weak inequality $S[u] \le S[v]$ adds a directed edge $r(u) \xrightarrow{w=0} r(v)$.
   - Each strict inequality $S[u] < S[v]$ adds a directed edge $r(u) \xrightarrow{w=1} r(v)$.
   Run Tarjan's Strongly Connected Components (SCC) algorithm on $G$:
   - **Feasibility Criterion**: The system has a valid assignment over an ordered alphabet if and only if **no SCC contains an edge of weight $w = 1$** (including self-loops $r(u) \xrightarrow{1} r(u)$).
   - **Why?**: Any cycle of $0$-weight edges $v_1 \le v_2 \le \dots \le v_k \le v_1$ simply forces $v_1 = v_2 = \dots = v_k$, meaning all vertices in the same SCC must receive the **exact same character**. If any edge inside the SCC has weight $1$ ($v_i < v_j$), the cycle implies $v_i < v_i$, a contradiction!
3. **Phase 3 (DAG Longest Path for Minimum Alphabet Size & Lexicographically Smallest String)**:
   Contract each SCC into a super-node to form a Condensed DAG $\mathcal{D}$ with edge weights $w \in \{0, 1\}$.
   Compute the longest path $\text{dist}[C]$ to each SCC $C$ in topological order:
   $$\text{dist}[C] = \max \left( \{0\} \cup \{ \text{dist}[P] + w(P \to C) \mid (P \to C) \in \mathcal{D} \} \right).$$
   - The **minimum required alphabet size** is $K_{\min} = 1 + \max_{C} \text{dist}[C]$.
   - Assigning each node in $C$ the character `'a' + dist[C]` simultaneously achieves the **minimum alphabet size** AND the **pointwise lexicographically smallest valid string** $S$!

#### 3.2 Compiling Non-Equality Constraints ($S[u] \ne S[v]$) & Small-Alphabet 2-SAT
When reconstructing from KMP $\pi$, Z-array, or Manacher radii, the negative constraints have the form $S[u] \ne S[v]$ (undirected conflict edges) rather than $S[u] < S[v]$:
- **Lexicographically Smallest String**: After contracting equalities in $\text{DSU}_0$, scan indices $i = 1, 2, \dots, N$ from left to right. If component $r(i)$ is not yet assigned a character, assign it the smallest character $c \in \Sigma$ not already used by any neighbor $r(j)$ in the conflict graph.
- **Binary Alphabet ($|\Sigma| = 2$)**: Every conflict $S[u] \ne S[v]$ is an XOR edge (bipartiteness check on $\text{DSU}_0$ components). If combined with implications or disjunctive constraints (e.g., "at least one of $S[i..j]$ is `'1'`"), compile directly into **2-SAT** in $O(N + M)$ time.

### 4. Boundary Pitfalls & Broken-Invariant Counterexamples

1. **The Phantom Equality Trap in Z-Array / Manacher Reconstruction**:
   Suppose you are given an arbitrary array $Z[1..N]$ and asked whether a string $S$ has Z-array equal to $Z$. A classic bug is to push the equalities $S[1..Z[i]] = S[i..i+Z[i]-1]$ into a DSU, check that no mismatch pair $(Z[i]+1, i+Z[i])$ falls in the same DSU component, and immediately return `YES`.
   - *Counterexample*: Consider $N=3$ with input $Z = [3, 0, 1]$, and suppose the alphabet is binary $\Sigma = \{\text{'a'}, \text{'b'}\}$.
     - $i=2, Z[2]=0 \implies S[1] \ne S[2]$.
     - $i=3, Z[3]=1 \implies S[1] = S[3]$.
     So $S[1]=S[3]=\text{'a'}$ and $S[2]=\text{'b'}$, giving $S = \text{"aba"}$, which works!
     Now change the input to $Z = [3, 0, 0]$ on binary alphabet $\Sigma = \{\text{'a'}, \text{'b'}\}$:
     - $Z[2]=0 \implies S[2] \ne S[1]$.
     - $Z[3]=0 \implies S[3] \ne S[1]$.
     Both DSU checks pass (there are no equalities at all, and no self-loops $S[1] \ne S[1]$!). Wait—does $Z=[3, 0, 0]$ work for $\Sigma = \{\text{'a'}, \text{'b'}\}$? Yes, $S = \text{"abb"}$ has $Z=[3, 0, 0]$.
     Now consider $N=4$, input $Z = [4, 2, 0, 0]$ on ANY alphabet:
     - $i=2, Z[2]=2 \implies S[1..2] = S[2..3] \implies S[1]=S[2]=S[3]$, and mismatch $S[3] \ne S[4]$.
     - $i=3, Z[3]=0 \implies$ mismatch $S[1] \ne S[3]$.
     Here DSU catches $S[1]=S[3]$ vs $S[1] \ne S[3]$.
     When *does* DSU miss an invalidity? When $Z[i]$ exceeds $N - i + 1$ (out-of-bounds length), OR when $|\Sigma|$ is too small for the chromatic number of the conflict graph (e.g., a triangle of $\ne$ edges $S[1] \ne S[2], S[2] \ne S[3], S[1] \ne S[3]$ cannot be 2-colored on a binary alphabet!). Therefore, **always construct a candidate string $S$ and re-run the forward Z / KMP / Manacher algorithm on $S$ to verify that its array equals the input!** Re-running the forward algorithm takes $O(N)$ time and automatically catches all chromatic-number, out-of-bounds, and transitivity violations.
2. **Forgetting the Sentinel Rank $\text{rk}[N+1] = 0$ in Suffix Array Reconstruction**:
   In the SA Adjacency Theorem (Section 2.3), when $u = N$ (the 1-character suffix $S[N..N]$), $u+1 = N+1$ is the empty suffix $\epsilon$, which is strictly smaller than every non-empty suffix ($\text{rk}[N+1] = 0$). If your code accesses `rk[u + 1]` without initializing `rk[N + 1] = 0` (or uses 0-indexed ranks where `0` collides with $\text{SA}[0]$), the comparison between $\text{SA}[i] = N$ and $\text{SA}[i+1]$ can invert, producing an off-by-one minimum alphabet size.

## Iteration 95: De Bruijn Graphs, the BEST Theorem, Burrows–Wheeler Transform (BWT) & Wheeler Graphs

### 1. The Diagnostic Signal (When Local $k$-Mer Constraints or Cyclic Shifts Govern Global Strings)

Two deeply connected families of problems translate stringology into directed multigraphs and prefix-sorted cyclic shifts:
1. **$k$-Mer Spectrum Reconstruction & Counting (`De Bruijn + BEST Theorem`)**:
   We are given a dictionary of allowed substrings of length $k$ (or exact multiplicities $c(w)$ for every $k$-mer $w \in \Sigma^k$, or forbidden $k$-mers) and asked to:
   - Construct the shortest superstring containing all $|\Sigma|^k$ words of length $k$ exactly once (a **De Bruijn sequence**, cyclic length $|\Sigma|^k$, linear length $|\Sigma|^k + k - 1$),
   - Reconstruct the lexicographically smallest string $S$ whose $k$-mer multiset equals $\{ (w, c(w)) \}$, or
   - Count the exact number of valid strings $S$ modulo $10^9+7$ when $N \le 10^{18}$ and $\sum c(w) = N - k + 1$.
2. **Compressed Full-Text Indexing & Cyclic-Shift Inversion (`BWT & Wheeler Graphs`)**:
   We are given the last column $L[1..N]$ of the sorted cyclic-shift matrix of a string $S$ (its **Burrows–Wheeler Transform**), or a labeled directed graph $G = (V, E, \Sigma)$ representing a compressed string index, and asked to invert $L \mapsto S$ in $O(N)$ time, count occurrences of a pattern $P[1..M]$ in $O(M)$ steps without a Suffix Array in memory (**FM-Index LF-Mapping**), or maintain interval ranges $[l, r]$ over a **Wheeler DFA**.

**Why Naive String Methods Fail**:
- Keeping track of the last $k-1$ characters in a bitmask DP takes $O(N |\Sigma|^k)$ time and cannot answer "how many strings have exact $k$-mer frequency vector $c$" without exponential state space.
- Inverting BWT by repeatedly sorting pairs $(L[i], \text{prev\_rank}[i])$ simulates Suffix Array doubling in $O(N^2 \log N)$ or $O(N \log^2 N)$ time instead of exploiting the rank-preservation property of stable prepending.

### 2. The Combinatorial Word Invariant (Line-Graph Duality, BEST Bijection & Wheeler Co-Lex Monotonicity)

#### 2.1 De Bruijn Subword-to-Walk Bijection
Let $\mathcal{G}_{k} = (V, E)$ be the **$(k-1)$-dimensional De Bruijn Graph** over $\Sigma$:
- The vertex set is $V = \Sigma^{k-1}$ (every word of length $k-1$).
- For every $k$-mer $w = c_1 c_2 \dots c_k \in \Sigma^k$ with prescribed multiplicity $c(w)$, we place $c(w)$ parallel directed edges from the $(k-1)$-prefix $u = w[1..k-1]$ to the $(k-1)$-suffix $v = w[2..k]$, labeled by the character $w[k]$.

**Fundamental Bijection**: Every string $S$ of length $N \ge k-1$ corresponds bijectively to a walk of $N - k + 1$ edges in $\mathcal{G}_k$: the $i$-th step traverses the edge $S[i .. i+k-2] \xrightarrow{S[i+k-1]} S[i+1 .. i+k-1]$. Consequently, strings with prescribed $k$-mer frequencies $c(w)$ are in **exact 1-to-1 correspondence with Eulerian trails** (or Eulerian circuits for cyclic strings) of the directed multigraph $\mathcal{G}_k$!

#### 2.2 The BEST Theorem (de Bruijn, van Aardenne-Ehrenfest, Smith, Tutte)
How do we count Eulerian circuits in a connected balanced directed multigraph $G = (V, E)$ where every vertex $v \in V$ has $\text{in}(v) = \text{out}(v) = d(v) \ge 1$?

**Theorem 95.1 (BEST Theorem for Directed Multigraphs)**.
*Fix a root vertex $r \in V$ and a distinguished outgoing edge $e_0$ from $r$. The number of distinct edge-labeled Eulerian circuits starting with edge $e_0$ is:*
$$\mathcal{E}_{\text{edge}}(G, e_0) = T_{\text{in}}(G, r) \cdot \prod_{v \in V} \big(d(v) - 1\big)!,$$
*where $T_{\text{in}}(G, r)$ is the number of **directed in-arborescences** (spanning trees directed toward the root $r$), given by Tutte's Directed Matrix-Tree Theorem as the determinant $\det L^{(r)}_{\text{out}}$ of the $(|V|-1) \times (|V|-1)$ cofactor obtained by deleting row $r$ and column $r$ from the out-degree Laplacian:*
$$L_{\text{out}}(u, v) = \begin{cases} d(u) - A(u, u) & \text{if } u = v, \\ -A(u, v) & \text{if } u \ne v. \end{cases}$$
*To count **distinct strings** (where parallel edges between the same $(u, v)$ represent identical $k$-mers and are indistinguishable!), we divide by the edge-multiplicity symmetry factor $\prod_{u, v \in V} A(u, v)!$:*
$$\text{Count}_{\text{strings}}(\text{starting at } u_1 \text{ along } k\text{-mer } w_1) = A(u_1, v_1) \cdot \frac{T_{\text{in}}(G, u_1) \cdot \prod_{v \in V} (d(v) - 1)!}{\prod_{u, v \in V} A(u, v)!}.$$

*Combinatorial Proof of the BEST Bijection*:
1. **From Eulerian Circuit to In-Arborescence + Local Permutations**:
   Follow an Eulerian circuit starting with $e_0$ at $r$. For every vertex $v \ne r$, let $e_{\text{last}}(v)$ be the **very last outgoing edge** used to exit $v$ before the circuit finally terminates at $r$. For $r$ itself, let $e_{\text{last}}(r) = e_0$.
   - Why do the edges $\{ e_{\text{last}}(v) \mid v \ne r \}$ form a directed spanning tree rooted at $r$? Every vertex $v \ne r$ has out-degree $1$ in this subset, so it suffices to show there are no directed cycles. Suppose $v_1 \to v_2 \to \dots \to v_m \to v_1$ were a cycle of last-exit edges ($r$ cannot be on the cycle since $r$ has no outgoing edge in the set). Let $v_i$ be the vertex on the cycle whose last exit $e_{\text{last}}(v_i) = (v_i \to v_{i+1})$ is traversed *last* in time along the Eulerian circuit. When the circuit traverses $(v_i \to v_{i+1})$, it enters $v_{i+1} \ne r$, so it must subsequently exit $v_{i+1}$ via some outgoing edge—contradicting the assumption that $e_{\text{last}}(v_{i+1})$ was already traversed earlier!
2. **From In-Arborescence + Local Permutations back to Eulerian Circuit**:
   Conversely, given any in-arborescence $\mathcal{T}$ rooted at $r$ and, at each vertex $v \in V$, an arbitrary linear ordering of its remaining $d(v) - 1$ non-tree outgoing edges (with $e_{\text{last}}(v)$ placed at the very end of $v$'s exit list, and $e_0$ placed first at $r$), a deterministic walk that starts with $e_0$ and always takes the next unused outgoing edge at the current vertex can **never get stuck** at any $v \ne r$ (since $\text{in}(v) = \text{out}(v)$) and cannot get stuck at $r$ prematurely before exhausting all edges of $G$ (because any unvisited edge would have a directed path in $\mathcal{T}$ to $r$, forcing an earlier unused tree edge along that path to have been skipped!). Thus every choice of $(\mathcal{T}, \{ \pi_v \}_{v \in V})$ produces a unique Eulerian circuit! $\blacksquare$

#### 2.3 Burrows–Wheeler Transform (BWT), LF-Mapping & Wheeler Graphs
Let $S[1..N]$ be a string ending with a unique lexicographically smallest sentinel $S[N] = \text{'\$'}$ (or consider cyclic shifts of a primitive word). Sort all $N$ cyclic shifts of $S$ into an $N \times N$ matrix $\mathcal{M}$:
- The **First Column** $F[1..N]$ is simply the sorted characters of $S$.
- The **Last Column** $L[1..N]$ is the **Burrows–Wheeler Transform** $\text{BWT}(S)$: $L[i]$ is the character immediately **preceding** the $i$-th sorted cyclic shift (or suffix) in $S$!

**Theorem 95.2 (The LF-Mapping Rank-Preservation Invariant)**.
*The $k$-th occurrence of character $c$ in the last column $L$ corresponds to the **exact same text position** in $S$ as the $k$-th occurrence of character $c$ in the first column $F$!*

*Proof*: Consider all cyclic shifts $W_1 < W_2 < \dots < W_m$ that **end** with character $c$ (these appear in $L$ in the order $W_1, \dots, W_m$). Rotating each such shift right by one position (moving the trailing $c$ to the front) produces $c W_1[1..N-1], \dots, c W_m[1..N-1]$, which are all the cyclic shifts that **begin** with $c$ (appearing in $F$). Since prepending the *same* character $c$ preserves relative lexicographical order:
$$W_1 < W_2 \iff W_1[1..N-1] < W_2[1..N-1] \iff c W_1[1..N-1] < c W_2[1..N-1],$$
their relative order in $L$ is identical to their relative order in $F$! $\blacksquare$

**Generalization to Wheeler Graphs (Gagie, Manzini, Sirén 2017)**:
A directed edge-labeled graph $G = (V, E, \Sigma)$ is a **Wheeler Graph** if there exists a total ordering $<$ on the vertices $V$ such that for all edges $(u_1, v_1, c_1)$ and $(u_2, v_2, c_2)$:
1. $0$-in-degree vertices come first.
2. **Label Monotonicity**: $c_1 < c_2 \implies v_1 < v_2$ (all incoming edges to $v$ have the same character label, and vertices are grouped by incoming character).
3. **Co-Lexicographical Path Monotonicity**: $(c_1 = c_2 \;\land\; u_1 < u_2) \implies v_1 \le v_2$.
In any Wheeler Graph, the set of vertices reachable by reading any pattern $P[1..M]$ from the start always forms a **single contiguous interval $[l, r]$** in the vertex order $<$, which updates in $O(1)$ rank queries per character via $\text{LF}(i, c) = C[c] + \text{rank}_c(i)$! De Bruijn graphs (ordered co-lexicographically by their $(k-1)$-mers), Tries (ordered by reverse-string co-lex order), and BWT suffix arrays are all special cases of Wheeler Graphs.

### 3. The Reverse-Engineering Scratchpad (Non-Closed Trails, Lex-Smallest Hierholzer & BWT Inversion)

1. **Adapting BEST from Circuits to Open Eulerian Trails ($u_{\text{start}} \to u_{\text{end}}$)**:
   A string $S[1..N]$ whose $(k-1)$-prefix $u_{\text{start}} = S[1..k-1]$ differs from its $(k-1)$-suffix $u_{\text{end}} = S[N-k+2..N]$ corresponds to an **open Eulerian trail** with $\text{out}(u_{\text{start}}) - \text{in}(u_{\text{start}}) = 1$ and $\text{in}(u_{\text{end}}) - \text{out}(u_{\text{end}}) = 1$.
   - **Reduction**: Add one artificial return edge $e^* = (u_{\text{end}} \to u_{\text{start}})$ to make $G$ balanced, and set the root $r = u_{\text{end}}$ with distinguished first edge $e_0 = e^*$. Every Eulerian circuit starting with $e^* = (u_{\text{end}} \to u_{\text{start}})$ in $G \cup \{e^*\}$, once $e^*$ is deleted from the front, becomes a unique open Eulerian trail from $u_{\text{start}}$ to $u_{\text{end}}$ in $G$! (Do not divide by edge multiplicity for $e^*$ since $e^*$ is distinguished.)
2. **Lexicographically Smallest Eulerian String via Reverse-Sorted Hierholzer**:
   To reconstruct the lexicographically smallest string with a given $k$-mer spectrum: sort each vertex's outgoing adjacency list in ascending character order (or descending if popping from the back of a `std::vector`), run Hierholzer's DFS from $u_{\text{start}}$ always picking the smallest available outgoing character first, and reverse the post-order edge list.
   - *Why does post-order reversal produce the lexicographically smallest prefix?* At the first step where two Eulerian trails diverge at vertex $v$, one trail takes the smaller edge $e_1$ and first explores a sub-circuit back to $v$ before continuing along $e_2$, ensuring the string begins with $e_1$ rather than $e_2$!

### 4. Boundary Pitfalls & Broken-Invariant Counterexamples

1. **Isolated Vertices in Matrix-Tree / BEST Theorem**:
   In the De Bruijn graph $\mathcal{G}_k$, $|\Sigma|^{k-1}$ vertices exist in theory, but many $(k-1)$-mers may have degree $0$ (never appearing in $S$). If you include isolated vertices ($d(v) = 0$) in the Laplacian $L_{\text{out}}$, then $\det L^{(r)}_{\text{out}} = 0$ and $(d(v)-1)! = (-1)!$ is undefined! **Contract the vertex set $V$ purely to vertices with $d(v) > 0$**, and explicitly check that all active vertices belong to a single weakly connected component before computing $\det L^{(r)}_{\text{out}}$.
2. **Cyclic vs. Sentinel BWT Inversion Ambiguity (`[BOI 2004] REPEATS` / Cyclic BWT)**:
   When BWT is computed on cyclic shifts *without* a unique sentinel `'\$'`, if $S = w^d$ is a periodic power (e.g., $S = \text{"abab"}$, $d=2$), the LF-mapping splits into $d = \gcd\text{-cycles}$ of length $N/d$ instead of a single cycle of length $N$! Always check whether the problem appends a sentinel (or guarantees a primitive / Lyndon necklace) vs. requires merging multiple cycles of a periodic word.

## Iteration 96: Strings on Trees — Tree Suffix Array, Tree Generalized SAM & Centroid Decomposition + Automata/FFT

### 1. The Diagnostic Signal (Why Naive Tree Suffix Sorting & Path Matching Degrade to $O(N^2)$)

When characters sit on the vertices or edges of a tree $T = (V, E)$ with $|V| = N \le 5 \times 10^5$, three canonical problem classes arise:
1. **Sorting All Rooted Tree Paths (`Tree Suffix Array`, `Luogu P5353`)**:
   Given a rooted tree $T$ where each node $u$ has a character $c(u)$ and parent $p(u)$, let $\text{str}(u) = c(u) c(p(u)) \dots c(\text{root})$ be the upward path string from $u$ to the root. Sort all $N$ nodes $u \in V$ lexicographically by $\text{str}(u)$ (breaking ties by node index or previous rank).
2. **Distinct Substrings Across All Tree Paths (`Tree GSAM`, `[ZJOI2015] 诸神眷顾的幻想乡`)**:
   Given an unrooted tree $T$ ($N \le 10^5$) with **at most $L \le 20$ leaves**, count the total number of distinct strings formed by simple paths $u \leadsto v$ in $T$.
3. **Undirected Tree-Path Pattern Counting (`Centroid Decomposition + AC / SAM / FFT`, `CF 914E`, `[CTSC2010] 珠宝商`)**:
   Given an unrooted tree $T$ ($N \le 5 \times 10^4$ or $2 \times 10^5$) and either a single pattern $P[1..M]$ or a dictionary of patterns, count how many directed simple paths $(u, v)$ in $T$ spell $P$ (or have a palindromic / AC-matched path label).

**Why Linear String Templates Fail on Trees**:
- **Duplicate-Rank Collapse in Naive Tree SA Doubling**: On a linear string $S[1..N]$, all suffixes have distinct lengths, so at step $k = \lceil \log_2 N \rceil$, no two suffixes can have identical $2^k$-prefixes. On a tree, however, two distinct nodes $u \ne v$ can have the **exact same upward path string** $\text{str}(u) = \text{str}(v)$! If we assign identical ranks $\text{rk}_k[u] = \text{rk}_k[v]$, then radix sort has $O(N)$ tied buckets and cannot decide which of two children $u', v'$ with $p(u')=u, p(v')=v$ comes first when ties are broken by parent node IDs; conversely, if we break ties immediately at step $k$ using node IDs so all $\text{rk}_k[u]$ are distinct, then $\text{rk}_k[u] \ne \text{rk}_k[v]$ even when their $2^k$-prefixes are identical, **corrupting the $2^{k+1}$-length string comparison** at step $k+1$!
- **DFS Insertion Blowup in Tree GSAM**: Inserting a branched tree into a Suffix Automaton by running DFS and resetting `last` to `pos[parent]` must be done cleanly (either via BFS on the Trie or offline GSAM) to avoid creating redundant zero-length clone states.

### 2. The Combinatorial Word Invariant (Dual-Rank Splitting, Leaf-Rooted Coverage & Centroid Path Stitching)

#### 2.1 Resolving the Tree SA Tie-Breaking Paradox (`rk` vs `sa_rk` Dual-Rank Invariant)
In `Luogu P5353` (Tree Suffix Sorting), why do we need **two** rank arrays at each doubling step $k$?
Let $P_k(u)$ denote the upward prefix of length $2^k$ starting at $u$. At step $k$, comparing $P_k(u)$ and $P_k(v)$ requires comparing the pair of half-strings $(P_{k-1}(u), P_{k-1}(\text{anc}(u, 2^{k-1})))$.
- **Invariant 1 (True String Equivalence Rank $\text{rk}_k[u]$)**: Two nodes $u, v$ receive $\text{rk}_k[u] = \text{rk}_k[v]$ **if and only if** their $2^k$-length upward strings are character-for-character identical:
  $$\text{rk}_k[u] = \text{rk}_k[v] \iff \big(\text{rk}_{k-1}[u], \text{rk}_{k-1}[\text{anc}(u, 2^{k-1})]\big) = \big(\text{rk}_{k-1}[v], \text{rk}_{k-1}[\text{anc}(v, 2^{k-1})]\big).$$
  This guarantees that at step $k+1$, the first half $P_k(u)$ only masks the second half $P_k(\text{anc}(u, 2^k))$ when $P_k(u)$ and $P_k(v)$ are genuinely unequal as strings!
- **Invariant 2 (Strict Permutation Tie-Breaking Rank $\text{id\_rk}_k[u]$)**: To perform $O(N)$ counting/radix sort in step $k$ without $O(N)$-sized tied buckets (and to satisfy problem statements that break ties between $u$ and $v$ by $\text{id\_rk}[p(u)]$ vs $\text{id\_rk}[p(v)]$), we maintain the strict permutation $\text{SA}_k[1..N]$ and its inverse $\text{id\_rk}_k[\text{SA}_k[i]] = i$ (all distinct in $1..N$). When sorting at step $k$, we bucket-sort using the **4-tuple** $(\text{rk}_{k-1}[u], \text{rk}_{k-1}[\text{anc}(u, 2^{k-1})], \text{id\_rk}_{k-1}[u], \text{id\_rk}_{k-1}[\text{anc}(u, 2^{k-1})])$—which reduces to sorting the already-ordered sequence $\text{SA}_{k-1}$ by second key $\text{id\_rk}_{k-1}[\text{anc}(u, 2^{k-1})]$ and first key $\text{rk}_{k-1}[u]$ in $O(N)$ time!

#### 2.2 The Leaf-Rooted Coverage Theorem for Low-Leaf Trees (`[ZJOI2015] 诸神眷顾的幻想乡`)
**Theorem 96.1 (Every Simple Path on a Tree is a Prefix of a Leaf-Rooted Path)**.
*In any tree $T$ with at least $2$ vertices, every directed simple path $u \leadsto v$ can be extended backward from $u$ to some leaf $\ell \in \text{Leaves}(T)$ such that $u \leadsto v$ is a contiguous substring of the root-to-node path starting at root $\ell$!*

*Proof*: Root the tree at $v$. Move $u$ strictly deeper into $u$'s subtree (away from $v$) until reaching a node $\ell$ with no children in the $v$-rooted tree. Since $\ell \ne v$ has degree $1$ in $T$, $\ell$ is a leaf of $T$, and the path $\ell \leadsto v$ contains $u \leadsto v$ as a suffix (and therefore as a substring of the $\ell$-rooted tree Trie)!
**Consequence**: If $T$ has $L \le 20$ leaves, rooting $T$ at each of the $L$ leaves in turn and inserting all $L$ rooted trees into a single **Generalized Suffix Automaton (GSAM)** captures **every possible simple path** of $T$ in at most $L \cdot N \le 2 \times 10^6$ Trie states! The number of distinct path strings is simply $\sum_{x \in \text{GSAM}} \big(\text{len}(x) - \text{len}(\text{link}(x))\big)$ in $O(L \cdot N)$ time.

#### 2.3 Centroid Decomposition + SAM/AC/FFT Path Stitching (`[CTSC2010] 珠宝商`)
What if the tree is arbitrary (up to $O(N)$ leaves, e.g., a star graph) and we must count how many tree paths $u \leadsto v$ match a given pattern $P[1..M]$ (or appear in a text $P[1..M]$)?
Apply **Centroid Decomposition**. At a centroid $c$ with component size $S_c$, every simple path $u \leadsto v$ passing through $c$ splits into an upward path $u \leadsto c$ (the reversal of a downward path from $c$ to $u$) and a downward path $c \leadsto v$.
How do we count pairs $(u, v)$ where $\text{str}(u \leadsto c) \cdot \text{str}(\text{next}(c, v) \leadsto v) = P[1..M]$ when $M$ can be as large as $N$?
- **Method A (Small Component Size $S_c \le B$: Naive $O(S_c^2)$ Path Walk on SAM)**:
  If $S_c \le \sqrt{N}$, there are only $O(S_c^2)$ pairs $(u, v)$ in this centroid component! Walk from each $u$ through $c$ to $v$ directly on the SAM of $P$ (and its $\text{endpos}$ counts) in $O(S_c^2)$ time.
- **Method B (Large Component Size $S_c > B$: $O(S_c + M)$ Split-Point Convolution on SAM of $P$ and $P^R$)**:
  Build the SAM of $P$ ($\text{SAM}_P$) and the SAM of $P^R$ ($\text{SAM}_{P^R}$).
  1. Walk downward from $c$ into its subtrees to find, for each node $v$, the state $x(v) \in \text{SAM}_P$ reached by $\text{str}(c \leadsto v)$ (if it exists in $P$), and the state $y(u) \in \text{SAM}_{P^R}$ reached by $\text{str}(c \leadsto u)$ (which equals $\text{str}(u \leadsto c)^R$!).
  2. Notice that $\text{str}(u \leadsto c)$ is a suffix of $P[1..i]$ (ending at split position $i$ in $P$) if and only if the Link-Tree node of $P[1..i]^R$ in $\text{SAM}_{P^R}$ lies in the subtree of $y(u)$! Similarly, $\text{str}(\text{next}(c, v) \leadsto v)$ is a prefix of $P[i+1..M]$ starting at $i+1$ if and only if the Link-Tree node of $P[i+1..M]$ in $\text{SAM}_P$ lies in the subtree of $x(\text{next}(c, v))$.
  3. Therefore, pushing subtree tags down the Link Trees of $\text{SAM}_{P^R}$ and $\text{SAM}_P$ takes $O(S_c + M)$ time!
  Balancing $B = \sqrt{M}$ yields $O(N \sqrt{M})$ total time across the entire centroid decomposition (`[CTSC2010] 珠宝商`).

### 3. The Reverse-Engineering Scratchpad (BFS Tree GSAM & LCP on Tree SA)

1. **BFS-Ordered Tree Generalized SAM Construction**:
   Given a rooted tree (or Trie) where each node $u$ has parent $p(u)$ and character $c(u)$, never call standard `extend(c)` in DFS order without handling already-existing transitions! Instead, traverse the tree in **BFS order** (increasing depth). Store $\text{pos}[u]$, the GSAM state representing the path from the root to $u$. When processing $u$, set `last = pos[p(u)]` and extend by $c(u)$ to obtain $\text{pos}[u]$. Because BFS visits nodes in non-decreasing order of path length, any state split during `extend` has $\text{len}(q) = \text{len}(\text{last}) + 1 > \text{len}(\text{last})$, completely preventing zero-length clone states!
2. **Computing Tree LCP (`height` array) after Tree SA**:
   Unlike linear strings where Kasai's theorem $\text{height}[\text{rk}[i]] \ge \text{height}[\text{rk}[i-1]] - 1$ holds in $O(N)$ time, on a tree, two nodes $u, v$ can have $p(u) = p(v)$, or $\text{rk}[p(u)]$ may not be adjacent to $\text{rk}[p(v)]$ in the same way. However, since we already maintained the equivalence ranks $\text{rk}_k[u]$ for $k = 0 \dots \lfloor \log_2 N \rfloor$ during Tree SA doubling (or via a 64-bit polynomial hash + binary lifting on the tree), the exact LCP between $\text{SA}[i-1]$ and $\text{SA}[i]$ is obtained in $O(\log N)$ time by binary lifting on $k$: if $\text{rk}_k[u] = \text{rk}_k[v]$, advance both $u \leftarrow \text{anc}(u, 2^k)$ and $v \leftarrow \text{anc}(v, 2^k)$ and add $2^k$ to the LCP!

---

### 4. Boundary Pitfalls & Broken-Invariant Counterexamples

1. **Subtracting Same-Subtree Contributions in Centroid Path Matching**:
   In Centroid Decomposition (Section 2.3), when aggregating upward paths $u \leadsto c$ and downward paths $c \leadsto v$, if $u$ and $v$ lie in the **same** child subtree of $c$, their concatenation $u \leadsto c \leadsto v$ backtracks across the edge $(c, \text{child})$ and is **not a simple path**! You must either subtract each child subtree's internal $(u, v)$ convolution before summing over the whole centroid, or process child subtrees sequentially using a prefix/suffix sweep.
2. **Kasai's $h[i] \ge h[p(i)] - 1$ Fallacy on Branched Trees**:
   A notorious bug in Tree SA problems is attempting to run linear-time Kasai's algorithm (`if (k) k--; while (...) k++;`) to compute `height[i]` between $\text{SA}[\text{rk}[u]-1]$ and $u$.
   - *Why it fails*: Suppose $v = \text{SA}[\text{rk}[u]-1]$ has $c(v) = c(u)$, so $\text{LCP}(u, v) = 1 + \text{LCP}(p(u), p(v))$. In a branched tree, another node $w$ can also have $p(w) = p(u)$ and $c(w) = c(u)$! Then $\text{SA}[\text{rk}[p(u)] - 1]$ is **not** necessarily $p(v)$ (or $p(u)$ might equal $p(v)$ while $\text{SA}[\text{rk}[p(u)]-1]$ is completely unrelated), invalidating Kasai's lower bound! Always use binary lifting with $\text{rk}_k$ or tree hashes in $O(\log N)$ per adjacent SA pair.

      - When $S_c > B$: there are at most $\frac{N \log N}{B}$ such centroids! Map upward paths $u \leadsto c$ into $\text{SAM}_{S^R}$ and downward paths $c \leadsto v$ into $\text{SAM}_S$, push path counts down both Link Trees to the prefix/suffix nodes $1 \dots M$ of $S$, and dot-product across split index $i \in [1, M]$ in $O(S_c + M)$ time!

### 4. Hand-Checkable Worked Traces & Verification Checklist (Wave 5A Audit)

#### Trace A: Signed Binary-Lifting DSU on Overlapping Palindrome + Translation ($N = 6$)
Suppose $S[1..6]$ satisfies:
1. $S[1..4] = S[3..6]$ (forward translation, $L = 4 = 2^2$), and
2. $S[1..4] = (S[1..4])^R$ (palindrome of length $4 = 2^2$).

Let us trace the Signed Binary-Lifting DSU from $k=2$ down to $k=0$:
- **At $k = 2$ ($2^2 = 4$)**:
  - Constraint 1 merges $(1, 3, \text{rev}=0)$ in $\text{DSU}_2$.
  - Constraint 2 merges $(1, 1, \text{rev}=1)$ in $\text{DSU}_2$ (a self-reversal loop on $B_2(1)$).
- **Pushdown $k = 2 \to 1$ ($2^1 = 2$)**:
  - Edge $(1, 3, \text{rev}=0)$ splits into $\text{union}_1(1, 3, 0)$ and $\text{union}_1(1+2, 3+2, 0) = \text{union}_1(3, 5, 0)$.
  - Self-reversal $(1, 1, \text{rev}=1)$ splits with swapped half-offsets into $\text{union}_1(1, 1+2, 1) = \text{union}_1(1, 3, 1)$ and $\text{union}_1(3, 1, 1)$.
  - Notice that in $\text{DSU}_1$, blocks $1, 3, 5$ are all connected, and $B_1(1)$ has both a forward path $(1 \equiv 3, \text{rev}=0)$ and a reversed edge $(1 \equiv 3, \text{rev}=1)$, forcing $B_1(1) = B_1(1)^R$!

  - $(1, 3, 0) \implies S[1]=S[3],\; S[2]=S[4]$.
