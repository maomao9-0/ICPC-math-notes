08 — Transforms on Subsets and Divisors

The same trick, on a different index set

In Chapter 06 a quadratic-looking sum \(c_k = \sum_{i+j=k}a_ib_j\) became pointwise multiplication after evaluating at roots of unity. Contests ask the same question with the addition replaced by something else:

\[h[S] = \sum_{A \cup B = S}f[A]\,g[B], \qquad h[s] = \sum_{a \oplus b = s}f[a]\,g[b], \qquad h[x] = \sum_{\operatorname{lcm}(a,b) = x}f[a]\,g[b].\]

Each of these has a change of coordinates that turns it into “multiply entry by entry”, and each transform is a handful of lines of code. So the coding is never the hard part. The hard part is deciding which relation among indices the statement actually combines — union, disjoint union, intersection, XOR, lcm, gcd — because the transforms look almost identical and none of them will complain if you pick the wrong one.

That is the skill this chapter builds: read the index relation off the statement, derive the matching transform, and prove the inverse exists in your coefficient ring.

Unless stated otherwise, array values live in a commutative ring. The zeta/Möbius stages use only addition and subtraction; a convolution additionally needs the pointwise products to make sense.

Prerequisites, notation, and learning objectives

Read sets and induction, divisor sums, and modular units.

You should finish able to derive a transform from an index relation, prove its inverse, tell union apart from disjoint union, and choose the correct stage order for divisor transforms.

The universe is \(\{0,\ldots,n-1\}\), subsets are masks \(0,\ldots,2^n-1\), and \(|S|\) is the popcount. A poset is a set with a reflexive, antisymmetric, transitive order; subset inclusion and divisibility are the two we use. A zeta transform sums over predecessors in that order, and a Möbius transform undoes it. Complexities count ring operations, not bit costs for huge integers.

1. Subset zeta and Möbius transforms

The subset zeta transform changes coordinates from “exactly \(T\)” to “any subset of \(S\)”:

\[F[S] = \sum_{T \subseteq S}f[T].\]

Read it concretely: if \(f[T]\) counts objects whose feature set is exactly \(T\), then \(F[S]\) counts objects using only features from \(S\) — the quantity you can actually compute by a DP, whereas “exactly” is the quantity you want.

The computation processes one bit at a time: for each bit \(b\), add the value at the mask without \(b\) into the mask with \(b\). Invert by subtracting in the same schedule.

Why this works is the invariant, not the loop shape. After a set \(B\) of bits has been processed, the value at \(S\) is

\[\sum_{\substack{T \subseteq S\\ S\setminus T \subseteq B}}f[T],\]

i.e. only processed bits may have been deleted. Processing one more bit splits the allowed terms into two disjoint cases — that bit deleted or not — which is exactly the update.

NoteTwo bits, by hand

With \(f[\varnothing], f[\{0\}], f[\{1\}], f[\{0,1\}] = (1,2,3,4)\): processing bit \(0\) gives \((1,3,3,7)\), then bit \(1\) gives \((1,3,4,10)\). Check the last entry: \(1+2+3+4 = 10\). ✓ Subtracting in the same order restores \((1,2,3,4)\).

Both directions cost \(O(n2^n)\) time and \(O(1)\) extra memory. The inverse is legitimate because the Möbius function of the Boolean lattice is \(\mu(T,S) = (-1)^{|S\setminus T|}\); concretely, each butterfly \((a,b)\mapsto(a,a+b)\) is inverted by \((a,b)\mapsto(a,b-a)\). Bit order does not matter — the stages commute — but which member of each pair receives the update does: flip it and you have computed a different transform.

The superset variants reverse the condition: for masks s without bit b, do f[s] += f[s | (1<<b)]. Recognition signals: “sum over all submasks/supermasks”, compatibility masks, inclusion–exclusion over missing features.

OR and AND convolution

For \(h[S] = \sum_{A\cup B=S}f[A]g[B]\): subset-zeta both arrays, multiply pointwise, subset-Möbius the result. The reason is visible at a fixed \(S\), where the product is

\[\left(\sum_{A\subseteq S}f[A]\right)\left(\sum_{B\subseteq S}g[B]\right),\]

which counts every pair whose union is contained in \(S\). That is exactly a zeta transform of the answer, so Möbius inversion turns “contained in” back into “equal to”. For \(A \cap B = S\), run the same argument with superset zeta. Both cost \(O(n2^n)\).

2. XOR convolution and the Walsh–Hadamard transform

XOR makes masks into the group \((\mathbb Z/2\mathbb Z)^n\), where every element is its own inverse. Groups like this have characters: functions turning the group operation into multiplication. Here they are the sign functions

\[\chi_k(x) = (-1)^{\langle k,x\rangle}, \qquad \langle k,x\rangle = \textstyle\sum_b k_bx_b \bmod 2,\]

the parity of shared set bits. Since bit parities add, \(\chi_k(a\oplus b) = \chi_k(a)\chi_k(b)\) — and that single identity is the whole method. Defining \(\widehat f[k] = \sum_x f[x]\chi_k(x)\),

\[\widehat h[k] = \sum_{a,b}f[a]g[b]\chi_k(a\oplus b) = \widehat f[k]\,\widehat g[k]\]

for \(h[s] = \sum_{a\oplus b = s}f[a]g[b]\). Convolution becomes pointwise multiplication in character coordinates.

Inversion. Consider \(\sum_k \chi_k(x)\chi_k(y)\). If \(x = y\) all \(2^n\) terms are \(1\). If \(x \ne y\), take a bit where they differ and pair each \(k\) with the mask toggling that bit: the two terms have opposite signs and cancel. So applying the transform twice returns \(2^n f\). Splitting the frequency masks by one bit gives the butterfly \((a,b)\mapsto(a+b,\,a-b)\), and \(n\) stages cost \(O(n2^n)\).

WarningThe \(2^n\) must be invertible

Inversion divides by \(N = 2^n\), so the ring must make \(N\) a unit — over a field, characteristic \(\ne 2\). Under an odd prime modulus multiply by \(N^{-1}\); over the integers, transform in a wide type and divide exactly at the end (intermediate values can be far larger than the final coefficients).

In characteristic two the length-two transform maps both \((1,0)\) and \((0,1)\) to \((1,1)\): information is destroyed and no scaling can recover it. OR/AND transforms use triangular butterflies and need no normalization at all.

Worked check. \(f = [1,2]\), \(g = [3,4]\). Directly, \(h = [1\cdot3+2\cdot4,\ 1\cdot4+2\cdot3] = [11,10]\). By transform: \(\widehat f = [3,-1]\), \(\widehat g = [7,-1]\), product \([21,1]\), and the inverse butterfly gives \([(21+1)/2,\ (21-1)/2] = [11,10]\). ✓

3. Subset convolution: when the parts must be disjoint

The disjoint-union convolution

\[h[S] = \sum_{T\subseteq S}f[T]\,g[S\setminus T]\]

is the one that appears in “partition this set into two labelled parts” DPs. Direct enumeration over submasks costs \(O(3^n)\). The trick to reach \(O(n^22^n)\) is to carry the set size as an extra index, because disjointness is a statement about sizes:

\[|A| + |B| = |A\cup B| + |A\cap B|,\]

so among pairs with \(A\cup B = S\), the disjoint ones are exactly those with \(|A|+|B| = |S|\).

So: split each array by rank (\(f_k[S] = f[S]\) when \(|S| = k\), else \(0\)), zeta each rank, form

\[H_k[S] = \sum_{i=0}^{k}F_i[S]\,G_{k-i}[S],\]

Möbius each rank back, and read off \(h[S] = H_{|S|}[S]\). After inversion, rank \(k\) at mask \(S\) holds pairs with \(A\cup B = S\) and \(|A|+|B| = k\); selecting \(k = |S|\) keeps precisely the disjoint ones. Time \(O(n^22^n)\), memory \(O(n2^n)\).

WarningDo not prune overlapping ranks early

It is tempting to zero out entries with \(k > |S|\) before inversion. Don’t: those entries hold overlapping pairs that must still cancel at larger masks. Two copies of the singleton \(\{0\}\) produce a rank-two contribution at mask \(\{0\}\) and, after zeta, at \(\{0,1\}\); inversion subtracts one from the other. Deleting the first leaves a phantom disjoint pair at \(\{0,1\}\).

For \(S = \{0,1\}\) the wanted sum is

\[f[\varnothing]g[S] + f[\{0\}]g[\{1\}] + f[\{1\}]g[\{0\}] + f[S]g[\varnothing],\]

whereas OR convolution would also admit overlapping pairs such as \((S,S)\). The rank index is the only thing separating them.

Use it when a transition splits a set into two labelled disjoint parts and \(n \approx 20\). If one side is sparse, plain \(O(3^n)\) submask enumeration can be both faster and easier.

Budget the memory before you code it. At \(n = 20\), one ranked array of 32-bit entries takes \(21\cdot 2^{20}\cdot 4 \approx 84\) MiB; three of them are 252 MiB. Count the arrays that are simultaneously live against the actual limit — the asymptotic bound alone promises nothing.

4. Divisor-poset transforms

Order positive integers by divisibility instead of inclusion and the whole story repeats, with primes playing the role of bits:

\[F[x] = \sum_{d \mid x}f[d] \quad(\text{divisor zeta}), \qquad G[x] = \sum_{x \mid m}f[m] \quad(\text{multiple zeta}).\]

For arrays up to \(N\), divisor zeta runs one stage per prime \(p\), doing f[i*p] += f[i] for \(1 \le i \le \lfloor N/p\rfloor\), ascending in \(i\); the inverse subtracts descending. Multiple zeta uses f[i] += f[i*p] descending, and inverts ascending.

Why direction matters. The stage must accumulate along a whole prime-power chain, then undo it in reverse dependency order. On the chain \(1,2,4\) with values \((a,b,c)\), ascending updates give \((a,\,a+b,\,a+b+c)\) — correct, since index \(4\) must include \(f[1]\). Descending updates would give \((a,\,a+b,\,b+c)\), silently dropping \(a\) from index \(4\). To invert, subtract index \(2\) from index \(4\) first, then index \(1\) from index \(2\).

The invariant matches the subset case: after processing a set \(P\) of primes, the value at \(x\) sums \(f[d]\) over divisors \(d\) such that every prime factor of \(x/d\) lies in \(P\). Each stage adds all choices of one prime’s exponent, and unique factorization is what makes the stages commute.

Which one for which operation. For lcm convolution, “both operands divide \(x\)” is the transformed condition, so use divisor zeta, multiply, and invert. For gcd convolution, the condition is “both operands are multiples of \(x\)”, so use multiple zeta. Prime-stage transforms cost \(O(N\log\log N)\) (versus \(O(N\log N)\) for direct divisor loops).

Preconditions: indices start at \(1\), and you must decide explicitly what happens at \(0\), since \(\gcd(0,x)\) and \(\operatorname{lcm}(0,x)\) make it a special element.

One subtlety about truncation: the lcm output only covers \(1,\ldots,N\), and pairs with lcm above \(N\) simply appear nowhere. That is harmless, because for any retained \(x\) both operands divide \(x\) and so are themselves in range. For gcd convolution every pair of in-range inputs has an in-range gcd.

5. Pitfalls and decision guide

  • A | B, A & B, and A ^ B need three different transforms. Visual similarity is not algebraic equivalence.
  • Do the Möbius inversion in the same ring as the sums; under a modulus, normalize subtractions.
  • Subset convolution hits the memory limit before the time limit. Use contiguous rank-major storage.
  • SOS DP often needs only the forward transform. Don’t pay for an inverse you never use.
  • To decide which XOR values are reachable, a linear basis (Chapter 07) beats FWT. Use FWT when you need multiplicities or a distribution over every XOR value.

6. Solved exercises

A. Union is not disjoint union

On a two-element universe let \(f[\{0\}] = g[\{0\}] = 1\) and everything else be zero. Compute the OR convolution and the disjoint-union convolution.

TipHint

There is exactly one ordered pair with nonzero weight. Look at its intersection.

NoteSolution

OR convolution is \(1\) at \(\{0\}\): the union of the singleton with itself is itself. Subset convolution is zero everywhere, because the pair overlaps.

In the ranked method that pair carries rank two at a mask of size one, so it is discarded only at the final step, when rank \(|S|\) is selected after inversion — which is exactly why it must be kept until then.

B. Count AND-zero subsequences

For the masks \((1,2,3)\) on two bits, count the nonempty subsequences whose AND is zero. Derive the signs rather than guessing them.

TipHint

Let \(c[S]\) count inputs containing every bit of \(S\).

NoteSolution

In mask order \(0,1,2,3\) we get \(c = (3,2,2,1)\). A subsequence whose AND contains \(S\) is any nonempty subset of those \(c[S]\) occurrences, so

\[F[S] = 2^{c[S]} - 1\]

is the superset zeta of the exact-AND distribution. Inverting at \(S = 0\): \(7 - 3 - 3 + 1 = 2\), namely the subsequences \((1,2)\) and \((1,2,3)\). ✓

In general compute \(c\) in \(O(n2^n)\) and take \(\sum_S(-1)^{|S|}\bigl(2^{c[S]}-1\bigr)\). Equal input values still count as distinct occurrences.

C. Recover exact gcd counts

Both operands are chosen independently from \(\{1,2,3,4\}\). How many ordered pairs have gcd \(1, 2, 3, 4\)?

TipHint

Pairs with both operands divisible by \(d\) number \(\lfloor 4/d\rfloor^2\).

NoteSolution

With \(h[d]\) the exact-gcd count, \(\lfloor 4/d\rfloor^2 = \sum_{d \mid m}h[m]\). Subtracting downward from the top: \(h[4] = 1\), \(h[3] = 1\), \(h[2] = 4 - h[4] = 3\), \(h[1] = 16 - 3 - 1 - 1 = 11\). The four values sum to all \(16\) pairs. ✓

This is multiple-zeta inversion. Squaring pointwise counts ordered independent choices; unordered pairs or distinct-index requirements need their own correction.

7. Practice, in order

Labels: Foundation isolates one idea; Advanced combines it; Mastery requires recognition. All statements are available in English.

  1. Foundation — Compatible Numbers, CF 165E. Superset/subset SOS DP. Official tutorial.
    • Why: the canonical “find a disjoint present mask” transform.
      Hints
    1. A number compatible with \(x\) is a submask of the complement of \(x\).
    2. Store any present witness, then propagate witnesses from submasks.
    3. This uses zeta’s dependency order but is not an invertible additive transform; no inverse is needed.
  2. Advanced — Jzzhu and Numbers, CF 449D. Superset zeta plus inclusion–exclusion. Official tutorial.
    • Why: converts AND-zero into counts of elements containing each mask (exercise B at full scale).
      Hints
    1. Count subsequences whose AND contains \(S\).
    2. If \(c[S]\) inputs contain \(S\), there are \(2^{c[S]}-1\) nonempty choices.
    3. Möbius-invert, or take the alternating sum by popcount.
  3. Advanced — Nim Counting, AtCoder ABC212 H. XOR FWT. Official editorial.
    • Why: forces reasoning in character space instead of treating FWT as a black box.
      Hints
    1. Winning or losing is decided by the XOR of the chosen pile sizes.
    2. Transform the one-choice frequency distribution.
    3. Sum transformed powers for lengths \(1\) through \(N\), invert, and subtract the XOR-zero count. Where the transformed value is \(1\), the geometric sum is \(N\) — do not divide by a vanishing difference.
  4. Mastery — Sum the Fibonacci, CF 914G. Ranked subset, XOR, and AND convolutions in one problem. Official tutorial.
    • Why: the explicit disjointness condition is what turns OR into subset convolution.
      Hints
    1. Build the frequency array \(f\). The pair \((a,b)\) needs \(s_a \mathbin\& s_b = 0\), so its union distribution is the ranked subset convolution \(f * f\).
    2. Get the \((d,e)\) XOR distribution separately, then weight each distribution pointwise by the corresponding Fibonacci values.
    3. AND-convolve the three weighted distributions and sum the outputs at powers of two. The statement counts ordered five-tuples of indices with repetition allowed, so no symmetry division belongs anywhere here.

8. Reference sheet

Index relation Transform Time Extra algebra
\(A\cup B = S\) subset zeta / product / inverse \(O(n2^n)\) ring operations only
\(A\cap B = S\) superset zeta / product / inverse \(O(n2^n)\) ring operations only
\(A\oplus B = S\) Walsh–Hadamard \(O(n2^n)\) \(2^n\) a unit, or exact integer division
\(A\sqcup B = S\) ranked subset convolution \(O(n^22^n)\) keep overlap ranks until inversion
\(\operatorname{lcm}(a,b) = s\) divisor zeta \(O(N\log\log N)\) positive indices; output truncated at \(N\)
\(\gcd(a,b) = s\) multiple zeta \(O(N\log\log N)\) positive indices

The recurring proof is always the same: rewrite “exactly this result” as a sum over “results below (or above) this index”, factor the now-independent choices, and invert. XOR is the exception, using multiplicative signs from group characters. Decide which proof applies before calling the library routine.
