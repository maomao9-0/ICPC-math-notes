Sources and maintenance policy

The textbook’s proofs are written from definitions and checked independently; a linked editorial is supporting evidence, not permission to copy its claims. The rewrite found mistakes even in official-hosted explanatory material. Small exhaustive calculations complement proofs but do not certify arbitrary instances or randomized error bounds.

Verification records

The repository maintains CONTENT_AUDIT.md as the complete original chapter inventory and disposition tracker, CURRICULUM.md as the editorial dependency plan, and VALIDATION_REPORT.md as the integrated result. Detailed AUDIT and VALIDATION documents record chapter findings and checks. Exact small-instance oracles live under tests/; site checks under scripts/. HTTP reachability and mathematical relevance are recorded separately.

Original exercises include local solutions. External statements are linked instead of reproduced. Where a site blocks automated access, the validation report states that limitation; it is neither a confirmed broken link nor a successful content check.

Trust order

  1. Official problem statements and official contest editorials.
  2. Official library specifications and verification suites.
  3. Author or setter tutorials, and established Codeforces tutorials.
  4. Standard references such as Concrete Mathematics or Stanley’s Enumerative Combinatorics for theorem statements.
  5. Community explanations, used only after checking the mathematics.

Link conventions

  • Link directly to a task, not a search result.
  • Link an official editorial separately from the statement.
  • Mark [JA], [ZH], or another language code when the target is not English.
  • Codeforces ratings are recorded only when the problem page supplies one.
  • Native scores and ratings are optional metadata and should be omitted if they have not been verified; course-relative difficulty is sufficient.
  • ICPC and Universal Cup problems receive only the course’s local level; an invented numeric rating is worse than no rating.

Copyright and spoilers

Problem statements and editorials are not mirrored. Each practice entry says what skill it trains and supplies progressively stronger hints in collapsed blocks. Those hints should reconstruct the decisive reduction, not reproduce an implementation or the original editorial.

Link rot

Contest sites occasionally move PDF editorials. If a link dies, retain the contest, year, round, and problem letter in the entry so it remains searchable; then prefer a new official URL over an unofficial mirror. The last mechanical link audit is recorded in the repository handoff rather than claimed permanently inside these notes.
