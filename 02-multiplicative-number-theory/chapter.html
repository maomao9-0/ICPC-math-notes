02 — Multiplicative Number Theory

Counting with the wrong index

Suppose you must count the pairs \((x,y)\) with \(1 \le x, y \le 10^7\) and \(\gcd(x,y) = 1\). Iterating over pairs is \(10^{14}\) operations. Iterating over gcd values is \(10^7\). Same problem, different index, seven orders of magnitude.

That is the whole subject of this chapter. Nothing here is about numbers being mysterious; everything is about re-indexing a sum so the work collapses:

  • from integers to their prime powers, because most quantities of interest are determined independently at each prime;
  • from pairs to their gcd, turning an exact condition into a weighted sum over divisors;
  • from all \(n\) values of \(\lfloor n/i \rfloor\) to the \(O(\sqrt n)\) distinct ones, because the quotient is constant on long stretches.

Learn the three re-indexings and the formulas write themselves. Memorize the formulas instead and you will be stuck the moment a problem perturbs them.

Prerequisites and learning objectives

You need unique factorization and double counting and modular fields and valuations.

By the end you should be able to reconstruct an arithmetic function from its values on prime powers, prove Möbius inversion instead of quoting it, turn a gcd restriction into a sum over multiples, and decide between sieving a bounded domain and factoring a handful of large values.

Definitions and notation

An arithmetic function assigns a coefficient to each positive integer — concretely, an array indexed from \(1\). Coefficients live in the integers or in a stated commutative ring, and no division is assumed unless a unit condition is stated.

The standard cast: \(\mathbf 1(n) = 1\) for all \(n\); \(\operatorname{id}(n) = n\); and \(\varepsilon(n)\), which is \(1\) at \(n=1\) and \(0\) elsewhere. Be careful to distinguish the pointwise product \(f(n)g(n)\) from Dirichlet convolution \(f*g\), introduced below; they are different operations and contest editorials rarely say which they mean.

A factorization \(n = \prod_p p^{e_p}\) has finitely many nonzero exponents, and \(1\) is the empty product. Zero is outside the domain of every divisor transform here.

1. Getting the prime factorization at all

Everything below assumes you can see a number’s prime powers. For values up to \(10^7\) a sieve does it. For isolated 64-bit values it does not, and trial division by all primes up to \(2^{32}\) is far too slow. The standard pair of tools is Miller–Rabin to decide primality and Pollard–Rho to split composites.

Miller–Rabin: turning Fermat’s test into a real test

Fermat’s little theorem says a prime \(n\) satisfies \(a^{n-1} \equiv 1\). The converse is false, so a naive Fermat test has false positives. Miller–Rabin extracts more information from the same exponentiation by looking at the square roots encountered along the way.

Write \(n - 1 = d \cdot 2^s\) with \(d\) odd, and consider the chain

\[a^d, \; a^{2d}, \; a^{4d}, \; \ldots, \; a^{2^s d} = a^{n-1}.\]

If \(n\) is prime, the last value is \(1\), and in a field the only square roots of \(1\) are \(\pm 1\) (because \(x^2 - 1 = (x-1)(x+1)\) has at most two roots). So the chain must either start at \(1\) or hit \(-1\) before it first hits \(1\). A base \(a\) whose chain does neither is a witness: it proves \(n\) composite, with no probability attached.

A base that passes is only evidence, so several bases are tried. For unsigned 64-bit inputs the set

\[\{2,\ 325,\ 9375,\ 28178,\ 450775,\ 9780504,\ 1795265022\}\]

is known to be sufficient — it has been verified exhaustively over the whole range, so the test is deterministic there, not probabilistic. (The certificate is catalogued in the SPRP base database.) Handle \(n < 4\) and even \(n\) first, reduce every base modulo \(n\), and skip a base that reduces to zero rather than treating it as a witness. Cost: \(O(\log n)\) modular multiplications per base.

NoteBoth outcomes on small inputs

\(n = 21\): \(n - 1 = 5 \cdot 4\), so \(d = 5\), \(s = 2\). With base \(2\) the chain is \(2^5 = 11\), then \(11^2 = 121 \equiv 16\), then \(16^2 = 256 \equiv 4\). It never starts at \(1\) and never hits \(20 = -1\), so \(2\) witnesses that \(21\) is composite.

\(n = 2047 = 23 \cdot 89\) passes base \(2\) completely. One base is never enough; this is the smallest counterexample and the reason for the base list above.

Pollard–Rho: finding a factor you cannot see

Iterate \(f(x) = x^2 + c \bmod n\) from a random start. Modulo the unknown prime factor \(p\), this sequence must cycle after about \(\sqrt p\) steps by the birthday bound — but you cannot observe it modulo \(p\), only modulo \(n\).

The trick: if two iterates \(x, y\) collide modulo \(p\), then \(p \mid (x - y)\), so \(\gcd(|x-y|, n)\) is a nontrivial divisor of \(n\) — computed without ever knowing \(p\). Floyd or Brent cycle detection supplies the candidate pairs, and batching many differences into a single gcd makes it fast in practice. The expected time is heuristically \(O(\sqrt p)\) for the smallest factor \(p\), usually quoted as \(O(n^{1/4})\) for a balanced semiprime.

Pitfalls. Handle \(n < 2\) separately; use unsigned 128-bit multiplication; restart with a new \(c\) when the gcd comes back as \(n\) itself; remember the recursion receives prime powers as well as semiprimes, so re-test primality at each level; and accept that the runtime bound is heuristic, not worst-case.

2. Multiplicative functions: local data determines global

A function \(f\) is multiplicative when \(f(1) = 1\) and \(f(ab) = f(a)f(b)\) for coprime \(a, b\). Combined with unique factorization, this says something strong and very usable:

\[f(n) = \prod_p f(p^{e_p}).\]

A multiplicative function is completely specified by its values on prime powers. That is why sieves that build \(f\) one prime at a time are possible at all, and why “compute \(f\) for all \(n \le N\)” is an \(O(N)\) task rather than \(N\) independent factorizations.

The coprimality hypothesis is not decoration. \(f(ab) = f(a)f(b)\) can fail badly when \(a\) and \(b\) share a prime: \(\varphi(2)\varphi(2) = 1\) while \(\varphi(4) = 2\). Functions that do satisfy it unconditionally are called completely multiplicative; \(\operatorname{id}\) is, \(\varphi\) is not.

\(f(n)\) value at \(p^e\) what it counts
\(\varphi\) \(p^e - p^{e-1}\) units modulo \(n\)
\(\mu\) \(-1\) if \(e = 1\), else \(0\) the Dirichlet inverse of \(\mathbf 1\)
\(\tau\) \(e + 1\) divisors of \(n\)
\(\sigma_k\) \(1 + p^k + \cdots + p^{ek}\) \(k\)-th powers of the divisors, summed

Each entry is a small count, and each is worth deriving once.

  • Totient at \(p^e\): among the \(p^e\) residues, the non-units are exactly the \(p^{e-1}\) multiples of \(p\). Multiplicativity across different primes is CRT: a unit modulo \(ab\) is exactly an independent pair of units modulo \(a\) and modulo \(b\).
  • Divisor count and divisor sums: a divisor picks each exponent independently from \(0, \ldots, e_p\), which is a product over primes.
  • Möbius: define \(\mu(1) = 1\), \(\mu(n) = 0\) if any exponent exceeds one, and \(\mu(n) = (-1)^r\) for a product of \(r\) distinct primes. Multiplicative, again by independent choices per prime. Its meaning is inclusion–exclusion signs, made explicit in Section 3.

The linear sieve, and its one clever rule

Building all these up to \(N\) in \(O(N)\) rests on a single idea: visit each composite exactly once, through its least prime factor. Every composite \(x\) has a unique representation \(x = i \cdot p\) where \(p = \operatorname{lpf}(x)\) and \(i = x/p\), and this is the one the sieve emits.

Concretely, loop \(i = 2, \ldots, N\), and for each known prime \(p \le \operatorname{lpf}(i)\) with \(ip \le N\), emit \(ip\). The famous “break when \(p \mid i\)” rule is exactly the condition \(p \le \operatorname{lpf}(i)\); without it, composites are emitted several times and the running time degrades, but worse, the value updates become wrong.

The updates need to know whether \(p\) already divides \(i\), because that decides whether the exponent of \(p\) is fresh:

  • if \(p \nmid i\): \(\mu(ip) = -\mu(i)\) and \(\varphi(ip) = (p-1)\varphi(i)\);
  • if \(p \mid i\): \(\mu(ip) = 0\) and \(\varphi(ip) = p\,\varphi(i)\).

Both lines are just the prime-power table applied locally. For a general multiplicative \(f\) you additionally need to store, for each \(i\), the exponent of its least prime (or the value \(f\) takes on that prime power), since the local factor changes from \(f(p^e)\) to \(f(p^{e+1})\). Total cost: \(O(N)\) time and memory, producing primes, \(\mu\), \(\varphi\), and any similar function simultaneously.

3. Dirichlet convolution and Möbius inversion

Convolution of arrays combines indices by addition. There is an analogous operation for arithmetic functions that combines indices by multiplication:

\[(f*g)(n) = \sum_{d \mid n} f(d)\,g(n/d),\]

the sum over all ordered factorizations \(n = d \cdot (n/d)\). For example \((\mathbf 1 * \mathbf 1)(6) = 4 = \tau(6)\), since each of the four divisors of \(6\) chooses one factorization.

Three structural facts, each with a one-line reason:

  • Associative: both \(((f*g)*h)(n)\) and \((f*(g*h))(n)\) expand to \(\sum_{abc = n} f(a)g(b)h(c)\) — the same ordered triples, grouped differently.
  • Commutative: swap the two factors of each factorization.
  • Multiplicativity is preserved: for coprime \(u, v\), every divisor of \(uv\) splits uniquely into a divisor of \(u\) times a divisor of \(v\), so the sum factors.

The identity element is \(\varepsilon\), since \((f * \varepsilon)(n) = f(n)\).

The key identity, and what it means

\[\mathbf 1 * \mu = \varepsilon .\]

Proof. For \(n\) with \(r \ge 1\) distinct prime factors, the divisors with \(\mu \ne 0\) are exactly the products of subsets of those primes, and \(\mu\) contributes \((-1)^{|S|}\):

\[\sum_{d \mid n}\mu(d) = \sum_{S \subseteq [0,r)}(-1)^{|S|} = \prod_{i=0}^{r-1}(1 - 1) = 0 .\]

For \(n = 1\) the empty product gives \(1\). So \(\mu\) is precisely the sequence of inclusion–exclusion signs, packaged so that “sum over divisors” can be undone.

Möbius inversion is now pure algebra. If \(F\) is the divisor-sum of \(f\), then \(F = f * \mathbf 1\); convolving both sides with \(\mu\) cancels \(\mathbf 1\) and returns \(f\):

\[F(n) = \sum_{d \mid n} f(d) \quad\Longleftrightarrow\quad f(n) = \sum_{d \mid n}\mu(d)\,F(n/d).\]

This is worth re-deriving rather than memorizing, because the same two lines handle every variant you meet (sums over multiples, sums over subsets, sums over a general poset).

Some identities that follow, and which you will use constantly:

\[\mathbf 1 * \varphi = \operatorname{id}, \qquad \mu * \operatorname{id} = \varphi, \qquad \mathbf 1 * \mathbf 1 = \tau.\]

Why \(\sum_{d \mid n}\varphi(d) = n\): classify each \(a \in \{1,\ldots,n\}\) by \(d = n/\gcd(a,n)\). Writing \(a = (n/d)b\), the valid \(b\) are exactly the \(\varphi(d)\) values in \(\{1,\ldots,d\}\) coprime to \(d\). Every \(a\) lands in exactly one class, so the classes partition \(n\) elements. The second identity is the first one inverted.

The gcd filter: the workhorse pattern

Here is the identity that solves the problem this chapter opened with:

\[[\gcd(x,y) = 1] = \sum_{d \mid x,\; d \mid y} \mu(d).\]

Why: the right side is \(\sum_{d \mid g}\mu(d)\) for \(g = \gcd(x,y)\), which is \(1\) when \(g = 1\) and \(0\) otherwise — exactly \(\varepsilon(g)\).

The payoff is that an exact, entangled condition on a pair becomes a weighted sum of independent conditions. Summing over all pairs,

\[\#\{(x,y) : \gcd(x,y) = 1\} = \sum_d \mu(d)\,A_d B_d,\]

where \(A_d\) and \(B_d\) count multiples of \(d\) in each coordinate — quantities that are usually trivial to compute. More generally, when the condition is “gcd equals \(g\)”, group the pairs by gcd, write down the resulting divisor relation, and invert it.

NoteWorked example: coprime pairs in a \(4 \times 4\) box

Count \((x,y)\) with \(1 \le x,y \le 4\) and \(\gcd(x,y) = 1\). For each \(d\) there are \(\lfloor 4/d\rfloor\) multiples in each coordinate, so

\[\sum_{d=1}^{4}\mu(d)\left\lfloor\frac4d\right\rfloor^2 = 16 - 4 - 1 + 0 = 11.\]

Verify by hand: the rows \(x = 1,2,3,4\) contribute \(4, 2, 3, 2\), total \(11\).

Now a warning about what the number means. For unordered pairs of distinct values, first remove the one coprime diagonal entry \((1,1)\) and then halve: \((11-1)/2 = 5\). Halving \(11\) directly would compound an ordered/unordered error with a diagonal error — and would not even be an integer.

NoteThe dynamic version

Maintain \(C_d\), the number of currently active values divisible by \(d\). Before inserting \(x\), the number of active values coprime to it is

\[\sum_{d \mid x}\mu(d)\,C_d,\]

and only square-free \(d\) contribute, so a value with \(r\) distinct primes costs \(2^r\) terms. Then increment \(C_d\) for those divisors. Deletion is the exact algebraic inverse: decrement first, then apply the same formula to the remaining set.

With active values \(\{2,3\}\), inserting \(6\) gives \(2 - 1 - 1 + 0 = 0\) new coprime pairs; inserting \(5\) gives \(2\). This is the whole reduction behind the first contest exercise below.

4. Divisor transforms: sieving a whole array at once

When a problem is about all \(n \le N\) simultaneously, do not process values individually — transform the entire array.

The divisor zeta transform replaces each entry by the sum over its divisors, \(F[j] = \sum_{d \mid j} f[d]\). Looping over divisor–multiple pairs directly costs \(N(1 + \tfrac12 + \cdots) = O(N \log N)\), which is often fine. The faster route mirrors a multidimensional prefix sum, one prime at a time:

For each prime \(p\): for \(i\) increasing with \(ip \le N\), do f[i*p] += f[i].

Cost \(O(N \log\log N)\). The invariant that makes it correct: after processing a set of primes, \(f[x]\) holds the sum over exactly those divisors of \(x\) obtained by lowering the exponents of the processed primes, each counted once. Ascending \(i\) order is what lets a contribution travel up a whole prime-power chain (\(1 \to 2 \to 4 \to 8\)), and that is exactly why the inverse transform uses the same pairs in descending order with subtraction.

The multiple zeta transform reverses the divisibility direction: \(F[d] = \sum_{d \mid j} f[j]\), computed with f[i] += f[i*p] for \(i\) decreasing, and inverted by subtracting with \(i\) increasing.

Which one you need depends on the operation you are trying to diagonalize: divisor zeta linearizes LCM convolution, multiple zeta linearizes GCD convolution. The general poset statement appears in Chapter 08.

“Diagonalizes” means a double count. If \(h[x] = \sum_{\operatorname{lcm}(a,b) = x} f[a]g[b]\), then

\[\sum_{d \mid x} h[d] = \sum_{a \mid x}\sum_{b \mid x} f[a]g[b] = F[x]\,G[x],\]

where the first equality holds because \(\operatorname{lcm}(a,b) \mid x\) is equivalent to (\(a \mid x\) and \(b \mid x\)). So: transform, multiply pointwise, transform back. Flip every divisibility sign and the same proof gives GCD convolution with the multiple transform.

Example. With \(f[1] = 2\), \(f[2] = 3\), \(f[3] = 5\), the transformed value at \(6\) is \(f[1] + f[2] + f[3] + f[6]\). This is the integer analogue of the subset zeta transform, with “submask” replaced by “divisor”.

Recognition. Reach for these when every operation replaces a value by all its divisors, when queries involve \(\gcd\) or \(\operatorname{lcm}\), or when values are bounded while the number of queries is large.

5. Quotient grouping: only \(O(\sqrt n)\) distinct floors

Sums like \(\sum_{i=1}^{n} \lfloor n/i \rfloor\) look like \(n\) separate terms, but the quotient takes only about \(2\sqrt n\) distinct values — it changes rarely for large \(i\) and is large-but-few for small \(i\).

Precisely: \(\lfloor n/i \rfloor = q\) exactly when \(n/(q+1) < i \le n/q\), so once the quotient equals \(q\) at position \(l\), it stays constant up to

\[r = \left\lfloor \frac{n}{q} \right\rfloor,\qquad q = \left\lfloor\frac nl\right\rfloor.\]

Hence the loop for (l = 1; l <= n; l = r + 1) performs \(O(\sqrt n)\) iterations, each handling a whole block. Combine it with prefix sums of \(\mu\), \(\varphi\), powers, or whatever function the summand carries.

With two numerators in the same summand, compute the block end for each and take the minimum. Watch the degenerate case: once a quotient reaches zero it stays zero for the rest of the loop, and evaluating m/(m/l) with a zero quotient divides by zero.

A derivation worth internalizing, because it shows the two pictures are the same object:

\[\sum_{i=1}^{n}\left\lfloor\frac ni\right\rfloor = \#\{(a,b) : ab \le n\} = \sum_{k \le n}\tau(k).\]

The middle expression counts lattice points under a hyperbola; the left counts them column by column, the right by the product.

6. Dirichlet inverses and designing a prefix-sum recurrence

If \(f(1)\) is invertible in the coefficient ring, \(f\) has a Dirichlet inverse \(g\) with \(f * g = \varepsilon\). It is computed greedily: the \(n=1\) equation determines \(g(1)\), and each larger equation contains exactly one new unknown, namely the \(d = 1\) term \(f(1)g(n)\). Solving for it,

\[g(1) = \frac{1}{f(1)}, \qquad g(n) = -\frac{1}{f(1)}\sum_{\substack{d \mid n \\ d > 1}} f(d)\,g(n/d).\]

This is the mechanism behind a family of sublinear prefix-sum algorithms. Here is the design pattern. You want \(G(N) = \sum_{n \le N} g(n)\) for a hard \(g\). Find an easy convolution identity \(f * g = h\) with \(f\) and \(h\) both easy to sum. Then summing over \(n \le N\) and grouping by the \(f\)-factor,

\[\sum_{n \le N} h(n) = \sum_{d \le N} f(d)\, G\!\left(\left\lfloor \frac Nd \right\rfloor\right).\]

The \(d = 1\) term is \(f(1)G(N)\) — the unknown you want. Move it to the left, and evaluate the remaining sum by quotient grouping, which needs \(G\) only at the \(O(\sqrt N)\) distinct quotients. Memoize and recurse. That is the Du Jiao sieve, developed in Chapter 14.

7. Gaussian integers and sums of two squares

A different flavour of factorization, and a good illustration that “factorization” is a property of a ring rather than of numbers.

The Gaussian integers \(\mathbb Z[i]\) are the complex numbers \(a + bi\) with integer coordinates. Their norm \(N(a+bi) = a^2 + b^2\) is a nonnegative integer and is multiplicative: \(N(zw) = N(z)N(w)\), because \(N(z) = z\bar z\) and conjugation respects products. Multiplicativity of the norm is precisely what makes “is \(n\) a sum of two squares?” a question about factorization.

\(\mathbb Z[i]\) also supports Euclidean division: to divide \(\alpha\) by nonzero \(\beta\), round each coordinate of the complex quotient \(\alpha/\beta\) to a nearest integer. Each coordinate is off by at most \(1/2\), so the remainder has norm at most \(N(\beta)/2 < N(\beta)\). With division-with-remainder come Euclid, Bézout, and — as in Chapter 00 — unique factorization into irreducibles. The units are the four elements of norm one, \(\pm 1, \pm i\). In code, test the few rounding candidates with exact integer arithmetic; floating point picks the wrong quotient for large coordinates.

Fermat’s two-square theorem. A positive integer \(n\) is a sum of two squares exactly when every prime \(p \equiv 3 \pmod 4\) occurs in \(n\) with an even exponent.

NoteWhy the criterion is true

Necessity. Suppose \(p \equiv 3 \pmod 4\) divides \(a^2 + b^2\) with \(p \nmid b\). Then \((a/b)^2 = -1\) in \(\mathbb F_p\), so \(-1\) is a quadratic residue — but Euler’s criterion from Chapter 01 gives \((-1)^{(p-1)/2} = -1\) for \(p \equiv 3 \pmod 4\). Contradiction, so \(p \mid b\) and then \(p \mid a\). Remove \(p^2\) and repeat: the exponent of \(p\) must be even.

Sufficiency. For \(p \equiv 1 \pmod 4\), cyclicity of \(\mathbb F_p^\times\) supplies \(t\) with \(t^2 \equiv -1\). Put \(\delta = \gcd(p, t+i)\) in \(\mathbb Z[i]\). It is not a unit: otherwise Bézout multiplied by \(t - i\) would force \(p \mid t - i\), impossible since the imaginary coordinate is \(-1\). It is not an associate of \(p\) either, since \(p \nmid t+i\). As \(\delta \mid p\), its norm divides \(p^2\), and we just excluded norms \(1\) and \(p^2\); hence \(N(\delta) = p\), i.e. \(p\) is a sum of two squares. Together with \(2 = N(1+i)\), even powers of \(3 \bmod 4\) primes, and multiplicativity of the norm, every allowed \(n\) is representable.

Constructing a representation. For \(p \equiv 1 \pmod 4\), find a square root of \(-1\) modulo \(p\) (Tonelli–Shanks) and run Cornacchia’s Euclidean descent to obtain \(p = x^2 + y^2\). For \(p^e\), raise the Gaussian integer: \((x + yi)^e\), not the coordinates separately. The remaining local cases are explicit: \(2^e = N((1+i)^e)\), and a \(3 \bmod 4\) prime with exponent \(2e\) contributes \(p^{2e} = (p^e)^2 + 0^2\). Combine local pieces with the Brahmagupta–Fibonacci identity, which is nothing but \(N(zw) = N(z)N(w)\) written out:

\[(a^2+b^2)(c^2+d^2) = (ac - bd)^2 + (ad + bc)^2 .\]

Normalize signs and ordering only at the very end.

Worked example. \(65 = 5 \cdot 13\) with \(5 = N(2+i)\) and \(13 = N(3+2i)\). Multiply in \(\mathbb Z[i]\): \((2+i)(3+2i) = 4 + 7i\), giving \(65 = 4^2 + 7^2\). Multiplying coordinates separately would give \(6^2 + 2^2 = 40\), which is not even the right number — norms multiply, coordinates do not.

This construction produces a representation. Counting all representations is a separate task requiring you to track the choice of conjugate at each prime and quotient by the unit symmetries.

Contest checklist

  • Multiplicative is not completely multiplicative: \(\varphi(p^2) \ne \varphi(p)^2\).
  • Decide whether your divisor formula uses \(f(d)\) or \(f(n/d)\) before you code it; the two differ whenever \(f\) is not symmetric in that swap.
  • \(\mu(n) = 0\) as soon as a prime square divides \(n\); only square-free divisors ever contribute.
  • Frequency transforms need a bounded value domain. For a few large values, factor them and do inclusion–exclusion over their prime subsets instead.
  • Quotient blocks must use 64-bit division, and with several floors the block end is the minimum over all of them.
  • Pollard–Rho returns a multiset of factors with repetitions; compress it before enumerating divisors or subsets.

5. Coprime Arrays — Codeforces 915G

  • Level: Mastery · Language: English/Russian
  • Trains: counting by gcd, divisor zeta transform, inversion.
  • Editorial: official Educational Round 36 tutorial
Hint 1 First count arrays whose every element is divisible by \(d\).
Hint 2 This counts gcds that are multiples of \(d\); invert over the divisibility poset.
Hint 3 The task needs every upper bound, so take differences of the Möbius formula and accumulate contributions over divisor–multiple pairs.
TipEditorial guidance: all upper bounds

Let \(B(i)=\sum_{d\le i}\mu(d)\lfloor i/d\rfloor^n\) and \(B(0)=0\), for the positive array length \(n\). The floor changes from \(i-1\) to \(i\) only when \(d\mid i\), so \(B(i)-B(i-1)=\sum_{d\mid i}\mu(d)((i/d)^n-(i/d-1)^n)\). Precompute powers, add these differences over all \(i=dt\le k\), then prefix sum. Cost is \(O(k\log n+k\log k)\) arithmetic operations and \(O(k)\) memory. For \(n=3,k=4\), the counts are \(1,7,25,55\). Apply the statement’s final XOR/output aggregation only after reducing each count as specified. Recomputing a full inversion for every upper bound would be too slow.

Exercises with solutions

1. A multiplicativity trap — concept check

Compute \(\tau(12)\), \((\mu * \mathbf 1)(12)\), and \(\varphi(12)\) from prime powers. Then explain why \(\tau(12) \ne \tau(6)\tau(2)\).

TipHint and solution

Hint: check the coprimality hypothesis before using multiplicativity.

From \(12 = 2^2 \cdot 3\): \(\tau(12) = 3 \cdot 2 = 6\) and \(\varphi(12) = (4-2)(3-1) = 4\). The square-free divisors of \(12\) are \(1, 2, 3, 6\) with signs \(1, -1, -1, +1\), so \((\mu * \mathbf 1)(12) = 0\), as \(\mathbf 1 * \mu = \varepsilon\) predicts.

But \(\tau(6)\tau(2) = 4 \cdot 2 = 8 \ne 6\). Multiplicativity applies only to coprime arguments, and \(6\) and \(2\) share the prime \(2\). Splitting at a shared prime double-counts that prime’s exponent choices.

2. Recover an arithmetic function — derivation

Suppose \(\sum_{d \mid n} f(d) = n^2\) for every positive \(n\). Find \(f(p^e)\) and \(f(12)\).

TipHint and solution

Hint: at a prime power, subtract consecutive equations.

At \(p^e\) the divisors are \(1, p, \ldots, p^e\), so subtracting the equation at \(p^{e-1}\) from the one at \(p^e\) leaves \(f(p^e) = p^{2e} - p^{2e-2}\) for \(e \ge 1\), with \(f(1) = 1\).

Möbius inversion says \(f = \mu * \operatorname{id}^2\), a convolution of two multiplicative functions, hence multiplicative. Therefore \(f(12) = f(4)f(3) = (16-4)(9-1) = 96\).

Interpretation: \(f(n)\) counts ordered pairs of residues modulo \(n\) such that the pair and \(n\) have joint gcd one — the prime-by-prime exclusion of pairs both divisible by \(p\) is exactly the factor \(p^{2e} - p^{2e-2}\).

3. Equal gcd with a fixed value — modelling

For positive integers \(m, k\), count the \(1 \le x \le m\) with \(\gcd(x,k) = d\), using only square-free divisors.

TipHint and solution

Hint: substitute \(x = dy\) to turn “gcd equals \(d\)” into “gcd equals \(1\)”.

If \(d \nmid k\) the answer is \(0\). Otherwise \(x = dy\) with \(y \le \lfloor m/d \rfloor\) and \(\gcd(y, k/d) = 1\). Applying the gcd filter,

\[\sum_{e \mid k/d}\mu(e)\left\lfloor \frac{m}{de} \right\rfloor .\]

For \(m = 10\), \(k = 12\), \(d = 2\): \(5 - 2 - 1 + 0 = 2\), realized by \(x = 2\) and \(x = 10\).

Only square-free \(e\) contribute, so after factoring \(k/d\) this is \(O(2^{\omega(k/d)})\) terms, where \(\omega\) counts distinct primes.

4. Regroup a floor sum — synthesis

Derive \(\sum_{i=1}^{N} i\lfloor N/i \rfloor = \sum_{n=1}^{N}\sigma_1(n)\), then give an algorithm using \(O(\sqrt N)\) arithmetic operations.

TipHint and solution

Hint: both sides count weighted lattice points under a hyperbola.

The left side gives weight \(i\) to each pair \((i,j)\) with \(ij \le N\). Group those pairs by the product \(n = ij\): the weights are the divisors \(i\) of \(n\), summing to \(\sigma_1(n)\). Hence the two sides agree.

For the algorithm, use quotient grouping: on a block \([l,r]\) where the quotient is the constant \(q\), the contribution is \(q \cdot (l+r)(r-l+1)/2\). That division by \(2\) is exact over the integers — divide the even factor before reducing modulo anything, since \(2\) need not be a unit.

Check at \(N = 5\): \(5 + 4 + 3 + 4 + 5 = 21\), and \(\sigma_1(1..5) = 1+3+4+7+6 = 21\).

Summary and reference sheet

  • A multiplicative function is determined by its prime-power values; that is what makes \(O(N)\) sieves and prime-by-prime derivations possible. Shared primes break naive splitting.
  • Dirichlet convolution sums over factorizations \(n = ab\). It is associative, commutative, has identity \(\varepsilon\), and preserves multiplicativity.
  • \(\mathbf 1 * \mu = \varepsilon\) is inclusion–exclusion over prime subsets; Möbius inversion is that identity plus associativity, not a separate fact.
  • The gcd filter \([\gcd = 1] = \sum_{d \mid \gcd}\mu(d)\) converts an exact entangled condition into independent counts of multiples.
  • Divisor zeta ascends prime-power chains, multiple zeta descends; each inverse reverses the direction and subtracts. They diagonalize LCM and GCD convolution respectively.
  • Costs: linear sieve \(O(N)\); direct divisor sums \(O(N\log N)\); prime-wise transforms \(O(N \log\log N)\); quotient grouping \(O(\sqrt N)\) blocks.
  • 64-bit factorization has a deterministic primality contract (Miller–Rabin with the fixed base set) and a heuristic splitting runtime (Pollard–Rho).
  • \(n\) is a sum of two squares exactly when every prime \(\equiv 3 \pmod 4\) has even exponent; build representations by multiplying Gaussian integers, never coordinates.
