02 — Multiplicative Number Theory

Why this topic matters

This chapter is about changing the indexing of a sum: from integers to prime powers, from pairs to their gcd, or from every quotient to the \(O(\sqrt n)\) distinct values of \(\lfloor n/i\rfloor\). The formulas are less important than the objects they regroup. Each section says what a new coordinate represents, so that it can be re-derived when the statement changes slightly.

Prerequisites and learning objectives

Use unique factorization and double counting and modular fields and valuations. After reading, you should be able to derive a function from its prime-power values, prove divisor inversion, convert gcd restrictions to frequency sums, and choose between a sieve over a bounded domain and factorization of sparse values.

Definitions and notation

An arithmetic function assigns a coefficient to each positive integer. Coefficients lie in the integers or a stated commutative ring; no division is assumed unless a unit condition is stated. The function \(\mathbf1(n)=1\) is constant one, \(\operatorname{id}(n)=n\), and \(\varepsilon\) is one at \(n=1\) and zero elsewhere. Products of function values differ from Dirichlet convolution, denoted \(*\) below. The prime factorization \(n=\prod_p p^{e_p}\) has only finitely many nonzero exponents; \(1\) is the empty product. Zero is outside the divisor-transform domain.

1. Reliable 64-bit primality and factorization

Factorization is useful because most arithmetic functions are determined by a number’s prime powers. Trial division asks every small prime whether it divides \(n\), which becomes too slow for large 64-bit inputs. For arbitrary unsigned 64-bit integers, use deterministic Miller–Rabin to tell primes from composites and Pollard–Rho to split composites.

Miller–Rabin

For odd \(n\), write \(n-1=d\cdot2^{s}\) with \(d\) odd. If \(n\) is prime and \(a\not\equiv0\pmod n\), set \(x=a^d\). Because \(x^{2^s}=1\) and a field has only the two square roots \(\pm1\) of \(1\), the squaring chain must either start at \(1\) or reach \(-1\) before it reaches \(1\). A base that does neither is a witness that \(n\) is composite. A base that passes is only evidence, which is why several bases are tested. After handling \(n<4\) and reducing every base modulo \(n\), testing bases

\[\{2,\ 325,\ 9375,\ 28178,\ 450775,\ 9780504,\ 1795265022\}\]

is deterministic for \(0\le n<2^{64}\) with the usual small/even branches. A base that reduces to zero is skipped, not treated as a compositeness witness; other bases must still be tested. The finite-range certificate is recorded in the SPRP base database. Complexity is \(O(\log n)\) modular multiplications per base.

For example, \(n=21\) has \(n-1=5\cdot4\). For base \(2\), the chain starts \(2^5=11\bmod21\), then squares to \(16\), then \(4\); it neither starts at one nor reaches \(-1=20\). Thus \(2\) witnesses compositeness. Passing one base is weaker: \(2047=23\cdot89\) passes base two.

Pollard–Rho

Iterate a pseudo-random polynomial \(f(x)=x²+c \bmod n\). Although the sequence is not visibly periodic modulo \(n\), it eventually cycles modulo an unknown factor \(p\). If two iterates \(x,y\) agree modulo \(p\), then \(p\mid(x-y)\), and \(\gcd(|x-y|,n)\) can reveal a nontrivial divisor without knowing \(p\) first. Floyd/Brent cycle detection and batched gcds make this fast in practice. It is randomized with heuristic expected time about \(O(p^{1/2})\) for a factor \(p\), often described as \(O(n^{1/4})\) for balanced semiprimes.

Pitfalls. Handle \(n<2\); use unsigned 128-bit multiplication; restart Rho when it returns \(n\); recursion receives prime powers as well as semiprimes; randomized runtime has no strict worst-case guarantee.

2. Multiplicative functions and the linear sieve

\(f\) is multiplicative when \(f(1)=1\) and \(f(ab)=f(a)f(b)\) for coprime \(a,b\). Prime factorization then says that \(f(n)\) is the product of its values on the prime-power factors of \(n\). It does not say \(f(ab)=f(a)f(b)\) when \(a,b\) share a prime. For example \(\varphi(2)\varphi(2)=1\) but \(\varphi(4)=2\). Central examples are:

\(f(n)\) prime-power value \(f(p^{e})\) interpretation
\(\varphi\) \(p^{e}-p^{e-1}\) units modulo \(n\)
\(\mu\) \(-1\) if \(e=1\), else \(0\) inverse of constant-one function
\(τ\) \(e+1\) number of divisors
\(\sigma_k\) \(1+p^{k}+…+p^{ek}\) sum of kth powers of divisors

The totient prime-power formula follows by deleting the \(p^{e-1}\) multiples of \(p\) among \(p^e\) residues. CRT pairs independent unit choices for coprime moduli, proving multiplicativity of \(\varphi\). Divisor counts and sums factor because a divisor independently chooses each exponent \(0,\ldots,e_p\). For \(\mu\), define \(\mu(1)=1\), \(\mu(n)=0\) when any exponent exceeds one, and \(\mu(n)=(-1)^r\) for a product of \(r\) distinct primes. This is also multiplicative by independent prime choices.

The Euler/linear sieve visits each composite exactly once as \(i\cdot p\), where \(p\) is its least prime factor. The “stop when \(p\) divides \(i\)” rule is what makes that representation unique. Keep enough information about the exponent of the least prime to distinguish, for example, whether adding another \(p\) makes \(\mu\) zero or changes \(\varphi(p^e)\) to \(\varphi(p^{e+1})\). It computes primes, \(\mu\), and \(\varphi\) through \(N\) in \(O(N)\) time and memory. More precisely, process \(i=2,\ldots,N\) and primes \(p\le\operatorname{lpf}(i)\) while \(ip\le N\), where \(\operatorname{lpf}(i)\) is the least prime factor. Every composite \(x\) appears at \(p=\operatorname{lpf}(x),i=x/p\) because \(\operatorname{lpf}(i)\ge p\). Any other emitted representation would have a different least prime factor. If \(p\nmid i\), then \(\mu(ip)=-\mu(i)\) and \(\varphi(ip)=(p-1)\varphi(i)\); if \(p\mid i\), then \(\mu(ip)=0\) and \(\varphi(ip)=p\varphi(i)\). These follow directly from the local table.

3. Dirichlet convolution and Möbius inversion

For arithmetic functions, Dirichlet convolution combines two functions by splitting an integer into an ordered pair of divisors:

\[ (f*g)(n)=\sum_{d\mid n} f(d)g(n/d). \]

For example \((1*1)(6)\) counts the divisors of \(6\), because each divisor \(d\) chooses the factorization \(6=d\cdot(6/d)\). It is associative and commutative, with identity \(ε(1)=1\), \(ε(n>1)=0\). Convolution preserves multiplicativity. Let \(1(n)=1\); since \(1*\mu=ε\),

\[F(n)=\sum_{d\mid n}f(d)\quad\Longleftrightarrow\quad f(n)=\sum_{d\mid n}\mu(d)F(n/d).\]

This is not a formula to memorize in isolation. \(F(n)\) is the sum of \(f\) over divisors of \(n\), so it says \(F=f*1\); convolving both sides with \(\mu\) cancels \(1\) and recovers \(f\). Useful identities follow immediately:

\[1*\varphi=\operatorname{id},\qquad \mu*\operatorname{id}=\varphi, \qquad 1*1=\tau.\]

Why convolution identities hold

Associativity groups the same ordered triples \(abc=n\): both \(((f*g)*h)(n)\) and \((f*(g*h))(n)\) equal \(\sum_{abc=n}f(a)g(b)h(c)\). Commutativity swaps the two factors. For coprime \(u,v\), every divisor of \(uv\) uniquely splits into a divisor of \(u\) and a divisor of \(v\), proving that convolution preserves multiplicativity.

For \(n\) with \(r\) distinct prime factors, the divisors contributing nonzero \(\mu\) correspond to subsets of those primes. Consequently

\[\sum_{d\mid n}\mu(d)=\sum_{S\subseteq[0,r)}(-1)^{|S|} =\prod_{i=0}^{r-1}(1-1)=\varepsilon(n).\]

For \(n=1\) the empty product is one; otherwise cancellation gives zero. This proves the inverse identity that the earlier algebra uses. Likewise classify \(1\le a\le n\) by \(d=n/\gcd(a,n)\). Writing \(a=(n/d)b\) leaves exactly the \(\varphi(d)\) values \(1\le b\le d\) coprime to \(d\). Every \(a\) has one such class, so \(\sum_{d\mid n}\varphi(d)=n\).

GCD counting pattern

If a condition asks for \(\gcd(x,y)=1\), the following identity is a filter:

\[[\gcd(x,y)=1]=\sum_{d\mid x,\ d\mid y}\mu(d).\]

Why does it work? If \(g=\gcd(x,y)\), the right side is \(\sum_{d\mid g}\mu(d)\), which is \(1\) when \(g=1\) and \(0\) otherwise. The pair sum becomes \(\sum_d \mu(d) A_d B_d\), where \(A_d,B_d\) count multiples of \(d\). More generally, group pairs by their gcd, derive a divisor zeta relation, then invert.

Worked example: ordered coprime pairs. Count \((x,y)\) with \(1\le x,y\le4\) and \(\gcd(x,y)=1\). For a fixed divisor \(d\), there are \(\lfloor4/d\rfloor\) choices for each coordinate, so the filter gives

\[\sum_{d=1}^4\mu(d)\lfloor4/d\rfloor^2=16-4-1+0=11.\]

The row counts by \(x=1,2,3,4\) are \(4,2,3,2\), also summing to \(11\). For unordered distinct pairs, first remove the only coprime diagonal \((1,1)\) and then divide by two, giving \(5\). Dividing \(11\) by two first would combine an ordered/unordered error with a diagonal error.

Dynamic translation. Maintain \(C_d\), the number of active values divisible by \(d\). Before inserting \(x\), the number of new coprime unordered pairs is \(\sum_{d\mid x}\mu(d)C_d\). Then increment these counts. For deletion, decrement first and use the same formula on the remaining set. Only square-free divisors matter, so a factorization with \(r\) distinct primes gives \(2^r\) terms. For active values \(\{2,3\}\), inserting \(6\) creates \(2-1-1+0=0\) coprime pairs; inserting \(5\) creates two. This is the reduction behind the first contest exercise.

4. Divisor zeta/Möbius transforms

For arrays on \([1,N]\), the divisor zeta transform replaces the value at \(j\) by the sum of values stored at its divisors: \(F[j]=\sum_{d\mid j}f[d]\). Direct non-in-place divisor loops cost \(N(1+1/2+\cdots+1/N)=O(N\log N)\); inversion follows from the arithmetic Möbius formula. Prime-wise in-place updates compute the transform and its inverse in \(O(N\log\log N)\). For each prime \(p\), the divisor-zeta update \(f[ip]\mathrel{+}=f[i]\) for \(ip\le N\) must traverse \(i\) upward so prime powers accumulate; its inverse uses the same pairs in downward \(i\) order while subtracting. For example, the \(p=2\) stage sends the contribution at \(1\) first to \(2\), then that accumulated contribution to \(4\). After a set of prime stages, the value at \(x\) has accumulated exactly the divisors obtained by lowering the exponents of those primes; this is the no-overcounting invariant. The multiple zeta transform \(F[d]=\sum_{d\mid j}f[j]\) reverses the divisibility order: for each prime \(p\), apply \(f[i]\mathrel{+}=f[ip]\) with \(i\) decreasing, and invert with subtraction while \(i\) increases. Divisor zeta diagonalizes LCM convolution, while multiple zeta diagonalizes GCD convolution; the more general poset view appears in the transforms chapter.

The word “diagonalizes” is a double count. If \(h[x]=\sum_{\operatorname{lcm}(a,b)=x}f[a]g[b]\), then

\[ \sum_{d\mid x}h[d] =\sum_{a\mid x}\sum_{b\mid x}f[a]g[b] =F[x]G[x]. \]

The first equality holds because \(\operatorname{lcm}(a,b)\mid x\) exactly when both \(a\mid x\) and \(b\mid x\). Reversing all divisibility signs gives the same proof for GCD convolution and the multiple transform.

Example. If \(f[1]=2,f[2]=3,f[3]=5\), then the transformed value at \(6\) is \(f[1]+f[2]+f[3]+f[6]\). This is the integer analogue of a subset zeta transform: “submask” becomes “divisor.” Recognition. If every operation replaces a set by all divisors, every query involves \(\gcd\), or values are bounded while query count is large, transform the entire frequency vector instead of processing elements individually.

5. Quotient grouping (harmonic lemma)

The value \(q=\lfloor n/l\rfloor\) does not change one index at a time. Once it has value \(q\), it remains constant through

\[r=\left\lfloor n/q\right\rfloor.\]

This works because \(\lfloor n/i\rfloor=q\) exactly when \(n/(q+1)<i\le n/q\). Thus a loop for (l=1; l<=n; l=r+1) has only \(O(\sqrt n)\) iterations. The distinct quotients are precisely the small integers up to \(\sqrt n\) plus values \(\lfloor n/i\rfloor\) for small \(i\).

For two or more floor terms, take the minimum end point: if a summand uses \(\lfloor n/i\rfloor\) and \(\lfloor m/i\rfloor\), then compute the end point for each nonzero current quotient and take their minimum. If the loop continues beyond one numerator, that quotient is zero and remains zero through the loop’s final bound; do not evaluate m/(m/l) when m/l is zero. Pair this with prefix sums of \(\mu\), \(\varphi\), powers, or another arithmetic function.

A standard derivation is

\[\sum_{i=1}^n \left\lfloor\frac ni\right\rfloor =\sum_{ab\le n}1=\sum_{k\le n}\tau(k),\]

showing how a floor sum and a divisor sum are the same lattice-point count.

6. Dirichlet inverses and recurrence design

If \(f(1)≠0\) in a coefficient field, its Dirichlet inverse is the function \(g\) for which \(f*g=ε\). The \(n=1\) equation fixes \(g(1)\); every larger \(n\) equation has exactly one unknown term, \(f(1)g(n)\), giving the recurrence

\[g(1)=1/f(1),\qquad g(n)=-\frac1{f(1)}\sum_{\substack{d\mid n\\d>1}}f(d)g(n/d).\]

In prefix-sum problems, search for an easy convolution identity \(f*g=h\). Summing for \(n≤N\) and swapping divisors yields

\[\sum_{n\le N}h(n)=\sum_{d\le N}f(d)\,G(\lfloor N/d\rfloor).\]

If the \(d=1\) term contains the unknown prefix \(G(N)\), isolate it. Quotient grouping then turns the rest into \(O(\sqrt{N})\) states. This is the bridge to Du Jiao sieve in Chapter 03.

7. Gaussian integers and two squares

The Gaussian integers \(\mathbb Z[i]\) are numbers \(a+bi\) with integer coordinates. Their norm \(N(a+bi)=a^{2}+b^{2}\) is nonnegative and, crucially, multiplicative: \(N(zw)=N(z)N(w)\). They admit Euclidean division by rounding a complex quotient to nearby integer coordinates. Hence gcd, units, associates, and unique factorization behave much like the integers. Use exact integer arithmetic to test the few rounding candidates; floating point may select the wrong quotient for large coordinates.

For a positive integer \(n\), Fermat’s two-square theorem says \(n\) is a sum of two squares iff every prime \(p=3 \bmod 4\) has even exponent. For \(p=1 \bmod 4\), find a square root of \(-1 \bmod p\) and run Cornacchia/Euclidean descent to obtain \(p=x^{2}+y^{2}\). The local representation of \(p^e\) is then \((x+yi)^e\): it is important to raise the Gaussian integer, not merely the integer coordinates. The other local cases are explicit: \(2^e=N((1+i)^e)\), and a \(3\bmod4\) prime with exponent \(2e\) contributes \(p^{2e}=(p^e)^2+0^2\). Multiply local representations with

\[ (a^{2}+b^{2})(c^{2}+d^{2})=(ac-bd)^{2}+(ad+bc)^{2}, \]

Normalize signs/order only after constructing the result.

Why the two-square criterion is true

For \(z=a+bi\), complex conjugation sends it to \(\bar z=a-bi\), and \(N(z)=z\bar z\). Hence \(N(zw)=N(z)N(w)\). To divide Gaussian integers \(\alpha\) by nonzero \(\beta\), round each coordinate of \(\alpha/\beta\) to a nearest integer. The squared distance is at most \(1/2\), so the remainder has norm at most \(N(\beta)/2\). Euclid and the Bézout argument therefore work in this ring. Its units are the elements of norm one: \(\pm1,\pm i\); associates differ by a unit. As for ordinary integers, Euclid’s divisibility lemma proves unique factorization into irreducible Gaussian integers.

If \(p\equiv3\pmod4\) divides \(a^2+b^2\) and \(p\nmid b\), then \((a/b)^2=-1\) in \(\mathbb F_p\). Euler’s criterion rules this out because \((-1)^{(p-1)/2}=-1\). Thus \(p\mid b\) and also \(p\mid a\). Removing \(p^2\) and repeating proves that such primes have even valuation.

If \(p\equiv1\pmod4\), cyclicity supplies \(t\) with \(t^2=-1\bmod p\). Let \(\delta=\gcd(p,t+i)\) in the Gaussian integers. It is not a unit: otherwise a Bézout equation multiplied by \(t-i\) would force \(p\mid t-i\), contradicting its imaginary coordinate \(-1\). It is not associated to \(p\) either, since \(p\) does not divide the imaginary coordinate of \(t+i\). Because \(\delta\mid p\), its norm divides \(p^2\), and the two excluded possibilities are norm one and norm \(p^2\). Therefore \(N(\delta)=p\). Together with \(2=N(1+i)\) and multiplication of norms, this proves sufficiency.

For \(65=5\cdot13\), multiply \((2+i)(3+2i)=4+7i\), giving \(65=4^2+7^2\). Multiplying coordinates separately would give \(6^2+2^2=40\), which does not preserve norms. This construction finds a representation; counting all representations requires separately tracking conjugate-factor choices and symmetries.

Contest checklist

  • Multiplicative is not completely multiplicative: \(\varphi(p²)≠\varphi(p)²\).
  • Decide whether a divisor formula uses \(f(d)\) or \(f(n/d)\) before coding.
  • \(\mu(n)=0\) whenever a prime square divides \(n\).
  • Frequency transforms require a bounded value domain; factorization-based inclusion–exclusion may be better for sparse large values.
  • Quotient blocks must use 64-bit division; for multiple floors, update the end point for each one.
  • Pollard–Rho factor lists contain repetitions; compress them before enumerating divisors or inclusion–exclusion subsets.

Exercises with solutions

1. A multiplicativity trap — concept check

Compute \(\tau(12)\), \((\mu*\mathbf1)(12)\), and \(\varphi(12)\) from prime powers. Why is \(\tau(12)\ne\tau(6)\tau(2)\)?

TipHint and solution

Since \(12=2^2\cdot3\), \(\tau(12)=3\cdot2=6\) and \(\varphi(12)=(4-2)(3-1)=4\). The square-free divisor signs give \(1-1-1+1=0\). But \(\tau(6)\tau(2)=4\cdot2=8\); multiplying values requires coprime arguments, whereas \(6,2\) share a prime.

2. Recover an arithmetic function — derivation

Suppose \(\sum_{d\mid n}f(d)=n^2\) for every positive \(n\). Find \(f(p^e)\) and \(f(12)\).

TipHint and solution

At a prime power, subtract the equations at \(p^e\) and \(p^{e-1}\): \(f(p^e)=p^{2e}-p^{2e-2}\) for \(e\ge1\), with \(f(1)=1\). Inversion says \(f=\mu*\operatorname{id}^2\), hence it is multiplicative. Thus \(f(12)=(16-4)(9-1)=96\). It counts ordered pairs of residues modulo \(n\) whose coordinates and \(n\) have joint gcd one, by excluding pairs both divisible by each prime.

3. Equal gcd with a fixed value — modelling

For positive integers \(m,k\), count \(1\le x\le m\) with \(\gcd(x,k)=d\). Express the answer using only square-free divisors.

TipHint and solution

If \(d\nmid k\), the answer is zero. Otherwise write \(x=dy\); we need \(y\le\lfloor m/d\rfloor\) and \(\gcd(y,k/d)=1\). Apply the filter: \(\sum_{e\mid k/d}\mu(e)\lfloor m/(de)\rfloor\). For \(m=10,k=12,d=2\), it is \(5-2-1+0=2\), represented by \(x=2,10\). Enumerating only square-free \(e\) takes \(O(2^{\omega(k/d)})\) terms after factorization, where \(\omega\) counts distinct primes.

4. Regroup a floor sum — synthesis

Derive \(\sum_{i=1}^N i\lfloor N/i\rfloor=\sum_{n=1}^N\sigma_1(n)\) and obtain an \(O(\sqrt N)\) arithmetic-operation algorithm.

TipHint and solution

Each left summand gives weight \(i\) to every pair \((i,j)\) with \(ij\le N\). Grouping by \(n=ij\) sums all divisors \(i\) of \(n\), giving \(\sigma_1(n)\). On a quotient block \([l,r]\) with quotient \(q\), the contribution is \(q(l+r)(r-l+1)/2\). The division is exact in integers; divide an even factor before modular reduction when two is not a unit. For \(N=5\), the value is \(5+4+3+4+5=21\).

Summary and reference sheet

Prime-power values determine a multiplicative function, but shared primes prevent naive multiplication. Dirichlet convolution enumerates factorizations \(n=ab\); \(\mathbf1*\mu=\varepsilon\) follows from cancellation over prime subsets. The gcd filter converts exact coprimality into weighted counts of multiples. Divisor zeta uses increasing prime-power updates; multiple zeta uses decreasing updates. Their inverses reverse those directions.

A linear sieve costs \(O(N)\) arithmetic operations and storage; direct divisor sums cost \(O(N\log N)\), prime-wise transforms \(O(N\log\log N)\), and floor quotient grouping uses \(O(\sqrt N)\) blocks. Factorization of isolated 64-bit values has a deterministic primality contract and a heuristic randomized splitting runtime. Positive two-square representations exist exactly when every \(3\bmod4\) prime has even valuation.
