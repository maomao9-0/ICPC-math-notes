02 — Multiplicative Number Theory

This chapter is about changing the indexing of a sum: from integers to prime powers, from pairs to their gcd, or from every quotient to the O(√n) distinct values of ⌊n/i⌋. Those changes of viewpoint are the core of advanced ICPC number theory.

1. Reliable 64-bit primality and factorization

Trial division is enough only up to roughly 10^12 for a few inputs. For arbitrary unsigned 64-bit integers, use deterministic Miller–Rabin and Pollard–Rho.

Miller–Rabin

For odd n, write n-1=d·2^s, d odd. If n is prime, each base a has a^d=1 or reaches -1 while repeatedly squaring. A witness that does neither proves compositeness. Testing bases

{2, 325, 9375, 28178, 450775, 9780504, 1795265022}

is deterministic for all 64-bit inputs. Complexity is O(log n) modular multiplications per base.

Pollard–Rho

Iterate a pseudo-random polynomial f(x)=x²+c mod n. If two iterates coincide modulo an unknown factor p, then gcd(|x-y|,n) reveals a divisor. Floyd/Brent cycle detection and batched gcds make this fast in practice. It is randomized with heuristic expected time about O(p^(1/2)) for a factor p, often described as O(n^(1/4)) for balanced semiprimes.

Pitfalls. Handle n<2; use unsigned 128-bit multiplication; restart Rho when it returns n; recursion receives prime powers as well as semiprimes; randomized runtime has no strict worst-case guarantee.

2. Multiplicative functions and the linear sieve

f is multiplicative when f(1)=1 and f(ab)=f(a)f(b) for coprime a,b. It is determined by values on prime powers. Central examples:

f(n) prime-power value f(p^e) interpretation
φ p^e-p^(e-1) units modulo n
μ -1 if e=1, else 0 inverse of constant-one function
τ e+1 number of divisors
σ_k 1+p^k+…+p^(ek) sum of kth powers of divisors

The Euler/linear sieve visits each composite exactly once as i·p, where p is its least prime factor. It computes primes, μ, and φ through N in O(N) time and memory.

3. Dirichlet convolution and Möbius inversion

For arithmetic functions,

\[ (f*g)(n)=\sum_{d\mid n} f(d)g(n/d). \]

It is associative and commutative, with identity ε(1)=1, ε(n>1)=0. Convolution preserves multiplicativity. Let 1(n)=1; since 1*μ=ε,

\[F(n)=\sum_{d\mid n}f(d)\quad\Longleftrightarrow\quad f(n)=\sum_{d\mid n}\mu(d)F(n/d).\]

This is not a formula to memorize in isolation. Derive it by convolving F=f*1 with μ. Useful identities follow immediately:

\[1*\varphi=\operatorname{id},\qquad \mu*\operatorname{id}=\varphi, \qquad 1*1=\tau.\]

GCD counting pattern

If a condition asks for gcd(x,y)=1, insert

\[[\gcd(x,y)=1]=\sum_{d\mid x,\ d\mid y}\mu(d).\]

The pair sum becomes Σ_d μ(d) A_d B_d, where A_d,B_d count multiples of d. More generally, group pairs by their gcd, derive a divisor zeta relation, then invert.

For arrays on [1,N], the divisor zeta transform computes F[j]=Σ_{d|j} f[d]:

This costs N(1+1/2+…+1/N)=O(N log N). Its inverse can subtract in reverse divisor order, or use prime-wise updates. The multiple zeta transform F[d]=Σ_{d|j}f[j] uses the same loop with the accumulation direction reversed. These diagonalize gcd/LCM-style convolutions; the more general poset view appears in the transforms chapter.

Recognition. If every operation replaces a set by all divisors, every query involves gcd, or values are bounded while query count is large, transform the entire frequency vector instead of processing elements individually.

5. Quotient grouping (harmonic lemma)

The value q=⌊n/l⌋ remains constant through

\[r=\left\lfloor n/q\right\rfloor.\]

Thus a loop for (l=1; l<=n; l=r+1) has only O(√n) iterations. The distinct quotients are precisely the small integers up to √n plus values ⌊n/i⌋ for small i.

For two or more floor terms, take the minimum end point: if a summand uses ⌊n/i⌋ and ⌊m/i⌋, then r=min(n/(n/l), m/(m/l)). Pair this with prefix sums of μ, φ, powers, or another arithmetic function.

A standard derivation is

\[\sum_{i=1}^n \left\lfloor\frac ni\right\rfloor =\sum_{ab\le n}1=\sum_{k\le n}\tau(k),\]

showing how a floor sum and a divisor sum are the same lattice-point count.

6. Dirichlet inverses and recurrence design

If f(1)≠0 in a coefficient field, its Dirichlet inverse exists:

\[g(1)=1/f(1),\qquad g(n)=-\frac1{f(1)}\sum_{\substack{d\mid n\\d>1}}f(d)g(n/d).\]

In prefix-sum problems, search for an easy convolution identity f*g=h. Summing for n≤N and swapping divisors yields

\[\sum_{n\le N}h(n)=\sum_{d\le N}f(d)\,G(\lfloor N/d\rfloor).\]

If the d=1 term contains the unknown prefix G(N), isolate it. Quotient grouping then turns the rest into O(√N) states. This is the bridge to Du Jiao sieve in Chapter 03.

7. Gaussian integers and two squares

The Gaussian integers Z[i] have norm N(a+bi)=a^2+b^2 and admit Euclidean division by rounding a complex quotient to nearby integer coordinates. Hence gcd, units, associates, and unique factorization behave much like the integers. Use exact integer arithmetic to test the few rounding candidates; floating point may select the wrong quotient for large coordinates.

Fermat’s two-square theorem says n is a sum of two squares iff every prime p=3 mod 4 has even exponent. For p=1 mod 4, find a square root of -1 mod p and run Cornacchia/Euclidean descent to obtain p=x^2+y^2. Multiply representations with

\[ (a^2+b^2)(c^2+d^2)=(ac-bd)^2+(ad+bc)^2, \]

and include the forced contributions of 2 and 3 mod 4 primes. Normalize signs/order only after constructing the result.

Contest checklist

  • Multiplicative is not completely multiplicative: φ(p²)≠φ(p)².
  • Decide whether a divisor formula uses f(d) or f(n/d) before coding.
  • μ(n)=0 whenever a square divides n.
  • Frequency transforms require a bounded value domain; factorization-based inclusion–exclusion may be better for sparse large values.
  • Quotient blocks must use 64-bit division; for multiple floors, update the end point for each one.
  • Pollard–Rho factor lists contain repetitions; compress them before enumerating divisors or inclusion–exclusion subsets.
